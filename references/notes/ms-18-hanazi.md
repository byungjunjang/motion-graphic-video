## 5. 타이포

- 글꼴은 굵고 둥근 고딕이다. 획 끝이 둥글다. 세로 자막과 작은 자막도 같은 계열이다. 속삭임 자막만 보통 굵기의 작은 글자(약 50px)이고, 한 글자씩 써진다.
- 층 구조(제목 기준) · 노랑 그라데이션 면(위 연노랑 → 아래 주황 #FCB424 근처) → 흰 테 약 14px → 분홍 테 약 14px → 아래쪽 짙은 분홍 두께 약 10px. 충격 자막은 빨강 그라데이션 면(위 분홍빛 빨강 → 아래 짙은 빨강) → 흰 테 약 16px → 짙은 남보라 테 약 10px.
- 자막 종류와 자리 · 제목은 아래 가운데, 속삭임은 왼쪽 위 작게, 기호 무리는 오른쪽 위, 세로 혼잣말은 왼쪽 가장자리, 소개 자막(작은 꼬리표 + 큰 이름 + 작은 설명)은 왼쪽 가운데 비스듬히(약 -10°), 띠 자막(빨강 판에 노랑·빨강 사선 테, 양끝 경고 삼각형, 폭 72%)은 아래, 충격은 가운데 아래 큰 상자 안, 마무리는 아래 가운데 가장 크게. 감정마다 자리와 모양이 다르다.

- 원작은 세로 1080x1920 이다. 16:9(1920x1080)로 옮기는 구도.
  - 바탕 사진은 16:9 전체를 채운다. 주인공 요소는 가로 30~75%, 세로 5~100% 에 둔다(원작처럼 화면 높이의 60~100%). 주인공 요소를 가운데 세로 띠(가로 656~1264)에만 두고 양옆을 비우지 않는다.
  - 자막 크기는 화면 높이 비율로 옮긴다. 제목 9%(97px), 띠 자막 글자 6%(65px), 충격 자막 14%(151px → 한국어 상한 140px), 마무리 15%(→ 140px). 줄 폭은 원작의 화면 폭 비율 대신 1920 의 45~60%(860~1150px)로 둔다. 가로가 넓어져 폭 비율을 그대로 쓰면 글자가 140px 를 넘는다.
  - 자리 · 제목과 띠 자막은 아래(세로 72~92%), 가로 가운데. 기호 무리는 오른쪽 위(가로 70~92%, 세로 8~45%). 세로 자막은 왼쪽(가로 6~12%, 세로 20~85%). 소개 자막은 왼쪽 가운데(가로 6~30%, 세로 45~65%). 충격 구간은 오려 낸 주인공 요소를 가로 25~75%, 세로 5~70% 에, 충격 상자를 가로 20~80%, 세로 62~95% 에 둔다.
  - 끝 화면 · 카드(약 700x560, +4°)를 가로 10~47% 에, 마무리 자막과 작별 자막을 가로 52~92% 에 두 줄로 놓는다. 둥근 표식은 카드 오른쪽 아래 모서리에 걸친다.
  - 구석 이름표는 왼쪽 위(가로 3~22%, 세로 4~14%).
- 코드로 만들 때 밀도가 줄어드는 지점과 막는 법.
  - 실사 바탕이 빠진다 · 재현 시험의 가장 큰 감점이었다. 도형 배경으로 바꾸지 않는다. `## 8` 의 바탕 대체 순서를 따른다.
  - 펀치가 부드러운 확대가 된다 · 줌은 한 프레임에 바뀐다. `scale = 1.3^k`(k 는 지나간 펀치 수)로 계단처럼 올린다. 펀치 프레임에 흰 덮개 `opacity 0.4` 를 한 프레임만 준다.
  - 섬광이 빠진다 · 60% 상당 시점에 흰 화면 두 프레임(불투명), 75% 상당 시점에 흰 덮개 0.8 두 프레임을 넣는다. 둘 다 타격 박에 맞춘다.
  - 컷이 적다 · 12초 판도 하드 컷 6번 이상, 그중 4번을 1초 안에 몰아 둔다.
  - 자막이 얇다 · 흰 테가 없으면 사진 위에서 묻힌다. 흰 테 14~16px 와 바깥 색 테 8~14px 를 반드시 둔다.
  - 한 번에 자막 하나 · 장면마다 자막과 기호를 4개 이상 겹친다.
- 한국어 · 둥근 굵은 글꼴이 없다. Pretendard SemiBold 에 테 두 겹과 두께를 얹으면 굵기가 보충된다. 글자는 140px 를 넘기지 않는다. 짧은 감탄(2~4자)을 고른다.
- 원본 화면의 실존 로고·이름은 쓰지 않는다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

16:9(1920x1080) 기준 값이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 실사 바탕 | 저장소에 사진이 없고 실사는 코드로 못 그린다 | 순서대로 고른다. (1) 사용자가 준 대상 사진(허락받은 파일). (2) codex-image 사실적 사진풍 일러스트, 글자·로고 없이. 장면마다 1장, 2560x1440 이상으로 만든다(켄 번스와 펀치 여유). 구도별(전체 모습·아주 가까이·절반 크기) 1장씩. 같은 개체가 다시 나오면 같은 그림을 다시 쓴다. (3) 둘 다 안 되면 canvas 그림(단순화한 주인공 형태 + 흐린 배경 원 덩어리)으로 하되 충격 구간은 방사 햇살 배경으로 대체한다 | (2) 사진의 결과 생생함 일부, (3) 실사 느낌 전부 |
| 줌 펀치 누적 약 2.8배 | 원본 해상도가 모자라면 흐려진다 | 펀치 구간 원본은 3840x2160 으로 만들거나, 누적 배율을 2.0배(1.26배 x 3)로 낮춘다. 확대 중심은 주인공 요소의 시선이 모이는 점 | 마지막 펀치의 압박감 |
| 오려 낸 주인공 스티커 | 배경 제거가 필요하다 | codex-image 로 마젠타 바탕 위에 그리고 `scripts/key.py` 로 투명 PNG 로 만든다. 사용자 사진이면 직접 오려 받는다. 테두리는 canvas 에서 외곽을 24px 키운 흰 면 + `HAND.wobble(P, true, 6, 'tear', 0)` 로 톱니를 만들고 회색 2px 선 | 정확한 가장자리 |
| 둥근 굵은 글꼴 | 저장소에 Pretendard Regular·SemiBold 뿐이다 | Pretendard SemiBold. SVG `<text>` 를 세 번 겹친다. 바깥 `stroke` 색 테 30px(`paint-order: stroke`), 가운데 `stroke` 흰색 16px, 안쪽 `fill` 그라데이션. 아래 두께는 같은 글자를 (0,8)px 에 짙은 색으로 한 번 더. `stroke-linejoin: round` | 둥근 획 끝 |
| 손그림 만화 기호(문장부호 꼴·물방울 꼴·충격 상자·방사 획) | 손그림 결 | SVG 경로로 직접 그리고 같은 세 층(색 면 + 흰 테 + 남보라 테)을 준다. 충격 상자는 꼭짓점 16~20개 별꼴, 반지름 안 0.7 · 바깥 1.0, 꼭짓점마다 ±8% 흔들림 | 손그림 획의 불규칙함 |
| 방사 햇살·사선 줄무늬 배경 | 없다. 코드로 된다 | 햇살 · `conic-gradient` 로 분홍 #CC5484 / 노랑 #E4B43C 띠 24개(추정 색). 줄무늬 · `repeating-linear-gradient(-55deg, #24CCFC 0 70px, #FFFFFF 70px 110px)` | 없음 |
| 붉은 둥근 표식 | 도장 결 | SVG 원 2겹 + 둥근 글자(가상 문구) + `texTile` 로 얼룩 마스크. 찍힐 때 1.6 → 1.0 배, 4프레임 | 잉크 번짐 |
