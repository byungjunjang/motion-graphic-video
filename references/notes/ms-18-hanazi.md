## 1. 본질

- 바탕은 실사 고양이 사진이다. 네 장면이 다르다. 돌바닥 위에 앉은 연한 크림색 고양이(전신), 회색 줄무늬 고양이 얼굴 아주 가까이, 파랑 흐린 배경 앞 흑백 장모 고양이(가슴 위), 같은 흑백 고양이를 오려 낸 스티커 사진이다. 사진은 화면을 가득 채운다. 피사체가 화면 높이의 60~100% 를 차지한다.
- 자막 글자는 세 층이다. 안쪽은 색 그라데이션 면(노랑 → 주황, 분홍 → 빨강, 분홍 → 보라), 가운데는 두꺼운 흰 테(약 14~16px), 바깥은 색 테(분홍 #FC3C84 근처 또는 짙은 남보라 #240C3C 근처, 약 8~14px)다. 아래로 같은 색의 짙은 두께(약 8~10px)가 붙는다. 면에 흰 광택 줄이 있다.
- 색은 아주 진하다. 분홍(#FC3C84 근처), 노랑(#FCCC3C 근처), 하늘색(#24CCFC 근처), 빨강(#FC243C 근처), 흰색, 짙은 남보라 테. 흰 테가 모든 색을 사진과 떼어 놓는다.
- 만화 기호가 자막과 함께 나온다. 반짝이 별(4갈래, 지름 20~40px), 물음표 3개, 물방울 2개, 경고 삼각형, 충격 터짐 상자(노랑 톱니 테두리), 방사 속도선, 계기판 스티커, 붉은 둥근 도장.
- 왼쪽 위 구석에 프로그램 이름표(고양이 귀가 달린 말풍선 + 회차 꼬리표)가 늘 붙어 있다(가로 52~405, 세로 95~190, 화면 폭 33%).
- 아닌 것 · 얇은 흰 글자 한 줄, 화면 아래 자막 띠, 단색 배경, 차분한 디졸브, 느린 흐름, 사진 없이 도형만 있는 화면, 자막 하나만 오래 떠 있는 화면.

## 5. 타이포

- 글꼴은 굵고 둥근 고딕이다. 획 끝이 둥글다. 세로 자막과 작은 자막도 같은 계열이다. 속삭임 자막만 보통 굵기의 작은 글자(약 50px)다.
- 층 구조(제목 기준) · 노랑 그라데이션 면(위 연노랑 → 아래 주황 #FCB424 근처) → 흰 테 약 14px → 분홍 테 약 14px → 아래쪽 짙은 분홍 두께 약 10px. 충격 자막은 빨강 그라데이션 면(위 분홍빛 빨강 → 아래 짙은 빨강) → 흰 테 약 16px → 짙은 남보라 테 약 10px.
- 자막 종류와 자리 · 제목은 아래 가운데, 속삭임은 왼쪽 위 작게, 물음표는 오른쪽 위, 세로 혼잣말은 왼쪽 가장자리, 이름표는 왼쪽 가운데 비스듬히, 경고 띠는 아래, 충격은 가운데 아래 큰 상자 안, 마무리는 아래 가운데 가장 크게. 감정마다 자리와 모양이 다르다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 5.0~6.6초. 화면을 채운 실사 동물 위에 폭 72% 경고 띠 자막이 튀어 오르고, 5.27·5.50·5.77초에 한 번에 1.3~1.45배씩 줌 펀치(프레임마다 흰빛 덮개)가 들어가 눈이 화면을 채운 뒤, 6.0초 흰 섬광 두 프레임 → 6.03초 방사 햇살 위 오려 낸 사진과 화면 폭 60% 충격 자막으로 넘어간다. 펀치·섬광 없이 자막만 차례로 나오면 이 영상이 아니다.
- 12초 판 압축 예 · 10초 원본을 12초에 펼친다. 0~3.0초 장면 1(이름표 날아감, 제목 한 글자씩, 속삭임과 배터리), 3.0~4.6초 장면 2(물음표 3개, 세로 혼잣말, 물방울), 4.6~4.9초 줄무늬 쓸기, 4.9~6.3초 장면 3(이름표, 경고 띠), 6.3~7.1초 펀치 3번(0.25초 간격, 원본 박을 그대로)과 흰 섬광, 7.1~9.2초 충격 장면, 9.2~9.4초 흰 섬광 2, 9.4~9.7초 카드 축소, 9.7~12.0초 끝 화면(마무리 자막, 도장, 작별 자막, 정지 1초). 늘어난 2초는 느린 앞부분과 끝 정지에 나눈다. 펀치 구간은 늘리지 않는다.
- 감정마다 다른 자막 모양과 자리(속삭임·물음·혼잣말·소개·경고·충격·마무리).
- 글자 세 층(색 면 + 흰 테 + 색 테)과 아래 두께.
- 한 글자씩 2~4프레임 엇갈려 0 → 1.15 → 1.0 배로 튀어 오르는 등장.
- 느린 앞 절반과 컷·펀치·섬광이 몰리는 뒤 절반의 대비.
- 늘 붙어 있는 프로그램 이름표와, 코너 사이 줄무늬 쓸기.

## 7. 함정

- 화면의 자막 문장, 프로그램 이름, 회차 표시, 출연자 이름, 도장 글자는 원작의 것이다. 옮기지 않는다. 역할(코너 제목, 속삭임 한 줄, 혼잣말 세로줄, 출연자 소개, 경고 한 마디, 충격 한 마디, 마무리 한 마디, 작별 인사, 인증 도장)만 가져온다.
- 원작은 세로 1080x1920 이다. 16:9(1920x1080)로 옮기는 구도.
  - 바탕 사진은 16:9 전체를 채운다. 피사체는 가로 30~75%, 세로 5~100% 에 둔다(원작처럼 화면 높이의 60~100%). 피사체를 가운데 세로 띠(가로 656~1264)에만 두고 양옆을 비우지 않는다.
  - 자막 크기는 화면 높이 비율로 옮긴다. 제목 9%(97px), 경고 띠 글자 6%(65px), 충격 자막 14%(151px → 한국어 상한 140px), 마무리 15%(→ 140px). 줄 폭은 원작의 화면 폭 비율 대신 1920 의 45~60%(860~1150px)로 둔다. 가로가 넓어져 폭 비율을 그대로 쓰면 글자가 140px 를 넘는다.
  - 자리 · 제목과 경고 띠는 아래(세로 72~92%), 가로 가운데. 물음표는 오른쪽 위(가로 70~92%, 세로 8~45%). 세로 혼잣말은 왼쪽(가로 6~12%, 세로 20~85%). 이름표는 왼쪽 가운데(가로 6~30%, 세로 45~65%). 충격 장면은 오려 낸 사진을 가로 25~75%, 세로 5~70% 에, 충격 상자를 가로 20~80%, 세로 62~95% 에 둔다.
  - 끝 화면 · 카드(약 700x560, +4°)를 가로 10~47% 에, 마무리 자막과 작별 자막을 가로 52~92% 에 두 줄로 놓는다. 도장은 카드 오른쪽 아래 모서리에 걸친다.
  - 프로그램 이름표는 왼쪽 위(가로 3~22%, 세로 4~14%).
- 코드로 만들 때 밀도가 줄어드는 지점과 막는 법.
  - 실사 바탕이 빠진다 · 재현 시험의 가장 큰 감점이었다. 도형 배경으로 바꾸지 않는다. `## 8` 의 바탕 대체 순서를 따른다.
  - 펀치가 부드러운 확대가 된다 · 줌은 한 프레임에 바뀐다. `scale = 1.3^k`(k 는 지나간 펀치 수)로 계단처럼 올린다. 펀치 프레임에 흰 덮개 `opacity 0.4` 를 한 프레임만 준다.
  - 섬광이 빠진다 · 6.0초 상당 시점에 흰 화면 두 프레임(불투명), 7.5초 상당 시점에 흰 덮개 0.8 두 프레임을 넣는다. 둘 다 타격 박에 맞춘다.
  - 컷이 적다 · 12초 판도 하드 컷 6번 이상, 그중 4번을 1초 안에 몰아 둔다.
  - 자막이 얇다 · 흰 테가 없으면 사진 위에서 묻힌다. 흰 테 14~16px 와 바깥 색 테 8~14px 를 반드시 둔다.
  - 한 번에 자막 하나 · 장면마다 자막과 기호를 4개 이상 겹친다.
- 한국어 · 둥근 굵은 글꼴이 없다. Pretendard SemiBold 에 테 두 겹과 두께를 얹으면 굵기가 보충된다. 글자는 140px 를 넘기지 않는다. 짧은 감탄(2~4자)을 고른다.
- 실존 프로그램처럼 보이는 이름표나 실존 방송사 로고를 흉내 내지 않는다. 가상 코너 이름을 쓴다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

16:9(1920x1080) 기준 값이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 실사 바탕 사진 4장 | 저장소에 사진이 없고 실사는 코드로 못 그린다 | 순서대로 고른다. (1) 사용자가 준 대상 사진(허락받은 파일). (2) codex-image 사실적 사진풍 일러스트, 글자·로고 없이. 장면마다 1장, 2560x1440 이상으로 만든다(켄 번스와 펀치 여유). 전신 1장, 얼굴 아주 가까이 1장, 가슴 위 1장. 같은 개체가 필요한 장면 3·4 는 같은 그림을 다시 쓴다. (3) 둘 다 안 되면 canvas 그림(단순화한 동물 + 흐린 배경 원 덩어리)으로 하되 장면 4 는 방사 햇살 배경으로 대체한다 | (2) 사진의 털 결과 생생함 일부, (3) 실사 느낌 전부 |
| 줌 펀치 누적 약 2.8배 | 원본 해상도가 모자라면 흐려진다 | 장면 3 원본은 3840x2160 으로 만들거나, 누적 배율을 2.0배(1.26배 x 3)로 낮춘다. 확대 중심은 눈 사이 | 마지막 펀치의 압박감 |
| 오려 낸 사진 스티커 | 배경 제거가 필요하다 | codex-image 로 마젠타 바탕 위에 그리고 `scripts/key.py` 로 투명 PNG 로 만든다. 사용자 사진이면 직접 오려 받는다. 테두리는 canvas 에서 외곽을 24px 키운 흰 면 + `HAND.wobble(P, true, 6, 'tear', 0)` 로 톱니를 만들고 회색 2px 선 | 정확한 털 가장자리 |
| 둥근 굵은 글꼴 | 저장소에 Pretendard Regular·SemiBold 뿐이다 | Pretendard SemiBold. SVG `<text>` 를 세 번 겹친다. 바깥 `stroke` 색 테 30px(`paint-order: stroke`), 가운데 `stroke` 흰색 16px, 안쪽 `fill` 그라데이션. 아래 두께는 같은 글자를 (0,8)px 에 짙은 색으로 한 번 더. `stroke-linejoin: round` | 둥근 획 끝 |
| 손으로 그린 기호(물음표·물방울·충격 상자·방사 획) | 손그림 결 | SVG 경로로 직접 그리고 같은 세 층(색 면 + 흰 테 + 남보라 테)을 준다. 충격 상자는 꼭짓점 16~20개 별꼴, 반지름 안 0.7 · 바깥 1.0, 꼭짓점마다 ±8% 흔들림 | 손그림 획의 불규칙함 |
| 방사 햇살·사선 줄무늬 배경 | 없다. 코드로 된다 | 햇살 · `conic-gradient` 로 분홍 #CC5484 / 노랑 #E4B43C 띠 24개(추정 색). 줄무늬 · `repeating-linear-gradient(-55deg, #24CCFC 0 70px, #FFFFFF 70px 110px)` | 없음 |
| 붉은 인증 도장 | 도장 결 | SVG 원 2겹 + 둥근 글자(가상 문구) + `texTile` 로 얼룩 마스크. 찍힐 때 1.6 → 1.0 배, 4프레임 | 잉크 번짐 |
