# 리소그래프 판 어긋남으로 찍은 스튜디오 소개 — 분석 노트

> 미색 종이 위에 분홍·파랑·노랑·주황 네 색 판을 겹쳐 찍은 듯한 69초 스튜디오 소개 영상. 모든 면과 글자에 리소그래프 특유의 입자(잉크가 덜 묻은 흰 점)가 있고, 판이 조금씩 어긋나 글자와 도형 가장자리에 다른 색 테두리가 비친다. 장마다 바탕 무늬(사선, 점 격자, 세로 줄무늬, 수평 주사선)와 큰 도형(원, 벤 다이어그램, 번호 원, 막대 조절기)을 통째로 바꾸며, 속이 찬 굵은 한국어 글자가 화면의 주인공이다. 01→10 단계 카운터와 점 진행 막대, 숫자 강조 카드가 있다. 디자인·출판·굿즈·제작사 소개, 따뜻하고 손맛 있는 브랜드 소개에 맞는다. 리소그래프(risograph) · 판 어긋남(misregistration) · 키네틱 타이포 · 단계형 설명.

출처 · pm:rneayan-474bcf. 작성자의 프롬프트는 41자다. 주제(자기 스튜디오)와 스타일 이름(리소그래프) 하나만 정했다. 구도, 색, 장면, 문구, 길이는 없다. 같은 작성자가 같은 문장 흐름을 오실로스코프 스타일로 만든 영상이 pm:rneayan-ea6129 다(아래 "## 6" 끝에 차이를 적었다). 이 노트는 영상 프레임(1초 간격 70장, 직접 뽑은 원본 크기 8장)을 보고 썼다.
측정 · 파일 1280x720 · 30fps · 69.3초. 위치·크기는 1920x1080 으로 바꿔 적는다(1.5배). 장면 전환 검출 시각은 3.30, 16.53, 19.83, 29.77, 36.37, 39.67초다. 나머지 장 교체는 바탕이 조금씩 바뀌어 검출에 걸리지 않았다(시간표에 적었다). 0.5초마다 움직임 세기의 평균은 6.2 다. 입자 질감이 프레임마다 다시 뿌려져 정지 화면에서도 값이 2~4 아래로 잘 내려가지 않는다. 끝 카드 57~67초는 입자 떨림만 남는다. 색 값은 화소를 24단계로 묶어 잰 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. 검출 BPM 71.8(마디 약 3.3초)이다. 타격음이 고르게 약해(세기 0.3~0.5) 박자 검출은 믿기 어렵다. 0.04초에 가장 큰 타격(세기 1.00)이 있다. 29.83초(0.76)와 36.42초(0.94)의 큰 타격은 장면 컷 29.77초, 36.37초와 0.06초 안에서 맞는다. 음량은 0~29초 약 -22~-26dB, 29.8~56초 약 -13~-18dB(후반이 더 크다), 56~66초 약 -26~-30dB, 67초부터 줄어 69초에 -68dB 다. 47~56초에 저역 킥이 늘어난다(47.82, 49.74, 50.49, 51.19, 51.42, 54.72, 55.34초).

## 1. 본질

- 바탕은 미색 종이(#DCD8CC 근처, 장에 따라 화면의 40~60%)다. 가장자리가 조금 어둡다(#C0C0C0 근처). 종이 결 얼룩이 약하게 있다.
- 잉크는 다섯 색이다. 모두 근삿값이다.
  - 분홍(#E0508A 근처) · 원, 물음표, 점 격자, 구름, 끝 카드 상징
  - 파랑(#1A6AA6 근처) · 주 문장, 화살표, 벤 오른쪽 원, 연도 숫자
  - 노랑(#E2C40C 근처) · 카운터 판, 강조 띠, 라벨 상자, 해, 끝 카드 테두리
  - 주황 빨강(#E04A10 근처) · 큰 숫자(카운터, 경력 숫자), 강조 문장
  - 짙은 녹색(#1E6A28 근처) · 작은 라벨 글자와 큰 숫자의 그림자 판(추정 · 노랑 위 파랑 겹침일 수 있다)
- 겹침 · 두 판이 겹치면 곱하기처럼 어두워진다. 분홍 + 파랑 = 남색(#142060 근처, 2.5초 글자와 원이 겹친 곳, 벤 다이어그램 가운데), 노랑 + 파랑 = 녹색(55초 해와 비행선이 겹친 곳).
- 입자 · 모든 면에 흰 점이 촘촘하다. 점 하나는 1~2px(1280 기준), 덮는 비율은 면의 약 10~20% 다. 프레임마다 점 배치가 바뀐다.
- 판 어긋남 · 한 물체를 두 색으로 찍고 한 판을 조금 옮겨 둔다. 비행선(52초)은 파랑 몸통 아래 왼쪽으로 분홍 판이 약 (-24px, +18px) 비친다. 큰 연도 숫자(43초)는 파랑 위에 분홍 빗금 판이 오른쪽 아래로 약 (+10px, +8px) 어긋난다. 경력 숫자(37초)는 주황 아래로 녹색 판이 약 (+14px, +14px) 비친다.
- 아닌 것 · 그라데이션, 그림자 효과, 사진, 3D, 윤곽선만 있는 글자, 완전한 검정.

## 3. 움직임

- 등장은 튀어나오기(pop)가 많다. 원·번호 원·물음표·도장이 0.2~0.3초에 0 → 105% → 100% 로 커진다.
- 미끄러지기 · 벤 다이어그램의 두 원(1초에 양 끝 → 겹침), 완료 띠, 비행선(약 6초에 화면 폭 + 비행선 폭을 지나간다), 연도 숫자.
- 바탕이 움직인다 · 사선 줄무늬, 점 격자 크기 물결, 세로 줄무늬 모아레, 구름 흐름. 글자는 대부분 멈춰 있고 바탕과 도형이 움직인다.
- 입자는 매 프레임 다시 뿌려진다. 이것이 정지 장면에서도 움직임 세기를 2~4 로 유지한다.
- 카운터 · 9.8~14.5초 동안 01 → 10. 한 단계 약 0.45초다. 진행 막대의 원이 한 단계에 하나씩 찬다. 차는 원은 테두리 파랑 원 안에 분홍 원이 0 → 100% 로 커진다.
- 움직임 세기 목표 · 평균 6.2. 장면 컷마다 15~30 으로 뛴다. 끝 카드 10초는 2 안팎이다.

## 4. 전환

- 대부분 하드 컷이다. 장마다 바탕 종류를 통째로 바꾼다(종이 → 사선 → 점 격자 → 종이 → 노랑 판 → 줄무늬 → 종이 → 노랑 전체 → 종이 → 주사선 → 노랑 테두리).
- 같은 장 안에서는 글자와 도형만 바꾼다. 바탕은 그대로 둔다.
- 컷 6번 중 큰 타격과 맞는 것은 29.77초, 36.37초 두 번이다.
- 강조 장(공정 카운터, 경력 숫자, 끝 카드)에 노랑을 넓게 쓴다. 노랑 면적이 큰 장이 영상의 마디 역할을 한다.

## 5. 타이포

- 글꼴 · 한국어 굵은 고딕 한 계열이다. 획이 두껍고 글자 사이가 좁다. 모든 글자가 속이 찬 면이고 입자 질감이 있다.
- 크기(화면 높이 대비) · 도입 한 줄 19%, 사선 장의 동사 17%, 공정 이름 18%, 질문·위쪽 문장 7~10%, 노랑 상자 안 문장 8%, 작은 라벨 3~4%.
- 숫자 · 공정 번호 31%, 경력 숫자 약 60%, 연도 숫자 약 30%, 번호 원 안 숫자 약 12%. 숫자는 글자보다 훨씬 크게 쓴다.
- 라벨 상자 · 노랑 사각형 안에 짙은 녹색 또는 파랑 글자. 상자는 글자보다 좌우 약 0.6em, 위아래 약 0.3em 크다.
- 끝 카드 · 한국어 이름 7%, 라틴 줄 2%(분홍, 가운데점으로 연도를 붙임).

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 9.8~14.5초의 공정 카운터. 왼쪽 36%(약 690px) 노랑 판에 주황 두 자리 번호(높이 31%, 약 330px), 오른쪽 미색에 파랑 공정 이름(높이 18%, 약 190px, Pretendard 제한으로 140px), 세로 76% 에 점 10개 진행 막대(지름 78px). 동시에 보이는 요소는 판 1 + 번호 1 + 이름 1 + 점 10 + 라벨 1 이다. 번호가 약 0.45초마다 오른다.
- 12초 판 압축 예 · 0~2초 분홍 원 + 도입 문장 → 2~5.5초 공정 카운터(01 → 05 처럼 다섯 단계만, 0.6초 간격) → 5.5~8초 벤 다이어그램(두 원 겹침 + 결론 문장) → 8~10초 경력·수치 숫자 카드(노랑 전체) → 10~12초 끝 카드(2초). 사선 장, 점 격자, 질문, 줄무늬, 파이프라인 화살표, 순서 원, 조절기, 연표, 도장, 비행선 항해는 뺀다.
- 25초 판 장면 선택(원본 69초) · 도입 원 2초 → 사선 장 2초 → 공정 카운터 4초 → 파이프라인 화살표 3초 → 벤 다이어그램 3.5초 → 순서 번호 원 3초 → 경력 숫자 2.5초 → 비행선 항해 3초(대상 상징으로 바꾼다) → 끝 카드 2초. 점 격자 반전, 질문, 모아레, 조절기, 연표, 도장을 뺀다.
- 끝 로고 정지를 2초 안으로 · 원작은 56.5~67.5초 약 11초 정지 후 1.8초 페이드다. 상징이 0.3초에 튀어나오고, 이름이 0.4초 뒤에 붙고, 1.0초 정지 후 0.3초 페이드로 끝낸다(합 2.0초).
- 판 어긋남 한 가지 규칙. 주인공 물체(비행선, 큰 숫자)만 두 색 판으로 찍고 다른 요소는 한 판으로 둔다. 어긋남 방향은 영상 내내 오른쪽 아래 또는 왼쪽 아래 하나로 정한다.
- 바탕 무늬로 장을 나누는 방식. 장마다 무늬 종류를 바꾸면 컷만으로 장이 갈린다.
- 오실로스코프 판과의 차이(같은 작성자, pm:rneayan-ea6129) · 문장 흐름과 장 순서는 거의 같다. 이 판은 네 색 면, 속이 찬 굵은 글자, 입자와 판 어긋남, 장마다 바탕 교체 컷, 69초다. 오실로스코프 판은 검정 바탕 한 색 선, 윤곽 글자, 잔광으로 이어 붙인 교체, 하단 파형 띠와 상시 표기로 묶은 하나의 계측기 화면, 40초다. 이 판에만 있는 것은 01→10 카운터와 점 진행 막대, 벤 다이어그램, 막대 조절기, 도장, 알약 라벨, 지나가는 비행선이다. 오실로스코프 판에만 있는 것은 리사주 덩어리, 펄스, 사각파 연표, 눈금판 바늘, 빔이 그리는 윤곽이다.

## 7. 함정

- 화면의 스튜디오 이름(한국어·라틴), 문장, 공정 이름, 분야 라벨, 연도, 숫자는 원작의 것이다. 옮기지 않는다. 역할(도입 문장, 공정 단계, 결론 문장, 경력 숫자, 끝 이름)만 가져온다.
- 끝 카드 정지가 약 11초다. 그대로 옮기면 영상의 1/6 이 정지 화면이 된다. 2초 안으로 줄인다.
- 입자를 프레임마다 다시 뿌리면 움직임은 살지만 파일이 커지고 글자 가장자리가 지저분해진다. 작은 라벨(높이 4% 아래)에는 입자를 약하게(덮는 비율 5%) 준다.
- 판 어긋남을 모든 요소에 주면 화면이 흐려 보인다. 주인공 물체와 큰 숫자에만 준다.
- 분홍 + 파랑 겹침이 남색이 되려면 곱하기 합성이 필요하다. 일반 합성으로 겹치면 위 판 색만 보인다.
- 모아레(16.5~19.8초)는 해상도와 압축에 따라 결과가 크게 바뀐다. 줄 간격이 4px 아래면 동영상 압축에서 뭉개진다. 줄 간격 6px 이상으로 둔다.
- 한국어 글자 높이가 원작에서 17~19%(약 190~200px)다. Pretendard 140px 제한에 걸린다. 140px 로 줄이고 숫자는 InterVariable 로 크게 남긴다.
- 모든 장이 화면 가운데 정렬이다. 장이 많으면 단조롭다. 원작은 바탕 무늬로 이를 메운다. 무늬를 빼면 장을 더 줄인다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 글꼴은 Pretendard Regular·SemiBold 뿐이다(숫자·라틴은 InterVariable).

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 리소 입자 | 잉크가 덜 묻은 실제 판 | 로드 때 노이즈 마스크 canvas 4장(1920x1080, 화소의 14% 를 1~2px 흰 점으로 뚫음, seed 0~3)을 굽는다. seek 에서 `Math.floor(t*12)%4` 번째를 고른다(초당 12번 바뀜). 각 색 판을 오프스크린에 그린 뒤 `destination-out` 으로 마스크를 뺀다 | 판마다 다른 잉크 농도 |
| 판 겹침 색 | 곱하기 인쇄 | 판끼리 `globalCompositeOperation='multiply'`. 분홍 #E0508A x 파랑 #1A6AA6 ≈ #142058(원작 #142060 근처). DOM 이면 `mix-blend-mode: multiply` | 없음 |
| 판 어긋남 | 없다 | 주인공 물체만 같은 모양을 두 색으로 두 번 그리고 둘째 판을 (+14px, +14px) 옮긴다. 아래 판을 먼저, 위 판을 multiply 로 | 없음 |
| 굵은 한국어 글자 | 원작 글꼴이 더 굵다 | Pretendard SemiBold, 자간 -0.04em. 굵기를 더하려면 같은 색 `-webkit-text-stroke: 3px`. 최대 140px. 입자 마스크를 글자에도 씌우려면 글자를 canvas 에 `fillText` 하지 않고 DOM 글자 위에 `mask-image` 로 노이즈 PNG 를 씌운다 | 원작의 아주 두꺼운 획 |
| 큰 숫자 | 330px, 650px 숫자 | InterVariable 굵기 800, 높이 그대로(330px, 650px). 녹색 그림자 판 (+14px, +14px) | 없음 |
| 사선·점·줄무늬 바탕 | 없다 | CSS `repeating-linear-gradient(-45deg, #E0508A 0 10px, transparent 10px 26px)`. 점 격자는 canvas 원 10x5 개, 지름 = `40 + 24*sin(t*3 - x*0.004)`px. 줄무늬 모아레는 6px 간격 세로줄 두 판(분홍·파랑)을 1.5° 기울기 차이로 겹침 | 없음 |
| 비행선·상징 그림 | 고유 상징 | SVG 로 대상의 단순 실루엣을 만든다(타원 + 꼬리 삼각형 2 + 아래 사각형). 또는 `codex-image` 로 마젠타 바탕 단색 실루엣을 그리고 `key.py` 로 투명 PNG 를 만든 뒤 색 판으로 칠한다(글자·로고 없이) | 없음 |
| 도장 | 찍힌 잉크 번짐 | 노랑 원(지름 260px) + 녹색 테두리 6px 를 `HAND.wobble(P, true, 3, 'stamp', 0)` 로 한 번 흔든 경로로 그린다. 0.15초에 130% → 100% | 번짐 |
| 종이 | 실제 종이 스캔 | `texTile(seed, { mc: '120,115,100', mottle: .03, dark: .02, light: .03, fibers: 60, specks: 20 })` 를 바탕에, 위에 가장자리 비네트 `radial-gradient(transparent 60%, rgba(0,0,0,.12))` | 종이 섬유의 깊이 |
