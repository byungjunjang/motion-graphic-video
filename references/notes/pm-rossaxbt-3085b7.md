## 3. 움직임

- 카메라는 장면마다 아주 천천히 밀린다(원래 글은 장면마다 1.0 → 1.04 로 정했다). 0.25초 간격 프레임으로는 거의 보이지 않는다. 장면 사이에 확대값이 되돌아가지 않는다.
- 나타남은 0.3초 넘는 부드러운 페이드다. 결과 카드 교체와 사진 번쩍임만 즉시 바뀐다.
- 사진은 무리로 움직인다. 콜라주는 바깥으로 흩어지고, 무드보드는 날아와 격자로 섰다가 원으로 돌고, 폭발은 가운데에서 터지고, 마지막에 다시 가운데로 빨려 든다. 들어오는 사진에는 움직임 흐림이 있다(6.5초, 8.5초 프레임).
- 결과 카드 이름표 글자는 위로 굴러가며 바뀐다(숫자 회전판처럼).
- 설정 판 손잡이는 내레이션이 그 이름을 말할 때 움직인다. 손잡이 위치와 오른쪽 숫자(백분율)가 같이 바뀐다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 5.5초. 흰 바탕, 위 10~14% 높이의 굵은 머리 문장(56px), 그 아래 가로 28~71%(x308~768)·세로 20~26%의 유리 입력 막대(460x64px)와 뒤의 연보라 빛, 가로 23~77%·세로 30~70%의 결과 카드(585x435px, 화면 면적의 22%), 그 아래 검은 이름표(168x44px)와 썸네일 5장(60px). 동시에 보이는 요소는 약 10개. 결과 그림이 0.12초마다 다른 화풍으로 바뀌는 것이 빠지면 이 영상이 아니다.
- 12초 판 압축 예 · 0~1.2초 이름 타이핑 → 1.2~2.0초 사진 번쩍임 6장 → 2.0~4.5초 입력과 결과(교체 12번) → 4.5~6.5초 무드보드(날아와 격자 → 원) → 6.5~9.0초 설정(손잡이 둘) → 9.0~10.5초 사진 폭발과 자막 알약 → 10.5~12.0초 로고. 첫 콜라주, 소개 줄, 강조 문장 장은 뺀다.
- 화면 글자를 말소리 시각에 맞춰 한 낱말씩 쓴다. 한 장면에 한 문장.
- 결과물 교체를 16분음표 격자에 맞춘다. 교체마다 작은 딸깍 소리를 둔다.
- 사진 무리의 모양 바꾸기(흩어짐 → 격자 → 원 → 폭발 → 로고)로 장을 잇는다.
- 유리 조각은 색 있는 바탕 위에만 놓는다. 흰 바탕이면 빛 덩어리를 깐다.
- 강조는 그라데이션 낱말 하나로만 한다.
- 끝은 2초 넘게 멈추고 음악을 줄인다.

## 7. 함정

- 화면의 제품 이름, 문장, 입력어, 화풍 이름표, 설정 이름은 원작의 영문 글자다. 옮기지 않는다. 역할(이름, 한 줄 소개, 입력어, 결과 이름, 설정 셋)만 가져온다.
- 사진 속 인물은 실존 인물이다. 원작 사진을 쓰지 않는다. 소개 대상이 실제로 만든 결과물이나 사용자가 허락한 사진만 쓴다. 사진이 없으면 AI 일러스트로 채운다(아래 `## 8`).
- 사진이 120장 넘게 필요하다. 소재가 모자라면 폭발 장의 사진 수를 60장으로 줄이고 카드 크기를 1.4배로 키운다.
- 원래 글은 박에 맞춘 쾅을 금지했지만 실제 화면의 사진 교체는 16분음표에 딱 맞는다. 맞추는 것은 교체 시각이고, 크기 튐·흔들림은 넣지 않는다.
- 분석기 박자 값(84.7)을 그대로 믿지 않는다. 교체 간격으로 박을 다시 잡는다.
- 내레이션이 있어야 글자 타이밍이 산다. 내레이션 없이 만들면 타이핑 속도를 초당 10글자(한국어 초당 6글자)로 고정한다.
- 한국어 강조 문장은 두 줄이 될 수 있다. 큰 줄 글자 크기를 96px → 84px 로 줄이고 한 줄에 12글자를 넘기지 않는다.
- 정사각(1080x1080)이다. 16:9(1920x1080)로 옮길 때는 높이를 그대로 두고 다음처럼 바꾼다.
  - 글자 장(이름·소개·강조) · 가운데 (960, 540) 그대로, 글자 크기 그대로. 큰 줄은 폭 852px 그대로.
  - 입력과 결과 · 세로 쌓기를 가로로 편다. 왼쪽 가로 10~45%(x190~860)에 머리 문장(세로 30%)과 입력 막대(600x64px, 세로 42%), 오른쪽 x960~1700 에 결과 카드(740x550px, 세로 24~75%)와 그 아래 이름표·썸네일.
  - 무드보드 · 3x3 격자(한 장 150px)를 가운데 두고, 원으로 돌 때는 반지름 380 → 가로 반지름 640·세로 반지름 380 의 타원으로 넓힌다.
  - 설정 · 판(495x503)을 x480~975, 사진 카드(427x548)를 x1015~1442, 둘 다 세로 가운데. 빛 덩어리는 가로로 1.8배 늘린다.
  - 사진 폭발 · 사진 수를 120 → 200장으로 늘리거나 카드 크기를 1.3배로 키운다. 자막 알약은 685 → 900px.
  - 로고 · 가운데 그대로.

## 8. 코드로 재현 못 하는 요소와 대체 방법

글꼴은 Pretendard Regular·SemiBold 와 숫자·라틴용 InterVariable 이다. 값은 원본 1080 정사각 기준이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 실제 사진 120장 | 원작 사진은 쓸 수 없다 | 대상의 실제 결과물·화면을 먼저 쓴다. 모자라면 AI 일러스트(codex-image)로 한 장에 4~6개 그림을 마젠타 바탕에 그려 `scripts/key.py --split` 으로 자른다. 글자·로고·실존 인물 얼굴은 넣지 않는다. 사물·풍경·추상 위주 | 사진 특유의 현실감 |
| 화풍이 바뀌는 결과 그림 12장 | 같은 주제를 다른 화풍으로 그려야 한다 | AI 일러스트로 같은 사물을 12개 화풍(장난감, 판화, 각진 다면체, 유화, 인상파풍, 팝아트풍 등 일반 양식 이름)으로 그린다. 시간이 없으면 한 장에 CSS 필터 조합 12개(`grayscale(1) contrast(1.6)`, `hue-rotate(120deg) saturate(2)`, `sepia(.8)` 등)를 0.118초마다 바꾼다 | 화풍 차이의 폭 |
| 유리 입력 막대·설정 판·자막 알약 | 뒤 화면을 굴절시키는 두꺼운 유리 | DOM 상자에 `backdrop-filter: blur(14px) saturate(1.2)`, 배경 `rgba(255,255,255,.45)`, 테두리 1px `rgba(255,255,255,.8)`, 위쪽 안쪽 빛 `inset 0 1px 0 #fff`, 그림자 `0 12px 32px rgba(60,40,90,.12)`, 모서리 32px(알약은 40px). 가장자리 굴절은 생략한다. 촬영에서 `backdrop-filter` 가 잡히는지 `render.mjs --snap` 으로 먼저 본다 | 가장자리 12px 의 휘어 보이는 굴절 |
| 파스텔 빛 덩어리 | 크고 흐린 색 덩어리가 천천히 돈다 | DOM 원 4개(지름 700~900px, #c8e9df, #f2c9de, #e9e4c8, #d8d4e8)에 `filter: blur(120px)`, 각자 반지름 60px 원 궤도를 12초 주기로 돈다. 사진이 바뀌면 원 색을 0.5초에 사진 평균색 쪽으로 옮긴다 | 없음 |
| 그라데이션 강조 낱말과 옅은 빛 | 없다 | span 에 `background: linear-gradient(90deg, #f86aa6, #a860f1, #597aff); -webkit-background-clip: text; color: transparent`, 같은 span 사본을 뒤에 `filter: blur(18px)` 불투명도 0.35 로 | 없음 |
| 사진 폭발과 모임 | 120장의 경로 | canvas 에 사진 카드를 그린다. 카드마다 씨앗 난수로 각도 θ, 최종 반지름 r(150~760px), 크기(60~130px)를 정하고 위치 = 중심 + r·감속(t)·(cosθ, sinθ). 모일 때는 감속을 거꾸로 0.35초. 원래 글처럼 그림 촬영을 하위 프레임 8장으로 나눠 움직임 흐림을 만들 수도 있다 | 없음 |
| 이름표 굴림 | 없다 | 이름표 안에 낱말 두 개를 세로로 쌓고 `translateY(-100%)` 를 0.08초에 | 없음 |
| 내레이션과 글자 동기 | 낱말 시각표가 필요하다 | 내레이션은 저장소 규칙의 음성 생성 도구로만 만든다. 없으면 내레이션을 빼고 박 격자에 맞춰 낱말을 0.24초(8분음표 2개)마다 하나씩 쓴다 | 말과 글이 같이 오는 느낌 |
