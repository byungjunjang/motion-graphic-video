# 팝아트 인쇄 포스터 · 망점에서 물러나 같은 판화의 벽으로 — 분석 노트

> 1960년대 실크스크린·팝아트 포스터 말투로 한 가지 사물의 이야기를 전하는 52초 영상. 동전만 한 빨간 망점에서 시작해 한 장의 포스터로 물러나고, 같은 판화가 점점 빠르게 찍혀 화면 가득한 벽이 된다. 원형 단면으로 맞춰 자르기, 큰 숫자 구멍 지나기, 망점이 번지며 판화를 검게 먹어 들어가기, 가운데 타일 뒤집기의 물결을 거쳐 끝에 타일 바탕색들이 모여 하나의 큰 그림(모자이크)이 된다. 일상 사물의 내력, 제품 포스터, 작은 자료 이야기에 맞는다.

## 3. 움직임

- 원래 글의 등장 방식(도장, 판별 인쇄), 로그 확대, 빨라지는 복제, 카드 뒤집기, 번지는 앞선은 화면과 맞다.
- 영상에서 확인한 점 · 첫 물러남은 3.5초 동안 끊기지 않는다(세기 30~66). 줌은 처음이 빠르고 끝이 느리다(로그). 회전도 같이 풀려 3.0초쯤 멈춘다.
- 복제 수는 5.5초 2장 → 7.0초 약 14장 → 9.5초 약 50장이다. 0.5초마다 1.4배 남짓 는다.
- 화면이 멈추는 구간(4.0, 11.0~12.5, 16.0~17.0, 23~26, 37.5~40.0, 47.5~52초)은 모두 글을 읽게 하는 자리다. 움직임 → 정지가 2~4초 단위로 번갈아 온다.
- 망점은 카메라가 움직여도 종이에 붙어 있다. 확대하면 망점이 같이 커진다. 화면에 고정된 무늬처럼 흐르지 않는다.

## 4. 전환

- 원래 글대로 디졸브·검은 화면 페이드가 없다. 전환은 모두 인쇄물에서 나온다.
- 영상에서 확인한 점 · 맞춤 컷(10.42초)은 종이 원이 화면을 덮는 순간 같은 크기의 단면 원으로 바뀐다. 밀어 들어가기가 약 0.4초로 매우 빠르다(세기 73.1).
- 카드 뒤집기(27.5초)는 화면을 꽉 채운 검은 판이 가로로 접혔다 펴지며 파랑 포스터가 된다. 뒤집기 뒤 29.5~30.0초에 판 네 장이 차례로 내려앉고 30.0초에 완전히 멈춘다(0.0).
- 끝 물결(40.45~44.9초)은 가운데 한 장에서 시작해 동심원으로 퍼지며 타일마다 다른 색 배합으로 뒤집힌다.

## 5. 타이포

- 좁고 굵은 고딕 대문자. 노랑 채움 + 먹 외곽선 + 빨간 어긋난 그림자(첫째 줄), 빨강 채움 + 먹 외곽선 + 파랑 그림자(둘째 줄).
- 크기 · 포스터 제목 대문자 14.6%(약 158px), 꼬리표 제목 7.2%(약 78px), 둘째 언어 줄 4~5.6%, 자막 두 줄 약 3% + 2%.
- 위치 · 꼬리표는 늘 왼쪽 위(가로 2~48%, 세로 3~30%), 종이색 판에 먹 테두리와 빨간 어긋난 그림자. 자막은 늘 아래 가운데(가로 28~72%, 세로 87~98%)의 같은 꼬리표 모양. 원래 글의 배치 규칙과 맞다.
- 큰 숫자 장면만 숫자가 화면 높이의 약 53% 까지 커진다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 0.0~9.5초의 "동전만 한 빨간 망점(지름 약 60px)에서 로그 줌으로 물러나 파랑 정사각 포스터 한 장(한 변 약 865px)에 멈추고, 같은 판이 점점 빠르게 찍혀 2장 → 약 50장의 벽(타일 간격 약 230px)이 되는" 장면이다. 망점이 종이에 붙어 커지고 작아지는 것, 판마다 조금씩 어긋난 복제가 빠지면 이 영상이 아니다.
- 12초 판 압축 예 · 박자 분당 108(마디 약 2.2초). 0~2.4초 망점에서 한 장으로 물러나기(로그 줌, 회전이 풀림), 2.4~3.4초 한 장 포스터와 제목 정지, 3.4~6.0초 도장 복제(간격 0.4초에서 0.1초로 줄며 약 50장), 6.0~7.8초 검붉은 망점 앞선이 벽을 왼쪽부터 먹는다, 7.8~8.2초 무음과 정지, 8.2~9.6초 가운데 타일이 다른 색으로 뒤집히고 물결로 퍼진다, 9.6~11.0초 가장 넓게 물러나 타일 바탕이 큰 그림이 되고 계단 먹선, 11.0~12.0초 끝 꼬리표 정지. 맞춤 컷, 들판 따라가기, 숫자 구멍 지나기는 뺀다.
- 한 장의 포스터를 단위로, 수량·변화는 같은 포스터의 반복과 한 장의 색 배합 바꾸기로 보여 준다.
- 번지는 것(질병, 유행, 가격)은 망점 크기가 커지는 앞선으로 보여 준다.

## 7. 함정

- 화면의 제목, 꼬리표 낱말, 품종 이름, 병 이름, 연도, 나라 이름, 자막은 원작의 것이다. 옮기지 않는다. 역할(포스터 제목 두 줄, 꼬리표 한 줄, 큰 연도 숫자)만 가져온다. 실존 품종·지명은 우리 영상에 쓰지 않는다. 끝 꼬리표의 실존 회사·모델 이름도 쓰지 않는다.
- 유명 팝아트 작가의 특정 작품(같은 과일 그림, 수프 깡통의 반복)을 떠올리게 하는 구도를 그대로 쓰지 않는다. 우리 주제의 사물로 바꾼다.
- 망점을 화면 좌표로 그리면 필터처럼 보이고 카메라가 움직일 때 미끄러진다. `LOOKS.halftone` 은 화면 좌표(`gl_FragCoord`)로 점을 찍는다. 그래서 카메라가 움직이는 숏에는 쓰지 않는다. 아래 표의 종이 좌표 망점을 쓴다.
- 넓은 화면에서 망점 칸이 4px 아래가 되면 물결무늬가 생긴다. 그 크기 아래에서는 망점 대신 평균 색 면으로 바꾼다.
- 복제 벽의 판을 모두 똑같이 찍으면 디지털 복사처럼 보인다. 판마다 노랑·빨강 판을 2~6px 다르게 어긋나게 하고 잉크 농도를 ±5% 바꾼다.
- 빈 종이 프레임을 만들지 않는다. 판별 인쇄도 첫 판이 깔린 상태에서 시작한다. 원래 글의 함정과 같다.
- 한국어 제목은 140px 이하라서 원본 제목(158px)보다 작아진다. 두 줄 132px 로 쓰고 포스터와 제목 사이를 줄여 무게를 맞춘다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 화면 전체를 canvas 2D 하나로 그리고, 카메라는 `ctx.setTransform(배율, 회전, 이동)` 으로 종이 좌표를 화면으로 옮긴다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 종이에 붙은 45° 망점 | 화면 좌표 무늬로는 카메라 이동에서 미끄러진다 | 종이 좌표에서 45° 돌린 격자(칸 14단위)를 잡고, 그늘 면 안의 칸마다 반지름 = 칸 x 0.5 x sqrt(농도) 인 원을 찍는다. 화면에 보이는 칸만 그린다. 화면에서 칸이 4px 아래면 원 대신 (잉크 x 면적비 + 종이) 평균색으로 면을 칠한다. 첫 숏은 배율 18 → 1.45(로그 보간), 회전 0.55 라디안 → 0 | 없음 |
| 네 판과 어긋남 | 판마다 따로 그려야 한다 | 판화 한 장을 노랑·빨강·파랑·먹 네 번 그린다. 판마다 시드 고정 어긋남 ±2~6px(`HAND.rngKey('reg', 판화번호, 판)`). 판별 인쇄는 판마다 40px 밖에서 0.25초 지수 감속으로 제자리에 들어오고, 박자마다 하나씩(노랑 → 빨강 → 파랑 → 먹) | 실제 잉크가 겹친 곳의 탁한 색 |
| 굵은 먹 외곽선 | 인쇄된 선의 미세한 흔들림 | SVG 경로를 canvas 에 획 굵기 14단위(한 장 포스터에서 약 14px), 둥근 이음으로 그린다. 경로 점에 `HAND.wobble(P, true, 1.5, 'key', 0)` 을 한 번만 적용해 굽는다(떨지 않는다) | 잉크가 번진 가장자리 |
| 판화 그림(사물, 단면, 식물) | 평면 도형이지만 주제마다 새로 그려야 한다 | SVG 로 직접 그린다. 면 3~4개 + 그늘 면 1개(그늘 면에만 빨간 망점) + 밝은 면 1개(종이색 줄). 복잡한 사물은 AI 일러스트를 평면 벡터 느낌, 마젠타 바탕, 글자 없이 그리고 `scripts/key.py` 로 자른 뒤 네 잉크 색으로 줄이고 그늘에 망점을 올린다 | 손으로 판을 자른 맛 |
| 점점 빨라지는 도장 복제 | 수십 장을 매 프레임 그리면 무겁다 | 판화 한 장을 색 배합마다 화면 밖 canvas 에 미리 굽는다. 타일 위치는 망점 칸의 정수 배로 잡아 망점 격자가 끊기지 않게 한다. 찍히는 간격 0.5초에서 시작해 한 장마다 0.8배(최소 0.06초), 첫 판에서 고리 순서로. 찍힐 때 크기 1.1 → 1.0 을 0.12초 | 없음 |
| 번지는 망점 앞선 | 없다 | 앞선 가로 위치 x(t) 를 정하고, 앞선 뒤 거리 d 에서 검붉은 망점 반지름 = 칸 x 0.5 x min(1, d / 300px). d 가 300px 를 넘은 곳은 #4A131C 면으로 덮는다 | 없음 |
| 카드 뒤집기와 물결 | 없다 | `scaleX` 1 → 0 → 1 을 0.3초, 0 지점에서 새 배합으로 교체. 물결은 가운데 타일과의 고리 거리 x 0.04초 지연 | 없음 |
| 숫자 구멍 지나기 | 글자 안쪽 구멍 위치를 알아야 한다 | 숫자는 InterVariable 900, 높이 약 570px(숫자라 140px 규칙과 상관없다). 0 의 구멍에 맞춘 원(지름은 글자 높이의 약 35%)을 SVG 마스크로 두고, 그 중심을 기준으로 1.0초 동안 배율 1 → 40(지수 가속) | 구멍 모양의 정확한 곡선 |
| 좁고 굵은 제목 | 좁은 굵은 글꼴이 없다 | 라틴·숫자는 InterVariable 900 에 `transform: scaleX(0.8)`. 한국어는 Pretendard SemiBold 132px, `scaleX(0.88)`, `-webkit-text-stroke: 6px #141414` + `paint-order: stroke fill`, `text-shadow: 12px 9px 0 #D71F21` | 진짜 좁은 글자의 리듬 |
| 끝 모자이크와 계단 먹선 | 그림을 타일 격자로 바꾸고 외곽을 칸 경계로 따야 한다 | 43x24 칸(칸 45px). 우리 사물의 실루엣을 같은 격자로 래스터해 칸마다 바탕색(몸, 그늘, 꼭지, 바깥 파랑)을 정한다. 외곽은 칸 경계를 따라가는 계단 선(칸이 안·밖으로 바뀌는 변만 잇는다), 굵기 6px #141414. 선은 1.0초 동안 한 바퀴 그려진다 | 없음 |
| 깨끗한 종이 | 실제 종이 스캔 | `texTile(seed, { mc: '120,110,90', mottle: .03, dark: .03, light: .03, fibers: 80, specks: 10 })` 를 바탕 #F1E9D8 위에 곱하기로. 더 거칠게 하지 않는다 | 종이 섬유의 실감 |
