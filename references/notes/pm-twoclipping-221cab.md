# 사진 인화 앱 한 테이크 · 화면에서 벽까지 — 분석 노트

> 사진 인화 앱을 소개하는 29초 정사각 영상. 굵고 넓은 워드마크가 자기 마침표 속으로 접혀 들어가고, 그 점이 검은 알약 → 조리개 → 사진 → 사진 격자 → 액체 유리 도구 → 잠금 화면 → 휴대폰 → 브라우저 창 → 상품 카드 → 주문 상태 알약으로 차례로 모양을 바꾼다. 마지막에 검은 원이 화면을 덮었다가 실제 벽에 걸린 액자로 줄어들고, 두 손이 액자를 들어 올린다. 다시 처음 워드마크로 돌아와 끝 프레임이 첫 프레임과 같다. 사진·인화·커머스 앱, "화면 속 결과물이 실물이 된다"는 이야기에 맞는다. 제품 UI 한 테이크 · 커서 연출 · 액체 유리 · 실사 합성.

출처 · pm:twoclipping-221cab. 작성자의 글은 약 5,200자의 제작 주문이다. 입력 목록, 금지 효과, 장 구성(여는 장 · 유리 · 무대 · 주문 · 벽), 박자 수, 구현 방법(시간 함수 스프링, 유리 필터, 조리개 날, 실사 프레임 처리)은 정했다. 실제 크기·위치·색 값, 장마다의 정확한 시각, 결과 화면이 계획과 어디서 달라졌는지는 비어 있다. 이 노트는 영상 프레임(1초 간격 30장, 0.5초 간격 59장, 전환 세 곳은 0.1초 간격 60장, 원본 크기 23장)을 보고 썼다.
측정 · 파일 1440x1440 · 60fps · 29.08초. 장면 감지(문턱 0.28)가 잡은 컷은 0번이다. 0.5초마다 움직임 세기의 평균은 19.5 다. 큰 값은 26.5초(96.4, 조리개가 닫히고 검게 덮임), 21.5초(87.8)와 22.0초(66.6, 검은 원이 화면을 덮음), 5.5초(55.7, 격자 칸 확대), 25.0초(54.6, 손이 액자를 듦), 13.0초(44.0, 휴대폰으로 물러남)다. 거의 멈춘 구간(1 미만)은 1.5초, 6.5초, 28.0~28.5초다. 첫 프레임과 끝 프레임의 화소 차이 평균은 0.23(0~255)이다. 크기는 원본 1440 화소로 적는다. 16:9 1080 높이로 옮길 때는 0.75 를 곱한다. 색 값은 9x9 화소 평균으로 잰 근삿값이다.

## 1. 본질

- 바탕은 따뜻한 회백색(#ECECE7 근처, 가운데는 #F1F1EC 로 조금 밝다)이다. 잉크는 거의 검정(#0B0A0D 근처) 하나다. 포인트 색은 따로 없다. 색은 사진에서만 온다.
- 주인공은 장면마다 모양을 바꾸며 이어지는 검은 덩어리 하나다. 워드마크의 마침표 → 알약 → 원 → 사각 → 격자 → 유리 → 휴대폰 → 창 → 주문 알약 → 검은 원 → 액자. 앞 장의 모양이 다음 장의 재료가 된다. 화면이 끊기지 않는다.
- 사진이 두 번째 주인공이다. 사진 9장이 격자로 나온 뒤, 두 장(낮 → 노을로 바뀌는 언덕 아치, 초록 하늘의 우주복 인물)이 끝까지 이어진다. 두 번째 사진이 잠금 화면, 랜딩 페이지 대표 사진, 상품 액자, 벽의 실물 액자가 된다.
- 액체 유리가 세 번 나온다. 사진 위 도구 막대(4.5% 높이의 아이콘 4개), 밝기 슬라이더, 사진을 비추는 유리 구다. 잠금 화면의 시계 숫자도 유리 글자다.
- 커서가 모든 변화를 일으킨다. 클릭 약 9번, 끌기 2번, 길게 누르기 1번이 보인다. 화면이 확대되면 커서도 같이 커진다.
- 실사가 한 번 들어간다. 22.2~26.0초의 흰 벽(식물 그림자가 흔들림)과 액자를 드는 두 손이다.
- 아닌 것 · 하드 컷, 배경 그라데이션, 포인트 색, 1.1초 넘는 정지. 원래 글이 금지한 효과는 화면에서 찾지 못했다.

## 3. 움직임

- 거의 모든 변형이 크기·모서리 반지름·위치 세 값의 스프링이다. 넘침은 작다(눈대중으로 목표의 3~5%).
- 장의 박자 · 큰 변형은 0.3~0.5초, 상태 교체는 0.5초, 정지는 0.2~0.6초다. 정지가 1초를 넘는 곳은 끝 정지뿐이다.
- 카메라는 확대·축소만 한다. 장마다 주인공이 화면 폭의 40~97% 를 채우도록 다가간다. 화면 회전, 기울기는 없다.
- 커서 경로 · 클릭 전에 0.2~0.4초 머문다. 클릭 순간에 대상이 조금(눈대중 3~5%) 눌린다. 끌기 동안에는 값이 커서 위치를 그대로 따른다.
- 액체 변형 두 번 · 7.5초 유리 낱말이 방울로 녹는다. 14.0초 휴대폰 위 알약이 늘어나 떨어진다. 두 번 모두 가장자리가 끈적하게 이어졌다가 끊긴다.
- 덮기 두 번 · 21.7~22.2초, 26.5~26.8초. 덮는 모양이 화면 모서리 밖까지 0.15초쯤에 커지고, 검정이 0.2~0.3초 머문 뒤 다음 장면의 모양으로 줄어든다.
- 움직임 흐림이 있다. 1.2초 점이 늘어날 때, 27.4초 글자가 튀어나올 때처럼 이동이 빠른 프레임마다 잔상 3~4겹이 보인다.
- 실사 구간에서는 카메라가 손의 움직임을 따라 다가간다. 22.5~25.5초 액자 테 폭이 화면의 42% → 79% 가 된다.

## 4. 전환

- 하드 컷이 없다. 모든 전환이 변형, 확대, 덮기 셋 중 하나다.
- 변형 · 마침표 → 알약(0.4초), 알약 → 원(0.3초), 원 → 사각(0.5초), 손잡이 → 렌즈 → 잠금 화면, 휴대폰 알약 → 창, 대표 사진 → 액자, 주문 단추 → 상태 알약.
- 조리개 · 2.4~2.7초(검은 원 → 사진), 22.6~22.8초(검은 사각 → 액자 속 사진), 26.5초(사진 → 검정). 날 6장, 가운데 구멍은 육각이다.
- 확대 · 격자 칸 → 전체 사진(5.6~6.0초), 액자 → 사진(25.7~26.0초). 확대가 끝나는 순간에 다음 장의 첫 요소가 나온다.
- 덮기 · 화면의 실사 장면은 검정 덮기를 지나야만 들어오고 나간다. 디지털 화면과 실물 벽 사이의 문이다.
- 장의 경계는 소리 구조와 맞는다. 큰 확대(6.0초)는 음량 최고, 벽(22.2~26.0초)은 조용한 구간, 워드마크 복귀(27.35초)는 마디 첫 박이다.

## 5. 타이포

- 워드마크 · 아주 넓은 폭의 아주 굵은 고딕, 소문자 한 낱말 + 마침표. 엑스높이 114px(화면 높이 7.9%), 올림 글자 높이 166px(11.5%), 내림 포함 206px(14.3%). 자간이 좁아 글자끼리 거의 붙는다.
- 부제 · 회색 작은 고딕 한 줄. 글자 높이 24px(1.7%). 0.0초에 이미 있고, 끝에서는 28.0초에 올라온다.
- 알약 이름표 · 흰 중간 굵기 고딕, 글자 높이 약 34px(2.4%, 눈대중).
- 랜딩 페이지 제목 · 워드마크와 같은 넓은 굵은 고딕, 두 줄 왼쪽 정렬. 17.0초 기준 줄 높이 약 60px(4.2%). 그 아래 회색 설명 두 줄.
- 상품 카드 · 상품 이름 약 68px 높이(4.7%, 19.0초), 설명 두 줄, 라벨 작은 글자, 가격 굵은 숫자. 상태 알약 안 글자는 약 30px.
- 잠금 화면 · 날짜 약 40px, 유리 시계 숫자 약 300px(21%). 숫자 획 안으로 사진이 비친다.
- 커서 · 기본 화살표, 1440 기준 약 30px. 화면 확대 비율만큼 커진다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 21.6~23.0초. 화면 폭 97% 를 채운 상품 카드 위의 체크 원(지름 약 120px)이 0.15초 만에 화면 네 모서리 밖까지 검게 덮고, 0.3초 검정이 머문 뒤 600x780px(화면의 42%x54%) 검은 사각으로 줄며 실사 흰 벽이 드러나고, 그 사각 안에서 조리개가 열려 흰 매트 액자가 된다. 요소는 벽 하나, 액자 하나, 식물 그림자뿐이다. 화면 속 상품이 검정을 지나 실물이 되는 이 한 번이 빠지면 이 영상이 아니다.
- 12초 판 압축 예 · 0~1.5초 워드마크 → 점 → 알약, 1.5~3.0초 조리개로 사진 한 장, 3.0~4.5초 격자 펼침과 칸 확대, 4.5~6.0초 유리 슬라이더로 낮 → 노을, 6.0~7.5초 상품 카드와 주문 단추 상태 3개(체크 → 진행 → 체크), 7.5~9.5초 검게 덮기 → 벽의 액자, 9.5~12.0초 덮기 → 알약 → 워드마크 복귀. 잠금 화면, 휴대폰, 브라우저 창, 손 장면은 뺀다.
- 한 검은 모양이 끝까지 주인공인 구성. 단추 → 진행 막대 → 체크 → 덮개처럼 상태 표시가 장면 전환의 재료가 된다.
- 마침표에서 시작해 마침표로 끝나는 고리. 끝 프레임이 첫 프레임과 같아 반복 재생이 끊기지 않는다.
- 조리개 전환. 날 6장의 닫힘·열림 0.3초로 장면을 바꾼다. 같은 전환을 세 번 써서 "찍는다"는 의미를 반복한다.
- 결과물의 일생을 순서대로 보여 주는 이야기. 사진 → 보정 → 배경화면 → 웹 → 상품 → 주문 → 배송 → 벽.
- 소리 구조와 장 배치. 가장 큰 확대를 음악의 가장 큰 곳에, 실물 장면을 조용한 곳에 둔다.

## 7. 함정

- 화면의 워드마크 낱말, 부제, 제목과 설명 문장, 사진 9장, 가격, 상품 이름은 원작의 것이다. 옮기지 않는다. 역할(브랜드 한 낱말, 결과 문장 한 줄, 상품 이름, 가격)만 가져온다.
- 잠금 화면, 휴대폰 위 알약, 브라우저 창의 신호등 단추, 연보라 바탕의 파란 띠 무늬는 실존 운영 체제 화면을 닮았다. 그대로 그리지 않는다. 시계는 숫자 크기와 유리 재질만, 창은 둥근 모서리와 빈 머리줄만 가져온다.
- 실사 벽과 두 손은 촬영본이다. 코드로 만들 수 없다. 사용자가 준 영상이 없으면 아래 표의 대체 방법을 쓰고, 손 장면은 뺀다.
- 장이 12개를 넘는다. 29초에 장마다 0.5~2.5초다. 한국어 소개 영상으로 그대로 옮기면 읽을 틈이 없다. 글자는 워드마크, 제목 한 줄, 상태 낱말만 남긴다.
- 덮기는 반드시 화면 모서리 밖까지 커져야 한다. 화면 안에서 멈추면 원 가장자리가 보인다. 커지는 시간이 0.1초보다 짧으면 한 프레임에 화면 절반이 바뀌어 번쩍인다. 원작은 약 0.15초에 지름이 화면 폭에 닿고 0.3초에 대각선 밖까지 간다.
- 액체 유리를 반투명 흰 사각으로 대신하면 이 영상의 고급감이 사라진다. 굴절이 보여야 한다. 아래 표의 SVG 필터를 쓴다.
- 16:9 로 옮기는 구도(1920x1080).
  - 워드마크는 화면 폭 60%(약 1150px)로 줄인다. 내림 포함 높이는 약 210px(19%)다. 가로 가운데, 세로 50% 에 둔다. 한국어 이름이면 140px 규칙 때문에 글자 높이 130px 안팎에 자간 -0.02em 로 쓴다.
  - 알약·원·조리개는 정사각 기준 px 에 0.75 를 곱한다(알약 450x145px, 원 지름 350px, 둥근 사각 720px).
  - 격자는 3x3 대신 4x3 으로 한다. 칸 225px, 틈 11px, 묶음 932x711px, 가로 26–74%, 세로 17–83%.
  - 사진 전체 화면 장면은 16:9 로 자른다. 정사각 사진의 위아래 21%(각 약 300px)를 잃는다. 아치·인물처럼 주인공이 가운데에 있는 사진을 고른다.
  - 휴대폰은 높이 54%(583px)로 두고 가로 30% 에, 창은 가로 42–92%(960x600px)에 둔다. 랜딩 페이지 창은 1500x880px(가로 11–89%, 세로 9–90%)다.
  - 벽의 검은 사각은 450x585px(가로 38–62%, 세로 23–77%)다. 벽은 좌우로 넓어진 만큼 식물 그림자를 오른쪽 아래 1/3 에 둔다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

글꼴은 Pretendard Regular·SemiBold 뿐이다(숫자·라틴은 InterVariable 도 있다). 값은 정사각 1440 기준이다. 16:9 판은 0.75 를 곱한다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 넓고 굵은 워드마크 | 폭이 넓은 아주 굵은 글꼴이 없다 | InterVariable 을 쓴다. `font-weight: 800`, `letter-spacing: -0.04em`, 글자 높이 166px. 넓은 폭은 `transform: scaleX(1.18)` 로 낸다. 접힐 때는 글자마다 마침표 쪽으로 이동하며 `scaleX` 를 1.18 → 0.2 로 줄인다 | 진짜 넓은 폭 글꼴의 획 균형 |
| 액체 유리 막대·슬라이더 | 뒤 장면의 굴절과 색 번짐 | SVG 필터. `feImage` 로 둥근 사각 거리장 그림(가장자리 24px 에서만 값이 변함)을 넣고 `feDisplacementMap` 3개(scale 18·21·24)를 빨강·초록·파랑 채널에 따로 건 뒤 합친다. 뒤 장면은 같은 사진을 막대 안에 복제해 둔다. 테두리는 `box-shadow: inset 0 0 0 1px rgba(255,255,255,.55)` 와 위쪽 1px 흰 선 | 실시간 렌즈의 빛 반사 변화 |
| 유리 구(10.5~11.5초) | 구 모양 굴절 | three.js `LOOKS.clearGlass({ dispersion: 4, roughness: 0.03 })` 구(반지름 화면 폭의 24%) 뒤에 사진을 붙인 `PlaneGeometry` 를 둔다. 환경맵은 `LOOKS.env(gl, 'studio')`. 다음 사진은 구 안에 원 마스크로 따로 그린다 | DOM 장면과 섞을 때 화질 차이가 생긴다 |
| 유리 시계 숫자 | 글자 모양 굴절 | canvas 에 숫자를 그리고 흐림 8px 로 높이 지도를 만든다. 그 지도를 `feImage` 로 넣고 `feDisplacementMap` scale 30. 획 안쪽 위에 흰 30% 반사 띠 | 글자 가장자리의 입체감 일부 |
| 끈적한 방울·알약 분리 | 두 모양이 이어졌다 끊기는 경계 | 흐림 + 알파 문턱. `feGaussianBlur stdDeviation=12` → `feColorMatrix` 알파 행 `0 0 0 22 -9` → 원본을 `feComposite operator="atop"` 로 위에 얹는다 | 유리 질감이 문턱 경계에서 납작해진다 |
| 조리개 날 6장 | 날 모양 계산 | SVG 경로 6개. 육각 구멍의 꼭짓점 두 개, 두 변의 연장선, 바깥 원의 짧은 호로 날 하나를 만든다. 구멍 반지름을 0 → 원 반지름의 1.1배로 0.3초에 연다. 날 색 #2A2A2E, 경계 1px rgba(255,255,255,.15) | 없음 |
| 사진 9장 | 사진 자료 | 사용자가 준 사진을 쓴다. 없으면 AI 일러스트(codex-image)로 그린다. 글자·로고 없이, 같은 구도의 낮·노을 두 장은 프롬프트에 시간대만 바꿔 두 번 만든다 | 실제 사진의 질감 |
| 실사 흰 벽과 식물 그림자 | 촬영본이 필요하다 | 바탕을 #DEDCDA 로 칠하고 `texTile(7, { mc: '128,128,128', mottle: .02, dark: .03, light: .03, fibers: 0, specks: 20 })` 를 깐다. 그림자는 AI 일러스트(codex-image)로 그린 잎 실루엣을 `scripts/key.py` 로 투명 그림으로 만들고 `filter: blur(10px)`, 투명도 0.25, 2초 주기로 2° 흔든다 | 실제 빛과 그림자의 움직임 |
| 액자를 드는 두 손 | 촬영본이 필요하다 | 뺀다. 대신 액자를 0.6초에 1.0 → 1.8배로 확대하고 아래 그림자를 10px → 40px 로 키워 앞으로 다가오는 느낌을 낸다 | 실물감의 정점 |
| 움직임 흐림 | 하위 프레임 합성 기능이 없다 | 빠른 이동 구간(1.1~1.3초, 27.3~27.5초)에만 같은 요소를 투명도 0.25 로 3개 복제해 이전 위치(1/240초 간격)에 겹친다 | 부드러운 잔상 |
