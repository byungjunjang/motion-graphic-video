# 홀로그램 계기판 · 빛 선으로 스캔한 제품 사양 — 분석 노트

> 거의 검은 청록 무대의 둥근 투영 받침 위에서, 스캔 평면이 올라가며 사물(이 영상에서는 도시용 전기 자전거)을 빛나는 청록 선 뼈대로 쌓는 39초 영상. 부품마다 조준 상자가 잠기고, 부품이 갈라지고, 지시선 끝 카드의 숫자가 깨진 글자에서 진짜 값으로 굴러 들어가 호박색으로 바뀐다. 한 번 화면이 찢어지는 깨짐과 함께 사물이 꽉 찬 홀로그램으로 켜지고 한 바퀴 돈다. 제품 사양 소개, 출시 영상, 전시장 반복 화면에 맞는다.

출처 · lo:hologram-hud. 색인에 든 원래 글은 약 8천 자의 스타일 명세다(본질, 움직임, 카메라 문법, 함정, 박자별 카메라와 화면 좌표 값). 글은 조준 상자가 잠기는 시간, 부품이 갈라지는 방향, 숫자 굴리기, 칩 꽂기, 휙 넘기기의 값을 자세히 정했다. 그러나 선·바탕·강조 숫자의 실제 색 값, 사물과 카드의 화면 점유율, 선이 화면에서 차지하는 넓이, 빛이 켜지는 순간이 얼마나 밝은지가 없다. 그리고 글의 세 겹 깊이 중 배경 점 격자는 실제 화면에서 거의 보이지 않는다. 그래서 영상 프레임을 보고 이 노트를 썼다.
측정 · 파일 1280x720 · 24fps · 39.02초. 크기는 1920x1080 기준으로 바꿔 적는다(1.5배). 하드 컷은 없다(장면 감지 0회). 움직임 세기 평균은 3.5 다. 큰 구간은 0~2.0초(4.6~7.4, 스캔으로 쌓기), 8.5초(8.3, 첫 부품으로 밀고 들어가기), 22.5~26.5초(10.7~18.0, 물러남과 켜짐과 한 바퀴 돌기, 최대 25.5초 18.0), 28.5초(13.9), 34.5초(8.9, 스캔으로 지우기)다. 9.5~12.5초, 19.0~21.0초, 29.5~33.5초는 0.3~1.0 으로 읽기 위해 거의 멈춘다. 색 값은 프레임에서 잰 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. BPM 95.7(박 검출 96.05, 마디 약 2.50초). 가장 큰 타격(1.00, 낮은 대역 킥)은 23.99초다. 바로 앞 23.48~24.00초가 무음이고, 24.0초 프레임에 화면 깨짐이 있다. 7.99초(0.92)는 첫 조준 상자가 잠기는 자리다. 18.00초에도 킥이 있다(세 번째 부품으로 물러나는 자리). 짧은 무음 0.15~0.5초가 2.78초부터 31.72초까지 13번 있다. 대부분 문장 사이다. 36.24~39.00초는 끝 무음이다.

## 1. 본질

- 원래 글의 본질(빛 선 뼈대, 둥근 투영 받침, 스캔 평면, 계산되는 숫자, 앞쪽 계기판 장식)은 화면과 맞다. 되풀이하지 않는다.
- 원래 글과 실제 화면이 다른 점 두 가지.
  - 배경 점 격자가 거의 없다. 사물 왼쪽 빈 바탕의 가장 밝은 화소가 #040A0F 다. 바탕(#010707 ~ #020507)과 구별되지 않는다. 깊이는 받침 둘레의 동심원 눈금과 바닥의 옅은 방사선이 만든다.
  - 강조색은 청록이 아니라 호박색이다. 청록은 사물과 장식 전체의 바탕색이고, 잠긴 숫자 값과 그 아래 밑줄만 호박색(#F7C253 근처)이다. 화면에 호박색이 있는 곳은 늘 숫자뿐이다.
- 색(근삿값).
  - 바탕 · #010707 ~ #020507 거의 검은 청록. 사물 뒤쪽은 #030E12 로 아주 조금 밝다.
  - 선 뼈대 · 보통 #64A4AC, 조준된 부품은 #BDEDF4 로 하얗게 탄다. 켜진 홀로그램은 #D2FDFF.
  - 꽉 찬 홀로그램 면(26.0초) · #408D97 반투명. 선은 여전히 면 위에 보인다.
  - 계기판 글자(네 귀퉁이 상태 표기) · #4E7C7F.
  - 조준 꼬리표 바탕 · #65D9EA 채움에 어두운 글자.
  - 강조 숫자 · #F7C253.
- 선이 화면에서 차지하는 넓이 · 스캔 완료 장면(3.0초) 약 9%, 부품 조준 장면(11.5초) 약 5%, 홀로그램 켜짐(24.0초) 약 18% 이고 그중 하얗게 탄 화소가 5.4%. 나머지 80~95% 는 검은 바탕이다.
- 아닌 것 · 렌더한 제품 사진, 파란 바탕 도면, 흰 바탕, 둘째 강조색.

## 3. 움직임

- 원래 글의 수치(조준 0.22초, 갈라짐 한두 박, 숫자 굴리기 0.5~1초, 칩 꽂기, 휙 넘기기 0.5초)는 화면과 맞다.
- 영상에서 확인한 점 · 부품 하나의 흐름은 "잠기기 0.5초 → 밀고 들어가기 0.5초 → 갈라짐 0.5초 → 지시선 0.5초 → 숫자 1.0초 → 읽기 1.5~2초"로 약 5초다. 첫 부품만 이렇게 길고, 둘째·셋째는 약 4초다.
- 읽는 동안에도 완전히 멈추지 않는다. 움직임 세기 0.4~0.8 의 아주 느린 흐름이 있다. 갈라진 전지 속 줄이 빛을 조금씩 바꾼다.
- 한 바퀴 돌기(24~29초)가 가장 크게 움직이는 구간이다. 이 영상의 다른 모든 이동보다 2배 크다.

## 4. 전환

- 컷과 페이드가 없다. 스캔 평면(시작과 끝), 휙 넘기기, 돋보기 열기가 전부다. 원래 글에 있다.
- 영상에서 확인한 점 · 깨짐은 24.0초 한 번뿐이다. 화면이 가로 띠 6~8개로 찢어지고 띠마다 좌우로 2~6px 어긋나며 귀퉁이 글자가 두 겹으로 보인다. 무음 0.5초 뒤 가장 큰 타격과 함께 온다.

## 5. 타이포

- 제목 · 얇은 산세리프 대문자 한 단어, 아주 넓은 자간, 글자 높이 화면의 약 10.4%(약 112px), 화면 가로 6%, 세로 14~24%. 아래 작은 고정폭 한 줄과 작은 산세리프 한 줄(각 약 1.4%).
- 네 귀퉁이 상태 표기 · 고정폭 대문자 약 1.4%(약 15px), #4E7C7F, 각 귀퉁이에서 화면 가장자리 약 3% 안쪽에 꺾쇠 선과 함께. 오른쪽 위 표기는 장면마다 바뀐다(조준 번호, 부품 이름).
- 자막 · 화면 가운데 아래 세로 약 87%, 글자 높이 약 2.8%(약 30px), 옅은 회색. 왼쪽에 작은 소리 막대 아이콘.
- 카드 · 번호(약 1.4%) + 대문자 머리글(약 2.2%, 넓은 자간) + 큰 숫자(약 8.3%, 약 90px, 얇은 획) + 작은 단위(약 2.8%) + 밑줄 + 회색 설명 한 줄(약 2%).
- 왼쪽 칩 줄 · 칩 한 장 약 400 x 95px(화면 가로 5~26%), 위에서 세로 42% 부터 약 112px 간격. 칩 안 숫자도 호박색.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 7.5~11.5초의 "청록 선 사물(높이 화면의 65%) 전체가 어두워지고 한 부품만 #BDEDF4 로 밝아진 뒤, 45° 돌아간 큰 꺾쇠가 0.2초 만에 잠기고, 카메라가 밀고 들어가 부품이 축을 따라 갈라지고, 지시선 끝 카드의 숫자가 깨진 글자에서 굴러 들어와 호박색(#F7C253)으로 바뀌는" 4초다. 검은 바탕이 화면의 90% 이상, 호박색은 숫자에만. 숫자가 굴러 들어오지 않고 그냥 나타나면 이 영상이 아니다.
- 12초 판 압축 예 · 0~2.0초 스캔 평면이 올라가며 사물을 쌓는다, 2.0~3.0초 왼쪽에 얇은 제목, 3.0~7.0초 대표 장면 4초(조준·잠기기 0.5 + 밀기 0.5 + 갈라짐 0.5 + 지시선 0.5 + 숫자 1.0 + 읽기 1.0), 7.0~8.0초 휙 넘겨 둘째 부품을 잠그고 숫자(칩은 왼쪽 줄로), 8.0~8.5초 무음 뒤 깨짐 한 번과 꽉 찬 홀로그램 켜짐, 8.5~10.5초 한 바퀴 돌기의 절반(180°), 10.5~12.0초 위에서 아래로 스캔 지우기와 끝 표기. 돋보기 부품, 셋째 부품, 무게·값 카드 장면은 뺀다.
- 숫자는 계산되는 것처럼 보인다. 깨진 글자가 오른쪽부터 한 자씩 맞아 들어간다.
- 다 본 값은 칩으로 접혀 왼쪽 줄에 끝까지 남는다. 화면에 "지금까지 본 것"이 쌓인다.

## 7. 함정

- 화면의 제품 이름(제목 한 단어), 모델 표기, 자막 문장, 카드 머리글, 숫자 값은 원작의 가상 제품 것이다. 옮기지 않는다. 역할(제품 이름 한 단어, 부품 이름, 사양 숫자 셋, 무게·값)만 가져온다. 우리 영상의 숫자는 사용자 자료에서 확인한 값만 쓴다. 끝 표기의 제작 표기에 실존 이름이 있다. 쓰지 않는다.
- 원래 글대로 배경 점 격자를 또렷하게 깔면 원본보다 화면이 시끄럽다. 넣는다면 불투명도 0.05 아래로 둔다. 깊이는 받침의 동심원 눈금으로 낸다.
- 청록을 강조색으로 착각하고 숫자까지 청록으로 쓰면 값이 안 읽힌다. 청록은 바탕색, 호박색은 숫자 전용으로 나눈다.
- 선이 너무 많으면(바큇살, 볼트 하나하나) 화면이 하얗게 뭉친다. 평소 선 넓이를 화면의 5~10% 로 지키고, 조준되지 않은 부분은 밝기를 40% 로 낮춘다.
- 깨짐을 여러 번 쓰면 값이 떨어진다. 한 번, 3프레임 이하, 가장 큰 변화(켜짐)에만.
- 원래 글의 함정 절(조준 상자가 부풀기, 긴 지시선이 엉뚱한 부품을 가리키기, 무음 속 효과음)은 그대로 맞다.

| 사물의 선 뼈대 | 실제 제품의 정확한 모형이 필요하다 | 관은 `CylinderGeometry`(둘레 8칸), 바퀴는 `TorusGeometry` + 바큇살 `LineSegments` 24개로 단순 모형을 짓는다. 모든 형상에 `EdgesGeometry`(각도 20°) + `LineBasicMaterial`(#64A4AC, `AdditiveBlending`, `depthWrite: false`). 관마다 고리 선 8~12개를 더해 "스캔된 결"을 낸다 | 실제 제품의 세부 실루엣 |
| 빛 번짐 | 직접 짜기 어렵다 | `LOOKS.post(gl, { w: 1920, h: 1080, tone: 'aces', bloom: 1.1, threshold: 0.7, scan: 0.1, vignette: 0.4, grain: 0 })`. 조준된 부품은 선 색을 #BDEDF4 로 바꿔 bloom 을 받게 한다 | 없음에 가깝다 |
| 스캔 평면으로 쌓기·지우기 | 없다. 키트와 기본 기능으로 된다 | 모든 선 재질에 `clippingPlanes`(`Plane` 하나)를 주고 높이를 2.6초에 바닥 → 꼭대기로. 평면 자리에 납작한 원판(`RingGeometry` 안 0.98·밖 1.0, #65D9EA, 불투명도 0.5)과 옅은 채움 원판(불투명도 0.08)을 같이 올린다. 지우기는 위 → 아래로 1.5초 | 없음 |
| 꽉 찬 홀로그램 켜짐 | 반투명 면과 선의 겹침 | 같은 형상에 면 재질 `MeshBasicMaterial`(#408D97, 불투명도 0 → 0.35, `AdditiveBlending`)을 0.4초에 켜고 선은 그대로 둔다. 키트의 `holoPoints` 는 구 위 점이라 이 사물에는 맞지 않는다 | 면 안쪽의 결 |
| 깨짐 3프레임 | 후처리 패스가 필요해 보인다 | 렌더한 canvas 를 2D canvas 로 옮겨 그린다. 가로 띠 7개(높이 40~160px, 시드 고정)를 2~6px 씩 좌우로 밀고, 같은 그림을 빨강 +4px·파랑 −4px 로 옮긴 사본을 화면 합성(불투명도 0.5)한다. DOM 귀퉁이 글자는 같은 프레임에 `text-shadow: 4px 0 #F00, -4px 0 #0FF` | 띠 안의 미세한 잡음 |
| 숫자 굴리기 | 없다. DOM 으로 된다 | 자리마다 잠기는 시각을 오른쪽부터 0.12초 간격으로 정한다. 잠기기 전에는 `floor(t × 24)` 와 자리 번호로 고른 기호(시드 고정 배열 30자)를 보여 준다. 다 잠긴 프레임에 색을 #FFFFFF → #F7C253 로 바꾸고 1프레임 밝기 1.6배 | 없음 |
| 조준 꺾쇠와 지시선 | 3D 부품의 화면 위치가 필요하다 | `LOOKS.pin` 으로 부품 경계 상자 꼭짓점 8개의 화면 좌표를 얻어 꺾쇠 네모를 SVG 로 그린다. 시작은 1.9배 크기·45° 회전·불투명도 0.3, 0.22초 3차 감속으로 제자리. 지시선은 고리(지름 14px) → 대각선 → 수평, 굵기 1.5px #65D9EA, 0.5초 | 없음 |
| 얇고 넓은 제목·고정폭 계기판 글자 | 얇은 굵기·고정폭 글꼴이 없다 | 제목은 InterVariable 200 대문자 120px, 자간 0.3em, #D6EEF0(한국어 제목이면 Pretendard Regular 96px, 자간 0.2em). 계기판 글자는 InterVariable 500 대문자 15px, 자간 0.12em, 숫자 고정폭, #4E7C7F | 고정폭 글꼴의 기계 느낌 |
| 받침 둘레 눈금 | 없다. 그대로 된다 | SVG 동심 타원 3개(#2E5A5E, 1px)와 바깥 타원에 짧은 눈금 180개(길이 8px, 2° 간격)를 원근 타원(세로 0.28배)으로. 카메라 회전에 맞춰 타원 각도를 바꾼다 | 3D 받침이 기울 때의 정확한 원근 |
