# 도형 하나가 일곱 아이콘으로 바뀌는 사슬 — 분석 노트

> 도형 하나가 끊기지 않고 아이콘 일곱 개로 차례로 변하는 10초 영상. 위에서 떨어진 검은 방울이 컵이 되고, 컵이 빨강 공을 거쳐 해가 되고, 해가 바다 위로 지는 해가 되고, 흰 타원을 거쳐 갈매기, 종이비행기, 위치 핀, 하트가 된다. 마지막에 흰 공이 굴러가며 가상 이름 글자를 한 자씩 놓는다. 아이콘이 바뀔 때마다 바탕 색면도 원이 퍼지거나 띠가 밀려 바뀐다(종이색 → 노랑 → 빨강·파랑 → 파랑 → 종이색 → 빨강 → 검정). 아이콘은 화면 가운데 폭 13~18%, 높이 27~35% 크기이고, 화면을 채우는 것은 바탕 색면이다. 앱·서비스 기능 여러 개를 한 흐름으로 잇는 소개, 브랜드 이야기 오프닝에 맞는다. 모프(morph) · 도형 변형 · 색면 전환.

출처 · ms:08-morph. 쇼케이스 프롬프트에는 효과 이름, 기법 값(중간 도형을 거치는 단계의 프레임 수, 찌그러짐 비율, 완화 곡선), 아이콘 사슬 예시만 있다. 아이콘 크기와 위치, 색면 전환 방식과 시각, 화면 구석 표기, 끝 화면 구성은 없다. 이 노트는 영상 프레임(0.5초 시트 20장, 0.1초 간격 100장, 1920 기준으로 잰 11장)을 보고 그 빈칸을 채웠다.
측정 · 파일 1920x1080 · 30fps · 10.0초. 장면 전환 검출 시각은 6.40, 6.43초 두 번이다. 둘 다 컷이 아니라 빠른 원형 색면 전환이다. 0.5초마다 움직임 세기의 평균은 13.7 이다. 큰 값은 6.0초(71.5), 7.0초(52.1), 8.0초(43.0), 2.5초(32.4), 1.5초(21.9)이고 모두 색면 전환 구간이다. 작은 값은 3.0초(1.0), 6.5초(0.9), 9.5초(0.9)다. 색면 전환을 뺀 아이콘 변형만의 세기는 2~10 이다. 위치·크기는 960x540 으로 줄인 프레임에 10% 격자를 얹어 재고 1920 기준 px 로 바꿨다. 색 값은 프레임에서 잰 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. BPM 약 120(박 0.5초). 마디 첫 박은 0.34, 2.36, 4.37, 6.39, 8.41초로 약 2초 간격이다. 큰 타격은 0.79초(1.00), 6.37초(0.84), 3.99초(0.68), 2.39초(0.64)다. 6.37초는 비행기가 핀으로 내려앉고 종이색 원이 퍼지는 순간(6.40초)이다. 2.39초는 해가 빨강 원과 바다로 바뀌기 시작하는 순간(2.5초), 3.99초는 지는 해가 흰 타원이 되어 빨강 띠가 밀려 나가는 순간(4.0~4.2초)이다. 0.79초는 컵 위로 김이 피어오르는 순간이다. 5.2~5.9초에 작은 타격이 약 0.3초 간격으로 이어진다(비행기 비행 구간). 9.60~10.0초는 무음이다.

## 1. 본질

- 주인공은 화면 가운데의 아이콘 하나다. 아이콘은 단순한 면 도형이다. 선 아이콘이 아니다. 오른쪽 아래 절반에 같은 색의 조금 어두운 면(접힌 종이 같은 그림자)이 있다. 컵·핀·하트·비행기에서 이 면이 보인다.
- 바탕 색면이 장면마다 바뀐다. 종이색(#EDE9DE 근처, 결과 비네트 있음), 노랑(#F0B52C 근처), 빨강(#E93E2D 근처), 파랑(#252EDC 근처), 검정(#141519 근처). 아이콘 색은 바탕과 대비되는 하나다(종이 위 검정·빨강, 노랑 위 빨강, 파랑 위 흰색, 빨강 위 흰색 #F8F4E9 근처).
- 색은 다섯 가지뿐이다. 장면 한 화면에 두세 색만 쓴다.
- 화면 구석 표기가 영상 내내 있다. 왼쪽 아래에 장면 번호(예 · 몇 번째/일곱), 한자 두 자 장면 이름, 작은 라틴 대문자 영문 이름. 오른쪽 아래에 점 7개 진행 표시(현재 장면은 긴 막대). 장면이 바뀌면 같이 바뀐다.
- 아이콘 사슬은 일곱 장면이다. 컵(아침) → 해(해돋이) → 지는 해(해넘이) → 갈매기(바닷바람) → 종이비행기(떠남) → 위치 핀(도착) → 하트(설렘). 앞 장면의 부품이 다음 장면의 부품이 된다(김 → 햇살 → 물결 막대, 비행기 점선 → 핀 둘레 물결).
- 아닌 것 · 하드 컷, 페이드, 선 아이콘, 꼬이는 변형, 화면 가득한 아이콘, 복잡한 그림, 그라데이션 바탕.

- 화면 점유율 · 아이콘 하나가 폭 12~26%, 높이 13~44% 다. 화면 가운데(가로 37~63%) 밖으로 거의 나가지 않는다. 화면을 채우는 것은 바탕 색면이다. 3.3초는 빨강·파랑 두 띠가 화면을 반씩 채운다. 아이콘 둘레가 비어 보이지 않는 이유는 바탕 색이 강하고, 아이콘의 부품(김, 햇살, 물결 막대, 점선, 물결 고리)이 아이콘보다 넓게 퍼지기 때문이다.
- 동시에 보이는 요소 수 · 아이콘 1개 + 부품 3~8개(김 3, 햇살 8, 햇살 5 + 막대 4, 물결 고리 2~3) + 구석 표기 4개(장면 번호, 장면 이름, 영문 이름, 진행 점).
- 변형 한 번의 길이 · 아이콘 A → 중간 도형 → 아이콘 B 가 0.3~0.5초다. 중간 도형(공·타원)은 0.1~0.2초 보인다. 컵 → 빨강 공(1.35~1.7초), 해 → 공(2.45~2.6초), 지는 해 → 흰 타원(3.75~4.15초), 갈매기 → 타원(5.0~5.3초), 비행기 → 빨강 덩어리(6.25~6.4초), 핀 → 공(7.15~7.3초), 하트 → 타원(8.1~8.3초).
- 아이콘 유지 · 0.6~1.0초씩 머문다. 머무는 동안에도 김 흔들림, 해 돌기, 날개 퍼덕임, 비행, 물결, 하트 뛰기가 있다.
- 회전 · 변형 중에 도형이 10~20° 돈다(컵 → 공 약 20°, 해 약 10°, 흰 타원 약 15°). 변형이 끝나면 0° 로 돌아온다.
- 찌그러짐·늘어남 · 떨어지는 방울 0.7 x 1.4, 착지 1.4 x 0.7. 변형 중 중간 도형은 진행 방향으로 10~15% 늘어난다. 하트 뛰기 1.06배.
- 완화 · 변형은 가운데가 가장 빠르고 처음과 끝이 느리다. 처음과 끝에 약 3프레임씩 거의 멈춘 구간이 있다.
- 색면 전환 · 원형 퍼짐 5번(1.7, 2.5, 6.4, 7.3, 8.1초), 띠 밀기 2번(2.5초 바다가 아래에서, 4.0초 빨강이 위로). 원형 퍼짐은 항상 아이콘 자리에서 시작하고 0.15~0.25초에 화면을 덮는다. 퍼지는 원의 가장자리는 조금 흐리다(약 20~40px).
- 움직임 세기 목표 · 평균 13.7. 대부분은 색면 전환이 만든다(전환 구간 20~70). 아이콘 변형만으로는 2~10 이다. 색면 전환을 빼면 평균이 5 아래로 떨어진다. 바탕이 바뀌는 횟수 7번을 지킨다.

## 4. 전환

- 컷과 페이드가 없다. 10초 동안 모양 하나가 계속 이어진다.
- 아이콘 → 아이콘 · 늘 단순한 중간 도형(공·타원)을 거친다. 바로 바뀌지 않는다.
- 부품 이어 주기 · 컵의 김 세 줄이 해의 햇살이 되고, 햇살이 지는 해의 물결 막대가 된다. 비행기의 점선 자국이 핀 둘레를 감싸고, 핀의 물결 고리가 된다. 각 장면의 색이 끝 화면의 색 막대가 되어 이름의 점으로 모인다.
- 색면 · 원형 퍼짐은 아이콘이 중간 도형일 때 시작한다. 바탕이 바뀌는 동안 아이콘 색도 같이 바뀐다(검정 → 빨강, 빨강 → 흰색).
- 끝 화면 · 마지막 흰 공이 글자를 놓으며 구른다. 도형 하나가 이름이 된다.

## 5. 타이포

- 이름 · 둥근 기하 고딕 소문자 한 단어(글자 6개)와 빨강 마침점. 소문자 몸통 높이 약 134px(화면 높이 12.4%), 올림 획 높이 약 190px(17.6%), 단어 폭 약 960px(50%). 가운데 정렬, 세로 중심 약 33%. 색은 흰색(#F8F4E9 근처).
- 부제 · 이름 아래(세로 약 64%). 한자 두 자 + 빨강 점 + 한자 두 자, 글자 높이 약 40px(3.7%), 자간 넓음. 그 아래(세로 약 71%) 라틴 대문자 작은 줄, 약 16px, 자간 아주 넓음, 회색.
- 구석 표기 · 왼쪽 아래(가로 5~22%, 세로 약 92%). 장면 번호 숫자 약 16px(고정폭), 한자 장면 이름 약 32px(3%), 라틴 영문 이름 약 12px. 오른쪽 아래(가로 87~95%, 세로 약 92%) 점 7개, 현재 장면은 길이 약 30px 막대. 표기 색은 바탕에 따라 검정 또는 흰색이다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 1.35~3.3초. 화면 가운데 폭 16% 의 검은 컵이 0.35초 동안 약 20° 돌며 빨강 공으로 오므라들고, 김 세 줄을 그대로 단 채 노랑 원이 0.2초 만에 화면을 덮으며 해(폭 470px)가 되고, 다시 빨강 원과 아래에서 차오르는 파랑 띠로 바탕을 반씩 나눈 지는 해(폭 500px)가 된다. 중간 도형 없이 바로 바뀌거나 바탕 색면이 그대로면 이 영상이 아니다.
- 12초 판 압축 예 · 10초 원본을 12초에 펼친다. 아이콘 일곱 개를 그대로 두고 각 장면 유지를 0.6~1.0초에서 0.8~1.2초로 늘린다. 0~0.9초 떨어짐과 컵, 0.9~2.3초 컵 유지와 해로 변형, 2.3~3.4초 해, 3.4~4.8초 지는 해, 4.8~5.9초 갈매기, 5.9~7.3초 비행기와 고리, 7.3~8.4초 핀, 8.4~9.5초 하트, 9.5~12초 이름 굴리기·부제·끝 정지. 변형 한 번의 길이(0.3~0.5초)와 색면 전환 길이(0.15~0.25초)는 늘리지 않는다. 박을 0.5초 간격으로 두고 변형 착지를 2초 마디 첫 박에 맞춘다.
- 중간 도형(공·타원)을 거치는 변형, 변형 중 10~20° 회전과 10~15% 늘어남.
- 아이콘 자리에서 퍼지는 원형 색면 전환. 바탕 색이 일곱 번 바뀐다.
- 앞 장면의 부품이 다음 장면의 부품이 되는 이어 주기.
- 구석의 장면 번호와 점 7개 진행 표시. 사슬의 순서를 보여 준다.
- 마지막 공이 굴러가며 이름 글자를 놓는 끝.

## 7. 함정

- 화면의 이름 한 단어, 부제, 장면 이름 일곱 개는 원작의 것이다. 옮기지 않는다. 역할(가상 이름 한 단어, 부제 한 줄, 장면 이름 일곱 개, 장면 번호)만 가져온다.
- 코드로 만들 때 밀도가 줄어드는 지점과 막는 법.
  - 바탕이 한 색으로 남는다 · 아이콘이 작은 영상이라 바탕이 바뀌지 않으면 화면이 빈다. 색면 전환을 7번 넣는다. 원형 퍼짐은 아이콘 중심에서 반지름 0 → 화면 대각선(약 2200px)까지 0.2초에 키운다.
  - 아이콘이 더 작아진다 · 아이콘 폭을 화면의 12% 아래로 두지 않는다. 해·지는 해처럼 부품이 있는 장면은 부품까지 폭 24~26% 로 둔다. 컵·하트·핀은 높이 27~35% 로 둔다.
  - 변형이 꼬인다 · 두 경로의 점 수가 다르거나 첫 점의 방향이 다르면 중간에 꼬인다. 아래 8절 방법으로 모든 경로를 같은 점 수로 다시 뽑고 첫 점을 맞춘다. 변형 한가운데(진행 0.5) 화면을 `render.mjs --snap` 으로 찍어 확인한다.
  - 바로 바뀐다 · A → B 를 직접 보간하지 않는다. A → 공(또는 타원) → B 두 단계로 나누고 각 0.15~0.25초를 준다.
  - 부품이 사라진다 · 김·햇살·막대·점선은 아이콘과 따로 된 경로로 두고, 다음 장면의 부품 경로로 따로 변형한다.
  - 구석 표기를 빠뜨린다 · 장면 번호와 진행 점은 화면이 비어 보이지 않게 하는 요소다. 처음부터 끝까지 둔다.
- 한국어로 옮길 때 · 이름은 소문자 몸통 134px, 올림 획 190px 이다. 라틴 가상 이름이면 InterVariable 으로 원래 크기를 쓴다. 한국어 이름이면 Pretendard SemiBold 140px 두세 글자에 마침점 하나를 빨강 원(지름 약 36px)으로 붙인다. 장면 이름 한자 두 자는 Pretendard SemiBold 32px 한국어 두세 글자로 바꾼다. 부제는 Pretendard Regular 36~40px, 자간 0.2em.

## 8. 코드로 재현 못 하는 요소와 대체 방법

글꼴은 Pretendard Regular·SemiBold 와 숫자·라틴용 InterVariable 뿐이다. 외부 변형 라이브러리는 저장소에 없다고 본다. 값은 1920x1080 기준이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 꼬이지 않는 경로 변형 | 저장소에 점 맞추기 라이브러리가 없다 | SVG 경로를 로드 때 `getPointAtLength` 로 같은 점 수(128개)로 다시 뽑는다. 두 점 배열의 첫 점을 각 도형의 맨 위 점으로 맞추고, 128가지 시작점 이동 가운데 점 사이 거리 합이 가장 작은 것을 고른다. 진행값은 `cubic-bezier(0.7,0,0.3,1)` 로 바꾼다. seek(t) 에서 점을 보간해 `d` 를 다시 쓴다 | 구멍 있는 도형(컵 손잡이 구멍) 처리 |
| 구멍 있는 도형 | 경로 하나로 구멍을 보간하기 어렵다 | 손잡이 구멍은 따로 된 작은 원으로 두고, 변형 시작 0.1초 안에 지름을 0 으로 줄인다 | 없음에 가깝다 |
| 원형 색면 전환 | 없다. 된다 | 바탕 위 DOM 원 하나(`border-radius: 50%`), 중심은 아이콘 중심, 지름 0 → 2200px 를 0.2초에, 완화는 앞이 빠른 곡선. 가장자리 흐림은 `filter: blur(20px)` | 없음 |
| 접힌 종이 그림자 면 | 없다. 된다 | 아이콘 경로를 오른쪽 아래 대각선으로 자른 반쪽에 검정 12% 를 덮는다(`clipPath`) | 없음 |
| 종이 결 바탕 | 실제 종이 스캔 | `texTile(seed, { mc: '237,233,222', mottle: .03, fibers: 80 })` 에 모서리 비네트(검정 8%) | 큰 얼룩 |
| 점선 비행 자국 | 없다. 된다 | SVG 경로에 `stroke-dasharray: 8 10`, 흰색 2px, 비행기 위치까지 `stroke-dashoffset` 으로 그려지게 한다 | 없음 |
| 굴러가며 글자 놓기 | 글자가 공에서 나온다 | 흰 공(지름 약 90px)이 0.6초에 가로 25% → 75% 를 구르며 돈다. 공이 글자 자리를 지날 때마다 그 글자를 0.06초 동안 크기 0.6 → 1.0, 투명도 0 → 1 로 놓는다. 마지막에 공이 빨강 점이 된다 | 공에서 글자가 빠져나오는 모양 |
