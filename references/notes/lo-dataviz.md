# 연필이 찍는 꺾은선 · 한 사람의 백 년 기온 — 분석 노트

> 크림색 종이 위의 50초 영상. 파랑·빨강 두 빛깔 연필 한 자루가 한 해에 점 하나씩 꺾은선을 찍고, 손글씨 메모가 몇몇 점에 꽂힌다. 첫 점의 극단 접사에서 물러나며 축이 자라고, 연필을 따라 옆으로 가다가, 값이 치솟는 끝에서 화면이 기울고 틀이 깨진다. 마지막 점 뒤 전체 그래프가 왼쪽부터 줄무늬 띠로 바뀌고, 다음 해 빈칸이 끝 카드로 넓어진다. 실제 수치 하나를 이야기로 보여 주는 보고서·과학·통계 영상에 맞는다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 36.0~39.0초의 "점 약 100개와 메모 5개가 보이는 전체 꺾은선 → 0.65초 동안 왼쪽부터 세로 줄무늬로 바뀌는 순간"이다. 그래프 몸통이 화면 가로 2~96%, 세로 22~74% 를 차지하다가, 줄무늬 띠(가로 84%, 세로 33%, 짙은 파랑 #3D5D71 → 거의 흰색 → 짙은 빨강 #A41525)로 바뀐다. 이 바뀜이 빠지면 단순한 꺾은선 그리기 영상이 된다.
- 12초 판 압축 예 · 0~2.0초 빈 종이에 첫 점과 메모(접사 4배), 2.0~3.0초 물러나며 축이 자라고 제목, 3.0~6.0초 연필을 따라 옆으로(점 약 40개, 박을 나눠 빨라짐, 메모 1개 더), 6.0~7.5초 기울며 치솟음과 연필 뒤집기, 7.5~8.5초 무음 0.5초 + 마지막 점, 8.5~11.0초 대표 장면(물러나 전체 1.0초 + 줄무늬 바뀜 0.65초 + 정지 0.85초), 11.0~12.0초 빈칸 끝 카드. 메모는 5개 중 2개만 남긴다. 줄무늬 뒤의 당기며 옆으로 가는 구간은 뺀다. 20~27초의 촘촘한 따라가기(점 약 26개, 요소 묶음 9개, 8분·16분 박)는 3.0~6.0초 안의 1.5초로 줄이고 하트 메모와 앞 메모 흐려짐을 뺀다.
- 종이를 비워 두고 색을 아꼈다가 줄무늬에서 한 번에 쓰는 구조.
- 연필 한 자루가 끝까지 시선을 끈다. 파랑에서 빨강으로 뒤집히는 순간이 이야기의 꺾임이다.

## 7. 함정

- 제목, 메모, 자막, 끝 카드의 제작 표기는 원작의 것이다. 옮기지 않는다. 역할(제목 한 줄, 점에 꽂힌 메모, 아래 자막, 끝 카드)만 가져온다. 끝 카드 제작 표기와 자료 설명에 실존 기관·서비스 이름이 있다. 쓰지 않는다.
- 원작의 줄무늬 띠는 널리 알려진 기온 줄무늬 그림과 같은 모양이다. 자료가 기온이 아니면 다른 양 끝 색(예: 짙은 청록 → 흰색 → 짙은 주황)과 자료에 맞는 그래프를 쓴다.
- 수치는 우리 원문에서 확인한 실제 자료만 쓴다. 원작 수치를 옮기지 않는다.
- 종이에 색을 많이 쓰면 끝의 줄무늬가 사건이 되지 않는다. 줄무늬 전까지 채도 있는 화소를 화면의 3% 아래로 둔다(연필·점·메모만).
- 원본은 전체 그래프에서 메모 글자가 화면 높이의 1.3% 까지 내려간다. 우리 판은 한국어 메모를 2.5%(약 27px) 아래로 내리지 않고, 메모를 2~3개로 줄인다.
- 연필 길이가 짧으면 커서처럼 보인다. 화면 대각선의 40% 이상이 보이게 하고 늘 같은 각도(약 35~40°)를 지킨다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 그래프는 canvas 하나에 2D 카메라(위치·배율·기울기)를 걸어 그린다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 손글씨 메모 | 손글씨 글꼴이 없다 | Pretendard Regular 27~85px(배율에 따라), 색 #446B92 또는 #A73747. 글자를 왼쪽부터 `clip-path: inset(0 X% 0 0)` 으로 공개해 쓰는 느낌을 낸다(한 글자 약 0.06초). 지시선은 canvas 곡선을 `HAND.ink(ctx, P, { frac, w: 2, color: '#446B92', key: 'lead1', B: 0 })` 로 0.4초에 그린다. | 필기체의 손맛 |
| 세리프 제목·자막 | 세리프 글꼴이 없다 | 제목 Pretendard SemiBold 70px, 자막 Pretendard Regular 34px #3E3632. 자막은 낱말마다 span 으로 나눠 아직 안 나온 낱말을 불투명도 0.25 로 먼저 두고 차례로 1 로 올린다 | 신문 같은 인쇄 인상 |
| 고정폭 값 표기·눈금 | 고정폭 글꼴이 없다 | InterVariable 의 고정폭 숫자(`font-variant-numeric: tabular-nums`) 16~20px, #6E6862 | 타자기 느낌 |
| 실물 같은 연필 | 깎은 나무, 육각 면, 그림자 | SVG 로 그린다 · 길이 1100px, 폭 40px 막대를 반으로 나눠 #446B92·#A73747, 면 두 줄(밝은 면 +12% 밝기, 그늘 #2A5585), 깎은 끝은 삼각형 #E8C9A0 + 심 삼각형. 각도 37° 고정. 뒤집기는 0.5초 동안 화면 안에서 끝과 끝이 바뀌는 180° 회전(`rotate`) + 흐림 대신 0.08초 간격 잔상 3장 | 실물 연필의 재질, 초점 흐림 |
| 초점 이동(31.0~32.0초) | 렌즈 흐림 | CSS `filter: blur(8px)` → `blur(0)` 을 0.5초에. | 렌즈 특유의 번짐 모양 |
| 줄무늬로 바뀜 | 없다. canvas 로 그대로 된다 | 점마다 시작 시각을 왼쪽부터 0.0065초씩 늦춘다(100개 → 0.65초). 점 하나는 0.25초 동안 띠 가운데(세로 47%)로 떨어지고(앞 45%), 남은 시간에 높이 0 → 360px 로 늘어난다(끝이 느려지는 곡선). 폭은 띠 폭 ÷ 점 수(약 16px). 색은 값에 따라 위의 파랑·흰색·빨강 9단계를 보간한다 | 없음 |
| 점 격자 바탕 | 없다. CSS 로 된다 | `background-image: radial-gradient(circle, #EAE6DE 1.3px, transparent 1.8px); background-size: 24px 24px` 를 화면에 고정해 둔다(그래프 카메라와 따로) | 없음 |
| 치솟을 때 화면 기울기 | 없다 | canvas 카메라에 `rotate(-2.4°)` 를 24.0~30.5초 동안 0 → -2.4° 로 천천히 걸고, 30.5초 밀고 들어갈 때 0 으로 되돌린다 | 없음 |
| 끝 카드 점선 틀 | 없다 | SVG `rect` 1180x560, `stroke: #7F414A`, `stroke-width: 3`, `stroke-dasharray: 9 7`. 빈칸(폭 17px)의 너비와 높이를 1.0초 동안 이 크기로 늘린다(끝이 느려지는 곡선) | 없음 |
| 종이 | 실제 종이 | `texTile(seed, { mc: '120,110,95', mottle: .02, dark: .02, light: .03, fibers: 60, specks: 8 })` 를 바탕 #F5F2EB 위에 깐다. 결을 거의 안 보이게 한다 | 없음에 가깝다 |
