# 경계 공간 발견 영상 · 노란 복도의 캠코더 테이프 — 분석 노트

> 1990년대 가정용 캠코더로 찍은 한 사람의 시점 영상 60초. 누렇게 바랜 벽지와 칸막이가 끝없이 이어지는 빈 사무 공간을 형광등이 웅웅대며 비춘다. 벽의 안내문이 근무 규칙을 알려 주고, 걷는 사람은 규칙을 지키며 복도를 지난다. 줌을 당긴 먼 끝에 손을 흔드는 형체가 1초쯤 보이고, 테이프가 찢기듯 튄 뒤 같은 구도에서 시각만 세 시간 뛰어 있다. 끝에 빨간 비상구 표지 아래 문이 저절로 열리고 녹화가 꺼진다. 미스터리·공포 분위기 게임 예고, 수수께끼형 이벤트, "규칙이 있는 공간"을 소개하는 영상에 맞는다.

출처 · lo:backrooms. 원래 글은 긴 스타일 명세다(본질, 움직임, 카메라 문법, 함정, 숏 표, 데모의 움직임 수치). 손떨림·걸음·호흡 주파수, 줌 화각, 깜박임 길이, 문 열림 시간까지 수치가 있다. 그러나 숏 표에 시각이 없고, 화면 색 값, 4:3 화면이 16:9 안에 놓인 크기, 화면 표시(녹화 표시·배터리·시각)의 자리와 크기, 형체의 실제 크기와 보이는 시간, 장면 길이가 없다. 그래서 영상 프레임을 보고 이 노트를 썼다.
측정 · 파일 1280x720 · 24fps · 59.71초. 크기는 1920x1080 기준으로 바꿔 적는다(1.5배). 장면 감지 전환은 8회(0.58초, 27.12~28.29초 사이 6회, 56.62초)다. 가운데 6회는 형광등이 세 번 꺼졌다 켜지는 순간이다. 움직임 세기 평균은 6.5 다. 손떨림 때문에 거의 모든 구간이 2~15 사이에 있다. 큰 값은 56.5초(44.4, 녹화가 꺼지는 순간), 0.0초(34.1, 테이프가 돌기 시작), 28.0초(16.9, 깜박임), 42.0~43.0초(13~16, 모퉁이 돌기)다. 44.0~48.5초는 1.4~3.0 으로 거의 멈춘다(숨 멈춤). 57.0초부터 끝까지 0 이다. 색 값은 프레임에서 잰 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. 박 검출은 분당 약 120 이지만 타격이 약하다(0.29초의 첫 타격 1.00 을 빼면 대부분 0.16~0.26). 음악보다 웅웅거림과 말소리로 보인다. 46.76~47.74초는 완전 무음(-90dB)이고, 47.74초에 킥(세기 0.49)이 들어온다(비상구 앞 숨 멈춤 뒤). 49.63초·50.12초에도 킥이 있다(문이 열리는 자리). 56.39초 타격(0.60) 직후 56.66초부터 끝까지 무음이다(녹화 꺼짐). 16.66~21.0초는 -22~-28dB 로 낮고 고르다(안내문을 읽는 구간). 26.68~28.28초에 짧은 무음 4개가 깜박임과 맞물린다.

## 3. 움직임

- 원래 글의 수치(보폭 0.72m, 머리 위아래 3cm, 좌우 1.8cm, 기울기 ±0.8°, 호흡 0.27Hz, 떨림 1·3.5·9Hz, 아래 보기, 줌 52° → 27°, 깜박임 0.1초 세 번, 노출 늦게 따라오기 약 0.45초, 문 1.3초)는 화면과 맞는다. 되풀이하지 않는다.
- 영상에서 확인한 점 · 손떨림만으로 움직임 세기가 평균 6.5 를 유지한다. 걷는 구간 4~8, 고개 돌리기 12~17 이다. 손떨림이 꺼지는 숨 멈춤 구간(33.0초, 44.0~48.5초)은 1.4~3 으로 뚜렷하게 내려간다. 이 대비가 긴장을 만든다.
- 문은 측정상 약 1.5초(50.0~51.5초)에 걸쳐 열린다.
- 아무 일도 없는 걷기가 7.0~12.0초, 21.5~27.0초, 37.5~42.0초에 있다. 합쳐 약 15초다.

## 4. 전환

- 원래 글대로 컷은 테이프 사건에서만 난다 · 시작(0.6초), 깜박임 세 번(27~28.5초), 튐(36.5초), 녹화 꺼짐(56.6초). 그 밖은 하나로 이어진 촬영이다.
- 영상에서 확인한 점 · 구도는 그대로이고 화면 표시만 바뀌는 것이 시간 점프의 유일한 신호다(37.0초). 배터리 칸 수까지 함께 바뀐다.
- 끝 제목은 녹화가 꺼진 뒤 검은 화면에 따로 둔다. 캠코더 그림 위에 겹치지 않는다.

## 5. 타이포

- 화면 표시 · 녹화 표시(빨간 점 + 글자, 그림 왼쪽 위 · 가로 약 15%, 세로 약 7%), 배터리(오른쪽 위 · 가로 약 83%, 세로 약 7%), 시각과 날짜 두 줄(오른쪽 아래 · 가로 약 70~85%, 세로 87~95%). 모두 흰 글자에 옅은 그림자, 글자 높이 약 3%(약 32px). 고정폭 도트 글자.
- 캠코더 제목 · 2~5초에 큰 도트 글자 두 줄(글자 높이 약 7%), 흰 글자에 검은 테.
- 자막 · 화면 가운데 아래(세로 약 79~84%)에 검은 상자, 흰 고정폭 글자 높이 약 2.2%. 방송 목소리 줄은 머리표를, 혼잣말 줄은 기울인 글자를, 소리 설명은 대괄호를 쓴다. 2줄을 넘기지 않는다.
- 안내문 · 화면을 채울 때 제목 굵은 산세리프(글자 높이 약 5%), 규칙 번호 목록(약 3%). 읽기 쉽게 크게 보여 주는 것이 연출이다.
- 끝 제목 · 검은 화면 가운데 가는 고정폭 글자 한 줄(높이 약 3%)과 작은 표기 두 줄.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 32.5~37.5초의 "복도 정면에서 줌을 당겨 먼 끝 가운데에 화면 높이 약 16% 의 어두운 형체가 손을 흔드는 1초, 초점이 미끄러져 빈 안개, 테이프 튐, 같은 구도에서 시각 표시와 배터리 칸만 바뀜"이다. 형체는 가로 50% 근처, 화면의 약 2% 면적보다 작다. 흔들림이 멈춘 상태에서 보인다. 이 흐름이 빠지면 그냥 노란 복도 걷기가 된다.
- 12초 판 압축 예 · 0~0.4초 테이프 시작, 0.4~2.0초 벽 안내문과 캠코더 제목(색이 푸름 → 노랑), 2.0~2.6초 옆으로 돌아 복도, 2.6~4.0초 걷기, 4.0~5.5초 안내문 근접(규칙 2~3줄만, 1.5초 가려지지 않게), 5.5~6.0초 깜박임 세 번, 6.0~6.5초 신발 내려다보기, 6.5~9.5초 대표 장면 3초(줌 0.5초, 형체 0.8초, 초점 미끄러짐 0.4초, 튐 0.3초, 같은 구도 1.0초), 9.5~11.2초 비상구 표지 앞 숨 멈춤과 문이 저절로 열림, 11.2~12.0초 녹화 꺼짐(정지 0.2초, 튐 0.2초, 검정). 모퉁이 돌기와 마지막 안내문은 뺀다.
- 규칙 안내문을 화면 가득 오래 보여 주는 연출.
- 손떨림을 끄는 순간을 긴장의 신호로 쓰는 방법.
- 노랑 한 계열 화면에 빨강 하나(비상구 표지)만 두는 색 규칙.

## 7. 함정

- 캠코더 제목, 안내문 규칙 문장, 방송·혼잣말 자막, 화면 표시의 날짜, 끝 제목과 표기는 원작의 것이다. 옮기지 않는다. 역할(캠코더 제목, 규칙 안내문, 자막, 시각 표시)만 가져온다. 끝 표기에 실존 회사·서비스 이름이 있다. 쓰지 않는다.
- 이 공간 양식은 인터넷에서 널리 알려진 특정 괴담 장소를 떠올리게 한다. 그 장소의 이름과 고유 설정을 화면·문구에 쓰지 않는다. 노란 칸막이 복도라는 일반 공간과 규칙 형식만 가져온다.
- 4:3 을 16:9 로 옮기는 구도 · 원본처럼 가운데 1440 x 1080px 에 4:3 그림을 두고 양옆 240px 을 순흑으로 둔다. 16:9 전체를 채우고 싶으면 그림을 1920 x 1080 으로 넓히고, 화면 표시를 그림 모서리 안쪽 5%(가로 96px, 세로 54px)에 둔다. 넓히면 복도 양옆 칸막이가 더 보여 소실점이 약해지므로, 화각을 원래 글의 52° 대신 수평 약 66° 로 잡아 세로 구도를 같게 맞춘다. 양옆 검은 띠는 "옛 테이프" 신호이므로 남기는 쪽을 먼저 고른다.
- 형체를 크게 또는 오래 보여 주면 공포 영화가 된다. 화면 높이 20% 이하, 1초 이하, 초점이 맞는 동안만.
- 화면 전체를 밝게 칠하면 병원 복도처럼 보인다(원래 글의 함정). 먼 끝은 #43403F 근처로 어둡게, 형체 주변 등은 꺼 둔다.
- 움직임 세기 · 손떨림을 빼면 평균이 1 아래로 떨어져 멈춘 화면처럼 보인다. 걷는 구간은 4~8 을 목표로 걸음·호흡·떨림을 늘 켠다. 끄는 것은 숨 멈춤 한두 곳뿐이다.
- 효과음으로 놀래지 않는다. 원본은 타격이 거의 없고(0.16~0.26), 가장 큰 사건 앞에 완전 무음 약 1초를 둔다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 그림 영역은 가운데 1440 x 1080px 이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 끝없는 칸막이 복도 | 실사 같은 3D 실내 | three.js(`vendor/three`)로 만든다. 칸막이는 상자(폭 0.08m, 높이 2.4m, 길이 1.2~3m)를 시드 고정 난수로 복도 양옆에 40개, 천장 판 2.7m, 형광등 판은 빛나는 평면 0.6 x 1.2m 를 2.4m 간격으로 한 줄. 안개 `THREE.Fog` 색 #43403F, 시작 8m, 끝 40m. 형체 주변 ±5m 의 등은 끈다 | 전역 조명의 부드러운 반사 |
| 바랜 벽지와 습한 카펫 | 실제 재질 사진 | canvas 로 텍스처를 굽는다 · 벽지는 #837536 바탕에 세로 줄 4px 간격(#786A30), 작은 마름모 무늬 24px 간격. 카펫은 #7A6A2C 바탕에 `texTile(seed, { mc: '90,75,30', mottle: .12, dark: .1, light: .04, fibers: 0, specks: 60 })` 을 겹친다 | 실제 얼룩의 사실감 |
| 캠코더 화질(번짐·잡음·색 번짐) | 테이프 매체의 결 | `LOOKS.post(gl, { w: 1440, h: 1080, tone: 'neutral', bloom: 0.5, threshold: 0.9, ca: 0.002, vignette: 0.45, grain: 0.08 })`. 그 위에 화면 전체를 세로 2배로 늘렸다 줄이는 해상도 낮추기(가로 720px 로 그리고 키우기) | 테이프 색 번짐의 독특한 결 |
| 자동 초점 찾기 | 피사계 심도 렌더 | 3D 캔버스 요소에 `filter: blur()` 를 건다. 흐림 반지름을 6px → 0 → 2.5px → 0 으로 넘쳤다 돌아오게 움직인다(각 0.25~0.4초). 줌 때는 카메라 화각을 52° → 27° 로 1.0초에 | 거리마다 다른 흐림 |
| 손떨림 | 없다 | 카메라 위치·회전을 t 에서 계산한다 · 걸음 주기(보폭 0.72m) 위아래 3cm, 좌우 1.8cm, 기울기 ±0.8°, 호흡 0.27Hz, 떨림 1·3.5·9Hz 의 사인 합(위상은 시드 고정). 숨 멈춤 구간은 모두 0 | 없음 |
| 먼 끝의 형체 | 사람 모양을 사실적으로 만들기 어렵다 | 원래 글처럼 canvas 에 어두운 실루엣(작은 머리, 긴 목, 좁고 높은 어깨, 무릎까지 오는 팔)을 그려 카메라를 보는 평면에 붙인다. 색 #1E1A12, 높이 화면의 16%(약 175px)가 되는 거리에 둔다. 팔은 3.6초 주기로 ±18° 흔든다 | 없음 |
| 형광등 깜박임과 노출 늦음 | 없다 | 0.13초 꺼짐을 0.25초 간격으로 세 번. 켜진 뒤 `post.o.exposure` 를 0.4 → 1.0 으로 0.45초에 올린다 | 없음 |
| 테이프 튐·찢김 | 줄마다 다른 어긋남 | 최종 프레임을 2D canvas 로 받아 0.4초 동안 가로 줄(높이 4~12px)마다 시드 고정 난수로 ±10~60px 옆으로 밀어 다시 그린다. 화면 위 10% 에 흰·회색 잡음 띠. 화면 표시 글자도 같은 구간에 2~3줄 어긋난다 | 없음 |
| 화면 표시와 자막 글자 | 도트 고정폭 글꼴이 없다 | DOM. 숫자와 시각은 InterVariable 굵기 600, `font-variant-numeric: tabular-nums`, 32px, 흰색에 `text-shadow: 2px 2px 0 rgba(0,0,0,.6)`. 녹화 표시는 빨간 원 지름 18px + 한국어 녹화 표시 Pretendard SemiBold 30px. 자막은 Pretendard Regular 26px, 검은 상자 안쪽 여백 6px 12px | 도트 글자의 테이프 인상 |
| 안내문 | 종이에 인쇄한 문서 | DOM 으로 문서를 만들어 canvas 에 그려 3D 평면 텍스처로 벽에 붙인다(크림 #EFE8D6, 제목 Pretendard SemiBold, 규칙 Regular). 테이프 자국은 반투명 사각 2개 | 종이 구김 |
| 녹화 꺼짐 | 없다 | 마지막 프레임을 0.2초 정지, 0.2초 테이프 튐, 검정. 끝 제목은 검은 화면에서 0.8초 뒤 불투명도 0 → 1 | 없음 |
