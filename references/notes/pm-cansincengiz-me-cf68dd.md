## 1. 본질

- 바탕은 두 번 바뀐다. 남색이 섞인 검정(#080808·#080818 근처) → 위 짙은 파랑(#1828a8 근처)에서 아래 하늘색(#a8d8f8 근처)으로 가는 세로 그라데이션 → 흰색(#f8f8f8 근처).
- 주인공은 로고 없는 3D 은색 노트북 하나다. 처음에는 열려 있고 화면에 코딩 에이전트의 터미널 창(고정폭 글자, 초록·빨강·주황 강조)이 있다. 파란 바탕에서는 회청색(#B3BBCB, 프레임에서 직접 잰 값)으로 보인다.
- 구도는 세로 3단이다. 위(화면 높이의 9~28%)에 두 줄 제목, 가운데(33~65%)에 노트북(너비의 약 70%), 아래(66~81%)에 상태 카드.
- 상태 카드는 둥근 반투명 하늘색 판(#BBEAFE, 프레임에서 직접 잰 값)과 옅은 그림자다. 포인트 색(초록 점·체크, 빨강 기준 숫자, 초록→빨강 온도 막대)은 카드 안에서만 작게 쓴다.
- 아닌 것 · 사진, 화면 녹화, 사람·손, 책상 같은 3D 배경, 입자, 물체 여러 개, 연속 하드 컷.

## 3. 움직임

- 제목 등장은 한 가지다. 줄마다 아래 마스크(mask)에서 올라오고, 낱말마다 약 0.05초 늦게 흐림(blur)에서 선명해진다. 두 줄이 0.4초에 다 나온다. 퇴장은 위로 빠지며 흐려진다(0.1~0.15초).
- 기능 구간의 노트북은 제자리에서 천천히 돌고, 윗면에 반사광이 지나간다. 기능이 바뀌는 순간에만 각도가 0.03초 안에 바뀐다.
- 카드 숫자는 기능마다 다르게 센다. 호출 횟수는 계속 오르고(초당 약 34), 온도는 빠르게 올라 멈추고, 배터리는 천천히 내린다.
- 잠 기호(z)는 두 번 나온다. 앞은 가는 외곽선 z 셋이 작은 것부터 오른쪽 위로 쌓인다. 뒤는 채운 흰 z 둘이다.

## 4. 전환

- 어두운 장 → 파란 장 · 유일한 바탕 교체다. 4.12초에 화면이 회색(#A2A1A3, 프레임에서 직접 잰 값)으로 번쩍이고, 같은 프레임에 하늘색 원이 가운데에서 열린다. 흰 고리가 뒤따라 퍼진다.
- 마크 → 워드마크 → 모서리 로고 · 같은 물체가 크기와 자리만 바꾼다. 컷이 없다.
- 기능끼리 · 제목 교체, 노트북 각도 점프, 카드의 흐림 교차(약 0.1초)가 한 번에 온다. 바뀌는 시각(6.25, 7.6, 9.02, 10.42초 무렵)이 반 마디(1.40초) 간격이다.
- 파란 장 → 끝 카드 · 컷이 없다. 장면이 위로 밀려 나가고 흰색이 아래에서 차오른다.

## 5. 타이포

- 제목은 두 줄 짝이다. 첫 줄은 굵은 산세리프(자간 좁음), 둘째 줄은 세리프 이탤릭(폭이 좁고 획 대비가 크다)이다. 줄마다 2~3낱말이고 둘째 줄 끝에 마침표가 있다. 가운데 정렬이다.
- 첫 줄 대문자 높이는 화면 높이의 약 5%, 둘째 줄은 어센더(ascender)까지 약 6.5%다. 두 줄 너비가 비슷하다(너비 약 40%).
- 제목 색은 장면을 따른다. 어두운 장은 흰색, 잠드는 장은 회색, 파란 장은 흰색, 끝 카드는 검정이다.
- 워드마크는 아주 굵은 기울어진 산세리프 소문자 + 마침표다. 끝 카드에서 너비 약 66%다.
- 카드 안은 작은 대문자 라벨(회색, 넓은 자간, 높이 약 1.3%), 굵은 이름, 고정폭에 가까운 숫자다.

## 6. 가져올 것

- 문제 → 공개 → 기능 → 끝 카드의 4막을 15초에 넣는 뼈대. 문제는 물체의 상태 변화(열림 → 닫힘 → 잠듦)로 보여 준다.
- 문제의 상징이 브랜드 마크가 되어 바탕 교체로 이어지는 전환.
- 3D 물체 하나를 끝까지 같은 자리에 두고, 기능마다 각도와 아래 카드만 바꾼다.
- 카드 숫자의 움직임이 기능의 뜻이 된다. 계속 오름(일함), 올랐다 멈춤(안정), 천천히 내림(아낌), 아이콘 교체(끝남).
- 기능 교체를 반 마디 격자에 맞춘다. 제목·각도·카드가 한 번에 바뀌어 박자가 또렷하다.
- 같은 두 줄 제목 짝을 끝 카드 표어까지 쓴다.

## 7. 함정

- 화면의 제목, 워드마크, 카드 속 라벨·이름·숫자, 주소, 작은 줄은 원작의 것이다. 옮기지 않는다. 카드에 나오는 다른 회사 도구 이름도 쓰지 않는다.
- 원본은 1080x1080 정사각(1:1)이다. 제목-물체-카드를 세로로 쌓았다. 1920x1080 에 그대로 두면 양옆이 빈다. 물체를 조금 왼쪽에 두고 제목과 카드를 오른쪽 단으로 옮긴다. 크기는 화면 높이를 기준으로 다시 잰다.
- 3D 노트북은 모델링 부담이 크다(키보드, 화면, 경첩 회전, 금속 재질). three.js 로는 둥근 상자 두 개 + 경첩 축 회전 + canvas 화면 텍스처로 줄인다. 다른 대상이면 그 대상을 단순한 3D 도형으로 다시 고른다.
- 은색 판은 단색으로 칠하면 납작하다. 환경 맵(environment map)이나 그라데이션 반사를 넣어야 돌 때 반사광이 지나간다.
- 둘째 줄의 세리프 이탤릭 대비는 영어 글꼴에 기댄다. 한글은 기울인 명조가 어색하다. 바로 선 명조로 바꾸고 굵기 대비를 키운다. 작은 라벨은 키우거나 뺀다.
- 기능 4장이 1.4초씩이다. 30~40초로 늘리면 장마다 한 마디(2.8초)로 늘리거나 기능 수를 늘린다.
