# 픽셀 모험 게임 타이틀 — 분석 노트

> 브라운관이 켜지듯 선 하나에서 열린 화면에, 8비트 옆 스크롤 게임 한 판이 펼쳐지는 10초 영상. 빨강 머리 주인공이 달리고 뛰며 동전을 먹고, 하늘이 낮 → 노을 → 보랏빛 저녁 → 밤으로 바뀐다. 대화창이 한 글자씩 찍히고, 카메라가 상자 앞으로 2배 다가간 뒤 상자가 열리며 빛줄기가 터진다. 끝에서 굵은 픽셀 로고가 떨어지고 시작 안내 한 줄이 깜박인다. 화면은 320x180 칸을 6배로 키운 큰 픽셀이고, 하늘·먼 산·숲·땅 네 층이 서로 다른 속도로 흐른다. 게임·앱 출시, 복고 느낌 행사 소개에 맞는다. 픽셀 아트(pixel art) · 8비트 · 시차 스크롤 · 브라운관 효과.

출처 · ms:20-pixel. 쇼케이스 프롬프트에는 효과 이름, 기법 목록, 내부 해상도, 사건 목록이 있다. 화면 구도, 층별 위치·속도, 주인공 크기, 사건 시각, 대화창·로고 크기는 없다. 이 노트는 영상 프레임(0.5초 간격 시트 20장, 0.1초 간격 띠 72장, `ffmpeg -ss` 로 직접 뽑은 9장, 1.0~2.0초 30프레임의 층별 앞뒤 차이)을 보고 그 빈칸을 채웠다.
측정 · 파일 1920x1080 · 30fps · 10.0초. 장면 전환 검출 시각은 0.13, 0.17, 0.20, 6.40, 6.47초다. 앞의 셋은 화면이 켜지는 순간, 뒤의 둘은 흰 번쩍임이다. 0.5초마다 움직임 세기의 평균은 13.3 이다. 0.0초 구간(69.0, 화면 켜짐)을 빼면 10.3 이다. 0.5~3.0초는 9.5~10.9 로 고르다. 큰 값은 4.0초(27.9), 6.0초(24.9), 6.5초(23.0)다. 작은 값은 5.0초(1.3), 3.5초(1.7), 8.5~9.5초(1.0~2.0)다. 위치·크기는 원본 프레임과 960x540 으로 줄인 프레임에서 재어 1920 기준 px 로 적었다. 색 값은 프레임에서 잰 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. BPM 은 74.9 로 잡혔지만 타격이 약 0.2초 간격으로 촘촘하다(빠른 분산화음으로 추정). 마디 첫 박은 1.58, 4.79, 8.00초다. 가장 큰 타격(세기 1.00, 킥)은 7.19초이고 로고가 떨어져 자리 잡는 순간(7.2초)과 겹친다. 2.39초(0.80)는 주인공이 점액 괴물을 밟아 점수 팝업이 뜨는 순간이다. 4.99~5.99초에 큰 타격이 0.2초 간격으로 6번 있고, 대화창 글자가 찍히는 구간과 겹친다. 4.62~4.80초에 짧은 무음이 있다. 타격과 화면 사건의 1:1 대응은 일부만 확인했다.

## 1. 본질

- 픽셀 한 칸이 1920 기준 6px 다. 내부 해상도는 320x180 이다. 확대한 프레임에서 주인공 윤곽을 세어 확인했다. 모든 가장자리가 계단이다. 흐린 경계가 없다(번쩍임·빛 번짐 제외).
- 색은 장면마다 16~24색 정도다. 낮 하늘은 위 #2C4FB0 → 가운데 #3E99E2 → 아래 #67C7EF 근처로 3~4단 띠이고, 띠 사이를 체크무늬 디더링으로 잇는다. 숲은 #348E4C 근처 진초록과 연초록 2단, 흙벽돌은 #A3583A 근처다.
- 층은 다섯이다. 하늘(디더 띠 + 구름 + 해), 먼 산(눈 덮인 봉우리), 가운데 숲(뾰족한 소나무 줄 + 돌기둥 폭포), 가까운 땅(풀 줄 + 흙벽돌 + 물·다리), 소품·인물(동전, 괴물, 상자, 주인공). 앞에 화면 정보 층(점수, 동전 수)이 있다.
- 브라운관 마감이 있다. 가로 주사선이 픽셀 한 칸 안에 1~2줄 보인다. 화면 네 모서리가 둥글게 검게 먹힌다(배럴 왜곡과 비네트). 밝은 곳에 약한 빛 번짐이 있다. 픽셀이 뭉개지지는 않는다.
- 주인공은 빨강 머리, 파랑 옷, 노랑 띠의 작은 인물 하나다. 크기는 약 16x19 칸(98x113px, 화면 높이의 10.5%)이다.
- 아닌 것 · 매끈한 확대, 부드러운 그라데이션, 반 픽셀 위치, 벡터 같은 매끈한 선, 큰 주인공 클로즈업 위주 화면, 3D.

## 3. 움직임

- 층별 흐름 속도(1.0~2.0초, 30프레임의 층별 앞뒤 차이로 셌다).

| 층 | 바뀌는 주기 | 1초 이동(추정) | 가까운 땅 대비 |
|---|---|---|---|
| 구름 | 4프레임마다(번갈아 약하게) | 약 4칸 = 24px | 0.1 |
| 먼 산 | 4프레임마다 | 7.5칸 = 45px | 0.25 |
| 숲·돌기둥 | 3~4프레임 중 2프레임 | 약 17칸 = 100px | 0.6 |
| 가까운 땅 | 매 프레임 | 약 30칸 = 180px | 1 |

- 모든 층이 한 번에 한 칸(6px)씩만 옮겨진다. 반 칸 위치가 없다. 느린 층은 몇 프레임을 그대로 멈췄다가 한 칸 뛴다. 그래서 층마다 계단처럼 움직인다.
- 주인공은 화면 가로 28~34% 에 머문다. 세계가 흘러서 달리는 것처럼 보인다. 3.3초 뒤 흐름이 멈추고 주인공이 상자까지 직접 걸어간다(가로 30% → 45%).
- 스프라이트 갱신 · 화면 전체의 앞뒤 차이가 2~3프레임 주기로 오르내린다. 주인공 달리기 그림이 1초에 10~15장으로 바뀐다고 추정한다. 그림 장수는 세지 못했다.
- 뛰기 · 돌기둥으로 오르는 점프는 약 0.3초, 높이 약 25칸(150px)이다. 정점에서 2프레임 멈춘다.
- 카메라 · 5.9~6.3초 한 번만 확대한다. 확대 배율 약 2배, 중심은 주인공과 상자 사이(가로 약 45%, 세로 약 80%)다. 확대 후에도 픽셀 경계가 계단으로 남는다(가장 가까운 이웃 확대).
- 팔레트 전환 · 낮 → 노을(3.1~3.3초) → 저녁(4.4~4.6초) → 밤(8.0~8.4초). 전환은 색 단계를 몇 프레임에 걸쳐 바꾸는 방식이다. 섞어서 흐리게 바꾸지 않는다. 노을 전환 첫 2프레임은 하늘이 하얗게 날아간다.
- 화면 요소 수 · 낮 장면에 동시에 약 25개(구름 6, 해, 산 7봉우리, 나무 30그루 이상, 돌기둥, 다리, 동전 3~6, 괴물, 상자, 주인공, 점수, 동전 수). 빈 하늘도 디더 띠와 구름이 채운다.
- 움직임 세기 목표 · 0.5~3.0초 10 안팎. 흐름이 멈추는 대화 구간(3.5~5.5초)은 2 아래로 떨어진다. 이 대비가 박자다. 확대·번쩍임·빛줄기(6.0~7.0초)에서 20 넘게 오른다. 끝 정지는 1~2 다.

## 4. 전환

- 브라운관 켜짐 · 점 → 가로선 → 띠가 벌어짐. 0.2초다. 첫 0.12초만 검정이다.
- 팔레트 전환 · 장면을 자르지 않고 하늘과 땅의 색표를 바꿔 시간을 넘긴다. 세 번 일어난다.
- 확대와 번쩍임 · 2배 확대(0.4초) → 2프레임 크림색 번쩍임 → 넓은 화면으로 돌아오며 빛줄기. 번쩍임이 확대를 되돌리는 순간을 가린다.
- 로고 등장 · 위에서 떨어져 착지 → 0.4초 뒤 사선 빛 쓸기 → 띠 꼬리표 펼침. 0.4초 간격 세 박자다.

- 모든 글자가 픽셀 글꼴이다. 획 굵기는 1~2칸이다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 6.5~7.6초. 저녁 하늘 아래 상자(가로 53%, 세로 83%)에서 디더 빛줄기 8개가 화면 위 끝까지 부채꼴로 뻗고, 동전 10여 개가 튀는 가운데, 높이 170px 두 줄 픽셀 로고(폭 44%)가 위에서 떨어진다. 픽셀 한 칸이 6px 보다 작거나 층이 셋 아래면 이 영상이 아니다.
- 10초 원본을 12초에 어떻게 펼칠지 · 켜짐 0.2초 → 낮 달리기 3.3초(0.2~3.5, 동전·괴물) → 노을 1.3초(3.5~4.8) → 대화창 1.4초(4.8~6.2) → 확대·번쩍임·빛줄기 1.6초(6.2~7.8) → 로고·빛 쓸기 1.0초(7.8~8.8) → 밤·부제·시작 줄 3.2초(8.8~12.0, 끝 정지 1.5초 포함). 늘어난 2초는 낮 달리기와 끝 정지에 준다. 대화창 글자 속도(0.12초/자)는 바꾸지 않는다.
- 320x180 내부 화면 + 6배 확대. 모든 위치를 정수 칸으로 둔다.
- 네 층 시차 흐름. 속도 비 1 : 0.6 : 0.25 : 0.1.
- 하루가 지나는 팔레트 전환으로 시간을 넘긴다.
- 대화창 한 글자씩 → 확대 → 번쩍임 → 빛줄기 → 로고. 이 영상의 정점 순서다.
- 브라운관 켜짐으로 시작하고 시작 줄 깜박임으로 끝낸다.

## 7. 함정

- 화면의 로고 단어, 부제 네 글자, 대화창 문장, 이름 꼬리표 문구는 원작의 것이다. 옮기지 않는다. 역할(가상 게임 이름 두 줄, 짧은 부제, 환영 한 줄, 물건 이름 꼬리표, 시작 안내 한 줄)만 가져온다.
- 코드로 만들 때 밀도가 줄어드는 지점과 막는 법.
  - 픽셀이 흐려진다 · 320x180 canvas 에 그리고 CSS `width:1920px; height:1080px; image-rendering: pixelated` 로 키운다. 그림의 좌표는 모두 `Math.round` 한다. canvas 2D 의 `imageSmoothingEnabled = false` 를 켠다.
  - 층이 하나다 · 하늘·먼 산·숲·땅 네 층을 따로 그리고 각 층의 x 를 `floor(t × 속도)` 로 정한다. 속도는 땅 30, 숲 17, 산 7.5, 구름 4 칸/초다.
  - 매끈한 움직임이 된다 · 스프라이트 그림 번호를 `floor(t × 12) % 장수` 로 정한다. 달리기 6장, 숨쉬기 2장. 위치도 칸 단위로만 바뀐다.
  - 화면이 비어 있다 · 낮 장면에 나무 30그루 이상, 구름 6개, 동전 3~6개, 괴물, 상자를 둔다. 빈 하늘에 디더 띠를 깐다.
  - 주인공이 너무 크다 · 원작 주인공은 화면 높이의 10.5% 다. 캐릭터를 크게 키우면 게임 화면이 아니라 캐릭터 소개가 된다. 확대 장면(2배)에서만 21% 로 키운다.
  - 브라운관 효과가 픽셀을 덮는다 · 주사선은 2줄마다 검정 12~18% 로만 넣는다. 배럴 왜곡은 모서리를 검게 먹이는 둥근 비네트(반지름 화면 높이의 6%)로만 대신한다. 빛 번짐은 밝은 곳에만 반경 6px 로 준다.
- 한국어로 옮길 때 · 저장소에 픽셀 글꼴이 없다. 아래 8번 표의 방법을 쓴다. 로고를 한국어로 하려면 4~6자로 짧게 하고 칸 글꼴을 직접 그린다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 내부 그림은 320x180 canvas 하나다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 픽셀 글꼴(라틴·숫자) | 저장소에 픽셀 글꼴이 없다 | 5x7 칸 비트맵 글꼴을 코드 배열로 직접 만든다(대문자 26 + 숫자 10). 내부 canvas 에 1칸 = 1비트로 찍는다. 화면 정보는 글자 높이 7칸(42px) | 없음(손이 많이 든다) |
| 픽셀 글꼴(한국어) | 한글 비트맵 글꼴이 없다 | 내부 canvas 에 Pretendard SemiBold 를 12px 로 찍고, 알파 0.5 를 기준으로 0/1 로 자른다(`getImageData` 로 문턱값). 6배 확대하면 72px 픽셀 글자가 된다. 대화창 한 줄 10자 안 | 손으로 다듬은 글자의 고른 획 |
| 큰 픽셀 로고 | 로고용 굵은 픽셀 글꼴이 없다 | 글자마다 9x13 칸 비트맵을 배열로 그린다. 채움 3단(#FFE14A / #FF9A2E / #E8352E 근처) + 단 경계 2칸 체크무늬 디더. 테 2칸 #1B1A3A, 아래 두께 3칸 #8E1F2B | 없음 |
| 스프라이트(주인공·괴물·상자·동전) | 그림을 그릴 도구가 없다 | 16x19 칸 주인공을 색 번호 배열로 코드에 쓴다. 달리기 6장은 다리·팔 칸만 바꾼다. AI 이미지는 칸이 어긋나서 쓰지 않는다 | 전문 픽셀 작가의 형태감 |
| 디더 하늘 | 없다. 그대로 된다 | 띠 4단, 띠 경계마다 2x2 바이어 행렬로 2칸 높이 체크무늬 | 없음 |
| 빛줄기 8개 | 없다 | 내부 canvas 에 삼각형 8개, 상자에서 시작, 각도 간격 22°, 노랑 #FFF3A0 을 4x4 바이어 디더로 투명도 표현. 각도를 `floor(t × 10)` 마다 1° 돌린다 | 없음 |
| 브라운관 배럴 왜곡 | canvas 를 휘게 하려면 셰이더가 필요하다 | 모서리 둥근 검정 비네트로 대신한다. 또는 three.js(vendor/three) 평면 하나에 320x180 canvas 를 텍스처로 붙이고 정점을 바깥으로 3% 부풀린다. 텍스처 필터는 `NearestFilter` | 가장자리의 휘어짐 |
| 주사선·빛 번짐 | 없다 | 1920x1080 위에 3px 마다 1px 검정 18% 줄 div. 빛 번짐은 같은 canvas 를 `filter: blur(6px)` 로 한 장 더 겹치고 `mix-blend-mode: screen`, 투명도 0.25 | 실제 형광체의 색 번짐 |
| 칩튠 소리 | 소리 생성은 ElevenLabs 만 쓴다 | ElevenLabs 음악에 "8비트, 펄스 리드, 삼각파 베이스, 노이즈 드럼"을 요청한다. 효과음(점프·동전·상자)도 같은 도구로 만든다. 확인 지점 뒤에만 부른다 | 실제 음원 칩의 소리 |
