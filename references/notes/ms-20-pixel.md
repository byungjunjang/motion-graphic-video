# 8비트 픽셀 타이틀 · 320x180 칸 시차 스크롤과 브라운관 마감 — 분석 노트

> 브라운관이 켜지듯 선 하나에서 열린 화면에 8비트 옆 스크롤 게임 화면이 펼쳐지는 10초 영상. 화면은 320x180 칸을 6배로 키운 큰 픽셀이고, 하늘·먼 층·가운데 층·바닥 네 층이 서로 다른 속도로 한 칸씩 계단처럼 흐른다. 장면을 자르지 않고 하늘 팔레트를 바꿔 시간대를 넘기고, 한 글자씩 찍히는 대화창 → 2배 확대 → 2프레임 번쩍임 → 디더 빛줄기 → 위에서 떨어지는 픽셀 로고로 정점을 만든다. 게임·앱 출시, 복고 느낌 행사 소개에 맞는다. 픽셀 아트(pixel art) · 8비트 · 시차 스크롤 · 브라운관 효과.

출처 · ms:20-pixel. 쇼케이스 프롬프트에는 효과 이름, 기법 목록, 내부 해상도, 사건 목록이 있다. 화면 구도, 층별 위치·속도, 주인공 크기, 사건 시각, 대화창·로고 크기는 없다. 이 노트는 영상 프레임(0.5초 간격 시트 20장, 0.1초 간격 띠 72장, `ffmpeg -ss` 로 직접 뽑은 9장, 1.0~2.0초 30프레임의 층별 앞뒤 차이)을 보고 그 빈칸을 채웠다.
측정 · 파일 1920x1080 · 30fps · 10.0초. 장면 전환 검출 시각은 0.13, 0.17, 0.20, 6.40, 6.47초다. 앞의 셋은 화면이 켜지는 순간, 뒤의 둘은 흰 번쩍임이다. 0.5초마다 움직임 세기의 평균은 13.3 이다. 0.0초 구간(69.0, 화면 켜짐)을 빼면 10.3 이다. 0.5~3.0초는 9.5~10.9 로 고르다. 큰 값은 4.0초(27.9), 6.0초(24.9), 6.5초(23.0)다. 작은 값은 5.0초(1.3), 3.5초(1.7), 8.5~9.5초(1.0~2.0)다. 위치·크기는 원본 프레임과 960x540 으로 줄인 프레임에서 재어 1920 기준 px 로 적었다. 색 값은 프레임에서 잰 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. BPM 은 74.9 로 잡혔지만 타격이 약 0.2초 간격으로 촘촘하다(빠른 분산화음으로 추정). 마디 첫 박은 1.58, 4.79, 8.00초다. 가장 큰 타격(세기 1.00, 킥)은 7.19초이고 로고가 떨어져 자리 잡는 순간(7.2초)과 겹친다. 2.39초(0.80)는 점수 팝업이 뜨는 순간이다. 4.99~5.99초에 큰 타격이 0.2초 간격으로 6번 있고, 대화창 글자가 찍히는 구간과 겹친다. 4.62~4.80초에 짧은 무음이 있다. 타격과 화면 사건의 1:1 대응은 일부만 확인했다.

쓰는 법 · 이 노트는 스타일 문법(색·질감·크기 비율·움직임·전환·타이포·밀도)만 적는다. 원본의 소재·장면·순서는 적지 않았다. 숫자는 원본 영상을 보고 잰 근삿값이다.

## 1. 본질

- 픽셀 한 칸이 1920 기준 6px 다. 내부 해상도는 320x180 이다. 확대한 프레임에서 스프라이트 윤곽을 세어 확인했다. 모든 가장자리가 계단이다. 흐린 경계가 없다(번쩍임·빛 번짐 제외).
- 색은 장면마다 16~24색 정도다. 낮 하늘은 위 #2C4FB0 → 가운데 #3E99E2 → 아래 #67C7EF 근처로 3~4단 띠이고, 띠 사이를 체크무늬 디더링으로 잇는다. 가운데 층은 #348E4C 근처 진초록과 연초록 2단, 바닥의 벽돌 면은 #A3583A 근처다.
- 하늘 팔레트는 네 벌이다. 낮(위 표), 노을(위 #5488FF → 가운데 #FFFEA8 → 아래 #FF9D49 근처, 먼 층이 주황을 받는다), 보랏빛 저녁(위 #4B2A66 → 가운데 #F94370 근처), 밤(#2C3162 ~ #3D4785 근처, 별, 먼 층과 가운데 층이 어두워진다). 번쩍임은 크림색 #FFFDE0 근처다.
- 층은 다섯이다. 하늘(디더 띠 + 작은 덩어리 + 둥근 광원), 먼 층(봉우리 실루엣), 가운데 층(뾰족한 수직 무늬 줄 + 큰 세로 덩어리), 가까운 바닥(가장자리 줄 + 벽돌 면 + 물), 작은 요소와 주인공 요소. 앞에 화면 정보 층(점수, 수집 수)이 있다.
- 브라운관 마감이 있다. 가로 주사선이 픽셀 한 칸 안에 1~2줄 보인다. 화면 네 모서리가 둥글게 검게 먹힌다(배럴 왜곡과 비네트). 밝은 곳에 약한 빛 번짐이 있다. 픽셀이 뭉개지지는 않는다.
- 주인공 요소는 원색 세 가지로 칠한 작은 스프라이트 하나다. 크기는 약 16x19 칸(98x113px, 화면 높이의 10.5%)이다. 작은 상대 요소는 약 70x45px 다.
- 아닌 것 · 매끈한 확대, 부드러운 그라데이션, 반 픽셀 위치, 벡터 같은 매끈한 선, 큰 주인공 클로즈업 위주 화면, 3D.

## 3. 움직임

- 층별 흐름 속도(1.0~2.0초, 30프레임의 층별 앞뒤 차이로 셌다).

| 층 | 바뀌는 주기 | 1초 이동(추정) | 가까운 바닥 대비 |
|---|---|---|---|
| 하늘의 작은 덩어리 | 4프레임마다(번갈아 약하게) | 약 4칸 = 24px | 0.1 |
| 먼 층 | 4프레임마다 | 7.5칸 = 45px | 0.25 |
| 가운데 층 | 3~4프레임 중 2프레임 | 약 17칸 = 100px | 0.6 |
| 가까운 바닥 | 매 프레임 | 약 30칸 = 180px | 1 |

- 모든 층이 한 번에 한 칸(6px)씩만 옮겨진다. 반 칸 위치가 없다. 느린 층은 몇 프레임을 그대로 멈췄다가 한 칸 뛴다. 그래서 층마다 계단처럼 움직인다.
- 주인공 요소는 화면 가로 28~34% 에 머문다. 세계가 흘러서 달리는 것처럼 보인다. 흐름이 멈춘 뒤에는 주인공 요소가 직접 걸어간다(가로 30% → 45%).
- 스프라이트 갱신 · 화면 전체의 앞뒤 차이가 2~3프레임 주기로 오르내린다. 달리기 그림이 1초에 10~15장으로 바뀐다고 추정한다. 그림 장수는 세지 못했다.
- 뛰기 · 점프는 약 0.3초, 높이 약 25칸(150px)이다. 정점에서 2프레임 멈춘다.
- 점수 · 0.3초마다 +100 씩 오르고, 큰 사건에는 한 번에 +500 이 오른다. 수집 수는 1씩 오른다. 수집할 때마다 작은 반짝임이 있다.
- 카메라 · 한 번만 확대한다. 확대 배율 약 2배(픽셀 한 칸이 약 12px), 중심은 주인공 요소와 목표 요소 사이(가로 약 45%, 세로 약 80%)다. 확대 후에도 픽셀 경계가 계단으로 남는다(가장 가까운 이웃 확대). 확대 동안 목표 요소 둘레에 떨림 선이 생긴다.
- 팔레트 전환 · 낮 → 노을 → 저녁 → 밤. 전환은 색 단계를 몇 프레임에 걸쳐 바꾸는 방식이다. 섞어서 흐리게 바꾸지 않는다.
- 빛줄기 · 목표 요소(가로 약 53%, 세로 83%)에서 디더 빛줄기 8개가 부채꼴로 화면 위 끝까지 뻗고 천천히 돈다. 둘레에 파란 빛 덩어리가 숨 쉬듯 커졌다 작아진다.
- 화면 요소 수 · 낮 화면에 동시에 약 25개(하늘 덩어리 6, 둥근 광원, 봉우리 7, 가운데 층 수직 무늬 30개 이상, 큰 세로 덩어리, 작은 반짝 요소 3~6, 작은 상대 요소, 목표 요소, 주인공 요소, 화면 정보 2). 빈 하늘도 디더 띠와 작은 덩어리가 채운다.
- 움직임 세기 목표 · 흐르는 구간 10 안팎. 흐름이 멈추는 대화 구간은 2 아래로 떨어진다. 이 대비가 박자다. 확대·번쩍임·빛줄기에서 20 넘게 오른다. 끝 정지는 1~2 다.

## 4. 전환

- 브라운관 켜짐 · 점 → 가로선 → 띠가 벌어짐. 0.2초다. 첫 0.12초만 검정이다.
- 팔레트 전환 · 장면을 자르지 않고 하늘과 바닥의 색표를 바꿔 시간을 넘긴다. 세 번 일어난다.
- 확대와 번쩍임 · 2배 확대(0.4초) → 2프레임 크림색 번쩍임 → 넓은 화면으로 돌아오며 빛줄기. 번쩍임이 확대를 되돌리는 순간을 가린다.
- 로고 등장 · 위에서 떨어져 착지 → 0.4초 뒤 사선 빛 쓸기 → 띠 꼬리표 펼침. 0.4초 간격 세 박자다.
- 대화창 · 가는 가로 막대로 나타났다가 세로로 열린다(0.2초). 닫힐 때도 가는 막대로 접힌다.

## 5. 타이포

- 모든 글자가 픽셀 글꼴이다. 획 굵기는 1~2칸이다.
- 화면 정보 · 라벨과 여섯 자리 숫자, 작은 아이콘과 두 자리 수. 글자 높이 약 40px(3.7%). 흰 글자에 짙은 남색 1칸 그림자. 숫자는 노랑.
- 대화창 · 가로 22~77%, 세로 45~62%. 남색 판(#2E3570 근처) + 흰 1칸 테 + 바깥 짙은 테. 본문 글자 높이 약 36px(3.3%), 흰색. 약 0.12초에 한 글자씩 찍힌다. 왼쪽 위 이름 꼬리표 약 30px, 빨강 판 노랑 글자. 왼쪽에 작은 아이콘, 꼬리 끝이 목표 요소를 가리킨다.
- 로고 · 라틴 대문자 두 줄. 줄마다 글자 높이 약 170px(화면 높이의 16%), 로고 폭 약 840px(44%), 가로 28~72%, 세로 7~46%. 처음 2프레임은 흰색, 그다음 채움은 노랑(위) → 주황 → 빨강(아래) 3단 띠이고 띠 사이를 디더링으로 잇는다. 짙은 남색 테 2칸, 아래로 짙은 빨강 두께 3칸. 둘레의 반짝이가 착지 때 흩어진다.
- 사선 빛 쓸기 · 흰 사선 빛이 로고 위를 왼쪽 아래에서 오른쪽 위로 0.3초에 쓸고 지나간다.
- 부제 띠 · 빨강 띠(약 650x80px, 가로 33~67%, 세로 49~57%), 양 끝이 접힌 리본. 흰 픽셀 글자 네 자, 높이 약 50px, 0.1초 간격으로 찍힌다.

## 6. 가져올 것

- 핵심 장치 · 320x180 내부 화면을 6배 정수 확대하고, 네 층을 1 : 0.6 : 0.25 : 0.1 속도로 한 칸(6px)씩만 계단처럼 흘린다. 주인공 요소는 가로 28~34% 에 두고 세계가 흐른다.
- 핵심 장치 · 장면을 자르지 않고 하늘·바닥의 팔레트를 몇 프레임에 걸쳐 바꿔 시간대를 넘긴다(세 번). 섞지 않고 단계로 바꾼다.
- 핵심 장치 · 흐름을 멈춰 세기를 2 아래로 떨어뜨린 뒤 정점을 몰아 둔다. 한 글자씩(0.12초/자) 찍히는 대화창 → 2배 확대(0.4초) → 2프레임 번쩍임 → 넓은 화면의 디더 빛줄기 → 위에서 떨어지는 로고 → 0.4초 간격으로 사선 빛 쓸기와 띠 꼬리표.
- 핵심 장치 · 브라운관 켜짐(점 → 가로선 → 띠, 0.2초)으로 시작하고 1.0초 주기 시작 줄 깜박임으로 끝낸다.

## 7. 함정

- 코드로 만들 때 밀도가 줄어드는 지점과 막는 법.
  - 픽셀이 흐려진다 · 320x180 canvas 에 그리고 CSS `width:1920px; height:1080px; image-rendering: pixelated` 로 키운다. 그림의 좌표는 모두 `Math.round` 한다. canvas 2D 의 `imageSmoothingEnabled = false` 를 켠다.
  - 층이 하나다 · 하늘·먼 층·가운데 층·바닥 네 층을 따로 그리고 각 층의 x 를 `floor(t × 속도)` 로 정한다. 속도는 바닥 30, 가운데 층 17, 먼 층 7.5, 하늘 덩어리 4 칸/초다.
  - 매끈한 움직임이 된다 · 스프라이트 그림 번호를 `floor(t × 12) % 장수` 로 정한다. 달리기 6장, 숨쉬기 2장. 위치도 칸 단위로만 바뀐다.
  - 화면이 비어 있다 · 흐르는 화면에 가운데 층 수직 무늬 30개 이상, 하늘 덩어리 6개, 작은 요소 3~6개와 큰 요소 몇 개를 둔다. 빈 하늘에 디더 띠를 깐다.
  - 주인공이 너무 크다 · 원작 주인공 요소는 화면 높이의 10.5% 다. 크게 키우면 게임 화면이 아니라 캐릭터 소개가 된다. 확대 장면(2배)에서만 21% 로 키운다.
  - 브라운관 효과가 픽셀을 덮는다 · 주사선은 2줄마다 검정 12~18% 로만 넣는다. 배럴 왜곡은 모서리를 검게 먹이는 둥근 비네트(반지름 화면 높이의 6%)로만 대신한다. 빛 번짐은 밝은 곳에만 반경 6px 로 준다.
- 한국어로 옮길 때 · 저장소에 픽셀 글꼴이 없다. 아래 8번 표의 방법을 쓴다. 로고를 한국어로 하려면 4~6자로 짧게 하고 칸 글꼴을 직접 그린다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 내부 그림은 320x180 canvas 하나다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 픽셀 글꼴(라틴·숫자) | 저장소에 픽셀 글꼴이 없다 | 5x7 칸 비트맵 글꼴을 코드 배열로 직접 만든다(대문자 26 + 숫자 10). 내부 canvas 에 1칸 = 1비트로 찍는다. 화면 정보는 글자 높이 7칸(42px) | 없음(손이 많이 든다) |
| 픽셀 글꼴(한국어) | 한글 비트맵 글꼴이 없다 | 내부 canvas 에 Pretendard SemiBold 를 12px 로 찍고, 알파 0.5 를 기준으로 0/1 로 자른다(`getImageData` 로 문턱값). 6배 확대하면 72px 픽셀 글자가 된다. 대화창 한 줄 10자 안 | 손으로 다듬은 글자의 고른 획 |
| 큰 픽셀 로고 | 로고용 굵은 픽셀 글꼴이 없다 | 글자마다 9x13 칸 비트맵을 배열로 그린다. 채움 3단(#FFE14A / #FF9A2E / #E8352E 근처) + 단 경계 2칸 체크무늬 디더. 테 2칸 #1B1A3A, 아래 두께 3칸 #8E1F2B | 없음 |
| 스프라이트(주인공 요소·작은 요소) | 그림을 그릴 도구가 없다 | 16x19 칸 주인공 요소를 색 번호 배열로 코드에 쓴다. 달리기 6장은 다리·팔 칸만 바꾼다. AI 이미지는 칸이 어긋나서 쓰지 않는다 | 전문 픽셀 작가의 형태감 |
| 디더 하늘 | 없다. 그대로 된다 | 띠 4단, 띠 경계마다 2x2 바이어 행렬로 2칸 높이 체크무늬 | 없음 |
| 빛줄기 8개 | 없다 | 내부 canvas 에 삼각형 8개, 목표 요소에서 시작, 각도 간격 22°, 노랑 #FFF3A0 을 4x4 바이어 디더로 투명도 표현. 각도를 `floor(t × 10)` 마다 1° 돌린다 | 없음 |
| 브라운관 배럴 왜곡 | canvas 를 휘게 하려면 셰이더가 필요하다 | 모서리 둥근 검정 비네트로 대신한다. 또는 three.js(vendor/three) 평면 하나에 320x180 canvas 를 텍스처로 붙이고 정점을 바깥으로 3% 부풀린다. 텍스처 필터는 `NearestFilter` | 가장자리의 휘어짐 |
| 주사선·빛 번짐 | 없다 | 1920x1080 위에 3px 마다 1px 검정 18% 줄 div. 빛 번짐은 같은 canvas 를 `filter: blur(6px)` 로 한 장 더 겹치고 `mix-blend-mode: screen`, 투명도 0.25 | 실제 형광체의 색 번짐 |
| 칩튠 소리 | 소리 생성은 ElevenLabs 만 쓴다 | ElevenLabs 음악에 8비트 · 펄스 리드 · 삼각파 베이스 · 노이즈 드럼을 요청한다. 효과음(점프·수집·열림)도 같은 도구로 만든다. 확인 지점 뒤에만 부른다 | 실제 음원 칩의 소리 |
