## 3. 움직임

- 모든 장면이 움직이는 중에 들어온다. 첫 몇 프레임에 남은 거리의 12~19%씩 가는 감속(지수 감속)이라 처음 0.1~0.2초에 거의 다 오고 나머지는 천천히 붙는다. 머리글은 첫 0.2초에 화면 높이의 약 36%를 움직인다.
- 나갈 때는 거꾸로 빨라진다. 입력 장면은 위로 휘두르며(마지막 프레임 프레임당 약 25px), 카드 장면은 위로 빨라지며, 끝 카드는 줄어들며 끝난다.
- 흐림이 속도를 따른다. 위아래로 움직이면 세로로만 흐려지고(입력 장면 끝 6~8px, 로고 원반 들어올 때), 크기가 바뀌면 둥글게 흐려진다. 정지하면 선명해진다.
- 커서가 살아 있다. 진행 방향으로 몸을 돌리고, 대상 위에서 커지고(1.55배), 누를 때 15% 줄어든다. 같은 커서 하나를 세 장면에 쓴다.
- 카메라가 확대 → 잠시 멈춤 → 빠지면서 컷 하는 모양이 첫 장면 끝(2.0~2.4초)에 한 번 있다.
- 멈춤은 8.97~9.58초(0.6초) 한 번뿐이다. 다른 모든 프레임에서 무언가가 1px 이상 움직인다.

- 10.03초 · 흰 화면에서 검은 화면으로. 단어가 가로로 끌린 상태로 들어온다(줌 끌림).
- 컷 시각은 마디 첫 박보다 약 2프레임 앞이다(원래 글이 그렇게 정했다). 측정된 마디 첫 박(1.56, 3.50, 5.43 …)과는 0.1~0.15초씩 어긋나 있다. 측정 박자가 원래 글의 박 격자와 약 0.1초 어긋나게 잡혔을 수 있다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 4.95초. 위 40%는 흰 페이지, 가운데에 검은 테두리 띠와 남색 메뉴 막대(오른쪽에 표식 1 + 색 점 3 + 날짜), 아래 하늘 그라데이션 위에 유리 입력 상자(724x226px, 폭 67%, 가로 18~85%, 세로 53~74%)와 그 안의 한 줄 입력 문장(44px), 아이콘 3, 파란 보내기 단추(지름 51px). 동시에 보이는 요소는 약 12개. 유리 상자와 그 뒤의 파란 하늘이 빠지면 이 영상이 아니다.
- 12초 판 압축 예 · 이미 12초다. 그대로 쓰되 16:9 로 옮긴다. 줄인다면 카드 하나 장면(6.24~7.17초)을 빼고 그 0.9초를 입력 장면(타이핑)과 끝 카드에 나눠 준다.
- 장면 진입은 지수 감속, 퇴장은 가속 + 방향 흐림. 정지 화면에서 컷하지 않는다.
- 커서 하나로 장면을 잇는다(누르는 순간이 컷).
- 제품 표식이 크기와 역할을 바꿔 다섯 번 나온다.
- 흰 바탕 위 유리는 반드시 파란 그라데이션을 깐 영역 안에만 둔다.
- 끝 카드는 단어가 계속 천천히 줄어드는 동안 끝난다(정지한 끝 카드보다 짧고 힘 있다).

## 7. 함정

- 제품 이름, 플랫폼 이름, 입력 문장, 페이지 제목·본문, 카드 이름은 원작의 영문 글자다. 옮기지 않는다. 운영체제 메뉴 막대와 커서도 실존 제품의 화면 모양이라 그대로 흉내 내지 않는다. 메뉴 막대는 아이콘 수를 줄이고 일반 도형으로 다시 그린다.
- 정사각(1080x1080)이다. 16:9(1920x1080)로 옮길 때는 높이를 그대로 두고 장면별로 다음처럼 바꾼다.
  - 첫 장면 · 앱 창의 왼쪽 위 모서리를 (408, 405) → (760, 405)로 옮기고 오른쪽·아래는 계속 화면 밖으로. 머리글 묶음은 가로 40~92%(x770~1770).
  - 아이콘 장면 · 가운데 (960, 540) 유지, 크기 그대로(아이콘 176px, 궤도 반지름 213px). 좌우 빈 곳은 흰 바탕 그대로 둔다.
  - 메뉴 막대 장면 · 막대와 테두리 띠를 폭 1920 전체로 늘린다. 유리 상자는 724x226 → 900x226, 가로 27~73%(x510~1410). 표식 위치는 x960.
  - 답 페이지 · 본문 열을 x120 → x420, 열 폭 1080px 로. 글자 크기 47px 유지.
  - 유리 제목 카드 둘 · 위아래 쌓기 대신 나란히 놓는다. 카드 538x348 두 장, 사이 64px, x382~920 과 x984~1522, 세로 366~714. 유리 글자 크기 그대로.
  - 로고 원반·끝 카드 · 가운데 (960, 540) 그대로, 크기 그대로.
- 흐림 값이 크면 도형이 사라진다. 원래 글의 흐림 최고값(24px)은 1080 화면 기준이다. 1920 화면에서도 높이가 같으므로 그대로 쓴다.
- 흰 사각은 흰 바탕에서 보이지 않는다. 1px 회색 테두리 + 옅은 그림자를 꼭 준다.
- 유리 글자 뒤 그림에 글자가 들어 있으면 글자가 두 겹으로 보인다. 카드 표지는 글자 없는 그림으로 만든다.
- 한국어로 바꾸면 입력 문장이 짧아지고 유리 글자는 두 글자 낱말이 된다. 한국어 140px 상한 때문에 유리 글자는 140px 로 줄이고 카드 아래 가장자리에서 위 75%만 보이게 한다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

글꼴은 Pretendard Regular·SemiBold 와 숫자·라틴용 InterVariable 이다. 값은 원본 1080 정사각 기준이다(16:9 는 `## 7` 의 위치를 쓴다).

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 유리 입력 상자 | 뒤 장면을 흐리고 굴절시키는 재질 | DOM 상자에 `backdrop-filter: blur(18px) saturate(1.3)`, 배경 `rgba(235,242,255,.18)`, 테두리 1.5px `rgba(255,255,255,.55)`, 위쪽 안쪽 밝은 띠 `inset 0 2px 0 rgba(255,255,255,.5)`, 그림자 `0 18px 40px rgba(20,40,90,.25)`, 모서리 60px. 프레임 촬영에서 `backdrop-filter` 가 잡히는지 `render.mjs --snap` 으로 먼저 확인한다 | 가장자리의 굴절 휨 |
| 거대한 유리 글자 | 뒤 그림을 흐리고 밝게 한 것을 글자로 오린다 | 카드 표지 그림을 복제해 `filter: blur(10px) brightness(1.35)` 를 주고 `background-clip: text` 대신 SVG `clipPath` 에 글자(Pretendard SemiBold 140px)를 넣어 오린다. 글자 아래 25%는 카드 `overflow: hidden` 으로 자른다 | 없음 |
| 방향 흐림 | CSS blur 는 둥글게만 흐린다 | SVG 필터 `feGaussianBlur stdDeviation="0 7"`(세로) 를 장면 묶음에 건다. 값은 속도에 비례(프레임당 25px 일 때 7px) | 없음 |
| 끝 카드 줌 끌림 | 단어가 가로로 늘어난 잔상 | 단어 사본 24장을 scale 1.0~1.6, 불투명도 0.04 로 겹친다. 빛은 같은 단어를 `filter: blur(6px)` 0.8 + `blur(40px)` 0.35 로 뒤에 두 겹. 바탕은 `radial-gradient(#282828 0, #020104 70%)` | 없음 |
| 커서 | 실존 운영체제 커서 모양 | SVG 화살표(검은 채움, 흰 외곽선 2px, 그림자)를 일반 모양으로 다시 그린다. 32x39px, 회전·크기만 t 로 계산 | 없음 |
| 사각 넷의 궤도 | 없다 | DOM 사각 92px(모서리 26px) 넷. 각도 = 기준각 + 270°·(1 − 감속(t)), 반지름 = 216 + 120·(1 − 감속(t)), 감속은 0.47초 지수 감속 | 없음 |
| 하늘 벽지 선 그림 | 없다 | SVG 큰 원(지름 약 900px) 1, 가로선 2, 세로선 1, 네 갈래 반짝임 1, 선 굵기 1.5px 흰색 불투명도 0.5. 바탕은 `linear-gradient(#2b497f, #446ba2)` + 오른쪽 위 청록 빛 `radial-gradient(#5aa8a0 0, transparent 300px)` | 없음 |
| 카드 표지 그림 | 원작은 카드마다 다른 추상 그림 | AI 일러스트(codex-image)로 파란 추상 무늬를 글자 없이 그리거나, SVG 원·선 그림 + 그라데이션으로 대신한다 | 그림마다의 개성 |
| 화면 질감 | 원작은 아주 깨끗하다 | 질감을 넣지 않는다. 끝 카드에만 `grainLayer(stage, 3)` 를 불투명도 0.04 로 | 없음 |
