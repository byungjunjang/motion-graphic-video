# 흰 바탕 파란 유리 제품 화면 · 지수 감속으로 들어와 방향 흐림으로 나가는 정사각 박자 컷 — 분석 노트

> 거의 흰 바탕 위에 짙은 남색·하늘빛·파랑만 쓰는 정사각 제품 화면 스타일. 모든 장면이 이미 움직이는 상태로 들어와 첫 0.1~0.2초에 거의 다 오고, 나갈 때는 빨라지며 움직임 방향으로 흐려진다. 커서 하나가 장면을 잇고 누르는 순간이 컷이 된다. 유리 패널은 늘 파란 그라데이션 위에만 놓인다. 주인공 표식이 크기와 역할을 바꿔 여러 번 돌아온다. 앱·도구·인공지능 기능 소개, 짧은 출시 알림에 맞는다. 제품 화면형 · 유리 질감 · 박자 컷.

출처 · pm:notdwd-7de38a. 원래 글은 약 1만 자의 긴 명세다(형식은 pm: 항목이지만 내용은 장면표 수준이다). 색 값 10여 개, 글꼴, 장면 8개의 프레임 번호·좌표·크기·흐림 값, 소리 시각까지 정했다. 비어 있는 것은 실제 화면의 점유율, 장면마다 보이는 요소 수, 다른 비율로 옮기는 구도, 측정된 소리 배치다. 이 노트는 영상 프레임(0.5초 시트 25장 + 0.25초 간격 직접 뽑은 프레임 45장 + 컷 앞뒤 0.04초 간격 프레임 + 원본 해상도 프레임 12장)을 보고 썼다. 화면은 원래 글의 값과 거의 그대로 맞는다.
측정 · 파일 1080x1080(정사각) · 59.94fps · 12.07초. 장면 감지가 잡은 컷은 3.35·5.29·8.16·10.03초 4번이다. 첫 하드 컷(2.40초)은 흰 바탕 → 흰 바탕이라 감지가 놓쳤다. 0.04초 간격 프레임에서 2.36초와 2.40초가 바로 붙어 있어 하드 컷이 맞다. 6.9~7.25초는 흐림 녹임이라 감지되지 않는다. 움직임 세기 평균 약 16, 큰 구간은 전체의 78.7%(92.7, 흰 화면 → 검은 끝 카드), 41.4%(46.9, 위로 휘두르는 기울기), 24.9%(45.7, 큰 표식이 작은 자리로 접힘), 49.7~58.0%(18~23)다. 70.4% 지점은 0.1로 사실상 정지(원래 글이 허락한 유일한 멈춤). 원본 프레임에서 잰 크기는 `## 3` 에 옮겼다. 색은 원본 프레임 화소를 직접 읽은 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. 분당 약 124박(측정 123.0, 마디 첫 박 1.56·3.50·5.43·7.37·9.30·11.24초, 마디 1.935초). 가장 센 타격은 0.13초(1.00, 킥) = 첫 장면의 부드러운 충격. 0.5~2.25초는 -20~-26dB 로 조용하고 2.5초에 -12dB 로 뛴다 = 음악이 터지는 지점(첫 하드 컷 바로 뒤). 무음은 1.40~1.56, 2.78~3.00, 4.72~4.94초. 킥은 4.45초부터 4.93·6.38·6.87·7.84·8.80·9.29·9.78·10.74초로 이어진다. 4.93초(0.84)는 글자 입력이 끝난 직후, 10.74초(0.76, 킥)는 끝 카드 단어가 줄어드는 도중이다.

## 3. 움직임

- 모든 장면이 움직이는 중에 들어온다. 첫 몇 프레임에 남은 거리의 12~19%씩 가는 감속(지수 감속)이라 처음 0.1~0.2초에 거의 다 오고 나머지는 천천히 붙는다. 첫 진입은 0.2초에 화면 높이의 약 36%를 움직인다.
- 나갈 때는 거꾸로 빨라진다. 위로 휘두르며(마지막 프레임 프레임당 약 25px), 위로 빨라지며, 또는 줄어들며 끝난다.
- 흐림이 속도를 따른다. 위아래로 움직이면 세로로만 흐려지고(끝 6~8px), 크기가 바뀌면 둥글게 흐려진다. 정지하면 선명해진다.
- 커서가 살아 있다. 진행 방향으로 몸을 돌리고, 오른쪽 위에서 들어와 감속하며 방향을 틀어 내려앉는다. 대상 위에서 커지고(1.55배), 누를 때 15% 줄어든다. 누르기 0.4초 전부터 대상 둘레에 옅은 빛 고리가 생긴다.
- 카메라가 확대(1.2배) → 잠시 멈춤 → 빠지면서 컷 하는 모양이 한 번 있다(0.4초).
- 궤도 · 가운데 아이콘 176px(화면의 16%), 회색 후광 원 지름 322px, 궤도 반지름 213px, 사각 92px 넷(흰·파랑·하늘·민트). 0.47초 감속으로 돌아 십자(위·오른쪽·아래·왼쪽)로 선 뒤 0.4초 동안 아이콘이 약 40px 로 줄고 사각들이 한 줄로 붙으며 흐려진다.
- 유리 패널 · 표식 아래에서 튀어나와 0.73초 만에 724x226px(폭 67%, 가로 18~85%, 세로 53~74%)로 선다. 그 안의 한 줄 글자가 0.95초 동안 한 글자씩 쳐진다. 보내기 단추 지름 51px, 아이콘 3.
- 카드 · 한 장 폭 약 675px 가 0.45초 만에 흐림에서 선명해진다. 두 장은 537x346px(위 y166~512, 아래 y547~891), 가로 50% 가운데, 위 카드가 먼저, 아래 카드가 조금 늦게 선다.
- 원반 · 지름 약 165px(15%) 연회색 안 짙은 표식 78px. 0.4초 만에 지름 약 120px 로 줄며 나간다.
- 끝 카드 단어 · 폭 약 1650px 로 들어와 0.1초 만에 1100px, 0.57초 뒤 572px, 1.47초 뒤 약 500px 로 계속 줄고 마지막 0.15초에 빨라지며 304px 까지 접힌다.

## 4. 전환

- 하드 컷 4번과 흐림 컷 2번(흐림 녹임 1, 흐림 최고점에서 컷 1)이다. 모두 움직임 도중에 끊긴다.
- 누르는 순간 컷 · 커서가 표식을 누르는 동작이 다음 장면의 같은 표식(더 크게)으로 바로 이어진다.
- 접힘 컷 · 줄어든 표식이 다음 장면의 작은 표식 자리로 간다. 앞 장면 끝의 사각 넷 한 줄이 다음 장면의 점 셋(파랑·하늘·민트)과 같은 색이다.
- 휘두르기 컷 · 위로 휘두르는 기울기 → 옅은 하늘빛 번쩍임(#e2f4fe 근처) → 아래에서 흐린 채 올라오는 다음 장면. 움직임 방향이 컷 앞뒤로 같다(위로).
- 흐림 컷 · 흐려지며 위로 나가고 흐린 채 아래에서 들어온다.
- 마지막 컷 · 흰 화면에서 검은 화면으로. 단어가 가로로 끌린 상태로 들어온다(줌 끌림).
- 컷 시각은 마디 첫 박보다 약 2프레임 앞이다(원래 글이 그렇게 정했다). 측정된 마디 첫 박과는 0.1~0.15초씩 어긋나 있다. 측정 박자가 원래 글의 박 격자와 약 0.1초 어긋나게 잡혔을 수 있다.

## 5. 타이포

- 글꼴은 고딕 한 계열(굵기 400~700)이다.
- 유리 패널 안 문장 · 약 44px(화면 높이 4.1%), 흰색, 왼쪽 정렬, 캐럿 항상 켜짐. 막대의 작은 정보 글자 · 약 34px(3.1%) 흰색.
- 본문 화면 · 약 47px(4.4%), 회색(#bcbcba 근처), 줄 간격 58px. 핵심 구절만 검정 굵게. 제목 줄은 조금 더 진한 회색.
- 카드 제목 상자 · 굵은 검정 약 28px(2.6%). 알약 표지 · 약 22px 흰색.
- 유리 글자 · 아주 굵은 고딕, 글자 크기 약 155px(대문자 높이 약 110px, 눈대중), 카드 아래 가장자리에 잘려 위 70%만 보인다. 뒤 그림을 흐리고 밝게 만든 것을 글자 모양으로 오린 색(#c8d6ea 근처)이다.
- 끝 카드 단어 · 굵기 600, 흰색(#f6f5f8), 단어 높이 약 76px(7%), 좁은 빛 + 넓은 부드러운 후광.

## 6. 가져올 것

- 핵심 장치 · 장면 진입은 지수 감속(첫 0.1~0.2초에 거리의 대부분), 퇴장은 가속 + 움직임 방향의 흐림(세로 6~8px). 정지 화면에서 컷하지 않는다.
- 핵심 장치 · 커서 하나가 대상을 누르는 순간(커서 1.55배 → 15% 줄어듦)이 컷이 되고, 다음 장면은 누른 표식을 더 크게 이어받는다.
- 핵심 장치 · 주인공 표식이 원반·아이콘·작은 표식·단어로 크기와 역할을 바꿔 다섯 번 돌아온다.
- 핵심 장치 · 유리 패널은 반드시 파란 그라데이션을 깐 영역 안에만 두고, 흰 여백 장면과 번갈아 쓴다.
- 끝 카드는 단어가 계속 천천히 줄어드는 동안 끝난다(정지한 끝 카드보다 짧고 힘 있다).

## 7. 함정

- 원본 화면의 실존 로고·이름은 쓰지 않는다. 운영체제 막대와 커서는 실존 제품의 화면 모양이라 그대로 흉내 내지 않는다. 막대는 아이콘 수를 줄이고 일반 도형으로 다시 그린다.
- 정사각(1080x1080)이다. 16:9(1920x1080)로 옮길 때는 높이를 그대로 두고 다음처럼 바꾼다.
  - 화면 밖으로 이어지는 큰 창 · 왼쪽 위 모서리를 (408, 405) → (760, 405)로 옮기고 오른쪽·아래는 계속 화면 밖으로. 머리글 묶음은 가로 40~92%(x770~1770).
  - 가운데 요소(아이콘·궤도·원반·끝 단어) · 가운데 (960, 540) 유지, 크기 그대로. 좌우 빈 곳은 흰 바탕 그대로 둔다.
  - 가로 띠와 막대 · 폭 1920 전체로 늘린다. 유리 패널은 724x226 → 900x226, 가로 27~73%(x510~1410). 표식 위치는 x960.
  - 본문 열 · x120 → x420, 열 폭 1080px 로. 글자 크기 47px 유지.
  - 카드 두 장 · 위아래 쌓기 대신 나란히 놓는다. 카드 538x348 두 장, 사이 64px, x382~920 과 x984~1522, 세로 366~714. 유리 글자 크기 그대로.
- 흐림 값이 크면 도형이 사라진다. 원래 글의 흐림 최고값(24px)은 1080 화면 기준이다. 1920 화면에서도 높이가 같으므로 그대로 쓴다.
- 흰 사각은 흰 바탕에서 보이지 않는다. 1px 회색 테두리 + 옅은 그림자를 꼭 준다.
- 유리 글자 뒤 그림에 글자가 들어 있으면 글자가 두 겹으로 보인다. 카드 표지는 글자 없는 그림으로 만든다.
- 한국어로 바꾸면 패널 문장이 짧아지고 유리 글자는 두 글자 낱말이 된다. 한국어 140px 상한 때문에 유리 글자는 140px 로 줄이고 카드 아래 가장자리에서 위 75%만 보이게 한다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

글꼴은 Pretendard Regular·SemiBold 와 숫자·라틴용 InterVariable 이다. 값은 원본 1080 정사각 기준이다(16:9 는 `## 7` 의 위치를 쓴다).

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 유리 패널 | 뒤 장면을 흐리고 굴절시키는 재질 | DOM 상자에 `backdrop-filter: blur(18px) saturate(1.3)`, 배경 `rgba(235,242,255,.18)`, 테두리 1.5px `rgba(255,255,255,.55)`, 위쪽 안쪽 밝은 띠 `inset 0 2px 0 rgba(255,255,255,.5)`, 그림자 `0 18px 40px rgba(20,40,90,.25)`, 모서리 60px. 프레임 촬영에서 `backdrop-filter` 가 잡히는지 `render.mjs --snap` 으로 먼저 확인한다 | 가장자리의 굴절 휨 |
| 거대한 유리 글자 | 뒤 그림을 흐리고 밝게 한 것을 글자로 오린다 | 카드 표지 그림을 복제해 `filter: blur(10px) brightness(1.35)` 를 주고 `background-clip: text` 대신 SVG `clipPath` 에 글자(Pretendard SemiBold 140px)를 넣어 오린다. 글자 아래 25%는 카드 `overflow: hidden` 으로 자른다 | 없음 |
| 방향 흐림 | CSS blur 는 둥글게만 흐린다 | SVG 필터 `feGaussianBlur stdDeviation="0 7"`(세로) 를 장면 묶음에 건다. 값은 속도에 비례(프레임당 25px 일 때 7px) | 없음 |
| 끝 카드 줌 끌림 | 단어가 가로로 늘어난 잔상 | 단어 사본 24장을 scale 1.0~1.6, 불투명도 0.04 로 겹친다. 빛은 같은 단어를 `filter: blur(6px)` 0.8 + `blur(40px)` 0.35 로 뒤에 두 겹. 바탕은 `radial-gradient(#282828 0, #020104 70%)` | 없음 |
| 커서 | 실존 운영체제 커서 모양 | SVG 화살표(검은 채움, 흰 외곽선 2px, 그림자)를 일반 모양으로 다시 그린다. 32x39px, 회전·크기만 t 로 계산 | 없음 |
| 작은 요소 넷의 궤도 | 없다 | DOM 사각 92px(모서리 26px) 넷. 각도 = 기준각 + 270°·(1 − 감속(t)), 반지름 = 216 + 120·(1 − 감속(t)), 감속은 0.47초 지수 감속 | 없음 |
| 하늘 벽지 선 그림 | 없다 | SVG 큰 원(지름 약 900px) 1, 가로선 2, 세로선 1, 네 갈래 반짝임 1, 선 굵기 1.5px 흰색 불투명도 0.5. 바탕은 `linear-gradient(#2b497f, #446ba2)` + 오른쪽 위 청록 빛 `radial-gradient(#5aa8a0 0, transparent 300px)` | 없음 |
| 카드 표지 그림 | 원작은 카드마다 다른 추상 그림 | AI 일러스트(codex-image)로 파란 추상 무늬를 글자 없이 그리거나, SVG 원·선 그림 + 그라데이션으로 대신한다 | 그림마다의 개성 |
