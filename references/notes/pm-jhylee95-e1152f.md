## 3. 움직임

- 낱말은 매 컷 가로 움직임 번짐 속에서 선다. 0.95초 프레임에서 낱말이 좌우로 약 250px 번져 있다. 0.1초 안에 멈추고 그 뒤로는 거의 움직이지 않는다.
- 한 낱말 안의 시간 배분은 늘 같다. 0~0.1초 진입(번짐), 0.1~0.5초 정지, 0.5초(킥) 시연 동작 하나, 0.5~1.0초 정지. 0.5초 간격 움직임 값이 높음·낮음을 번갈아 오가는 것이 이 배분 때문이다.
- 시연 동작은 UI 하나의 상태 바뀜이다. 말풍선이 튀어나옴(0.15초 안팎, 조금 넘쳤다가 자리 잡음), 선택 상자가 그려짐, 파형이 짙어짐, 낱말의 언어가 바뀜, 버튼 글이 바뀜, 숫자가 오름.
- 커서가 자주 나온다(0초, 7.5초, 10.97초, 17.5초). 실제 마우스처럼 곡선을 그리며 가고, 누를 때 둘레에 원이 퍼진다.
- 신기능 이름(14초)만 방사선이 붙는다. 다른 낱말은 장식이 없다.
- 채팅 시연(15~21초)은 이 영상에서 유일하게 6초 동안 컷이 없다. 카메라가 대화 칸 → 제품 화면 → 전체로 천천히 옮겨 간다(움직임 값 0.7~57).
- 끝에 정지가 없다. 마지막 낱말 화면이 0.88초 만에 끝난다.

## 4. 전환

- 기본은 하드 컷이다. 낱말이 바뀔 때 바탕색도 같이 바뀐다(흰 → 검정 → 파랑 → 흰 …). 같은 바탕색이 두 번 이어지지 않는다.
- 하드 컷 위에 가로 움직임 번짐을 얹는다. 앞 낱말이 한쪽으로 빠지고 새 낱말이 같은 방향에서 들어오는 것처럼 보인다.
- 원형 닦기는 한 번뿐이다(3.83초, 낱말 4 → 낱말 5).
- 같은 낱말 안의 색 바뀜(6.5초 주황, 6.73초 연두)은 컷처럼 보이지만 기능 시연이다.
- 13.0초 검정 화면의 타이핑과 무음이 "숨 고르기"다. 이 1초 뒤 14.0초에 가장 큰 사건(방사선 + 화면보다 큰 이름)이 온다.
- 마지막 세 낱말은 앞의 기능 낱말과 같은 틀로 돌아간다. 처음과 끝이 같은 문법이다.

## 5. 타이포

- 글꼴은 하나다. 둥근 기하형 산세리프의 가장 굵은 굵기, 소문자만, 자간을 좁게 붙였다. 색 테마 시연(6~7초)에서만 좁고 굵은 다른 글꼴이 나온다.
- 낱말 크기 · 높이 178~253px(올림 획에서 내림 획까지, 화면 높이의 16~23%). 짧은 낱말은 화면 너비의 35%, 긴 낱말은 70~75% 다. 글자 크기는 거의 같고 폭은 낱말 길이를 따른다.
- 마침표 · 지름 약 48px, 글자 높이의 약 27%. 바탕에 따라 색이 바뀌는 유일한 강조다.
- 위쪽 문구(10~13초) · 같은 글꼴, 높이 약 70px(6.5%), 화면 위쪽 가운데. 아래에 제품 화면이 온다.
- 꼬리표 · 왼쪽 위, 고정폭 같은 작은 대문자, 높이 14px(1.3%), 자간이 넓고 회색. 컷마다 내용이 바뀐다.
- UI 조각 안의 글자 · 산세리프 보통 굵기, 높이 16~24px. 읽히지만 주인공이 아니다.
- 한 화면의 글자 덩어리는 늘 1~2개다(낱말 1 + UI 조각 1).

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 0.0~1.0초. 흰 회색 바탕 가운데 위쪽(세로 30~46%)에 굵은 소문자 낱말 하나(675x178px, 높이 16.5%)와 파랑 마침표(48px), 0.5초 킥에 커서가 마침표를 누르면 바로 아래에 파랑 말풍선 안내(약 420x180px)가 튀어나온다. 요소 4개(낱말, 마침표, 커서, 말풍선) + 고정 배지·꼬리표. 마침표가 곧 눌리는 단추가 되는 것, 낱말 1개 = 기능 1개 = 1초가 빠지면 이 영상이 아니다.
- 12초 판 압축 예 · 0~6초 기능 낱말 6개(각 1초, 바탕 흰·검정·파랑을 돌려 가며, 색 테마 시연 하나 포함), 6~7.5초 제품 화면 한 컷, 7.5~8.0초 검정 숨 고르기(무음 0.5초), 8.0~9.0초 신기능 또는 대상 이름의 방사선 등장, 9.0~12.0초 장점 낱말 3개(각 1초). 6초 채팅 시연은 빼거나 제품 화면 컷 하나에 합친다. 끝에 0.5초 정지를 더한다(원작에는 정지가 없다).
- 마침표를 강조 단추로 쓰는 법. 낱말마다 마침표 색이 바탕 대비색이고, 첫 컷에서는 그 점이 실제로 눌린다.
- 한 낱말 안의 0.5초 배분(정박에 낱말, 반 박 뒤 킥에 시연 동작). 컷이 많아도 매 컷에 정지 반 초가 있어 읽힌다.
- 기능을 화면 전체로 시연하기. 테마 기능은 바탕색 자체를 바꾸고, 번역 기능은 낱말 자체의 언어를 바꾼다.
- 큰 사건 앞의 무음 1초.

## 7. 함정

- 화면의 브랜드 배지, 낱말들, 위쪽 문구, 제품 화면 안의 가상 회사 이름·숫자, 링크 주소, 삽입 코드, 채팅 문장, 연동 서비스의 실존 로고(제품 화면 안 연동 목록에 여러 개)는 원작의 것이다. 옮기지 않는다. 실존 로고는 쓰지 않는다. 역할(기능 동사 낱말, 장점 낱말, 신기능 이름)만 가져온다.
- 한국어 낱말은 라틴 소문자처럼 위아래 들쭉날쭉한 모양이 없어서 덩어리감이 다르다. 두 글자 낱말(예: 동사 명사형)을 Pretendard SemiBold 140px 로 쓰면 원작의 178~253px 보다 작고 폭도 좁다. 화면 높이의 13% 가 한국어 상한이므로 마침표 크기(지름 36px)와 UI 조각 크기를 같이 줄여 비례를 맞춘다.
- 1초 안에 한국어 낱말 + 설명 조각을 읽혀야 한다. 낱말은 4글자 이하, 조각 안 글자는 8글자 이하로 둔다. 넘으면 그 낱말만 1.5초로 늘린다(원작도 제품 화면 컷은 1.5초다).
- 바탕색이 매 초 뒤집힌다(흰 #F4F3F6 ↔ 검정 #090911). 화면 밝기가 크게 오가서 눈이 피로하다. 원작도 그렇다. 따라 할 때는 검정 컷을 3컷에 1번 이하로 줄여도 된다.
- 6.5~6.73초 주황 → 연두는 0.23초 만에 화면 전체 색이 두 번 바뀐다(움직임 값 125). 깜박임에 민감한 시청자를 생각해 한 번만 바꾼다.
- 끝에 로고도 정지도 없다. 원작을 그대로 따르면 대상 이름이 마지막에 남지 않는다. 12초 판에서는 마지막 낱말 뒤에 대상 이름 0.8초 + 정지를 더한다.
- 30fps 다. 가로 번짐은 이 프레임 수에서 1~2프레임에 걸친다. 60fps 로 만들면 번짐을 2배 프레임에 나눠 같은 시간(약 0.07초)을 지킨다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 글꼴은 Pretendard Regular·SemiBold(한국어), 숫자·라틴은 InterVariable 이다. 원작의 둥근 기하형 극굵은 글꼴은 없다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 극굵은 소문자 낱말 | 가장 굵은 굵기가 SemiBold 다 | Pretendard SemiBold 140px(높이 13%), 자간 -0.04em, 줄간격 1. 라틴 낱말이면 InterVariable `font-weight: 900`, 220px, 자간 -0.05em | 한국어에서 원작의 두꺼운 덩어리감 |
| 색 있는 마침표 | 없다 | 낱말 끝 span 에 지름 36px 원(`border-radius: 50%`), 기준선에 맞춤. 바탕별 색 · 흰 바탕 #424AE5, 파랑 바탕 #090911, 검정 바탕 #6870F8 | 없음 |
| 가로 움직임 번짐 | 실제 셔터 번짐 | 진입 0.07초 동안 낱말을 `translateX(-120px → 0)` 로 옮기며 `filter: blur(12px → 0)` 와 SVG `feGaussianBlur stdDeviation="24 0"`(가로만)을 같이 건다. 같은 낱말 사본 2개를 -40px·-80px 에 투명도 .3·.15 로 겹쳤다가 지운다 | 셔터 번짐의 자연스러운 꼬리 |
| 말풍선 안내 튀어나옴 | 없다 | div 420x180px, 반지름 14px, #424AE5, 위쪽에 12px 삼각 꼬리. `scale(0.6 → 1.04 → 1)` 0.18초, 원점은 꼬리 끝. 안에 단계 표시와 버튼 하나(SemiBold 22px 흰색) | 없음 |
| 누를 때 퍼지는 원 | 없다 | 마침표 중심에 지름 48 → 110px 원, 테두리 2px #424AE5, 투명도 .6 → 0, 0.35초 | 없음 |
| 흐림 선택 상자 | 없다 | 낱말 뒤쪽 절반을 감싼 div 에 `backdrop-filter: blur(14px)`, 테두리 2px 점선 흰색 투명도 .7, 0.2초에 왼쪽 위 → 오른쪽 아래로 그려지게 `clip-path` | 없음 |
| 음성 파형 | 없다. SVG 로 된다 | SVG 막대 24개(폭 6px, 간격 6px, 높이 8~44px 씨앗 난수), 왼쪽부터 0.4초 동안 투명도 .3 → 1. 흰 알약(800x80px, 반지름 40px) 안 | 없음 |
| 방사선 등장 | 없다. SVG 로 된다 | 가운데에서 SVG line 40개, 길이 60~180px, 굵기 3px 흰색, 시작 반지름 300 → 900px 로 0.4초에 밀려 나가며 투명도 1 → 0. 이름은 `scale(1.6 → 1)` 0.3초, `1-(1-k)^3` | 없음 |
| 원형 닦기 | 없다 | 다음 장면 층에 `clip-path: circle(r at 1500px 540px)`, r 0 → 2200px, 0.12초 | 없음 |
| 제품 화면 판과 채팅 시연 | 실제 앱 화면 | 대상의 실제 화면 캡처를 사용자가 허락한 것만 쓴다. 판 920x560px, 반지름 12px, 그림자 `0 30px 80px rgba(9,9,17,.18)`. 움직일 말풍선·버튼·채팅 줄은 DOM 으로 따로 얹는다. 카메라 이동은 부모의 `scale`·`translate` 로 6초 동안 3구간, 구간 사이 0.5초 `1-(1-k)^3` | 실제 앱의 세부 반응 |
| 글자 섞임 꼬리표 | 없다 | 왼쪽 위 InterVariable 14px 대문자, 자간 0.2em, #8A8A99. 컷마다 0.2초 동안 무작위 라틴 대문자를 0.03초마다 바꾸다 제 글자로 고정 | 없음 |
