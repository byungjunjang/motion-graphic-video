# 갤러리 사이트 한 바퀴 · 카메라 하나로 훑는 웹 홍보 — 분석 노트

> 영상 갤러리 웹사이트를 그 사이트의 실제 화면만으로 소개하는 23초 홍보 영상. 꽉 찬 영상 한 편에서 시작해 카메라가 물러나면 그 영상이 홈 화면 격자의 타일 하나가 된다. 격자를 내려 보다가 타일 하나로 빨려 들어가고, 박자에 맞춰 영상 세 편이 하드 컷으로 지나간다. 다시 타일로 돌아와 커서가 하나를 누르면 상세 화면이 열리고, 글 한 구절에 형광펜이 칠해지고 복사 버튼이 눌린다. 끝은 사이트 이름 + 주소 알약 + 오른쪽 타일 줄이다. 웹 서비스·앱·포트폴리오 사이트 소개에 맞는다. 화면 녹화형 · 단일 카메라 · 흰 바탕 UI.

출처 · pm:antonio-kodheli-490109. 작성자의 프롬프트는 약 4천 자다. 주제(갤러리 사이트 홍보), 스타일(거의 흰 바탕, 검은 알약, UI 글꼴 하나 + 고정폭 글꼴, 강조색 하나와 그 쓰임 세 곳), 구성(박 단위 장면표 9칸), 제작 방법과 금지 목록을 정했다. 실제 요소의 크기·위치·점유율, 타격과 화면 사건의 대응, 끝 화면의 배치 숫자는 비어 있다. 이 노트는 영상 프레임(1초 간격 시트 2장, 0.5초 간격으로 직접 뽑은 46장)을 보고 그 빈칸을 채웠고, 원래 글과 실제 화면이 다른 점을 적었다.
측정 · 파일 1280x720 · 30fps · 23.1초. 아래 크기는 1920x1080 으로 환산했다(1.5배). 장면 감지가 잡은 하드 컷은 2곳(6.97, 7.47초)이다. 6.5초의 타일 → 꽉 찬 화면은 카메라가 빨려 들어간 것이라 컷으로 잡히지 않았다. 0.5초마다 움직임 세기의 평균은 14.1 이다. 가장 큰 값은 0.0초(65.6, 물러나기), 8.0초(56.8, 타일로 돌아가기), 6.5초(56.1), 6.0초(41.1), 4.5초(43.1)다. 11.0~16.0초(상세 화면) 평균은 약 4.6, 18~23초(끝 화면)는 4.9~5.9 로 고르다(타일 줄이 계속 흐른다). 색 값은 원본 프레임에서 잰 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. BPM 120.2(박 0.5초, 마디 2.0초). 0.25초 간격으로 고른 타격이 처음부터 끝까지 이어진다. 킥(120Hz 아래 비율이 큰 타격)은 9.08초부터 거의 매 박 들어온다. 그 전에는 1.59초 한 번뿐이다. 음량(rms)은 0~7초 -13~-16dB 에서 7.5초 뒤 -11~-13dB 로 오른다. 가장 센 타격은 18.05(1.00), 12.06(0.94), 20.05(0.94), 19.05(0.88), 10.07(0.85)초다. 원래 글은 음악의 떨어짐(드롭)을 버스트(6.5초)에 맞추라고 정했다. 실제 측정으로는 음량이 7.5초부터 오르고 킥은 9.08초부터 시작한다. 드롭은 버스트보다 1~2.5초 늦다고 본다. 두 하드 컷(6.97, 7.47초)은 타격(7.08, 7.57초)보다 약 0.1초 앞선다. -28dB 아래 짧은 무음 11곳이 마디 끝(3.26, 5.28, 11.30, 13.78, 19.28, 21.28초 등)에 0.25초씩 있다.

## 1. 본질

- 바탕은 거의 흰 따뜻한 회백색(#F6F6F3 근처)이다. 끝 화면은 #F5F5F2 근처로 같다. 그림자와 그라데이션이 없다.
- 화면에 나오는 것은 사이트의 실제 요소뿐이다. 머리글(사이트 이름 + 한 줄 소개 + 작은 메뉴), 세 칸 격자의 영상 타일, 타일 아래 제작자 표기 줄, 상세 화면(왼쪽 영상, 오른쪽 제작자·제목·정보 세 줄·프롬프트 상자), 검은 알약 버튼.
- 강조색은 붉은 주황 하나다. 실제로 잰 형광펜 색은 #DB3530 근처다(원래 글의 값보다 조금 어둡고 붉다). 형광펜, 커서 둘레 빛, 주소 알약의 점에만 쓴다.
- 색이 강한 것은 갤러리 안의 영상들이다. 첫 화면 빨강(#EB4A3A 근처), 버스트의 연두(#C5FF26 근처) · 파랑(#2F2CEF 근처) · 빨강(#E44031 근처). 흰 바탕 UI 와 강한 색 영상이 번갈아 나온다.
- 카메라는 하나다. 사이트 전체를 한 장의 큰 판으로 놓고 그 위를 움직인다. 한 번에 한 가지 이동만 한다.
- 아닌 것 · 유리 카드, 그라데이션, 튀는 글자, 모든 것에 쓰는 흐려짐, 사이트에 없는 버튼이나 숫자.

## 3. 움직임

- 카메라 이동이 전부다. 이동은 네 종류다. 물러나기(0~0.5초, 1.0초), 흐르기(4.5~6.0초), 빨려 들어가기(6.0~6.5초), 다가가기(13.0~13.5초). 버티는 동안에도 카메라가 아주 조금 다가간다(멈춘 화면이 없다).
- 빠른 이동은 0.5초 안에 끝난다. 이동 사이의 버티기는 2~4초다. 빠름 → 버팀 → 빠름의 박자다.
- 타일 안의 영상은 계속 돈다. 격자 화면에서 9개 안팎의 작은 영상이 동시에 움직인다. 이웃 타일이 같은 프레임에 바뀌지 않는다.
- 커서는 하나다. 둘레에 붉은 주황 빛 원이 있다. 누를 때 원이 조금 줄었다 커진다.
- 형광펜은 왼쪽에서 오른쪽으로 0.3~0.5초에 칠해진다. 띠는 단색이고 가장자리가 반듯하다.
- 끝 화면의 오른쪽 타일 줄은 5초 동안 같은 속도로 위로 흐른다(움직임 세기 약 5 로 고르다).
- 움직임 세기의 모양 · 큰 봉우리(40~66)가 0.0, 4.5~6.5, 8.0초에 몰려 있고 11~16초는 낮다(1.3~11.3). 앞 절반은 카메라가 바쁘고 뒤 절반은 커서·형광펜 같은 작은 사건만 움직인다. 화면 점유율로 보면 앞 절반의 주인공은 격자 전체(화면의 약 90%)이고, 뒤 절반의 주인공은 프롬프트 상자(약 38x22%)와 알약 하나(약 20x6%)다. 점점 작은 것으로 시선을 좁힌다.

## 4. 전환

- 컷 대신 카메라가 장면을 잇는다. 첫 영상 → 격자는 물러나기, 격자 → 버스트는 빨려 들어가기, 버스트 → 격자는 줄어들기(일치 컷), 격자 → 상세는 타일이 피어나기, 상세 → 끝은 왼쪽으로 밀기.
- 타일이 꽉 찬 화면이 될 때 모서리 둥글기가 0 이 된다. 반대로 줄어들 때 둥글기가 돌아온다. 그래서 타일과 꽉 찬 화면이 같은 물체로 보인다.
- 하드 컷은 버스트의 2번뿐이다(6.97, 7.47초). 영상 세 편을 박마다 바꾼다.
- 복사됨 알약 → 주소 알약 · 버튼 하나가 글자만 바꿔 끝 화면의 주소가 된다. 상세 화면의 요소가 끝 화면으로 넘어간다.

## 5. 타이포

- 글꼴은 고딕 계열 UI 글꼴 하나와 고정폭 글꼴 하나다. 고정폭은 프롬프트 상자에만 쓴다.
- 사이트 이름 · 굵은 고딕, 검정(#1A1A1A 근처). 홈 화면에서 가로 5% 에서 시작해 높이 약 7%(대문자 기준), 세로 13~23% 지점이다. 끝 화면에서는 폭 40%, 세로 32~45% 지점으로 더 크다.
- 한 줄 소개 · 보통 굵기, 회색, 화면 높이의 약 2%. 끝 화면에서 두 줄이다.
- 타일 아래 제작자 표기 · 동그란 사진 + 작은 글자(높이 약 1%). 모든 영상 타일에 붙어 있다.
- 프롬프트 글 · 고정폭, 회색, 줄간격 약 1.6, 글자 높이 약 1.5%(1.5배 다가간 뒤 약 2%).
- 알약 · 검은 바탕에 흰 글자, 높이 약 6%, 왼쪽에 붉은 주황 점 하나.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 6.0~8.5초. 세 칸 격자(칸 폭 552px, 화면 폭의 29%, 간격 36px)의 타일 하나로 카메라가 0.5초 만에 빨려 들어가 꽉 찬 화면이 되고, 박마다(0.5초) 꽉 찬 영상 세 편이 하드 컷으로 지나간 뒤, 마지막 영상이 자기 타일로 줄어든다. 꽉 찬 화면은 단색 바탕 + 큰 글자 한 낱말 구도다. 타일과 꽉 찬 화면이 같은 물체로 이어지지 않으면 이 영상이 아니다.
- 12초 판 압축 예 · 0~0.5초 물러나기. 0.5~2.5초 홈 격자 버티기. 2.5~3.0초 빨려 들어가기. 3.0~4.5초 버스트 세 편(0.5초씩). 4.5~5.0초 타일로 돌아가기. 5.0~6.0초 커서가 누른다. 6.0~8.5초 상세 화면 + 형광펜 + 복사(형광펜 0.4초, 복사 0.5초). 8.5~9.0초 왼쪽으로 밀기. 9.0~12.0초 끝 화면(이름 + 주소 알약 + 타일 줄). 격자 흐르기는 뺀다.
- 사이트 전체를 한 장의 판에 놓고 카메라 하나로 움직이는 방식. 화면 전환 효과를 따로 만들 필요가 없다.
- 둥글기 0 → 원래 값으로 바뀌는 타일 확대. 같은 물체임을 보여 준다.
- 버튼 하나가 끝 화면의 주소가 되는 마무리.
- 강조색을 형광펜·커서·점 세 곳에만 쓰는 절제.
- 빠른 이동 0.5초 + 버티기 2~4초의 박자.
- 넓게 → 좁게 시선을 모으는 순서. 격자 전체 → 타일 하나 → 상세 화면 → 글 한 구절 → 버튼 하나. 대상 서비스의 핵심 기능 하나를 마지막 구절·버튼 자리에 둘 수 있다.

## 7. 함정

- 화면의 사이트 이름, 소개 문장, 제작자 표기, 영상 속 글자(실존 로고 글자 포함), 프롬프트 글, 주소는 모두 원작 사이트의 것이다. 옮기지 않는다. 역할(서비스 이름, 한 줄 소개, 제작자 표기, 설명 글 상자, 주소 알약)만 가져온다. 실존 로고가 든 영상 화면은 쓰지 않는다.
- 원래 글은 사이트의 실제 화면과 영상을 긁어 와 쓰라고 정했다. 우리 영상은 사용자가 허락한 화면과 영상만 쓴다. 남의 영상 타일을 채우는 데 다른 사람의 작품을 쓰지 않는다. 타일 영상은 단색 바탕 + 간단한 도형·글자 움직임으로 직접 만든다.
- 타일 안 영상 9개를 동시에 돌리면 렌더가 무겁다. 각 타일을 canvas 나 DOM 의 짧은 반복 움직임으로 만들고, 시작 위상을 0.13초씩 어긋나게 한다.
- 흰 바탕과 같은 색의 타일은 사라진다. 타일마다 1px 테두리(#E4E4E0 근처)를 준다.
- 카메라가 다가간 뒤 머리글이나 정보 줄이 화면 가장자리에 걸린다. 다가간 마지막 프레임을 꼭 확인한다.
- 한국어로 옮기면 사이트 이름과 소개가 한글이 된다. 끝 화면 이름은 Pretendard SemiBold 120~130px, 소개는 Regular 34px 두 줄로 둔다. 프롬프트 상자는 한국어 글이면 고정폭 대신 Pretendard Regular 26px, 숫자·라틴만 InterVariable 을 쓴다.
- 드롭을 버스트에 맞추라는 것이 원래 의도였지만 실제 영상은 1~2.5초 어긋났다. 우리 판에서는 버스트 첫 컷을 마디 첫 박에 두고 `audio-probe --fit` 으로 오차를 잰다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

글꼴은 Pretendard Regular·SemiBold 와 InterVariable 이다. 값은 1920x1080 기준이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 실제 사이트 화면 | 남의 사이트와 작품이다 | DOM/CSS 로 가상 사이트를 짓는다. 바탕 #F6F6F3, 머리글(이름 SemiBold 76px, 소개 Regular 22px), 세 칸 격자 `grid-template-columns: repeat(3, 552px); gap: 36px`, 좌우 여백 96px. 타일은 16:9(552x310px), 모서리 12px, 아래에 제작자 줄(동그라미 20px + 글자 15px) | 진짜 사이트라는 증거력 |
| 타일 속 영상 9개 | 실제 영상 파일이 필요하다 | 타일마다 단색 바탕 + 큰 글자 한 낱말 또는 도형 하나가 1~2초 주기로 움직이는 작은 장면을 DOM 으로 만든다. 색은 #EB4A3A · #C5FF26 · #2F2CEF · #111111 · #F6F6F3 를 돌려 쓴다 | 서로 다른 작품의 다양함 |
| 단일 카메라 | 없다. CSS 로 된다 | 사이트 전체를 감싼 부모 하나에 `transform: translate(-fx, -fy) scale(s)` 를 t 의 함수로 준다. s 는 로그로 보간한다(`s = exp(lerp(ln a, ln b, e))`). 빠른 이동 0.5초, 가속 곡선은 `cubic-bezier(.7,0,.2,1)` | 없음 |
| 타일 → 꽉 찬 화면 | 둥글기와 크기를 함께 바꿔야 한다 | 확대 진행값 p 에 맞춰 `border-radius: (12 * (1 - p) / s)px`. 꽉 찼을 때 타일 하나를 1920x1080 에 맞춘다(s = 3.48) | 없음 |
| 형광펜 | 없다 | 구절을 감싼 span 에 `background: linear-gradient(#DB3530,#DB3530) 0 50% / X% 100% no-repeat`, X 를 0.4초 동안 0 → 100. 칠해진 부분 글자는 흰색 | 없음 |
| 커서 둘레 빛 | 없다 | 커서 SVG(높이 28px) 뒤에 지름 34px 원, `background: rgba(219,53,48,.35)`, `filter: blur(4px)`. 누를 때 0.15초 동안 `scale` 1 → 0.8 → 1 | 없음 |
| 상세 화면 피어나기 | 레이아웃 두 개 사이 보간 | 타일의 시작 사각형과 상세 화면 왼쪽 영상 사각형을 재서 0.5초 동안 `left/top/width/height` 를 보간한다. 오른쪽 열은 0.1초 늦게 `opacity` 와 `translateY(16px → 0)` | 없음 |
| 끝 화면 타일 줄 | 없다 | 오른쪽 열(가로 64~95%)에 16:9 타일 6개를 세로로 쌓고 `translateY` 를 초당 -40px 로 흐르게 한다. 위아래 끝은 `mask-image: linear-gradient(transparent, #000 10%, #000 90%, transparent)` | 없음 |
