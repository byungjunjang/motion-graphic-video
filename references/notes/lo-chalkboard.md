# 칠판 · 쓰고, 닦고, 같은 자리에 다시 쓰기 — 분석 노트

> 교실 칠판 위에 분필 글씨가 획순대로 스스로 써지는 49초 영상. 손도 분필도 지우개도 보이지 않는다. 사람들이 흔히 믿는 주장을 먼저 쓰고, 같은 화면에서 그 주장을 닦아 낸 뒤, 같은 자리에 맞는 설명을 다시 쓴다. 화면은 대부분 멈춰 있고 분필 획만 늘어난다. 낱말이나 글자의 뿌리, 흔한 오해 바로잡기, 풀이 한 개를 차근차근 가르치는 짧은 강의형 영상에 맞는다.

출처 · lo:chalkboard. 원래 글은 긴 스타일 명세다. 쓰는 속도, 카메라 규칙, 숏마다의 시각이 자세하다. 그러나 칠판·분필의 실제 색, 큰 글자의 화면 크기와 자리, 실제로 화면이 얼마나 오래 멈춰 있는지, 닦기가 화면에서 어떻게 보이는지가 없다. 그래서 영상 프레임을 보고 이 노트를 썼다.

## 3. 움직임

- 원래 글의 분필 속도와 카메라 규칙은 화면과 맞다. 큰 글자 한 개가 약 1초에 써진다(2.75~4.0초).
- 영상에서 확인한 점 · 49초 중 약 30초가 움직임 세기 1 미만이다. 큰 값 다섯 개는 모두 장 사이 이동이다. 글씨가 써지는 동안 세기는 0.0~0.6 이다. 획이 멈춘 채 0.5초를 넘는 곳은 38.44~39.72초 무음 하나뿐이다.
- 쓰는 순서는 이야기 순서다. 주인공 글자 → 부품 이름 → 물음 → 영어 보조 줄.

## 4. 전환

- 원래 글의 전환 목록(하드 컷, 판 밀기, 이음매를 넘는 선)은 화면에 있다. 디졸브는 없다. 컷은 세 번뿐이고 나머지는 카메라 이동이나 판 밀기다.
- 이음매를 넘는 선 · 뒤판의 주황 선이 아래로 나가 오른쪽으로 달리고(32.5~33.5초), 컷 뒤 앞판 왼쪽 아래 끝에서 같은 선이 이어 들어온다.
- 원래 글과 다른 점 · 글은 젖은 자국이 남는 한 번의 닦기 동작을 정했다. 실제 닦기는 젖은 자국 없이 왼쪽부터 덩어리 단위로 사라진다(34.7~35.4초). 젖은 자국은 2.5초 물러나기 때만 보인다.

## 7. 함정

- 화면의 글자(큰 글자, 제목, 물음, 풀이, 판정, 날짜, 끝 카드 표기)는 원작의 것이다. 옮기지 않는다. 역할(따라가는 부분 하나, 주장, 바로잡은 풀이, 판정)만 가져온다.
- 원본은 외국 글자의 구조를 가르친다. 한국어 영상에서 같은 구조를 쓰려면 낱말의 뿌리(한자어의 뜻 글자, 합성어의 앞뒤 말)나 수식의 항으로 바꾼다. 한글 낱자를 획순대로 쓸 때는 획 자료를 직접 만들고 표준 획순과 대조한다.
- 한국어 큰 글자 크기 · 원본 큰 글자는 315px, 가까이 500px 이다. 한국어 글자는 140px 이하만 쓰므로 그 크기의 조판 글자를 쓸 수 없다. 큰 글자는 글꼴이 아니라 획 경로(SVG 경로를 따라 그리는 분필 선)로 만든다. 획 경로라서 글꼴 크기 규칙의 대상이 아니다. 조판 글자(대사 자막 등)는 Pretendard Regular 36px 이하로 둔다.
- 원본은 8~9초씩 카메라를 세운다. 대신 획이 0.5초 넘게 멈추지 않게 하고, 멈춤은 판정 직전 1~1.3초 한 번만 둔다.
- 분필이 순백(#FFFFFF)이면 인쇄 글자처럼 보인다. #E3E2D7 근처로 두고 획 안에 알갱이 빈 곳을 낸다. 주황은 따라가는 부분 하나와 그 연결선에만 쓴다.
- 교실의 벽·시계는 빼지 않는다. 원작의 시계 시각은 옮기지 않는다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 획순대로 써지는 큰 분필 글자 | 획마다의 경로·순서·압력이 필요하다. 글꼴 윤곽에서 자동으로 뽑으면 점·획이 빠진다 | 글자마다 획 중심선을 SVG 경로로 손수 만든다(한 글자 8~14획). seek 에서 획 i 의 진행률로 `HAND.subPath(P, frac)` 를 잘라 canvas 에 그린다. 획 굵기는 시작·꺾임에서 굵고 끝에서 가늘게(큰 글자 18 → 10px), `HAND.ribbon(ctx, P, u => 10 + 8 * (1 - u) ** 2, { color: '#E3E2D7' })` 를 쓴다. 한 획 0.08~0.1초, 획 사이 0.02초 | 실제 손글씨의 미세한 흔들림과 압력의 우연 |
| 분필 알갱이 결 | 분필이 칠판 결에 걸려 끊기는 질감이다 | 획을 그린 뒤 `globalCompositeOperation = 'destination-out'` 으로 시드 고정 점 수천 개(지름 1~2px, 획 넓이의 15%)를 빼낸다. 점 배치는 판마다 한 번 굽고 seek 에서는 쓰지 않는다. 작은 글자(40px 급)는 빼는 비율을 8% 로 낮춘다 | 분필 가루가 쌓이는 가장자리 |
| 칠판 바탕과 옅은 얼룩 | 실제 칠판의 결이다 | 바탕 #14241C 위에 `texTile(seed, { mc: '30,60,48', mottle: .03, dark: .03, light: .02, fibers: 0, specks: 10 })` 를 곱하기로 깐다. 기본 `mc`(누런 종이색)는 칠판을 갈색으로 만들므로 바꾼다. `grainLayer(parent, seed)` 를 불투명도 0.04 로 얹는다 | 큰 얼룩의 자연스러움 |
| 닦기 | 지우개 없이 덩어리가 사라지는 모양이다 | 지울 덩어리마다 사라지는 시각을 정한다(왼쪽에서 오른쪽으로 0.7초 안에 분배). 덩어리마다 폭 140px 의 세로 마스크가 0.12초에 지나가며 획을 지운다(마스크는 `HAND.trace` 로 만든 경로에 `clip`). 마스크가 지나간 자리에 칠판보다 4% 어두운 띠를 0.3초 남기고 서서히 지운다(젖은 자국을 아주 옅게) | 손으로 닦을 때의 불규칙한 문지름 |
| 판 밀기와 교실 | 나무 틀·받침·벽·시계가 있는 실제 공간이다 | 교실 벽 전체를 AI 일러스트(codex-image)로 한 장 만든다. 크림 벽 #BCB4A4, 아래 녹회색 판 #5C7464, 나무 틀 #5C442C, 빈 칠판 두 장, 둥근 시계, 글자·로고 없음. 칠판 면 자리는 비워 두고 우리 canvas 를 그 자리에 원근 없이 끼운다. 판 밀기는 앞판 canvas 를 `translateX` 로 1.2초에 판 폭만큼 민다(부드럽게 들고 남) | 칠판 면과 틀 사이 그림자의 정확한 맞물림 |
| 주황 연결선과 원 | 없다. canvas 로 된다 | 경로를 3차 곡선 2개로 만들고 `HAND.ink(ctx, P, { frac, w: 6, color: '#C67F45', key: 'link', B: 0 })` 로 1.0초에 그린다. 원은 지름 115px 의 닫힌 점 배열에 `HAND.wobble(P, true, 2, 'ring', 0)` 을 한 번 적용해 굽고 0.4초에 그린다 | 없음 |
