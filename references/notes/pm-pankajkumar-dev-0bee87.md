## 3. 움직임

- 모든 등장이 "쾅"이다. 0.1~0.15초에 1.1~1.2배에서 제 크기로 떨어진다. 흐린 페이드가 거의 없다.
- 장마다 움직임의 종류가 다르다. 조립(1) → 밀기(2) → 빠져나감(3) → 3D 기울기와 시차(4) → 원색 면 교체(원색) → 원근 공간 전진(바닥) → 빨려 듦(구멍) → 쌓기(5) → 줄어 날아감(6) → 정지(7).
- 3D 는 판을 기울이는 정도다. 판은 모두 평면이고 두께가 없다. 바닥 장에서만 원근 격자와 서 있는 글자로 공간을 만든다.
- 세로 움직임 흐림을 한 번 쓴다(11.5~12.5초, 아래 낱말).
- 박자 · 앞 10초는 0.5초(한 박)마다 글자 하나. 10초 뒤는 마디(약 1.9초)마다 장면, 박마다 요소 하나.

## 4. 전환

- 1~4장은 컷 없이 하나의 틀이 변한다.
- 4장 → 원색 · 파랑 판으로 확대해 들어간 뒤 빨강 전체 화면으로 바꾼다.
- 원색 장 안은 하드 컷과 0.25초 번쩍임(검정, 파랑)이다. 원색 면이 통째로 바뀐다.
- 글자 속으로 확대(12.5초) · 짧은 낱말 글자 안의 격자 결로 들어가 다음 장(바닥)의 격자가 된다.
- O 의 구멍(17~18.6초) · 검은 O 가 터널이 되어 다음 장으로 빨려 든다.
- 화소 깨짐(19.0초) · 크림 덩어리가 격자 칸 단위로 깨진다.
- 콜라주 → 빈 틀 · 모든 것이 한 덩어리로 줄어 날아간 뒤 첫 장면의 틀이 돌아온다. 시작과 끝이 같은 빈 틀이다.

## 5. 타이포

- 큰 글자 · 굵은 산세리프 대문자. 두 가지 폭을 쓴다. 넓은 굵은 체(조립 낱말, 두 글자 낱말)와 아주 좁은 굵은 체(좁은 낱말들). 글자 높이는 화면 높이의 40~55%(430~600px)다.
- O 는 검은 꽉 찬 원이다. 원 지름이 다른 글자의 높이와 같다.
- 색 글자 · 파랑 판 위는 크림 글자, 빨강 판 위는 검은 글자, 크림 바탕 위는 검은 글자가 기본이다. 절정 장에서만 빨강·파랑 글자를 섞는다.
- 세로 낱말 · 절정 장에서 낱말 2개를 90° 돌려 화면 왼쪽·오른쪽 끝에 세운다.
- 작은 라벨 · 고정폭 대문자, 글자 높이 약 0.8%(9px). 틀 네 모서리에만 둔다. 장 번호는 "두 자리 숫자 / 장 이름" 꼴이다.
- 서명 · 보통 굵기 산세리프 한 줄, 높이 약 1.8%, 오른쪽 정렬.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 24.5초의 콜라주 절정. 크림 바탕에 노랑 큰 원(지름 약 45%)과 빨강 사선 띠(-8°)가 깔리고, 두 글자 낱말(높이 55%)이 왼쪽 위, 좁은 낱말(높이 40%)이 오른쪽 아래에 서며, 양 끝에 90° 세운 낱말 둘과 작은 조각 10여 개가 붙어 낱말 9~10개가 화면을 채운 화면.
- 12초 판 압축 예 · 0~2초 빈 틀과 원 → 글자 조립, 2~3.5초 틀을 밀고 빠져나감, 3.5~5초 틀이 기울며 파랑 판, 5~7.5초 원색 면 2장(빨강, 빨강/파랑 경계), 7.5~10.5초 콜라주 쌓기, 10.5~12초 줄어 날아감 + 빈 틀과 서명. 바닥 장, O 구멍, 화소 깨짐을 뺀다.
- O 자리에 원을 쓰는 규칙. 한 도형이 글자와 그림을 겸한다. 한국어에서는 받침 ㅇ 이나 초성 ㅇ 을 원으로 바꿀 수 있다.
- 틀 모서리의 장 번호 라벨. 장이 바뀔 때마다 숫자가 올라가 이야기의 진행을 알린다.
- 시작과 끝을 같은 빈 틀로 닫는 구성. 끝은 크게 줄인 콜라주 + 가장 큰 타격 + 정지다.
- 원색 셋의 역할 배분. 빨강은 띠와 판, 파랑은 판과 작은 원, 노랑은 큰 원. 검정은 글자만.

## 7. 함정

- 화면의 낱말(조립 낱말, 장 이름, 콜라주 낱말), 라벨 문장, 서명 이름은 원작의 것이다. 서명은 실존 인물 이름이다. 옮기지 않는다. 역할(주제 낱말, 장 이름, 서명)만 가져온다.
- 한국어로 옮기면 글자 크기 제한에 걸린다. 이 프로젝트는 한국어 글자를 140px 까지만 쓴다. 원작의 큰 글자는 430~600px 다. 큰 글자 자리는 (1) 숫자·라틴 낱말(InterVariable 900)을 쓰거나 (2) 글자 대신 원·막대 도형으로 채우고 한국어 낱말은 140px 이하로 둔다.
- 한국어에는 좁은 굵은 체가 없다. Pretendard SemiBold 를 scaleX(0.8) 로 좁히면 획이 가늘어 보인다. 좁힘은 0.85 까지만 쓴다.
- 30초 동안 장이 7개다. 12초로 줄이면 장을 4~5개만 남긴다. 장을 다 넣으면 장당 1.5초 남짓이라 아무것도 읽히지 않는다.
- 측정 BPM 은 약 128 이다. 화면 라벨의 120 을 믿고 박을 맞추면 10초 뒤에 0.8초쯤 어긋난다. 실제 음원으로 audio-probe 를 다시 돌린다.
- 하드 컷과 번쩍임이 많다(10~21초에 7번). 번쩍임은 0.25초 이상 둔다. 빛에 민감한 시청자를 위해 흰색·검정 사이 번쩍임은 초당 3번을 넘기지 않는다.
- 콜라주는 낱말 수가 많아야 터진다. 낱말을 4개 이하로 두면 그냥 포스터처럼 보인다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 아주 좁은 굵은 체 | 좁은 굵은 글꼴이 없다 | 라틴은 InterVariable `font-weight: 900` + `transform: scaleX(0.72)`, 자간 -0.02em. 한국어는 Pretendard SemiBold 140px + scaleX(0.85) | 좁은 글꼴 특유의 높이감 |
| 넓은 굵은 큰 글자(500px) | 한국어 140px 제한 | 라틴·숫자는 InterVariable 900, 520px, 자간 -0.04em. O 는 SVG 원(지름 = 대문자 높이)으로 바꾼다. 한국어 핵심어는 그 아래 줄에 140px 로 둔다 | 한국어로만 된 거대 글자 |
| 틀이 휘는 압력 | 선이 탄성 있게 휜다 | SVG path · 틀 오른쪽 선을 3차 베지어로 그리고 가운데 제어점을 x 로 +40px 까지 밀었다 0.3초에 되돌린다(easeOutElastic). 아래 선은 진폭 6px 사인 물결 | 없음 |
| 3D 기울어 떠 있는 판 | 없다(CSS 로 된다) | 판마다 `transform: perspective(1600px) rotateY(-18deg) rotateX(6deg) translateZ(…)`. 판 셋의 translateZ 를 -300, 0, 200px 로 나눠 시차를 만든다 | 없음 |
| 원근 격자 바닥과 서 있는 글자 | 3D 공간 | three.js · 바닥 평면에 `GridHelper(4000, 120)` 색 #BDB8AC, 위쪽은 노랑 평면 벽. 글자는 canvas 로 그린 텍스처를 붙인 평면(`PlaneGeometry`)을 세워 둔다. 카메라를 z 로 초당 600 전진 | 글자의 두께(원작도 거의 없다) |
| O 구멍 터널 | 둥근 덩어리의 꿈틀거림 | canvas · 노이즈로 반지름을 ±6% 흔든 닫힌 곡선 6겹(검정, 파랑, 빨강, 노랑, 검정, 파랑)을 바깥부터 0.85배씩 줄여 그린다. 1초에 전체 크기를 0.4 → 2.6 배 | 없음 |
| 화소 깨짐 | 없다(코드로 된다) | canvas · 덩어리를 120px 칸으로 나누고 칸마다 0~0.3초 무작위 지연으로 사라지게 한다 | 없음 |
| 종이 결 | 종이 스캔 | `texTile(seed, { mc: '128,124,112', mottle: .025, dark: .02, light: .03, fibers: 40, specks: 8 })` (vendor/paper/texture.js) 를 바탕에만 깐다. 원색 면에는 깔지 않는다 | 큰 얼룩 |
| 고정폭 모서리 라벨 | 고정폭 글꼴이 없다 | InterVariable 13px 대문자, 자간 0.12em, `tabular-nums`, 색 #13130E 불투명도 0.7 | 고정폭의 기계 느낌 |
