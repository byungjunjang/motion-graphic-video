# 1950년대 만화 · 따라 하는 설치 안내 — 분석 노트

> 가상의 로봇 청소기를 세 단계로 설치하는 40초 안내 영상. 평평한 인쇄 색과 끊어진 먹선, 몸은 멈추고 손만 움직이는 진행자, 색 면 하나로 된 방이 특징이다. 단계가 바뀔 때마다 단계 번호 원이 문이 되어 화면이 원으로 열린다. 시작 버튼을 누르면 버튼이 원으로 열리며 집 평면도로 바뀌고, 카메라가 돌면서 물러나 청소 경로 전체를 보여 준다. 설치 안내, 도움말, 사용법, 안전 수칙 카드에 맞는다.

출처 · lo:midcentury-toon. 색인에 든 원래 글은 긴 스타일 명세다(본질, 움직임, 카메라 문법, 함정, 숏 표, 마디 단위 시간 배분). 전환 문법과 마디 수, 대표 숏의 배율·회전 값은 글에 있다. 그러나 장면별 바탕색, 진행자와 제품의 화면 크기, 색이 선에서 어긋나는 실제 거리, 평면도의 배치, 정리 화면의 구성, 원래 글과 화면이 다른 점이 없다. 그래서 영상 프레임을 보고 이 노트를 썼다.
측정 · 파일 1280x720 · 24fps · 40.0초. 크기는 1920x1080 기준으로 바꿔 적는다(1.5배). 장면 감지는 36.62초 한 번(끝 원 닫힘)뿐이다. 움직임 세기 평균 약 6. 큰 값은 원 전환 순간에 있다(7.0초 26.2, 12.5초 17.4, 18.0초 17.1, 21.5~23.5초 19~32, 27.0초 21.0, 30.5초 25.6, 36.5초 91.1 최대). 단계 안에서는 0.4~8.6 이다. 33.0~36.0초와 37.5초 이후는 0.0~0.5 로 멈춰 있다. 색 값은 프레임에서 잰 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. 박 검출은 66 BPM(마디 약 3.64초)을 냈다. 원래 글은 132 BPM 이라 정했다. 66 은 그 절반이고, 원 전환 시각이 132 BPM 마디(약 1.82초) 경계에 맞으니 원래 글 쪽이 맞다고 본다. 가장 큰 타격(세기 1.00)은 21.80초, 시작 버튼이 원으로 열리는 순간이다. 바로 앞 20.52~21.80초가 무음이다(버튼을 1초 누르고 있는 동안). 30.18~30.90초 무음 뒤 정리 화면이 올라온다. 37.84초부터 끝까지 무음이다. 0.43·0.88초의 저역 타격 두 번(킥)은 상자가 열리는 자리다.

## 3. 움직임

- 원래 글의 2프레임 단위 포즈(12fps), 카메라·원·화살표는 24fps, 튀어나오기(약 0.25초, 강한 넘침)는 화면과 맞다.
- 영상에서 확인한 점 · 진행자는 장면마다 포즈 하나로 버틴다. 움직이는 것은 팔 하나, 눈(웃는 눈 ↔ 뜬 눈), 입뿐이다. 장면 안 움직임 세기가 0.4~8 로 낮은 이유다.
- 확대 원은 늘 장면 시작 약 1.7초 뒤에 튀어나온다(9.0초, 14.0초). 진행자가 먼저 동작을 시작하고, 원이 그 손을 크게 보여 준다.
- 카메라는 장면 안에서 아주 천천히 민다(첫머리 1.00 → 1.07, 원래 글 값). 프레임에서 보면 첫머리 7초 동안 제품이 화면 가로 약 21% 에서 22% 로 커진다.

## 4. 전환

- 원래 글의 원 전환(번호 원이 문, 버튼 → 평면도, 끝 원 닫기)과 색 면 밀기(팁은 옆에서, 정리는 아래에서), 디졸브 없음은 화면과 맞다.
- 영상에서 확인한 점 · 번호 원은 다음 장면의 바탕색으로 차 있다. 원이 커지면 그 색이 그대로 다음 장면 바탕이 된다. 단계 3 → 결과 전환만 원 안이 크림이다(평면도의 종이색).
- 원 전환 길이는 약 0.4~0.5초(원래 글은 0.9박, 132 BPM 에서 약 0.41초). 움직임 세기는 17~28.
- 끝 원 닫기(36.5초)는 이 영상에서 가장 큰 변화다(91.1). 크림 정리 화면이 제품 위 작은 원으로 닫히고 짙은 갈색이 화면을 덮는다. 37.0초에 흰 점 하나만 남고, 37.5초부터 끝 화면 원(지름 화면 높이 약 92%)이 선다.

## 5. 타이포

- 세 종류 글자를 쓴다 · 기울어진 굵은 붓글씨 제목, 굵은 슬랩 세리프 머리글(아래에 노랑 그림자 2~3px), 자간이 넓은 대문자 꼬리표와 둥근 산세리프 본문.
- 단계 머리글 · 왼쪽 위에 짙은 번호 원(지름 화면 높이 약 10%, 약 105px, 가로 4~9%, 세로 7~17%), 그 오른쪽에 작은 단계 표시 줄(약 1.5%)과 머리글(약 5%).
- 자막 카드 · 아래 가운데(세로 87~94%), 크림 판에 먹 테두리와 양끝 빨간 별표. 글자 높이 약 3%. 장면이 끝날 때까지 바뀌지 않는다.
- 첫머리 제목 · 붓글씨 줄 글자 높이 약 10%, 머리글 두 줄 약 6%, 짙은 알약 꼬리표 약 2.5%. 모두 왼쪽 정렬, 가로 7~38%.
- 정리 화면 · 붓글씨 한 줄(빨강 #E5603F 근처, 약 6%), 머리글 한 줄(약 6%), 자간 넓은 꼬리표(약 2%), 단계 원 아래 이름(약 3%)과 조건 한 줄(약 2%).

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 21.0~24.5초의 "손가락이 버튼을 1초 누르고(무음, 빨간 고리) → 버튼에서 크림 원이 열리며 위에서 본 거실 한 구석(약 5배, −6°) → 2초 동안 돌며 물러나 평면도 전체(1.0배, 0°, 화면 가로 84%)가 서고 → 주황빨강 지그재그 경로가 구역마다 그려지는" 장면이다. 원 전환과 돌며 물러나기가 빠지면 이 영상이 아니다.
- 12초 판 압축 예 · 0.0~1.8초 첫머리 1마디(노랑 방사선, 크림 원 위 제품, 진행자, 제목), 1.8~3.6초 단계 1(번호 원이 열림, 무릎 포즈 + 확대 원), 3.6~5.4초 단계 2(같은 방식), 5.4~6.6초 단계 3 버튼 누르기(0.6초 무음), 6.6~9.4초 대표 장면(원 0.4초 + 돌며 물러나기 1.4초 + 경로 1.0초), 9.4~11.2초 정리 화면(단계 원 3개, 멈춤 1.5초 이상), 11.2~12.0초 제품 위로 원 닫기. 팁 장면은 빼고, 단계마다 확대 원은 하나만 둔다.
- 장면당 바탕색 하나 + 정리 화면 단계 원이 그 색을 다시 쓰는 구조.
- 진행자 크기 · 서 있을 때 화면 높이의 약 56%(약 605px), 무릎 꿇을 때 약 41%. 제품은 첫머리 화면 가로 약 21%, 버튼 장면 약 30%. 원래 글이 정한 주요 대상 크기(화면 높이의 1/3 이상)를 지킨다. 아래 140px(자막 카드 자리)는 비워 둔다.
- 정리 화면 구성 · 단계 원 3개(지름 화면 높이 약 19%, 약 210px, 가로 중심 28%, 50%, 72%, 세로 중심 40%), 원 사이 점선 화살표, 왼쪽 아래 작은 진행자(높이 약 35%), 오른쪽 아래 햇살 두른 제품. 요소 약 10개가 한 화면에 있고 3초 멈춘다.

## 7. 함정

- 화면의 제품 이름, 제목 문구, 단계 머리글, 자막 문장, 끝 화면 글자는 원작의 것이다. 옮기지 않는다. 역할(제목, 단계 머리글, 조건 꼬리표, 팁 한 줄)만 가져온다. 끝 화면 작은 줄에 실존 제작자·글꼴·음원 이름이 있다. 쓰지 않는다.
- 한국어로 바꾸면 붓글씨 제목과 슬랩 세리프 머리글을 낼 글꼴이 없다. Pretendard SemiBold 에 노랑 그림자(오른쪽 아래 3px)를 붙여 머리글의 무게를 내고, 붓글씨 줄은 빼거나 `HAND.ribbon` 밑줄로 손맛을 대신한다.
- 색을 선에 딱 맞춰 칠하면 평범한 벡터 그림이 된다. 색 면은 선에서 4~6px 어긋나게, 2프레임마다 1~2px 씩 흔든다.
- 원래 글의 함정 절(가는 팔이 막대처럼 보임, 뭉툭한 손가락, 따로 붙인 코)은 그대로 맞다. 진행자의 코는 얼굴 외곽선에서 이어진 긴 세모다.
- 평면도 경로를 한 번에 다 그리면 대표 장면이 약해진다. 구역마다 0.5~1박씩 나눠 그린다. 경로가 가구를 뚫고 지나가면 안 된다.
- 16:9 원본이라 비율 옮기기는 필요 없다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 어긋난 색 면 + 끊긴 먹선 | 두 층을 따로 흔들어야 한다 | 도형마다 점 배열 P 를 하나 두고, 색은 `HAND.paint(ctx, P, { fill, key, B })` 를 (−6px, −4px) 옮겨 그리고, 선은 `HAND.ink(ctx, P, { w: 4.5, color: '#2A2324', key, B })` 로 제자리에 그린다. B 는 `Math.floor(t * 12) % 3`. 끊긴 곳은 P 를 두세 토막으로 나눠 `HAND.subPath` 로 끝을 5~8% 잘라 낸다 | 붓 자국의 굵기 변화 |
| 마른 붓 결, 종이 결 | 실제 인쇄·종이 | 장면 바탕 위에 `texTile(seed, { mc: '120,95,60', mottle: .05, fibers: 120, specks: 25 })` 를 곱하기로 깔고, 전체에 `grainLayer(stage, 11)`. 가장자리는 CSS 방사형 그라데이션 비네트(#2A2324 투명도 0.18) | 붓 자국 결의 방향성 |
| 진행자(기하 도형 사람) | 손 동작과 무릎 포즈 | SVG/canvas 로 직접 그린다. 머리는 달걀형 + 코까지 이어진 열린 외곽선, 윗옷 #E56542, 바지 #354566. 포즈 3장(서기, 무릎, 가리키기)을 바꿔 끼우고 팔 하나만 두 마디 관절로 돌린다. 팔은 먹 띠 `HAND.ribbon` 굵기 22px 위에 색 띠 16px | 손가락 연기의 섬세함 |
| 번호 원 전환 | 없다. canvas 로 된다 | 다음 장면을 오프스크린 canvas 에 그리고, 현재 화면 위에 번호 원 자리를 중심으로 원 `clip` 을 건다. 반지름 52px → 화면 대각선 절반(약 1100px)까지 0.41초, 가속 곡선. 원 테두리에 먹선 5px 를 함께 키운다 | 없음 |
| 돌며 물러나기 | 평면도가 큰 그림이어야 한다 | 평면도를 3840x2160 오프스크린 canvas 에 한 번 그린다. seek 에서 `setTransform` 으로 배율 5.4 → 1.0, 회전 −6° → 0° 를 2.0초에 준다. 배율은 지수 보간(5.4^(1−u)), u 는 감속 곡선. 확대 상태에서도 먹선 굵기가 같아야 하므로 확대 구간에서는 그 배율에 맞는 선 굵기로 다시 그린다(원래 글의 함정과 같다) | 없음 |
| 그려지는 경로 | 없다. canvas 로 된다 | 구역마다 경로 점 배열을 미리 만들고 `HAND.subPath(P, frac)` 로 앞부분만 그린다. 거실 2.5초, 복도·부엌 각 0.45초(한 박). 선은 #E3583C 5px + 먹선 3px 를 (3px, 3px) 어긋나게. 제품 아이콘(지름 105px)을 경로 끝 점에 놓는다 | 없음 |
| 방사선 바탕 | 없다. CSS 로 된다 | `repeating-conic-gradient(from 0deg at 50% 60%, #E1AC36 0 7.5deg, #EEC660 7.5deg 15deg)`. 아주 천천히 돈다(초당 1°) | 없음 |
| 붓글씨 제목 | 붓글씨 글꼴이 없다 | 한국어 · Pretendard SemiBold 110px, 먹색 #2A2324, 기울기 −8°(`skewX`), 오른쪽 아래 노랑 #E1AC36 그림자 4px. 아래에 `HAND.ribbon(ctx, P, u => 3 + 7 * Math.sin(Math.PI * u), { color: '#E5603F' })` 밑줄을 0.4초에 긋는다 | 붓글씨의 굵기 변화와 리듬 |
