# 스케치북 하루 · 손그림 스티커 동물극 — 분석 노트

> 손으로 그린 수채·색연필 그림(동물·꽃·채소·바다 생물·집)을 오려 낸 스티커로 만들어, 크림색 종이 위에서 하루(아침 → 정원 → 바다 → 해 질 녘 → 밤 → 끝 인사)를 보여 주는 78초 영상. 펜 선 하나가 언덕을 긋고, 캐릭터가 하나씩 튀어나와 무대를 채운다. 가운데 10초(21.5~31.5초)만 박자에 맞춰 빠르게 바뀌는 낱말 카드 구간이다. 어린이 교육, 그림책, 손그림 작품 소개, 따뜻한 브랜드 이야기에 맞는다. 손그림 · 스티커 오려 붙이기 · 그림책 장면극.

출처 · pm:abderrahmen-g-9e8ed0. 작성자의 프롬프트는 약 500자다. 스타일(입력한 손그림 사진을 최대한 쓴다, 즐겁고 장난스럽게)과 소리를 화면에 맞추라는 요구, 예시 영상을 참고하되 베끼지 말라는 요구만 정했다. 주제, 장면 구성, 길이, 색, 글자, 카메라는 비어 있다. 이 노트는 영상 프레임(1초 간격 시트 4장, 대표 구간과 전환은 0.25~0.5초 간격으로 직접 뽑은 60장)을 보고 썼다.

## 1. 본질

- 바탕은 따뜻한 크림색 수채 종이(#F9EBD0 근처, 가장자리 #E1D3BA 근처)다. 종이 결이 보이고 네 모서리가 조금 어둡다. 첫 0.3초만 결 없는 밝은 종이(#FAF2E5 근처)다.
- 모든 사물은 실제 종이에 그린 그림을 사진으로 찍어 오려 낸 것이다. 캐릭터마다 흰 종이 테두리(두께 약 6~10px)가 남아 있어 스티커처럼 보인다. 수채 번짐, 색연필 결, 검은 펜 외곽선이 그대로 있다.
- 무대는 화면 아래의 녹색 언덕(#BFC898 ~ #A6B784 근처)이다. 언덕 꼭대기는 세로 70.6% 지점이고 양 끝은 84~89% 까지 내려간다. 오른쪽 위 가장자리에 웃는 해(#D4B503 근처, 대부분 화면 밖, 보이는 부분은 가로 90~100%, 세로 13~61%)가 걸려 있다. 왼쪽 위에 펜으로 그린 작은 구름 2개(폭 약 70px)가 있다.
- 장면은 일곱 개이고 장마다 바탕색이 다르다. 크림 종이 → 여러 파스텔 카드 → 크림 종이 정원 → 하늘색 바다(#BADBDC ~ #99BCC6 근처, 위에서 빛줄기) → 분홍빛 해 질 녘 → 짙은 남색 밤(#141A42 ~ #222C5E 근처) → 파스텔 햇살 무늬 → 거의 검정(#16110E 근처).
- 글은 손글씨 느낌의 굵은 마커 글꼴 한 가지다. 문장은 짧고 화면마다 한 줄만 있다.

## 3. 움직임

- 등장은 거의 모두 "튀어 오름"이다. 캐릭터가 언덕선 아래에서 솟아오르며 조금 지나쳤다가 제자리에 선다(약 0.3초). 놀람 선 3~4개와 의성어 한 낱말이 함께 뜬다.
- 캐릭터는 선 뒤에도 쉬지 않는다. 몸이 위아래로 조금 늘었다 줄고(진폭 2~4%), 좌우로 조금 기운다. 같은 박자로 움직이지 않고 저마다 위상이 다르다.
- 0~21초는 조용하다(움직임 세기 평균 2.6). 한 번에 하나만 새로 나타난다. 20초에는 약 16개가 동시에 보이지만 새로 움직이는 것은 1~2개다.
- 21.5~33초는 화면 전체가 바뀌는 하드 컷이 0.5~1초마다 온다(평균 23.2).
- 34~43초 정원은 아래에서부터 쌓인다. 요소 수가 1개 → 30개 이상으로 9초 동안 늘어난다(세기 3 → 20 으로 오른다).
- 바다에서는 해파리가 위아래로 천천히 오르내리고 물고기가 가로로 지나간다. 공기 방울 원(펜 선)이 떠오른다.
- 글자는 모두 "써지는" 등장이다. 손글씨 순서대로 글자 하나씩 약 0.1~0.2초 간격으로 나타난다. 지울 때는 새가 먹거나 흐려진다.
- 카메라 이동은 두 번뿐이다. 32~34초 해바라기에서 물러나기, 그리고 낱말 카드 구간의 큰 확대(원 안 그림을 4~8배로 보여 주기)다.

## 4. 전환

- 장면 사이 전환은 장마다 다르다. 같은 방식을 두 번 쓰지 않는다.
  - 21.5초 아침 → 카드 · 하드 컷.
  - 31.5~32.0초 카드 → 해바라기 · 원 안의 해바라기가 커지며 화면을 덮는다(확대 일치 전환).
  - 43.5초 정원 → 바다 · 오려 낸 물결 그림이 0.5초 동안 왼쪽에서 오른쪽으로 닦는다.
  - 53.5~54.5초 바다 → 해 질 녘 · 옅은 크림으로 바랜 뒤 밑그림 → 색칠로 녹아 바뀐다(1초).
  - 57.25~58.0초 해 질 녘 → 밤 · 물결 모양 가장자리의 밤 하늘이 위에서 아래로 내려와 덮는다.
  - 65.5초 밤 → 끝 인사 · 원이 가운데에서 0.25초 만에 열린다.
  - 75.5~76.5초 끝 인사 → 검정 · 원이 병아리 하나로 좁혀지며 닫힌다(그림책의 마지막 장 같은 원 닫기).
- 소리의 쉼과 전환이 겹친다. 1.5초 무음 뒤에 해 질 녘이 열리고, 짧은 무음 두 번 뒤에 원이 열린다.

## 5. 타이포

- 글꼴은 손글씨 느낌의 굵은 마커 글꼴 하나다. 소문자만 쓴다. 획 끝이 둥글고 굵기가 고르다. 검정(#1A1A1A 근처)이고 밤 장면과 끝 표기는 흰색이다.
- 크기 단계는 다섯 개다. 의성어 약 2%, 작은 윗줄·해 질 녘 문장 3~4%, 끝 인사 두 줄 약 8%, 카드 낱말 약 10%, 제목 약 16% (화면 높이 대비).
- 위치 · 큰 글은 가로 가운데. 해 질 녘 문장만 왼쪽 위(가로 5%, 세로 10%)다.
- 문장은 짧다. 인사말 한 줄, 다섯 낱말로 나눈 문장 하나, 해 질 녘 한 줄, 밤 인사 한 줄, 끝 인사 두 줄, 끝 표기. 화면에 한 번에 한 줄만 있다.
- 끝 표기 옆에만 작은 분홍 하트가 붙는다. 색 강조는 이것 하나다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 22.0~31.5초 낱말 카드. 위쪽 55% 는 단색 파스텔 바탕, 아래는 꼭대기가 세로 55% 에 걸린 지름 약 3000px 원 안에 손그림 한 장을 4~8배 확대해 보여 준다. 가운데 위(세로 30~40%)에 낱말 하나(폭 약 15%, 높이 약 10%)가 마디 첫 박에 튀어나온다. 바탕색과 원 안 그림은 1초 → 0.5초 간격으로 빨라지며 바뀐다. 동시에 보이는 요소는 바탕·원·낱말·작은 스티커 하나의 4개다. 원 안이 확대된 손그림이 아니거나 바뀜이 박자를 따르지 않으면 이 영상이 아니다.
- 12초 판 압축 예 · 0~1.5초 펜 선이 언덕을 긋고 칠해진다. 1.5~4.0초 캐릭터 5개가 0.5초마다 튀어 오른다(원본 10~21초를 줄인 것). 4.0~9.0초 낱말 카드 다섯 장(마디 2.0초 대신 1.0초 간격, 마지막 2초는 0.5초 간격 바탕 교체). 9.0~10.0초 원 안 그림이 커지며 다음 장면을 덮는다. 10.0~12.0초 캐릭터 타원 + 끝 문장 한 줄 + 원 닫기. 정원·바다·해 질 녘·밤은 뺀다.
- 손그림 사진을 오려 흰 테두리를 남긴 스티커. 사용자가 준 그림이 그대로 주인공이 된다.
- 펜 선 하나로 무대를 긋고 시작하는 첫 3초.
- 등장 하나마다 의성어 한 낱말 + 놀람 선. 작은 소리 효과와 1:1 로 맞출 수 있다.
- 장면마다 바탕색을 바꾸고 전환 방식을 한 번씩만 쓰는 구성.
- 처음 나온 캐릭터를 끝에서 모두 다시 불러 타원으로 세우는 마무리.
- 원으로 열고 원으로 닫는 끝맺음.

## 7. 함정

- 화면의 제목, 인사말, 낱말 카드 문장, 해 질 녘 문장, 밤 인사, 끝 인사, 끝 표기는 원작의 것이다. 옮기지 않는다. 역할(제목 한 낱말, 인사 한 줄, 다섯 조각 문장, 끝 문장 두 줄)만 가져온다.
- 원작 그림은 작성자가 넣은 손그림 사진이다. 가져다 쓰지 않는다. 같은 효과를 내려면 사용자에게 직접 그린 그림을 받거나 AI 일러스트(글자·로고 없이)로 새로 그린다.
- 78초는 길다. 0~21초의 느린 등장을 그대로 옮기면 12~20초 판에서는 앞 절반이 비어 보인다. 등장 간격을 0.5초로 줄이고 동물 수를 5~6개로 줄인다.
- 원 안의 큰 확대는 원본 그림의 해상도가 높아야 한다. 4~8배 확대에 2000px 이상 그림이 필요하다. 작은 그림을 크게 키우면 흐려진다. AI 일러스트는 확대할 부분만 1024~1536px 로 따로 그린다.
- 낱말을 한국어로 옮기면 한 낱말이 2~4글자다. 낱말 카드 다섯 장이 한 문장을 이루도록 어절 단위로 끊는다(어절마다 1장). 글자 높이는 140px 아래(화면 높이의 약 10~13%)로 둔다.
- 캐릭터가 많아지면(20초 16개, 43초 30개 이상) 모두 따로 흔들어야 산만하지 않다. 같은 위상으로 흔들면 기계적으로 보인다.
- 장면마다 전환을 바꾸는 것은 구현 부담이 크다. 12초 판에서는 하드 컷 + 원 확대 + 원 닫기 3가지만 쓴다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

글꼴은 Pretendard Regular·SemiBold 뿐이다. 값은 1920x1080 기준이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 손그림 캐릭터·꽃·채소 | 실제 종이 그림의 수채 번짐과 색연필 결 | AI 일러스트(codex-image)로 캐릭터를 그린다. 수채 + 검은 펜 외곽선, 마젠타 바탕, 글자·로고 없음. 한 장에 4~6개를 그리고 `scripts/key.py --split` 으로 따로 자른다. 캐릭터 키 185~260px 로 쓴다 | 한 사람이 그린 그림의 고른 손맛 |
| 스티커 흰 테두리 | 오려 낸 종이 가장자리 | 자른 PNG 에 CSS `filter: drop-shadow(0 0 0 #fff)` 를 여러 번 겹쳐(반경 3px 씩 4번) 흰 테두리 8px 를 만들고, `drop-shadow(2px 3px 2px rgba(0,0,0,.18))` 로 그림자를 더한다 | 가위 자국의 불규칙함 |
| 크림 수채 종이 | 실제 종이 스캔 | `texTile(seed, { mc: '150,120,80', mottle: .04, dark: .05, light: .05, fibers: 200, specks: 25 })` 를 바탕 #F9EBD0 위에 깐다. 네 모서리를 `radial-gradient(transparent 60%, rgba(120,90,50,.12))` 로 어둡게 한다 | 큰 얼룩의 자연스러움 |
| 펜으로 긋는 언덕선 | 손 떨림 있는 선 | 언덕 윤곽 점(꼭대기 세로 70.6%, 양 끝 84~89%)을 만들고 `HAND.ink(ctx, P, { frac, w: 4, color: '#1A1A1A', key: 'hill', B: 0 })` 로 1.0~2.4초에 `frac` 0 → 1 로 긋는다 | 없음에 가깝다 |
| 녹색 수채 언덕 칠 | 붓 자국 | `HAND.washPlate(1920, 400, P, { seed: 1, color: '#A6B784', layers: 30, alpha: .04 })` 를 로드 때 굽고, `HAND.trace` 로 만든 경로에 `clip` 한 뒤 2.5초에 0.4초 동안 왼쪽에서 오른쪽으로 공개한다 | 실제 물감 고임 |
| 손글씨 마커 글꼴 | 손글씨 글꼴이 없다 | Pretendard SemiBold. 제목 140px, 카드 낱말 120px, 끝 문장 90px, 의성어 24px. 자간 -0.01em. 글자마다 회전 ±2° 와 세로 ±3px 어긋남을 씨앗 난수로 고정해 준다. 써지는 등장은 글자 하나씩 0.12초 간격으로 `opacity` 0 → 1 + `scale` 0.6 → 1 | 손으로 쓴 획의 굵기 변화 |
| 원 안 확대 그림 | 고해상도 손그림 사진 | AI 일러스트를 1536px 로 그려 원 안에 `clip-path: circle(1508px at 50% 2104px)` 로 넣는다(꼭대기 세로 55%). 그림 한 장에서 4배 확대한 다른 부분을 고른다. 외곽선은 SVG 원 stroke 4px #1A1A1A | 붓 자국을 크게 볼 때의 실재감 |
| 물결 닦기 전환 | 오려 낸 물결 그림 | AI 일러스트 물결 한 장을 `key.py` 로 자르고 폭 2400px 로 놓아 0.5초 동안 `translateX(-2400px → 1920px)` 로 지나가게 한다. 물결 뒤 영역을 같은 진행값으로 `clip-path: inset(0 0 0 X)` 로 바꾼다 | 물결 테두리의 종이 질감 |
| 햇살 무늬 바탕 | 수채로 칠한 빛줄기 | CSS `repeating-conic-gradient(from 0deg at 50% 50%, #F2C9A0 0 7.5deg, #F4EBD8 7.5deg 15deg)` 위에 파랑·연두·분홍 줄을 섞는다(줄 24개). 그 위에 `texTile` 결을 `multiply` 로 얹는다 | 붓질 가장자리의 번짐 |
| 원 열기·닫기 | 없다 | `clip-path: circle(R at X Y)`. 열기 0.25초 R 0 → 1200px. 닫기 0.8초 R 1200 → 150px(병아리 중심, 가로 50%, 세로 80%) → 0 | 없음 |
| 밤 창문 불 | 빛 번짐 | 창문 자리에 #FFE9A0 사각형 + CSS `filter: blur(12px)` 복사본을 겹친다. 61~64초 대신 12초 판에서는 0.2초 간격으로 켠다 | 수채 위 빛의 부드러움 |
