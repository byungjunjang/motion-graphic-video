## 3. 움직임

- 가장 많이 쓰는 움직임은 오른쪽으로 가는 느린 수평 패닝이다. 25~50초의 25초 동안 거의 끊기지 않는다. 화면 폭 기준 초당 약 8~12%를 간다. 패닝하는 동안 세기는 5.5~10 사이로 고르다.
- 사물은 패닝 방향 앞쪽에 미리 그려져 있다가 화면 안으로 들어온다. 화면 안에서 생기는 사물(불, 전구, 로켓 연기)은 작게 부풀며 나타난다(약 0.3~0.5초).
- 인물은 거의 걷지 않는다. 고개, 팔, 가리키기, 손 흔들기처럼 작은 동작만 한다. 동작은 1~2초에 하나다.
- 카메라 다가가기는 이야기의 문턱에서만 쓴다. 공책 → 들판(4.5~6.8초), 달 → 행성(55~58초), 언덕 → 알(70~72초). 물러나기도 문턱에서만 쓴다. 생물 → 행성 → 공책(97~99.5초).
- 빛은 숨 쉬듯 커졌다 작아진다. 모닥불, 알, 생물의 빛 번짐이 1~2초 주기로 밝기가 바뀐다.
- 흩어짐과 다시 모임은 한 번뿐이다. 생물이 작은 네모 입자 수백 개로 부서져 위로 퍼지고(87~90초), 3초 뒤 같은 자리로 모여 커진 모습이 된다.
- 끝 장의 연필은 실제로 글씨를 쓰는 듯 끝이 획을 따라간다. 이름 한 줄에 약 2초가 걸린다.

- 글씨는 끝이 둥근 가는 단선 손글씨 모양이다. 색은 짙은 갈회색(#423b29 근처)으로 연필 자국처럼 보인다. 가운데 정렬이다.
- 크기 · 대문자 높이 약 112px(화면 높이의 10.4%), 줄 폭 약 458px(화면 폭 24%). 세로 위치는 약 63%다. 두 도장(세로 27~46%) 아래에 있다.
- 도장 · 손바닥(약 140x194px)과 생물(약 290x176px)이 가로 35~66% 에 나란히 선다. 색은 붉은 흙빛(#b06548 ~ #c87156 근처)이고 종이 결이 비친다. 사람과 생물이 나란히 선다는 뜻을 그림으로만 전한다.
- 원래 글의 이름은 실존 제품 이름이다. 옮기지 않는다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 72.5~74.5초. 밤 배경, 뒤의 둥근 불빛 번짐, 가운데 흰 알(화면 폭 약 32%)에 금이 가고 윗껍질이 오른쪽 위로 날아간다. 알 속에서 광선 약 14줄이 부채꼴로 퍼지고 흰 조각 8~10개가 뜨며, 주인공 생물의 머리(폭 18%)가 아랫껍질 위로 나온다. 알이 깨지는 순간과 광선이 없으면 이 영상이 아니다.
- 12초 판 압축 예 · 0~1.5초 공책 위에 연필이 행성을 그린다. 1.5~2.5초 종이 속으로 다가간다. 2.5~6.0초 아이 → 불 → 마을 → 도시를 오른쪽 패닝 하나로 지나간다(장마다 약 0.9초, 하늘색이 낮 → 저녁 → 밤으로 바뀐다). 6.0~6.5초 흰 번쩍임. 6.5~9.5초 알이 깬다(대표 장면). 9.5~10.5초 화면이 공책 한 장으로 물러난다. 10.5~12초 두 도장과 이름 한 줄. 동굴, 바다, 달, 흩어짐, 낮의 놀이는 뺀다.
- 처음과 끝을 같은 공책과 연필로 감싸는 틀. 그림 세계 전체가 누군가 그린 한 장의 그림이라는 뜻이 된다.
- 빛을 이어 달리게 하는 구성. 장마다 빛나는 사물 하나(불, 횃불, 등대, 전구, 불빛망, 알)를 두면 발전사가 한 줄로 읽힌다. 대상의 역사도 "그 시대의 빛나는 것"으로 고를 수 있다.
- 장소는 두고 하늘색만 바꿔 시간을 보내는 방법.
- 끝 장의 도장 두 개. 사람과 대상을 같은 크기·같은 색의 도장으로 나란히 둔다. 글 없이 관계를 보여 준다.
- 큰 타격에 맞춘 사건 배치. 불씨(16.03초), 알이 깨짐(72.93초), 도장(102.04초, 103.19초)이 박과 맞는다.

## 7. 함정

- 끝의 이름은 실존 제품 이름이고, 주황 네모 생물은 실존 마스코트를 닮은 모양이다. 둘 다 그대로 쓰지 않는다. 대상의 상징을 새로 정한다(가상 이름 한 줄, 단순한 도형 생물).
- 행성의 대륙은 실제 지도 윤곽이다. 지도를 그리려면 윤곽 자료가 필요하다. 지도 없이 둥근 파랑 원에 연두 얼룩 3~4개로 대신한다.
- 108초를 12초로 줄이면 장이 너무 많다. 장을 늘어놓으면 슬라이드처럼 보인다. 장 전환을 컷으로 하지 말고 오른쪽 패닝 하나에 장을 늘어놓는다. 패닝 속도는 화면 폭 기준 초당 30~40%로 올린다.
- 장마다 인물과 소품을 새로 그려야 한다. 그림 양이 많다. 12초 판은 소품을 장마다 1~2개(불, 초가, 빌딩)로 줄이고 인물은 같은 아이 하나를 계속 쓴다.
- 파스텔과 종이 결을 빼면 평범한 벡터 그림이 된다. 모든 면에 종이 결을 깔고, 채도를 낮게 둔다(하늘 띠 #bac4bc · #d1ac94 · #e6c2a1 · #e9cba1).
- 빛 번짐을 너무 세게 하면 화면이 하얗게 뜬다. 번쩍임은 두 번 이하, 0.3~0.5초로 쓴다.
- 말이 없는 영상이라 한국어 소개로 옮기면 정보가 모자라다. 끝 장에 이름 한 줄과 짧은 구호 한 줄을 더하는 정도로만 늘린다. 장마다 설명 자막을 넣으면 이 영상의 결이 깨진다.
- 한국어 손글씨 글꼴이 없다. 끝 이름은 Pretendard Regular 120px 를 연필 획처럼 한 글자씩 드러낸다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 글꼴은 Pretendard Regular·SemiBold 뿐이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 공책과 책상 | 종이 두께, 책등 그림자, 나뭇결 | canvas 에 책상 #6e513d 판, 그 위에 공책 두 장(가로 0~78%, 세로 13~87%) #ede6d4. 책등 쪽 폭 120px 를 #ded7c5 로 어둡게 하는 선형 그라데이션. 종이 결은 `texTile(seed, { mc: '120,110,90', mottle: .03, fibers: 120, specks: 20 })` 를 공책 위에 깐다 | 종이의 휨과 깊이 |
| 연필이 그리는 행성 | 손의 떨림과 칠 | `HAND.ink(ctx, P, { closed: true, w: 3, amt: 1.6, frac: u })` 로 원 윤곽을 u(0→1, 0.8초)만큼 긋는다. 칠은 `HAND.paint(ctx, P, { fill: '#9fc4d8', tex: [{ k: 'pencil', color: '#6f9fbf', alpha: .35 }] })`. 대륙은 연두 얼룩 3~4개를 같은 방식으로 | 실제 연필 압력의 농담 |
| 낙서 인물 | 장마다 다른 동작과 표정 | SVG 로 두 등신 인물 하나를 부품(머리 원, 사다리꼴 몸, 막대 다리, 점 눈)으로 만들고 팔 각도만 t 의 함수로 돌린다. 외곽선 2px #4a3a2a. 같은 인물을 끝까지 쓴다 | 장마다 다른 의상·소품 |
| 많은 소품과 장면 배경 | 108초 동안 수십 개의 소품 | AI 일러스트(codex-image, 글자·로고 없이)로 장면 띠 하나를 가로로 길게 그린다(예 5760x1080, 불 → 초가 → 빌딩). 마젠타 바탕으로 그린 소품은 `scripts/key.py --split` 으로 잘라 따로 움직인다 | 소품마다 따로 생기는 순서 |
| 파스텔 띠 하늘과 시간 바뀜 | 그라데이션이 아니라 띠 | canvas 에 가로 띠 4개(#bac4bc · #d1ac94 · #e6c2a1 · #e9cba1)를 `HAND.wobble` 로 가장자리만 흔들어 그린다. 밤 판(#1a2542)을 위에 두고 투명도를 0.5~1초에 0 → 1 로 올린다 | 띠 사이 물감 번짐 |
| 빛 번짐과 방사 광선 | 부드러운 빛, 광선의 결 | canvas 의 `createRadialGradient` 로 지름 600px 빛(가운데 #fff6dc 80% → 0%)을 `globalCompositeOperation = 'screen'` 으로 얹는다. 광선은 가늘고 긴 삼각형 14개(각 폭 3~5°, #fff2cc 25%)를 알 중심에서 부채꼴로 | 광선의 미세한 흔들림 |
| 알이 깨지는 순간 | 껍질 조각의 회전과 무게 | SVG 로 알을 톱니 선 하나로 위아래 두 조각으로 나눈다. 72.5초 금(선 0.2초에 그어짐), 73.0초 윗조각이 0.4초에 오른쪽 위로 (+330px, -200px) 날며 25° 돈다. 흰 삼각 조각 10개를 같은 시각에 바깥으로 흩는다 | 껍질의 입체감 |
| 흩어졌다 모이는 생물 | 입자 수백 개 | canvas 에 생물 모양 안의 격자점(간격 12px, 약 400개)을 네모로 찍고, 87~90초에 각 점을 씨앗별 위쪽 방향으로 퍼뜨린 뒤 91.5초에 원래 자리의 1.4배 위치로 모은다 | 입자 빛의 깊이감 |
| 손글씨 이름 | 손글씨 글꼴이 없다 | Pretendard Regular 120px, 색 #423b29. 글자마다 왼쪽에서 오른쪽으로 `clip-path: inset()` 를 0.2초에 연다. 연필 그림(SVG)의 끝을 열리는 가장자리에 붙인다 | 획 순서대로 쓰는 맛 |
| 도장 두 개 | 종이 결이 비치는 찍힘 | SVG 도형을 #b06548 로 칠하고 `mix-blend-mode: multiply` 로 종이 위에 얹는다. 찍히는 순간 크기 1.08 → 1.0(0.15초) | 잉크가 덜 묻은 얼룩 |
