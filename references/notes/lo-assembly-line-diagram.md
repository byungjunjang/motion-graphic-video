## 3. 움직임

- 원래 글의 규칙(벨트는 멈추지 않는다, 화물이 닿으면 방이 일한다, 표지는 사슬로 떨어져 한 번 튄다, 반복이 웃음, 시계로 시간을 줄인다)은 화면과 맞다.
- 영상에서 확인한 점 · 큰 카메라 이동(움직임 세기 40 이상)이 방과 방 사이에만 몰려 있다(10.5초, 15초, 18.5초, 22~24.5초, 35.5~36.5초, 43~44초, 47.5초). 방 안에서는 3~10 으로 조용하다. 이동 → 일하는 방 → 이동의 맥박이 약 3~10초마다 돈다.
- 범례 표지는 2초 간격(29.0·31.0·33.0초)으로 하나씩 떨어진다. 한꺼번에 내지 않는다.
- 끝 달리기는 한 주기 약 0.62초다. 원래 글에 다리 계산이 자세히 있다.

## 7. 함정

- 간판 제목, 방 이름, 범례 낱말, 자막 문장, 끝 명판의 제작 표기는 원작의 것이다. 옮기지 않는다. 역할(방 명판, 범례 표지, 자막 상자, 끝 명판)만 가져온다. 끝 명판에 실존 회사·서비스 이름이 있다. 쓰지 않는다.
- 원작 명판은 외국어 두 가지를 나란히 쓴다. 우리 영상에서는 "비유 기계 이름 · 실제 이름"을 둘 다 한국어로 쓴다. 두 이름 사이 세로 막대 형식만 가져온다.
- 범례 색을 남색 바탕 위에 두면 청록 #288278 이 묻힌다. 범례 화물과 표지는 방 안 크림 위에 둔다. 관은 남색 위에 두되 색 관 둘레에 크림 1~2px 테를 준다.
- 방을 실루엣 가장자리까지 채우면 실루엣이 사라진다(원래 글의 함정). 방과 외곽선 사이 남색 띠를 1920 기준 45px 이상 둔다.
- 크게 물러날 때 선 굵기를 그대로 두면 회색 덩어리가 된다. 원본은 물러난 그림에서 작은 일꾼과 글자를 빼고 방 윤곽만 남긴다(48.0초).
- 움직임 세기가 방 안에서 3~10 으로 내려간다. 방 안에서도 벨트와 기계 반복 동작을 늘 돌려 2초 넘게 멈춘 화면을 만들지 않는다. 멈춘 화면은 제목과 끝 두 곳뿐이다.
- 사람 몸이 아닌 대상(건물, 기계, 도시)으로 바꿀 때도 실루엣 하나를 정해 처음부터 끝까지 같은 실루엣 안에서 움직인다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 전체 그림은 정면 단면 하나라서 대부분 SVG 로 그대로 된다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 단면 실루엣과 방들 | 없다. SVG 로 그대로 된다 | 한 장의 큰 SVG(약 3840 x 7200px)에 실루엣 외곽(연어색 #E69678 두 겹 띠, 굵기 20px), 안쪽 남색 #1E2850, 방 크림 #F0E6DC 를 그린다. 방 테두리는 황토·청록·주홍 중 하나로 6px. 카메라는 SVG 전체에 거는 이동·확대 변환 하나 | 없음 |
| 거리마다 바뀌는 선 굵기 | 확대하면 선이 같이 굵어진다 | 모든 선에 `vector-effect: non-scaling-stroke` 를 주고, 굵기를 확대율 z 에 대해 3px · z^0.6 으로 seek 에서 넣는다. z 가 0.3 아래면 일꾼·글자 묶음의 `display` 를 끈다 | 없음 |
| 기계 반복 동작 | 없다 | 기계마다 주기를 박에 맞춘다(마디 1.977초의 1/2·1/4). 누름은 0.12초 내려가고 0.2초 올라간다. 롤러는 회전 각을 t 에서 바로 계산 | 없음 |
| 얼굴 없는 일꾼 | 없다 | SVG · 머리 원 지름 18px, 몸 직사각 22 x 34px, 흰 작업복 + 황토 안전모. 동작은 2프레임 자세 두 장을 0.25초마다 바꾼다 | 없음 |
| 사슬로 떨어져 튀는 표지 | 없다 | DOM 표지. 위 화면 밖에서 0.25초에 내려와 아래로 12px 지나쳤다가 0.15초에 돌아온다. 사슬은 SVG 선 2개. 두 번째 표지는 반 박(약 0.25초) 늦게 | 없음 |
| 방향 흐림 휙 이동 | 그림 전체가 한 방향으로 번진다 | 휙 이동하는 0.4초 동안 SVG 전체에 `feGaussianBlur stdDeviation="0 40"`(세로 기울기) 또는 `"40 0"`(가로)을 걸고, 위에 속도선 20개(굵기 3px, 크림, 불투명도 0.5)를 한 번 그린다. 겹상을 쌓지 않는다 | 실제 카메라 흐림의 질감 |
| 둥근 창 | 없다 | 바깥 장면 층에 `clip-path: circle()` 을 주고 반지름을 0 → 300px 으로 0.3초, 테두리 황토 12px. 창 속 장면(거리와 버스)은 SVG 평면 그림 | 없음 |
| 달리는 사람 도식 | 다리 계산이 필요하다 | SVG 몸통 + 두 마디 다리. 무릎 각은 두 뼈 길이로 계산하고 늘 앞으로 굽힌다. 디딤발 끝을 땅 줄무늬와 함께 뒤로 옮긴다. 주기 0.62초, 몸 위아래 흔들림 26px. 멈춤은 앞다리가 뻗은 공중 자세 | 손으로 다듬은 동작의 맛 |
| 종이 결 | 실제 종이 | `texTile(seed, { mc: '150,130,110', mottle: .03, dark: .03, light: .04, fibers: 80, specks: 10 })` 를 바탕 #E6DCD2 위에 곱하기로 깐다 | 종이 얼룩의 자연스러움 |
| 명판·표지 글자 | 원작은 압축 고정폭 대문자 | 한국어는 Pretendard SemiBold, 명판 26px, 범례 표지 34px, 제목 간판 76px. 번호는 InterVariable 굵기 700 을 황토 원(지름 34px) 안에 | 압축 글꼴의 공장 표지 인상 |
