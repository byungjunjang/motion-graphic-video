# 16비트 픽셀 롤플레잉 · 저장 파일로 들어가는 기억 — 분석 노트

> 1990년대 중반 가정용 게임기 롤플레잉처럼 보이고 움직이는 55초 영상. 320x180 픽셀 화면, 적은 색, 한 글자씩 찍히는 대화 상자, 저장 파일 메뉴가 이야기를 끌고 간다. 밤 회랑의 저장 수정 앞에서 파일 세 개를 하나씩 열면 각각 다른 시대의 화면(초록 네 톤, 검은 밤의 8비트, 노을 전투)으로 들어간다. 전투에서 동료를 잃은 뒤 화면 색이 무너지고, 새 파일을 저장하고, 큰 문을 올려다본 뒤 빛 속으로 걸어 들어간다. 게임 예고편, 한 해 돌아보기, 추억·성장 이야기에 맞는다.

## 3. 움직임

- 원래 글의 수치(걸음 초당 8장, 깜빡임 초당 12번, 창 0.3초, 커서 1px 흔들림, 글자 초당 38~40자)는 화면과 맞다.
- 영상에서 확인한 점 · 정수 픽셀 이동이라 스크롤·기울기 중에도 움직임 세기가 4~13 에 머문다. 큰 값은 전부 전환(모자이크, 소용돌이, 흰 화면)에서 나온다.
- 문 기울기(42.0~44.5초)는 약 2초 오르고 0.5초 머문 뒤 0.5초에 내려온다. 원래 글은 화면 세 배 높이를 정했는데, 프레임으로는 높이를 정확히 재지 못했다(두세 배로 보인다).
- 색이 무너질 때 화면은 거의 안 움직인다. 바뀌는 것은 팔레트뿐이다. 세 단계가 32.0, 33.0, 33.75초에 끊어서 온다. 섞이며 바뀌지 않는다.
- 끝의 색 넘침(48.0~49.0초)은 주인공 쪽에서 바깥으로 간다. 창의 파랑, 체력·기력 막대의 초록·청록, 초상의 피부색, 벽의 빨간 깃발 순서로 색이 돌아온다.

## 4. 전환

- 원래 글의 전환 다섯 종류가 모두 나온다. 썸네일 확대 + 모자이크(10.0~11.0초), 모자이크 교차(17.5~18.5초, 정점 18.0초에서 팔레트 교체), 조우 소용돌이(25.5~26.5초), 흔들림(29.2초), 팔레트 단계(0~1초, 32~34초).
- 영상에서 확인한 점 · 소용돌이 직전 25.0~25.5초에 화면 전체가 약 5° 기울어 돈다. 소용돌이 안의 색은 앞 장면(밤 숲)의 초록과 다음 장면의 주황이 섞인 회녹색이다.
- 흰 화면(49.5~50.4초)은 빛 속으로 들어간 끝이다. 흰색에서 끝 카드로 바로 바뀐다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 27.0~35.5초의 "옆에서 본 전투(적 왼쪽, 동료 오른쪽, 아래 파란 전투 창) → 큰 공격 → 동료가 깜빡이다 사라지고 천 조각만 남음 → 움직임 없이 팔레트만 세 단계로 무너지는(노을 → 세 톤 청회색) 정지"다. 적은 화면 높이의 51%, 동료는 20%, 전투 창은 아래 22%. 색이 무너질 때 아무것도 움직이지 않고 소리가 끊기는 것이 빠지면 이 영상이 아니다.
- 12초 판 압축 예 · 0~1.5초 밤 회랑 옆 스크롤(주인공 높이 1/6, 수정이 앞에), 1.5~2.5초 파일 선택 창이 0.3초에 들어오고 커서가 칸을 고른다, 2.5~3.3초 썸네일 확대 + 모자이크로 첫째 기억(초록 네 톤), 3.3~4.3초 걷기 + 대화 한 줄, 4.3~5.1초 조우 소용돌이, 5.1~6.6초 전투 1.5초(방벽, 공격, 사라짐), 6.6~8.6초 색이 무너지는 정지 2초(단계 3번, 무음), 8.6~9.6초 현재로 돌아와 새 파일 저장 완료, 9.6~11.0초 문 앞에서 빛 한 줄이 넓어지며 색이 돌아온다, 11.0~12.0초 흰 화면 → 끝 카드. 둘째 파일(모닥불)과 문 기울기는 뺀다.
- 저장 파일 메뉴를 장 목차로 쓰는 구조. 썸네일을 키워 들어가고, 돌아오면 칸 하나가 는다.
- 기억마다 다른 게임 시대의 팔레트. 오래된 기억일수록 색과 해상도가 낮다.
- 상실은 움직임이 아니라 팔레트로 보여 준다.

## 7. 함정

- 화면의 제목, 인물 이름, 장소 이름, 대사, 메뉴 낱말, 끝 표기는 원작의 것이다. 옮기지 않는다. 역할(제목 한 줄, 파일 이름표, 대사 한 줄, 행동 메시지)만 가져온다. 끝 표기에 실존 회사·모델 이름이 있다. 쓰지 않는다.
- 실존 게임기·게임의 화면 장식(특정 휴대용 기기의 테두리, 유명 작품의 창 모양·효과음·메뉴 문구)을 닮게 그리지 않는다. 초록 네 톤은 쓰되 우리 색 값을 조금 옮긴다(예 · #D2D8A0, #90A060, #4A5C38, #1C2818).
- 한국어 대사는 픽셀 글꼴로 7픽셀 높이에 들어가지 않는다. 한국어는 12픽셀(약 72px) 이상이 필요하다. 대화 상자를 원본 높이(약 40픽셀)로 두고 한 줄 16자 이하, 2줄 이하로 쓴다. 상자가 아래 1/4 을 덮으므로 원래 글의 함정대로 땅 선을 상자 윗변 위에 둔다.
- 반투명 페이드를 한 번이라도 쓰면 이 스타일이 깨진다. 모든 밝기 변화를 팔레트 4단계로 바꾼다.
- 카메라·스크롤 값을 반올림하지 않으면 픽셀이 반 칸씩 번진다. seek 에서 카메라 위치를 원본 픽셀 정수로 자른다.
- 전투 장면에 실존 작품의 전투 창 배치(아래 파란 창의 칸 배열과 명령 네 개)를 그대로 옮기지 않는다. 명령 낱말과 배치를 우리 이야기에 맞게 바꾼다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 원본 320x180 픽셀 기준이고, 화면에는 6배로 키운다. 모두 canvas 2D 로 그린다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 320x180 화면과 정수 배 확대 | 없다. 그대로 된다 | canvas 320x180, `ctx.imageSmoothingEnabled = false`, CSS `width: 1920px; image-rendering: pixelated`. 모든 좌표를 `Math.round` 로 자른다. 첫째 기억 장은 160x90 canvas 에 그려 12배로 키운다 | 없음 |
| 스프라이트와 초상 | 손으로 찍은 픽셀 그림이다. AI 그림을 줄이면 뭉개진다(원래 글의 함정과 같다) | 작은 스프라이트(높이 20~34픽셀)는 코드 안에 팔레트 번호 문자열 배열로 직접 적는다. 걷기 4장, 마법 자세 1장, 무릎 1장. 머리카락은 큰 뾰족 2~3개로. 초상(32x32픽셀)은 AI 일러스트를 마젠타 바탕에 그려 `scripts/key.py` 로 자른 뒤 32x32 로 줄이고 장의 팔레트(16색)로 순서 디더 없이 가장 가까운 색에 맞춘다. 뭉개진 곳은 문자열 배열로 고쳐 쓴다 | 손으로 찍은 점 하나하나의 매력 |
| 배경(회랑, 성 실루엣, 노을, 숲) | 큰 그림이다 | 코드로 그린다. 하늘은 팔레트 4~5색 띠 사이를 4x4 순서 디더 행렬로 섞는다(띠 경계 폭 12픽셀). 성은 폭 12~24픽셀 사각 탑 + 위 성가퀴(2픽셀 간격). 기둥은 폭 16픽셀 단위를 반복. 옆 스크롤은 시차 4층(속도 비 0.25, 0.5, 0.75, 1) | 그림의 손맛과 우연한 세부 |
| 픽셀 글꼴 | 픽셀 글꼴 파일이 없다 | 라틴·숫자는 5x7 점 글꼴을 코드에 문자열로 정의한다(필요한 글자만). 한국어는 Pretendard SemiBold 12px 를 따로 만든 1비트 canvas 에 그리고 알파 0.45 이상만 점으로 남겨 320x180 화면에 찍는다(화면에서 72px, 140px 아래) | 손질한 픽셀 한글의 가독성 |
| 글자 찍기와 ▼ | 없다 | 한국어는 초당 14~16음절(라틴 기준 38~40자와 비슷한 읽기 속도). 다 찍히면 ▼ 를 초당 3번 깜빡인다. 커서 손가락은 초당 4번 1픽셀 위아래, 망설이는 장면에서 멈춘다 | 없음 |
| 팔레트 단계 페이드 | 반투명을 쓰면 안 된다 | 장마다 팔레트 배열 4벌(밝음 → 어둠, 또는 색 → 청회색)을 미리 만들고, 화면을 팔레트 번호로 그린 뒤 마지막에 번호 → 색 표만 바꾼다. 단계 사이 0.25~0.75초, 섞지 않는다 | 없음 |
| 모자이크 전환 | 없다 | 다 그린 화면을 블록 크기 b 로 평균 내어 다시 찍는다. 썸네일 확대는 b = 10 → 1 을 0.75초, 교차는 1 → 16 → 1 을 0.8초에, 정점에서 다음 장 팔레트로 바꾼다 | 없음 |
| 조우 소용돌이 | 화소마다 극좌표 비틀기가 필요하다 | `getImageData` 로 320x180(57,600화소)을 읽고 화면 중심 기준 각도에 (반지름 비율) x 강도를 더해 다시 찍는다. 강도 = 6 x s^1.6(s 는 0 → 1, 0.8초), 동시에 모자이크 b = 1 → 8, 마지막 0.3초는 4x4 순서 디더 문턱값으로 흰색이 칸마다 덮는다 | 없음 |
| 화면 흔들림 | 없다 | 8프레임 동안 3, 3, 2, 2, 1, 1, 0, 0 픽셀, 좌우 번갈아 | 없음 |
| 빛 넘침과 색 돌아옴 | 둥근 경계가 디더로 퍼져야 한다 | 문 가운데 흰 띠를 1픽셀(46.5초 자리)에서 52픽셀(48초 자리)로 넓히고 양옆 10픽셀은 노랑(#FDE867)과 흰색을 4x4 순서 디더로 섞는다. 색 돌아옴은 화소마다 주인공과의 거리 < 반지름 이면 색 팔레트, 아니면 청회색 팔레트. 경계 6픽셀은 디더 문턱값으로 섞는다. 반지름은 0 → 400픽셀을 1.0초에 | 없음 |
