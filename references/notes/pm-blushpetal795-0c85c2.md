# 채용용 자기소개 · 굵은 이름과 수치 네 장 — 분석 노트

> 한 사람이 채용 담당자에게 자신을 소개하는 15초 자기소개 영상이다. 검은 바탕에 아주 굵은 흰 산세리프와 주황 한 색을 쓰고, 바탕이 주황·밝은 회색으로 잠깐씩 바뀐다. 이름 → 원형 인물 사진 + 한 줄 정의 → 큰 수치 4장(숫자마다 도식) → 대표 작업의 점 지도와 단추 클릭 → 역량 카드 6장 → 주황 연락처 카드 순서다. 인물·팀 소개와 성과 지표 소개에 맞는다. 키네틱 타이포(kinetic typography) + 인포그래픽(infographic), 1초 단위의 빠른 교체.

## 1. 본질

- 바탕은 검정(#080808 근처, 화소의 45%)이 기본이다. 주황(#f85818 근처, 합쳐 약 16%)은 이름 속 점, 강조 낱말, 도식, 단추, 바탕 한 장과 끝 카드에 쓴다. 밝은 회색 바탕은 수치 한 장뿐이다(가운데 #F3F4F7, 모서리 #C4C5C8, 프레임에서 직접 잰 값).
- 글자와 숫자가 주인이다. 이름과 수치는 화면 높이의 약 18% 크기로 왼쪽에 두고, 오른쪽 절반에 숫자를 그림으로 바꾼 도식을 둔다.
- 인물 사진 자리는 두 곳이다. 2.3~4.35초에 원형 사진(지름이 높이의 약 54%)이 왼쪽에 크게 나오고, 끝 카드에 작은 원(약 18%)으로 다시 나온다. 사진은 주 재료가 아니다. 나머지 약 11초는 글자·숫자·도형뿐이다.
- 도식은 모두 단순 도형(점, 막대, 원호, 사람 아이콘, 둥근 카드)이다.
- 아닌 것 · 3D, 촬영 영상, 화면 녹화, 주황 외 포인트 색, 페이드 위주 전환, 긴 정지 장면.

## 3. 움직임

- 글자는 글자 단위로 마스크에서 올라온다(약 0.05초 간격). 이름 둘째 줄은 회색으로 먼저 오르고 흰색이 왼쪽부터 채운다.
- 계수기는 모두 약 0.6초다. 처음이 빠르고 끝이 느리다(ease-out). 옆의 도식이 같은 시간에 찬다.
- 점 지도의 점은 속 빈 회색 원과 주황 점 두 가지다. 빛줄기가 지나간 뒤에만 생긴다.
- 클릭은 세 단계다. 닿기 → 눌림(작아짐) → 고리 퍼짐(0.1초).

## 4. 전환

- 이름 → 사진 · 이름 속 주황 점이 커져 화면을 채우고, 다시 줄어 사진 테두리가 된다. 컷이 없다.
- 사진 → 수치 · 왼쪽 휩 팬(whip pan)과 흐림, 0.1초 검정.
- 수치끼리 · 사선 면이 오른쪽에서 0.08초 만에 덮는 와이프 3번(5.34, 6.34, 7.34초 시작). 면의 색이 다음 장 바탕이라서 바탕이 1초마다 주황 → 검정 → 밝은 회색으로 바뀐다.
- 수치 → 지도 · 8.50초 한 프레임 컷(밝은 회색 → 검정). 지도 → 카드 · 확대·흐림 뒤 검정 0.15초.
- 카드 → 끝 카드 · 높이가 다른 주황 기둥이 솟는 계단 와이프. 막대 도식과 같은 모양이다.

## 5. 타이포

- 이름과 수치는 아주 굵고 폭이 넓은 산세리프다. 이름은 대문자 두 줄, 왼쪽 정렬, 너비 약 58%다. 둥근 글자 하나를 주황 원으로 바꾼다.
- 숫자에 단위·기호(K+, %, +, →)를 같은 크기로 붙인다. 설명은 회색 보통 굵기 2~3줄(높이의 약 3%)이다.
- 강조는 낱말 하나나 마지막 줄을 주황 세리프 이탤릭으로 바꾼다(세 번). 한 번은 밑줄을 긋는다.
- 작은 라벨은 주황 점 + 회색 작은 산세리프다. 인사 한 줄과 끝 카드 오른쪽 한 줄은 세리프 이탤릭이다.

## 6. 가져올 것

- 이름 → 정의 한 줄 → 수치 4장 → 대표 작업 → 역량 카드 → 연락처 순서. 제품 소개라면 이름은 제품명, 사진은 제품 그림, 수치는 지표로 바꾼다.
- 수치 장의 형식. 큰 숫자(0.6초 계수) + 회색 설명 두 줄 + 숫자를 그림으로 바꾼 도식. 도식이 숫자와 함께 찬다.
- 다음 장의 바탕색으로 덮는 사선 와이프. 숫자 4개가 서로 다른 장으로 읽힌다.
- 주황 점 하나로 이름·화면 전체·사진 테두리를 잇는 연결.
- 강조 낱말 하나만 주황 세리프 이탤릭으로 바꾸는 규칙. 아래 가장자리에서 시간에 비례해 자라는 가는 진행 막대.

## 7. 함정

- 화면의 이름, 인사, 직무·소속·경력, 지명, 수치, 카드 낱말, 연락처는 모두 실존 인물의 것이다. 옮기지 않는다. 역할만 가져온다.
- 인물 사진이 없으면 원 안을 이니셜 두 글자(굵은 산세리프), 단색 실루엣, 또는 대상의 상징 아이콘으로 채운다. 주황 테두리와 도는 글자 띠는 그대로 둔다.
- 확인된 숫자가 4개 없으면 수치 장이 빈다. 숫자는 원문에서 확인한 것만 쓴다.
- 점 지도는 실제 지역의 점 분포다. 지도 자료가 없으면 지명 없는 추상 점 무리 3개로 그린다. 점이 수백 개라서 canvas 로 그린다.
- 수치 장이 1초씩이라 설명 줄을 읽을 틈이 없다. 30~40초로 늘리면 장마다 한 마디(2초)로 늘린다. 라벨·글자 띠·이름표(높이의 약 1.5~2%)는 한국어로 바꾸면 더 작아 보인다. 키운다.
