# 빛알 하나의 십만 년 출근길 · 그림책 과학 해설 — 분석 노트

> 얼굴이 있는 빛알 하나가 태양 중심에서 태어나 바깥으로 빠져나와 사람의 눈에 닿기까지를 따라가는 60초 과학 해설 영상. 보라 밤하늘 → 주황 빛 덩어리 속 붐비는 입자 떼 → 태양 단면과 큰 계수기 → 옆에서 본 대류층 → 우주 비행과 거리·시간 계기판 → 커다란 눈 → 노을 실루엣 순서다. 주인공이 처음부터 끝까지 같은 캐릭터이고, 숫자가 장마다 하나씩 세어 올라간다. 만화 의성어 폭발, 말풍선, 손글씨 주석이 재미를 맡는다. 과학·교육 해설, 긴 과정을 짧게 압축하는 데이터 이야기, 캐릭터가 있는 서비스 소개에 맞는다. 그림책 · 캐릭터 해설 · 코드로 그린 시뮬레이션.

출처 · gh:astrothewizard-618782. 작성자의 프롬프트는 약 2,470자다. 주제(빛알의 여정), 분위기(그림책·귀여움), 넣을 실제 수치의 종류, 같은 기간 지구의 사건을 나란히 놓으라는 구성 하나, 내레이션·자막·음악·효과음·믹싱 요구, 검증 절차를 정했다. 장면 수, 장별 길이, 색, 글꼴, 구도, 캐릭터 모양, 전환 방식은 비어 있다. 이 노트는 영상 프레임(1초 간격 61장, 전환 구간 0.25초 간격 48장, 대표 구간 0.25초 간격 16장)을 보고 썼다.
측정 · 파일 1280x720 · 60fps · 60.05초. 아래 크기는 1920x1080 으로 환산했다. 장면 감지(scene>0.28)는 컷을 하나도 잡지 않았다. 전환이 모두 줌·흰 번쩍임·눈꺼풀 닦기라서 한 프레임에 크게 바뀌지 않는다. 0.5초마다 움직임 세기 평균은 7.1 이다. 가장 큰 값은 39.0초(111.8, 흰 번쩍임), 53.5초(65.7, 눈꺼풀), 50.0초(58.9, 지구 → 눈), 25.0초(46.2, 단면으로 줌 아웃), 7.0초(34.6), 33.5초(33.1)다. 0~6초는 0.2~0.9 로 거의 멈춰 있다. 13~25초는 7~10 으로 고르게 높다(카메라가 주인공을 따라간다). 색 값은 프레임에서 잰 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. 감지 BPM 94.0, 마디 첫 박으로 다시 잰 박은 95.4 BPM(마디 약 2.52초)이다. 첫 박은 2.37, 4.88, 7.40초 … 57.71초다. 장 시작 시각(7.5, 25.0, 34.0, 39.5, 50.5, 54.2초)은 첫 박과 ±0.4초 넘게 어긋난다. 음악 박보다 내레이션에 맞춰 잘랐다고 본다. 음량은 0.5초부터 -14~-23dB 로 끊김 없이 이어지고, -26dB 아래 짧은 틈(0.15~0.5초)이 23곳 있다. 말소리의 숨 자리로 보인다. 큰 타격은 1.93초(1.00), 34.39초(0.89, 대류층 장 시작), 13.48초(0.83), 32.37·52.28초(0.78)다. 39.0초 흰 번쩍임 ±0.5초 안에는 감지된 타격이 없다. 저음 킥은 22.08초 한 번뿐이다.

## 3. 움직임

- 시뮬레이션처럼 보이는 움직임 · 붐비는 장면의 빛알은 직선으로 가다 입자에 부딪히면 꺾인다. 지나간 자리는 노란 꺾은선으로 남는다. 단면 장의 갈색 자국은 수천 걸음을 겹친 모양이다. 원작 글이 실제 무작위 걸음을 요구했고, 화면도 그 결과처럼 보인다.
- 계수기 가속 · 튕긴 횟수는 처음 2초에 1씩, 그다음 0.5초마다 두 배 넘게 뛴다. 단면 장에서는 숫자가 지수로 바뀐다. 장 안에서 숫자 쓰는 방식을 바꿔 시간 압축을 보여 준다.
- 카메라 · 13~25초는 빛알을 따라가며 입자 배경이 흐른다(움직임 세기 7~10 이 이어진다). 25초 줌 아웃, 33.75초 줌 인, 50초 지구로 다가가기가 큰 카메라 움직임이다. 나머지 장은 고정이다.
- 의성어 폭발 · 0.25초에 작게 생겨서 0.5초 안에 화면 폭의 약 20%(약 390px)로 커지고, 1초 머문 뒤 0.25초에 흐려진다. 글자는 살짝 기운다.
- 입자 떼 · 빨강 입자는 제자리에서 천천히 흔들리고, 가까운 것은 크고 진하며 먼 것은 작고 흐리다(깊이 3단 정도).
- 손글씨 주석은 한 글자씩 써지고, 화살표는 선이 그려지듯 자란다.
- 숫자는 고정폭 또는 세리프 숫자로, 프레임마다 바뀌며 센다. 다 세면 멈추고 옆에 괄호 덧말이 붙는다.

## 4. 전환

- 컷이 없다. 모든 장이 카메라 움직임이나 빛으로 이어진다.
- 7.0~7.5초 · 제목 화면이 어두워지며 주황 중심 화면이 녹아 나온다.
- 25.0초 · 입자 화면이 원판 안으로 줄어들며 단면이 된다. 앞 장의 내부가 다음 장 원판 속 한 점이 된다.
- 33.75초 · 단면 원판의 가장자리로 다가가 옆모습 대류층이 된다.
- 39.0초 · 의성어 폭발 + 흰 번쩍임(0.25초) → 우주. 장면이 바뀌는 순간이 이야기 사건(표면 탈출)과 같다.
- 50.25초 · 지구로 다가가다 흰 빛이 화면을 덮고 눈으로 바뀐다.
- 53.75초 · 눈꺼풀이 닫혔다가 가로 틈이 열리며 노을이 나온다.
- 자막 띠는 장이 바뀌어도 같은 자리에 남고, 문장 단위로 교체된다(약 1.5~3초마다).

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 16.5~19.0초. 주황 원형 그라데이션 바탕에 얼굴 있는 빨강 입자 수백 개(지름 22~68px)가 화면을 덮고, 가운데 빛알(지름 60px, 5.6%) 뒤로 노란 빛 꺾은선이 남는다. 왼쪽 위 계수기 상자(380x170px, 화면 폭 20%)의 숫자가 1 → 2 → 3 으로 오르고, 부딪힐 때 의성어 폭발(폭 약 390px)이 뜬다. 동시에 보이는 요소는 주인공 1, 입자 무리, 꺾은선, 계수기, 의성어, 자막 띠의 6가지다. 주인공 캐릭터, 실제로 꺾이는 경로, 세어 올라가는 숫자 중 하나라도 빠지면 이 영상이 아니다.
- 12초 판 압축 예 · 0~1.5초 밤하늘 등장 + 이름표, 1.5~5.5초 붐비는 입자 속 무작위 걸음과 계수기(의성어 2번), 5.5초 줌 아웃, 5.5~8.5초 단면 + 햇수 계수기(지구 사건 띠는 1개만), 8.5초 흰 번쩍임, 8.5~10.5초 우주 비행 + 거리 계기판, 10.5~12초 눈에 닿음 + 제목. 대류층 장, 온도계, 노을, 말풍선은 뺀다.
- 한 캐릭터를 끝까지 따라가며 장마다 숫자 하나를 세는 구성. 대상의 처리 과정(데이터 한 건의 여정, 주문 하나의 이동)에 그대로 쓸 수 있다.
- 장마다 숫자 쓰는 방식을 바꾸는 시간 압축. 낱개 → 두 배씩 → 지수 → 다 찬 값.
- 같은 기간 다른 세계의 일을 아래 띠에 나란히 놓는 방식. 대상의 처리 시간 동안 사용자가 하는 일을 띠에 놓을 수 있다.
- 사건과 전환을 겹치는 방식. 탈출 순간에 흰 번쩍임, 도착 순간에 눈 깜박임.
- 손글씨 주석과 괄호 덧말로 정확한 수치 옆에 농담을 붙이는 말투.
- 자막을 한 자리 알약 띠에 고정하는 방식.

## 7. 함정

- 화면의 자막 문장, 제목, 주석 문구, 말풍선 대사는 원작의 것이다. 옮기지 않는다. 역할(자막, 손글씨 덧말, 작별 농담)만 가져온다.
- 화면의 실제 수치(온도, 거리, 햇수, 추정 범위)와 지구 사건 그림은 이 주제의 것이다. 다른 대상에서는 원문에서 확인한 수치만 쓴다.
- 입자 수백 개에 각각 얼굴을 그리면 프레임마다 부담이 크다. 얼굴 있는 입자 그림을 크기 3가지로 미리 구워 두고 찍기만 한다.
- 무작위 걸음을 seek(t) 안에서 매번 새로 뽑으면 프레임마다 경로가 바뀐다. 씨앗 난수로 경로 전체를 로드 때 한 번 계산하고 t 로 앞부분만 보여 준다.
- 장면 감지가 컷을 하나도 잡지 않는다. 전환 시각은 움직임 세기 큰 구간(25.0, 33.5, 39.0, 50.0, 53.5초)으로 찾는다.
- 내레이션이 길고 끊김 없다. 한국어로 옮기면 같은 길이에 음절이 많아진다. 자막 한 줄 길이를 20자 안쪽으로 줄인다.
- 바탕색이 장마다 크게 바뀐다. 모든 장에 같은 빛알, 같은 손글씨, 같은 자막 띠를 두어야 한 영상으로 보인다.
- 한국어에는 세리프·손글씨 이탤릭이 없다. 제목·숫자·자막은 Pretendard SemiBold, 주석은 Pretendard Regular 를 기울여서 쓰고 색으로 나눈다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 글꼴은 Pretendard Regular·SemiBold 와 InterVariable(숫자)만 쓴다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 빛나는 빛알 캐릭터 | 없다. canvas 로 된다 | canvas 원 지름 60px, `createRadialGradient` 로 #FFFBE6 → #FFD34E → 투명(반지름 150px). 눈은 지름 7px 점 둘(간격 14px), 입은 폭 10px 호. 붐비는 장면에서는 빛 번짐 반지름을 90px 로 줄인다 | 없음 |
| 얼굴 있는 입자 수백 개 | 하나씩 그리면 무겁다 | 로드 때 오프스크린 canvas 3장(지름 24·44·68px, 몸 #D8603C → 가장자리 #A84838 그라데이션, 눈 2점)을 굽는다. 씨앗 난수로 300개 위치·크기·흔들림 위상을 정하고 seek 에서 `drawImage` 만 한다. 먼 것은 투명도 0.55 | 표정의 다양함 |
| 무작위 걸음 경로 | 매 프레임 같아야 한다 | 로드 때 `HAND.rngKey('walk')` 로 걸음 400개(한 걸음 30~90px, 각도 무작위)를 계산해 점 배열로 둔다. seek 에서 `HAND.subPath(P, frac)` 로 앞부분만 자르고 `HAND.ink(ctx, P2, { w: 3, color: '#FFE88A', B: 0 })` 로 긋는다. 계수기는 지나간 꺾임 수를 센다 | 실제 입자와 부딪히는 판정 |
| 의성어 폭발 | 장식 글꼴이 없다 | SVG 별 모양 다각형(꼭짓점 14개, 바깥 반지름 195px, 안 반지름 120px, #FFD94A, 테두리 6px #2A1420) 위에 Pretendard SemiBold 96px 한글 의성어(#E83C78, 테두리 `-webkit-text-stroke: 4px #2A1420`), 회전 -8도. 0.25초에 크기 0.3 → 1.1 → 1.0 | 장식 글자의 손맛 |
| 손글씨 주석 | 손글씨 글꼴이 없다 | Pretendard Regular 33px, `transform: skewX(-10deg)`, 색 #F6E7B8. 화살표는 SVG 2차 곡선 path(굵기 3px)에 `stroke-dashoffset` 으로 0.4초 동안 그린다. 글자는 0.04초에 한 자씩 보인다 | 손글씨의 불규칙함 |
| 태양 단면의 얼룩 띠 | 부글거리는 결 | canvas 고리(바깥 지름 600px, 띠 폭 90px, #EE5F41) 안에 반투명 원 60개(지름 20~50px, #F88850, 투명도 0.4)를 씨앗 난수로 뿌린다. 원 위치를 sin(t) 로 3px 흔든다 | 유기적인 대류 무늬 |
| 커다란 눈과 노을 실루엣 | 일러스트 | AI 일러스트(codex-image, 글자·로고 없이)로 눈 한 장(마젠타 바탕)과 사람 상반신 실루엣 한 장을 그린 뒤 `scripts/key.py` 로 바탕을 지운다. 노을 하늘·언덕·빛살은 CSS 그라데이션과 SVG 로 그린다. 홍채만 따로 두어 동공 반짝임을 DOM 원(지름 30px, 흰색, 0.3초)으로 얹는다 | 벡터 그림의 선명함 |
| 거리·시간 계기판의 세는 숫자 | 없다. DOM 으로 된다 | InterVariable 600, 72px, `font-variant-numeric: tabular-nums`. 반투명 상자 #2A1E45 투명도 0.6, 모서리 12px. 머리글은 Pretendard SemiBold 18px, 자간 0.4em | 없음 |
| 흰 번쩍임과 눈꺼풀 닦기 | 없다 | 번쩍임은 흰 div 투명도 0 → 0.9 → 0(0.1초 + 0.25초). 눈꺼풀은 위아래 검은 div 두 장이 0.25초에 가운데로 닫히고, 다음 장면 위에서 높이 0 → 1080px 로 열린다 | 없음 |
