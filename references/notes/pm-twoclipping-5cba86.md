# UI 모양 변형 · 검은 모양 하나가 상태를 이어 입는 흑백 화면 — 분석 노트

> 회백색 바탕 가운데 검은 모양 하나가 14초 동안 컷 없이 UI 상태 열두 개를 이어 입는 정사각 스타일. 커서가 누르고 끌 때마다 모양의 크기·모서리·색이 거의 넘치지 않는 스프링으로 바뀌고, 안의 내용은 0.1초 남짓의 흐림으로 갈린다. 사진·배경·제목이 없고, 끝 프레임이 첫 프레임과 같아서 반복 재생된다. 앱·디자인 시스템·UI 도구의 작은 동작 품질을 보여 주는 소개, 기능 목록을 하나의 흐름으로 묶는 짧은 소셜 영상에 맞는다. 제품 UI 모션 · 모양 변형 · 흑백.

출처 · pm:twoclipping-5cba86. 작성자의 글은 약 2,700자의 제작 주문이다. 입력 목록, 금지 효과, 상태 순서(14단계), 박자(120 BPM 7마디), 구현 방법(시간 함수 스프링, 두 끝이 다른 스프링을 타는 표시, 직접 조작 끌기)은 정했다. 모양마다의 크기·위치·색 값, 상태별 시각, 내용이 바뀌는 순서와 길이는 비어 있다. 이 노트는 영상 프레임(1초 간격 15장, 0.25초 간격 56장, 가장 빠른 구간은 0.05초 간격 24장, 원본 크기 17장)을 보고 썼다.
측정 · 파일 1440x1440 · 60fps · 14.06초. 장면 감지(문턱 0.28)가 잡은 컷은 0번이다. 0.5초마다 움직임 세기의 평균은 6.2 로, 같은 작성자의 영상 넷 가운데 가장 낮다. 큰 값은 3.5초(26.2, 카드 → 납작한 막대로 접힘), 1.5초(26.1, 원 → 알약 → 카드), 11.5초(22.2, 목록 선택), 5.0초(12.1, 막대 늘어남)다. 거의 멈춘 구간(1 미만)은 2.5~3.0초, 8.5초, 12.0초, 13.0~13.5초다. 첫 프레임과 끝 프레임의 화소 차이 평균은 0.34(0~255)다. 크기는 원본 1440 화소로 적는다. 색 값은 7x7 화소 평균으로 잰 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. BPM 120.2(박 0.5초, 마디 2.0초). 마디 첫 박은 0.08, 2.08, 4.08, 6.09, 8.09, 10.09, 12.09초다. 음량은 -15~-19dB 로 처음부터 끝까지 고르다. 큰 고조나 쉼이 없다. 짧은 무음(-18dB 아래, 0.15~0.46초)이 13곳 있고 대부분 박의 0.18~0.34초 뒤에 온다. 가장 센 타격은 9.08초(1.00), 12.57초(0.99), 13.08초(0.98), 0.04초(0.89), 10.08초(0.86)다.

## 1. 본질

- 바탕은 따뜻한 회백색(#EBEBE6 근처, 가운데 #EFEFEA, 모서리 #E7E7E2)이다. 가운데가 조금 밝은 넓은 원형 빛이 있다.
- 주인공은 검은 모양 하나(#000000)다. 흰색으로 바뀌는 상태가 셋(긴 탭 줄, 넓은 카드 둘)이다. 그때 바탕과의 경계는 넓고 옅은 그림자가 맡는다.
- 색은 흑·백·회색뿐이다. 예외는 카드 안 그림 자리 하나의 주황 → 분홍 → 보라 그라데이션(#FEA463 → #EB6A6F → #B24BAA 근처)이다.
- 화면에 동시에 보이는 요소는 모양 하나 + 커서 하나다. 모양 안의 부품은 2~7개다.
- 상태별 크기(정사각 1440 기준) · 작은 알약 643x205px(화면 폭 45%, 높이 14%), 원 지름 217px(15%), 가로 알약 870x221px(60%), 중간 카드 989x629px(69%x44%, 모서리 약 60px), 납작한 막대 1077x187px(75%x13%), 토글 485x260px(34%x18%), 긴 탭 줄 1179x185px(82%x13%), 큰 카드 1105x893px(77%x62%), 목록 카드 1038x855px(72%x59%), 작은 검색창(가로 20–80%, 세로 44–56%), 가로 알약(가로 16–84%, 높이 약 180px).
- 아닌 것 · 컷, 두 번째 모양, 사진, 배경 무늬, 제목 자막, 빛 번짐, 입자, 튀는 탄성, 1초 넘는 정지(끝 0.8초 제외).

## 3. 움직임

- 모양의 크기 변화 폭이 크다. 너비는 15%(원) → 82%(탭 줄) 사이, 높이는 13%(막대) → 62%(큰 카드) 사이를 오간다. 모양이 커질 때 화면 가운데를 기준으로 커진다.
- 스프링은 거의 넘치지 않는다. 눈대중으로 목표의 2~3% 다. 튀는 느낌이 없다.
- 상태 하나의 박자 · 클릭 → 0.1초 뒤 모양 변형 시작 → 0.3~0.4초 변형 → 내용이 0.05~0.1초 간격으로 차례로 들어옴 → 0.3~0.8초 머묾. 상태 하나가 1~2.5초다.
- 내용 교체 · 나가는 내용은 흐려지며 0.1~0.15초에 빠진다. 들어오는 내용은 흐림 약 8px(눈대중)에서 0.1초에 선명해진다. 나가고 들어오는 시각이 겹치지 않는다.
- 두 끝 스프링 · 선택 표시와 토글 손잡이는 앞 끝이 먼저 출발하고 뒤 끝이 늦게 따라온다. 이동 중 길이가 원래의 1.3~1.5배(눈대중)로 늘어난다.
- 직접 조작 · 끄는 손잡이는 커서와 같은 자리에 있다(한 번은 26% → 82%, 한 번은 18% 까지 줄였다가 끝까지). 끝을 넘어 끌면 모양 전체가 늘어나고(+8.5%), 놓으면 그 자리에서 약 0.25초에 스프링으로 돌아온다.
- 숫자가 움직인다. 시간 표시, 큰 숫자(0.5초에 흐림 속에서 세어 오름), 커서를 따르는 값 표시가 커서 위치에 따라 바뀐다. 선 그래프는 왼쪽부터 0.25초에 그려진다.
- 토글은 0.25초마다 켜짐(검은 바탕·흰 손잡이)과 꺼짐(옅은 회색 바탕)을 오간다. 손잡이가 움직일 때 가로로 늘어난다.
- 목록 줄은 위에서부터 0.05초 간격으로 들어오고, 글자를 칠 때마다 줄 수가 줄며 카드 높이가 준다.
- 카메라는 거의 고정이다. 목록 카드 구간만 약 1.2배 다가간다. 그 밖의 꽉 찬 느낌은 모양 자체의 크기 변화로 낸다.

## 4. 전환

- 하드 컷이 없다. 모든 전환이 같은 모양의 크기·모서리·색 변화다.
- 모양 사이의 연결 고리를 매번 다르게 쓴다. 쓰인 고리는 일곱 가지다.
  - 가로가 줄어 원이 된다(누름 = 기다림).
  - 체크 뒤 가로로, 다시 세로로 커진다(완료 = 결과).
  - 카드에서 부품 하나만 남아 다음 상태가 된다(같은 부품이 다른 기능이 됨).
  - 손잡이가 다음 상태의 주인공이 된다.
  - 줄이 다음 카드의 머리줄로 남는다.
  - 크게 줄였다가 다시 키운다.
  - 선택한 줄의 글이 다음 상태의 글이 된다.
- 검정 ↔ 흰색 바뀜은 모양이 커지는 도중에 0.15초쯤 걸쳐 일어난다(세 번).
- 박자 맞추기 · 상태가 크게 바뀌는 시각 넷이 마디 첫 박에서 0.1초 안쪽이다. 짧은 사건(클릭, 체크, 토글)은 박마다 하나씩 온다.

## 5. 타이포

- 고딕 한 계열, 중간 굵기와 굵게 둘만 쓴다. 숫자는 고른 폭이다.
- 작은 알약 낱말 · 흰색, 글자 높이 50px(3.5%). 가로 알약 글 · 흰색 약 36px(2.5%, 눈대중).
- 중간 카드 · 제목 흰색 약 34px, 부제 회색 약 24px, 고정폭 숫자 회색 약 18px(눈대중).
- 큰 카드 · 큰 숫자 검정 굵게 약 80px(5.6%, 눈대중), 아래 회색 설명 약 20px, 탭 낱말 약 24px.
- 목록 카드 · 입력 글 약 34px, 목록 줄 약 28px, 오른쪽 단축키 표기 회색 약 20px(눈대중).
- 화면 글자는 모두 UI 부품 안에 있다. 제목·자막·설명 문장이 없다.

## 6. 가져올 것

- 핵심 장치 · 화면에 모양 하나와 커서 하나만 두고, 그 모양이 대상의 기능 8~12개를 차례로 입는다. 앞 상태의 부품 하나가 다음 상태의 주인공이 되도록 잇는다. 너비는 화면 폭 15~82%, 높이는 13~62% 사이를 오간다.
- 핵심 장치 · 모양이 먼저 0.3~0.4초에 변하고, 내용은 위에서 아래로 0.05~0.1초 간격으로 흐림(약 8px)을 걷고 들어온다. 나가는 내용이 다 빠진 뒤 들어오는 내용을 시작한다.
- 핵심 장치 · 작은 물리감 두 가지를 둔다. 끝을 넘어 끌면 모양 전체가 늘어났다가(+8.5%) 스프링으로 돌아오고, 이동하는 표시는 앞 끝이 먼저 가고 뒤 끝이 따라와 길이가 1.3~1.5배로 늘어난다.
- 핵심 장치 · 첫 상태에서 시작해 첫 상태로 끝나고, 커서까지 같은 자리로 돌아온다. 끝 0.8초를 첫 프레임으로 고정해 반복 재생한다.
- 큰 상태 교체는 마디 첫 박에, 짧은 사건은 박마다 하나씩 놓는다.

## 7. 함정

- 가로 알약은 실존 기기 화면 위쪽의 알림 모양을 닮았다. 위치를 화면 위로 옮기거나 기기 틀을 그리지 않는다. 가운데에 떠 있는 알약으로만 쓴다.
- 움직임 평균이 6.2 로 낮다. 화면 대부분이 바탕이고 모양이 작을 때(원은 화면의 15%) 비어 보이기 쉽다. 상태마다 머묾을 0.8초 아래로 두고, 머무는 동안에도 커서나 숫자를 움직인다.
- 내용 교체를 겹치기(크로스페이드)로 하면 글자가 이중으로 보인다. 나가는 내용이 다 빠진 뒤 들어오는 내용을 시작한다. 원작은 0.1~0.15초 간격을 둔다.
- 카메라 크기를 바꾸는 부모에 `will-change` 를 두면 글자가 흐려진다. 크기는 모양의 `width`·`height` 를 직접 바꾸고, 전체 확대는 목록 카드처럼 꼭 필요한 곳에만 쓴다.
- 끝 프레임은 커서 위치와 속도까지 첫 프레임과 같아야 반복이 끊기지 않는다. 끝 0.8초를 첫 상태로 고정한다.
- 한국어로 옮길 때 · 알약 낱말은 두세 글자 동사로 쓰고, 글자 높이 50px 를 Pretendard SemiBold 로 지킨다. 카드 제목은 8자 이내로 줄인다. 입력 글은 한글 자모가 조합되는 과정을 보이지 말고 음절 단위로 친다(0.15초 간격).
- 16:9 로 옮기는 구도(1920x1080).
  - 정사각 px 에 0.75 를 곱하면 높이 비율이 같다. 작은 알약 482x154px, 원 163px, 가로 알약 653x166px, 중간 카드 742x472px, 막대 808x140px, 토글 364x195px, 탭 줄 884x139px, 큰 카드 829x670px, 목록 카드 779x641px.
  - 모양은 가로 가운데(50%), 세로 50% 에 둔다. 좌우 여백이 넓어지므로 너비가 큰 상태(막대·탭 줄)는 0.75 배 대신 0.85 배(916px, 1002px)로 키워 가로 비율 48~52% 를 맞춘다.
  - 커서 시작점은 가로 72%, 세로 83% 로 옮긴다. 정사각의 가로 90% 를 그대로 쓰면 모양에서 너무 멀다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

거의 모두 DOM/CSS 로 된다. 글꼴은 Pretendard Regular·SemiBold 뿐이다(숫자·라틴은 InterVariable 도 있다). 값은 정사각 1440 기준이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 모양 하나의 연속 변형 | 상태마다 다른 요소를 쓰면 이음매가 생긴다 | 바깥 `div` 하나에 `width`·`height`·`border-radius`·`background` 를 t 의 함수로 준다. 각 값은 목표가 바뀔 때마다 스프링 하나씩 더한 합(감쇠비 0.85, 고유 진동수 14rad/s)이다. 안의 내용은 상태별 `div` 를 겹쳐 두고 투명도와 `filter: blur()` 만 바꾼다 | 없음 |
