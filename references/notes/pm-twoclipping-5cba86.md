# 검은 모양 하나가 UI 상태 열두 개로 — 분석 노트

> 회백색 바탕 가운데의 검은 모양 하나가 14초 동안 단추 → 로딩 원 → 체크 → 알약 알림 → 음악 재생기 → 음량 슬라이더 → 토글 → 탭 → 차트 카드 → 명령 팔레트 → 알림 토스트 → 단추로 쉬지 않고 바뀌는 정사각 영상. 컷이 없고 사진·배경·제목이 없다. 커서가 누르고 끌 때마다 모양의 크기·모서리·색이 스프링으로 바뀌고, 안의 내용은 짧은 흐림으로 갈린다. 끝 프레임이 첫 프레임과 같아서 반복 재생된다. 앱·디자인 시스템·UI 도구의 "작은 동작이 잘 만들어졌다"를 보여 주는 소개, 기능 목록을 하나의 흐름으로 묶는 짧은 소셜 영상에 맞는다. 제품 UI 모션 · 모양 변형 · 흑백.

출처 · pm:twoclipping-5cba86. 작성자의 글은 약 2,700자의 제작 주문이다. 입력 목록, 금지 효과, 상태 순서(단추에서 다시 단추까지 14단계), 박자(120 BPM 7마디), 구현 방법(시간 함수 스프링, 두 끝이 다른 스프링을 타는 탭 표시, 직접 조작 끌기)은 정했다. 모양마다의 크기·위치·색 값, 상태별 시각, 내용이 바뀌는 순서와 길이는 비어 있다. 이 노트는 영상 프레임(1초 간격 15장, 0.25초 간격 56장, 대표 구간은 0.05초 간격 24장, 원본 크기 17장)을 보고 썼다.
측정 · 파일 1440x1440 · 60fps · 14.06초. 장면 감지(문턱 0.28)가 잡은 컷은 0번이다. 0.5초마다 움직임 세기의 평균은 6.2 로, 같은 작성자의 영상 넷 가운데 가장 낮다. 큰 값은 3.5초(26.2, 재생기 끌기 → 슬라이더로 접힘), 1.5초(26.1, 원 → 알약 → 재생기), 11.5초(22.2, 팔레트 선택), 5.0초(12.1, 슬라이더 늘어남)다. 거의 멈춘 구간(1 미만)은 2.5~3.0초, 8.5초, 12.0초, 13.0~13.5초다. 첫 프레임과 끝 프레임의 화소 차이 평균은 0.34(0~255)다. 크기는 원본 1440 화소로 적는다. 색 값은 7x7 화소 평균으로 잰 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. BPM 120.2(박 0.5초, 마디 2.0초). 마디 첫 박은 0.08, 2.08, 4.08, 6.09, 8.09, 10.09, 12.09초다. 음량은 -15~-19dB 로 처음부터 끝까지 고르다. 큰 고조나 쉼이 없다. 짧은 무음(-18dB 아래, 0.15~0.46초)이 13곳 있고 대부분 박의 0.18~0.34초 뒤에 온다. 가장 센 타격은 9.08초(1.00), 12.57초(0.99), 13.08초(0.98), 0.04초(0.89), 10.08초(0.86)다. 상태가 크게 바뀌는 시각(2.0초 재생기, 4.0초 슬라이더, 10.0초 검색창, 12.0초 토스트)은 마디 첫 박에서 0.1초 안쪽이다.

## 1. 본질

- 바탕은 따뜻한 회백색(#EBEBE6 근처, 가운데 #EFEFEA, 모서리 #E7E7E2)이다. 가운데가 조금 밝은 넓은 원형 빛이 있다.
- 주인공은 검은 모양 하나(#000000)다. 흰색으로 바뀌는 구간이 셋(탭 7.0~7.5초, 차트 카드, 명령 팔레트)이다. 그때 바탕과의 경계는 넓고 옅은 그림자가 맡는다.
- 색은 흑·백·회색뿐이다. 예외는 재생기 앨범 그림의 주황 → 분홍 → 보라 그라데이션(#FEA463 → #EB6A6F → #B24BAA 근처) 하나다.
- 화면에 동시에 보이는 요소는 모양 하나 + 커서 하나다. 모양 안의 부품은 2~7개다(재생기: 그림·제목·부제·진행 막대·시간 2개·단추 3개).
- 원래 글의 상태 14단계가 모두 나온다. 화면에서 순서를 확인했다.
- 아닌 것 · 컷, 두 번째 모양, 사진, 배경 무늬, 제목 자막, 빛 번짐, 입자, 튀는 탄성, 1초 넘는 정지(끝 0.8초 제외).

## 3. 움직임

- 모양의 크기 변화 폭이 크다. 너비는 15%(로딩 원) → 82%(탭) 사이, 높이는 13%(슬라이더) → 62%(차트) 사이를 오간다. 모양이 커질 때 화면 가운데를 기준으로 커진다.
- 스프링은 거의 넘치지 않는다. 눈대중으로 목표의 2~3% 다. 튀는 느낌이 없다.
- 상태 하나의 박자 · 클릭 → 0.1초 뒤 모양 변형 시작 → 0.3~0.4초 변형 → 내용이 0.05~0.1초 간격으로 차례로 들어옴 → 0.3~0.8초 머묾. 상태 하나가 1~2.5초다.
- 내용 교체 · 나가는 내용은 흐려지며 0.1~0.15초에 빠진다. 들어오는 내용은 흐림 약 8px(눈대중)에서 0.1초에 선명해진다. 나가고 들어오는 시각이 겹치지 않는다.
- 두 끝 스프링 · 탭 표시와 토글 손잡이는 앞 끝이 먼저 출발하고 뒤 끝이 늦게 따라온다. 이동 중 길이가 원래의 1.3~1.5배(눈대중)로 늘어난다.
- 직접 조작 · 진행 막대(3.0~3.7초)와 음량(4.1~5.0초)은 손잡이가 커서와 같은 자리에 있다. 끝을 넘어 끌면 모양 전체가 늘어나고, 놓으면 그 자리에서 돌아온다.
- 숫자가 움직인다. 시간 표시, 차트 큰 숫자(세어 오름), 말풍선 값이 커서 위치에 따라 바뀐다.
- 카메라는 거의 고정이다. 명령 팔레트 구간만 약 1.2배 다가간다. 그 밖의 "꽉 찬 느낌"은 모양 자체의 크기 변화로 낸다.

## 4. 전환

- 하드 컷이 없다. 모든 전환이 같은 모양의 크기·모서리·색 변화다.
- 모양 사이의 연결 고리가 매번 다르다.
  - 단추 → 원 · 가로가 줄어 원이 된다(누름 = 기다림).
  - 원 → 알약 → 카드 · 체크 뒤 가로로, 다시 세로로 커진다(완료 = 결과).
  - 진행 막대 → 슬라이더 · 카드에서 막대만 남는다(같은 부품이 다른 기능이 됨).
  - 슬라이더 → 토글 → 탭 · 손잡이가 다음 상태의 주인공이 된다.
  - 탭 → 차트 · 탭 줄이 차트 카드의 머리줄로 남는다.
  - 차트 → 검색창 → 팔레트 · 크게 줄였다가 다시 키운다.
  - 팔레트 → 토스트 → 단추 · 선택한 줄의 글이 토스트 글이 된다.
- 검정 ↔ 흰색 바뀜은 모양이 커지는 도중에 0.15초쯤 걸쳐 일어난다(7.4초, 9.8초, 11.8초).
- 상태 교체 시각은 마디 첫 박 근처다. 짧은 사건(클릭, 체크, 토글)은 박마다 하나씩 온다.

## 5. 타이포

- 고딕 한 계열, 중간 굵기와 굵게 둘만 쓴다. 숫자는 고른 폭이다.
- 단추 낱말 · 흰색, 글자 높이 50px(3.5%). 토스트 글 · 흰색 약 36px(2.5%, 눈대중).
- 재생기 · 제목 흰색 약 34px, 부제 회색 약 24px, 시간 고정폭 회색 약 18px(눈대중).
- 차트 · 큰 숫자 검정 굵게 약 80px(5.6%, 눈대중), 아래 회색 설명 약 20px, 탭 낱말 약 24px.
- 명령 팔레트 · 입력 글 약 34px, 목록 줄 약 28px, 오른쪽 단축키 표기 회색 약 20px(눈대중).
- 화면 글자는 모두 UI 부품 안에 있다. 제목·자막·설명 문장이 없다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 1.2~2.3초. 지름 217px(화면 폭 15%) 검은 체크 원이 0.25초 만에 870x221px(60%) 알약 알림이 되고, 다시 0.4초 만에 989x629px(69%x44%) 재생기 카드로 커지며, 앨범 그림 → 제목 → 진행 막대 → 단추 3개가 0.05~0.1초 간격으로 흐림을 걷고 들어온다. 화면에는 이 모양 하나와 커서 하나뿐이다. 모양이 하나가 아니거나 내용이 한꺼번에 나타나면 이 영상이 아니다.
- 12초 판 압축 예 · 0~1.2초 단추 → 로딩 원 → 체크, 1.2~2.4초 알약 → 재생기, 2.4~3.6초 재생 → 진행 막대 끌기, 3.6~5.0초 슬라이더(끝 넘어 늘어남 포함), 5.0~6.4초 토글 → 탭, 6.4~8.4초 차트(선 그리기 + 말풍선), 8.4~10.4초 명령 팔레트(타이핑 2글자 + 엔터), 10.4~12.0초 토스트 → 단추. 차트의 탭 다시 누르기(9.0~9.75초)와 토글 두 번째 깜박임을 뺀다.
- 한 모양이 기능 목록을 순서대로 입는 구성. 기능 8~12개를 14초에 보여 줄 수 있다. 앞 상태의 부품이 다음 상태의 주인공이 되도록 순서를 짠다.
- 내용 교체의 시차. 모양이 먼저 변하고, 내용이 위에서 아래로 0.05~0.1초 간격으로 선명해진다.
- 끝을 넘어 끌면 늘어나는 슬라이더, 앞 끝이 먼저 가는 탭 표시. 작은 물리감 두 가지가 "잘 만든 UI" 인상을 만든다.
- 고리 구조. 단추에서 시작해 단추로 끝나고, 커서까지 같은 자리로 돌아온다.

## 7. 함정

- 화면의 단추 낱말, 재생기 제목과 부제, 차트 숫자, 팔레트 명령 이름, 토스트 문장은 원작의 것이다. 옮기지 않는다. 역할(동작 낱말, 콘텐츠 이름, 지표 숫자, 명령 이름, 완료 문장)만 가져온다.
- 1.4초의 알약 알림은 실존 휴대폰 상단의 알림 모양을 닮았다. 위치를 화면 위로 옮기거나 휴대폰 틀을 그리지 않는다. 가운데에 떠 있는 알약으로만 쓴다.
- 움직임 평균이 6.2 로 낮다. 화면 대부분이 바탕이고 모양이 작을 때(로딩 원은 화면의 15%) 비어 보이기 쉽다. 상태마다 머묾을 0.8초 아래로 두고, 머무는 동안에도 커서나 숫자를 움직인다.
- 내용 교체를 겹치기(크로스페이드)로 하면 글자가 이중으로 보인다. 나가는 내용이 다 빠진 뒤 들어오는 내용을 시작한다. 원작은 0.1~0.15초 간격을 둔다.
- 카메라 크기를 바꾸는 부모에 `will-change` 를 두면 글자가 흐려진다. 크기는 모양의 `width`·`height` 를 직접 바꾸고, 전체 확대는 팔레트처럼 꼭 필요한 곳에만 쓴다.
- 끝 프레임은 커서 위치와 속도까지 첫 프레임과 같아야 반복이 끊기지 않는다. 13.25초부터 0.8초를 첫 상태로 고정한다.
- 한국어로 옮길 때 · 단추 낱말은 두세 글자 동사로 쓰고, 글자 높이 50px 를 Pretendard SemiBold 로 지킨다. 재생기 제목은 8자 이내로 줄인다. 팔레트 타이핑은 한글 자모가 조합되는 과정을 보이지 말고 음절 단위로 친다(0.15초 간격).
- 16:9 로 옮기는 구도(1920x1080).
  - 정사각 px 에 0.75 를 곱하면 높이 비율이 같다. 단추 482x154px, 로딩 원 163px, 알약 653x166px, 재생기 742x472px, 슬라이더 808x140px, 토글 364x195px, 탭 884x139px, 차트 829x670px, 팔레트 779x641px.
  - 모양은 가로 가운데(50%), 세로 50% 에 둔다. 좌우 여백이 넓어지므로 너비가 큰 상태(슬라이더·탭)는 0.75 배 대신 0.85 배(916px, 1002px)로 키워 가로 비율 48~52% 를 맞춘다.
  - 커서 시작점은 가로 72%, 세로 83% 로 옮긴다. 정사각의 가로 90% 를 그대로 쓰면 모양에서 너무 멀다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

거의 모두 DOM/CSS 로 된다. 글꼴은 Pretendard Regular·SemiBold 뿐이다(숫자·라틴은 InterVariable 도 있다). 값은 정사각 1440 기준이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 모양 하나의 연속 변형 | 상태마다 다른 요소를 쓰면 이음매가 생긴다 | 바깥 `div` 하나에 `width`·`height`·`border-radius`·`background` 를 t 의 함수로 준다. 각 값은 목표가 바뀔 때마다 스프링 하나씩 더한 합(감쇠비 0.85, 고유 진동수 14rad/s)이다. 안의 내용은 상태별 `div` 를 겹쳐 두고 투명도와 `filter: blur()` 만 바꾼다 | 없음 |
| 내용 흐림 교체 | 나가고 들어오는 시각 관리 | 나감 0.12초(투명도 1 → 0, 흐림 0 → 8px), 0.03초 쉼, 들어옴 0.12초(흐림 8px → 0). 부품마다 0.06초씩 늦춘다 | 없음 |
| 재생·일시 정지 아이콘 변형 | 삼각형 → 막대 두 개 | SVG 경로 두 개를 꼭짓점 수(8개)를 맞춰 만들고 t 로 꼭짓점을 보간한다. 0.2초 | 없음 |
| 앞 끝이 먼저 가는 탭 표시 | 두 끝의 시차 | 표시의 왼쪽 끝과 오른쪽 끝을 각각 다른 스프링으로 계산한다. 진행 방향 쪽 끝은 고유 진동수 18, 반대쪽 끝은 11 | 없음 |
| 끝을 넘어 늘어나는 슬라이더 | 넘친 거리의 감쇠 | 넘친 거리 d 에 대해 늘어난 길이 = 120 × (1 − e^(−d/200)) px. 놓으면 그 값에서 스프링으로 0 으로 돌아온다 | 없음 |
| 그려지는 선 그래프 | 없다 | SVG `path` 에 `stroke-dasharray` 와 `stroke-dashoffset` 을 t 로 준다. 0.5초, 아래 회색 면은 같은 경로로 `clip-path` 를 넓힌다 | 없음 |
| 넓은 원형 그림자 | 흰 카드와 흰 바탕의 경계 | `box-shadow: 0 30px 80px rgba(0,0,0,.10), 0 4px 12px rgba(0,0,0,.06)` | 없음 |
| 움직임 흐림 | 하위 프레임 합성 기능이 없다 | 큰 변형 구간(1.3~1.5초, 1.8~1.95초, 3.7~4.0초)에만 모양을 투명도 0.3 으로 2개 복제해 1/240초 전 크기로 겹친다 | 변형 가장자리의 부드러운 번짐 |
| 앨범 그림 | 사진 자료 | CSS `linear-gradient(160deg, #FEA463, #EB6A6F 50%, #B24BAA)`, 모서리 반지름 그림 폭의 22% | 없음 |
