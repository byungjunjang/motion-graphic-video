# 미니멀 UI · 흰 바탕 굵은 한 줄 문장과 다시 그린 UI 판의 교대 — 분석 노트

> 흰 바탕에 굵은 산세리프 문장 한 줄과 다시 그린 UI 판이 하드 컷으로 번갈아 나오는 32초 기능 예고편(trailer). 요소는 제자리에서 0.1초에 진해지며 뜨고, 낱말·작은 표시·칩·카드가 타격음에 하나씩 맞춰 차례로 뜬다. 움직임 세기는 컷을 빼면 3.7 이 최고이고, 1~2초 정지가 10곳 있다. 강조는 옅은 파랑 상자와 작은 배지 둘뿐이고 색 글자가 없다. 같은 배치를 두고 일부 칸만 접고 펴서 "사람마다 다른 화면"을 보여 준다. SaaS 기능 출시, 권한·역할·요금제처럼 사람마다 보이는 범위가 다른 주제에 맞는다. 미니멀 UI(minimal UI) · 에디토리얼(editorial).

출처 · gh:wustep-884086. 작성자의 프롬프트는 공개되지 않았다. 대신 작성자의 게시글 748자(일부만 공개)가 있다. 기능 출시를 알리는 말과 제작 과정이 들어 있다. 코드로 영상을 만드는 프레임워크만 썼고, AI 코딩 도구와 메시지 약 90번을 주고받으며 이틀 동안 시안 33개를 냈다고 적혀 있다. 이 노트는 영상 프레임(0.75초 간격 43장)을 보고 썼다.
측정 · 파일 1280x720 · 60fps · 31.9초. 측정된 하드 컷은 1번이다(98.5% 지점, 검은 화면으로). 흰 화면끼리 바뀌는 컷은 측정에 잡히지 않았다. 프레임으로 보면 16번 있다. 움직임 세기는 그 컷을 빼면 3.7이 최고다. 0.8초 이상 정지 구간이 10곳이다(가장 긴 것은 88.4~98.1% 지점, 3.1초). 색 값은 화소를 16단계로 묶어 잰 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. BPM 84.7(마디 약 2.8초). 타격음 134개, 큰 타격 35개. 측정된 컷 1번은 타격음과 맞지 않는다(0/1). 프레임으로 확인한 차례 등장(낱말 6개, 작은 배지, 이름표 4개, 칩 16개, 카드 6장)과 15.04초 컷(가장 센 타격)은 타격음 ±0.1초 안에 있다. 무음 구간은 7곳이다. 그중 4곳 바로 뒤에 사건이 온다(2.84, 3.79, 15.04, 28.17초). 29.48초(92.4%)부터 끝까지도 무음이다.

쓰는 법 · 이 노트는 스타일 문법(색·질감·크기 비율·움직임·전환·타이포·밀도)만 적는다. 원본의 소재·장면·순서는 적지 않았다. 숫자는 원본 영상을 보고 잰 근삿값이다.

## 1. 본질

- 바탕은 흰색(#F8F8F8 근처, 82%)이다. 글자는 진회색(#282828 근처, 프레임에서 잰 값)이다. 순수한 검정은 마지막 0.5초의 빈 화면뿐이다. 칩 장면만 바탕이 조금 따뜻한 흰색이다.
- 재료는 두 가지다. 굵은 산세리프 문장과 UI 판이다. 문장은 한 화면에 하나만 있다.
- UI 판은 화면 캡처가 아니라 다시 그린 UI 로 보인다(작성자 글에 코드만 썼다고 적혀 있다). 행과 열이 있는 목록형이다. 열 머리글은 회색 아이콘 + 이름이다. 행 사이에 옅은 1px 선이 있다. 분류 값은 파스텔 칩이다. 크기는 5열 4행, 6열 5행 정도다.
- 강조는 두 가지다. 한 열을 감싸는 옅은 파랑 상자(채움 #ECF4FC 근처 + 파랑 테두리)와 열 이름 옆의 작은 배지다.
- 사람 표시는 흰 원 안의 검은 선 그림 아바타다. 12개를 세 개씩 겹쳐 네 묶음을 만든다. 넷째 묶음은 색 원 안의 아이콘이다. 묶음 아래에 파스텔 이름표(분홍, 초록, 살구, 회색)가 붙는다.
- 아닌 것 · 어두운 바탕, 그라데이션, 3D, 커서, 강조 색 글자, 장면을 넘기는 쓸기·밀기.

## 3. 움직임

- 움직임이 아주 적다. 요소는 제자리에서 뜨고 제자리에서 사라진다. 등장은 0.1초 동안 옅은 회색에서 진회색으로 진해지는 것 하나다.
- 차례로 뜨기(stagger)가 기본이다. 낱말, 아바타, 이름표, 행, 칩이 모두 하나씩 뜬다. 간격은 0.03초(아바타)에서 0.24초(낱말·이름표·칩)까지다. 행은 0.1초 간격, 아바타 12개는 0.4초 동안 왼쪽부터 튀어나온다.
- 칩 16개는 읽는 순서로 하나씩 켜진다. 앞 8개는 약 0.24초, 뒤 8개는 약 0.12초 간격이다. 켜지는 순간 파랑 상자가 됐다가 흰 칩으로 돌아온다. 배지는 조금 크게 떴다가 줄어든다.
- 파랑 상자는 머리글에서 아래로 0.25초에 자란다. 옆 열까지 넓어질 때는 약 0.45초 뒤에 늘어난다.
- 제자리 교체 때 열이 접힌다. 숨는 열은 너비가 줄어 사라지고 드러나는 열은 너비가 늘어 나타난다(약 0.15초). 숨은 칸에는 가려짐 표시(사선 그은 눈 + 회색 두 낱말)가 들어간다. 아바타는 교차 페이드다.
- 화면 크기가 바뀌는 곳은 두 번이다. 확대 컷(약 2배)과 줌아웃(0.3초)이다.
- 문장과 확대 화면은 1~2초 그대로 둔다. 정지 구간 10곳이 여기서 나온다.
- 열 카드 · 머리글과 3행이 0.15초에 차례로 뜬다.

## 4. 전환

- 장면 전환은 거의 모두 흰 화면끼리의 하드 컷이다(16번). 앞 장면이 한 프레임에 사라지고 다음 내용이 0.1초에 뜬다.
- 확대 컷 · UI 판 전체에서 두 열로 바로 뛴다. 옆 열은 옅은 회색으로 잘려 보인다.
- 줌아웃(약 0.3초) · 하나뿐인 이어지는 전환이다. 크게 보이던 열이 판 안의 제자리로 줄어들고 나머지 열이 페이드로 나타난다. 질문에서 답으로 넘어가는 자리에 쓴다.
- 제자리 교체 · 배치는 두고 아바타와 열만 바꾼다.
- 빠른 컷 묶음(약 2.75초) · 같은 배치의 카드 6장이 약 0.47초마다 바뀐다.

## 5. 타이포

- 문장은 굵은 산세리프다. 자간이 좁다. 대문자 높이는 화면 높이의 8~10%다(720p 에서 59~72px). 문장 끝에 마침표나 물음표가 있다. 끝 이름에는 마침표가 없다.
- 문장은 2~6낱말이고 가운데 정렬이다. 질문만 열 옆에 왼쪽 정렬로 둔다. 낱말은 하나씩 약 0.23초 간격으로 뜨고, 낱말마다 회색에서 진회색으로 0.1초에 진해진다.
- UI 판 글자는 같은 산세리프의 중간 굵기다. 720p 에서 약 20px 다. 머리글은 회색(#808080 근처), 값은 진회색이다. 금액은 오른쪽 정렬이다.
- 확대 장면과 열 카드에서는 판 글자가 2~3배로 커진다. 문장 없이 판 글자만으로 읽힌다.
- 끝 카드의 작은 줄은 끝 이름의 약 1/3 크기다. 끝 이름을 약 2초 먼저 보여 주고 작은 줄을 나중에 붙인다.
- 색으로 강조한 글자가 없다. 굵기와 크기만으로 위계를 만든다.

## 6. 가져올 것

- 핵심 장치 · 흰 화면에서 굵은 문장 한 줄(2~6낱말)과 다시 그린 UI 판을 하드 컷으로 번갈아 놓는다. 문장이 주장이나 질문을 말하고, 다음 화면의 UI 가 그것을 보여 준다. 문장과 확대 화면은 1~2초 멈춘다.
- 핵심 장치 · 타격음 하나에 요소 하나. 낱말·작은 표시·이름표·칩·카드를 타격 ±0.1초에 하나씩 0.1초 진해짐으로 띄운다. 긴 목록은 뒤 절반에서 간격을 절반(0.24 → 0.12초)으로 줄여 속도를 붙인다.
- 핵심 장치 · 배치를 고정한 채 일부 칸의 너비만 0.15초에 접고 펴서, 약 1초마다 "누가 보느냐"에 따라 같은 판이 달라지는 모습을 보인다.
- 핵심 장치 · 같은 UI 판을 전체 → 확대 컷(약 2배) → 한 칸 확대 + 질문 → 0.3초 줌아웃으로 다시 쓴다. 질문은 무음 0.24초 뒤 가장 센 타격에 놓는다.
- 끝 카드 · 끝 이름을 2초 먼저 보여 주고 작은 줄을 나중에 붙인다.

## 7. 함정

- 원본 화면의 실존 로고·이름은 쓰지 않는다.
- UI 판은 소개하는 제품의 화면을 본뜬 것으로 보인다. 그대로 그리면 그 제품으로 보인다. 소개할 대상의 UI 로 다시 그리고 아이콘도 직접 그린다.
- 손그림 아바타는 코드로 그리기 어렵다. 원 + 단순한 선 얼굴이나 머리글자 원으로 대신한다. 원본의 얼굴을 따라 그리지 않는다.
- 원본은 1280x720 이다. 1920x1080 으로 옮기면 치수에 1.5를 곱한다. 판 글자는 30px 이 된다.
- 움직임이 적어서 박자가 어긋나면 바로 보인다. 요소 등장을 타격 시각에 맞춘다. 소리 없이는 정지 구간이 길게 느껴진다.
- 전체 판 장면에서는 값을 읽을 시간이 없다. 읽혀야 하는 값은 확대 장면이나 열 카드에 둔다.
