> 실제 화면 녹화처럼 보이지만 창·메뉴·코드 줄을 모두 다시 그린 60초 소프트웨어 안내 영상. 큰 네모 픽셀로 된 작은 마스코트가 매끈한 고해상도 화면 안에서 살며, 소프트웨어가 하는 일을 몸으로 보여 준다. 읽을 때는 목록 위를 달리고, 검사할 때는 단추를 밟는다. 마스코트가 화면 전환 단추를 밟으면 어둠이 원으로 번져 앱 전체가 어두운 화면으로 바뀐다. 소프트웨어 기능 소개, 신기능 출시, 사용 안내 영상에 맞는다.

## 3. 움직임

- 원래 글의 마스코트 연기(웅크림, 늘어남, 착지 찌그러짐, 숨쉬기, 깜빡임, 눈 방향)와 커서 규칙은 화면과 맞다. 되풀이하지 않는다.
- 영상에서 확인한 점 · 화면 대부분이 거의 멈춰 있다(평균의 대부분이 0.2~6). 화면에서 움직이는 것은 마스코트, 커서, 타자, 바뀌는 줄 정도다. 큰 움직임은 장 전환과 원 번짐 1초 안팎에만 있다.
- 마스코트는 늘 어떤 화면 요소의 윗변에 서 있다(입력창, 메뉴, 막대, 의견 상자, 단추). 공중에 떠 있는 프레임은 뛰는 중뿐이다.
- 마스코트의 위치는 픽셀 칸 단위로 끊겨 움직인다. 화면 글자는 매끄럽게 움직인다. 같은 화면에서 두 움직임 질이 나란히 보인다.
- 밀고 들어가기는 약 2.2배까지다. 1배보다 작게 물러나지 않는다(바탕 화면이 보이는 것은 처음, 대표 장면 뒤, 끝뿐).

## 4. 전환

- 원래 글은 장 알약 지우기, 픽셀 지우기, 화면 전환 원만 허용했다. 화면도 그렇다. 디졸브가 없다.
- 영상에서 확인한 점 · 장 전환 넷 중 셋(10.0, 19.0, 35.0초)이 같은 픽셀 지우기다. 테라코타 모자이크 칸(약 40px)이 화면 왼쪽부터 대각선으로 0.4~0.5초에 채우고, 장 제목 카드를 약 0.5초 보인 뒤, 반대쪽으로 0.4~0.5초에 빠진다. 앞쪽 가장자리의 칸은 크기가 들쭉날쭉하고 일부는 테두리만 있다.
- 화면 전환 원은 두 번 쓴다. 40.25초(밝음 → 어둠, 단추에서), 53.5초(어둠 → 밝음, 마스코트 발밑에서). 처음과 끝이 대칭이다.

## 5. 타이포

- 세 계열이다. 화면 글자는 작은 고딕, 터미널과 코드는 고정폭, 제목·장 제목·끝 문구는 세리프.
- 세리프 제목 · 앱 첫 화면 제품 이름은 글자 높이 약 75px(7%), 끝 화면 제품 이름 약 90px(8%), 끝 문구 낱말 약 45px(4%). 마지막 낱말만 기울임 + #D87454.
- 화면 글자(앱 안) · 원래 제품의 실제 크기 비례. 밀고 들어가지 않은 화면에서는 12~16px 로 읽히지 않는다. 읽어야 할 글자는 밀고 들어가서 보여 준다.
- 큰 숫자 타이머 · 세리프 계열 가는 숫자, 높이 약 160px.

- 12초 판에서 꼭 남길 대표 장면 · 원본 40.0~42.0초의 "픽셀 마스코트(약 115px, #D87454)가 화면 전환 단추를 밟자 단추 가운데에서 어두운 원이 약 0.75초에 가속하며 화면 전체를 덮고, 글자 위치는 그대로인 채 앱과 바탕 화면이 어두운 판(#1C1C18)으로 바뀐 뒤 물러나는" 장면이다. 마스코트의 발이 원인, 원이 결과다. 원이 마스코트가 밟은 자리에서 시작하지 않으면 이 영상이 아니다.
- 12초 판 압축 예 · 0~1.5초 터미널에서 명령어 타자, 1.5~2.5초 로고 블록이 흩어져 마스코트가 되어 창 위로 올라선다, 2.5~3.0초 픽셀 지우기(제목 카드 없이), 3.0~5.0초 입력창으로 밀고 들어가 타자, 마스코트가 보낸 말을 타고 오른다, 5.0~6.5초 마스코트가 파일 목록 위를 달리며 줄이 칠해진다, 6.5~7.0초 휙 옮겨 바뀐 파일 막대 위 환호, 7.0~9.5초 대표 장면(밟기 0.3초 + 원 0.75초 + 물러나기 1초 + 여유), 9.5~11.0초 어두운 바탕에 제품 이름과 낱말이 하나씩, 마스코트가 낱말 위를 건너뛴다, 11.0~12.0초 마스코트 발밑에서 밝은 원이 번지며 끝. 방식 메뉴, 계획 칸, 의견 상자, 세션 나누기는 뺀다.
- 소프트웨어의 동작마다 마스코트의 동작 하나를 짝 짓는다(읽기 = 달리기, 검사 = 밟기). 마스코트의 동작이 늘 실제 화면 변화를 일으킨다.
- 밝음 → 어둠 → 밝음의 큰 구조. 원 두 번이 그 경계다.

## 7. 함정

- 이 영상의 제품, 마스코트 모양, 제품 이름, 자막 문장, 명령어, 파일 이름, 단축키는 모두 실존 회사의 것이다. 노트와 우리 영상에 옮기지 않는다. 마스코트 모양(넓은 몸통, 옆으로 튀어나온 팔, 다리 넷)을 흉내 내지 않는다. 우리 영상에는 우리 제품의 마스코트를 새로 그린다. 끝 화면 제작 표기에도 실존 이름이 있다. 쓰지 않는다.
- 원래 글대로 화면의 모든 단추·메뉴·방식은 우리 제품의 실제 문서에서 확인한 것만 그린다. 지어낸 기능을 그리지 않는다.
- 마스코트를 `transform: scale` 로 찌그러뜨리면 픽셀 칸이 흐려지고 크기가 들쭉날쭉해진다. 찌그러짐은 미리 그린 칸 그림(서기, 웅크림, 늘어남, 착지)으로 바꿔 끼운다.
- 화면 전체가 오래 멈춰 있어도 이 스타일에서는 정상이다. 대신 마스코트의 숨쉬기(박마다 1칸 찌그러짐)와 깜빡임을 멈추지 않는다. 마스코트까지 멈추면 그냥 화면 녹화가 된다.
- 한국어 세리프가 없다. 제목을 Pretendard 로 쓰면 원본의 세리프 제목과 고딕 화면의 대비가 사라진다. 제목은 Pretendard Regular 에 자간 -0.02em, 크기 차이로 대비를 낸다(제목 90px 대 화면 글자 16px).
- 원 번짐을 부드러운 페이드로 바꾸면 대표 장면이 사라진다. 원 가장자리는 흐리지 않는다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 화면은 DOM/CSS 로 다시 그린다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 우리 제품의 마스코트 | 실존 마스코트를 쓸 수 없다 | 우리 제품에 맞는 새 캐릭터를 canvas 칸 그림으로 그린다(가로 10~14칸 x 세로 7~9칸, 칸 10px, 몸 색 하나 + 눈 짙은 회색). 칸 그림은 서기, 웅크림, 늘어남, 착지, 걷기 2장, 팔 들기, 눈 방향 6가지. `imageSmoothingEnabled = false` 로 키운다. 제품에 로고가 있으면 사용자가 허락한 로고 파일에서 색만 가져온다 | 원본 캐릭터의 익숙함 |
| 마스코트가 화면 요소 위에 서기 | 요소 위치가 바뀐다 | seek(t) 마다 서야 할 요소의 `getBoundingClientRect()` 윗변을 읽고, 마스코트 발을 그 위에 놓는다. 위치는 `Math.round(x / 10) * 10` 으로 칸에 맞춘다. 밀고 들어간 장면에서는 칸 크기도 배율대로 키운다 | 없음 |
| 실제 제품 화면 | 화면 캡처를 쓰지 않는다 | 우리 제품 화면을 DOM 으로 다시 그린다. 창 #F8F8F4, 바탕 화면은 `radial-gradient` 두 겹(왼쪽 위 #F1D9C7, 오른쪽 아래 복숭아 #E8B49A 불투명도 0.5) 위에 #EBDDCC → #C4B9A9 세로 그러데이션. 화면 글자 Pretendard Regular 16px, 코드는 InterVariable 15px `font-variant-numeric: tabular-nums` | 고정폭 글꼴의 코드 느낌 |
| 어둠이 번지는 원 | 없다. CSS 로 된다 | 어두운 판 DOM 을 같은 위치에 하나 더 겹쳐 두고 `clip-path: circle(r at x y)` 로 연다. 중심은 단추 가운데, r 을 0 → 2300px 로 0.75초, 가속 곡선(u³). 가장자리 흐림 없음. 어두운 판 색 #1C1C18, 글자 #E8E4DC | 없음 |
| 픽셀 지우기 | 없다 | 화면을 40px 칸(48 x 27칸)으로 나누고, 칸마다 도착 시각 = (가로 위치 + 세로 위치 x 0.5) x 0.004초 + 시드 고정 흔들림 ±0.06초. 칸은 #D87454 와 #E08A6C 를 시드로 섞는다. 앞쪽 가장자리 칸은 0.08초 동안 테두리만(굵기 3px) 보였다가 채운다. 들어오기 0.45초, 제목 카드 0.5초, 빠지기 0.45초 | 없음 |
| 휙 옮기기의 흐림 | 변형한 층에 흐림을 주면 픽셀 마스코트가 번진다 | 화면을 담은 바깥 상자(변형하지 않은 것)에 SVG `feGaussianBlur` stdDeviation 을 가로만 0 → 28 → 0 으로 0.3초 준다. 마스코트는 그 상자 밖 층에 둔다 | 없음 |
| 커서 | 없다 | SVG 화살표 24px. 경로는 용수철 감속(겹침 5%), 누를 때 0.1초 동안 0.85배. 순간 이동하지 않는다 | 없음 |
| 세리프 제목 | 세리프 글꼴이 없다 | Pretendard Regular 90px(제품 이름), 45px(끝 문구), 자간 -0.02em. 마지막 낱말만 #D87454 + `transform: skewX(-10deg)` | 세리프와 고딕의 대비 |
| 조명 멈춤 | 없다 | 화면 위에 rgba(0,0,0,0.45) 판을 덮고 `mask-image: radial-gradient` 로 마스코트 둘레 지름 420px 만 밝게 남긴다. 0.3초에 들어온다 | 없음 |
