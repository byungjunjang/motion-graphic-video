# 어두운 데이터 UI 배율 여행 · 빛점에서 부화소 격자까지 컷 없는 한 카메라 — 분석 노트

> 순검정 위의 빛나는 점 하나가 가로선이 되고, 창 테두리가 되고, 빽빽한 정보 창 다섯 개로 채워진다. 카메라는 컷 없이 47초 동안 배율과 위치만 바꾼다. 한 세부로 들어가면 화면의 빨강·초록·파랑 부화소 격자까지 보이고, 물러나면 전체 화면이 점 하나가 되며, 이웃 점으로 들어가면 다른 기기 화면이 열린다. 왼쪽 아래의 배율 표시(숫자 + 로그 눈금)가 지금 배율을 계속 알려 준다. 데이터 도구, 데스크톱과 모바일을 함께 가진 서비스 소개에 맞는다. 어두운 데이터 UI · 배율 여행 · 한 번의 연속 카메라.

출처 · pm:dale-vaz-cc612a. 작성자의 프롬프트는 약 630자다. 주제와 구성은 정했지만 색, 길이, 크기, 창의 배치, 카메라 속도, 글꼴, 소리는 비어 있다. 이 노트는 영상 프레임(1초 간격 시트 3장, 전환 구간은 0.25~0.5초 간격으로 직접 뽑은 32장, 원본 해상도 프레임 9장)을 보고 썼다.
측정 · 파일 1920x1080 · 30fps · 47.0초. 하드 컷은 0번이다(장면 감지가 하나도 잡지 않았다). 0.5초마다 움직임 세기의 평균은 4.4 로 낮다. 가장 큰 값은 16.5초(24.8), 17.0초(23.2), 13.5초(21.4)다. 모두 깊이 들어가는 확대 구간이다. 0~3.0초, 30.5~33.0초, 43.5~46.0초는 거의 0 이다. 색 값은 원본 프레임에서 잰 근삿값이다.
소리 · 소리 트랙이 없다. 파일에 음성 흐름이 없어서 잴 것이 없다.

쓰는 법 · 이 노트는 스타일 문법(색·질감·크기 비율·움직임·전환·타이포·밀도)만 적는다. 원본의 소재·장면·순서는 적지 않았다. 숫자는 원본 영상을 보고 잰 근삿값이다.

## 1. 본질

- 바탕은 순검정(#000000)이다. 창과 기기 화면 안은 짙은 남색 회색(#080D15 근처) UI 다.
- 강조색 두 개는 서로 반대인 두 상태를 뜻한다. 한쪽은 청록빛 초록(#38EEC1 근처, 값 꼬리표에도 쓴다), 다른 쪽은 분홍빛 빨강(#DC607F 근처)이다. 그 밖의 글은 흰색과 회색이다. 현재 값 표시줄만 연파랑 알약(#6B98FD 근처)이다.
- 처음 점과 물러난 뒤의 점은 푸른 흰빛(#717D93 근처, 둘레에 흐린 빛)이다. 점밭 화면에는 푸른 빛 얼룩(가운데)과 자홍 빛 얼룩(오른쪽 위, #221223 근처)이 아주 흐리게 있다.
- 왼쪽 아래(가로 2.5~15%, 세로 94~97%)에 배율 표시가 전체의 19.1~89.4% 구간 동안 있다. 작은 회색 이름표 + 고정폭 숫자(높이 약 14px, 1.3%) + 가로 로그 눈금(10의 -5제곱 ~ 2제곱, 폭 약 90px)과 그 위의 연파랑 점. 배율 값은 1.00배 → 6.34배 → 48.9배 → 0.76배 → 7.6 × 10의 -5제곱 → 1.01배로 바뀐다.
- 창은 실제 작업 화면처럼 빽빽하다. 전체 화면에 창 다섯 개, 숫자 수백 개. 창 묶음이 가로 2.5~95.6%, 세로 4.7~97.4% 를 채운다(화면의 약 87%).
- 아닌 것 · 컷, 장식 도형, 그라데이션 패널, 큰 제목, 사진, 내레이션 자막.

## 3. 움직임

- 카메라 하나가 배율과 위치만 바꾼다. 회전이 없다.
- 배율은 지수로 움직인다. 1배 → 48.9배까지 약 6.5초, 1배 → 7.6 × 10의 -5제곱까지 약 5초. 화면 속 크기가 같은 비율로 계속 바뀌어 속도가 고르게 느껴진다.
- 깊은 확대가 가장 빠르다(세기 12~25). 전체 화면과 점밭은 느리다(세기 0.1~5).
- 늘어나며 생기기 · 빛점(지름 약 48px, 속은 약 8px)이 2.5초 동안 천천히 숨쉰 뒤 좌우로 늘어나 가로선(폭 1617px, 84%, 굵기 약 4px, 세로 50%, 양 끝이 흐리다)이 된다. 선이 위아래로 벌어져 가는 테두리 사각형(약 1220x340px)이 되고, 0.5초 뒤 화면 거의 전체(가로 2.5~95.5%, 세로 4.7~97%)로 커진다.
- 창은 테두리 → 내용 순서로 생긴다. 테두리가 먼저 그어지고 0.3~0.5초 뒤 그래프·숫자가 채워진다. 창마다 약 0.5~1초 간격이다.
- 깊이 들어가기의 크기 변화 · 다가갈수록 그래프 막대 폭이 약 20px → 70px → 110px 으로 커지고, 꼬리표 글자가 화면 밖으로 잘린다(높이 약 150px). 약 30배에서 막대 속에 가는 격자가 보이기 시작하고, 48.9배에서 화면 전체가 부화소 격자가 된다. 칸 하나에 세로 막대 셋(빨강·초록·파랑), 칸 폭 약 45px. 초록 요소는 초록 막대만 밝고, 빨강 요소는 빨강 막대만 밝다. 격자 속에서 동그란 빛점 3개(지름 약 60px)가 이어 지나간 뒤 약 8배로 물러나면 막대와 꼬리표가 다시 또렷해진다.
- 물러나기의 크기 변화 · 전체 화면 → 1327x741px(69%) → 약 120x60px 작은 사각형 → 점 하나. 1초마다 한 단계씩 줄어든다.
- 다른 점으로 들어가기 · 검정 + 작은 빛점 → 작은 기기 화면(약 450x220px) → 0.5초 뒤 약 1450x720px. 둥근 테의 가로 기기다.
- 숫자는 계속 바뀐다. 값 꼬리표의 마지막 두 자리가 장면마다 다르다. 표의 현재 값 알약이 위아래로 한 줄씩 움직인다.
- 빛점이 시선을 이끈다. 처음 점, 다가가는 세부의 끝, 물러난 뒤의 점, 끝 글자 위에 같은 푸른 흰 빛점이 있다.
- 배율 표시의 점도 함께 움직인다. 숫자가 바뀌는 동안 눈금 위 점이 왼쪽(축소)이나 오른쪽(확대)으로 간다.
- 정지 구간이 세 번 있다. 전체의 0~6.4%(점만), 64.9~70.2%(점밭), 92.6~100%(끝 이름).

## 4. 전환

- 모든 전환이 배율 변화다. 다음 장면은 지금 화면 속 어딘가에 이미 들어 있다.
  - 점 → 선 → 테두리 → 창 · 한 요소가 늘어나 다음 요소가 된다.
  - 전체 화면 → 한 창 → 부화소 격자 · 계속 다가간다.
  - 격자 → 이웃 창 · 물러나며 옆으로 옮긴다.
  - 전체 화면 → 점 · 계속 물러나 사각형이 점이 된다.
  - 점 → 다른 기기 화면 · 이웃 점으로 옮겨 다가가면 그 점이 다른 기기 화면이다.
- 처음의 점과 물러난 뒤의 점이 같은 모양이다. 영상이 점에서 시작해 점을 거쳐 다시 화면으로 돌아오는 고리다.
- 배율 표시가 전환의 크기를 숫자로 보여 준다. 화면만 보면 길을 잃기 쉬운 배율 변화를 정리한다.

## 5. 타이포

- 글꼴은 두 가지다. UI 글과 이름은 고딕 계열, 숫자와 배율 표시는 고정폭이다.
- UI 글은 작다(1920 기준 10~14px). 전체 화면에서는 읽히지 않고, 다가간 뒤에 읽힌다. 다가가야 보이는 것이 이 스타일의 재미다.
- 확대 뒤 큰 숫자 · 눈금 글자 약 40px(약 6배), 값 꼬리표 약 90px(약 8배), 표 숫자 약 30px(줄 높이 약 160px). 모두 고정폭, 흰색·초록·빨강.
- 끝 화면 · 기기 화면이 위로 가며 작아진다(935x430px, 49%, 세로 9~49%). 아래에 작은 한 줄(높이 약 18px, 회색, 세로 63~65%), 큰 이름(굵은 고딕, 높이 약 104px, 9.6%, 흰색, 가운데, 세로 72~82%), 그 아래 아주 작은 회색 한 줄. 이름 끝 글자 위에만 푸른 빛점.

## 6. 가져올 것

- 핵심 장치 · 컷 없이 카메라 배율 하나로 모든 장면을 잇는다. 배율은 지수로 보간해(1배 → 48.9배 약 6.5초) 화면 속 크기가 같은 비율로 바뀌고, 다음 장면은 늘 지금 화면 속 어딘가에 이미 들어 있다.
- 핵심 장치 · 가장 작은 세부 하나로 계속 다가가 48.9배에서 화면 전체가 빨강·초록·파랑 세로 막대 셋의 부화소 격자(칸 폭 약 45px)가 되고, 그 자리 요소의 색 막대만 밝게 남는다.
- 핵심 장치 · 왼쪽 아래 배율 표시(작은 회색 이름표 + 고정폭 숫자 높이 1.3% + 폭 90px 로그 눈금 위 연파랑 점)가 지금 배율을 숫자와 점 위치로 계속 알려 준다.
- 핵심 장치 · 빛점 하나로 시작해, 물러나 전체 화면이 점 하나(69% → 약 120x60px → 점)가 되고, 이웃 점으로 다가가면 다른 기기 화면이 열리는 고리. 데스크톱 판과 모바일 판을 같은 점밭의 이웃 점으로 보여 줄 수 있다.
- 테두리 먼저, 내용 나중의 창 등장.
- 두 상태 색 + 연파랑 알약 하나만 쓰는 색 절제.

## 7. 함정

- 원본 화면의 실존 로고·이름은 쓰지 않는다.
- 데이터 화면은 숫자가 서로 맞아야 한다. 가상 값을 쓸 때도 두 상태 색과 값의 방향, 합계와 표의 값이 서로 맞게 만든다. 엉터리 숫자는 사용자에게 바로 보인다.
- 배율이 10의 7제곱 넘게 바뀐다. DOM 한 덩어리에 `scale` 만 주면 큰 배율에서 글자가 흐리거나 숫자 오차로 떨린다. 장면을 배율 층(전체 화면 층, 그래프 층, 화소 층, 점밭 층)으로 나누고, 층마다 제 배율 범위에서만 보이게 하며 이웃 층과 0.3초 겹쳐 바꾼다.
- 부화소 격자는 실제 화면 확대가 아니라 그린 무늬다. 격자로 넘어가는 순간 요소의 색과 위치가 격자의 밝은 막대와 맞아야 이어져 보인다.
- 소리 트랙이 없다. 우리 판에서는 배율 변화에 오르내리는 효과음(점밭 진입, 화소 진입)을 붙이고 정지 구간에 음악 쉼을 둔다.
- 점밭의 점은 수백 개다. 하나하나 DOM 으로 그리면 무겁다. canvas 나 three.js 점으로 그린다.
- 정지 구간(전체의 0~6.4%, 64.9~70.2%)은 짧은 판에서 0.8초 아래로 줄인다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

글꼴은 Pretendard Regular·SemiBold 와 InterVariable 이다. 값은 1920x1080 기준이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 빽빽한 정보 창 다섯 개 | 숫자가 많다 | DOM 으로 가상 창을 짓는다. 바탕 #080D15, 창 테두리 1px rgba(255,255,255,.08), 모서리 6px. 숫자는 InterVariable `font-variant-numeric: tabular-nums` 12px. 값은 씨앗 난수로 만든 걸음 값 300개로 고정한다 | 없음 |
| 막대형 데이터 그래프 | 없다 | canvas 에 막대 120개. 한쪽 상태 #38EEC1, 다른 쪽 #DC607F, 몸통 폭 6px(전체 화면 배율 기준), 이동평균선 1.5px #8A93C8. 마지막 막대 끝에 지름 12px 흰 원 + `shadowBlur` 24px | 없음 |
| 깊은 배율 확대 | DOM 한 덩어리로는 흐려진다 | 층을 넷으로 나눈다. 전체 화면 층(0.5~4배), 그래프 층(canvas 를 배율마다 다시 그림, 4~30배), 화소 층(30~60배), 점밭 층(10의 -5제곱 ~ 0.5배). 배율 s 는 `s = exp(lerp(ln a, ln b, e))` 로 보간하고 층 사이는 0.3초 `opacity` 로 겹친다 | 아주 작은 이음매 |
