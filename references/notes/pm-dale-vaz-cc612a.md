> 검은 화면의 빛나는 점 하나가 가로선이 되고, 창 테두리가 되고, 차트·호가표·관심 종목·보유 내역 창이 하나씩 채워져 증권 거래 데스크톱 화면이 된다. 카메라는 컷 없이 47초 동안 배율만 바꾼다. 차트의 마지막 봉으로 들어가 화면의 빨강·초록·파랑 부화소 격자까지 보고, 다시 나와 호가표와 손익 그래프를 지나, 데스크톱이 우주의 별 하나가 될 때까지 물러난다. 그리고 다른 별로 들어가 가로로 누운 휴대전화 화면을 연다. 왼쪽 아래의 배율 표시(숫자 + 로그 눈금)가 지금 배율을 계속 알려 준다. 금융·데이터 도구, 데스크톱과 모바일을 함께 가진 서비스 소개에 맞는다. 어두운 금융 UI · 배율 여행 · 한 번의 연속 카메라.

출처 · pm:dale-vaz-cc612a. 작성자의 프롬프트는 약 630자다. 주제(실존 증권 거래 단말 소개)와 구성(점 하나 → 창 여러 개 → 여러 배율 확대·축소 → 데스크톱이 우주의 점 → 가로 휴대전화의 두 칸 화면 → 끝 문구)을 정했다. 색, 길이, 크기, 창의 배치, 카메라 속도, 글꼴, 소리는 비어 있다. 이 노트는 영상 프레임(1초 간격 시트 3장, 전환 구간은 0.25~0.5초 간격으로 직접 뽑은 32장, 원본 해상도 프레임 9장)을 보고 썼다.

## 3. 움직임

- 카메라 하나가 배율과 위치만 바꾼다. 회전이 없다.
- 배율은 지수로 움직인다. 1배 → 48.9배까지 약 6.5초, 1배 → 7.6 × 10의 -5제곱까지 약 5초. 화면 속 크기가 같은 비율로 계속 바뀌어 속도가 고르게 느껴진다.
- 깊은 확대(13~17초)가 가장 빠르다(세기 12~25). 데스크톱 전체 화면과 우주는 느리다(세기 0.1~5).
- 창은 테두리 → 내용 순서로 생긴다. 테두리가 먼저 그어지고 0.3~0.5초 뒤 차트·숫자가 채워진다.
- 숫자는 계속 바뀐다. 가격 꼬리표 값이 장면마다 다르다(13초 → 17초 사이 마지막 두 자리가 바뀐다). 호가표 줄의 현재가 알약이 위아래로 한 줄씩 움직인다.
- 빛점이 시선을 이끈다. 처음 점, 차트 봉 끝, 별, 끝 글자 위에 같은 푸른 흰 빛점이 있다.
- 배율 표시의 점도 함께 움직인다. 숫자가 바뀌는 동안 눈금 위 점이 왼쪽(축소)이나 오른쪽(확대)으로 간다.
- 정지 구간이 세 번 있다. 0~3초(점만), 30.5~33초(우주), 43.5~47초(끝 문구).

## 4. 전환

- 모든 전환이 배율 변화다. 다음 장면은 지금 화면 속 어딘가에 이미 들어 있다.
  - 점 → 선 → 테두리 → 창 · 한 요소가 늘어나 다음 요소가 된다.
  - 데스크톱 → 차트 → 화소 · 계속 다가간다.
  - 화소 → 호가표 · 물러나며 옆으로 옮긴다.
  - 데스크톱 → 별 · 계속 물러나 사각형이 점이 된다(26~28초).
  - 별 → 휴대전화 · 다른 별로 옮겨 다가가면 그 별이 휴대전화다(35~37초).
- 처음의 점과 우주의 별이 같은 모양이다. 영상이 점에서 시작해 점을 거쳐 다시 화면으로 돌아오는 고리다.
- 배율 표시가 전환의 크기를 숫자로 보여 준다. 화면만 보면 길을 잃기 쉬운 배율 변화를 정리한다.

## 5. 타이포

- 글꼴은 두 가지다. UI 글과 서비스 이름은 고딕 계열, 숫자와 배율 표시는 고정폭이다.
- UI 글은 작다(1920 기준 10~14px). 데스크톱 전체 화면에서는 읽히지 않고, 다가간 뒤에 읽힌다. 다가가야 보이는 것이 이 영상의 재미다.
- 확대 뒤 큰 숫자 · 가격 눈금 약 40px(13초), 가격 꼬리표 약 90px(17초), 호가표 숫자 약 30px(19초). 모두 고정폭, 흰색·초록·빨강.
- 끝 화면 · 작은 한 줄(높이 약 18px, 회색), 서비스 이름(굵은 고딕, 높이 약 104px, 흰색, 가운데), 그 아래 아주 작은 회색 구호 한 줄. 이름 끝 글자 위에만 푸른 빛점.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 13.5~16.5초. 차트 마지막 봉(폭 약 70px)과 초록 가격 꼬리표로 다가가다가 48.9배에서 화면 전체가 빨강·초록·파랑 세로 막대 셋으로 된 부화소 격자(칸 폭 약 45px)가 되고, 초록 봉은 초록 막대만 밝게 남는다. 왼쪽 아래 배율 숫자가 6.34 → 48.9 로 오른다. 격자까지 들어가지 않거나 배율 표시가 없으면 이 영상이 아니다.
- 12초 판 압축 예 · 0~0.8초 점. 0.8~1.5초 점 → 선 → 테두리. 1.5~3.0초 창 다섯 개가 0.3초씩 채워진다. 3.0~3.5초 데스크톱 전체. 3.5~6.0초 차트 → 부화소 격자(대표 장면). 6.0~7.0초 물러나 데스크톱. 7.0~8.0초 계속 물러나 별 하나 + 이웃 별. 8.0~9.0초 이웃 별로 들어가 휴대전화. 9.0~10.0초 휴대전화 주문 + 알림. 10.0~12.0초 끝 문구. 호가표·손익 그래프 확대와 우주 정지는 뺀다.
- 배율 하나로 모든 장면을 잇는 구성. 대상 서비스의 큰 그림(전체 화면)과 작은 세부(숫자 하나)를 한 동작으로 보여 준다.
- 배율 표시. 숫자 + 로그 눈금 + 점으로 지금 크기를 알린다.
- 점에서 시작해 별(점)을 거쳐 다른 기기로 가는 고리. 데스크톱 판과 모바일 판을 같은 별밭의 이웃 별로 보여 줄 수 있다.
- 테두리 먼저, 내용 나중의 창 등장.
- 시세 색 두 개 + 연파랑 알약 하나만 쓰는 색 절제.

## 7. 함정

- 화면의 서비스 이름, 종목 이름, 끝 문구, 구호, 별 이름표는 실존 서비스의 것이다. 쓰지 말고 옮기지 않는다. 역할(서비스 이름, 데스크톱 판·모바일 판 이름표, 한 줄 구호)만 가져온다. 화면 속 시세 숫자도 옮기지 않고 가상 숫자를 만든다.
- 금융 화면은 숫자가 맞아야 한다. 가상 시세를 쓸 때도 오름은 초록, 내림은 빨강, 손익 합계와 표의 값이 서로 맞게 만든다. 엉터리 숫자는 금융 사용자에게 바로 보인다.
- 배율이 10의 7제곱 넘게 바뀐다. DOM 한 덩어리에 `scale` 만 주면 큰 배율에서 글자가 흐리거나 숫자 오차로 떨린다. 장면을 배율 층(데스크톱 층, 차트 층, 화소 층, 우주 층)으로 나누고, 층마다 제 배율 범위에서만 보이게 하며 이웃 층과 0.3초 겹쳐 바꾼다.
- 부화소 격자는 실제 화면 확대가 아니라 그린 무늬다. 격자로 넘어가는 순간 봉의 색과 위치가 격자의 밝은 막대와 맞아야 이어져 보인다.
- 소리 트랙이 없다. 우리 판에서는 배율 변화에 오르내리는 효과음(우주 진입, 화소 진입)을 붙이고 정지 구간에 음악 쉼을 둔다.
- 우주의 별은 수백 개다. 하나하나 DOM 으로 그리면 무겁다. canvas 나 three.js 점으로 그린다.
- 47초 판의 정지 구간(0~3초, 30.5~33초)은 12초 판에서 0.8초 아래로 줄인다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

글꼴은 Pretendard Regular·SemiBold 와 InterVariable 이다. 값은 1920x1080 기준이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 빽빽한 거래 단말 창 다섯 개 | 실존 화면이고 숫자가 많다 | DOM 으로 가상 단말을 짓는다. 바탕 #080D15, 창 테두리 1px rgba(255,255,255,.08), 모서리 6px. 숫자는 InterVariable `font-variant-numeric: tabular-nums` 12px. 시세는 씨앗 난수로 만든 걸음 값 300개로 고정한다 | 없음 |
| 봉 차트 | 없다 | canvas 에 봉 120개. 오름 #38EEC1, 내림 #DC607F, 몸통 폭 6px(데스크톱 배율 기준), 이동평균선 1.5px #8A93C8. 마지막 봉 끝에 지름 12px 흰 원 + `shadowBlur` 24px | 없음 |
| 깊은 배율 확대 | DOM 한 덩어리로는 흐려진다 | 층을 넷으로 나눈다. 데스크톱 층(0.5~4배), 차트 층(canvas 를 배율마다 다시 그림, 4~30배), 화소 층(30~60배), 우주 층(10의 -5제곱 ~ 0.5배). 배율 s 는 `s = exp(lerp(ln a, ln b, e))` 로 보간하고 층 사이는 0.3초 `opacity` 로 겹친다 | 아주 작은 이음매 |
| 부화소 격자 | 실제 화면 확대 무늬 | canvas 에 칸 45px, 칸마다 세로 막대 3개(폭 11px, 간격 4px, #FF3B5C · #3BFF9A · #3B7BFF). 막대 밝기 = 그 칸 자리의 봉 색 성분. 칸 사이 가로 틈 6px #050608. 칸 경계 위에 `radial-gradient` 비네트 | 렌즈로 본 듯한 번짐 |
| 우주 별밭과 성운 | 별 수백 개 + 흐린 빛 | three.js 에서 `LOOKS.orbs(600, { spread: [40, 24, 10], color: '#B8C4E8', size: 0.08, seed: 3 })` 로 별을 뿌리고, 성운은 `LOOKS.dome({ base: ['#000000', '#05060C'], blobs: [{ dir: [0, 0, -1], color: '#1A2A44', size: .5, power: .6 }, { dir: [.5, .4, -1], color: '#2A1430', size: .4, power: .5 }] })`. 십자 빛은 별 20개에만 DOM 가로·세로 선(길이 30px, 1px)을 겹친다. 카메라는 `LOOKS.fly` 로 움직인다 | 없음에 가깝다 |
| 별 이름표 고리 | 3D 점에 붙는 글 | `LOOKS.pin(v, cam, 1920, 1080)` 으로 별 위치를 화면 좌표로 바꾸고 지름 40px 원 테두리(1px) + Pretendard Regular 14px 이름표를 DOM 으로 붙인다 | 없음 |
| 배율 표시 | 없다 | 왼쪽 아래 `left:48px; bottom:40px`. 이름표 Pretendard Regular 13px #8A8F99, 숫자 InterVariable 26px 고정폭 흰색, 눈금 폭 90px 선 1px + 지름 8px 점 #6B98FD. 점 위치 = (log10 s + 5) / 7. 숫자는 1 이상이면 소수 둘째 자리 + 배, 0.01 아래면 지수 표기 | 없음 |
| 가로 휴대전화 테 | 실제 기기 모양 | DOM 사각형 1450x720px, 모서리 64px, 테 12px #2A2E36 + 안쪽 1px 하이라이트. 실존 기기 모양을 흉내 내지 않고 단순한 둥근 판으로 둔다 | 실제 기기의 질감 |
| 끝 서비스 이름 | 실존 이름 | Pretendard SemiBold 120px 흰색 가운데. 끝 글자 위 빛점은 지름 24px 흰 원 + `filter: blur(10px)` 복사본 #6B98FD | 없음 |
