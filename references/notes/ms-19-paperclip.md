# 스티커 해설 · 흰 테 스티커와 세로로 긴 한 장을 따라 내려가는 카메라 — 분석 노트

> 차분한 청회색 바탕과 점 격자 위에 흰 테를 두른 사진 스티커, 지시선 이름표, 칸 격자, 막대그래프를 빽빽하게 놓고, 카메라가 세로로 긴 한 장의 페이지를 따라 내려가는 10초 해설 영상. 하드 컷 없이 세로 이동과 요소 넘겨주기로 장면을 잇고, 끝에서 카메라가 물러나 페이지 전체를 기기 화면 속에 넣은 뒤 큰 숫자 하나로 멈춘다. 장면마다 요소가 20개 이상이고, 0.2~0.3초마다 새 요소가 하나씩 들어온다. 제품 속 구성 해설, 데이터 기반 소개에 맞는다. 스티커 해설(sticker explainer) · 큰 화면 카메라 이동 · 정밀 차트.

출처 · ms:19-paperclip. 쇼케이스 프롬프트에는 효과 이름, 기법 목록, 장면 순서, 색 두세 개만 있다. 화면 구도, 요소 수, 스티커와 표의 크기, 카메라 경로, 장면 시각은 없다. 이 노트는 영상 프레임(0.5초 간격 시트 20장, 0.1초 간격 띠 72장, `ffmpeg -ss` 로 직접 뽑은 10장)을 보고 그 빈칸을 채웠다.
측정 · 파일 1920x1080 · 30fps · 10.0초. 장면 전환 검출(scene>0.28)은 0번이다. 10초가 한 숏이다. 0.5초마다 움직임 세기의 평균은 16.9 다. 0~3초 15.0, 3~6초 19.0, 6~8초 30.6, 8~10초 3.0 이다. 가장 큰 값은 7.5초(47.0), 6.5초(37.4), 7.0초(33.4), 4.5초(32.9)다. 가장 작은 값은 8.5초(2.0), 9.0초(2.6), 6.0초(4.7), 2.0초(5.6)다. 위치·크기는 960x540 으로 줄인 프레임에서 재고 2배 해서 1920 기준 px 로 적었다. 색 값은 프레임에서 잰 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. BPM 117.5(마디 약 2.04초). 마디 첫 박은 2.02, 4.06, 6.10, 8.14초다. 가장 큰 타격(세기 1.00, 킥)은 8.13초이고, 끝 화면의 큰 숫자가 자리 잡는 순간(8.0~8.1초)과 겹친다. 그 밖에 2.28·2.53초, 5.34·5.47초에 짝 타격이 있다. 8.78~9.98초는 -22dB 아래로 조용하다. 타격과 화면 사건의 1:1 대응은 확인하지 못했다.

쓰는 법 · 이 노트는 스타일 문법(색·질감·크기 비율·움직임·전환·타이포·밀도)만 적는다. 원본의 소재·장면·순서는 적지 않았다. 숫자는 원본 영상을 보고 잰 근삿값이다.

## 1. 본질

- 바탕은 옅은 청회색(#EAEFF2 근처)이다. 바탕 전체에 작은 점 격자가 있다(점 간격 약 48px, 점 색 #C9D2D8 근처). 그라데이션이 없다.
- 색은 세 가지다. 진한 남회색(#233036 근처, 글자·켜진 칸·지시선), 빨강(#EA412C 근처, 강조 하나), 흰색(스티커 테·꺼진 칸). 꺼진 칸의 글자는 회색(#9AA5AB 근처)이다. 끝 화면만 짙은 남회색 바탕(#1B262C 근처)이다.
- 사진 스티커가 핵심 재료다. 요소가 모두 실물 사진처럼 보인다. 모두 흰 테(1920 기준 약 12px)와 옅은 그림자를 두른다. 사진의 출처가 달라도 흰 테 하나로 같은 재질처럼 묶인다.
- 차트는 정밀하다. 칸 격자는 18열 x 7행 + 아래 2행 15칸, 모두 118칸이다. 막대그래프는 격자 칸을 실제 개수만큼 이어 붙여 막대 길이를 만든다. 숫자와 막대 길이가 맞는다.
- 화면 틀이 끝까지 남는다. 왼쪽 아래에 가상 채널 이름표, 오른쪽 아래에 4칸 진행 막대(1920 기준 가로 1180~1830px, 세로 약 1015px)가 있다. 진행 막대의 현재 칸이 장면마다 빨강으로 바뀐다.
- 아닌 것 · 넓은 빈 바탕에 작은 요소 하나, 어두운 바탕(끝 화면 전), 네온, 손그림, 3D 회전, 하드 컷, 장식용 도형.

- 동시에 보이는 요소 수 · 첫 장면 약 18개(주인공 스티커 1, 글 줄 6, 밑줄, 선, 빈 점선 칸 10, 틀). 스티커 장면 약 30개(스티커 5, 이름표 5, 라틴 작은 줄 5, 작은 칸 11, 지시선 5, 틀). 격자 장면 120개 이상. 넓은 면 장면 약 20개(넓은 면 그림, 사진 스티커 4, 이름표 5, 경로 3, 도착점 원, 경로 점 8). 어느 장면도 요소가 15개 아래로 내려가지 않는다.
- 빈 바탕 비율 · 첫 장면 약 40%, 스티커 장면 약 45%, 격자·넓은 면 장면 20% 이하. 빈 바탕도 점 격자가 덮는다.
- 카메라 경로 · 큰 페이지 한 장을 세로로 따라 내려간다. 이동은 전체의 12–16%, 29–32%, 46–53%, 58–60% 네 번이다. 한 번에 0.3~0.7초다. 이동 중에는 세로 방향 움직임 흐림이 크다(1920 기준 20~40px 로 추정). 머무는 구간에서는 카메라가 거의 멈추고, 요소 등장만 일어난다.
- 장면이 빠지는 방식 · 지금 묶음이 세로로 번지며 위로 빠진다. 주인공 스티커만 다음 자리로 옮겨 남을 수 있다.
- 끝의 물러나기 · 배율이 1 → 약 0.5 → 약 0.29 로 두 단계 준다(전체의 70–80%). 0.29 는 기기 화면 폭(약 560px)을 1920 으로 나눈 값이다. 페이지 전체를 기기 화면 안에 넣는다. 그 뒤 화면 속 페이지가 위로 스크롤되고, 기기 틀이 왼쪽으로 빠르게 옮겨 가며 약 6° 기운다. 큰 숫자는 오른쪽 밖에서 흐린 채 날아 들어온다.
- 요소 등장 방식 · 스티커는 화면 밖에서 회전하며 날아와 0.1초 넘게 살짝 지나쳤다가 제자리에 선다(오버슈트). 이름표와 작은 칸은 작게 시작해 커진다. 지시선은 스티커 쪽 점에서 바깥으로 자란다. 글 줄은 아래에서 위로 올라오며 0.1초 간격으로 나타난다.
- 세는 숫자 · 격자 칸이 하나씩 진한 색으로 켜지는 동안 큰 숫자가 한 자리에서 두 자리 최종값까지 1.2초 동안 오른다. 강조 칸은 빨강으로 켜진다.
- 경로와 맥박 · 굵은 곡선 경로 3줄이 약 0.3초에 다 그어지고, 도착점 빨강 원이 커지며 맥박친다. 끝 화면에서는 기기 속 작은 숫자에서 큰 숫자로 빨강 점선이 이어지고 점이 흐른다.
- 칸이 장면을 잇는다 · 이름표 아래 작은 칸이 떨어지면서 돌고(회전 10~30°) 다음 장면 격자의 제자리로 날아간다. 격자의 켜진 칸만 떨어져 비스듬히 쏟아진 뒤 가로 막대 5줄로 다시 쌓이고, 막대 끝에 개수 숫자가 붙는다. 빨강 막대는 한 덩어리 알약 꼬리표로 뭉쳐 다음 장면의 빨강 이름표 자리로 따라간다. 같은 물체가 다음 장면의 재료가 된다.
- 움직임 세기 목표 · 전체 평균 16.9, 0~8초 평균 약 20. 카메라 이동 4번, 칸 무리 이동 2번, 끝의 물러나기가 큰 값을 만든다. 머무는 구간에도 0.1~0.3초마다 작은 등장이 있어 세기가 5 아래로 1초 넘게 내려가지 않는다(끝 정지 제외).

## 4. 전환

- 하드 컷이 없다. 모든 전환은 카메라 이동이다.
- 세로 휘두르기 · 지금 장면이 세로로 번지며 위로 빠지고 다음 장면이 아래에서 올라온다. 0.3~0.4초다. 흐림은 세로 방향만이다.
- 물체 넘겨주기 · 작은 칸, 빨강 막대가 다음 장면으로 날아가 제자리를 찾는다. 전환 중에도 화면 가운데에 움직이는 물체가 있다.
- 마지막 반전 · 카메라가 물러나며 지금까지의 화면이 기기 화면 속 페이지였다고 보여 준다. 바탕이 밝은 청회색에서 짙은 남회색으로 바뀐다. 장면이 바뀌는 것이 아니라 틀이 바뀐다.

## 5. 타이포

- 글꼴은 굵기가 고른 고딕 한 계열이다. 한자 글자는 굵게, 라틴 작은 줄은 자간을 넓힌 대문자다.
- 첫 장면 제목 · 두 줄, 글자 높이 약 100px(화면 높이의 9.3%), 아주 굵게, 남회색. 둘째 줄 뒤쪽 다섯 글자 아래에 빨강 밑줄(두께 약 12px, 글자 아래 1/3 에 걸침)이 0.3초 동안 그어진다.
- 분류 꼬리표 · 빨강 작은 사각형 + 굵은 짧은 말 + 라틴 대문자 회색. 글자 높이 약 26px(2.4%).
- 지시선 이름표 · 굵은 두 글자 약 40px(3.7%). 아래에 라틴 대문자 약 16px(1.5%) 회색. 그 아래 작은 칸(약 60x60px, 남회색 바탕 흰 기호, 강조 칸은 빨강 바탕). 칸 아래에 이름 약 18px.
- 격자 칸 · 기호 약 34px, 번호 약 14px. 꺼진 칸은 흰 바탕 + 1px 회색 테 + 회색 글자. 켜진 칸은 남회색 바탕 + 흰 글자.
- 세는 숫자 · 글자 높이 약 150px(14%), 아주 굵게, 남회색. 옆에 분모 약 60px 회색.
- 끝 화면 · 큰 숫자 높이 약 280px(26%), 빨강 면 + 흰 테 약 16px. 분모 약 100px 회색. 결론 문장 약 60px(5.6%) 흰색 굵게, 세 글자에 빨강 밑줄. 설명 약 32px 회색. 각주 약 18px 짙은 회색. 큰 숫자가 먼저 앉고 나머지 줄이 0.1초 간격으로 아래에서 올라온다.
- 정렬 · 모든 글 묶음이 왼쪽 맞춤이다. 줄마다 왼쪽 끝이 같은 세로선에 선다.

## 6. 가져올 것

- 핵심 장치 · 화면 전체를 세로로 긴 한 장의 페이지로 만들고, 카메라가 0.3~0.7초짜리 세로 이동(세로 흐림 20~40px)으로 다음 자리로 내려간다. 이동 사이 머무는 구간에는 0.1~0.3초마다 요소 하나가 들어와 장면마다 요소가 20개 이상이 된다.
- 핵심 장치 · 앞 장면의 작은 칸이 0.3~0.5초 동안 호를 그리며 날아가(회전 10~30°, 칸마다 0.01~0.02초씩 늦게 출발) 다음 장면의 격자·막대 재료가 된다. 전환 중에도 화면 가운데에 움직이는 요소가 있다.
- 핵심 장치 · 마지막에 카메라가 배율 1 → 약 0.5 → 약 0.29 로 물러나 지금까지 본 페이지 전체가 기기 화면 속이었음을 보이고, 바탕을 #EAEFF2 에서 #1B262C 로 바꾼 뒤 큰 숫자 하나(높이 26%)로 멈춘다.
- 핵심 장치 · 출처가 다른 그림·사진을 모두 흰 테 12px + 옅은 그림자 스티커로 묶어 한 재질로 보이게 한다.
- 길이를 늘릴 때 카메라 이동 한 번의 길이(0.3~0.4초)는 늘리지 않는다. 늘어난 시간은 머무는 구간과 끝 정지에 나눠 준다. 장면 수를 줄이지 않는다.
- 화면 틀(채널 이름표, 4칸 진행 막대)을 끝까지 둔다.

## 7. 함정

- 원본 화면의 실존 로고·이름은 쓰지 않는다.
- 화면에 쓰는 숫자·이름은 원문에서 직접 확인한 사실만 쓴다.
- 코드로 만들 때 밀도가 줄어드는 지점과 막는 법.
  - 스티커가 작아진다 · 가장 흔한 실패다. 첫 장면의 주인공 스티커는 화면 높이 74%, 스티커 장면의 가운데 스티커는 64% 로 고정한다. 주변 스티커 4장은 각각 화면 폭 11~19% 로 둔다. 위 층 배치 표의 값을 그대로 쓴다.
  - 화면이 비어 있다 · 점 격자 바탕을 깔고, 장면마다 요소를 20개 이상 둔다. 첫 장면에도 빈 점선 칸 10개, 진행 막대, 채널 이름표를 넣는다.
  - 격자를 줄인다 · 칸 수를 줄이지 않는다. 대상에 맞는 격자(칸 50개 이상)를 만들고 화면 폭 85% 이상을 채운다.
  - 장면을 따로 만들어 페이드로 넘긴다 · 페이지 한 장을 DOM 으로 만들고, 장면 위치를 세로 좌표로 둔다(예 · 장면 1 y=0, 장면 2 1200, 장면 3 2400, 장면 4 3600, 장면 5 4800). 카메라는 페이지를 감싼 부모 하나에 `translateY` 와 `scale` 을 t 의 함수로 준다.
  - 이동이 매끈하기만 하다 · 이동 구간에 세로 흐림을 준다. 속도에 비례해 0 → 30px → 0 으로 준다. 이동 전후에 0.1초 예비 동작(반대로 10~20px)을 넣는다.
  - 칸이 순간이동한다 · 칸마다 출발 위치와 도착 위치를 저장하고, 0.3~0.5초 동안 호를 그리며 날게 한다. 칸마다 0.01~0.02초씩 늦게 출발시킨다. 비행 중 회전 10~30°.
  - 끝 반전을 쓸 때 · 같은 페이지 DOM 을 기기 틀 div 안에 넣고 배율을 0.29 까지 줄인다. 페이지를 다시 그리지 않는다.
- 한국어로 옮길 때 · 첫 장면 제목은 Pretendard SemiBold 100px 두 줄로 쓴다. 끝 결론 문장은 SemiBold 60px 한 줄이다. 큰 숫자는 라틴 숫자라 InterVariable 굵기 800 으로 280px 까지 쓴다(140px 규칙은 한국어 글자에만 걸린다). 원작은 한자 제목이 아주 굵다. SemiBold 가 가볍게 보이면 남회색을 #1E2A30 정도로 더 짙게 하고 자간을 -0.02em 으로 좁힌다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 사진 스티커(주인공·주변 요소) | 실물 사진을 쓰지 않는다 | codex-image 로 요소 하나씩 그린다(글자·로고 없이, 마젠타 바탕). `scripts/key.py` 로 투명 PNG 를 만든다. CSS `filter: drop-shadow(0 0 0 #fff)` 를 12번 겹치는 대신, canvas 에서 알파를 12px 팽창시킨 흰 실루엣을 뒤에 깔고 그 뒤에 `drop-shadow(0 8px 16px rgba(30,45,55,.18))` 를 준다 | 사진의 질감과 실물 느낌 |
| 작은 사진 스티커 4장 | 같은 이유 | codex-image 로 그린다. 크기 220~260 x 140~190px, 흰 테 10px | 재료마다의 실제 색과 결 |
| 넓은 면 그림 | 저장소에 윤곽 자료가 없다 | SVG 로 점 30~60개짜리 다각형을 직접 그린다. 채움 #C9D2D8, 바탕 타원 #DDE4E8, 강조 면은 #233036. 또는 codex-image 로 글자 없는 회색 그림을 그린다 | 윤곽의 정확도 |
| 세로 움직임 흐림 | CSS `blur()` 는 사방으로 번진다 | SVG 필터 `feGaussianBlur stdDeviation="0 σ"` 를 카메라 층에 건다. σ = 이동 속도(px/프레임) x 0.5, 최대 30px | 프레임 사이를 섞는 진짜 셔터 흐림 |
| 큰 숫자의 흰 테 | 없다. 그대로 된다 | InterVariable 800, 280px, 채움 #EA412C, `-webkit-text-stroke: 16px #fff` + `paint-order: stroke fill` | 없음 |
| 세는 숫자 | 없다 | t 로 정수를 계산해 DOM 에 넣는다. 0.08초마다 값이 바뀌게 한다. 마지막 0.2초는 천천히 | 없음 |
| 경로 선 그리기 | 없다 | SVG path 3줄, 굵기 5px #233036, `stroke-dashoffset` 를 t 로 줄인다. 경로 위 점 지름 12px 를 0.1초 간격으로 켠다 | 없음 |
| 기기 틀 | 실물 기기 사진 | div 하나 · 둥근 모서리 반지름 80px, 검정 테 22px + 바깥 흰 테 14px. 안에 페이지 DOM 을 그대로 넣는다 | 기기 재질의 반사 |
| 굵은 한자 제목 | 굵은 한글 글꼴이 SemiBold 까지다 | Pretendard SemiBold 100px, 자간 -0.02em, 색 #1E2A30. 밑줄은 높이 14px 빨강 div 를 글자 아래 1/3 에 겹친다 | 원작의 무거운 굵기 |
