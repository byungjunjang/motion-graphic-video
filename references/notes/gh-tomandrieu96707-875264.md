## 3. 움직임

- 붙이기 · 거의 모든 종이가 같은 방식으로 나온다. 크기 0.85~0.9 에서 1.0 으로, 0.3~0.4초, 끝에 약간 넘쳤다 돌아오는 튕김(약 4%). 회전은 −3~+3° 에서 놓인 각도(±1~2°)로 간다.
- 오리기는 아래에서 올라온다(이동 약 60px, 0.4초). 자막 띠는 아래에서 밀려 올라온다(0.3초).
- 선 그리기 · 윤곽 그림·원·표 칸은 선이 앞에서부터 그려진다. 윤곽 하나에 0.8~1.0초. 원은 반 바퀴에 0.4초씩. 다 그린 뒤 0.1초 안에 안쪽 색이 한 번에 찬다.
- 카운트업 · 메모지 숫자가 1.5~2.5초 동안 오른다. 처음이 빠르고 끝에서 느려진다(ease-out). 작은 원 표지가 늘어나는 것과 같은 시간이다. 숫자 높이 약 10%(108px), 굵은 손글씨체, 천 단위 쉼표. 숫자가 끝값에 닿는 순간에 색종이가 메모지 둘레에서 터지고, 이 순간을 가장 큰 타격에 맞춘다.
- 작은 원 표지 · 하나씩 튀어나온다(0 → 1.15 → 1.0, 0.25초). 수십 개를 쓸 때는 0.03~0.05초 간격. 반원 호를 그리며 하나씩 솟게 배치하기도 한다(16개).
- 여러 장 튀어 들어오기 · 오리기 4장이 왼쪽부터 0.4초 간격으로 튀어 들어오고(크기 0.9 → 1.0), 이름 카드가 위에 하나씩 붙는다.
- 부딪치기와 도장 · 스티커 두 장이 양쪽에서 기울어 들어와 가운데에서 부딪치고, 0.5초 뒤 카드 한 장이 그 위를 덮고 빨간 원형 고무도장이 15° 기울어 찍힌다.
- 끝 카드 · 아래에서 올라오며 2° 기울었다가 바로 선다. 알약 버튼은 작게 튀어나와 커진다.
- 여는 카드 둘레에는 작은 원 표지 5개가 하나씩 튀어나오고, 손그림 밑줄(주황)이 왼쪽부터 그려진다. 화면 아래에서 작은 그림 하나가 속도선을 끌고 오른쪽으로 4.2초에 가로지른다.
- 장면 안의 붙이기 순서는 늘 같다 · 머리 라벨 → 주인공 오리기 → 자막 띠 → 이름 카드 → 도형 카드 → 메모지 숫자. 장면 하나에 4~6초.
- 움직임이 작고 고르다. 전환을 빼면 세기 1~4 사이다. 정지는 장면 끝 0.5~1.5초뿐이다.

## 4. 전환

- 단색 판 쓸기 · 화면 전체 크기의 단색 판이 오른쪽에서 왼쪽으로 지나간다. 0.3초에 화면을 덮고, 이어서 0.5~0.6초에 왼쪽으로 빠지며 새 장면을 드러낸다. 판의 가장자리는 곧은 세로선이다. 판 색은 장면마다 다른 파스텔이다(크림 #F9EFC5 → 하늘 #CEF5FD → 연두 #D6FCC6 → 살구 #F5DACA → 연보라 #C8C6CE → 크림 → 흰색, 모두 근삿값).
- 판이 지나가는 동안 새 장면의 머리 라벨이 이미 붙어 있다. 판이 빠지자마자 라벨이 보인다.
- 같은 카드가 이어질 때는 판 없이 머리 라벨과 카드 내용만 바꾼다.
- 끝 카드는 판 대신 0.2초 밝은 번쩍임 뒤에 아래에서 올라온다. 앞 장면이 카드 뒤에 그대로 남는다.

## 6. 가져올 것

- 핵심 장치 · 같은 바탕 위에 종이 5~8장을 늘 같은 순서(머리 라벨 → 주인공 오리기 → 자막 띠 → 이름 카드 → 도형 카드 → 메모지 숫자)로 붙인다. 붙이기는 크기 0.85~0.9 → 1.0, 0.3~0.4초, 넘침 약 4% 이고, 한 장면에 4~6초를 쓴다.
- 핵심 장치 · 화면 전체 파스텔 단색 판(밝기 85% 이상)이 오른쪽에서 왼쪽으로 0.3초에 덮고 0.5~0.6초에 빠지며 다음 장면을 드러낸다. 대략 2마디(5초)마다 온다.
- 핵심 장치 · 숫자 카운트업(1.5~2.5초, ease-out)과 작은 원 표지 늘리기를 같은 시간에 두어, 숫자가 무엇을 세는지 화면이 보여 준다. 끝값에 닿는 순간을 가장 큰 타격에 맞춘다.
- 핵심 장치 · 화면 아래 찢긴 종이 자막 띠(y 84~98%)는 자리를 고정하고 글자만 바꾼다.

## 7. 함정

- 원본 화면의 실존 로고·이름은 쓰지 않는다.
- 바탕을 실제 지도 타일로 만들지 않는다. SVG 로 가상의 길 그물과 굵은 곡선 띠 하나를 그린다.
- 주인공 오리기를 빼고 이름 카드만 두면 화면 왼쪽 절반이 빈다. 오리기 자리(x 5~38%, y 32~85%)는 반드시 무언가로 채운다(`## 8` 참고).
- 종이가 많아 복잡해 보이지만 한 화면의 붙인 종이는 5~8장이다. 10장을 넘기지 않는다.
- 단색 판 색을 진하게 하면 영상이 끊겨 보인다. 채도가 낮은 파스텔(밝기 85% 이상)을 쓴다.
- 자막 띠를 장면마다 새로 만들면 바쁘다. 원본은 띠 위치가 고정이고 글자만 바뀐다(판 전환 때 같이 쓸린다).
