## 4. 전환

- 단색 판 쓸기 · 화면 전체 크기의 단색 판이 오른쪽에서 왼쪽으로 지나간다. 0.3초에 화면을 덮고, 이어서 0.5~0.6초에 왼쪽으로 빠지며 새 장면을 드러낸다. 판의 가장자리는 곧은 세로선이다. 판 색은 장면마다 다른 파스텔이다(크림 → 하늘 → 연두 → 살구 → 연보라 → 크림 → 흰색).
- 판이 지나가는 동안 새 장면의 연도 라벨이 이미 붙어 있다. 판이 빠지자마자 라벨이 보인다.
- 37.5초와 39초는 판 없이 연도 라벨과 카드 내용만 바꾼다(같은 브라우저 카드가 이어진다).
- 끝 카드는 판 대신 0.2초 밝은 번쩍임 뒤에 아래에서 올라온다. 앞 장면(팀 사진)이 카드 뒤에 그대로 남는다.

  2. 3.0~3.8초 크림 판. 3.8~8.0초 연도 장면 1(인물 + 표 카드 체크 3개).
  3. 8.0~8.8초 하늘 판. 8.8~13.3초 연도 장면 2(지도 윤곽 + 핀 + 카운트업). 대표 장면이다. 4.5초를 준다.
  4. 13.3~14.1초 연두 판. 14.1~18.6초 연도 장면 6(지구본 선 그리기 + 카운트업 끝값 + 색종이). 숫자가 끝값에 닿는 순간을 큰 타격에 맞춘다.
  5. 18.6~19.4초 흰 판. 19.4~25.0초 팀 장면 2초 + 끝 카드 3.6초(버튼, 주소).
  - 빼는 장면 · 두 사람 장면(휴대폰·유리병), 합치기 장면(도장), 넷째 사람 장면(핀 반원), 브라우저 두 장면. 내용이 필요하면 자막 한 줄로 대신한다.
  - 전환 판을 0.8초로 줄인다(덮기 0.3초 + 빠지기 0.5초). 장면 안 정지는 0.5초까지 줄인다.
- 장면마다 붙이는 순서를 같게 둔다(연도 → 주인공 → 자막 → 카드 → 숫자).
- 숫자 카운트업과 핀 늘리기를 같은 시간에 둔다. 숫자가 무엇을 세는지 화면이 보여 준다.

## 7. 함정

- 실존 인물 사진 4명, 실존 로고, 실존 서비스 이름과 주소가 화면에 있다. 쓰지 않는다. 자막 문장, 이름, 숫자도 원작의 것이다. 역할(연도 라벨, 이름 카드, 한 문장 자막, 카운터)만 가져온다.
- 한 나라의 실제 윤곽을 그린 장면이 있다. 소개 대상과 관련된 지역 윤곽이나 가상 도형으로 바꾼다.
- 거리 지도 바탕이 실제 도시 지도처럼 보인다. 실제 지도 타일을 쓰지 않는다. SVG 로 가상의 길 그물과 강 하나를 그린다.
- 인물 사진을 빼고 이름 카드만 두면 화면 왼쪽 절반이 빈다. 사진 자리(x 5~38%, y 32~85%)는 반드시 무언가로 채운다(`## 8` 참고).
- 종이가 많아 복잡해 보이지만 한 화면의 붙인 종이는 5~8장이다. 10장을 넘기지 않는다.
- 단색 판 색을 진하게 하면 영상이 끊겨 보인다. 채도가 낮은 파스텔(밝기 85% 이상)을 쓴다.
- 자막 띠를 장면마다 새로 만들면 바쁘다. 원본은 띠 위치가 고정이고 글자만 바뀐다(판 전환 때 같이 쓸린다).

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 종이·테이프·사진 자리는 DOM/CSS 로, 손그림 선은 canvas(hand.js)나 SVG 로 만든다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 실존 인물 사진 오리기 | 실존 인물이라 쓰지 않는다 | 1순위 · 고객이 준 팀 사진(허락받은 파일)을 쓴다. 바탕을 지우고 흰 테두리 6px(`filter: drop-shadow` 4방향 0px 흰색) + 그림자(0 6px 12px rgba(0,0,0,.18))를 준다. 2순위 · AI 일러스트(codex-image)로 이름 없는 인물 상반신을 그린다. 프롬프트에 "플랫 일러스트, 단색 마젠타 바탕, 글자·로고 없음"을 넣고 `key.py` 로 바탕을 지운다. 한 사람에 1장. 3순위 · 사람 대신 대상의 사물(도구, 화면, 제품)을 같은 자리·크기로 붙인다 | 실제 얼굴의 친근함과 신뢰 |
| 실존 로고 | 쓰지 않는다 | 고객이 허락한 로고 파일만 쓴다. 없으면 대상 이름을 Pretendard SemiBold 96px 로 노트 카드 안에 쓰고 아래 주황 밑줄을 그린다 | 브랜드 인지 |
| 굵은 붓 손글씨체(연도·이름·숫자) | 손글씨 글꼴이 없다 | 숫자는 InterVariable 800 굵기 86~108px, `font-style: oblique 8deg` 로 기울이고 자간 −0.02em. 한국어 이름은 Pretendard SemiBold 44px. 연도 테이프만은 숫자를 SVG 로 직접 그려도 된다(획 굵기 14px, 끝을 둥글게) | 손으로 쓴 들뜬 느낌 |
| 찢긴 종이 가장자리(자막 띠) | 찢긴 섬유 결 | `clip-path: polygon()` 으로 위아래 가장자리에 점 60개를 두고 y 를 ±4px 씨앗 난수로 흔든다. 띠 색 #FBFBF6, 그림자 0 4px 10px rgba(0,0,0,.12). 한 번 정하면 장면 내내 고정 | 종이 섬유 |
| 마스킹 테이프 | 반투명 종이 결 | div 120x34px, 색 #E4C23A(연도)·#C59BE6·#9CD3EA·#A9E0A0, 불투명도 0.85, 양 끝을 `clip-path` 톱니(6px)로 자른다. 회전 −4~+4° | 테이프 결 |
| 손그림 선 윤곽이 그려지기 | 사람 손의 떨림 | `HAND.ink(ctx, P, { frac: p, w: 6, color: '#111', key: 'outline', B: 0 })`. 윤곽 하나 0.9초. 다 그리면 `HAND.paint` 로 #CEF5FD 를 채운다(외곽선 없음). 떨림 칸 B 는 0 으로 둔다(원본 선은 떨지 않는다) | 없음에 가깝다 |
| 거리 지도 바탕 | 실제 지도는 쓰지 않는다 | SVG 1920x1080 · 바탕 #D2D8D9, 가상의 길 80~120줄(흰색 #EAF0F1, 굵기 4~14px, 격자를 15~30° 비튼 것), 강 하나(굵기 40px 곡선, #A9B8C6). 로드 때 한 번 그린다 | 실제 도시의 결 |
| 카운트업 숫자 | 없다 | `n = round(끝값 × easeOutCubic(p))`, 1.5~2.5초. `Intl.NumberFormat('ko-KR')` 로 쉼표. 숫자 칸 폭을 끝값 기준으로 고정해 흔들리지 않게 한다(`font-variant-numeric: tabular-nums`) | 없음 |
| 색종이 터짐 | 없다 | canvas 로 작은 사각형 40개(8x4px, 핀과 같은 색), 0.8초 동안 반지름 0 → 220px, 중력 600px/s², 회전. 위치는 씨앗 난수로 고정 | 없음 |
| 고무도장 | 잉크가 번진 결 | SVG 원(지름 260px, 테두리 8px #E0633A, 안쪽 숫자) + `HAND.wobble` 로 원 경로를 2px 흔든다. 들어올 때 크기 1.4 → 1.0, 0.15초, 15° 기울임 | 번진 잉크 |
| 소리 | 이 노트는 듣지 못했다 | 박 96 BPM. 단색 판 전환을 2마디(5초)마다, 덮는 순간을 마디 첫 박 0.5초 앞에 둔다. 카운터 끝값과 색종이를 가장 큰 타격에 맞춘다. 끝 3초는 소리를 줄인다 | 원곡의 분위기(확인 못 함) |
