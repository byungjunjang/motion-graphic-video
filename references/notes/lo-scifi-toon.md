## 3. 움직임

- 원래 글의 움직임 규칙(인물 12fps, 카메라·차원 문 24fps, 준비 동작, 착지 눌림, 떨림)은 화면과 맞다.
- 영상에서 확인한 점 · 말하는 장면은 거의 멈춰 있다. 2.3~5.6초 움직임 세기 2.0~2.2, 말하는 컵과 노려보는 장면은 5~9 다. 움직이는 것은 입, 눈 깜빡임, 떠는 외곽선뿐이다. 이 정지가 웃음의 박자를 만든다.
- 큰 움직임은 컷과 소용돌이에 몰려 있다. 영상 안에서 인물이 크게 이동하는 장면은 빨려 들어가기(12.5초)와 컵 던지기(49~50초)뿐이다.
- 연속 프레임 차이를 재면(3.0초부터 12프레임) 0.8 과 3.5 안팎이 번갈아 나온다. 인물 그림은 두 프레임씩 머문다(초당 12장, 원래 글과 맞다). 0.8 은 한 프레임마다 움직이는 작은 요소다.
- 차원 문은 늘 돈다. 소용돌이 팔이 약 1초에 1/4 바퀴, 빛 무리가 조금씩 숨 쉰다. 방울 3개가 아래로 흔들린다.

## 4. 전환

- 원래 글의 규칙(전환은 이동 장치의 소용돌이나 하드 컷, 디졸브 없음)은 화면과 맞다.
- 영상에서 확인한 점 · 소용돌이 전환은 세 박자다. (1) 화면 안의 차원 문이 카메라 쪽으로 커진다 0.1~0.15초, (2) 소용돌이가 화면을 가득 덮고 옅어진다 1칸~0.1초, (3) 소용돌이가 가운데로 줄며 새 세계가 바깥부터 드러난다 0.15초. 합해서 0.25~0.5초다.
- 하드 컷은 대사의 끊김, 반응 얼굴, 사물 가까이에 쓴다. 컷 앞뒤에서 인물의 좌우 자리를 지킨다(조수 왼쪽, 과학자 오른쪽).

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 28.4~31.6초의 "같은 구도(차원 문 13%, 조수 21%, 과학자 36%, 세계의 생물 70~75%)로 세 세계를 1초씩 지나고, 세계마다 색 한 벌이 통째로 바뀌며, 그 사이를 0.25~0.4초 소용돌이 전환이 박 위에서 잇는" 3초다. 인물의 자리와 크기가 그대로인 것, 세계 색이 통째로 바뀌는 것, 매번 같은 짧은 반응 중 하나라도 빠지면 이 영상이 아니다.
- 12초 판 압축 예 · 0~1.5초 고장 난 기계를 사물 가까이(우리 주제의 작은 불편), 1.5~3.0초 두 사람 구도에서 조수가 말하다 끊긴다, 3.0~3.6초 과학자 얼굴로 하드 컷, 3.6~5.0초 차원 문이 열리고 제목 로고, 5.0~5.4초 소용돌이, 5.4~8.6초 대표 장면 3세계 몽타주, 8.6~10.0초 해결된 세계에서 우리 제품을 받는다, 10.0~11.0초 반전 하나(사물이 말을 건다)와 반응 얼굴, 11.0~12.0초 넓은 구도로 끝. 분홍·주황 세계의 긴 장면, 노려보는 정적, 끝 카드는 뺀다. 정적은 0.6초만 남긴다.
- 말하는 장면은 멈추고, 컷과 전환에서만 크게 움직이는 대비.
- 모든 이상한 그림 뒤에 반응 얼굴 한 컷.

## 7. 함정

- 원래 글의 저작권 금지선은 그대로 지킨다. 특히 이 영상의 차원 문(연두 소용돌이, 흰 가운데 점, 흘러내리는 방울, 빛 무리)은 잘 알려진 성인 만화의 차원 문과 아주 비슷하다. 우리 영상에서는 모양과 색을 바꾼다 · 연두 대신 주황·자홍 같은 다른 색, 소용돌이 대신 겹친 고리나 찢어진 종이 구멍, 방울을 빼기. 과학자의 겉모습(대머리, 이마 위 고글, 가운)도 그대로 쓰지 않는다.
- 화면의 제목, 인물 이름, 자막, 세계 이름표, 칠판 글씨, 크레딧은 원작의 것이다. 옮기지 않는다. 역할(제목 로고 하나, 말하는 사람 표시, 세계 이름표)만 가져온다. 크레딧에 실존 회사·글꼴·음성 도구 이름이 있다. 쓰지 않는다.
- 대사가 이 장르의 몸통이다. 이 저장소의 내레이션·음성은 ElevenLabs 로만 만든다. 커넥터가 없으면 대사를 소리로 못 낸다. 그때는 자막과 말풍선만으로 웃음을 만든다 · 대사를 4단어 이하로 줄이고, 끊기는 대사는 줄 끝에 대시를 두고 0.3초 뒤 하드 컷, 반응 얼굴은 0.8초 이상 둔다. 소리 없이 만든 판은 웃음의 박자가 약하다고 결과 보고에 적는다.
- 인물이 너무 많이 움직이면 이 장르가 아니다. 말하는 장면에서 움직임 세기가 3 아래로 내려가도 괜찮다. 외곽선 떨림은 멈추지 않는다.
- 세계마다 색을 조금씩만 바꾸면 몽타주가 안 읽힌다. 세계마다 바탕 색상을 60° 이상 돌린다(쑥색 → 분홍 → 주황 → 빨강 → 청회 → 보라·노랑).
- 한국어 글자 · 제목 로고를 Pretendard SemiBold 로 쓰면 장식 글자의 맛이 없다. 140px 이하로 두고, 크림색 채움 + 두 겹 그림자(분홍 6px, 검정 10px)와 타원 고리로 장식을 대신한다. 자막은 Pretendard SemiBold 40px 흰색 + 검은 테두리 3px(글자 그림자를 8방향으로 겹쳐 만든다).

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 인물 연기(자세, 표정, 입 모양) | 손으로 그린 만화 연기다 | 인물을 SVG 부품(머리, 눈 흰자, 눈동자, 눈꺼풀, 입 5모양, 몸, 팔 2자세)으로 나눠 그린다. 외곽선은 `HAND.ink(ctx, P, { w: 8, color: '#1C0E1B', key: 'part' + id, B, closed: true, amt: 1.5 })` 로 그린다(ink 가 안에서 `HAND.wobble` 로 흔든다). B 는 t 에 12 를 곱해 내린 정수를 3 으로 나눈 나머지처럼 t 에서만 만든다(초당 12번). 평면 색은 `HAND.paint(ctx, P, { fill, key, B, line: false })`, 그림자는 같은 부품을 왼쪽 아래로 14px 옮긴 모양으로 잘라 한 단계 어두운 색 | 관절이 휘는 부드러운 연기 |
| 인물의 큰 동작(빨려 들어가기, 던지기) | 동작마다 새 그림이 필요하다 | AI 일러스트(codex-image)로 같은 인물의 자세 4장(서기, 놀라 뒤로 젖히기, 빨려 늘어나기, 던지기)을 마젠타 바탕에 그리고 `scripts/key.py --split` 로 자른다. 프롬프트에 굵은 검은 외곽선 약 8px, 평면 색, 그라데이션 없음, 글자 없음을 적는다. 자세는 0.083초(2프레임)마다 바꾼다 | 부품 방식 인물과 겉모습이 조금 어긋난다 |
| 세계별 배경 | 장소마다 새 그림이다 | AI 일러스트로 세계 배경을 1536x1024 로 그린다(인물 없이, 글자 없이). 그림을 받은 뒤 canvas 에서 색을 6~8개로 줄여(가까운 색으로 바꾸기) 평면 색을 되살린다. 세계마다 바탕 색상을 60° 이상 다르게 | 배경 외곽선의 떨림(배경은 떨지 않게 둔다) |
| 차원 문 소용돌이 | 손그림 소용돌이 판이다 | canvas 에 로그 나선 팔 3개(r = 12·e^(0.18θ))를 두 색으로 칠하고 `t * 1.6` 라디안씩 돌린다. 외곽은 원에 `HAND.wobble` 진폭 10px, 외곽선 8px. 빛 무리는 방사형 그라데이션(지름 1.5배, 불투명도 0.35). 색은 원작과 다르게(`## 7`) | 손으로 그린 팔의 굵기 변화 |
| 소용돌이 전환 | 없다. 위 문 그림으로 된다 | 0.12초에 문 크기를 화면 대각선의 1.3배까지 점점 빠르게 키우고, 1칸 동안 흰색 불투명도 0.35 를 덮고, 0.15초에 원형 마스크 반지름을 0 → 대각선으로 키우며 새 세계를 연다. 전환의 가운데를 박 위에 맞춘다 | 없음에 가깝다 |
| 대사의 입 모양 맞추기 | 음성 파형을 읽어야 한다 | ElevenLabs 로 대사를 만들었으면 `scripts/audio-probe.py` 로 음량 곡선을 재서 1/12초마다 입 모양 5개 중 하나를 고른다(음량이 크면 크게 벌린 입). 소리가 없으면 자막이 보이는 동안 입을 3모양으로 0.17초마다 바꾼다 | 소리 없는 판은 말의 박자 |
| 제목 로고와 궤도 고리 | 장식 글꼴이 없다 | Pretendard SemiBold 120px, 크림 #FAF3D4, `text-shadow: 0 6px 0 #E8559A, 0 10px 0 #1C0E1B`. 고리는 SVG 타원(가로 1000px, 세로 160px, -6° 기울임, 하늘색 6px + 검은 외곽 3px)을 글자 뒤 반쪽, 앞 반쪽으로 나눠 그린다. 별 5개가 0.5초마다 깜빡인다 | 둥근 장식 글자의 귀여움 |
