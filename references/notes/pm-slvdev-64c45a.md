# AI 어시스턴트 홍보 · 쓰임새마다 색과 소품이 바뀌는 장면 — 분석 노트

> 여러 가지를 만들어 주는 AI 어시스턴트의 18초 홍보 영상(promo). 크림색 바탕의 굵은 질문으로 열고, 쓰임새 여섯 가지를 장면마다 다른 바탕색·소품·글꼴로 1.3~1.9초씩 보여 준다. 질문 → 쓰임새 6장면(휴대폰, 원고 종이, 막대 차트, 픽셀 게임 창, 브라우저 창, 코드 편집기) → 낱말 터널 → 두 낱말 답 → 앞 장면이 카드로 모이는 갤러리 → 끝 카드 순서다. 전환 10번이 모두 다르다. 쓰임새가 여럿인 도구·플랫폼·서비스 소개에 맞는다. 키네틱 타이포(kinetic typography) + 도형 소품, 에디토리얼(editorial).

소리 · 듣지 못했다. 측정값만 적는다. 소리 트랙이 없다.

## 1. 본질

- 색은 일곱 가지다. 크림(#F8F8E8·#F8E8E8 근처), 거의 검정(#181818 근처), 파랑(#2848D8 근처), 노랑(#E8D858 근처), 주황, 분홍, 초록이다. 뒤의 셋은 측정 상위 8색에 없다.
- 쓰임새 장면 하나는 네 가지로 이루어진다. 단색 바탕, 초점이 맞은 소품 하나, 가장자리의 흐린 작은 소품 2개 이상, 라벨 한 줄이다. 바탕색은 파랑 → 노랑 → 초록 → 주황 → 분홍 → 검정 순서다.
- 첫 화면의 도형(노란 원, 분홍·파랑 둥근 네모, 초록 조각, 주황 점)이 뒤 장면의 바탕색을 미리 보여 준다. 답 화면에서 같은 도형이 돌아온다.
- 소품은 모두 도형으로 그렸다. 휴대폰 목업(mockup), 종이 3장, 막대 차트 카드, 픽셀 게임 창, 브라우저 창, 코드 편집기다. 깊이는 그림자와 흐림(blur)으로 낸다.
- 아닌 것 · 사진, 화면 캡처, 3D 모델, 인물, 긴 문장, 한 글꼴로 통일한 타이포, 같은 전환의 반복.

## 3. 움직임

- 질문의 낱말은 들어오는 방식이 낱말마다 다르다. 첫 낱말은 회전하며 위에서 떨어진다. 셋째 낱말은 흐린 큰 글자에서 줄어든다. 넷째 낱말은 기운 채 아래에서 올라온다. 알약은 작은 네모에서 늘어나고 그 안에 글자가 하나씩 찍힌다.
- 라벨 등장은 두 가지다. 산세리프와 세리프 이탤릭 라벨은 글자가 마스크(mask) 아래에서 왼쪽부터 하나씩 올라온다. 슬랩 세리프와 고정폭 라벨은 한 글자씩 타이핑된다. 모두 0.3~0.4초다.
- 소품의 사건은 장면마다 하나다. 카드가 튀어나온다. 줄이 그어진다. 동전이 튄다(약 0.16초마다 착지). 캐릭터가 터진다. 단추가 눌린다. 오류 줄이 고쳐진다.
- 클릭은 두 번이다(8.63초, 16.43초). 커서가 멈추고 가는 원이 0.3~0.4초 동안 퍼진다. 끝 카드의 단추는 눌릴 때 조금 줄어든다.
- 멈춘 화면이 없다. 끝 카드도 2.4초 동안 약 1.3% 커진다.

## 4. 전환

- 전환 10번이 모두 다르다. 동심원 확대(1.4초) → 가로 밀기(3.23초) → 세로 밀기(4.53초) → 하드 컷(5.93초) → 검은 창으로 확대한 뒤 작은 카드에서 확대(7.57초) → 비스듬한 색 띠 3개 쓸기(9.2초) → 확대하며 겹치기(10.97초) → 원 열기(11.83초) → 축소(12.97초) → 카드 올라오기(14.7초).
- 전환 길이는 0.15~0.6초다. 밀기 두 번에는 움직임 흐림(motion blur)이 걸린다.
- 전환의 재료가 색이다. 동심원의 마지막 원(파랑)이 다음 장면의 바탕이 된다. 색 띠(노랑, 파랑, 검정)의 마지막 띠도 그렇다.
- 축소 전환은 답 화면 전체를 카드 한 장으로 줄인다. 앞의 여섯 장면이 카드로 다시 나온다.

## 5. 타이포

- 질문, 답, 제품 이름은 같은 글꼴이다. 아주 굵은 산세리프, 검정, 좁은 자간이다. 대문자 높이는 화면 높이의 약 12%(질문), 21%(답), 18%(제품 이름)다.
- 라벨은 장면마다 글꼴이 다르다. 굵은 산세리프(노랑), 세리프 이탤릭(검정), 굵은 산세리프(크림), 굵은 슬랩 세리프로 보이는 글꼴(검정), 보통 굵기 산세리프(검정), 굵은 고정폭(크림)이다.
- 라벨은 소문자 2~4낱말이다. 소문자 높이는 화면 높이의 8~10%다. 코드 장면만 두 줄이고 약 4.5%다.
- 낱말 터널은 한 화면에 여섯 글꼴과 여섯 색을 섞는다.
- 강조는 두 가지다. 질문의 마지막 낱말을 주황 알약에 넣고 4도쯤 기울인다. 답의 마침표를 주황 점으로 찍는다.
- 갤러리 위 두 줄은 굵은 산세리프(크림)와 세리프 이탤릭(노랑)이다. 끝 카드는 큰 이름, 주황 고정폭 버전, 검은 알약 단추(크림 글자 + 화살표)의 세 층이다.

## 6. 가져올 것

- "질문 → 쓰임새 여섯 개 → 그 밖의 것(낱말 터널) → 짧은 답 → 모아 보기 → 끝 카드" 뼈대.
- 장면 공식. 바탕색 하나 + 소품 하나 + 라벨 하나 + 사건 하나를 1.3~1.9초에 보여 준다.
- 첫 화면의 도형으로 뒤 장면의 색을 미리 보여 주고, 답 화면에서 같은 도형으로 돌아오는 구성.
- 다음 장면의 색으로 만드는 전환(동심원, 색 띠).
- 화면을 축소해 앞 장면을 카드로 다시 보여 주는 요약.
- 끝 카드에서 커서가 단추를 누르는 마지막 동작.

## 7. 함정

- 화면의 질문, 라벨, 답, 제작 방법을 밝히는 문장, 끝의 제품 이름·버전·주소는 원작의 것이다. 옮기지 않는다. 역할(질문, 쓰임새 이름, 답, 끝 카드 세 층)만 가져온다.
- 제작량이 많다. 18초에 장면 11개, 소품 6종, 전환 10종이다. 30~40초로 만들 때 장면 수를 늘리지 않는다. 장면 길이를 2~3초로 늘린다.
- 흐림에 기댄다. 초점 밖 소품과 밀기 전환이 흐림을 쓴다. 흐림 필터가 많으면 프레임 촬영이 느려질 수 있다. 흐림을 빼면 깊이가 사라진다.
- 소리가 없다. 장면 길이가 1.3~1.9초로 고르지 않다. 음악을 붙이려면 전환 시각을 박자에 다시 맞춘다.
- 한국어 글꼴은 여섯 갈래로 나누기 어렵다. 고딕·명조·고정폭에 굵기, 기울임, 색을 더해 구분한다.
- 소품 안의 작은 글자(코드, 장 제목, 카드 제목)는 읽히지 않아도 되게 만든다.
