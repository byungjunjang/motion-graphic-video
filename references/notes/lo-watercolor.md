# 수채 붓 · 비를 따라 걷는 한 장짜리 관찰 일지 — 분석 노트

> 따뜻한 미색 종이 한 장 위에서 풍경이 붓 자국으로 저절로 칠해지는 113.6초 영상. 카메라는 60초 동안 한 번도 끊지 않고 옆으로 걸어가며 마른 땅 → 관목 → 숲 → 큰 나무 → 우림으로 넘어간다. 화면 오른쪽 위의 강수량 숫자가 걸음에 따라 오른다. 중간에 불이 지나가고 검게 탄 나무에 새순이 다시 칠해진다. 종이색 안개가 풍경을 지운 뒤 지도 한 장으로 바뀌어 시간을 거꾸로 돌린다. 자연 다큐, 여행 경로, 과학 해설, 하나의 값이 변하는 구간을 따라가는 영상에 맞는다.

출처 · lo:watercolor. 색인에 든 원래 글은 약 7천 자의 스타일 명세다(본질, 움직임, 카메라 문법 표, 매체 함정, 숏 표, 칠해지기·흔들림·붓 가장자리 지우기·박자 맞춤·사건·지도의 구현 메모). 카메라 위치 함수와 붓 획 순서 공식까지 적혀 있어 글이 자세하다. 그러나 색 값, 화면 안의 요소 크기와 자리, 구역마다의 시각과 길이, 불 장면의 실제 진행, 끝의 긴 정지와 무음이 없다. 그래서 영상 프레임을 보고 이 노트를 썼다.
측정 · 파일 1280x720 · 60fps · 113.6초. 크기는 1920x1080 기준으로 바꿔 적는다(1.5배). 하드 컷은 없다(장면 감지 0회). 움직임 세기는 프레임 사이가 짧은 60fps 라서 전체가 낮다. 0~10초는 0.0~0.7, 걷는 구간은 13~35초 1.3~3.1, 36~56초 3.3~11.8, 59~70초 9~16 으로 점점 커진다. 걷는 구간의 최대는 71.5초(21.9, 안개가 오른다)다. 72.5초부터 끝까지는 대부분 0.0~2.5 다. 7.5·104.5·107.5초의 3.5 한 칸은 0.05초 단위로 다시 재면 변화가 0 이라서 측정 잡음으로 본다. 색 값은 프레임에서 잰 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. 박 검출 79.95 BPM(박 약 0.75초, 마디 약 3.0초). 원래 글은 박 간격을 약 0.58초로 정했다. 0.75초와는 절반·두 배 관계가 아니고, 11.8~16초의 타격 간격도 어느 쪽으로 딱 맞지 않아 판단하지 못했다. 가장 큰 타격은 7.22초(세기 1.00)다. 제목이 다 나온 뒤 멈춘 화면이다. 47.74~56.31초에 큰 타격(0.5~0.87)이 몰린다. 새순과 큰 나무 기울기 구간이다. 무음은 0.00~0.68초, 21.60~22.22초(구역 바뀜 직전), 100.72~102.64초(지도 끝), 104.42초부터 끝까지 9.2초다.

## 1. 본질

- 원래 글의 핵심(종이 한 장이 바탕이자 지우개, 모든 것이 반투명 붓 자국, 구조 → 세부 순서로 칠해짐, 손글씨 주석 층)은 화면과 맞다. 되풀이하지 않는다.

  - 사막 땅 · #E3B99A ~ #DEAB88, 먼 언덕 #CC805E. 숲 땅 · #C1AF8A ~ #DDC19A. 우림 땅 · #A7B299.

## 3. 움직임

- 원래 글의 움직임 규칙(칠해지기가 주된 움직임, 다 칠한 뒤에만 흔들림, 붓 가장자리 지우기, 안개로 지우기, 부드러운 속도 곡선)은 화면과 맞다.
- 영상에서 확인한 점 · 나무는 화면 오른쪽 약 20% 안에서 칠해진다. 화면 가운데에 올 때는 이미 다 칠해져 있다. 그래서 화면 오른쪽 끝에는 늘 덜 칠한 나무가 한두 그루 있다.
- 불 장면은 "칠해지기의 반대"다. 잎이 지워지고 검은 가지 그림으로 바뀐 뒤, 같은 가지 위에 연두 잎 획이 다시 칠해진다. 원래 글은 불 앞선이 3초에 지나간다고 정했다. 화면에서는 첫 불꽃(42.0초)부터 불이 빠질 때(47.0초)까지 약 5초다.
- 걷는 구간 움직임 세기는 13초 1.5 에서 64초 12.5 로 거의 꾸준히 커진다. 구역이 바뀔수록 화면 안 물체가 많아져서다.

## 4. 전환

- 하드 컷이 한 번도 없다. 원래 글에 있다.
- 영상에서 확인한 점 · 큰 전환은 셋이다. 10.3~13.5초 물결 가장자리 공개(왼쪽 → 오른쪽, 약 3초), 70.5~73.0초 안개 지우기(아래 → 위, 약 2.5초), 101~104초 지도를 30% 로 옅게 하고 제목 겹치기.
- 구역이 바뀔 때는 왼쪽 위 이름과 아래 설명만 바뀐다. 이름은 바뀌기 직전 약 0.5초 비고(23.0초, 34.0초) 새 이름이 왼쪽 → 오른쪽으로 닦여 나온다. 21.60~22.22초 무음이 구역 1 끝에 있다.
- 끝 9.2초는 무음 + 정지다. 원래 글에 없다.

## 5. 타이포

- 제목·구역 이름은 세리프, 부제·설명은 기울인 세리프, 숫자 눈금과 머리표는 작은 고정폭이다. 손글씨 이름표(지시선 끝)는 작은 기울인 필기체로 약 1.2~1.5%.
- 강수량 값은 기호 `≈` 와 숫자, 단위로 된 한 줄이다. 값이 걷는 내내 바뀌는 것이 이 영상의 시계 노릇을 한다.
- 글자는 모두 #3A3028 근처 짙은 밤색이다. 강조색 글자는 없다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 41.5~51.0초의 "쉬지 않는 옆 걷기 속에서 땅에 불꽃 줄이 번지고(가로 45~80%), 회녹색 나무 7그루가 차례로 검은 가지 그림으로 바뀌고, 재 띠가 땅을 덮은 뒤, 같은 가지에 연두 잎 획이 다시 칠해지는" 장면이다. 지평선은 세로 68.5%, 나무 높이는 화면의 45~55%, 오른쪽 위 강수량 숫자는 그동안 계속 오른다. 칠해짐 → 지워짐 → 다시 칠해짐과 끊기지 않는 걷기가 빠지면 이 영상이 아니다.
- 12초 판 압축 예 · 0~1.5초 빈 종이에 지평선이 그어지고 해가 찍힌다(제목 한 줄 0.8초), 1.5~3.0초 풍경이 물결 가장자리로 드러나며 걷기 시작(마른 땅), 3.0~5.0초 걷기 2초 동안 나무가 오른쪽에서 칠해지며 땅빛이 붉은 흙 → 누런 풀로 바뀐다, 5.0~9.0초 대표 장면 4초(불꽃 1.0 + 검은 나무와 재 띠 1.5 + 새순 칠하기 1.5), 9.0~10.0초 걷기가 빨라지며 초록 숲이 한꺼번에 칠해진다, 10.0~11.0초 안개가 아래에서 올라와 지운다, 11.0~12.0초 빈 종이에 단순한 지도 윤곽과 손글씨 이름표 하나. 큰 나무 기울기, 지도의 시간 되감기, 끝 9초 정지는 뺀다.
- 화면 구석의 숫자 하나가 걸음에 따라 오르게 해서 이동을 값의 변화로 읽히게 한다.
- 구역마다 땅빛을 바꾸고, 바뀌는 순간에는 구역 이름만 닦아 바꾼다.
- 화면 오른쪽 끝에서만 칠해진다. 가운데는 늘 완성된 그림이다.

## 7. 함정

- 화면의 제목, 구역 이름, 설명 문장(두 언어), 손글씨 이름표, 끝 크레딧은 원작의 것이다. 옮기지 않는다. 역할(제목 한 줄, 구역 이름, 강수량 값, 한 줄 설명)만 가져온다. 끝 크레딧에 실존 회사·서비스 이름과 음악 정보가 있다. 쓰지 않는다.
- 지도는 실존 대륙의 윤곽이다. 붉은 둥근 바위는 실존 명소를 떠올리게 한다. 둘 다 옮기지 않는다. 우리 영상은 주제에 맞는 땅을 그리고, 실존 지역이면 사용자가 허락한 지도 자료만 쓴다. 뛰는 동물과 특정 식물 이름도 주제가 같을 때만 쓴다.
- 원래 글의 카메라 위치 숫자는 원작 세계 크기(약 9800px) 기준이다. 12초 판에 그대로 쓰면 너무 빠르다. 걷는 속도는 화면 가로의 6~11%/초(초당 120~210px)를 목표로 하고 사건 앞에서 절반으로 줄인다.
- 칠해지기를 화면 전체에서 한꺼번에 하면 슬라이드 공개가 된다. 칠해지는 자리를 화면 오른쪽 20% 로 묶는다.
- 처음 6초 정지(4.0~10.3초)와 끝 9초 정지는 원작이 긴 영상이라 가능한 길이다. 12초 판에서 정지는 1초를 넘기지 않는다.
- 박자 맞춤 동작(동물의 뜀)은 우리 음악의 박으로 다시 계산한다. 원래 글의 박 간격과 측정값이 맞지 않는다. `scripts/audio-probe.py --onsets --write` 로 우리 음악의 박을 잰 뒤 정한다.
- 원래 글의 함정 절(수채 판이 짧으면 기울일 때 이음이 보인다, 판 끝이 딱 끊기면 이음이 보인다, 매 프레임 획을 새로 만들면 느리다)은 그대로 맞다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 바탕 세계는 가로 5760px(화면 3배), 세로 1080px 띠로 둔다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 반투명 붓 획과 갈라지는 붓털 자국 | 붓털이 끊기는 마른 붓 자국 | 줄기·가지는 `HAND.ribbon(ctx, P, u => 6 * (1 - u) + 1.5, { color: '#8A7A66' })`, 잎은 짧은 `HAND.ribbon` 획 30~80개(길이 14~28px, 투명도 0.55, #78886A·#88987C 번갈아). 붓털 자국은 같은 경로를 2px 옆으로 옮겨 `HAND.subPath` 로 앞부분만 끊어 3~4번 겹친다 | 붓털이 점선으로 갈라지는 결 |
| 나무가 획 순서대로 칠해지기 | 없다. 코드로 된다 | 나무마다 획 목록(줄기 → 가지 → 잎 덩어리)을 로드 때 정한다. 진행값 p = (오른쪽 가장자리 기준 위치 - 나무의 화면 x) / 380px 를 0~1 로 자르고, 획 i 는 p 의 [i/N, i/N + 0.3] 구간에서 `HAND.ink` 의 `frac` 처럼 0 → 1 로 그린다. 다 그린 나무만 skewX 0.006 × sin(1.15t + φ) 로 흔든다 | 없음 |
| 넓은 수채 땅·하늘·먼 산 | 큰 면의 번짐 | `HAND.washPlate(5760, 340, P, { seed, layers: 30, alpha: 0.04, color: '#DEAB88' })` 를 구역마다 색을 바꿔 4장 굽는다(#DEAB88 · #DDC19A · #C1AF8A · #A7B299). 판 사이는 가로 600px 그라데이션 마스크로 잇는다. 먼 산 2겹도 같은 방법, 시차 0.3·0.5 | 물감이 고인 가장자리의 우연한 결 |
| 종이 결 | 실제 면 종이 | `texTile(seed, { mc: '120,95,60', mottle: .03, dark: .04, light: .05, fibers: 200, specks: 20 })` 를 바탕 #EAE2D3 위에 곱하기로 깐다 | 큰 얼룩의 자연스러움 |
| 불꽃과 재 띠 | 불꽃이 흔들리는 붓 그림 | 불꽃은 물방울 모양 경로(높이 30~110px)를 `HAND.paint(ctx, P, { fill: '#E08038', key: 'f' + i, B })` 로 칠하고 B 를 초당 8번 바꾼다(`HAND.wobble` 떨림). 불 앞선은 세계 좌표에서 5초에 화면 가로 70% 를 지난다. 재 띠는 땅에 #8A7A60 판을 투명도 0 → 0.35 로 덮는다. 나무는 앞선이 지날 때 #38281E 가지 그림으로 바꿔치기한다 | 불꽃 하나하나의 손맛 |
| 안개 지우기·물결 공개 | 없다 | 종이색 #EAE2D3 판 두 장의 위 가장자리를 사인파 두 개 합(진폭 30px·12px, 파장 900px·320px)으로 만들고 2.5초에 화면 아래 → 위로 올린다. 두 판은 0.4초 어긋나게. 처음 공개는 같은 물결을 세로로 돌려 clip 으로 쓴다 | 없음 |
| 실존 지역 지도 | 실제 지형 자료 | 우리 주제의 지역이 있으면 사용자가 허락한 윤곽 자료를 SVG 경로로 쓰고 `HAND.ink` 로 해안선을 부분씩 그린다. 칸 색 채움은 24px 격자 칸마다 값 → 5단 색(#D59B70 · #D3B77F · #B9B98A · #8CA67E · #50765B)을 칠하고 가장자리를 `HAND.washPlate` 판으로 곱한다. 지역이 없으면 지도 장면을 빼고 "걸어온 길" 한 줄 선 도식으로 바꾼다 | 실제 땅 모양이 주는 설득력 |
| 세리프·기울인 세리프·손글씨 | 해당 글꼴이 없다 | 구역 이름 Pretendard SemiBold 64px, 부제·설명 Pretendard Regular 30px #3A3028. 강수량 값은 InterVariable 72px, 눈금 InterVariable 16px. 손글씨 이름표는 Pretendard Regular 24px 에 `HAND.ink` 로 그린 지시선(굵기 1.5px, 0.4초)을 붙인다 | 세리프의 책 느낌과 필기체의 손맛 |
