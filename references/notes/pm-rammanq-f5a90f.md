# 투자 분석 서비스 기능 순회 · 3초 12장과 점 이어받기 — 분석 노트

> 여러 증권사 계좌를 모아 보여 주는 투자 포트폴리오 분석 서비스의 42초 소개 영상이다. 정사각 화면에 섹션 라벨 + 두 줄 제목 + 그래프 하나 + 설명의 같은 틀을 12번 되풀이하고 한 장을 약 3초에 넘긴다. 인트로(자산 이름 낱말 4개) → 기능 12장(자산 추이, 비중, 보유 종목, 배당, 지수 비교, 폭락기 재현, 미래 모의실험, 위험-수익 산점도, 옵션, 채권, 세금 서식, 모바일 AI 비서) → 끝 카드 순서다. 앞 장의 점과 선이 다음 그래프의 출발점이 되어 컷 없이 이어진다. 기능이 많은 데이터 도구·핀테크 소개에 맞는다. 인포그래픽(infographic) + 미니멀 UI.

## 3. 움직임

- 한 장은 약 3초다. 제목 → 그래프 그리기와 숫자 세기(약 1초) → 설명 → 정지(약 1초) → 나가기. 제목은 약 3초 간격이다(03~11장은 x.75초).
- 제목 두 줄은 마스크(mask) 아래에서 0.1초 차로 올라오고 나갈 때 위로 빠진다. 설명은 낱말 단위로 차례로 나타난다.
- 09·10장은 정지 없이 점이 선을 오가고 점 위 알약의 값이 같이 바뀐다.
- 인트로 낱말은 옛 낱말이 위로 빠지는 약 0.1초 동안 새 낱말이 아래에서 올라온다.

## 4. 전환

- 교체 13번이 같은 순서다. 설명·그래프가 옅어진다 → 제목이 위로 빠진다 → 남은 요소가 새 자리로 간다 → 새 제목이 올라온다. 나가기 시작부터 새 제목까지 0.35~0.55초다.
- 13번 가운데 11번은 앞 장의 요소를 넘긴다. 로고 → 한 점 → 선 출발점, 선 끝점 → 도넛 가운데, 로고 → 막대 줄 → 달력 칩, 지수 로고 → 선 도착점, 선 끝점 → 다음 선 출발점, 선 다발 끝 → 점 기둥 → 산점도, 곡선 → 손익선 → 내려가는 선, 칩 → 휴대폰.
- 바탕색이 바뀌는 8번은 0.2초쯤 회색이나 옅은 파랑을 거치는 교차 페이드다.

## 5. 타이포

- 굵은 그로테스크 산세리프(grotesque) 한 가지. 자간이 좁다. 문장형이고 마침표·쉼표·물음표로 끝난다.
- 대문자 높이(화면 높이 대비)는 인트로 낱말 약 12%, 제목 약 6%, 큰 금액 약 5%, 설명 약 2%, 라벨 약 1.5%다. 가장 긴 제목 줄은 화면 너비의 약 70%다.
- 제목 첫 줄은 밝은 바탕에서 검정, 어두운·파랑 바탕에서 흰색이다. 둘째 줄은 파랑이고 파랑 바탕에서만 남색이다.
- 라벨은 자간을 넓힌 작은 대문자다(번호 회색, 이름 파랑). 설명은 보통 굵기이고 숫자와 핵심 낱말만 파랑이다.
- 왼쪽 여백은 화면 너비의 약 7%다. 끝 카드만 가운데 정렬이다.

## 6. 가져올 것

- "3초 한 장 × 12장" 기능 순회. 틀을 되풀이해서 시청자는 그래프만 새로 읽으면 된다.
- 요소 이어받기 전환. 앞 그래프의 점과 선을 지우지 않고 다음 그래프의 출발점으로 옮긴다.
- 두 줄 제목. 첫 줄은 질문이나 사실, 둘째 줄은 파랑으로 받는 짧은 말.
- 숫자를 그래프에 묶어 센다. 금액이 자라는 선의 끝점을 따라간다.
- 말풍선 문답(질문 타이핑 → 답) 다음 앱 아이콘이 커지는 끝 카드.

## 7. 함정

- 화면의 제목 문장, 섹션 이름, 종목·지수·서식 이름, 금액·백분율, 워드마크, 주소는 원작의 것이다. 옮기지 않는다. 역할만 가져온다.
- 원작은 실존 회사 로고를 종목 배지로 쓴다. 허락 없이 쓰지 않는다. 색 원 + 머리글자의 가상 배지로 바꾼다.
- 원본은 정사각 720x720이다. 16:9로 옮기면 세로가 좁아진다. 제목·설명은 왼쪽 열(너비 약 40%), 그래프는 오른쪽으로 나눈다. 칩 격자는 4열 4줄로, 인트로 로고는 가로로 넓게 다시 놓는다.
- 그래프 12가지를 모두 코드로 그려야 한다. 선 다발은 canvas로 그리고 난수 씨앗을 고정한다. 이어받기는 앞 장의 끝 좌표와 다음 장의 출발 좌표가 맞아야 한다.
- 설명은 완성된 뒤 0.7~1.4초만 보인다. 한국어 설명은 한 줄로 줄인다. 기능이 적으면 장을 줄이고 한 장을 늘린다.
- 제목 간격 3초는 120 BPM의 박 6개다. 다른 빠르기의 음악이면 간격을 다시 잡는다.
