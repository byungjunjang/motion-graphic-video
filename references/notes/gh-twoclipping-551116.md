# 코발트 햇살 포스터 · 정사각 출시 예고편 — 분석 노트

> 코발트 파랑과 먹색이 엇갈리는 햇살 무늬 위에서 크림색 원반 하나가 이름이 되고, 상자가 되고, 섭외 무대가 되고, 휴대폰 네 대가 되고, 끝에 반원 포스터가 되었다가 다시 원반으로 접히는 25초 정사각 영상. 실제 사람이 찍은 짧은 영상이 디자인 안에서 재생된다. 화면이 한 번도 멈추지 않고, 장 사이는 0.3~0.5초의 색 덮기와 미끄러짐으로 이어진다. 크리에이터 섭외·광고 제작·마켓플레이스처럼 "사람을 고르고 결과물을 받는" 서비스의 출시 예고편에 맞는다. 큰 소리 포스터 · 옵아트 햇살 · 박자 지도.

## 3. 움직임

- 카메라가 쉬지 않는다. 장마다 1.03~1.07배의 느린 다가가기가 걸려 있다. 측정 세기의 최소값 4.1 이 이를 보여 준다.
- 바탕 무늬가 쉬지 않는다. 햇살은 두 고리가 서로 다른 속도로 계속 돌고, 물결은 가로로 계속 흐른다. 박에 맞춰 끊어 돌리지 않는다.
- 글자는 튀어나오지 않는다. 글자마다 아래 마스크 선 밑에서 위로 올라온다(한 글자 약 0.06~0.08초 간격). 이름만 캐럿 타이핑이다.
- 스티커는 부드럽게 들어와 붙은 뒤 천천히 흔들린다(±2~3°).
- 상자는 직교 투영이다. 원근이 없어 면의 크기가 회전 중에도 같다. 면은 방향에 따라 밝기만 바뀐다.
- 섭외 무대의 사람 바뀜은 회전목마식 미끄러짐이다(약 0.5초). 원반이 오른쪽에서 왼쪽으로 지나가며 크게 흐려진다.
- 숫자는 오른다. 일치율, 조회 수, 꼬리표 숫자가 0.5~1초 동안 올라간다.
- 움직임 세기 평균 16.2 는 이 저장소 레퍼런스 가운데 높은 편이다. 화면 안의 무늬 회전과 미끄러짐이 늘 일어나기 때문이다.

## 4. 전환

- 하드 컷과 겹침 전환이 없다. 모든 장 사이가 같은 물체의 변형이나 미끄러짐이다.
- 덮기 · 원반이 커져 화면을 덮는다(3.3~3.6초). 분홍이 원반에서 퍼진다(15.6~16.0초). 덮은 뒤에는 원 대신 화면 크기 사각형으로 바꾼다.
- 물러나기 · 크림 화면이 그대로 상자의 앞면이 된다(5.0~5.5초).
- 회전 · 상자를 돌려 다음 헤드라인 면을 보인다(0.5초씩 두 번).
- 휙 넘김 · 책상이 위로 빠지고 무대가 아래에서 들어온다(10.0~10.75초). 이 영상에서 유일하게 흐림이 화면 전체에 걸리는 전환이다.
- 바닥 빠짐 · 분홍 면이 아래로 떨어지며 뒤의 햇살이 드러난다(18.0초).
- 변형 · 티켓 몸통 → 아치(20.25초), 아치 → 원반(24.5초).
- 색 바뀜은 약 0.35초에 걸쳐 바뀐다. 0.1초 안에 바뀌는 곳이 없다.

## 5. 타이포

- 이름 · 아주 굵은 좁은 고딕 소문자. 열기 원반 안에서 글자 높이(소문자 몸통) 약 85px(7.9%), 포스터에서 가장 큰 글자(어센더 포함) 약 200px(18.5%), 단어 폭 530px(49%). 먹색.
- 헤드라인 · 아주 굵은 넓은 고딕 대문자. 크림 장에서 대문자 높이 약 140px(13%), 왼쪽 여백 약 6%. 휴대폰 장에서 약 105px(9.7%), 가운데 정렬.
- 무대 이름 · 아주 굵은 좁은 대문자, 분홍. 약 70px(6.5%).
- 라벨 · 고정폭 대문자. 장 번호, 동사 한 낱말, 꼬리표, 분야·팔로워, 정보 줄. 글자 높이 14~24px(1.3~2.2%). 자간이 넓다.
- 마침표가 없다. 헤드라인과 이름 뒤에 마침표를 찍지 않는다.
- 화면의 이름, 헤드라인, 사람 이름, 날짜, 주소는 원래 글의 기본값이나 가상 값이다. 옮기지 않는다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 10.75~12.25초. 물결 무대 위에 지름 37%의 큰 원반(흑백 영상), 그 둘레 얼굴 원 12개(각 8%)의 아치, 아래 먹색 무대 상자(가로 75%), 분홍 이름과 오르는 일치율, 원반 옆 귤색 티켓과 스티커 두 개, 오른쪽 위 꼬리표. 요소가 동시에 약 19개 보인다. 도장이 찍히며 영상이 컬러로 바뀌고 다음 사람이 미끄러져 들어온다. 원반과 아치가 없거나 사람이 바뀌지 않으면 이 영상이 아니다.
- 12초 판 압축 예 · 0~1.5초 햇살 위 원반에 이름 타이핑. 1.5~1.8초 원반이 화면을 덮는다. 1.8~3.3초 크림 헤드라인 → 상자로 물러나 한 번 회전. 3.3~3.6초 휙 넘김. 3.6~7.6초 섭외 무대(세 사람, 사람마다 약 1.3초). 7.6~7.9초 분홍 덮기. 7.9~9.5초 휴대폰 셋이 펴지고 헤드라인. 9.5~11.5초 아치 포스터와 정보 줄. 11.5~12초 원반으로 접힌다. 책상 장과 대기 명단 티켓은 뺀다.
- 원반 하나가 끝까지 형태를 바꾸는 이음. 처음과 끝이 같은 원반이라 반복 재생에 맞는다.
- 흑백 → 컬러로 "선택"을 보여 주는 방법. 도장 + 색 바뀜이 한 박 안에 일어난다.
- 박자 지도로 장을 나누는 방법. 장 길이가 4·2·2·6·12·5·5·10박이다. 무대가 가장 길다.
- 덮은 뒤 사각형으로 바꾸기, 상자를 직교 투영으로 그리기 같은 원래 글의 함정 처리.

## 7. 함정

- 화면의 이름, 구호, 헤드라인, 사람 이름, 수치, 날짜, 주소는 옮기지 않는다. 역할(이름 한 단어, 구호 한 줄, 헤드라인 세 개, 사람 이름 + 분야 + 일치율, 정보 줄 세 칸)만 가져온다.
- 실제 사람의 얼굴 영상이 핵심이다. 사용자가 준 영상이 없으면 이 영상을 만들 수 없다. 얼굴 영상을 인터넷에서 찾아 내려받지 않는다. 대체는 `## 8` 에 있다.
- 스티커는 실제 물건 사진이다. 외부 무료 사진을 내려받지 않는다. AI 일러스트(글자·로고 없이)로 그린다.
- 정사각을 16:9(1920x1080)로 옮기는 구도.
  - 주인공 부품은 가운데 1080x1080 칸(가로 420~1500px)에 원래 좌표 그대로 둔다. 원반 지름 514px, 무대 원반 400px, 아치 820px 를 바꾸지 않는다.
  - 햇살 무늬는 중심을 (960, 540)에 두고 반지름을 1100px 로 늘려 양옆 420px 씩을 채운다. 물결은 폭 1920px 로 그냥 늘인다.
  - 섭외 무대의 얼굴 원 아치는 12개 → 16개로 늘리고 반원 폭을 900px → 1300px 로 넓힌다(가로 16~84%). 무대 상자는 폭 805px → 1100px(가로 21~79%).
  - 휴대폰은 네 대 → 다섯 대, 각 폭 230px(12%), 가로 8~92% 에 부채꼴로 둔다.
  - 꼬리표·장 번호 같은 모서리 라벨은 각 모서리에서 60px 안쪽으로 옮긴다. 스티커는 양옆 빈칸(가로 5~20%, 80~95%)에 둔다.
  - 포스터 테두리 글자 띠는 위아래 두 변만 남기고(높이 45px), 양옆 변은 뺀다.
- 원래 글의 금지 목록(흰 번쩍임, 튀는 등장, 박에 끊기는 회전, 겹침 전환, 하드 컷)을 지키지 않으면 포스터가 싸 보인다. 측정으로 확인한다. `render.mjs --snap` 시트에서 같은 화면이 0.5초 넘게 이어지면 고친다.
- 영어 넓은 글자를 한국어로 옮기면 넓은 굵기 맛이 없다. Pretendard SemiBold 에 자간 0.02~0.04em, 장평 대신 `transform: scaleX(1.15)` 를 조금 쓴다. 한국어 글자는 140px 를 넘기지 않는다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1080x1080 기준이다(16:9 로 옮기면 `## 7` 의 좌표를 쓴다). 글꼴은 Pretendard Regular·SemiBold, 숫자·라틴은 InterVariable 이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 실제 사람 얼굴 영상 | 사용자가 준 영상이 있어야 한다 | 영상이 있으면 원래 글대로 ffmpeg 로 30fps 낱장을 뽑아 canvas 에 그리고 `ctx.filter = 'grayscale(1)'` 을 선택 전까지 건다. 없으면 AI 일러스트(codex-image, 글자·로고 없이) 인물 반신 그림 4장을 원반 안에 넣고 1.03배로 천천히 키운다 | 말하는 사람의 생기 |
| 오린 사진 스티커 | 실제 물건 사진 | AI 일러스트로 물건 6개를 마젠타 바탕 한 장에 그리고 `scripts/key.py --split` 으로 자른다. 흰 칼선은 투명도 테두리를 8px 넓힌 흰 판을 뒤에 깔고, 그림자는 `drop-shadow(0 6px 10px rgba(0,0,0,.35))` | 사진의 질감 |
| 옵아트 햇살 | 두 고리의 엇갈린 바큇살 | canvas 에 바큇살 24개짜리 고리 두 개(안쪽 반지름 260~600px, 바깥 600~1100px)를 #3341f5 / #181421 로 번갈아 칠한다. 안쪽은 초당 6°, 바깥은 초당 -4° 로 돈다. 마지막 프레임에 처음과 같은 무늬가 되게 속도를 맞춘다 | 없음 |
| 물결 바탕 | 없다. canvas 로 된다 | 사인 곡선 9줄(진폭 14px, 파장 260px, 굵기 18px, #2a37d6)을 초당 40px 로 가로로 흘린다 | 없음 |
| 직교 투영 상자 | three.js 없이 면 세 개 | 원래 글대로 면마다 1080px 화면 밖 canvas 를 만들고 `ctx.setTransform` 로 평행사변형에 그린다. 옆면은 밝기 0.75, 윗면 1.1 | 없음 |
| 회전목마 미끄러짐의 흐림 | 움직임 흐림 | 원래 글대로 프레임마다 보조 프레임 8장을 겹친다. 무겁다면 미끄러지는 부품에만 가로 `filter: blur(6px)` 를 0.2초 건다 | 자연스러운 흐림 꼬리 |
| 필름 그레인 | 프레임마다 다른 결 | `grainLayer(parent, seed)` 를 화면 위에 얹는다 | 실제 필름 결 |
| 넓은·좁은 굵은 라틴 글자 | 그 글꼴이 없다 | 라틴 이름은 InterVariable 굵기 900 에 `scaleX(0.82)`(좁게) 또는 `scaleX(1.2)`(넓게). 한국어는 Pretendard SemiBold 120~140px | 글꼴 고유의 획 모양 |
| 도장 | 잉크가 덜 묻은 결 | SVG 둥근 사각 테두리 4px + 굵은 글자, 분홍 #f277bc, -8° 기울기. `HAND.stipple` 로 바탕색 점(크기 2px, 300개)을 얹어 덜 묻은 곳을 낸다 | 실제 도장 번짐 |
