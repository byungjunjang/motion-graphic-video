# 입체 지도 해설 · 우주에서 떨어져 바다를 자르는 한 대의 카메라 — 분석 노트

> 밤 쪽 지구본에서 시작해 한 좁은 해협으로 떨어져 들어가는 52초 해설 영상. 높이를 과장한 사막색 지형 위에 빛나는 호박색 선(항로·측정선·관로)만 얹는다. 카메라가 해협의 가장 좁은 줄을 재고, 바다 높이로 내려가 지도를 반으로 잘라 바다 밑 단면을 세우고, 항로를 따라 낮게 날고, 물량을 쌓인 원통 기둥으로 세운 뒤, 다시 지구본으로 물러난다. 지리·물류·에너지·기후처럼 "어디에서, 얼마나"를 숫자로 설명하는 해설 영상, 장소 하나가 왜 중요한지 보여 주는 영상에 맞는다.

출처 · lo:map-explainer. 원래 글은 약 7천 자의 스타일 명세다(본질, 움직임, 카메라 문법, 자료 사용 조건과 함정, 시각이 붙은 숏 표). 글은 숏마다 시각과 카메라를 이미 정했다. 그러나 실제 색 값(지형·바다·빛나는 선·기둥), 빛나는 선의 굵기, 단면의 화면 크기, 결론 화면의 기둥 크기, 글자 크기와 자리가 없다. 숏 표에 적힌 박자와 측정한 박자가 다르다. 그래서 영상 프레임을 보고 이 노트를 썼다.

## 3. 움직임

- 원래 글의 움직임(카메라는 멈추지 않는다, 선은 근원에서 자란다, 머리가 밝은 점화, 높이에 따른 안개·번짐 변화)은 화면과 맞다.
- 영상에서 확인한 점 · 실제로는 두 번 "거의 멈춘다". 단면 16.5~19.0초(움직임 세기 0.5~2.5)와 결론 35.5~39.0초(0.6~1.5)다. 읽어야 하는 화면에서 카메라를 사실상 세운다. 움직임 세기가 1 아래로 내려가도 느린 흐름은 남아 있다.
- 큰 이동은 0.5~1.0초 안에 몰아서 한다(14.5, 30.0, 34.5, 40.0초). 그 사이는 느리다. 움직임 세기 그래프가 "높은 봉우리 + 긴 바닥" 모양이다.
- 배 점은 항로 위를 초당 화면 가로 약 3% 로 흐른다.

## 4. 전환

- 원래 글은 대기를 지나는 녹아들기, 지면을 여는 자르기, 하드 컷 최대 한 번을 정했다. 화면과 맞다(녹아들기 5.6~6.4초·40.0~40.8초, 자르기 15.7초, 하드 컷 20.0초).
- 영상에서 확인한 점 · 단면으로 갈 때 하늘색이 사막 위의 밝은 빛에서 회청 #6E7883 으로 바뀐다. 지도 장면과 단면 장면의 색 온도 차가 "땅 위 → 물 밑"을 말한다.
- 하드 컷 뒤 항로 비행에서는 지형 사진을 거의 지우고 회색 바다 위에 선만 둔다. 지도에서 "선만 보는 화면"으로 바뀌는 것이 컷의 뜻이다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 14.0~19.5초의 "빛나는 호박 선(중심 약 4px, 번짐 24px)이 지나는 해협을 비스듬히 내려보다가, 카메라가 돌며 바다 높이로 내려가고, 지도 절반이 쓸려 나가며 화면 폭 93% 의 바다 밑 단면(높이 화면의 47%, 수면 #1D535D → 깊은 곳 #0B2839, 지층 #94826E → #4A433D)이 서는" 흐름이다. 단면 위 수심 점선과 깊이 숫자, 왼쪽 위 제목 묶음이 2초 이상 거의 정지해 읽힌다. 자르기가 빠지면 이 영상이 아니다.
- 12초 판 압축 예 · 0~1.5초 검은 우주에서 지구본이 커지며 호박 점 하나, 1.5~2.2초 대기를 지나 입체 지형으로 녹아든다, 2.2~3.5초 출발점들에서 선이 자라 한 줄로 모인다, 3.5~4.5초 가장 좁은 줄과 거리 숫자, 4.5~8.0초 대표 장면 3.5초(돌며 내려가기 1초 + 자르기 0.5초 + 단면 정지 2초), 8.0~10.0초 기둥이 칸칸이 자라고 비교 기둥 둘이 선다(정지 1.2초), 10.0~12.0초 지구본으로 물러나며 항로 한 줄이 켜지고 오른쪽에 숫자 하나. 항로 위 낮은 비행과 관로 물러나기는 뺀다.
- 읽는 화면에서는 카메라를 세우고, 이동은 0.5~1초로 몰아서 한다.
- 빛나는 것은 자료 층뿐이다. 지형은 빛나지 않는다.
- 지구본 → 지역 → 단면 → 지구본으로 같은 세계를 높이만 바꿔 오간다.

## 7. 함정

- 이 영상은 실존 지역을 다룬다. 노트에 지역·나라·섬 이름을 쓰지 않았다. 우리 영상에서도 원작의 지역, 제목, 이름표, 숫자, 출처 기관 이름을 옮기지 않는다. 역할(지역 이름표, 측정값, 결론 숫자, 출처 줄)만 가져온다. 제작 표기에 실존 서비스·모델 이름이 있다. 쓰지 않는다.
- 실존 장소를 다루면 지형·바다 깊이·위성 영상이 실제 자료여야 하고, 화면의 모든 숫자는 출처를 `FACTS.md` 에 적는다(고정 규칙과 원래 글의 함정 절). 아래 `## 8` 의 대체(AI 그림 지형)는 가상 장소나 모식도에만 쓰고, 화면 출처 줄 자리에 모식도라고 적는다.
- 선이 2px 아래로 가늘어지면 화면이 반짝인다. 멀리서는 점선을 지우고 실선만 둔다.
- 결론 비교에서 작은 값을 옅은 색으로 두면 사라진다. 원본처럼 같은 척도, 진한 다른 색(청록), 같은 크기의 숫자, 2.5초 이상 정지를 지킨다.
- 단면 장면에서 카메라를 계속 움직이면 깊이 숫자가 안 읽힌다. 2초 이상 움직임 세기 2 이하로 둔다.
- 한국어 자막은 원본보다 크게 써도 된다. 31px 은 작다. 한국어 34~40px, 번역 줄은 넣지 않거나 24px.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080, 24fps 기준이다. 카메라·선·기둥·단면은 three.js(`vendor/three`)와 `vendor/three-looks/looks.js` 로 된다. 어려운 것은 땅이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 실제 높이 자료와 위성 영상으로 만든 지형 | 자료를 내려받아 타일을 이어야 하고, 쓸 수 있는 도구 밖이다 | 가상 장소나 모식도일 때 · AI 일러스트(codex-image)로 위에서 본 사막 해안 지형 그림 1536x1024 한 장(글자·경계선·도로 없음, 모래 #C6BB99·황토 #CAA675·바다 #242728)을 만든다. three.js 평면(400x267 칸)에 깔고, 그림 밝기를 높이로 써서 꼭짓점을 올린다(바다는 0, 밝기 0.6 이상 땅은 최대 높이 폭의 4%). 낮은 해 `DirectionalLight`(고도 15°, 색 #FFE2B8)로 산 그늘을 낸다 | 실제 지형의 정확한 모양과 출처 근거 |
| 지구본 | 실제 영상 텍스처 | 같은 AI 그림을 구 텍스처의 해당 위경도 칸에만 붙이고 나머지는 어두운 황토 단색. `LOOKS.atmosphere` 로 가장자리 대기 띠, 밤 쪽은 반구를 검게 곱한다. 지구본 → 지도 녹아들기는 0.8초 교차 불투명도 | 대륙 모양 |
| 빛나는 항로와 점화 머리 | 없다. 코드로 된다 | 점 목록을 `LOOKS.trail(points, { head })` 로 만들고 `tr.u.uP.value` 를 0 → 1 로 1.2초에 올린다. 중심 #FFE9C1, `LOOKS.post(gl, { bloom: 0.8, threshold: 0.9 })` 로 번짐 24px. 양옆 흰 점선은 같은 경로를 옆으로 민 `trail` 에 `dash` 를 준다. 배는 흰 평면 10x5px 를 경로 위 위치 u 로 옮긴다 | 없음 |
| 대기를 지나는 녹아들기, 높이에 따른 피사계 심도 | 후처리 묶음에 심도 흐림이 없다 | three.js 안개(밀도는 카메라 높이에 비례)로 먼 곳을 하늘색에 녹인다. 심도는 같은 canvas 를 CSS `filter: blur(6px)` 로 겹친 위쪽 층에 위·아래 30% 만 보이는 그라데이션 마스크를 건다 | 렌즈 흐림의 정확한 거리감 |
| 지도가 쓸려 나가고 단면이 서기 | 자르기 연출이 필요하다 | 지형 평면 재질에 three.js 의 자르는 면을 걸고 0.5초에 서쪽으로 민다. 단면은 canvas 에 깊이 곡선을 그린 판(수면 #1D535D → #0B2839 세로 그라데이션, 지층은 #94826E → #4A433D 줄무늬 12개, 곡선 테두리 흰 2px)을 three.js 평면 텍스처로 세워 0.4초에 아래에서 올린다 | 단면과 지형 사이 이음매의 자연스러움 |
| 원통 기둥 | 없다. 코드로 된다 | 원통 칸을 `InstancedMesh` 로 20개, 칸 높이 36px 환산, 칸 사이 3px 틈. 0.15초마다 한 칸이 위에서 떨어져 앉는다. 호박 #EBB96B, 청록 #41999A, 범위 위쪽은 #8FBCB7 | 없음 |
| 숫자·이름표 | 없다 | DOM 층, `LOOKS.pin(v, cam, w, h)` 로 3D 자리를 화면 좌표로 바꿔 붙인다. 숫자는 InterVariable 54~80px, 한국어 단위·설명은 Pretendard SemiBold 28~40px, 이름표는 대문자 대신 Pretendard Regular 20px 자간 0.2em | 없음 |
| 필름 그레인 | 없다 | `LOOKS.post` 의 `grain` 0.04, `fps` 24 | 없음 |
