# 살아 있는 흐름도 · 파란 꾸러미가 카드를 건너간다 — 분석 노트

> 흰 점 격자 위에 둥근 카드 여섯 장이 두 줄로 놓인 흐름도를 카메라가 한 장씩 따라가는 14초 설명 영상. 파란 꾸러미가 선을 타고 다음 카드에 닿을 때마다 카드가 맥박처럼 튀고, 요청 → 생성 → 코드 → 화면 → 프레임 → 영상 순서로 일이 흘러간다. 영상 카드에 심어 둔 실수 하나가 보이고, 고침 쪽지가 선을 타고 코드 카드로 되돌아가 고친다. 끝에 카메라가 물러나 기계 전체를 보여 준 뒤 영상 카드 속으로 날아 들어간다. 작동 원리, 처리 단계, 제품 흐름, 버튼 하나를 누른 뒤 안쪽에서 차례로 벌어지는 처리 과정의 설명에 맞는다.

측정 · 파일 1280x720 · 30fps · 14.0초. 크기는 1920x1080 기준으로 바꿔 적는다(1.5배). 장면 감지로 잡힌 컷은 없다. 원래 글이 카드 사이 컷을 금지했고 화면도 늘 카메라가 건너간다. 움직임 세기는 평균 13.9, 최대 45.7(3.5초)이다. 큰 값은 1.0초(12.4), 2.0초(35.7), 3.5초(45.7), 6.0초(27.6), 8.0~8.5초(22.0~38.2), 9.5~10.0초(18.1~20.4), 11.5초(42.8)다. 모두 카드와 카드 사이 카메라 이동이다. 12.0초 이후는 3.7~5.9 다. 색 값은 프레임에서 잰 근삿값이다.

## 3. 움직임

- 원래 글에 카드 착지·맥박·선 그리기·꾸러미·카메라·타이핑의 곡선과 초가 있다. 되풀이하지 않는다.
- 영상에서 확인한 점 · 카메라 이동이 큰 값을 만든다. 이동 사이 머무름은 0.5~1.5초다. 큰 이동(3.5초, 11.5초)은 0.5초 안에 끝난다.
- 빠른 이동 중에는 화면 전체가 흐려진다(4.0초 프레임). 이동이 끝나면 바로 선명해진다.
- 다음 카드는 꾸러미가 닿기 전에 반투명으로 먼저 있다. 꾸러미가 닿는 순간 불투명해지며 내려앉는다.
  - 4.0초 프레임에서 반투명 카드는 #E8EDF8 근처, 바탕은 #F4F5FA 근처다. 카드 불투명도로 치면 약 30% 다. 그 옆 아직 안 온 카드 자리는 점선 윤곽(굵기 약 1px, 회색)만 있다.
- 맥박 · 꾸러미가 닿는 프레임에 카드 테두리가 파랑(약 3px)으로 바뀌고, 다음 0.5초 동안 테두리가 유지된 채 카드가 살짝 커졌다 돌아온다. 테두리는 카메라가 다음 카드로 떠날 때 꺼진다. 전체 장면에서도 켜진 카드는 한 번에 하나뿐이다.
- 생성 카드(2.0초) · 표식 둘레에 옅은 원 두 겹(안쪽 실선, 바깥 점선)이 있고, 바깥 원 오른쪽 아래에 작은 파란 점(지름 약 27px)이 붙어 있다. 꾸러미가 카드 안으로 들어와 원을 따라 도는 모양이다. 1.5초 프레임에서는 같은 카드의 테두리가 파랗고 아이콘 타일은 흰색, 2.0초에는 테두리가 꺼지고 아이콘 타일이 파랗다. 켜짐이 테두리에서 아이콘으로 옮겨 간다.

## 4. 전환

- 컷·페이드가 없다. 모든 바꿈이 카메라 이동이다. 원래 글에 정한 방식 그대로다.
- 영상에서 확인한 점 · 고침 쪽지가 되돌아가는 구간(8.5~9.0초)은 카메라가 쪽지를 따라 위로 올라간다. 꾸러미의 흐름과 반대 방향으로 카메라가 움직이는 유일한 구간이다.
- 끝의 날아 들어가기(11.5~12.0초)는 기울기 없이 곧게 들어간다. 원래 글의 규칙(끝에서 기울기를 뺀다)과 맞다.

## 5. 타이포

- 원래 글은 카드마다 한 낱말, 굵은 고딕, 문장 없음으로 정했다. 화면과 맞다. 카드 제목 여섯 개 외의 글자는 화면에 없다.
- 영상에서 확인한 점 · 근접 장면의 제목(화면 높이의 5% 안팎)이 영상에서 가장 큰 글자다. 큰 숫자나 자막이 없다. 코드·입력 칸의 글은 모두 색 막대로 대신한다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 10.5~12.0초의 "흐름도 판이 3D 로 젖혀졌다가 평평해지며 카드 여섯 장과 선 여섯 개(돌아가는 고리 선 포함)가 화면 가로 92%, 세로 81% 에 한꺼번에 보이고, 켜진 테두리가 프레임 → 영상 카드로 옮겨 가며 실수 표시가 지워진 뒤, 카메라가 기울기 없이 영상 카드로 날아 들어가는" 1.5초다. 전체 장면이 없거나 카드가 한 줄로만 놓이면 이 영상이 아니다. 둘째로 남길 것은 8.0~9.5초의 실수 → 고침 쪽지 되돌아가기다.
- 12초 판 압축 예 · 0~1.0초 요청 카드와 입력, 1.0~1.8초 생성 카드, 1.8~2.6초 코드 카드, 2.6~3.4초 긴 이동과 화면 카드, 3.4~4.4초 프레임 카드(칸 여섯), 4.4~5.6초 영상 카드와 튀는 공, 5.6~7.6초 실수와 고침 쪽지와 코드 고침, 7.6~9.4초 대표 장면, 9.4~12.0초 영상 카드 속. 카드마다 머무름을 원본보다 약 0.2초씩 줄인다. 원본 7.0~7.5초의 재생 단추 머무름은 뺀다. 원래 글의 실사 소재용 절(카드 속 실제 화면, 실제 정지 화면 필름 띠)은 소재가 있을 때만 쓴다.
- 단계가 바뀌는 방법은 하나뿐이다. 파란 꾸러미가 앞 카드에서 출발해 선을 타고 다음 카드에 도착하고, 도착하는 순간 그 카드가 튄다.
- 다음 카드가 반투명으로 먼저 보여 이야기의 다음 칸을 예고한다.
- 고칠 실수 하나를 일부러 보여 준다. 고침 쪽지가 흐름과 반대로 돌아간다.

## 7. 함정

- 화면의 생성 카드에 실존 AI 이름과 그 표식(점토색 방사형 별)이 있다. 이름과 표식 모양을 옮기지 않는다. 우리 영상에서는 사용자가 정한 이름과 일반 도형 표식(예 · 네 갈래 반짝임, 동그라미 안 점)을 쓴다. 다른 카드 제목 낱말도 옮기지 않는다. 역할(요청, 생성, 코드, 화면, 프레임, 영상, 고침)만 가져온다.
- 원래 글은 필름 띠의 넷째 칸을 망가뜨리라고 정했다. 화면에서는 영상 카드의 공이 회색으로 납작해지는 것이 실수로 보이고, 필름 띠 넷째 칸은 전체 장면(10.5초)에서 점선으로만 표시된다. 둘 중 하나만 쓰면 시청자가 실수를 놓친다. 실수를 영상 카드에 크게 보이고, 같은 칸을 필름 띠에도 표시해 연결한다.
- 바탕을 순수 흰색으로 칠하면 카드(#FBFBFB)와 바탕이 붙는다. 바탕에 가장자리 쪽으로 2~4% 어두워지는 그라데이션과 점 격자를 깔고, 카드에 여러 겹의 부드러운 그림자를 준다.
- 한국어 카드 제목 · 한 낱말 2~4자로 둔다. 세계 좌표 50px, 근접 배율 최대 2.4 에서 화면 약 120px 로 140px 규칙 안이다. 근접 배율을 2.8 넘게 키우지 않는다.
- 카드 수 · 여섯 장이 전체 장면에서 모두 읽히는 한계다. 일곱 장 이상이면 전체 장면에서 제목이 20px 아래로 작아진다. 단계를 여섯으로 묶는다.
- 근접 장면에서 카드가 화면의 23~39% 를 차지하고, 양옆에 이웃 카드의 가장자리가 잘려 보인다(2.0초 왼쪽 요청 카드, 오른쪽 점선 자리). 근접에서 이웃 카드를 완전히 빼면 흐름도 안에 있다는 느낌이 사라진다. 화면 양끝에 이웃 카드가 5~10% 걸치게 배율을 고른다.
- 꾸러미만 움직이고 카메라가 멈춰 있으면 정적인 도표가 된다. 꾸러미가 출발하면 카메라도 같이 다음 카드로 출발한다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

글꼴은 Pretendard Regular·SemiBold 와 InterVariable 뿐이다. 값은 1920x1080 기준이다. 원래 글의 참조 코드처럼 세계(3200 x 1800)를 DOM/CSS 3D 판 하나로 만들고, 카메라는 그 판의 이동·확대·기울기로 움직인다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 아주 굵은 카드 제목 | 원래 글의 가장 굵은 글꼴이 없다 | Pretendard SemiBold, 세계 좌표 50px, 자간 -0.035em, #14213D. 라틴·숫자는 InterVariable 굵기 800 | 가장 굵은 글꼴의 단단함 |
| 혜성 꼬리 꾸러미 | 선을 따라가는 꼬리의 그라데이션 | SVG 선 경로에서 `getPointAtLength` 로 꾸러미 뒤 220px 를 10px 간격으로 22점 뽑는다. 각 점에 원(지름 22px → 4px, 불투명도 0.9 → 0, #2B7EF9)을 그린다. 꾸러미 머리는 지름 22px 원과 같은 색 번짐(반경 12px) | 없음 |
| 카메라 이동 중 흐림 | 큰 판 전체에 흐림을 걸면 무겁다 | 카메라 속도가 화면 폭의 1.5배/초를 넘는 프레임에만 세계 판에 `filter: blur(속도에 비례, 최대 4px)`. 이동이 끝나는 0.1초 안에 0 으로 | 진짜 움직임 흐림의 방향성 |
| 영상 카드 속 튀는 공 | 원래 글은 실사 영상을 전제로 한다. 원본도 코드 그림이다 | canvas · 하늘 선형 그라데이션 #DAE5FA → #EEF2FA, 오른쪽 위 흰 방사형 해(반지름 150px, 불투명도 0.8), 점선 궤적(포물선, 점 지름 18px, 간격 38px, #8FB3F0), 공은 방사형 그라데이션(#9CC4FF → #2C7BFB → #1C5FD0, 왼쪽 위 흰 반사점), 아래 남색 막대 #121F3A 와 진행 막대 #2C79F0 | 실제 영상의 내용 |
| 망가진 프레임 | 원래 글은 실제 정지 화면을 망가뜨린다 | 공을 회색 방사형(#E5E5E5 → #9A9A9A)으로 바꾸고 세로 0.6배로 납작하게. 둘레에 파란 점선 원(굵기 4px, 점 간격 10px). 필름 띠 같은 칸은 `filter: grayscale(1) blur(2px)` 와 가로로 엇갈린 세 조각(`clip-path` 로 띠 셋, 각 ±12px 이동) | 색 어긋남의 디지털 깨짐 느낌 |
| 손그림 같은 선 아이콘 | 없다. SVG 로 된다 | 아이콘마다 SVG 선 3~6개, 굵기 2.6px, 끝 둥글게, #2B7EF9. 아이콘 타일 68px, 모서리 18px, 바탕 #EAF2FE | 없음 |
| 켜진 카드의 빛 웅덩이와 그림자 번쩍임 | 없다 | 켜진 카드 뒤에 지름 900px 방사형(가운데 rgba(43,126,249,0.18) → 0)을 카메라와 함께 옮긴다. 맥박 때 카드 그림자를 0 20px 50px rgba(43,126,249,0.35) 로 0.1초 켜고 0.7초 동안 기본 그림자(0 2px 4px rgba(20,33,61,0.06), 0 12px 32px rgba(20,33,61,0.08))로 돌린다 | 없음 |
| 전체 장면 끝의 빛 훑기 | 없다 | 카드 테두리를 순서대로 #2B7EF9 2px 로 켰다 끄기(카드당 0.25초, 프레임 → 영상 → 고리 선 → 코드 순). 선 위에는 작은 꾸러미(지름 10px)를 0.4초 간격으로 계속 흘린다 | 없음 |
