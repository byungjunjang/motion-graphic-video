# 연필 현장 수첩으로 그린 한여름 더위 기록 · 3분 데이터 이야기 — 분석 노트

> 한 나라의 2026년 여름 더위를 3분 동안 설명하는 데이터 시각화 영상. 누런 종이 수첩 한 장 위에 연필 선과 빨강·파랑 빗금으로 그림과 그래프가 천천히 그려진다. 표지 뒤로 번호 붙은 장 7개와 끝 장이 이어지고, 장마다 손글씨 제목 한 줄 + 그림 하나 + 숫자 하나를 둔다. 장이 끝나면 종이를 비우고 다음 장을 같은 자리에서 처음부터 그린다. 선 가장자리에 1~2px 의 빨강·파랑 색 번짐이 있다. 기후·환경 보고, 긴 기간의 통계 비교, 차분한 해설형 데이터 이야기에 맞는다. 연필 스케치 · 현장 수첩 · 느린 데이터 저널리즘.

## 1. 본질

- 바탕은 누런 종이(#DDD2BE 근처)다. 네 모서리가 어둡다(#AEA296 근처). 장에 따라 종이 색이 조금 바뀐다. 비 오는 장은 회색빛(#EADEDE 근처), 폭염 날짜 장은 분홍빛(#EADEC6 근처)이다.
- 수첩 장치가 처음부터 끝까지 고정이다. 네 모서리 재단 표시(+), 위·아래 가운데 맞춤 십자 표시, 왼쪽 아래 타자기 글씨 쪽 번호, 오른쪽 아래 빗금 색 견본 4칸(회청·빨강·파랑·노랑)이다.
- 선은 연필 선이다. 먹 선(#18100D 근처)은 굵기 1.5~2.5px 이고 조금 떨린다. 면은 칠하지 않고 빗금으로 채운다. 빗금 방향과 간격이 면마다 조금씩 다르다.
- 색은 넷이다. 먹, 빨강(#B93418 ~ #A34F46 근처, 더위·올해), 파랑(#253049 근처 글자, 회청 #949599 빗금, 비·추위), 황토 주황(#A57614 근처, 위쪽 공기). 빨강이 이야기의 주인공 색이다.
- 색 번짐 · 선의 왼쪽 가장자리가 푸르고 오른쪽 가장자리가 붉다. 1280 판에서 1~2px, 1920 환산 2~3px 이다.
- 도장 · 빨강 사각 도장(한자), 파랑 사각 도장(평년 대비 백분율), 둥근 소인, 끝의 둥근 낙관. 장마다 결론 숫자 옆에 비스듬히(-8~+10도) 찍힌다.
- 아닌 것 · 빠른 컷, 큰 움직임, 3D, 사진, 그라데이션 면, 굵은 산세리프 제목, 화면 가득한 색면, 캐릭터.

## 3. 움직임

- 모든 것이 그려지며 나타난다. 선은 펜 끝이 지나가듯 자라고, 빗금은 한 줄씩 쓸려 찬다. 글자는 한 자씩 써진다. 사라질 때는 반대로 그리지 않고 장 전체가 0.75초에 옅어진다.
- 속도가 느리다. 큰 선 하나에 1~3초, 장 하나에 17.5~29.5초를 쓴다. 장 안에서 화면에 새로 생기는 요소는 2~4초에 하나다.
- 세는 숫자 · 우량, 바를 정 자 셈, 연도 계수기가 선 그리기와 같은 속도로 오른다. 숫자가 다 차면 도장이 찍힌다.
- 도장 · 0.1~0.2초에 크기 1.2 → 1.0 으로 앉고 비스듬하다. 이 영상에서 가장 빠른 움직임이다.
- 움직이는 그림은 셋뿐이다. 기류 화살표 곡선, 태풍 소용돌이 이동, 빗줄기.
- 선은 그려진 뒤 떨리지 않는다(장마다 다시 그리는 떨림이 없다). 손맛은 선 모양의 불규칙함과 빗금의 고르지 않음에서 온다.

## 4. 전환

- 컷이 없다. 장 사이는 "옅어지기 0.75초 → 빈 종이 0.25~1초 → 다음 장 머리글 타이핑" 하나뿐이다.
- 장 시작이 모두 마디 첫 박에 있다. 장 안의 그리기는 박과 묶이지 않는다.
- 수첩 테두리 장치(모서리 표시, 쪽 번호, 견본 칸)는 지워지지 않고 남는다. 쪽 번호만 장마다 바뀐다. 같은 수첩을 넘긴다는 느낌이 여기서 온다.
- 처음과 끝의 호응 · 표지의 빨강 빗금 해가 끝 장에서 지평선에 반쯤 걸린 해로 다시 나온다.

## 5. 타이포

- 손글씨 붓펜 이탤릭 · 장 제목. 먹색, 글자 높이 약 68px(6.3%), 왼쪽 여백 7.5%, 세로 19% 지점. 한 문장, 마침표로 끝난다.
- 타자기 고정폭 대문자 · 장 번호와 장 이름 머리글(세로 13%, 글자 높이 약 18px, 1.7%), 축 이름, 쪽 번호. 회색 먹.
- 손글씨 작은 글씨 · 그림 옆 이름표와 주석(글자 높이 약 20~27px). 빨강·파랑·황토로 그림 색을 따른다.
- 둥근 산세리프 · 사전 뜻풀이와 아래 서술 줄, 끝 장 문장(글자 높이 약 22~30px).
- 큰 숫자 · 손글씨 이탤릭 숫자. 빨강 또는 파랑, 글자 높이 약 50~60px.
- 한자 · 표지 제목은 굵은 붓 획(글자 높이 약 218px), 그 밖에는 이름표 크기의 작은 한자.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 150.0~159.5초. 누런 종이에 기준선(세로 54%, 가로 8~90%) 하나, 막대 129개가 회청(아래)·빨강(위) 빗금으로 서 있고 마지막 막대가 기준선 위 약 260px(화면 높이의 24%)로 가장 높다. 추세 점선이 화면을 비스듬히 가로지르고, 상위 다섯 해에 손글씨 동그라미가 하나씩 붙는다. 오른쪽 위 연도 계수기, 위쪽 손글씨 제목, 네 모서리 수첩 표시가 함께 보인다. 연필 빗금 막대, 빨강이 오른쪽 끝에 몰리는 모양, 수첩 테두리 중 하나라도 빠지면 이 영상이 아니다.
- 12초 판 압축 예 · 0~2초 표지(빨강 빗금 해가 부채꼴로 찬다 + 손글씨 제목), 2~2.5초 지우기, 2.5~8.5초 막대 그래프(막대를 1초에 약 21개로 빠르게 그리고 마지막 막대만 1초 머문다), 8.5~10초 추세 점선과 동그라미 2개, 10~12초 결론 한 줄 + 빨강 도장. 장 1~6, 끝 장의 인용은 뺀다.
- 장마다 "손글씨 제목 한 문장 + 그림 하나 + 숫자 하나 + 도장" 의 같은 틀. 긴 자료도 장을 늘리기만 하면 된다.
- 빗금으로만 면을 채우고 색은 뜻(올해·더위=빨강, 비·평년 아래=파랑)에만 쓰는 규칙.
- 지워지지 않는 수첩 테두리와 장마다 바뀌는 쪽 번호.
- 장 시작을 마디 첫 박에 고정하는 방식.
- 셈 막대 대신 바를 정 자 셈처럼 그 문화의 손 기록 방식을 그래프로 쓰는 생각. 대상에 맞는 손 기록(눈금, 점 찍기)으로 바꿔 쓴다.

## 7. 함정

- 화면의 지명, 기관 이름, 한자 낱말, 손글씨 제목, 인용문, 수치는 이 주제의 것이다. 옮기지 않는다. 지도 윤곽도 실제 나라 모양이라 다른 주제에서는 쓰지 않는다. 역할(지역 지도, 표제어 카드, 결론 줄)만 가져온다.
- 움직임 세기 평균 1.0 은 아주 낮다. 3분 길이에서는 차분하지만, 12~30초 판에서는 정지 화면으로 보인다. 짧은 판에서는 그리기 속도를 3~5배로 올리고 장 수를 줄인다.
- 그리기 속도가 느려서 한 장 안의 요소를 프레임마다 모두 다시 그리면 무겁다. 다 그린 선은 오프스크린 canvas 에 굽고, 지금 그려지는 선만 프레임마다 그린다. 단, 굽는 순서도 t 로만 정해야 seek 가 결정적이다.
- 빗금을 매 프레임 씨앗 없이 만들면 선이 떨린다. 이 영상은 떨림이 없다. 빗금마다 고정 씨앗을 준다.
- 색 번짐을 세게 주면 연필 선이 흐려 보인다. 2~3px 을 넘기지 않는다.
- 작은 글씨(18~27px)가 많다. 한국어 판에서는 18px 아래로 내리지 않는다.
- 3분 내내 같은 종이·같은 틀이라 지루할 수 있다. 원작은 장마다 종이 색을 조금 바꾸고 도장으로 박자를 준다. 이 두 가지를 빼지 않는다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 글꼴은 Pretendard Regular·SemiBold 와 InterVariable(숫자)만 쓴다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 연필 선이 그려지는 등장 | 없다. canvas 로 된다 | `HAND.ink(ctx, P, { w: 2, color: '#18100D', key: 'coast', B: 0, frac })`. `frac` 은 선 길이에 비례한 시간(300px 에 1초)으로 0 → 1. 다 그린 선은 오프스크린 canvas 에 굽는다 | 없음 |
| 빗금 채움 | 면마다 방향·간격이 달라야 한다 | `HAND.paint(ctx, P, { fill: 'transparent', line: false, key: 'bar' + i, B: 0, tex: [{ k: 'hatch', angle: 0.9, gap: 5, w: 1.2, color: '#B93418', jit: 1 }] })`. 쓸려 차는 등장은 `HAND.trace` 로 만든 경로에 부채꼴 마스크를 `clip` 해서 각도를 0 → 360도로 넓힌다 | 손으로 그은 빗금의 강약 |
| 색 번짐 | 연필 선 가장자리의 빨강·파랑 어긋남 | 그림 canvas 를 두 번 더 겹친다. 하나는 CSS `filter` 로 빨강만 남겨 오른쪽으로 2px, 하나는 파랑만 남겨 왼쪽으로 2px, 둘 다 `mix-blend-mode: multiply`, 투명도 0.35. three.js 를 쓰는 판이면 `LOOKS.post(gl, { ca: 0.0015, bloom: 0, tone: 'none' })` | 렌즈 같은 바깥쪽 번짐 증가 |
| 누런 종이와 어두운 모서리 | 종이 결 | 바탕 #DDD2BE 에 `texTile(7, { mc: '120,95,60', mottle: .05, dark: .06, light: .05, fibers: 200, specks: 30 })`. 모서리는 CSS `radial-gradient(ellipse at center, transparent 55%, rgba(80,64,40,.35) 100%)`. 필름 결은 `grainLayer(stage, 11)` | 실제 종이의 큰 얼룩 |
| 손글씨 제목과 이름표 | 손글씨 글꼴이 없다 | Pretendard Regular 68px, `transform: skewX(-12deg)`, 자간 -0.01em, #18100D. 한 자씩 0.06초 간격으로 투명도 0 → 1. 이름표는 같은 방식 24px, 그림 색 | 붓펜 획의 굵기 변화 |
| 타자기 머리글 | 고정폭 글꼴이 없다 | InterVariable 500 18px, `font-variant-numeric: tabular-nums`, 대문자 대신 한글은 Pretendard SemiBold 18px, 자간 0.2em, #5A5048 | 타자기 활자의 번짐 |
| 도장 | 잉크 얼룩진 도장 면 | SVG 사각(160x64px, 테두리 4px, #B93418) 안 Pretendard SemiBold 34px 흰 글자, 회전 -8도. 얼룩은 `HAND.stipple` 로 종이색 점 120개를 덮어 찍는다. 0.15초에 크기 1.2 → 1.0 | 도장 잉크의 번짐 |
| 지도 해안선 | 실제 지형 자료가 필요 | 다른 주제에서는 실제 지도를 쓰지 않는다. 필요하면 단순한 가상 지형 윤곽(점 60개)을 `HAND.wobble(P, true, 3, 'land', 0)` 으로 굽는다 | 실제 지리 정보 |
| 표지의 해와 산 일러스트 | 상징 그림 | 해는 원 + 빗금(위 방식). 산은 AI 일러스트를 쓰지 않고 SVG 삼각 윤곽 + 한쪽만 빗금으로 그린다. 상징물은 대상에 맞는 것으로 바꾼다 | 원작의 상징성 |
| 코드 합성 음악 | 음악 | `scripts/synth.py music videos/<id> --mood calm --bpm 80 --peak <결론 장 시각>` 으로 마디 3초 배경음악을 합성하고, 장 시작을 마디 첫 박에 맞춘다. 도장 순간에 효과음 하나 | 원작 선율 |
