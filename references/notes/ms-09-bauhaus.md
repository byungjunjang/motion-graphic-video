# 원색 기하 포스터 조립 — 분석 노트

> 크림 종이 위에서 빨강 원, 노랑 삼각형, 파랑 사각형, 검정 막대가 120px 격자에 맞춰 하나씩 떨어지고, 미끄러지고, 뒤집히며 포스터 한 장을 조립하는 10초 영상. 6초에 화면 전체가 120px 칸 112개로 쪼개져 칸마다 시차를 두고 도는 물결이 일어난다. 7초에 검은 판 위 원형 세 개(삼각형·사각형·원)가 잠깐 나오고, 8초에 완성 포스터로 돌아와 세로로 선 큰 제목 한 단어가 한 글자씩 찍힌다. 주인공 원이 첫 프레임부터 화면 높이의 44%(지름 480px)다. 작은 도형 하나가 빈 종이에 떠 있는 화면이 아니다. 디자인 도구·건축·교육·브랜드 정체성 소개에 맞는다. 기하 구성 · 모듈 격자 · 박자 맞춘 기계적 움직임.

## 1. 본질

- 콘텐츠 영역은 가로 120~1800px, 세로 60~1020px 이다(14x8 칸, 화면의 87.5% x 89%). 끝 화면에서 도형이 이 영역을 가득 채운다.

## 4. 전환

- 장면은 하나의 포스터다. 장면 사이는 도형이 한 박에 하나씩 더해지는 것으로 이어진다.
- 포스터 → 물결(6.0초) · 컷 검출은 되지만 실제로는 칸 쪼개기다. 빈 칸이 먼저 한 프레임에 채워지고, 다음 프레임에 큰 도형이 칸으로 갈라진다.
- 물결 → 검은 판(6.6~7.0초) · 칸이 열 단위로 왼쪽부터 카드처럼 뒤집힌다. 뒷면이 검다.
- 검은 판 → 포스터(7.6~8.0초) · 같은 칸 뒤집기를 거꾸로 한다. 8.0초에 칸 무늬가 한 프레임에 깨끗한 포스터로 바뀐다(컷).
- 페이드와 디졸브가 없다. 모든 전환을 칸과 도형이 맡는다.

## 5. 타이포

- 제목 · 굵은 기하 산세리프 대문자 한 단어. 90° 돌려 아래에서 위로 읽는다. 대문자 높이 120px(화면 높이의 11%, 모듈 1칸), 단어 길이 960px(모듈 8칸). 검정. 콘텐츠 영역 왼쪽 끝 열에 붙는다.
- 보조 · 제목 오른쪽에 같은 방향으로 아주 작은 대문자 세 낱말을 점으로 나눈 한 줄(글자 높이 약 20px, 자간 넓음). 그 옆에 한자 두 자씩 세 묶음(글자 약 28px). 그 위에 색 기호 세 개(각 약 25px).
- 구석 표기 · 12px 안팎의 대문자 줄 넷. 박자 세기가 0.5초마다 바뀐다.
- 검은 판의 색 이름 라벨 · 흰색, 글자 높이 약 14px, 자간 넓음.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 6.0~6.6초. 크림 종이의 콘텐츠 영역(가로 120~1800, 세로 60~1020)이 120px 칸 112개로 갈라져 빨강·노랑·파랑·검정 조각이 왼쪽 위부터 시차를 두고 돌았다가 새 무늬로 멈춘다. 칸이 화면의 59% 이상을 색으로 덮어야 한다. 도형 몇 개만 도는 화면이면 이 영상이 아니다.
- 12초 판 압축 예 · 10초 원본을 12초에 펼친다. 0~1.0초 원 낙하와 격자 긋기, 1.0~3.5초 한 박에 도형 하나(막대·삼각형 뒤집기·사각형, 원본보다 1박 더), 3.5~4.5초 화면 중심 90° 회전, 4.5~6.5초 반원·사분원·가로선·빨강 사분원으로 포스터 완성(도형 9개), 6.5~7.5초 칸 물결(원본 0.6초를 1.0초로), 7.5~8.5초 검은 판 원형 세 개와 갈라짐, 8.5~9.0초 칸 뒤집어 돌아오기, 9.0~10.5초 제목 한 글자씩, 10.5~12.0초 끝 화면 정지와 작은 사분원 회전. 박은 그대로 0.5초를 지킨다.
- 첫 프레임부터 화면 높이 44% 의 원이 떨어진다. 빈 종이로 시작하지 않는다.
- 다음 동작 자리를 조준 표시로 먼저 보여 주는 예고. 기계적 움직임에 의도가 보인다.
- 회전축 세 가지(화면 중심, 꼭짓점·변, 자기 중심)를 번갈아 쓴다.
- 색 견본과 박자 세기 같은 구석 표기가 진행을 센다. 인쇄물이라는 설정을 끝까지 지킨다.
- 끝 화면은 콘텐츠 영역을 다 채운 포스터다. 제목은 세로로 한 열을 차지한다.

## 7. 함정

- 화면의 제목 단어, 설명 세 낱말, 한자 묶음, 포스터 번호 줄, 구성 설명 줄은 원작의 것이다. 옮기지 않는다. 역할(제목 한 단어, 가치 세 낱말, 진행 세기, 판 번호)만 가져온다. 학교·운동 이름을 제목으로 쓰지 않는다.
- 코드로 만들 때 밀도가 줄어드는 지점과 막는 법.
  - 도형이 작아진다 · 가장 흔한 실패다. 모듈을 120px 로 고정하고 큰 도형은 4칸(480px, 화면 높이의 44%)으로 만든다. 5.75초 상당 시점에 도형 9개, 테두리 상자가 콘텐츠 영역의 80% 이상인지 `render.mjs --snap` 으로 확인한다.
  - 물결이 빠진다 · 칸 112개를 미리 만들어 둔다. 칸마다 `delay = (col + row) * 0.012` 초쯤의 시차로 같은 회전 함수를 부른다. 칸은 SVG `<g>` 나 canvas 로 그린다. DOM 112개도 된다. 큰 도형은 clip 으로 칸에 나눈다.
  - 튕긴다 · 속도 곡선에 튕김을 넣지 않는다. 2차 가속·감속(`t<.5 ? 2t² : 1-(-2t+2)²/2`)이나 일정 속도만 쓴다. 도착 위치는 120 의 배수로 반올림한다.
  - 박이 흐트러진다 · 모든 동작 시작을 `k * 0.5` 초(조준 표시는 `k * 0.25`)에 둔다. 소리를 쓰면 `audio-probe.py --onsets --write` 의 박에 맞춘다.
  - 움직임이 멈춘다 · 조용한 박에도 0.5초마다 무언가 하나는 일어난다. 끝 화면에도 작은 사분원 회전과 구석 박자 세기를 남긴다.
- 한국어로 옮길 때 · 세로 제목은 라틴 대문자 120px 이다. 한국어면 글자를 세로로 쌓는다(90° 돌리지 않는다). Pretendard SemiBold 120px 한 글자를 한 칸(120x120)에 넣고 세로로 4~6자를 쌓아 480~720px 를 채운다. 8칸을 채우려면 보조 줄을 같은 열 아래에 이어 붙인다. 가장 굵은 굵기가 SemiBold 라 원작보다 가볍다. 검정 막대·사분원 같은 굵은 면을 제목 옆에 두어 무게를 보탠다. 라틴 표기를 쓰면 InterVariable 의 굵은 굵기를 써도 된다.
- 도형 수를 4~5개로 줄이면 포스터가 비어 보인다. 끝 화면 도형 수는 9개 이상으로 둔다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

거의 다 SVG·canvas 로 된다. 값은 1920x1080 기준이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 굵은 기하 산세리프 제목 | 한국어 굵은 기하 글꼴이 없다 | 한국어는 Pretendard SemiBold 120px, 자간 0, 한 칸 한 글자 세로 쌓기. 라틴이면 InterVariable 굵기 800~900, 대문자 높이 120px 에 맞춰 `font-size` 약 165px | 원·직선만으로 된 글자 모양 |
| 인쇄 결과 거친 가장자리 | 실제 인쇄 번짐 | 도형 경로에 `HAND.wobble(P, true, 1.2, 'edge', 0)` 을 한 번 적용해 굽는다(떨지 않음, B=0). 바탕에 `texTile(seed, { mc: '120,110,95', mottle: .02, fibers: 60, specks: 10 })` | 잉크가 스민 결 |
| 판 어긋남(인쇄 판 사이 1~2px 밀림) | 없다. 코드로 된다 | 색 도형마다 (1,0)~(2,1)px 고정 오프셋. 9.5초 농도 흔들림은 0.25초 동안 채도를 +8% 올렸다 내린다 | 없음 |
| 칸 뒤집기 3D 효과 | CSS 3D 가 프레임 촬영에서 흔들릴 수 있다 | 칸마다 `scaleX = |cos(θ)|` 로 납작하게 만들고 θ 가 90° 를 넘으면 뒷면 색(검정)을 그린다. canvas 2D 로 충분하다 | 원근 기울기 |
| 이동 흐림 | canvas 에 흐림이 없다 | 빠른 프레임에서 같은 도형을 이동 방향으로 4~6번 투명도 0.15 로 겹쳐 그린다(길이 20~40px). 또는 CSS `filter: blur(4px)` 를 해당 도형에만 1~3프레임 | 매끈한 흐림 |
