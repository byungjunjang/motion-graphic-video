# 순간 게임 연속 · 매체가 바뀌며 빨라지는 쇼 — 분석 노트

> 60초 동안 짧은 게임 여덟 판과 보스 한 판이 이어지는 영상. 판마다 화면 매체가 통째로 바뀐다(크레용, 수묵, 단말기 글자 그림, 두 색 인쇄, 도트, 청사진, 격자 타이포, 옛 인쇄 콜라주). 판 사이에는 늘 같은 보라색 쇼 무대로 돌아온다. 무대의 텔레비전 화면이 게임 화면이 되고, 카메라가 그 화면으로 들어갔다 나온다. 뒤로 갈수록 판이 짧아진다. 게임 예고편, 온보딩, 기능 여러 개를 빠르게 훑는 소개에 맞는다.

출처 · lo:microgame. 색인에 든 원래 글은 긴 스타일 명세다(본질, 움직임, 카메라 문법, 매체별 함정, 숏 표, 데모 수치). 판 길이·명령어 유지 시간·전환 길이·속도 사다리 수치는 글에 있다. 그러나 무대의 실제 색과 배치, 텔레비전 화면이 화면에서 차지하는 크기, 판별 매체 순서와 시각, 주인공이 매체마다 얼마나 크게 보이는지, 대표 장면의 0.5초 단위 흐름이 없다. 그래서 영상 프레임을 보고 이 노트를 썼다.
측정 · 파일 1280x720 · 24fps · 59.83초. 크기는 1920x1080 기준으로 바꿔 적는다(1.5배). 장면 감지 31회(판 진입·복귀마다 한두 번). 움직임 세기 평균 약 19. 큰 값은 판 진입·복귀 순간에 몰린다(7.5초 78.9, 13.5초 68.2, 19.5초 89.9, 27.5초 136.6 최대, 38.0초 75.6). 게임 안에서는 1~15, 무대에서는 0.4~2 로 조용하다. 색 값은 프레임에서 잰 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. 박 검출은 80.7 BPM(마디 약 3.0초)을 냈다. 원래 글은 120 → 140 → 160 BPM 이라고 정했다. 첫 판 길이(4.0초 = 120 BPM 두 마디)는 원래 글과 맞는다. 박 검출이 2/3 박으로 잡혔다고 본다. 판 진입 바로 앞마다 0.15~0.4초 무음이 있다(7.58, 13.58, 19.58, 23.08, 25.72초). 가장 큰 타격(세기 1.00)은 40.26초, 보스 판 타일이 뒤집히는 자리다. 38.13초(0.78)는 마지막 목숨 조명, 13.49초(0.81)는 첫 실패 직후다.

## 1. 본질

- 원래 글의 핵심(명령어 한 마디 + 몇 초 + 동작 하나 + 결과, 판마다 다른 매체, 고정된 무대, 함께 빨라지는 다섯 값)은 화면과 맞다. 되풀이하지 않는다.
- 영상에서 확인한 점 · 이 영상의 몸통은 "무대의 텔레비전 화면 = 게임 화면"이라는 한 장치다. 게임이 끝나면 게임 화면 전체가 텔레비전 안으로 줄어들고, 다음 판은 텔레비전 안에서 먼저 첫 프레임으로 바뀐 뒤 카메라가 들어간다. 판이 바뀌어도 이어 보이는 이유가 이것이다.

## 3. 움직임

- 원래 글의 진행자 박마다 까딱이기, 실패는 연기로 보여 주기, 매체 고유의 물리로 웃기기는 화면과 맞다.
- 영상에서 확인한 점 · 진행자는 판정 직후 박에 맞춰 팔을 들었다 내린다(7.5~7.62초 팔 위, 7.66초 내림). 표정은 판정마다 바뀐다(웃음, 이마 짚기, 입 벌림, 무표정).
- 무대는 거의 멈춰 있다(움직임 세기 0.4~2). 무대가 조용해서 게임의 움직임과 매체 변화가 더 크게 느껴진다.
- 목숨을 잃으면 목숨 판의 오른쪽 아이콘이 회전하며 판 밖으로 튀어 나간다(약 0.5초).
- 도화선 · 화면 아래 세로 약 95%, 가로 7~89% 에 꼬인 줄이 깔린다. 매듭 8개, 간격 화면 가로의 약 10%(약 195px). 불꽃은 일정한 속도로 왼쪽에서 오른쪽으로 가고, 끝의 작은 폭죽(가로 약 91%)에 닿으면 판이 끝난다. 줄의 색과 질감은 판의 매체를 따른다(크레용 판은 크레용 줄, 단말기 판은 글자 점선, 도트 판은 도트).

## 4. 전환

- 원래 글의 통일 전환(텔레비전으로 밀고 들어가기 약 0.25초, 줄어들어 나오기 약 0.33초, 페이드·빈 프레임 없음)은 화면과 맞다.
- 영상에서 확인한 점 · 들어가기 직전에 텔레비전 안의 그림이 먼저 다음 판의 첫 프레임으로 바뀐다(7.80초). 그 뒤 약 0.25초 동안 카메라가 화면 안으로 들어가고, 8.04초에 명령어가 꽂힌다. 나오기는 11.94 → 12.10초에 게임 화면이 노랑 테를 두른 채 줄어든다. 약 0.2초 만에 무대 크기에 닿는다.
- 회전 띠(26~27.5초)와 타일 뒤집기(39.9~41.5초)는 지난 판 프레임을 재료로 다시 쓴다. 보스 예고의 타일은 검은 바탕 위에 하나씩 들어온다(39.95초 1장, 40.2초 2장, 40.6초 4장). 각 타일은 화면 가로의 약 25%.
- 마지막 목숨은 화면 구도를 바꾸지 않는다. 조명만 바꾼다. 바탕 보라가 거의 검게 내려가고, 진행자 위로 한 줄기 원뿔 조명만 남는다.

## 5. 타이포

- 명령어 · 꽂히는 순간 글자 높이가 화면의 약 33%(약 360px), 폭이 화면 가로의 약 77%, 약 -6° 기울어진다. 뒤의 노랑 별 폭발은 화면 가로의 약 45%. 원래 글대로 약 0.75초 머문 뒤 왼쪽 위 구석 꼬리표로 줄어든다(가로 2.5~15%, 세로 4~10%, 글자 높이 약 5%).
- 꼬리표 글자는 판의 매체를 따르지 않는다. 늘 같은 흰 글자 + 남색 외곽선이다. 이것이 매체가 바뀌어도 이어지는 두 번째 끈이다.
- 판 안의 효과 글자(재채기, 깨무는 소리 등)는 판의 매체 글씨로 쓴다. 크레용 판은 손글씨, 두 색 인쇄 판은 분홍 인쇄 글자, 수묵 판은 굵은 먹 글씨.
- 무대 글자 · 제목 간판(가로 22~78%, 세로 6~20%, 전구 테두리, 글자 높이 약 6%), 판 번호 카드(가로 3~17%, 세로 6~17%), 아래 자막 띠(가로 29~71%, 세로 84~92%, 글자 높이 약 3.5%). 자막은 판정마다 바뀐다.
- 끝 화면 · 큰 제목 두 줄(글자 높이 약 11%), 그 아래 작은 줄 3~4개.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 23.5~28.0초의 "게임이 텔레비전으로 줄어들며 초록 도장 → 버튼으로 밀고 들어가 내리치기 → 화면이 세로 띠 3개로 갈라져 지난 판 프레임이 돌다가 한 박에 하나씩 노랑·분홍·청록 낱말에서 멈춤 → 다음 매체 판"이다. 무대 요소 8개(간판, 판 번호, 진행자, 텔레비전, 목숨 판, 버튼 받침, 자막 띠, 분홍 원판)가 한 화면에 있고, 텔레비전 화면이 화면 가로의 약 41% 를 차지한다. 텔레비전 장치와 매체가 바뀌는 충격이 빠지면 이 영상이 아니다.
- 12초 판 압축 예 · 0.0~2.0초 판 1(첫 프레임부터 게임 안, 명령어 꽂힘, 매체 A), 2.0~3.0초 텔레비전으로 줄어들어 무대 공개 + 도장, 3.0~4.5초 판 2(매체 B, 실패 연기), 4.5~5.2초 무대 빨간 도장 + 목숨 하나 튀어 나감, 5.2~6.4초 판 3(매체 C), 6.4~8.4초 대표 장면 압축(도장 0.3초 + 버튼 0.5초 + 회전 띠 1.2초), 8.4~9.4초 판 4(매체 D), 9.4~10.4초 판 5(매체 E), 10.4~12.0초 무대 성공 + 주인공 경례 + 텔레비전으로 들어가 끝 화면. 즉석 재생, 마지막 목숨 조명, 보스 판은 뺀다. 판 길이는 2.0 → 1.5 → 1.2 → 1.0 → 1.0 초로 줄인다. 매체는 5개면 충분하다.
- 주인공이 모든 매체에서 같은 표지 셋을 지킨다 · 둥근 헬멧 방울, 끝에 공이 달린 더듬이, 가슴의 두 자리 번호. 매체마다 주인공 크기는 크게 바뀐다(크레용 화면 높이 약 50%, 수묵 얼굴 확대 약 50%, 단말기 글자 그림 약 85%, 두 색 인쇄 약 45%, 도트 약 18%, 청사진 약 20%, 격자 타이포 약 45%). 크기보다 표지가 연결을 맡는다.
- 무대는 대칭 정면 고정. 바뀌는 것은 도장, 목숨, 판 번호, 자막, 진행자 표정뿐이다.

## 7. 함정

- 화면의 쇼 제목, 판 이름, 명령어, 자막 문장, 끝 화면 제목은 원작의 것이다. 옮기지 않는다. 역할(쇼 간판 한 줄, 명령어 한 마디, 판정 자막 한 줄)만 가져온다. 끝 화면 아래 작은 줄에 실존 제작자·음원 이름이 있다. 쓰지 않는다.
- 원래 글의 숏 표에는 실존 감독 이름으로 버튼 확대 숏을 가리킨 대목과 실존 글꼴 이름이 있다. 둘 다 옮기지 않는다. 버튼을 아주 가까이 잡아 끼워 넣는 숏, 둥글고 굵은 장식 글꼴처럼 역할로만 적는다.
- 매체를 다섯 개 넘게 직접 만들면 품이 크다. 한 판에 1.0~2.0초만 보이므로 매체마다 바탕 한 장 + 주인공 한 장 + 동작 하나로 줄인다. 매체 차이는 바탕색과 선 질감에서 크게 난다. 바탕색이 서로 비슷하면(크림 두 개 연속 등) 충격이 사라진다. 이웃한 판은 밝기를 반대로 둔다(크림 → 검정 → 크림 → 남색).
- 판 진입이 페이드가 되면 이 스타일이 사라진다. 진입·복귀는 0.2~0.3초 크기 변화로만 한다. 이때 움직임 세기는 60 이상이 나와야 한다.
- 무대가 움직이면 판의 움직임이 묻힌다. 무대에서는 진행자의 박 까딱임과 도장만 움직인다.
- 한국어 명령어는 140px 이하라서 원본의 360px 크기를 못 낸다. 낱말을 두세 글자로 짧게 하고 뒤의 별 폭발을 화면 가로 50% 로 키워 무게를 낸다.
- 흰 섬광을 100% 로 쓰면 빈 프레임으로 읽힌다(원래 글과 같다). 버튼 내리치기와 띠 바래기는 50~60% 로 막는다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 판마다 다른 매체의 그림 | 매체 8개를 코드로 각각 그리기 어렵다 | 매체 5개로 줄인다. 크레용 판 · `HAND.paint(ctx, P, { fill, tex: [{ k: 'pencil' }] })` 와 `HAND.ink` 굵기 4px, 바탕 #E4DFD5. 수묵 판 · `HAND.washPlate` 먹색 #1A1A1A 판 3장을 로드 때 굽고 `HAND.ribbon` 으로 먹선. 단말기 판 · DOM 고정폭 글자(InterVariable, 숫자·기호만) 옅은 호박색 #B4A27E 근처(흰 글자 #F0F0F0 섞임), 검정 #050302 바탕, 줄마다 0.06초 간격으로 찍힌다. 도트 판 · canvas 를 480x270 으로 그리고 `imageSmoothingEnabled = false` 로 4배 확대. 두 색 인쇄 판 · `LOOKS.halftone({ ink, paper })` 파랑·분홍 2색 | 원본 매체의 수작업 느낌과 매체 수 |
| 주인공(매체마다 다른 그림체) | 같은 인물을 매체마다 다시 그려야 한다 | 표지 셋(둥근 헬멧, 공 달린 더듬이, 가슴 번호)만 고정한 SVG 기본 몸을 하나 만들고, 매체마다 선·채움만 바꾼다(크레용 · `HAND.paint` 빗금, 수묵 · 먹 원 + 흰 눈 2개, 단말기 · 고정폭 글자로 짠 그림, 도트 · 16x20 칸 도트). 또는 AI 일러스트(codex-image)로 매체별 자세 한 장씩을 마젠타 바탕에 그리고 `scripts/key.py` 로 자른다. 프롬프트에 글자·로고 없음을 적는다 | 매체마다 다른 연기 |
| 텔레비전 속으로 밀고 들어가기 | 무대와 게임이 같은 장면이어야 한다 | 게임을 1920x1080 오프스크린 canvas 에 그리고, 무대의 텔레비전 화면 자리(가로 30~71%, 세로 26~66%, 약 785x435px)에 `drawImage` 로 줄여 넣는다. 들어가기는 무대 층 전체를 화면 중심 기준으로 scale 1 → 2.45 로 0.25초(가속 곡선), 그 끝에서 게임 canvas 를 전체 화면으로 바꾼다. 나오기는 그 반대 0.3초. 텔레비전 노랑 테(#FFC827, 두께 약 40px)는 게임 canvas 와 함께 줄어든다 | 없음 |
| 세로 띠 3개 회전 | 지난 판 프레임을 다시 써야 한다 | 지난 판 마지막 프레임을 로드 때 각 판의 seek 로 오프스크린 canvas 에 찍어 둔다(판당 1장). 띠마다 그 프레임들을 세로로 이어 붙인 띠 그림을 만들고, 세로 위치를 t 로 정한다(초당 화면 높이 6배). 움직임 번짐은 같은 띠를 위아래 20px 씩 3번 투명도 0.3 으로 겹친다. 멈춤은 26.5·26.75·27.0 박에 하나씩, 멈출 때 6% 넘쳤다 돌아오기 0.12초 | 실제 움직임 흐림의 부드러움 |
| 명령어 꽂힘 | 한국어 140px 상한, 장식 글꼴 없음 | Pretendard SemiBold 140px, 흰 #FFFFFF, `-webkit-text-stroke` 대신 `paint-order: stroke` + stroke 16px 남색 #1E0E2F, 분홍 #FF2989 그림자 (8px, 10px), 기울기 -6°. 크기는 3프레임에 1.9 → 0.92 → 1.0 배. 뒤의 별 폭발은 SVG 12각 별(바깥 반지름 480px, 안쪽 300px, #E3C113, 외곽선 12px). 0.75초 뒤 왼쪽 위(가로 3%, 세로 5%)로 0.2초에 28% 크기로 줄어든다 | 원본의 둥글고 굵은 글꼴 인상과 크기 |
| 진행자(시계 얼굴) | 인물 연기 | SVG 로 둥근 시계 얼굴 + 정장 몸을 그린다. 팔 하나만 관절 회전(아래 -10° ↔ 위 160°), 얼굴은 표정 4장(웃음, 이마 짚기, 입 벌림, 무표정)을 바꿔 끼운다. 박마다 몸을 2px 내렸다 올린다 | 표정 사이의 중간 동작 |
| 무대 조명 기둥, 마지막 목숨 조명 | 빛 번짐 | CSS 층 · 위에서 아래로 넓어지는 사다리꼴 4개(#FFFFFF 투명도 0.08, `mix-blend-mode: screen`). 마지막 목숨은 바탕에 #000000 투명도 0.7 을 덮고 진행자 위에 원뿔 하나(투명도 0.25)만 남긴다 | 연기 같은 빛의 결 |
| 종이·인쇄 결 | 실제 종이 스캔 | 크레용·수묵·콜라주 판에 `texTile(seed, { mottle: .04, fibers: 150, specks: 20 })` 를 곱하기로 깔고, 전체 위에 `grainLayer(stage, 7)` 를 둔다. 무대와 도트 판에는 깔지 않는다 | 큰 얼룩의 자연스러움 |
