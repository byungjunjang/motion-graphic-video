## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 17.6초 2막. 노을 바다 앞 절벽 위 인물(가로 17~27%, 높이 22%)이 팔을 뻗고, 오른쪽 바다 위(가로 45~95%, 세로 38~95%)에 부메랑 궤도 타원 1개 + 점선 동심원 4개가 겹치며, 오른쪽 위 버전 숫자가 화면 높이 11%로 커지고, 왼쪽 세로 막대가 75% 찬 장면. 동시에 보이는 글자 칸은 3개(문장 상자, 버전 숫자, 막대 라벨)다.
- 12초 판 압축 예 · 연대기 4칸 각 1.0초(4.0초, 던지고 받을 때 칸 교체) → 부메랑이 다가오는 컷 0.5초 → 제목 상자 + 숫자 폭주 2.5초(숫자 4단계) → 수평 광선 + 큰 의성어 1.5초 → 정적 0.5초 → 클로즈업 1.0초 → 흰 프레임 0.1 + 폭발 1.0초 → 그을린 정지 0.9초. 클로즈업의 작은 의성어 키우기는 남기고 2막 문장 상자 세 번은 한 번으로 줄인다.
- "던지고 받기 = 한 칸" 박자. 동작 한 번이 연표 한 칸을 맡는다. 칸 길이를 2.0 → 1.0초로 조금씩 줄여 가속을 미리 깐다.
- 막 경계에 큰 킥 + 컷 + 음량 상승을 함께 둔다.
- 숫자 카운터가 단계를 건너뛰며 커지는 과장(1 → 4 → 256 → 거듭제곱 → 무한대). 숫자 칸 크기도 같이 키운다.
- 폭주 뒤 2초 정적 → 클로즈업 → 반전. 개그 박자를 비움으로 만든다.
- 처음과 끝이 같은 구도다. 끝에서 인물만 그을려 있다.

## 7. 함정

- 화면의 문장 상자, 제목 상자, 의성어는 원작의 것이다. 옮기지 않는다. 문장 상자에는 실존 논문 제목, 실존 모델·제품 이름, 실존 회사의 발표 문구가 들어 있다. 쓰지 않는다. 우리 연표의 사건과 연도는 원문에서 직접 확인한 것만 쓴다.
- 인물은 원작의 캐릭터다. 같은 옷·머리 모양으로 그리지 않는다. 다른 인물이나 사물(작은 로봇, 동물)로 바꾼다.
- 원작은 1280x720 이다. 1920x1080 으로 옮길 때 픽셀 크기를 정수배로 맞춘다. 바탕 그림을 320x180 으로 그리고 6배로 키운다(`image-rendering: pixelated`). 1.5배 같은 비정수 확대는 화소 모양이 깨진다.
- 한국어 픽셀 글꼴이 없다. 한글을 픽셀처럼 보이게 만들기 어렵다(8번 표). 연도·숫자·의성어는 라틴·숫자로, 문장은 Pretendard 로 나눈다.
- 1막은 움직임이 작다(평균 약 2.6). 12초 판에서 연대기 칸을 4개보다 많이 넣으면 한 칸이 0.7초 아래가 되어 문장을 못 읽는다. 한 칸은 1.0초 이상, 문장은 한 줄 12자 이하로 줄인다.
- 3막은 컷 5번, 흰 프레임, 흔들림이 1.5초 안에 몰린다. 흰 프레임은 0.1초를 넘기지 않는다. 깜박임이 3번을 넘지 않게 한다.
- 끝의 "인물이 터짐"은 개그다. 기업 소개 영상에서는 톤을 확인한다. 바꿀 때는 인물 대신 부메랑이 바다에 떨어져 물보라가 이는 끝으로 줄인다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 픽셀 한 칸은 6px 다. 글꼴은 Pretendard Regular·SemiBold, 숫자·라틴은 InterVariable 도 쓴다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 픽셀 노을 바탕 | 손으로 찍은 화소 그림 | 320x180 canvas 에 직접 그리고 CSS 로 6배 키운다(`image-rendering: pixelated`). 하늘은 높이 6~10칸 띠 12줄(#381358 → #BE5E7A → #FF7B62 단계). 해는 원을 그리고 가로 띠 6줄을 잘라 낸다. 구름·능선·절벽은 칸 단위 다각형. 반사 띠는 15줄을 사인으로 ±2칸 흔든다 | 화가가 찍은 디더링 결 |
| 픽셀 인물 | 표정·자세가 있는 캐릭터 | `codex-image` 로 32x40 칸 느낌의 픽셀 인물을 마젠타 바탕에 그려 `key.py` 로 투명화한다(포즈 3장 · 서기, 던지기, 그을림). 글자 없이. 또는 canvas 에 칸 배열로 직접 찍는다 | 손으로 찍은 표정의 정밀함 |
| 클로즈업 얼굴 | 큰 픽셀 그림 | `codex-image` 로 같은 인물의 상반신 픽셀 그림 2장(평소, 놀람+땀방울). 화면 높이 65%로 놓는다 | 넓은 장면 인물과의 완전한 일치 |
| 부메랑 회전 | 픽셀 그림 여러 장 | 20x20 칸 부메랑 한 장을 canvas 에서 90°씩 돌린 4장을 0.1초마다 바꾼다. 궤도는 타원(가로 반지름 420px, 세로 140px) 위 매개변수 t, 손에서 시작·끝. 꼬리 점 14개를 0.03초 간격 과거 위치에 지름 6px 흰 점으로 | 회전 중간 모양 |
| 빛 원 · 광선 꼬리 | 발광 | 부메랑 뒤 DOM 원(지름 240px, `radial-gradient(부메랑색 0%, transparent 70%)`, `mix-blend-mode: screen`). 광선은 높이 36px 흰 막대, 왼쪽 끝 투명 그라데이션, 폭 960px | 화소 단위로 끊긴 빛 |
| 브라운관 효과 | 후처리 | 전체 위에 `repeating-linear-gradient(transparent 0 4px, rgba(0,0,0,.18) 4px 6px)` 주사선 + `radial-gradient` 모서리 어둡게(가장자리 0.45). 글자에는 `text-shadow: -2px 0 rgba(255,0,80,.5), 2px 0 rgba(0,200,255,.5)` | 화면이 휘는 느낌 |
| 픽셀 글꼴 | 픽셀 글꼴이 없다 | 연도·숫자·의성어 · InterVariable 굵기 800 을 canvas 에 작게(높이 8~16칸) 그린 뒤 6배로 키워 픽셀처럼 만든다. 한국어 문장 · Pretendard SemiBold 44px, 자간 0.02em, 상자 안 두 줄. 상자는 노랑 #DAC760, 테두리 9px #120818, 그림자 (9px, 9px) | 한글의 픽셀 글꼴 맛 |
| 한 글자씩 쳐지는 문장 | 없다 | 글자 span 을 0.04초 간격으로 보인다. 상자는 아래에서 12px 올라오며 0.1초에 들어온다 | 없음 |
| 겹겹 궤도 · 점선 동심원 | 없다 | SVG ellipse 1개(stroke 6px #FFF0E0, opacity 0.8) + 점선 원 4개(stroke-dasharray 3 9, 반지름 120~360px). 숫자가 바뀔 때마다 하나씩 더한다 | 없음 |
| 픽셀 폭발 · 연기 | 손으로 찍은 효과 | 원 10개(지름 60~180px, 주황 #F08A2A·노랑 #F6D35A)를 칸 단위로 반올림해 그린다. 0.5초에 scale 0.2 → 1, 그 뒤 0.4초에 줄며 회색 연기 원으로 바뀐다. 화면 흔들림 ±12px, 0.4초 감쇠 | 폭발 모양의 손맛 |
