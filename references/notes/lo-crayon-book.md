# 크레용 그림책 · 그려지며 끝나는 한 장 — 분석 노트

> 따뜻한 미색 종이 한 장 위에서 크레용 그림책 한 쪽이 실시간으로 그려지는 52초 영상. 빈 종이에 집·나무·얼굴 있는 달이 선으로 그려지고 칠해진다. 잠 못 드는 달, 지붕에 오른 아이, 남색 수채가 띠로 쓸고 지나가며 밤이 오는 장면, 달이 잠드는 장면이 이어진다. 끝에 카메라가 물러나 책상 위의 펼친 책이 되고, 한 장을 넘겨 끝 쪽으로 간다. 어린이 교육, 잠자리 이야기, 다정한 공익 안내에 맞는다.

출처 · lo:crayon-book. 원래 글은 긴 스타일 명세다(본질, 움직임, 카메라 문법 표, 매체 함정, 숏 표). 매체 원리, 12장/초 떨림, 카메라 동작은 자세하다. 그러나 숏 표에 시각이 없고, 색 값, 화면 크기, 수채 띠의 속도와 넓이, 대표 장면이 없다. 이 노트는 영상 프레임을 보고 그 빈칸을 채웠다.
측정 · 파일 1280x720 · 24fps · 52.01초. 크기는 1920x1080 기준으로 바꿔 적는다(1.5배). 하드 컷은 없다(장면 감지 0회). 움직임 세기 평균 7.3. 0~5.0초는 0.1~3.1 로 거의 멈춰 있고, 큰 구간은 20.0초(22.0, 창으로 밀고 들어가기), 37.5~39.0초(14.6~18.3, 달로 밀고 들어가기), 42.5초(28.4), 45.5~46.5초(30.4~39.2, 책으로 물러나기, 최대)다. 색 값은 프레임에서 잰 근삿값이다.

## 3. 움직임

- 원래 글의 수치(12장/초, 선 하나 0.4~0.9초, 자세 갈아 끼우기)는 화면과 맞다.
- 영상에서 확인한 점 · 52초 가운데 세기 3 아래가 약 45%다. "멈춘 화면 위에 무엇이 그려지는가"로 시간을 채우고, 카메라 이동은 1.5~3초씩 끊어 넣는다. 고정 구간의 세기 0.3~0.7 은 2프레임마다 다시 그리는 떨림 값이다.
- 한 번에 하나만 그려진다. 겹쳐 그려지는 시간은 0.5초 안팎이다.

## 4. 전환

- 디졸브가 없다(원래 글). 큰 장면 변화 네 번이 모두 카메라 동작이다 · 제목 → 달(밀기 2초), 달 → 집(기울기 2.5초), 낮 → 밤(고정, 수채 띠 6초), 그림 → 책상(물러나기 2초). 제목은 지우지 않고 밀기로 화면 밖에 내보낸다. 책장 넘김은 0.8초 안팎이다.

## 5. 타이포

- 제목 · 왼쪽 위(가로 1~25%, 세로 3~17%), 두 줄, 손글씨 같은 크레용 글자, 글자 높이 화면의 약 5%(약 55px). 한 글자씩 써진다(3.0~5.0초).
- 자막 · 아래 가운데, 찢은 흰 종이 띠(글자 폭 + 양쪽 30px, 가장자리 들쭉날쭉) 위 글자 높이 약 2.5~3%(약 30px). 수채가 아래까지 덮어도 띠 덕분에 읽힌다.
- 숫자 1~5 · 크레용 손글씨 높이 약 5%. 끝 쪽 · 큰 제목 한 줄(약 9%) + 작은 두 줄.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 28.5~34.5초의 수채 띠 장면이다. 카메라는 넓은 구도에 멈춰 있고, 남색 수채 띠가 가로 방향을 바꿔 가며 화면을 덮는다. 띠 3개가 왼쪽 → 오른쪽, 오른쪽 → 왼쪽, 오른쪽 → 왼쪽으로 각 약 1초에 화면을 지나고, 덮인 넓이가 0% → 34% → 62% → 79% 로 는다. 크레용으로 그린 집·달·별·아이는 수채를 밀어내 그대로 남는다. 카메라가 움직이면 이 장면이 아니다. 띠가 화면을 한 번에 덮어도 이 장면이 아니다.
- 12초 판 압축 예 · 0~2.5초 빈 종이에 집·달 선이 그려지고 칠해진다(고정), 2.5~3.5초 달로 밀기, 3.5~5.0초 달 근접 갈아 끼우기 두 자세, 5.0~6.0초 아래로 기울여 지붕 위 인물, 6.0~9.0초 대표 장면 3초(띠 3개를 각 0.8초, 쉼 0.2초), 9.0~10.5초 달이 잠드는 근접(눈꺼풀 낙서, 모자), 10.5~12.0초 책상 위 펼친 책으로 물러나기. 양 세기, 사다리 오르기, 이불, 책장 넘김과 끝 쪽은 뺀다.
- 처음 1초는 빈 종이와 비네트만. 글자와 그림은 지우지 않고 카메라로 밀어내고, 밤은 덧칠로 온다. 끝에 물러나 한 장이 사물(책)이 된다.

## 7. 함정

- 화면의 제목, 자막, 끝 쪽의 글자, 인사말은 원작의 것이다. 옮기지 않는다. 역할(손글씨 제목 두 줄, 찢은 종이 띠 자막, 끝 쪽 큰 제목)만 가져온다. 끝 쪽 작은 글자에 제작자 이름과 실존 모델 이름이 있다. 쓰지 않는다.
- 얼굴 있는 달, 양 세기, 지붕 위 노래 같은 줄거리 소재는 원작의 것이다. 구조(문제 → 작은 용기 → 매체 변화로 해결 → 물러나 사물이 됨)만 가져오고 소재는 우리 주제로 바꾼다.
- 수채를 한 번에 덮으면 대표 장면이 1초로 끝난다. 띠 3개 이상, 방향을 번갈아, 사이에 쉼, 띠 높이 화면의 30~35%.
- 띠 사이 흰 줄을 막으려 띠를 30~40px 겹친다. 겹친 자리가 진해지는 것(#303668 줄)은 원본에도 있다.
- 수채 아래에서 크레용 그림이 지워지면 이 스타일이 아니다. 집·달·별·인물은 수채 판 위에 다시 그린다. 별은 수채보다 먼저 종이 색 점으로 깔고 수채를 그 점 밖에만 칠한다.
- 카메라 이동은 한 번 1.5~3초, 사이에 고정 구간을 둔다. 목표 움직임 세기는 고정 0.3~3, 이동 10~20.
- 종이 결은 그림 쪽에 붙여 카메라와 함께 움직인다. 화면에 붙이면 필터가 된다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 그림 판(세계)은 원래 글처럼 3200x1800 으로 두고, 한 장 전체는 0.6배로 본다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 크레용 칠(종이 결 봉우리에만 묻는 밀랍) | 결마다 묻는 정도가 다른 매체 효과다 | `HAND.paint(ctx, P, { key, B, fill: null, tex: [{ k: 'pencil', angle: -0.95, len: 14, per: 220 }, { k: 'hatch', angle: 0.6, gap: 6 }], line: '#3D2834', w: 4.5 })`. 칠은 두 겹으로 쌓고 위에 `texTile(seed, { mc: '120,110,95', mottle: .04, dark: .06, light: .06, fibers: 180, specks: 30 })` 을 곱하기로 덮는다. 비네트는 귀퉁이 #000 불투명도 0.25 방사형 | 밀랍이 결에서 끊기는 미세한 반짝임 |
| 선이 그려지는 등장과 떨림 | 없다. 코드로 된다 | `HAND.ink(ctx, P, { key, B, frac, w: 4.5, color: '#3D2834', amt: 1.8 })`. `B` 는 12장/초로 바뀐다(`Math.floor(t * 12) % 3`). 배경 선은 `amt: 1.1`, 배경 칠은 `B = 0` 으로 고정 | 없음 |
| 남색 수채 띠 쓸기 | 수채 번짐과 크레용이 수채를 밀어내는 효과 | 띠마다 `HAND.washPlate(3400, 640, P, { seed, layers: 30, alpha: 0.05, color: '#3A3F70', spread: 8 })` 를 로드 때 구운다(띠 3개 × 3장). seek 에서는 앞선 x 를 시간으로 옮기는 가로 마스크(앞선에 지름 30~60px 둥근 혹)로 공개한다. 앞선 x 는 0.9초 동안 사인 가감속(`0.5 - 0.5 * Math.cos(Math.PI * u)`)으로 0 → 1960px(첫째 띠), 둘째·셋째는 1.2초. 띠 높이 420·355·300px, 겹침 35px, 아래 가장자리는 `HAND.wobble` 로 10~20px 물결. 그 뒤 집·달·인물 층을 다시 그리고, 별 자리(지름 6~12px)는 `destination-out` 으로 지운다 | 크레용 경계에서 물감이 맺히는 테 |
| 얼굴 있는 달·아이의 자세 그림 | 손으로 그린 자세 여러 장 | 단순 도형 얼굴은 자세 3~4개를 `HAND.ink` 경로로 만들어 박자에 갈아 끼운다. 복잡한 인물은 AI 일러스트(codex-image)로 크레용 느낌의 자세 3장을 마젠타 바탕에 그려 `scripts/key.py --split` 로 자른다(글자 없음) | 그림마다 다시 그린 떨림(그림 파일은 `B` 로 1px 흔들기만 된다) |
| 책상 위 펼친 책으로 물러나기 | 종이 그림이 사물이 되는 3단 원근 | three.js(`vendor/three`) 평면 두 장(왼쪽 쪽, 오른쪽 쪽)에 그림 canvas 를 텍스처로 붙이고, 아래에 나뭇결 판(AI 일러스트 한 장, 크레용 7~8자루 포함, 글자 없음)을 둔다. 카메라를 2초에 세계 크기 1.0 → 0.45 로 물린다. 책장 넘김은 오른쪽 평면을 접힌 선 축으로 0 → 180° 0.8초 돌린다 | 쪽이 휘는 곡면과 그림자 |
| 손글씨 제목과 자막 | 손글씨 글꼴이 없다 | 제목은 Pretendard SemiBold 60px, #2E2A48, 한 글자씩 0.08초 간격으로 나타난다. 자막은 Pretendard Regular 32px, 흰 띠 위에 둔다. 띠는 `HAND.wobble` 로 가장자리를 흔든 직사각형(높이 52px, 글자 폭 + 60px), 바탕 #F7F4EC | 크레용 글씨의 거친 결 |
