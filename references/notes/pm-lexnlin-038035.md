## 3. 움직임

- 그림은 거의 움직이지 않는다. 그림을 바꾸는 것이 움직임이다. 한 그림이 머무는 시간은 0.05초(연사)에서 0.5초(조각 두상, 낱말)까지다. 0.15~0.25초가 가장 흔하다.
- 덧그린 요소가 움직임을 맡는다. 손그림 원이 그려지며 닫히고(0.2~0.3초), 산호색 점이 선을 따라 미끄러지고, 호가 길어져 나선이 된다(8.4~10.6초).
- 한 위치에 고정된 덧그림 위로 그림만 바뀌는 구간이 두 곳이다. 0.75~1.4초(같은 원 안에서 눈 결정 → 다른 결정 → 장식 무늬)와 8.4~10.6초(같은 호와 점 아래에서 그림 20여 장).
- 낱말 변형은 글자 단위다. 앞에 글자 하나 더하기(2.4초), 첫 글자 하나 바꾸기(5.75초), 부호 바꾸기(물음표 → 마침표, 2.25초). 바뀌는 글자는 먼저 산호색으로 들어오고 0.2초 뒤 검정이 된다.
- 확대는 두 번이다. 먹 획 확대(3.1초)와 눈 결정 격자 확대(3.25~3.6초).
- 입체는 한 번뿐이다(6.3~7.2초 별 모양). 선화 → 입체 → 회전 번짐.
- 사진 연속으로 회전을 흉내 낸다. 두상 정면 → 3/4 → 옆얼굴(4.6~4.9초), 말 실루엣 고리의 회전(3.75~4.0초).
- 끝 1.2초는 워드마크 정지다.

## 4. 전환

- 하드 컷이 1곳(8.42초)뿐이고 나머지는 같은 자리의 덧그림이 이어 준다. 원 → 원(같은 크기의 손그림 원 안에서 그림만 바뀜), 점 → 점(인체의 배꼽 점 → 팔 끝 점 → 낱말 위 호), 호 → 나선 → 글자 점.
- 반전 번쩍임 4번(1.17, 4.37, 9.10, 10.68초)이 큰 구분이다. 2~3프레임이고 셋은 타격에 맞는다. 번쩍임 앞뒤 그림은 같은 그림이다(장식 무늬, 말 뼈대, 근육 판화, 별). 그래서 컷이 아니라 강세다.
- 모양 이어 받기 · 물음표의 점(0.5초) → 원 끝의 산호색(0.75초), 원 → 말 고리(3.7초), 해바라기의 나선 중심(10.25초) → 낱말의 점(10.9초), 손그림 별(12.5초) → 워드마크 표지(13.5초).
- 낱말 → 그림 · 낱말이 화면 가운데에 남은 채 위아래에 그림이 붙었다 사라진다(2.1초, 2.6초).
- 처음과 끝이 같다. 첫 0.4초와 끝 1.2초가 같은 워드마크, 같은 자리, 같은 크기다.

## 5. 타이포

- 글꼴은 하나다. 획 대비가 중간인 굵은 세리프 소문자(끝 문구 첫 글자만 대문자), 검정. 워드마크도 세리프다.
- 낱말 크기 · 높이 208~273px(화면 높이의 11~14%, 올림 획에서 기준선까지), 폭 551~748px(화면 너비의 51~69%). 글자 크기는 낱말마다 같고 폭이 낱말 길이를 따른다. 왼쪽 여백 약 170px(16%)로 왼쪽 정렬처럼 놓인다.
- 다섯째 낱말만 두 줄로 쪼개고 더 크게(한 줄 높이 약 380px, 20%) 써서 오른쪽을 화면 밖으로 넘긴다.
- 끝 문구 · 두 줄, 첫 줄은 대문자 시작 낱말(높이 245px), 둘째 줄은 같은 굵기의 작은 낱말(글자 높이 약 160px) + 산호색 마침표. 둘째 줄이 첫 줄보다 작다.
- 산호색은 낱말마다 한 곳에만 쓴다. 부호, 바뀌는 글자, 줄 긋기, 글자 점, 마침표.
- 작은 글자·설명·꼬리표가 하나도 없다. 화면의 글자는 낱말 하나 또는 두 줄 문구 하나뿐이다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 9.6~10.9초. 흰 바탕 위쪽에 고정된 검은 호(굵기 약 4px)가 나선으로 길어지는 동안 뒤의 흑백 그림이 약 0.07초마다 바뀌고, 10.25초 해바라기 씨앗 무늬 한가운데의 산호색 점(34x45px)이 나선 중심에 놓였다가, 10.9초 낱말의 점(70px)이 된다. 동시에 보이는 요소 3개(그림 1, 나선 1, 점 1). 덧그림은 고정되고 그림만 바뀌는 연사, 산호색 점 하나의 이어 받기가 빠지면 이 영상이 아니다.
- 12초 판 압축 예 · 0~0.4초 워드마크, 0.4~1.4초 원 안 그림 3장 + 반전 번쩍임, 1.4~3.0초 점이 그림 위를 옮겨 다니다 낱말 하나에 닿고 글자 하나를 더해 둘째 낱말, 3.0~4.4초 그림 3~4장(조각 두상의 회전 포함), 4.4~5.2초 낱말 첫 글자 바꾸기, 5.2~6.2초 별 모양 선화 → 입체, 6.2~8.4초 호와 점 아래 그림 연사(0.07~0.15초 간격 15장 안팎) + 반전 번쩍임, 8.4~10.0초 끝 문구, 10.0~10.8초 별 → 워드마크, 10.8~12.0초 정지. 말 고리와 손 조각 구간을 뺀다.
- 덧그림을 한 자리에 고정하고 뒤 그림만 바꾸는 법. 바뀌는 그림이 많아도 눈이 고정점에 머물러 읽힌다.
- 글자 하나로 낱말 바꾸기. 바뀌는 글자만 산호색으로 먼저 넣고 0.2초 뒤 검정으로 돌린다.
- 반전 번쩍임 2~3프레임을 타격에 맞추는 강세. 4번 이하로 쓴다.
- 브랜드 표지가 선화 → 입체 → 손그림으로 모습을 바꾸며 영상 안에 세 번 나오는 구성.
- 끝 화면 = 첫 화면.

## 7. 함정

- 화면의 워드마크와 별 모양 표지는 실존 브랜드의 로고다. 쓰지 않는다. 우리 대상의 로고는 사용자가 허락한 파일만 쓴다. 낱말과 끝 문구도 원작의 것이니 옮기지 않는다. 역할(물음 → 일 → 결과로 이어지는 낱말 사슬, 끝 문구 두 줄)만 가져온다.
- 그림 대부분은 실존 화가·사진가의 옛 작품(인체 비례 판화, 동물 목판화, 근육 해부 판화, 연속 사진의 말, 눈 결정 사진)이다. 작품을 찾아 넣거나 비슷하게 그려 달라고 하지 않는다. AI 그림의 프롬프트에 작가·작품 이름을 넣지 않고, 이 영상의 프레임을 참조 이미지로 붙이지 않는다. "흑백 판화 양식의 해부도" 처럼 일반 양식으로만 쓴다.
- 그림 20여 장이 필요하다. 12초 판에서도 15장 이상이다. 그림 수가 모자라면 연사 구간(0.07초 간격)이 같은 그림의 반복으로 보인다.
- 반전 번쩍임과 0.05초 연사는 깜박임이 강하다. 화면 전체 밝기가 순백 ↔ 검정으로 2프레임 만에 바뀐다. 번쩍임은 4번 이하, 연사는 1초 이하로 둔다.
- 한국어 낱말 변형은 라틴 낱말처럼 글자 하나를 더해 다른 낱말이 되는 짝이 드물다. 받침 하나, 첫 음절 하나를 바꾸는 짝(두 글자 낱말)을 미리 찾아 두고, 없으면 낱말 끝의 부호(물음표 → 마침표)만 바꾸는 변형을 쓴다.
- 세로 → 가로(16:9) 구도 · 원본은 1080x1920 이고 주인공(그림·낱말)이 화면 너비의 51~85%(550~920px), 세로 40~65% 구간에 있다. 1920x1080 으로 옮길 때 주인공을 높이 기준으로 줄인다. 그림은 높이 720~800px(화면 높이의 67~74%, 원본 크기의 약 0.62~0.8배)로 가운데 세로 띠(가로 30~70%, 폭 약 770px)에 둔다. 손그림 원은 지름 900px → 760px(높이의 70%), 가로 50%·세로 50% 중심. 낱말은 원본 높이 208~273px(높이의 11~14%)를 가로판 높이의 13%(약 140px, 한국어 상한)로 두고, 폭은 화면 너비의 30~40% 를 넘기지 않는다. 원본에서 낱말 위아래에 붙던 그림 두 장(2.1초, 위 578x411px·아래 1080x753px)은 가로판에서 낱말 왼쪽(가로 5~32%)과 오른쪽(가로 68~95%)에 각각 높이 520px 로 놓는다. 위쪽에 고정되던 호와 점(세로 25~35%)은 가로판에서 세로 22~30%, 가로 55~75% 에 둔다. 다섯째 낱말처럼 화면 밖으로 넘기는 구도는 오른쪽 끝(가로 100%)을 넘기는 것으로 그대로 쓴다. 워드마크는 원본의 너비 83%(899px)를 가로판 너비 47%(약 900px)로, 세로 45~55% 에 둔다.
- 세로판의 빈 위아래(세로 0~25%, 75~100%)는 원본에서도 대부분 비어 있다. 가로판에서는 좌우가 비게 되므로 그림 크기를 키우지 말고 여백을 그대로 둔다. 흰 여백이 이 영상의 인상이다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080(가로판) 기준이다. 글꼴은 Pretendard Regular·SemiBold(한국어), 숫자·라틴은 InterVariable 이다. 세리프 글꼴은 없다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 옛 판화·과학 도판 그림 20여 장 | 실존 작품이고 수가 많다 | AI 일러스트(codex-image)로 "흑백 동판화 양식, 가는 빗금 음영, 흰 바탕, 글자 없음" 의 일반 주제(해부된 손, 말의 뼈대, 천구 원판, 다면체, 꽃 단면, 나선 조개)를 12~15장 만든다. 마젠타 바탕으로 그리게 한 뒤 `scripts/key.py` 로 바탕을 지운다. 여러 개를 한 장에 그렸으면 `--split` 으로 나눈다 | 옛 인쇄물 특유의 낡은 먹 번짐과 진짜 사료의 무게 |
| 흰 대리석 조각 사진 | 사진이 없다 | AI 일러스트로 "흰 대리석 두상 조각, 정면/3/4/옆얼굴 세 장, 같은 조각, 흰 바탕, 글자 없음" 을 만들고 `scripts/key.py` 로 오린다. 회전은 세 장을 0.15초씩 바꿔 흉내 낸다 | 세 장 사이 모양이 조금씩 어긋날 수 있다 |
| 손그림 원 | 굵기가 고르지 않은 붓 선 | `HAND.ribbon(ctx, P, u => 7 + 5 * Math.sin(Math.PI * u), { color: '#111111' })`. P 는 지름 760px 원 둘레 점 120개에 `HAND.wobble(P, false, 3, 'ring', 0)` 을 한 번 적용한 것. `HAND.subPath(P, frac)` 로 frac 0 → 1 을 0.25초에 그리고, 끝에 산호색 점(지름 22px)을 붙인다 | 붓 끝의 갈라짐 |
| 호와 나선 | 없다. SVG 로 된다 | SVG path 하나에 고른 간격 나선 r = 18 + 26θ(θ 0 → 5π). `stroke-dasharray` 로 1.4초에 그린다. 굵기 4px #111111, 끝에 산호색 원(지름 26px, #C86858)이 진행 끝을 따라간다 | 없음 |
| 그림 연사(0.05~0.07초) | 없다 | 그림 img 15장을 미리 불러 두고 seek(t) 에서 `Math.floor((t - t0) / 0.067)` 번째만 보이게 한다. 덧그림 층은 그 위에 고정 | 없음 |
| 반전 번쩍임 | 없다 | 장면 전체 부모에 `filter: invert(1)` 을 2프레임(0.033초)만 건다. 산호색은 반전되면 청록이 되므로 번쩍임 동안 산호색 요소만 따로 `filter: invert(1)` 을 한 번 더 걸어 되돌린다 | 없음 |
| 입체 별 모양 | 3D 돌출과 그림자 | three.js 로 별 윤곽 `Shape` 를 `ExtrudeGeometry`(depth 0.25, bevel 0.03)로 돌출, `MeshStandardMaterial` 색 #C86858, 거칠기 0.55. 바닥 그림자는 `LOOKS.floor()` 로 받는다. 후처리는 `LOOKS.post(gl, { w: 1920, h: 1080, bloom: 0, tone: 'neutral' })` | 없음 |
| 별 모양 선화(작도선) | 없다. SVG 로 된다 | SVG 로 별 윤곽(뿔 10개, 지름 600px) 굵기 3px 검정, 둘레에 컴퍼스 원 2개(반지름 300·330px, 굵기 1px)와 중심선 5개. 0.3초에 차례로 그린다 | 없음 |
| 굵은 세리프 낱말 | 세리프 글꼴이 없다 | 한국어는 Pretendard SemiBold 140px(높이 13%), 자간 -0.03em, #111111. 바뀌는 음절만 #C86858 로 0.2초 넣었다가 #111111 로 0.15초 동안 바꾼다. 라틴 낱말이면 InterVariable `font-weight: 800`, 180px | 세리프의 인문적 인상 |
| 가로 안내선 | 없다 | 1px #BBBBBB 가로선 5개, 간격 110px, 왼쪽에서 오른쪽으로 0.2초에 그어진다 | 없음 |
