## 3. 움직임

- 카메라 비행이 거의 전부다. 사물이 스스로 움직이는 것은 흐름 입자, 열 선, 트레이 미끄러짐, 층 들림, 칸 떠오름뿐이다.
- 장 안의 카메라는 한 방향으로 천천히 간다(밀기, 따라가기, 돌기 중 하나). 장 끝에서 사물 하나로 급히 다가가 다음 장 크기로 넘어가는 곳이 두 번 있다(4장 → 5장, 5장 → 6장).
- 흐름 입자의 속도는 화면에서 대략 초당 200~400px 다. 같은 경로에 입자가 고르게 흩어져 있다. 흐름이 켜질 때는 경로 시작부터 끝까지 약 1초에 퍼진다.
- 열 선은 짧은 빨강 선 수백 개가 아래에서 위로 오르며 흐려진다. 오르는 높이는 건물 높이의 약 2배다.
- 움직임 세기 평균 6.08. 장 안에서는 2~5, 카메라가 빨라지는 순간 8~15, 전환 순간 16~43 이다.

- 장 전환 두 가지가 섞여 있다.
  - 원작의 전환 · 화면이 회백 안개로 0.4~0.5초 흐려진다. 다음 장이 안개 속에서 나타난다. 왼쪽 아래 제목은 흐려진 뒤 새 제목이 한 글자씩 0.5초에 쳐진다. 설명 문장은 0.3초 페이드로 뒤따른다. 범례는 줄의 진하기만 바뀐다.
  - 녹화자의 건너뜀 · 28.65, 58.95, 80.43초는 녹화자가 재생 막대를 눌러 생긴 하드 컷이다. 원작의 전환이 아니다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 56초 칩 분해. 빈 회백 바탕 가운데에 은색 판(폭 약 58%, 가로 21~80%)이 떠 있고, 그 위(세로 20~35%)에 얇은 판 8~10장이 겹친 탑 두 무리와 다이가 층 사이 60~120px 빈칸을 두고 떠 있으며, 아래(세로 60% 아래)에 녹색 기판이 흐리게 깔린다. 지시선 이름표 3개, 범례는 파랑 한 줄만 진하다.
- 12초 판 압축 예 · 4장만 쓴다. 전경 + 열 선 2.5초 → 실내 통로 밀기 2.5초 → 랙에서 트레이가 미끄러져 나오고 다가가기 3.0초 → 칩 분해(층이 위로 들림) 2.5초 → 전경으로 돌아와 네 흐름 모두 켜기 1.5초. 장 전환은 0.4초 안개. 송전선 따라가기, 칩 표면, 뒤판 배선, 랙 무리, 냉각 배관은 뺀다.
- 20~30초 판을 만들 때 장 고르기 · 전경(3) → 전력 유입(4, 송전선 1구간 + 변압기 1개만) → 실내 통로(4) → 랙 + 트레이(5) → 칩 분해(5) → 열 빼내기(4, 배관이 지붕으로 올라가는 구간만) → 끝 전경(3) = 28초. 흐름 네 색이 모두 한 번씩 주인공이 되게 고른다. 칩 표면·뒤판 배선·랙 무리는 데이터 장이 겹치므로 뺀다.
- 흰 모형 + 색 흐름 네 가지의 역할 나눔. 모형은 구조, 색은 흐름만 맡는다.
- 범례 상시 + 이번 장 흐름만 진하게. 장이 바뀌어도 범례는 자리를 지킨다.
- 장 표기 막대의 색이 그 장의 주인공 흐름 색이다(전력 장은 주황, 열 장은 빨강).
- 처음과 끝이 같은 전경이고, 끝에서만 네 흐름이 모두 켜진다.
- 층이 위에서부터 차례로 들리는 분해.

## 7. 함정

- 녹화 화면이다. 아래의 재생 막대(높이 약 68px, 짙은 회청), 재생·전체 화면 같은 단추, 마우스 커서와 글자 커서는 영상이 아니라 녹화 도구다. 따라 그리지 않는다. 28.65·58.95·80.43초의 하드 컷도 녹화자가 건너뛴 자국이다. 장 전환은 안개 0.4초로 통일한다.
- 화면 비율이 1920x982(약 1.96:1)다. 16:9(1920x1080)로 옮기면 세로가 98px 늘어난다. 위 30px, 아래 68px 를 더한다. 재생 막대 자리였던 아래 7%는 비워 두고, 제목·설명 블록을 세로 70~90% 에 둔다. 범례는 세로 4~11% 그대로.
- 화면의 장 제목, 설명, 이름표 문장은 원작의 것이다. 옮기지 않는다. 칩·장비 장에는 실존 회사 이름, 실존 제품 이름, 실존 제조 공정 이름이 여러 번 나온다. 끝 장 설명에는 실존 도시 이름이 나온다. 모두 쓰지 않는다. 수치도 원작의 것이므로, 우리 대상의 수치는 원문에서 직접 확인한 것만 쓴다.
- 3D 부담이 크다. 건물·송전탑·랙 수백 칸·칩 층·배관이 모두 모형이다. 12초 판은 장 4개로 줄이고 모형을 상자와 판 위주로 단순화한다.
- 흐름 선이 많아지면 회백 모형 위에서 색이 서로 묻힌다. 한 장에 진한 흐름은 둘까지만 둔다. 나머지는 옅게(투명도 0.25) 남긴다.
- 지시선 이름표가 3D 사물에 붙어 카메라와 같이 움직인다. 화면 밖으로 나가거나 제목과 겹치기 쉽다. 이름표는 가로 15~90%, 세로 5~65% 안에서만 보인다.
- 설명 문장이 세 줄이고 수치가 많다. 12초 판에서는 장마다 제목 한 줄 + 수치 한 마디로 줄인다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 글꼴은 Pretendard Regular·SemiBold, 숫자·라틴은 InterVariable 도 쓴다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 흰 점토 모형 | 모형 수가 많다 | three.js 로 상자·원기둥·판만 쓴다. 재질은 `LOOKS.clay('#DFE1E0')`, 환경은 `LOOKS.env(gl, 'studio')`, 바닥은 `LOOKS.floor()`. 나무는 지름 0.6 구 + 원기둥 30개. 모서리는 `LOOKS.slab(w, h, d, 0.04)` 로 둥글린다 | 송전탑·설비의 세부 |
| 흐름 점선 입자 | 경로를 따라 흐르는 굵은 점선 | `LOOKS.trail(points, { dash: true, color, width })` 에 `tr.u.uFlow` 를 t 로 넘긴다. 전력 #E49E2E, 데이터 #2B4BF6, 열 #D32934, 냉각수 #3FBFA8. 켜질 때 `uP` 를 0 → 1 로 1.0초 | 입자 가장자리의 흐림 |
| 솟는 열 선 | 짧은 선 수백 개 | 지붕 위 40곳에서 선 8개씩(길이 0.4, 굵기 2px) 을 InstancedMesh 로. 높이 = (t*0.5 + 씨앗) mod 1 × 건물 높이 2배, 높이에 따라 opacity 1 → 0 | 거의 없음 |
| 안개 · 먼 곳 흐림 | 없다 | `scene.fog = new THREE.Fog('#D7DCDF', 40, 140)`, 배경도 #D7DCDF. 장 전환은 화면 전체 div(#E4E7E8)의 opacity 0 → 1 → 0 을 0.4초에 | 없음 |
| 서버 랙 앞면 | 칸 수백 개 | 앞면을 canvas 텍스처 하나로 그린다(짙은 회청 #3A4048 바탕에 가로줄 40칸, 칸마다 점 6개). 아래로 갈수록 흰색 그라데이션을 겹쳐 흐린다 | 칸마다의 입체감 |
| 칩 층 분해 | 반투명 얇은 판 여러 장 | 판 6장(`LOOKS.slab`), 메모리 탑은 얇은 판 9장 × 2무리. 층 i 의 y = 기본 + i × 0.35 × ease(t - 0.4i). 위층부터 0.4초 간격으로 들린다. 반투명은 `LOOKS.glass({ opacity: 0.55 })` | 판 표면의 회로 무늬 |
| 칩 표면 칸이 켜지고 떠오름 | 수백 칸 | 20x14 InstancedMesh 칸. 켜진 칸은 #2B4BF6 발광, `LOOKS.post(gl, { bloom: 0.4 })`. 떠오르는 칸 묶음은 y 를 1.2 올려 3x4 격자로 재배치(0.8초) | 칸 배치의 의미 |
| 녹색 기판 | 회로 무늬 | canvas 텍스처 · 바탕 #5E7550 에 옅은 노랑 가는 선 200개를 씨앗 난수로 그어 한 번 굽는다 | 실제 회로 같은 결 |
| 지시선 이름표 | 3D 점을 따라다닌다 | `LOOKS.pin(v, cam, 1920, 1080)` 로 화면 좌표를 구해 DOM 이름표를 놓는다. 원 10px + SVG 꺾인 선 + Pretendard SemiBold 22px 이름 + Regular 16px 회색 수치 | 없음 |
| 굵고 좁은 제목 글꼴 | 좁은 글꼴이 없다 | Pretendard SemiBold 64px, 자간 -0.04em, #1A1E22. 라틴·숫자만이면 InterVariable 굵기 800, `font-stretch` 대신 `transform: scaleX(0.88)` | 좁은 글자의 신문 그래픽 느낌 |
