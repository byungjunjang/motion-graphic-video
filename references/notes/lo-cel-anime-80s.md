## 7. 함정

- 화면의 제목, 연도, 간판 글자, 대사, 끝 카드 문구, 카세트 상표 글자는 원작의 것이다. 옮기지 않는다. 역할(빛나는 제목 한 줄, 윗줄, 연도)만 가져온다.
- 특정 시대 작품을 떠올리게 하는 인물·기계 디자인(머리 모양, 무전 장비, 오토바이 형태)은 우리 주제의 인물·물건으로 바꾼다. 프롬프트에 작품·작가 이름을 넣지 않는다.
- 밝게 만들면 장르가 바뀐다. 밤 장면은 40~80%를 #080818 근처로, 채도 높은 밝은 색은 10% 이하로 둔다. 화면 전체를 채도 높은 색으로 덮는 것은 속도선 장(약 44%) 한 번만 쓴다.
- 매 프레임 움직이는 인물은 요즘 애니처럼 보인다. 인물은 `Math.floor(t * 12) / 12`, 입·눈은 `Math.floor(t * 8) / 8` 로 시각을 끊는다. 카메라와 빛만 t 그대로 쓴다.
- 섬광과 충격은 정확히 2프레임(24fps 0.083초, 30fps 면 0.067초)이다. 길면 페이드가 된다. 끝 카드 디졸브는 따라 하지 말고 컷으로 바꾼다.
- 한국어 제목 · 원본은 약 195px 이다. Pretendard SemiBold 136px 에 `transform: skewX(-10deg)` 를 주고 빛 번짐으로 크기를 보탠다. 연도는 InterVariable 굵은 체로 크게 둔다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 손으로 그린 듯한 셀 인물(표정, 머리카락, 옷 주름) | 코드 도형으로는 이 그림 수준이 안 나온다 | AI 일러스트(codex-image)로 자세별 셀 그림을 마젠타 바탕에 만든다. 프롬프트에 평평한 두 톤 칠, 단단한 그림자 모양, 색 외곽선(검정 금지), 글자 없음을 적는다. 작품·작가 이름은 넣지 않는다. 눈 세 장(감음·반·뜸), 입 네 장, 옆 질주 두 장(바퀴 위치만 다름)을 만든 뒤 `scripts/key.py --split` 으로 자른다. seek 에서 장을 초당 12장(입·눈은 8장)으로 고른다 | 장과 장 사이의 미세한 일관성 |
| 에어브러시 밤 도시 바탕(창문, 비친 빛) | 넓은 그림이다 | AI 일러스트로 층 4장(먼 하늘, 먼 건물, 가까운 간판 줄, 앞쪽 기둥)을 가로 3840px 로 만든다. 옆 따라가기에서 층별 속도를 1 : 0.6 : 0.35 : 0.15 로 준다. 창문·간판의 빛은 따로 그린 발광 판(canvas)을 `globalCompositeOperation = 'lighter'` 로 얹는다 | 바탕과 빛의 정확한 맞물림 |
| 뚫고 나오는 빛과 번짐(간판, 제목, 전조등) | 빛 번짐 후처리가 필요하다 | three.js 로 화면을 판 하나에 그리고 `LOOKS.post(gl, { w: 1920, h: 1080, bloom: 0.6, threshold: 0.85, radius: 0.6, vignette: 0.5, grain: 0.04, scan: 0.08, ca: 0.0015 })` 로 마무리한다. 흰 셀이 분홍으로 번지지 않게 발광 판만 밝게 둔다(셀 판은 밝기 0.85 이하) | 손으로 칠한 빛 번짐의 결 |
| 방사형 속도선 | 없다. canvas 로 된다 | 화면 중심(가로 50%, 세로 45%)에서 선 140개. 굵기 2~10px, 길이 화면 대각선의 40~100%, 색 #FFFFFF 와 #F4A0C0 섞기. 시드 고정 난수로 각도를 정하고, 각 선의 시작 반지름을 매 프레임 바꿔 흐르게 한다. 바탕은 방사형 그라데이션 #D84878 → #681848 | 없음 |
| 충격 실루엣 프레임 | 자세 그림이 필요하다 | 공중 자세 그림의 알파를 흰색 단색으로 채운 판을 만든다(canvas `source-in`). 검정 바탕에 빨간 방사선(#D82828, 60개)을 깔고 그 판을 2프레임만 보인다 | 없음 |
| 테이프 화면 효과(모서리 어둡게, 번짐, 찢김) | 브라운관·테이프 재생 질감이다 | 모서리 어둡게는 `LOOKS.post` 의 `vignette` 0.5(모서리 밝기 약 50%). 색 번짐은 `ca` 0.0015. 찢김 잡음은 0.4초 동안 화면을 가로 띠 12개로 나눠 띠마다 ±20~60px 밀고, `grainLayer(parent, seed)` 를 그 동안만 불투명도 0.5 로 올린다 | 실제 테이프의 불규칙한 떨림 |
| 머리카락·목도리 순환 | 순환 장이 필요하다 | `HAND.ribbon(ctx, P, u => 22 * (1 - u), { color: '#5B46C0' })`. P 는 이동하는 사인파(진폭 18px, 파장 220px)를 초당 12장으로 끊은 점 배열 | 그림체와의 질감 차이 |
| 빛나는 제목 글자 | 네온 글꼴이 없다 | Pretendard SemiBold 136px, 글자색 #F8E8F8, `text-shadow: 0 0 6px #FF4FB0, 0 0 18px #D846B2, 0 0 42px #D846B2`. 켜질 때 글자마다 초당 12번 불투명도 0/1 을 0.4초 동안 바꾼다. 빛 막대는 폭 120px 의 흰 그라데이션 div 를 `mix-blend-mode: screen` 으로 0.6초에 가로질러 보낸다 | 굵은 기울임 장식 글꼴의 모양 |
