## 3. 움직임

- 장면 하나는 대개 1.3~2.7초다. 마디(2.67초)마다 큰 교체, 그 사이 반 마디에 작은 교체가 있다.
- 캐릭터는 늘 조금씩 움직인다. 빛살이 출렁이고, 몸이 위아래로 1~3px 튄다. 손그림 선은 매끄럽게 움직인다(그림을 장마다 다시 그리는 떨림은 거의 없다).
- 화면 분할이 핵심 움직임이다. 1칸 → 2칸 → 4칸 → 9칸으로 0.6~0.7초마다 늘어난다. 9칸이 된 뒤 2.7초 동안 칸마다 다른 동작이 동시에 돈다.
- 점선 연결 · 감독에서 각 칸 소품으로 연보라 점선(굵기 3px, 점 길이 약 12px)이 그어진다. 일을 나눠 맡겼다는 표시다.
- 체크 표시 · 일이 끝난 칸에 초록 체크가 0.1초에 커지며 찍히고 짧은 반짝 선 3개가 붙는다.
- 폭발 · 16.03초 한 프레임에 화면 전체가 노랑 별 + 굵은 빛살로 바뀐다. 1.5초 동안 빛살이 바깥으로 밀려나고, 연기 구름이 덮은 뒤 1초에 걷힌다.
- 카메라 · 단말기 장면은 확대한 채 천천히 미끄러진다. 13.3~15.0초는 필름 띠를 따라 흐르다 한 칸 속으로 들어간다. 나머지는 고정 구도다.

## 4. 전환

- 단말기 → 촬영장(5.2초) · 화면 속 작은 아이콘이 선을 뻗고 별 폭발로 화면을 채운다. 크기가 커지는 같은 모양이 두 세계를 잇는다.
- 슬레이트 · 시작(5.5초)과 끝(28.0초)에 같은 슬레이트를 둔다. 끝에서는 번호만 바뀐다. 처음과 끝이 호응한다.
- 화면 분할 · 칸이 늘어나는 것 자체가 전환이다(10.0, 10.6초).
- 필름 칸으로 들어가기(13.3~15.0초) · 편집 화면의 한 칸이 커져 다음 장면이 된다.
- 폭발 → 연기 → 박수 · 연기가 화면을 덮는 동안 장면을 바꾼다.
- 되감기(24.0초) · 컬러 장면이 푸른 밑그림 선으로 바뀌었다가 다시 칠해진다.
- 끝(28.7초) · 단말기 남색으로 돌아가 처음과 이어진다.

- 12초 판 압축 예 · 0~2초 단말기에서 설정을 고르는 장면(확대, 손그림 타원), 2~2.5초 아이콘 폭발, 2.5~3.5초 슬레이트, 3.5~4.5초 감독 외침, 4.5~8초 2칸 → 4칸 → 9칸과 체크, 8~9.5초 촬영장 폭발, 9.5~10.5초 계기 확대(바늘 그대로), 10.5~12초 끝 문구 + 둘째 슬레이트. 필름 편집 장면, 연기, 되감기는 뺀다.
- 기능 이름을 소품(슬레이트, 계기판) 위에 올려 캐릭터 이야기로 바꾸는 방식.
- 같은 크기의 칸이 늘어나며 동시 작업을 보여 주는 화면 분할. 칸마다 체크로 끝을 알린다.
- 말하려는 수치를 계기 하나로 맡기고 장면마다 되풀이하는 방식. 큰 사건 뒤에도 바늘이 그대로라는 대비가 결론이다.
- 큰 사건 직전 0.3초 무음 → 킥과 함께 폭발.
- 처음과 끝의 슬레이트 호응, 번호만 바꾸기.

## 7. 함정

- 별 모양 붉은 캐릭터는 실존 로고를 닮았다. 다른 대상에서는 이 모양을 쓰지 않는다. 대상 자신의 허락받은 상징이 없으면 빛살 수·색·끝 모양을 바꾼 새 캐릭터를 만든다.
- 단말기 화면의 명령어·설정 이름·경고 문장, 슬레이트의 이름, 끝 문구, 셋째 줄의 실존 제품 표기는 옮기지 않는다. 역할(설정 고르기, 기능 이름, 결론 두 줄)만 가져온다.
- 참고 영상의 화풍을 따른 것으로 보인다. 그 원작 화풍을 흉내 내지 않고 구조(분할·점선·체크·계기)만 가져온다.
- 화면 교체가 16번이고 움직임 세기 평균이 14.8 이다. 캐릭터를 정지 그림으로 두면 평균이 반 아래로 떨어진다. 빛살 출렁임과 몸 튐을 모든 캐릭터에 준다.
- 아홉 칸에 캐릭터와 소품이 9벌 필요하다. 그림 수가 가장 많은 구간이다.
- 정사각 화면을 16:9(1920x1080)로 옮기는 구도.
  - 단말기 장면 · 확대 배율을 그대로 두고 가로로 넓힌다. 글자 높이 70px 을 지키면 한 줄에 보이는 글자가 약 1.8배가 된다. 가운데 1080px 폭(가로 22~78%)에 핵심 줄을 둔다.
  - 아홉 칸 · 3x3(칸 340px) 대신 5x3 열다섯 칸(칸 360x330px, 틈 14px, 전체 1856x1018px)이나, 3x3 을 가운데 1000x1000px(가로 24~76%)에 두고 양옆 각 460px 에 왼쪽 기능 이름·오른쪽 계기판을 둔다. 감독은 가운데 칸에 그대로 둔다.
  - 계기판 장면 · 계기판 폭을 화면 높이의 90%(약 970px)로 두고 가운데 정렬한다. 양옆 빈 풀밭에 폭약 상자와 일꾼을 나눠 놓는다.
  - 끝 문구 · 두 줄을 한 줄로 합쳐 세로 25% 에 두고, 캐릭터 무리를 화면 아래 40% 전체 폭(약 10명)으로 늘린다.
- 한국어 끝 문구는 둥근 손글씨 글꼴이 없다. Pretendard SemiBold 로 쓰고 밑줄만 손그림으로 그린다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1080x1080 기준이다(16:9 판은 `## 7` 의 배치를 쓴다). 글꼴은 Pretendard Regular·SemiBold, 숫자·라틴은 InterVariable 만 쓴다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 별 모양 캐릭터 9명 | 손그림 캐릭터와 소품 | canvas 로 그린다. 빛살 9개(로고와 다르게), 길이 70~95px, 폭 26px 둥근 막대, 색 #D2725A, 윤곽 `HAND.ink(ctx, P, { w: 4, color: '#2A1E1E', B })`. 그늘은 `HAND.paint` 의 `tex: [{ k: 'hatch', angle: 0.8, gap: 6, color: '#BA5A4E' }]`. 빛살 끝을 sin(t*6 + i) 로 2px 출렁인다 | 원작 그림의 표정 다양함 |
| 역할 소품(촬영기, 조명, 오토바이 등) | 그릴 것이 많다 | AI 일러스트(codex-image, 글자·로고 없이, 마젠타 바탕)로 소품 8개를 한 장에 그리고 `scripts/key.py --split` 으로 자른다. 캐릭터 손 위치에 DOM 이미지로 붙인다 | 선 굵기가 캐릭터와 조금 다름 |
| 손그림 풀밭과 빛줄기 바탕 | 결이 많다 | 바탕 #F4ECDE 에 `texTile(3, { mc: '150,130,100', mottle: .03, fibers: 120 })`. 대각선 빛줄기는 CSS `repeating-linear-gradient(135deg, transparent 0 60px, rgba(230,200,150,.25) 60px 120px)`. 풀밭은 #AEDE96 면 + `HAND.ink` 짧은 풀잎 40개 | 종이 얼룩의 자연스러움 |
| 화면 분할 2 → 4 → 9칸 | 없다. DOM 으로 된다 | 칸마다 같은 크기 div(340x340px, 테두리 4px #1E1E1E, 틈 14px). 칸 경계를 `clip-path: inset()` 으로 0.25초에 연다. 칸 안 캐릭터는 각자 seek(t - 칸 시작) 으로 움직인다 | 없음 |
| 연보라 점선과 초록 체크 | 없다 | SVG line(굵기 3px, #8A78E0, `stroke-dasharray: 12 9`)을 `stroke-dashoffset` 으로 0.3초에 긋는다. 체크는 SVG path(굵기 10px, #4C8A56)를 0.15초에 크기 0 → 1.15 → 1 로, 반짝 선 3개는 길이 14px | 손으로 그은 떨림 |
| 사용량 계기판 | 없다 | SVG 반원 띠(반지름 300px, 폭 70px)를 초록 #8CCB6E · 노랑 #E8C64A · 빨강 #D8473A 세 호로 나누고 눈금 18개. 바늘은 길이 260px 막대, 각도 -82도 ± sin(t*20)*1.5도 | 없음 |
| 별 폭발과 굵은 빛살 | 손그림 폭발 | SVG 별 다각형(꼭짓점 16개, 바깥 반지름 600px, #F2C14E)을 한 프레임에 띄우고, 둥근 막대 12개(폭 60px, #D8735A, 윤곽 4px)를 0.6초에 중심에서 바깥으로 밀어낸다. 파편은 작은 사각형 20개 | 폭발 그림의 손맛 |
| 연기 구름 | 부풀어 오르는 구름 | 회색 원 18개(지름 150~320px, #CFCFCF, 윤곽 3px #8A8A8A)를 씨앗 난수로 겹치고 0.5초에 크기 0.4 → 1.0, 1초 뒤 투명도 1 → 0 | 구름 결 |
| 단말기 확대 화면 | 없다. DOM 으로 된다 | 바탕 #11202E, 고정폭 대신 InterVariable 400 60px(라틴·숫자) + Pretendard Regular(한글). 커서는 분홍 #E0407A 막대 30x64px, 0.5초 깜박임. 화면 전체 div 에 `transform: scale(2.2)` 를 주고 translate 로 천천히 옮긴다. 손그림 타원은 `HAND.ink(ctx, ellipseP, { w: 4, color: '#9A82F0', frac })` | 실제 단말기의 글꼴 인상 |
| 끝 문구 둥근 글자와 손그림 밑줄 | 둥근 손글씨 글꼴이 없다 | Pretendard SemiBold 70px, #2A1E1E, 가운데 정렬. 밑줄은 `HAND.ribbon(ctx, P, u => 3 + 3 * Math.sin(Math.PI * u), { color: '#D8473A' })`, 길이는 낱말 폭 + 10px | 둥근 글꼴의 친근함 |
