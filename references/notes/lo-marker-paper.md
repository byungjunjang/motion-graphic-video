## 4. 전환

- 원래 글은 전환을 그림 속 모양으로 파고드는 일치 컷과 벗기기 둘로만 정했다. 화면과 맞다.
- 영상에서 확인한 점 · 파고들기는 약 0.6초(11.75~12.35초)에 가속하고, 새 장에서 빠져나오기는 약 0.9초(12.35~13.25초)다. 들어가기 직전 0.9초 무음이 있다.
- 벗기기는 약 0.4초(29.1~29.5초)로 아주 빠르다. 그늘은 벗겨지는 종이에만 생긴다. 직전에 이 영상에서 가장 큰 타격이 있다.

## 5. 타이포

- 모든 글자는 손으로 쓴 기울임체 마커 글씨다. 질문·식·숫자·이름표가 같은 획 굵기다. 화면 안에서 활자처럼 반듯한 글자는 자막 상자뿐이다.
- 식의 색은 뜻을 따른다 · 주어진 양의 문자와 숫자는 파랑, 구할 양과 답은 빨강, 연산 기호·괄호·계수는 검정.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 26.0~29.8초의 "1.62배로 기댄 화면에서 빨간 답(글자 높이 약 108px)을 한 자씩 쓰고, 밑줄 두 줄을 박마다 하나씩, 빨간 타원 동그라미 한 획(가로 27~74%)으로 감싼 뒤 1초 머물고, 오른쪽 아래 귀퉁이가 들려 0.4초에 종이가 벗겨지는" 흐름이다. 흰 종이 #F9F7F4 위 검정·파랑·빨강 세 색만 있고, 빨강이 마지막 획이다. 빨간 답의 동그라미나 벗기기가 빠지면 이 영상이 아니다.

## 7. 함정

- 화면의 질문, 식에 쓰인 값, 자막, 끝 표기는 원작의 것이다. 옮기지 않는다. 역할(질문 한 줄, 주어진 값, 구할 값, 빨간 답, 규칙 한 줄)만 가져온다. 끝 표기에 실존 서비스·모델 이름이 있다. 쓰지 않는다. 우리 영상의 숫자는 `FACTS.md` 에 근거를 적은 것만 쓴다.
- 한 장에 빨강이 두 군데 크게 있으면 뜻이 무너진다. 빨간 동그라미는 한 장에 하나만 둔다.
- 기대거나 파고들 때 그림을 비트맵으로 키우면 흐려진다. 획을 카메라 배율로 다시 그린다. 원본은 7배에서도 선 굵기가 화면에서 같다.
- 글자를 매 프레임 새로 흔들면 깜빡인다. 글자는 떨림 판을 쓰지 않는다.
- 종이에 그늘·비네트·얼룩을 넣으면 지저분해 보인다. 그늘은 벗기기에만 둔다.
- 기댈 때 질문 글자가 화면 가장자리에 반쯤 잘리면 안 된다. 원래 글의 규칙대로 전부 안에 두거나 전부 밖으로 민다.
- 한국어 질문을 손글씨 대신 반듯한 활자로 가운데 정렬하면 손으로 쓴 느낌이 사라지고 발표 화면처럼 보인다. 왼쪽 위에 왼쪽 정렬, 한 자씩 나타나게 한다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080, 24fps 기준이다. 그림 선은 canvas + `vendor/handdrawn/hand.js` 로 된다. 어려운 것은 손글씨다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 굵은 마커 획과 그려지는 등장 | 없다. 코드로 된다 | `HAND.ink(ctx, P, { frac, w: 12, color: '#242024', key, B, amt: 0.8 })`. 파랑 #3864D0, 빨강 #DC4C40. 긴 호 하나 0.4~0.6초, 화살표는 몸통 → 머리 두 획. 떨림 칸 B 는 t 에 12 를 곱해 내린 정수를 3 으로 나눈 나머지로 정한다(24fps 에서 둘씩 돈다) | 없음 |
| 겹친 곳만 진해지는 잉크 | 같은 획 안에서는 진해지면 안 된다 | 획마다 오프스크린 canvas 에 불투명으로 그린 뒤 본 화면에 canvas 곱하기 합성(multiply), 불투명도 0.88 로 얹는다. 획끼리 겹친 곳만 진해진다 | 마커가 처음 닿는 점의 진한 점 |
| 해칭 잔 선 | 없다 | 땅 호 아래에 길이 25px, 굵기 6px 의 짧은 획 60여 개를 호의 법선 방향으로 0.01초 간격으로 그린다(`HAND.ink`, 획마다 다른 key). `HAND.hatch` 는 면 채우기라 쓰지 않는다 | 없음 |
| 손글씨 숫자·식 | 손글씨 글꼴이 없다 | 숫자 0~9 와 기호(더하기, 같음, 근사, 제곱근, 괄호, 곱하기, 소수점, 위첨자 2)와 문자 몇 개의 한 획 경로를 점 배열로 직접 정의한다(글자 높이 기준 0~1 좌표, 기울기 12°). 글자마다 `HAND.ink` 의 frac 을 0.1초에 0 → 1 로 올려 왼쪽에서 오른쪽으로 쓴다. 획 굵기 12px, 글자 높이 약 70px(전체 장면) | 사람 손글씨의 들쭉날쭉함 |
| 한국어 질문·짧은 말 | 손글씨 한글 글꼴이 없다 | DOM 층에 Pretendard SemiBold 52px, #242024, 왼쪽 정렬. 글자마다 `clip-path: inset(0 100% 0 0)` → `inset(0 0 0 0)` 를 0.07초에 열어 쓰는 순서를 흉내 낸다. 밑줄은 `HAND.ink` 한 획(굵기 8px, 길이 문장 폭 + 20px)으로 손맛을 낸다 | 글씨가 손으로 쓰인다는 느낌 |
| 직각 표시로 파고들기 | 카메라 배율 7배에서 선이 흐려지면 안 된다 | canvas 변환 배율을 1 → 7 로 0.6초(지수 가속)에 올리되 `HAND.ink` 의 w 를 12 / 배율로 넣어 화면 굵기를 유지한다. 12.35초 자리에서 새 장 그림으로 바꾸고 7 → 1 로 0.9초에 물러난다 | 없음 |
| 벗기기 | 종이가 접히는 3D | canvas 에서 접힘 선(오른쪽 아래 → 왼쪽 위, 0.4초)으로 장을 둘로 나눈다. 선 앞쪽은 그대로, 선 뒤쪽은 접힘 선에 대해 대칭으로 뒤집은 뒷면(#FFFFFF, 접힘 선 쪽 40px 에 #000000 불투명도 0 → 0.12 그라데이션)을 그리고, 그 아래 새 장에 접힘 선을 따라 폭 30px 의 그늘(불투명도 0.1)을 둔다 | 종이 휨의 곡면 |
| 종이 | 없다. 단색이면 된다 | 바탕 #F9F7F4 단색. 결을 넣는다면 `texTile(seed, { mc: '120,110,100', mottle: .015, dark: .01, light: .02, fibers: 30, specks: 0 })` 정도로 거의 안 보이게 둔다 | 없음 |
| 자막 상자 | 없다 | DOM · 폭 화면의 28%, 아래 세로 88~97%, 바탕 #F8F8F4, 테두리 1px #E2DFDA. 한국어 Pretendard Regular 34px, 번역 줄은 넣지 않거나 Pretendard Regular 22px | 없음 |
