# 회로 기판 · 구리선 위를 달리는 빛 — 분석 노트

> 주제 전체를 위에서 내려다본 인쇄 회로 기판으로 그린 60초 영상. 녹색 보호막 아래 구리가 길이 되고, 금색 패드가 장소가 되고, 흰 인쇄 글자가 이름표가 된다. 흐르는 것(전기, 물, 신호, 물건)은 구리선 위를 달리는 빛으로 보인다. 카메라는 빛의 머리를 타고 가다가 위로 올라 지도 크기까지 물러나고, 부품 하나 크기까지 단숨에 파고든다. 에너지, 공급망, 기기 속 원리, 한 물건이 거치는 경로를 설명하는 영상에 맞는다.

출처 · lo:circuit-board. 원래 글은 긴 스타일 명세다. 무엇을 그리고 빛을 어떻게 움직이는지는 자세하다. 그러나 기판의 실제 색, 빛나는 선의 굵기와 화면 속 자리, 카메라가 빛을 탈 때 머리의 화면 위치, 실제로 멈춰 있는 시간이 없다. 숏 표에 실존 지명과 시설 이름이 많아 그대로 쓸 수 없다. 그래서 영상 프레임을 보고 이 노트를 썼다.

## 3. 움직임

- 원래 글의 흐름별 빛 움직임은 화면과 맞다.
- 영상에서 확인한 점 · 교류 토막은 길이 약 40~60px, 간격 약 30px 다. 흔들림 주기는 재지 않았다(원래 글은 약 0.55Hz).
- 빛을 탈 때 머리는 오른쪽 1/3 선(가로 68~70%, 세로 50%)에 1초 넘게 붙어 있고 카메라는 계속 물러난다. 오르기가 끝나면(21.0초) 카메라는 거의 멈추고 머리만 움직인다(0.3~1.5). 꽂히기는 0.3초 안팎이고 곧바로 멈춘다.
- 판정 화면(43~52초)은 9초 가까이 세기 1 미만이다.

## 4. 전환

- 원래 글의 전환 규칙(움직임에서 움직임으로, 맞춘 컷, 페이드 없음)은 화면과 맞다. 하드 컷은 10.1초, 맞춘 컷 넷, 34.63초뿐이다.
- 맞춘 컷 · 변압 기호가 같은 자리·같은 크기로 남고 둘레만 0.7초마다 바뀐다. 선은 약 30, 20, 12, 6px 로 가늘어진다.
- 구멍 · 0.5초 붙잡은 뒤 뛰어들고, 다른 구멍(금색 고리, 화면의 약 80%)에서 반대로 나온다. 구멍 속은 약 0.13초다.

- 이름표는 가는 고른 굵기의 흰 선 글씨이고, 아래에 작은 영어 보조 줄이 붙는다. 늘 주인공 근처, 화면 위·아래 15% 밖에 둔다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 18.75~23.5초의 "부품에서 빛줄이 나가는 순간 빠른 이동 → 빛의 머리를 화면 오른쪽 1/3 선(가로 약 70%, 세로 50%)에 붙잡고 타고 가며 물러나기 → 출발과 끝이 모두 보이는 지도 크기에서 1초 멈춤 → 끝점으로 0.3초 꽂히기 → 패드 번쩍임"이다. 빛줄은 12~15px, 45° 꺾임만 쓰고, 둘레에 빛나지 않는 길이 10여 개 있다. 카메라가 빛을 타지 않거나 지도 크기로 오르지 않으면 이 영상이 아니다.
- 12초 판에서 버리기 쉬운 밀도 높은 장면 · 같은 원리 판정 화면(45.0초)이다. 요소 약 12개(마름모 부품 둘, 원형 확대 창, 빛줄 두 개, 이름표 두 쌍, 작은 부품 6개). 왼쪽 마름모는 가로 22~47%, 세로 15~63%. 원형 확대 창은 가로 57~87%, 세로 9~61%(지름 약 575px). 두 부품을 잇는 빛줄은 세로 22%, 53% 두 줄이고, 흰 속 굵기는 약 33px(화면 높이의 3%)다. 속 #FDFEFF, 가장자리 #4E6C30 · #595F39. 9초 가까이 멈춰 있어 12초 판에서는 넣을 자리가 없다. 넣는다면 1.0초만 둔다.
- 12초 판 압축 예 · 0.0~1.5초 패드 근접 번쩍임 → 10배 물러나기, 1.5~3.0초 교류 토막이 흔들리는 근접, 3.0~4.3초 바꾸는 부품이 빛나며 빛줄 두 개가 나간다, 4.3~7.5초 대표 장면 3.2초(빠른 이동 0.3 + 타고 가기 1.2 + 지도 멈춤 1.0 + 꽂히기 0.3 + 번쩍임 0.4), 7.5~8.5초 시간 표기 붙잡기, 8.5~9.9초 맞춘 컷 두 번(0.7초씩), 9.9~10.6초 구멍 붙잡기와 뛰어들기, 10.6~12.0초 한 번에 물러나 책상 위 기판 전체. 손실 장, 충전기 장, 같은 원리 판정 장은 뺀다.
- 지도와 부품을 같은 재료로 그려 카메라가 매체를 바꾸지 않고 오간다.

## 7. 함정

- 화면의 이름표(지역 이름, 시설 이름, 제목, 거리·시간·배율 숫자), 대사 자막, 끝 카드의 제작 표기는 원작의 것이다. 옮기지 않는다. 역할(출발지, 도착지, 거리 표기, 시간 표기)만 가져온다.
- 지도 크기 장면의 길 모양과 끝 장면 기판의 외곽선은 실존 지역의 경계를 따른다. 옮기지 않는다. 우리 주제의 실제 경로·지역은 고객 자료에서 받아 그린다.
- 빈 녹색 판이 되면 슬라이드처럼 보인다. 지도 크기에서도 비아 점(지름 6~10px, 간격 40~80px), 빛나지 않는 실제 길, 보호막 얼룩을 깐다. 꾸밈 길은 그리지 않는다.
- 빛을 세게 하면 흰 막대가 된다. 빛줄 속은 10px 이하, 번짐 반지름은 30px 이하로 묶고 호박빛 몸(#D6C272)을 남긴다.
- 꽂히기 때 기판 가장자리 밖의 책상이 비친다(23.1~23.25초). 따라 하지 말고 기판을 넉넉히 크게 만든다. 구멍은 0.5초 붙잡은 뒤 뛰어든다.
- 한국어 이름표 · 원본은 약 50~55px 다. Pretendard Regular 48~60px, #E8EEE8, 자간 0.02em 으로 두고 숫자 단위는 InterVariable 18px 로 붙인다. 낱자를 구리선으로 배선할 때는 획을 손으로 그리고 크게 확인한다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 큰 기판 그림(보호막, 깎인 빈틈, 패드, 비아) | 없다. canvas 로 된다. 다만 양이 많다 | 기판을 화면의 4배 x 4배(7680 x 4320 단위) 좌표로 정하고, 로드 때 오프스크린 canvas 여러 장(크기별 2~3 단계)에 굽는다. 구리선은 0/45/90° 꺾은선만, 모서리는 45° 로 깎는다. 빈틈은 선보다 6px 넓게 #0E2719 로 먼저 긋고 그 위에 선을 긋는다. 비아는 지름 8px 금색 고리(#DDBF6F, 가운데 #0E2719 구멍) | 없음 |
| 보호막 얼룩 | 실제 기판의 결이다 | 바탕 #1F5A3E 위에 `texTile(seed, { mc: '20,60,40', mottle: .06, dark: .05, light: .05, fibers: 0, specks: 20 })` 를 곱하기로 깐다. `grainLayer(parent, seed)` 를 불투명도 0.05 로 얹는다 | 실제 보호막의 광택 차이 |
| 달리는 빛(머리, 잔광, 교류 토막) | 없다. canvas 로 된다 | 경로 길이 s 위에서 머리 위치를 seek(t) 로 정한다. 직류는 머리 뒤 구간을 `HAND.subPath(P, frac)` 로 잘라 세 번 긋는다(몸 #D6C272 14px 불투명도 0.9, 속 #F4F8EE 6px, 번짐은 같은 경로를 `globalCompositeOperation = 'lighter'` 로 30px 불투명도 0.15). 잔광은 머리에서 멀수록 불투명도를 1 → 0.35 로 2초에 걸쳐 낮춘다. 교류 토막은 `setLineDash([50, 30])` 와 `lineDashOffset = 80 * Math.sin(2 * Math.PI * 0.55 * t)` | 없음 |
| 빛 번짐과 화면 마무리 | canvas 만으로는 번짐이 거칠다 | 기판 canvas 를 three.js 평면 텍스처로 올리고 `LOOKS.post(gl, { w: 1920, h: 1080, bloom: 0.5, threshold: 0.9, radius: 0.4, vignette: 0.35, grain: 0.03 })` 로 마무리한다. 번짐이 흰 막대가 되면 `threshold` 를 1.0 으로 올린다 | 없음 |
| 카메라의 타고 가기·오르기·꽂히기 | 큰 배율 변화에서 좌표가 무너진다 | 크기 단계마다 기판을 따로 두고(지도 판, 부품 판), 카메라 배율이 단계 경계를 넘을 때 판을 바꾼다. 타고 가기는 카메라 중심 = 머리 위치 - (화면 가로 20%, 0), 배율은 1.0 → 0.25 로 1.5초에 지수 곡선. 꽂히기는 0.3초에 배율 0.25 → 2.5, 그 동안 이동량에 비례한 방향성 흐림(이전 3프레임 위치를 불투명도 0.3 씩 겹쳐 그림) | 원본의 측정 기반 움직임 흐림의 매끄러움 |
| 구멍으로 뛰어들기 | 원근감 있는 깊이가 필요하다 | 2D 로 한다. 구멍 원(지름 화면 높이의 8%)을 0.5초 붙잡은 뒤 0.4초에 배율 1 → 14 로 키워 화면을 검게 덮는다. 다음 판에서 금색 고리를 배율 14 → 1 로 0.4초에 줄이며 빠져나온다 | 구멍 벽의 깊이감 |
| 책상 위 기판과 창빛 | 실제 공간과 빛이다 | 책상 #0C0C0C 위에 기판 canvas 를 `rotate(2deg)` 로 놓고, 흰 띠 3개(폭 120~240px, 불투명도 0.06~0.1, 45°)를 `mix-blend-mode: screen` 으로 얹는다 | 실제 빛의 부드러운 번짐 |
| 흰 인쇄 글자가 그려지며 나타나기 | 한국어 선 글씨 글꼴이 없다 | 이름표는 Pretendard Regular 로 DOM 에 두고 `clip-path: inset(0 100% 0 0)` → `inset(0 0 0 0)` 로 0.4초에 왼쪽부터 드러낸다. 상자는 SVG `stroke-dasharray` 로 0.5초에 그린다 | 획마다 그어지는 선 글씨의 느낌 |
