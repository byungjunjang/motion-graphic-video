> 글쓰기 도구(문서 기호로 쓰는 편집기) 하나를 30초에 소개하는 제품 영상. 크림색 바탕에서 고정폭 글자로 타이핑한 단어가 큰 세리프 제목으로 바뀌고, 문서 기호(샵·별표·대괄호)가 흩어졌다 모여 로고가 되고, 편집기 화면에서 왼쪽 원문과 오른쪽 미리보기가 함께 채워지고, 기능 카드 다섯 장이 마디마다 바뀐다. 끝 가까이에서 화면이 어두운 색으로 뒤집히고 아이콘 격자 위에 한 낱말이 박자마다 바뀐 뒤 로고 끝 카드로 돌아온다. 글쓰기·문서·개발 도구, 밝은 편집 화면을 가진 서비스의 소개에 맞는다. 에디토리얼 세리프 · 크림 종이 · 기능 카드 반복 · 마디 단위 편집.

## 3. 움직임

- 글자가 먼저 고정폭으로 타이핑되고, 그다음 큰 세리프로 바뀐다. "원문 → 결과"를 글자 하나로 보여 주는 움직임이 처음 7초의 전부다. 바뀌는 0.3초 동안 글자가 뒤틀리고 옆으로 늘어난다.
- 문서 기호 조각(샵·별표·대괄호·숫자 목록 표시)이 입자 역할을 한다. 7.6~8.5초 로고 조립과 26.3~27.5초 끝 카드에서 같은 조각을 쓴다. 조각 수는 한 화면에 40~60개, 크기 20~40px(눈대중)다.
- 꼬리표·카드는 떠오를 때 조금 기울어 있다가 0으로 풀린다. 떨림이 작게 한두 번 있다.
- 기능 카드 다섯 장은 같은 틀이다. 왼쪽 40% 에 번호 꼬리표 + 두 줄 제목 + 설명 한 줄, 오른쪽 50% 에 그 기능을 보여 주는 그림 하나. 그림 안에서 작은 사건 하나(타이핑, 연결이 끊김, 경고 켜짐, 색 바뀜, 메뉴 열림)가 일어난다.
- 번호 꼬리표와 제목은 글자 섞임(무작위 기호가 돌다가 제 글자로 서는 것)으로 나타난다. 섞임 시간은 약 0.3초다.
- 7.54초 이후 장면 길이는 대부분 1.875초(한 마디)다. 편집기 장면만 약 4.8초(두 마디 반)다.
- 24.4~26.0초 낱말 연타는 0.25초 간격이다. 128 BPM 의 한 박(0.469초)의 반쯤이다.
- 끝 2.4초는 캐럿 깜박임 말고는 움직임이 없다(27.5초 이후 세기 0.4~1.1).

## 4. 전환

- 글자 → 글자 · 같은 낱말이 고정폭에서 세리프로 바뀐다. 장면을 바꾸지 않고 서체만 바꾼다.
- 소용돌이 → 방사선 → 조립 · 6.2~7.6초. 제목이 가운데 한 점으로 빨려 들고, 그 점에서 선이 터지고, 터진 뒤 기호 조각이 모여 로고가 된다. 이 영상에서 가장 큰 사건이고 본 음악 시작과 맞는다.
- 로고 → 편집기 · 로고가 사라지고 빈 편집기 판이 흐림 속에서 떠오른다(9.8~10.25초).
- 편집기 → 카드 1 · 화면 전체 흐림(15.0초). 영상에서 가장 평범한 전환이다.
- 카드 → 카드 · 마디 첫 박에 화면 전체가 옆으로 빠르게 미끄러지며 가로 흐림(움직임 번짐)이 생긴다(18.75초 프레임에서 글자가 가로로 길게 번져 있다). 새 카드의 왼쪽 글자는 섞임으로 선다.
- 밝은 → 어두운 · 카드 4 의 버튼에서 원형 닦기가 퍼진다. 카드 4 가 "밝은·어두운 테마" 기능이라서 전환 자체가 기능 시연이다.
- 어두운 격자 → 밝은 끝 카드 · 아이콘이 점으로 줄어들고, 회색 번쩍임 한 프레임 묶음 뒤 점에서 원이 퍼지며 끝 카드가 선다.

## 5. 타이포

- 큰 제목 세리프 · 획 대비가 큰 굵은 세리프, 짙은 갈색. 도입 첫 줄 낱말은 높이 157~160px(화면 높이의 15%). 기능 카드 첫 줄은 내림 획 포함 108px(대문자 높이 약 80px, 7.4%, 눈대중), 왼쪽 여백 160px(8%).
- 둘째 줄 이탤릭 · 같은 크기의 이탤릭, 벽돌 주황, 끝에 마침표. 글자 아래에 옅은 살구색 밑띠가 깔리는 장면이 있다(16.5초, 18.5초).
- 번호 꼬리표 · 고정폭 대문자, 주황, 높이 16px, 자간이 넓다. 번호 두 자리 + 줄표 + 기능 이름.
- 설명 한 줄 · 작은 산세리프, 회갈색, 높이 약 22px(대문자 기준). 한 줄 또는 두 줄.
- 낱말 연타 · 높이 190px(18%), 크림색 바른 세리프와 살구색 이탤릭이 번갈아. 형용사 한 낱말 + 마침표.
- 워드마크 · 굵은 세리프 소문자, 높이 150~156px(14%). 마침표 하나만 주황이다. 설명 줄은 산세리프 높이 34px(3%).
- 화면에 동시에 보이는 글자 덩어리는 1~3개다(제목 2줄 + 설명 1줄).

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 3.5~5.5초. 크림 바탕 가운데 두 줄 제목(첫 줄 바른 세리프 568x160px, 둘째 줄 이탤릭 주황 1041x161px, 화면 폭의 54%)이 고정폭 타이핑에서 세리프로 바뀌어 서고, 네 모서리에 흰 꼬리표 4개가 하나씩 떠오른다. 요소 6개(제목 2줄 + 꼬리표 4). 고정폭 → 세리프 서체 바뀜이 빠지면 이 영상이 아니다. 둘째로 17.5~18.5초 기능 카드(왼쪽 제목 + 오른쪽 선화와 주황 자물쇠 타일 150px)의 틀을 남긴다.
- 12초 판 압축 예 · 0~2.8초 타이핑 → 세리프 제목 두 줄과 꼬리표(꼬리표는 2개로), 2.8~3.6초 소용돌이 → 방사선, 3.6~4.6초 기호 조각이 모여 로고, 4.6~8.4초 기능 카드 2장(각 1.9초 · 마디 하나씩), 8.4~10.0초 낱말 연타 6개(각 0.25초), 10.0~12.0초 끝 카드와 정지. 편집기 화면 장면과 어두운 원형 닦기는 뺀다. 남기려면 기능 카드 1장을 편집기 판으로 바꾼다.
- 원문과 결과를 같은 글자로 잇는 시작. 대상이 "무엇을 넣으면 무엇이 나오는" 도구라면 입력 모양(고정폭)에서 결과 모양(세리프)으로 바뀌는 첫 3초를 그대로 쓴다.
- 기능 카드 틀. 왼쪽 번호 꼬리표 + 두 줄 제목(바른·이탤릭) + 설명 한 줄, 오른쪽 그림 하나와 그 안의 사건 하나. 마디마다 바꾼다.
- 기능 자체로 전환하기. 테마 기능 카드의 버튼이 원형 닦기가 되어 화면 전체를 어둡게 바꾼다.
- 끝 직전의 낱말 연타(0.25초 x 6) 뒤 점으로 줄었다가 로고로 퍼지는 마무리.

## 7. 함정

- 화면의 워드마크, 아이콘, 편집기 안의 글, 제목·설명 문구, 낱말 6개, 꼬리표 낱말은 실존 도구와 원작의 것이다. 옮기지 않는다. 실존 로고는 쓰지 않는다. 역할(제품 동사 + 대상 낱말, 기능 제목, 형용사 연타)만 가져온다.
- 한국어에는 이탤릭이 없다. 이 영상의 강조는 "바른 → 이탤릭 + 주황"의 두 겹이다. 한국어로는 둘째 줄을 SemiBold → Regular 로 바꾸지 않고, 색(주황)과 옅은 밑띠 두 겹으로 나눈다. 기울임 변환(`skewX`)으로 가짜 이탤릭을 만들지 않는다.
- 고정폭 → 세리프 바뀜은 라틴 글자의 모양 차이에 기대고 있다. 한국어는 고정폭과 Pretendard 의 차이가 작다. 입력 모양은 문서 기호(샵·별표)와 캐럿, 회색 고정폭 숫자로 만들고, 결과 모양은 크기(70px → 150px)와 굵기 차이로 보여 준다.
- 30초에 장면이 10개다. 12초로 줄이면 기능 카드를 2장 넘게 넣지 않는다. 카드 한 장이 한 마디(1.9초)보다 짧으면 제목을 읽을 수 없다.
- 낱말 연타(0.25초)는 한국어 두 글자 낱말까지만 읽힌다. 세 글자 이상이면 0.4초로 늘린다.
- 소용돌이(6.5초)와 격자 무너짐(26.0초)은 움직임 세기 90 이상으로 화면 전체가 흐려진다. 이 두 순간 말고는 화면이 조용하다(평균 8.5). 큰 움직임을 두 번 넘게 넣으면 이 영상의 "조용한 종이" 인상이 사라진다.
- 회색 번쩍임(26.25초)은 화면 전체 밝기가 한 번에 바뀐다. 따라 할 때는 0.1초 이하로 두거나 뺀다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 글꼴은 Pretendard Regular·SemiBold(한국어), 숫자·라틴 기호는 InterVariable 이다. 세리프와 고정폭 글꼴은 없다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 큰 세리프 제목 | 세리프 글꼴이 없다 | Pretendard SemiBold 140px(화면 높이의 13%), 자간 -0.03em, #302820. 둘째 줄은 Pretendard SemiBold 140px #B05838 + 글자 뒤 높이 40px 의 살구색 띠(#F2D3C2, 세로 위치는 글자 아래 1/3) | 획 대비가 큰 글자의 고급스러운 인상 |
| 고정폭 → 세리프 바뀜 | 두 서체 사이의 중간 모양이 없다 | 입력 상태는 InterVariable 70px 회색(#8A8078) + 앞에 주황 샵 기호, `font-variant-numeric: tabular-nums` 와 글자 사이 0.08em. 0.3초 동안 입력 글자를 `filter: blur(0 → 6px)`, 투명도 1 → 0, 같은 자리에서 결과 글자를 `blur(6px → 0)`, `scale(0.6 → 1)` 로 겹친다 | 글자가 뒤틀리며 바뀌는 재미 |
| 크림 종이 바탕 | 없다 | `radial-gradient(ellipse at 50% 45%, #FAF6EE 0%, #F3ECE3 55%, #D6CFC6 100%)` 위에 `texTile(5, { mc: '200,150,120', mottle: .03, dark: .02, light: .04, fibers: 60, specks: 8 })` 를 투명도 .5 로 깐다. 아래쪽에 지름 1400px 의 살구색(#F0D8C6) 번짐 원 하나 | 없음 |
| 문서 기호 조각이 모여 로고가 되기 | 조각 수십 개의 경로 | canvas 에 기호 50개(샵·별표·대괄호·숫자)를 InterVariable 24~40px 로 그린다. 조각마다 시작 위치(화면 밖 반지름 1100px 원 위)와 도착 위치(로고 둘레 반지름 0~300px)를 씨앗 난수로 정하고 0.9초 동안 `1-(1-k)^3` 로 옮긴다. 도착하면 투명도 0 으로 끈다 | 조각이 정확히 글자 획 자리에 박히는 느낌 |
| 방사선 폭발 | 없다. SVG 로 된다 | SVG line 42개, 길이 0 → 260~420px, 굵기 1.5px, 6개 중 1개는 주황(#B05838), 나머지는 #B8AEA4. 가운데 지름 30px 주황 점. 0.25초에 뻗고 0.25초에 바깥 끝부터 줄어든다 | 없음 |
| 글자 섞임 | 없다 | 제목 글자 수만큼 무작위 기호(샵·별표·대괄호·숫자)를 0.04초마다 바꾸고, 왼쪽부터 0.3초 안에 차례로 제 글자로 고정한다. 한국어는 섞는 동안 기호만 쓰고 고정할 때 한글로 바꾼다 | 없음 |
| 노트북 선화와 끊기는 연결 | 없다. SVG 로 된다 | SVG 선 굵기 4px #302820 의 노트북(폭 360px), 둘레 원 3겹(반지름 160·220·280px, 굵기 1.5px, #E9C9B8). 구름·서버 아이콘 4개를 점선(`stroke-dasharray: 4 8`)으로 잇고, 0.3초에 주황 빗금(굵기 4px)을 그어 끊는다 | 없음 |
| 원형 닦기로 어두운 화면 | 없다 | 어두운 장면 전체를 위에 두고 `clip-path: circle(r at 1640px 260px)`, r 을 0 → 2300px 로 0.8초, `1-(1-k)^4`. 경계에 굵기 2px 의 #D88860 원을 함께 키운다 | 없음 |
| 아이콘 격자 90개 | 아이콘 그림 | SVG 선 아이콘 15종을 직접 그려(굵기 2px, 40px 칸) 15x6 칸에 돌려 놓는다. 칸 간격 168px, 색 #5A4E44. 9칸은 살구색 둥근 타일(80x80px, 반지름 18px, #B47452 투명도 .8). 무너질 때는 칸마다 가운데로 0.25초, 회전 ±40도 | 아이콘 종류의 풍부함 |
| 화면 전체 흐림 전환 | 없다 | 장면 층에 `filter: blur(0 → 40px)` 0.3초, 다음 장면은 `blur(40px → 0)` 0.3초. 겹치는 0.1초에 두 층 모두 투명도 .5 | 없음 |
| 그레인 | 없다 | `grainLayer(stage, 11)` 기본값 그대로(밝은 바탕에서는 .34 가 맞다). 어두운 장면에서는 투명도를 .2 로 낮춘다 | 없음 |
