## 3. 움직임

- 글자가 먼저 고정폭으로 타이핑되고, 그다음 큰 세리프로 바뀐다. "원문 → 결과"를 글자 하나로 보여 주는 움직임이 처음 23% 의 전부다. 바뀌는 0.3초 동안 글자가 뒤틀리고 옆으로 늘어난다. 앞에 붙은 기호는 작은 조각으로 부서져 아래로 흩어진다.
- 첫 화면은 주황 캐럿 하나(높이 120px, 가로 39%, 세로 50%)다. 고정폭 글자 높이는 약 70px(눈대중)이고 0.5초에 3글자를 친다. 세리프로 바뀐 낱말은 588x157px(화면 높이의 15%, 가로 35~66%, 세로 43~57%)다. 둘째 낱말이 오면 첫 낱말은 세로 33~48% 로 오른다.
- 완성된 두 줄 제목 · 첫 줄 568x160px(15%), 둘째 줄 1041x161px(화면 폭의 54%, 세로 53~68%). 둘째 줄은 이탤릭으로 바뀌며 옆으로 커지고, 끝에 마침표와 캐럿이 붙는다.
- 꼬리표 4개는 네 모서리 쪽(가로 12~27%·76~88%, 세로 10~22%·74~87%)에 하나씩 떠오른다. 흰 알약, 약 280x120px(눈대중), 약 0.23초 간격 타격과 맞물린다. 꼬리표·카드는 떠오를 때 조금 기울어 있다가 0으로 풀린다. 떨림이 작게 한두 번 있다.
- 기호 조각(문장 부호·괄호·숫자 같은 글리프)이 입자 역할을 한다. 조각이 모이는 장면과 끝 카드가 서는 장면에서 같은 조각을 쓴다. 조각 수는 한 화면에 40~60개, 크기 20~40px(눈대중)다. 조각이 모일 때 옅은 원 두 겹이 둘레에 퍼진다.

- 격자가 무너질 때 아이콘이 흔들리며 가운데로 빨려 들고, 0.15초 뒤 어두운 바탕 가운데 주황 점 하나만 남는다. 0.1초 뒤 화면이 회색(#8C8780 근처)으로 번쩍인다.
- 끝 카드 · 아이콘(152x186px, 가로 19~27%) + 워드마크(978x156px, 가로 32~83%, 세로 31~46%) + 설명 한 줄(높이 34px) + 주황 밑줄. 아래쪽(세로 92%)에 흰 알약 꼬리표 3개가 0.5초 안에 차례로 뜬다. 설명 줄은 물결처럼 내려앉는다. 워드마크 끝에 주황 캐럿이 깜박인다.
- 끝 2.4초는 캐럿 깜박임 말고는 움직임이 없다(세기 0.4~1.1).

## 4. 전환

- 글자 → 글자 · 같은 낱말이 고정폭에서 세리프로 바뀐다. 장면을 바꾸지 않고 서체만 바꾼다.
- 소용돌이 → 방사선 → 조립 · 약 1.4초. 화면의 글자와 꼬리표가 낱자로 흩어져 돌며 가운데 한 점으로 빨려 들고(흐림이 강하다), 그 점에서 선이 터지고, 터진 뒤 기호 조각이 모여 다음 주인공이 된다. 이 영상에서 가장 큰 사건이고 본 음악 시작과 맞는다.
- 흐림 속에서 떠오르기 · 앞 주인공이 사라지고 빈 판이 흐림 속에서 0.45초에 떠오른다.
- 화면 전체 흐림 · 판이 흐림 속으로 사라진다. 영상에서 가장 평범한 전환이다.
- 카드 → 카드 · 마디 첫 박에 화면 전체가 옆으로 빠르게 미끄러지며 가로 흐림(움직임 번짐)이 생긴다(글자가 가로로 길게 번진다). 새 카드의 왼쪽 글자는 섞임으로 선다. 앞 카드가 옆으로 밀려 나갈 때 움직임 세기가 51~53 이다.
- 밝은 → 어두운 · 카드 안 버튼 자리에서 원형 닦기가 시작돼 약 0.9초에 바깥으로 퍼진다. 원 안쪽은 #1E1916 근처 짙은 갈색, 제목 둘째 줄은 #D88860 살구 주황으로 바뀐다. 카드 안 아이콘도 어두운 판으로 바뀐다. 전환 자체가 주인공 요소의 기능 시연이 된다.
- 어두운 → 밝은 끝 카드 · 아이콘이 점으로 줄어들고, 회색 번쩍임 한 프레임 묶음 뒤 점에서 원 두 겹이 퍼지고 기호 조각이 소용돌이치며 끝 카드가 선다.

- 화면에 동시에 보이는 글자 덩어리는 1~3개다(제목 2줄 + 설명 1줄).

## 6. 가져올 것

- 핵심 장치 · 입력 모양(고정폭 글자 약 70px + 앞 기호 + 캐럿)으로 타이핑한 낱말이 0.3초 동안 뒤틀리며 결과 모양(큰 세리프, 화면 높이의 15%)으로 바뀐다. 장면은 그대로 두고 서체만 바꾼다.
- 핵심 장치 · 한 마디(1.875초)마다 같은 틀의 카드(왼쪽 40% 번호 꼬리표 + 두 줄 제목 + 설명 한 줄, 오른쪽 50% 그림 하나와 그 안의 작은 사건 하나)를 마디 첫 박의 가로 움직임 번짐 미끄러짐으로 갈아 끼운다.
- 핵심 장치 · 화면 전체를 한 점으로 빨아들인 뒤 그 점에서 방사선 40여 개가 터지고 조각 40~60개가 모여 다음 주인공이 선다. 이 큰 움직임(세기 90 안팎)은 영상 전체에 두 번만 두고 나머지는 조용하게(평균 8.5) 둔다.
- 핵심 장치 · 주인공 요소의 버튼 자리에서 시작한 원형 닦기가 약 0.8초에 화면을 밝은 팔레트에서 어두운 팔레트로 뒤집고, 포인트 색도 #B05838 → #D88860 으로 같이 바꾼다.
- 두 줄 제목 짝(바른 세리프 짙은 갈색 + 이탤릭 주황 + 마침표)을 영상 내내 되풀이한다.
- 끝 직전의 낱말 연타(0.25초 x 6) 뒤 점으로 줄었다가 원 두 겹으로 퍼지며 끝 카드가 서는 마무리.

## 7. 함정

- 원본 화면의 실존 로고·이름은 쓰지 않는다.
- 한국어에는 이탤릭이 없다. 이 영상의 강조는 "바른 → 이탤릭 + 주황"의 두 겹이다. 한국어로는 둘째 줄을 SemiBold → Regular 로 바꾸지 않고, 색(주황)과 옅은 밑띠 두 겹으로 나눈다. 기울임 변환(`skewX`)으로 가짜 이탤릭을 만들지 않는다.
- 고정폭 → 세리프 바뀜은 라틴 글자의 모양 차이에 기대고 있다. 한국어는 고정폭과 Pretendard 의 차이가 작다. 입력 모양은 기호와 캐럿, 회색 고정폭 숫자로 만들고, 결과 모양은 크기(70px → 150px)와 굵기 차이로 보여 준다.
- 30초에 장면이 10개다. 카드 한 장이 한 마디(1.9초)보다 짧으면 제목을 읽을 수 없다. 짧은 판에서는 카드 수를 줄이고 카드 길이는 지킨다.
- 낱말 연타(0.25초)는 한국어 두 글자 낱말까지만 읽힌다. 세 글자 이상이면 0.4초로 늘린다.
- 화면을 한 점으로 빨아들이는 두 순간은 움직임 세기 90 안팎으로 화면 전체가 흐려진다. 이 두 순간 말고는 화면이 조용하다(평균 8.5). 큰 움직임을 두 번 넘게 넣으면 "조용한 종이" 인상이 사라진다.
- 회색 번쩍임은 화면 전체 밝기가 한 번에 바뀐다. 따라 할 때는 0.1초 이하로 두거나 뺀다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 글꼴은 Pretendard Regular·SemiBold(한국어), 숫자·라틴 기호는 InterVariable 이다. 세리프와 고정폭 글꼴은 없다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 큰 제목 | 세리프 글꼴이 없다 | Pretendard SemiBold 140px(화면 높이의 13%), 자간 -0.03em, #302820. 둘째 줄은 Pretendard SemiBold 140px #B05838 + 글자 뒤 높이 40px 의 살구색 띠(#F2D3C2, 세로 위치는 글자 아래 1/3) | 획 대비가 큰 글자의 고급스러운 인상 |
| 입력 → 결과 서체 바뀜 | 두 서체 사이의 중간 모양이 없다 | 입력 상태는 InterVariable 70px 회색(#8A8078) + 앞에 주황 샵 기호, `font-variant-numeric: tabular-nums` 와 글자 사이 0.08em. 0.3초 동안 입력 글자를 `filter: blur(0 → 6px)`, 투명도 1 → 0, 같은 자리에서 결과 글자를 `blur(6px → 0)`, `scale(0.6 → 1)` 로 겹친다 | 글자가 뒤틀리며 바뀌는 재미 |
| 크림 종이 바탕 | 없다 | `radial-gradient(ellipse at 50% 45%, #FAF6EE 0%, #F3ECE3 55%, #D6CFC6 100%)` 위에 `texTile(5, { mc: '200,150,120', mottle: .03, dark: .02, light: .04, fibers: 60, specks: 8 })` 를 투명도 .5 로 깐다. 아래쪽에 지름 1400px 의 살구색(#F0D8C6) 번짐 원 하나 | 없음 |
| 조각이 모여 중심 표지가 되기 | 조각 수십 개의 경로 | canvas 에 기호 50개(샵·별표·대괄호·숫자)를 InterVariable 24~40px 로 그린다. 조각마다 시작 위치(화면 밖 반지름 1100px 원 위)와 도착 위치(표지 둘레 반지름 0~300px)를 씨앗 난수로 정하고 0.9초 동안 `1-(1-k)^3` 로 옮긴다. 도착하면 투명도 0 으로 끈다 | 조각이 정확히 글자 획 자리에 박히는 느낌 |
| 방사선 폭발 | 없다. SVG 로 된다 | SVG line 42개, 길이 0 → 260~420px, 굵기 1.5px, 6개 중 1개는 주황(#B05838), 나머지는 #B8AEA4. 가운데 지름 30px 주황 점. 0.25초에 뻗고 0.25초에 바깥 끝부터 줄어든다 | 없음 |
| 글자 섞임 | 없다 | 제목 글자 수만큼 무작위 기호(샵·별표·대괄호·숫자)를 0.04초마다 바꾸고, 왼쪽부터 0.3초 안에 차례로 제 글자로 고정한다. 한국어는 섞는 동안 기호만 쓰고 고정할 때 한글로 바꾼다 | 없음 |
| 카드 안 선화와 끊기는 연결선 | 없다. SVG 로 된다 | SVG 선 굵기 4px #302820 의 선화 주인공 요소(폭 360px), 둘레 원 3겹(반지름 160·220·280px, 굵기 1.5px, #E9C9B8). 작은 아이콘 4개를 점선(`stroke-dasharray: 4 8`)으로 잇고, 0.3초에 주황 빗금(굵기 4px)을 그어 끊는다 | 없음 |
| 원형 닦기로 어두운 화면 | 없다 | 어두운 장면 전체를 위에 두고 `clip-path: circle(r at 1640px 260px)`, r 을 0 → 2300px 로 0.8초, `1-(1-k)^4`. 경계에 굵기 2px 의 #D88860 원을 함께 키운다 | 없음 |
| 아이콘 격자 90개 | 아이콘 그림 | SVG 선 아이콘 15종을 직접 그려(굵기 2px, 40px 칸) 15x6 칸에 돌려 놓는다. 칸 간격 168px, 색 #5A4E44. 9칸은 살구색 둥근 타일(80x80px, 반지름 18px, #B47452 투명도 .8). 무너질 때는 칸마다 가운데로 0.25초, 회전 ±40도 | 아이콘 종류의 풍부함 |
| 화면 전체 흐림 전환 | 없다 | 장면 층에 `filter: blur(0 → 40px)` 0.3초, 다음 장면은 `blur(40px → 0)` 0.3초. 겹치는 0.1초에 두 층 모두 투명도 .5 | 없음 |
| 그레인 | 없다 | `grainLayer(stage, 11)` 기본값 그대로(밝은 바탕에서는 .34 가 맞다). 어두운 장면에서는 투명도를 .2 로 낮춘다 | 없음 |
