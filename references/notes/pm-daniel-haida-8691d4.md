## 3. 움직임

- 카메라는 판에 붙어서 천천히 흐른다. 판은 늘 원근으로 기울어 있고, 장면 안에서도 회전·크기가 조금씩 계속 바뀐다. 움직임 세기 평균이 4.9 로 낮다. 큰 값은 판이 통째로 밀려 나가는 한 번뿐이다(전체의 28% 자리).
- 장면 안의 요소는 시차를 두고 들어온다. 큰 숫자 → 그래프 선 → 요약 칸 → 작은 지표 순서로 약 0.3~0.5초씩 늦다. 모두 같은 프레임에 멈추지 않는다.
- 그래프 선은 왼쪽 첫 점에서 오른쪽으로 0.5초 안팎에 그려진다(점 9개). 선 아래 면은 금색에서 투명으로 내려가는 옅은 그라데이션이다. 마지막 점 위에 작은 금색 꼬리표 하나, 현재 위치에 세로 점선 하나가 있다.
- 밖에서 들어오는 보조 카드는 무게가 있다. 들어올 때 약 15도 기울어 있다가 목표 줄에 다가가며 기울기가 0 으로 풀린다. 붙기 직전 0.25초 동안 화면의 11% 에서 1.5% 로 급히 줄어든다(약 1/7). 붙기 직전에 카드 위 칸 세 곳에 금색 테두리가 차례로 켜지고, 목표 줄 외곽선이 금색으로 켜진다.
- 목록에 새 줄이 끼어들면 위에서 들어오고 다른 줄이 아래로 밀린다.
- 날아가는 값은 0.5초 안팎에 두 판 사이를 옮기고, 도착하면 높이 41px 굵은 흰색으로 남는다.
- 상태 바뀜(경고 → 완료, 미결 → 완료)은 꼬리표의 색과 글이 바뀌는 0.1~0.2초의 작은 사건이다. 이 순간을 타격음에 맞춘다.
- 진행 막대는 1초에 0 → 60% 로 찬다. 숫자는 약 0.5초에 굴러 오른다.
- 가속 곡선은 빠르게 출발해 길게 멈추는 꼴이다. 튀어 넘치거나 되돌아오는 움직임은 보이지 않는다(0.25초 간격 프레임에서 확인).
- 끝 1.56초는 완전 정지다. 영상 길이의 11% 다.

## 4. 전환

## 6. 가져올 것

- 핵심 장치 · 하드 컷 없이, 앞 장면의 한 부품이 모양을 바꿔 다음 장면의 부품이 된다(타일 → 판 0.5초, 직선 막대 → 원형 지표 0.35초, 원형 지표 → 로고의 원 약 1초).

- 핵심 장치 · 원근으로 5~10도 기운 판에 카메라가 붙어 판의 일부만 보이고, 판 안 요소가 0.3~0.5초씩 늦게 차례로 자리 잡는다.

- 로고의 바탕 타일을 그대로 첫 화면의 판으로 키우는 시작. 로고를 보여 주는 시간과 제품 화면으로 들어가는 시간이 겹친다.
- 장면당 큰 문구 0~1개, 전체 2개. 문구가 있는 장면은 판을 오른쪽으로, 문구를 왼쪽 1/3 로 나눈다.

## 7. 함정

- 원본 화면의 실존 로고·이름은 쓰지 않는다. 원래 글의 색 토큰도 원본 브랜드의 것이므로 값 그대로 쓰지 말고 대상 브랜드의 색으로 바꾼다.
- 판 위 작은 글자가 원근으로 기울어 있다. 한국어 소개 영상에서 화면 높이의 1% 아래 글자는 읽히지 않으므로 질감으로만 쓴다. 읽혀야 하는 숫자·문구는 높이 40px 이상으로 키운다.
- 판을 실제 제품 화면처럼 다시 짜야 한다. 화면 캡처 한 장을 기울이면 값이 날아가거나 꼬리표가 바뀌는 사건을 만들 수 없다. 움직일 부분(큰 숫자, 그래프 선, 한 줄, 꼬리표, 막대, 고리)은 따로 그려야 한다.
- 공유 물체 전환이 이 스타일의 뼈대다. 모양이 이어지는 전환 하나를 사라졌다 나타나기로 바꾸면 구성이 무너진다. 대상의 화면에 이어 붙일 모양 짝이 없으면 다른 짝(예: 원형 진행 표시 → 로고의 원)을 먼저 찾는다.
- 바탕이 매우 어둡다(#05080F). 영상 압축에서 바탕 그라데이션에 띠가 생기기 쉽다. 아주 약한 그레인을 깐다.
- 빨강·초록 숫자 글자가 흐린 남색 판 위에서 대비가 낮다(빨강은 분홍빛으로 보인다). 한국어 숫자를 같은 크기로 쓰면 더 흐려 보이므로 굵기를 SemiBold 로 한다.
- 판 전체를 한 번에 미는 장면 넘김은 움직임 세기 24.5 로 이 스타일에서 가장 거친 순간이다. 따라 할 때는 0.4초 이상으로 늘리거나 판이 밀리는 거리를 줄인다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 글꼴은 Pretendard Regular·SemiBold(한국어), 숫자는 InterVariable 이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 원근으로 기운 UI 판 | 없다. DOM/CSS 로 된다 | 판을 div 로 짜고 부모에 `perspective: 2200px`, 판에 `transform: rotateX(8deg) rotateY(-10deg)`. 판 배경 #1E233C, 테두리 1px rgba(255,255,255,.06), 반지름 24px. seek(t) 마다 rotateY 를 -10 → -6deg 로 천천히 바꾼다 | 없음 |
| 판 뒤 빛 번짐 | 없다 | 판 뒤에 지름 1200px 의 `radial-gradient(rgba(232,184,72,.08), transparent 60%)` 원 하나. 장면이 바뀔 때 주인공을 따라간다 | 없음 |
| 로고 위를 지나는 빛줄기 | 렌즈 빛 번짐과 별 모양 반짝임 | canvas 에 길이 160px, 굵기 1.5px 의 흰 선(양 끝 투명 그라데이션)과 지름 18px 의 흰 원(`radial-gradient`)을 겹친다. `mix-blend-mode: screen`. 0.25초 동안 획의 아래 오른쪽 가장자리를 따라 이동 | 렌즈 특유의 십자 빛 |
| 로고 획이 갈라져 날아가기 | 실존 로고를 자르면 안 된다 | 사용자가 허락한 로고 SVG 를 경로 두 개로 나눌 수 있을 때만 한다. 나눌 수 없으면 로고는 그대로 커지며 투명해지고, 바탕 타일(360x360px, 반지름 72px)만 판으로 커진다 | 로고가 갈라지는 재미 |
| 선 그래프 긋기 | 없다. SVG 로 된다 | SVG path 를 `stroke-dasharray` 로 0.5초에 그린다. 선 굵기 3px, 금색. 선 아래 면은 금색 투명도 .25 → 0 의 세로 그라데이션 polygon 을 같은 진행도로 clip 한다 | 없음 |
| 종이 질감 보조 카드 | 톱니 모양 아래 끝과 종이 결 | DOM 카드 540x556px, 배경 #EEE7E1, 아래 끝은 CSS `clip-path: polygon(...)` 으로 높이 12px 톱니 20개. 종이 결은 `texTile(3, { mc: '128,128,128', mottle: .03, dark: .03, light: .04, fibers: 80, specks: 10 })` 를 배경으로 깐다. 기울기 15 → 0deg | 종이의 미세한 휨 |
| 값이 한 판의 칸에서 다른 판의 칸으로 날아가기 | 두 판의 좌표가 원근으로 다르다 | 출발 칸과 도착 칸의 `getBoundingClientRect()` 를 로드 때 한 번 재 둔다. 날아가는 값은 원근 밖의 DOM 층에 따로 두고 두 좌표 사이를 0.5초에 옮긴다. 도착 순간 원래 칸의 글자를 켜고 나는 글자를 끈다 | 글자가 기운 면에 붙는 느낌이 도착 순간 조금 튄다 |
| 막대 → 고리 변형 | 직선이 원호로 휘는 중간 모양 | SVG path 하나로 그린다. 진행도 k(0~1)에 따라 막대 길이 L=520px 를 반지름 R=∞→122px 의 원호로 바꾼다. 원호 각 = L/R. R 은 `122 / k` 로 줄이고, 같은 길이를 유지한다. 0.35초 | 없음 |
| 숫자 굴려 올리기 | 없다 | InterVariable SemiBold 72px, `font-variant-numeric: tabular-nums`. 0.5초에 정수로 올린다 | 없음 |
| 고리 → 로고의 원 | 대상 로고에 동그란 글자가 없을 수 있다 | 대상 로고에 원이 있으면 그 원의 크기·위치로 고리를 줄인다(지름 244 → 75px, 0.5초). 원이 없으면 고리를 로고 가운데 점으로 줄인 뒤 로고를 투명도 0 → 1 로 0.3초에 연다 | 마지막 글자로 이어지는 맞물림 |
| 전체 그레인 | 없다 | `grainLayer(stage, 7)` 를 맨 위에 깔고 투명도를 .34 → .12 로 낮춘다(어두운 바탕에서는 기본값이 강하다) | 없음 |
| 한국어 문구 | 원작은 둥근 기하형 산세리프다 | Pretendard SemiBold 64px(화면 높이의 5.9%), 자간 -0.02em, #F0F0EC. 한 줄 10자 이하. 끝 문구는 Pretendard Regular 34px 두 색(#80849C 근처 + #D8D8DC 근처) | 둥근 글자의 부드러운 인상 |
