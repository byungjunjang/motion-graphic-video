## 3. 움직임

- 카메라는 판에 붙어서 천천히 흐른다. 판은 늘 원근으로 기울어 있고, 장면 안에서도 회전·크기가 조금씩 계속 바뀐다. 움직임 세기 평균이 4.9 로 낮다. 큰 값은 판이 통째로 밀려 나가는 4.0초 한 번뿐이다.
- 장면 안의 요소는 시차를 두고 들어온다. 대시보드에서 큰 금액 → 그래프 선 → 요약 칸 → 작은 지표 순서로 약 0.3~0.5초씩 늦다. 모두 같은 프레임에 멈추지 않는다.
- 그래프 선은 왼쪽 첫 점에서 오른쪽으로 0.5초 안팎에 그려진다. 선 아래 면은 금색에서 투명으로 내려가는 옅은 그라데이션이다. 마지막 점 위에 작은 금색 꼬리표 하나, 오늘 위치에 세로 점선 하나가 있다.
- 영수증은 무게가 있다. 들어올 때 약 15도 기울어 있다가 첫 줄에 다가가며 기울기가 0 으로 풀린다. 붙기 직전에 화면 크기의 약 1/7 로 급히 줄어든다(5.5 → 5.75초).
- 상태 바뀜(경고 → 완료, 미결 → 완료)은 꼬리표의 색과 글이 바뀌는 0.1~0.2초의 작은 사건이다. 이 순간이 타격음(6.04초, 7.54초)과 맞는다.
- 숫자는 굴러 오른다(85 → 94, 약 0.5초).
- 가속 곡선은 빠르게 출발해 길게 멈추는 꼴이다. 튀어 넘치거나 되돌아오는 움직임은 보이지 않는다(0.25초 간격 프레임에서 확인).
- 끝 1.56초는 완전 정지다. 원래 글은 정지를 요구만 했고 길이는 비워 두었다. 실제로는 영상 길이의 11% 다.

## 4. 전환

- 하드 컷이 0개다. 모든 장면이 앞 장면의 물체에서 나온다.
- 아이콘 → 대시보드 · 아이콘의 금색 획은 밖으로 날아가고, 남은 바탕 타일이 그대로 커져 대시보드 판이 된다(0.75~1.25초). 타일의 둥근 모서리가 판의 모서리가 된다.
- 대시보드 → 거래 목록 · 같은 앱 화면을 위로 스크롤하듯 판이 위로 밀려 나간다. 대시보드 판과 거래 목록 판은 처음부터 한 화면에 위아래로 붙어 있다(4.0초에 아래 판의 제목이 이미 보인다).
- 영수증 → 거래 줄 · 영수증이 줄어들며 해당 줄에 붙고, 줄의 꼬리표가 바뀐다. 원래 글은 그래프의 금색 점이 영수증 모서리로 커지는 방식을 예로 들었으나, 실제 화면은 영수증이 화면 밖에서 따로 들어온다.
- 거래 목록 → 청구서 목록 · 새로 생긴 입금 줄의 금액이 떠올라 청구서 목록의 같은 금액 칸으로 날아간다. 카메라가 그 금액을 따라 오른쪽으로 간다.
- 청구서 → 세무 점수 · 금색 진행 막대가 휘어져 원형 점수 고리가 된다(9.4~9.75초). 이 영상에서 가장 눈에 띄는 공유 물체 전환이다.
- 세무 점수 → 워드마크 · 점수 고리가 줄어 워드마크의 동그란 글자가 된다(11.25~12.25초). 색은 초록 → 금색으로 바뀐다.
- 마디 첫 박에 맞는 전환은 2.0초(그래프 시작), 4.0초(판 밀림), 6.0초(영수증 붙음), 10.0초(점수 시작), 12.0초(워드마크)다. 8.0초 박에는 큰 사건이 없다.

## 5. 타이포

- 글꼴은 두 계열이다. 문구·라벨·워드마크는 둥근 기하형 산세리프, 금액·숫자는 고정폭 숫자 글꼴이다.
- 큰 문구 두 번 · 대시보드 장면(3.0~4.0초)과 세무 장면(10.25~11.25초)에만 한 줄씩 나온다. 굵은 흰색(#F0F0EC 근처), 글자 높이 59px(화면 높이의 5.5%, 대문자·올림 획 기준), 문구 폭 457px(24%). 세무 장면 문구는 내림 획 포함 71px. 둘 다 화면 왼쪽 1/3 에 두고 판은 오른쪽에 둔다.
- 세무 문구 위아래에 작은 초록 꼬리표 2개(글자 높이 약 22px, 어두운 초록 알약 바탕)가 붙는다.
- 대시보드의 큰 금액 · 고정폭 굵은 흰색, 3.5초에 높이 88px(8.1%), 1.75초에 104px(9.6%). 통화 기호는 작고 흐린 색으로 아래에 붙인다.
- 판 안의 작은 글자 · 라벨은 높이 10~14px 의 대문자 작은 글씨, 흐린 청회색. 원근으로 기울어 읽기보다 질감 역할을 한다.
- 워드마크 · 소문자 금색, 높이 99px(9.2%), 폭 488px(25%). 그 아래 문구는 높이 32px(3%) 로, 앞 낱말은 흐린 청회색, 뒷부분은 흰색이다. 한 줄 안에서 색 두 개로 강조를 나눈다.
- 원래 글은 장면마다 짧은 문구 하나씩을 예로 들었다. 실제로는 두 장면에만 문구가 있고 나머지 세 장면은 판만 보여 준다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 9.5~10.5초. 금색 진행 막대가 휘어 지름 244px(화면 높이의 23%) 고리가 되고, 고리가 초록으로 바뀌며 숫자가 오르는 세무 점수 카드(585x761px, 가로 50~81%)와 왼쪽 큰 문구 한 줄(높이 59~71px). 화면 요소는 카드 1 + 문구 1 + 꼬리표 2 = 4개. 막대 → 고리의 공유 물체 전환이 빠지면 이 영상이 아니다. 둘째로 11.25~12.25초의 고리 → 워드마크 글자 전환도 남긴다.
- 12초 판 압축 예 · 0~0.9초 아이콘 갈라짐과 타일 확대, 0.9~3.4초 대시보드(큰 숫자 + 그래프 긋기 + 문구), 3.4~5.4초 영수증이 목록 한 줄에 붙기, 5.4~6.4초 금액이 청구서 줄로 날아가 상태 바뀜(지급 상태 카드 막대 채우기는 6.4~7.4초로 짧게), 7.4~9.4초 막대 → 고리 → 점수 카드와 문구, 9.4~10.6초 고리 → 워드마크, 10.6~12.0초 정지. 마디 2.0초 박자를 그대로 쓰면 큰 사건이 0.9·2.9·4.9·6.9·8.9·10.9초 근처에 온다. 청구서 장면의 카메라 이동 거리를 반으로 줄인다.
- 아이콘의 바탕 타일을 그대로 첫 화면의 판으로 키우는 시작. 로고를 보여 주는 시간과 제품 화면으로 들어가는 시간이 겹친다.
- 같은 금색 물체가 장면을 이어 달리는 구성. 금색은 아이콘 → 그래프 선 → 강조 줄 → 막대 → 고리 → 워드마크로 한 줄기다. 의미 색(초록·빨강)은 이 줄기와 따로 쓴다.
- 장면당 큰 문구 0~1개, 전체 2개. 문구가 있는 장면은 판을 오른쪽으로, 문구를 왼쪽 1/3 로 나눈다.
- 상태 바뀜을 타격음에 맞추는 법. 무음(0.5초) → 상태 바뀜 + 타격.
- 끝 정지 1.5초 이상.

## 7. 함정

- 화면의 워드마크, 앱 아이콘, 영수증의 상호, 거래처·지명, 날짜, 금액, 문구는 실존 앱과 원작의 것이다. 옮기지 않는다. 실존 로고는 쓰지 말고, 사용자가 허락한 우리 대상의 로고 파일로만 같은 구조를 만든다. 원래 글의 색 토큰도 실존 앱의 것이므로 값 그대로 쓰지 말고 대상 브랜드의 색으로 바꾼다.
- 판 위 작은 글자가 원근으로 기울어 있다. 한국어 소개 영상에서 화면 높이의 1% 아래 글자는 읽히지 않으므로 질감으로만 쓴다. 읽혀야 하는 숫자·문구는 높이 40px 이상으로 키운다.
- 판을 실제 앱 화면처럼 다시 짜야 한다. 화면 캡처 한 장을 기울이면 금액이 날아가거나 꼬리표가 바뀌는 사건을 만들 수 없다. 움직일 부분(큰 숫자, 그래프 선, 한 줄, 꼬리표, 막대, 고리)은 따로 그려야 한다.
- 공유 물체 전환이 이 영상의 핵심이다. 막대 → 고리, 고리 → 글자 중 하나를 "사라졌다 나타나기"로 바꾸면 구성이 무너진다. 대상의 화면에 막대·고리·동그란 글자처럼 이어 붙일 모양이 없으면 다른 짝(예: 원형 진행 표시 → 로고의 원)을 먼저 찾는다.
- 바탕이 매우 어둡다(#05080F). 영상 압축에서 바탕 그라데이션에 띠가 생기기 쉽다. 아주 약한 그레인을 깐다.
- 빨강·초록 금액 글자가 흐린 남색 판 위에서 대비가 낮다(빨강은 분홍빛으로 보인다). 한국어 금액을 같은 크기로 쓰면 더 흐려 보이므로 굵기를 SemiBold 로 한다.
- 4.0초 장면 넘김은 판 전체가 한 번에 밀려 움직임 세기 24.5 가 된다. 이 영상에서 가장 거친 순간이다. 따라 할 때는 0.4초 이상으로 늘리거나 판이 밀리는 거리를 줄인다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 글꼴은 Pretendard Regular·SemiBold(한국어), 숫자는 InterVariable 이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 원근으로 기운 UI 판 | 없다. DOM/CSS 로 된다 | 판을 div 로 짜고 부모에 `perspective: 2200px`, 판에 `transform: rotateX(8deg) rotateY(-10deg)`. 판 배경 #1E233C, 테두리 1px rgba(255,255,255,.06), 반지름 24px. seek(t) 마다 rotateY 를 -10 → -6deg 로 천천히 바꾼다 | 없음 |
| 판 뒤 빛 번짐 | 없다 | 판 뒤에 지름 1200px 의 `radial-gradient(rgba(232,184,72,.08), transparent 60%)` 원 하나. 장면이 바뀔 때 주인공을 따라간다 | 없음 |
| 아이콘 위를 지나는 빛줄기 | 렌즈 빛 번짐과 별 모양 반짝임 | canvas 에 길이 160px, 굵기 1.5px 의 흰 선(양 끝 투명 그라데이션)과 지름 18px 의 흰 원(`radial-gradient`)을 겹친다. `mix-blend-mode: screen`. 0.25초 동안 획의 아래 오른쪽 가장자리를 따라 이동 | 렌즈 특유의 십자 빛 |
| 아이콘 획이 갈라져 날아가기 | 실존 로고를 자르면 안 된다 | 사용자가 허락한 로고 SVG 를 경로 두 개로 나눌 수 있을 때만 한다. 나눌 수 없으면 로고는 그대로 커지며 투명해지고, 바탕 타일(360x360px, 반지름 72px)만 판으로 커진다 | 로고가 갈라지는 재미 |
| 그래프 선 긋기 | 없다. SVG 로 된다 | SVG path 를 `stroke-dasharray` 로 0.5초에 그린다. 선 굵기 3px, 금색. 선 아래 면은 금색 투명도 .25 → 0 의 세로 그라데이션 polygon 을 같은 진행도로 clip 한다 | 없음 |
| 영수증 종이 | 톱니 모양 아래 끝과 종이 결 | DOM 카드 540x556px, 배경 #EEE7E1, 아래 끝은 CSS `clip-path: polygon(...)` 으로 높이 12px 톱니 20개. 종이 결은 `texTile(3, { mc: '128,128,128', mottle: .03, dark: .03, light: .04, fibers: 80, specks: 10 })` 를 배경으로 깐다. 기울기 15 → 0deg | 종이의 미세한 휨 |
| 금액이 줄에서 떠올라 다른 판으로 날아가기 | 두 판의 좌표가 원근으로 다르다 | 출발 칸과 도착 칸의 `getBoundingClientRect()` 를 로드 때 한 번 재 둔다. 날아가는 금액은 원근 밖의 DOM 층에 따로 두고 두 좌표 사이를 0.5초에 옮긴다. 도착 순간 원래 칸의 글자를 켜고 나는 글자를 끈다 | 글자가 기운 면에 붙는 느낌이 도착 순간 조금 튄다 |
| 막대 → 고리 변형 | 직선이 원호로 휘는 중간 모양 | SVG path 하나로 그린다. 진행도 k(0~1)에 따라 막대 길이 L=520px 를 반지름 R=∞→122px 의 원호로 바꾼다. 원호 각 = L/R. R 은 `122 / k` 로 줄이고, 같은 길이를 유지한다. 0.35초 | 없음 |
| 점수 숫자 오르기 | 없다 | InterVariable SemiBold 72px, `font-variant-numeric: tabular-nums`. 85 → 94 를 0.5초에 정수로 올린다 | 없음 |
| 고리 → 워드마크 글자 | 대상 로고에 동그란 글자가 없을 수 있다 | 대상 로고에 원이 있으면 그 원의 크기·위치로 고리를 줄인다(지름 244 → 75px, 0.5초). 원이 없으면 고리를 로고 가운데 점으로 줄인 뒤 로고를 투명도 0 → 1 로 0.3초에 연다 | 마지막 글자로 이어지는 맞물림 |
| 전체 그레인 | 없다 | `grainLayer(stage, 7)` 를 맨 위에 깔고 투명도를 .34 → .12 로 낮춘다(어두운 바탕에서는 기본값이 강하다) | 없음 |
| 한국어 문구 | 원작은 둥근 기하형 산세리프다 | Pretendard SemiBold 64px(화면 높이의 5.9%), 자간 -0.02em, #F0F0EC. 한 줄 10자 이하. 끝 문구는 Pretendard Regular 34px 두 색(#80849C 근처 + #D8D8DC 근처) | 둥근 글자의 부드러운 인상 |
