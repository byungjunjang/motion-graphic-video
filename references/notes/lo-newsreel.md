# 1920년대 유성 뉴스 영화 · 돌며 날아드는 신문과 흑백 필름 — 분석 노트

> 검은 화면 가운데 1.37:1 영사 창 하나에 담긴 55초 뉴스 영화. 방사형 빛살과 탐조등 두 줄 사이에 지구본 상표가 서고, 원형 조리개가 닫히면 신문 한 장이 돌며 날아와 화면에 꽂힌다. 이어 지도 위 점선 호, 잡지 사진 격자, 연속 사진 넘기기, 장식 테두리의 제목 카드, 실제 기록 필름, 좌우 분할, 네 칸 격자, 멈춘 화면 위 흰 기름연필 동그라미가 띠 음악의 박자에 맞춰 이어진다. 끝에 같은 상표로 돌아와 닫는다. 옛 유행, 기념일, 회사·기관의 역사, 옛날 소식처럼 보여 주고 싶은 이야기에 맞는다.

출처 · lo:newsreel. 색인에 든 원래 글은 발췌 약 8천 자의 스타일 명세다(본질, 편집 문법, 정지 화면 카메라 표, 함정, 시각이 붙은 숏 표 18개). 글은 실제 기록 자료를 쓰라고 정했고, 숏 순서와 전환 종류, 200 BPM 격자를 자세히 정했다. 그러나 영사 창의 크기, 은빛 색조의 실제 값, 깜빡임·흔들림의 세기, 자막 띠의 자리, 글자 크기, 대표 장면의 0.25초 단위 동작이 없다. 이 저장소는 실제 기록 필름을 구하기 어려운 경우가 많다. 그래서 영상 프레임을 보고 이 노트를 썼고 `## 8` 에 대신하는 값을 자세히 적는다.
측정 · 파일 1280x720 · 24fps · 54.58초. 크기는 1920x1080 기준으로 바꿔 적는다(1.5배). 장면 감지 컷은 0.17, 24.00, 27.00, 34.71, 37.08, 39.50초다. 나머지 전환은 닦기·조리개·뒤집기라서 컷으로 잡히지 않는다. 움직임 세기는 평균 11.6, 중앙값 8.9 다. 실제 기록 필름 구간(32.0~42.0초)이 19~42 로 가장 크고 최대는 39.0초(41.9, 네 칸 격자로 들어가는 순간)다. 9.0~12.0초(지도), 18.5~20.0초(제목 카드), 51.0초 뒤(끝 화면)는 0.2~1.6 으로 거의 멈춘다. 색 값은 프레임에서 잰 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. 박 검출은 71.8 BPM 으로 나와 원래 글의 200 BPM 과 맞지 않는다. 그러나 16.20~18.30초의 타격 7개(16.20, 16.50, 17.09, 17.39, 17.69, 18.02, 18.30)는 약 0.30초 간격으로 200 BPM 박과 맞는다. 가장 센 타격은 17.09초(0.68, 연속 사진 넘기기)이고, 4.79초(0.61, 킥)는 신문이 꽂히는 자리다. 무음(−30dB 아래)은 3.52~4.08초(조리개가 닫힌 뒤), 7.92~8.10초(지도 닦기 직전), 20.42~20.74초(제목 카드 뒤 조리개 열기 직전), 46.12~46.60초(멈춘 화면 끝, 띠 음악이 끊기는 자리), 49.74~51.32초, 53.04초~끝이다.

## 3. 움직임

- 원래 글의 정지 화면 카메라 표(돌며 꽂기, 천천히 밀다 박에 들어가기, 지도 밀기, 격자 놓기, 연속 사진, 멈춤과 흔들림, 분할)는 화면과 맞다.
- 영상에서 확인한 점 · 신문·지도·잡지처럼 정지 자료는 늘 움직인다. 지도 구간의 창 가장자리가 3초 동안 6px(720 기준) 꾸준히 옮겨 간다. 천천히 미는 속도는 초당 약 3~4% 크기 증가다.
- 박에 맞춘 "들어가기"는 한 번에 1.6~2배다. 이 순간이 움직임 세기 19~26 을 만든다.
- 기록 필름 구간은 필름 속 사람들이 움직여서 세기가 높다(32.0~42.0초 평균 약 25). 그 위에는 큰 카메라 이동을 얹지 않는다. 원래 글의 6% 제한과 맞다.
- 기름연필 · 한 바퀴를 약 0.25초에 그린다. 선은 굵기 약 6px 로 일정하고 끝이 둥글다.

## 4. 전환

- 원래 글에 있는 뉴스 영화식 전환(원형 조리개, 밝은 테두리 사선 닦기, 세로 축 뒤집기, 12장 블라인드, 시계 닦기, 도는 신문, 쪽 넘기기, 칸 밀어내기, 멈춤)이 각각 한 번씩 쓰인다. 이야기 사이 디졸브는 없다.
- 영상에서 확인한 점 · 큰 전환 바로 앞에 짧은 무음(0.2~0.6초)이 자주 온다 · 3.52초(조리개 뒤), 7.92초(사선 닦기 앞), 20.42초(조리개 열기 앞), 46.12초(멈춘 화면 끝).
- 원형 조리개는 검은 바탕 위에서 닫히고 열린다. 닫힐 때 중심은 다음 장면의 주인공 자리(상표의 지구본, 멈춘 화면의 무릎)다.
- 하드 컷은 기록 필름 사이에서만 쓴다(24.00, 27.00, 34.71, 37.08, 39.50초).

## 5. 타이포

- 글자는 세 종류다. 상표와 제목 카드의 장식 대문자(가운데가 높은 꺾인 획, 아래위로 밝아지는 금속 느낌 채움, 어두운 외곽선), 이름표의 폭 좁은 굵은 대문자, 자막의 굵은 고딕 한자 + 가는 라틴.
- 크기(화면 높이 대비).
  - 상표 제목 · 약 5.3%(57px), 한자 줄 약 3%.
  - 제목 카드 제목 · 약 7%(75px).
  - 지도 연도 숫자 · 약 6%, 상자 안.
  - 이름표 · 위 줄 대문자 약 2.6%(28px), 아래 한자 줄 약 2.2%.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 3.6~8.4초의 "작은 신문이 돌며 커져(창 가로 3% → 95%, 1.25초) 박에 꽂힌다 → 왼쪽 위 장소·날짜 이름표 → 천천히 밀다가 박에 맞춰 2배로 들어간다 → 한 부분에 흰 기름연필 동그라미(240x190px, 굵기 6px)"다. 1.37:1 영사 창(1478x1080px), 따뜻한 은빛 색조(어두운 곳 #14120F, 밝은 곳 #E0D7C9), 창 아래 검은 자막 띠가 함께 있어야 한다. 이 셋이 빠지면 옛 신문 소개 슬라이드가 된다.
- 12초 판 압축 예 · 0~1.8초 상표(빛살과 탐조등, 지구본, 1.4~1.8초 조리개 닫기), 1.8~5.4초 대표 장면 3.6초(돌기 1.8~2.8초, 꽂기 2.8초, 이름표 3.0초, 밀기 3.0~4.2초, 들어가기 4.2초, 동그라미 4.5~4.8초), 5.4~5.7초 사선 닦기, 5.7~8.1초 지도 또는 격자 놓기(점선 호 하나, 이름표 둘, 2.4초), 8.1~9.3초 연속 사진 4장(0.3초씩), 9.3~10.5초 멈춘 화면과 동그라미, 10.5~10.8초 조리개, 10.8~12.0초 상표 다시. 제목 카드, 책, 분할 화면, 네 칸 격자는 뺀다. 200 BPM 격자(박 0.3초)에 모든 컷과 착지를 맞춘다.
- 처음과 끝이 같은 상표 의식이다. 조리개로 닫고 조리개로 연다.
- 정지 자료는 꼭 한 가지 목적을 가진 카메라 동작을 받는다(꽂기, 밀기, 들어가기, 동그라미).

## 7. 함정

- 화면의 신문 이름, 제목, 기사 문장, 도시 이름, 인물 이름, 회사 이름, 자막 문장, 상표 이름은 모두 원작과 실제 기록의 것이다. 실존 이름이 많다. 옮기지 않는다. 역할(신문 한 장, 장소·날짜 이름표, 지도 한 장, 동그라미로 짚는 증거)만 가져온다.
- 원래 글은 실제 기록 자료를 쓰라고 정했다. 이 저장소의 사실 규칙도 같다. 그래서 둘 중 하나로만 만든다.
  - 사용자가 준 실제 기록 필름·스캔과 그 출처를 쓴다. 이름표의 장소·날짜는 그 자료에서 직접 확인한 것만 쓴다.
  - 자료가 없으면 가상의 이야기로 만든다. `## 8` 의 대체물은 "실제 기록"이 아니라 "기록처럼 보이는 연출"이다. 실존 날짜·인물·기관을 붙이지 않는다. 끝 화면에 연출 자료라고 밝힌다.
- 16:9 로 옮기는 구도 · 영사 창 자체가 이 스타일이다. 창을 화면 가득 늘리지 않는다. 1920x1080 안에 창 1478x1080(가로 11.5~88.5%)을 두고 양옆 221px 를 #020202 로 비운다. 이름표·자막·동그라미는 모두 창 안에 둔다. 창 밖에 아무것도 두지 않는다.
- 낡음을 세게 넣으면 장르가 바뀐다. 원본의 깜빡임은 밝기 0.6% 수준, 흔들림은 1px 아래다. 큰 깜빡임, 굵은 세로 긁힘, 화면 전체 얼룩은 넣지 않는다. 색조와 둥근 그늘이 먼저다.
- 순수한 검정·흰색을 쓰면 현대 흑백 사진이 된다. 어두운 끝 #14120F, 밝은 끝 #E0D7C9 사이로 누른다.
- 한국어 글자 크기 · 자막은 33px, 이름표는 28px 근처다. 장식 대문자 제목은 한국어로 바꾸면 Pretendard SemiBold 75px, 자간 0.12em 정도로 둔다. 140px 를 넘기지 않는다.
- 원래 글의 함정(기록 필름 앞뒤의 기록 표지와 흰 번쩍임을 자르기, 칸마다 자동 밝기를 쓰지 않기, 2.5배 넘게 키우지 않기)은 실제 기록을 쓸 때 그대로 맞다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 영사 창 안쪽 좌표는 창 왼쪽 위(221, 0)를 원점으로 적는다. 아래 대체물은 실제 기록이 없을 때의 연출 자료다(`## 7`).

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 실제 기록 필름(사람이 움직이는 장면) | 실사 동영상이다. 코드와 AI 그림으로 만들 수 없다 | 연속 사진 넘기기로 바꾼다(원본도 15.9~18.0초에 쓴다). AI 일러스트(codex-image)로 같은 사람·같은 배경의 자세 4~6장을 그린다 · `--size 1536x1024`, 프롬프트에 1920년대풍 흑백 사진, 낮은 대비, 고운 입자, 사람 한 명 전신, 글자·로고 없음. 장마다 0.3초(200 BPM 한 박)로 바꾼다. 각 장에 1.00 → 1.03 배 밀기 | 사람의 연속 동작과 실제 시대의 공기 |
| 옛 신문 한 장 | 실제 신문 스캔과 옛 활자 | canvas 에 가상의 신문을 짠다 · 종이 1500x700px, `texTile(seed, { mc: '120,110,95', mottle: .06, dark: .07, light: .05, fibers: 200, specks: 80 })` 위에 바탕 #D8CFC0. 제목 한 줄 Pretendard SemiBold 64px #1A1714, 본문 5단(단 폭 270px) Pretendard Regular 15px 줄간격 1.2, 가운데에 AI 사진 한 장(흑백, 600x450px). 다 그린 뒤 반경 0.7px 흐림 + 표준편차 6 잡음을 한 번 굽는다 | 옛 활자의 세리프와 잉크 번짐 |
| 돌며 날아드는 신문 | 없다. CSS 로 된다 | 구운 신문 이미지에 `transform: translate(…) rotate(θ) scale(s)`. 1.25초 동안 s 0.03 → 1.0, θ 900° → 0°(2.5바퀴), 처음 0.9초는 천천히 시작해 빨라지고 마지막 0.1초에 1.06 → 1.0 으로 꽂힌다. 꽂히는 칸에 창 전체를 4px 아래로 한 번 튕긴다. 아래에 같은 신문 3장을 회전 ±8° 로 겹쳐 둔다 | 없음 |
| 은빛 색조와 둥근 그늘 | 실제 필름 현상의 색 | 창 안 모든 층을 한 div 에 넣고 `filter: grayscale(1) sepia(.2) contrast(.85) brightness(.95)`. 위에 `radial-gradient(ellipse at 50% 40%, transparent 45%, rgba(10,8,6,.75) 100%)` 를 덮는다. 목표 · 어두운 끝 #14120F 근처, 밝은 끝 #E0D7C9 근처 | 필름 고유의 계조 |
| 입자·깜빡임·흔들림 | 실제 영사의 우연 | `grainLayer(gate, seed)` 를 창 안에만 붙인다(불투명도 0.34 기본값 유지). 깜빡임은 칸마다 `rng(floor(t*24))` 로 밝기 ±1%(`brightness(.99~1.01)`). 흔들림은 같은 난수로 창 내용을 ±0.7px 옮긴다. 흠집은 1~2초에 한 번, 1px 세로선(불투명도 0.25, 길이 창 높이 30~100%)을 2칸만 | 실제 필름 흠집의 모양 |
| 장식 대문자 제목 | 그런 글꼴이 없다 | 한국어 제목을 Pretendard SemiBold 75px, 자간 0.12em 으로 쓴다. 채움은 `background: linear-gradient(180deg, #F2EBDD, #A89C86); -webkit-background-clip: text`, 외곽은 `text-shadow` 로 #1A1612 2px 를 네 방향. 위아래에 가는 이중선(굵기 2px·1px, 간격 5px) | 시대를 말해 주는 장식 글꼴 |
| 상표의 빛살과 탐조등 | 없다. canvas 로 된다 | 지구본 중심에서 30줄 빛살 · `createConicGradient` 로 #3A3328 과 #221D17 을 6°씩 번갈아. 탐조등 두 줄은 위 귀퉁이에서 아래로 퍼지는 사다리꼴(위 폭 40px, 아래 폭 260px), 채움 #D9CFBC 불투명도 0.35 → 0, `lighter` 합성, ±12° 로 천천히 흔든다. 지구본은 SVG 원(지름 400px)에 위도선 6줄·경도선 8줄, 왼쪽 위에서 오는 방사형 그라데이션 #E8DFCE → #6E6454 | 실제 촬영 상표의 깊이 |
| 원형 조리개·블라인드·시계 닦기 | 없다. CSS 로 된다 | 조리개 · `clip-path: circle(r at x y)`, r 을 1100px → 0 으로 0.6초(끝으로 갈수록 빠르게), 뒤는 검정. 블라인드 · 가로 띠 12장, 각 `rotateX(90deg → 0)` 를 0.04초 간격으로 0.25초씩. 시계 닦기 · 마스크 `conic-gradient(from 0deg, #000 0 a, transparent a)` 에서 a 를 0 → 360°로 0.6초. 사선 닦기 · 경계에 밝은 6px 선(#E8E0D2) | 없음 |
| 흰 기름연필 동그라미 | 손 획의 고르지 않음 | 타원 점 40개에 `HAND.wobble(P, false, 4, 'ring', 0)` 를 한 번 적용해 시작과 끝이 15° 겹치게 만든다. `HAND.ink(ctx, P, { frac, w: 6, color: '#E1DBCF', key: 'ring', B: 0 })`, frac 0 → 1 을 0.25초. 꼬리 획은 길이 60px 직선 한 개를 0.1초 | 연필 획의 끊김과 밀림 |
| 지도 | 실제 국경 자료를 받아 오지 않는다 | 이야기에 필요한 지역만 우리가 그린 단순 다각형(꼭짓점 30~60개)으로 SVG 에 그린다. 땅 #C5B8A1, 내부 경계 1px #D3C7B0, 바탕 #352E27 위에 4px 간격 가로줄(불투명도 0.08). 점선 호는 `stroke-dasharray: 8 8`, 굵기 4px, #2A231C, `stroke-dashoffset` 으로 0.6초에 그린다. 실제 지도 모양이 꼭 필요하면 사용자에게 자료 파일을 받는다 | 실제 지도의 알아보기 쉬움 |
