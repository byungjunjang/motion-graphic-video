# 링크 하나로 광고 영상 스물넷 · 밝은 앱에서 어두운 3D 무대로 — 분석 노트

> 광고 영상 생성 서비스를 소개하는 20초 16:9 영상. 크림색 바탕에 첫 문장이 박마다 한 낱말씩 쌓이고, 앱 창에 주소를 넣어 단추를 누르면 단추에서 검은 원이 열려 어두운 무대로 넘어간다. 그 뒤로는 2초 한 마디에 장면 하나씩이다. 세로 영상 18개의 벽과 훑는 선, 순위 문장 3줄, 바닥에 비친 원통 회전목마와 휙 돌리기, 휴대폰과 뒤집히는 결과 패널, 큰 숫자 3개, 세 낱말 띠, 로고, 검은 화면. 실제 사람이 찍은 세로 영상이 화면의 주재료다. 생성형 마케팅 도구, 숏폼·광고 관련 서비스 소개에 맞는다. 넓은 여백 · 포인트 색 하나 · 3D 카드 무대.

출처 · pm:twoclipping-6dd14e. 작성자의 글은 약 2,500자의 제작 주문이다. 입력 목록, 금지 효과, 10마디 구성(마디마다 장면 하나), 구현 방법(실사 영상의 낱장 교체, 박 격자 맞춤, 하위 프레임 움직임 흐림)은 정했다. 장면마다의 크기·위치·색 값, 카드 수와 배치, 글자 크기, 소리와 화면이 실제로 어떻게 맞는지는 비어 있다. 이 노트는 영상 프레임(1초 간격 20장, 0.5초 간격 40장, 문이 열리는 구간과 휙 돌리기 구간은 0.1초 간격 40장, 원본 크기 12장)을 보고 썼다.
측정 · 파일 1920x1080 · 60fps · 20.06초. 장면 감지(문턱 0.28)가 잡은 컷은 0번이다. 0.5초마다 움직임 세기의 평균은 9.4 다. 큰 값은 4.0초(89.0, 단추에서 원이 열림), 11.5초(22.9, 가운데 카드가 휴대폰이 됨), 8.5초(20.5, 회전목마 등장), 10.0초(17.7), 5.0초(17.2, 훑는 선)다. 거의 멈춘 구간(1 미만)은 1.0초, 2.5~3.0초, 18.5~19.0초다. 색 값은 9x9 화소 평균으로 잰 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. BPM 120.2(박 0.5초, 마디 2.0초). 마디 첫 박은 0.04초부터 2.0초 간격(0.04, 2.04 … 18.05)이다. 0.06초에 이 영상에서 가장 센 타격(1.00, 킥)이 있다. 0~9.0초에는 짧은 무음(-18dB 아래)이 11곳 있고 음량이 -16~-21dB 다. 9.04초(킥) 뒤로는 무음이 없고 음량이 -13~-17dB 로 오른다. 화면의 "열림"은 4.1초지만, 소리가 꽉 차는 곳은 회전목마 장면(9~12초)이다. 킥은 7.05, 9.04, 10.30, 11.04, 18.80, 19.04초다. 19.56초부터 끝까지 무음이다.

## 1. 본질

- 두 세계로 나뉜다. 앞 4초는 밝은 크림색(가운데 #F5F3EF 근처, 모서리에 살구색 번짐 #F5E8E1 근처), 뒤 16초는 거의 검정(#0B0B0B 근처, 아래 모서리에 붉은 기운 #180E0D 근처)이다. 둘 사이를 단추에서 열리는 원 하나가 잇는다.
- 포인트 색은 주홍 하나(#FD6744 ~ #FE5B35 근처)다. 첫 문장의 강조 낱말 상자, 입력칸 테두리, 순위 번호, 결과 그래프, 마지막 띠 낱말, 로고 아이콘에만 쓴다.
- 실사 세로 영상이 주재료다. 18개(벽)와 약 9개(회전목마)가 동시에 재생된다. 모든 카드가 움직이는 영상이다. 빈 자리 카드가 없다.
- 장면마다 생각 하나다. 화면에 동시에 있는 글자는 한 묶음(문장 2줄, 순위 3줄, 숫자 1개, 낱말 1개)뿐이다.
- 3D 는 카드 배치에만 쓴다. 원근이 있는 벽, 원통 위에 늘어선 카드, 바닥 반사, 뒤집히는 패널.
- 아닌 것 · 하드 컷, 화면 흔들림이나 번쩍임 같은 자극 효과(원래 글이 금지한 효과는 화면에 하나도 없다), 사진 배경, 자리만 채운 빈 카드, 화면 글의 마침표.

## 3. 움직임

- 카메라 언어는 하나다. 앞으로 다가가며 다음 장면으로 들어간다(3.6초 단추, 6.0초 고른 카드, 11.7초 가운데 카드). 뒤로 물러나는 곳이 없다.
- 낱말 등장 · 마스크 선 아래에서 0.25~0.3초에 올라온다. 낱말 사이 0.5초(박 하나).
- 원통 회전목마 · 카드가 같은 반지름의 원통 위에 고른 간격으로 선다. 가장자리 카드는 좁게 보이고 어둡다. 바닥에 세로 길이의 약 40% 만큼 흐린 반사가 있다. 휙 돌리기는 0.6초에 약 1/3 바퀴(눈대중)를 돈다.
- 벽 · 카드마다 기울기가 2~6°(눈대중) 다르다. 훑는 선이 지나간 뒤 고른 3개가 앞으로 약 10% 커진다.
- 큰 숫자 · 아래에서 밀고 올라오는 이동과 숫자 세기가 같이 간다. 앞 숫자는 위로 밀려나며 흐려진다.
- 띠 · 위아래로 이어진 낱말 줄이 한 칸씩 굴러 올라간다. 다음 낱말이 아래에 투명도 약 20% 로 미리 보인다.
- 움직임 흐림이 모든 빠른 이동에 있다(10.6~10.8초 휙 돌리기, 14.5초와 15.5초 숫자 밀기, 16.5초 띠).
- 휴대폰 속 영상은 실제로 재생된다. 패널 뒤집기는 세로축 회전 180° 를 약 0.4초에 한다.

## 4. 전환

- 하드 컷이 없다. 장면 사이는 확대 진입, 원 열림, 밀어내기, 같은 물체의 변신이다.
- 원 열림(4.1~4.3초) · 단추 크기의 원이 0.2초 만에 화면 대각선 밖까지 커진다. 원 안은 다음 장면이다. 밝은 세계 → 어두운 세계의 문이다.
- 맞춤 컷 셋 · 둘째 줄의 강조 낱말 → 앱 창(2.4초), 회전목마의 가운데 카드 → 휴대폰(11.8초), 결과 패널의 숫자 → 큰 숫자(14.4초). 앞 장면의 한 요소가 다음 장면의 주인공 자리로 간다.
- 밀어내기 · 순위 문장 → 회전목마(8.0~8.3초), 숫자 사이(14.5, 15.5초), 띠 낱말 사이.
- 장면 경계는 마디 첫 박(2.04초 간격)에 있다. 4.1초 원 열림은 마디 첫 박 4.04초 직후다.

## 5. 타이포

- 고딕 한 계열, 굵게 쓰고 자간이 좁다. 모두 소문자이고 마침표가 없다.
- 첫 문장 · 두 줄, 줄마다 올림 글자부터 내림 글자까지 약 105px(9.7%). 줄 간격 약 144px.
- 앱 창 · 제목 약 30px(2.8%, 눈대중), 입력 글은 고정폭 약 18px, 메뉴 줄 약 14px.
- 순위 문장 · 흰색, 올림부터 내림까지 51px(4.7%). 머리글은 자간이 넓은 회색 작은 대문자 약 12px(눈대중).
- 큰 숫자 · 216px(20%), 흰색 굵게, 아래 설명 회색 약 30px.
- 띠 낱말 · 165px(15%), 셋째 낱말만 주홍(#FE5B35).
- 로고 이름 · 흰색 굵게, 아이콘과 같은 높이(약 120px).

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 10.2~11.9초. 어두운 바닥 위 원통에 세로 영상 카드 약 9장(가운데 216x390px, 화면 11%x36%, 묶음 가로 8–92%)이 늘어서 바닥에 반사되고, 0.6초 휙 돌리기로 카드가 가로 띠처럼 번졌다가 멈추고, 가운데 카드가 앞으로 나와 0.2초 만에 휴대폰 화면이 된다. 카드가 평면 격자이거나 반사가 없거나 가운데 카드가 휴대폰으로 이어지지 않으면 이 영상이 아니다.
- 12초 판 압축 예 · 0~1.5초 첫 문장(낱말 3개), 1.5~3.0초 앱 창 + 주소 입력 + 단추, 3.0~3.5초 원 열림, 3.5~5.0초 영상 벽 + 훑는 선 + 고른 3개, 5.0~7.5초 회전목마 → 휙 → 휴대폰, 7.5~9.0초 휴대폰 + 결과 패널, 9.0~10.5초 큰 숫자 1개, 10.5~12.0초 로고. 순위 문장, 숫자 2개, 세 낱말 띠를 뺀다.
- 밝은 입력 화면 → 어두운 결과 무대의 두 세계 구성. "입력은 간단, 결과는 풍성"을 색으로 나눈다.
- 2초 한 마디에 장면 하나. 10마디 = 10장면이라 길이 계산이 쉽다.
- 맞춤 컷. 앞 장면의 요소 하나(강조 낱말, 가운데 카드, 숫자)가 다음 장면의 주인공이 된다.
- 결과물 수를 세는 머리글 숫자(0 → 24)와 생성 완료 초록 점. 처리 과정을 기다림 없이 보여 준다.
- 뒤집히는 패널. 설정 → 결과를 한 패널의 앞뒷면으로 보여 준다.

## 7. 함정

- 화면의 첫 문장, 앱 이름과 로고, 입력한 주소, 순위 문장, 점수, 지표 숫자, 띠 낱말, 마지막 한 줄은 원작의 것이다. 옮기지 않는다. 역할(문제 제기 문장, 서비스 이름, 입력값, 생성 결과 문장, 성과 숫자, 동사 세 개)만 가져온다.
- 세로 영상 27개 안팎에 실존 인물의 얼굴이 나온다. 쓰지 않는다. 사용자가 권리를 가진 영상만 쓴다. 없으면 아래 표의 대체 방법을 쓴다.
- 설정 패널의 토글 이름과 휴대폰 화면 틀은 실존 광고 플랫폼과 짧은 영상 앱을 닮았다. 플랫폼 이름과 화면 틀을 그리지 않는다. 토글은 "채널 1·2"처럼 일반 역할로 쓴다.
- 영상 카드 수가 많아 촬영 부담이 크다. 18개 벽은 같은 영상 6개를 위치만 바꿔 세 번 쓰면 반복이 보인다. 최소 12개의 서로 다른 영상이 필요하다.
- 소리와 화면의 고조가 어긋나 있다. 원 열림(4.1초)에 큰 타격이 없다(4.54초 세기 0.38). 음악을 직접 고르면 원 열림 시각에 음악의 고조를 둔다.
- `preserve-3d` 요소에 투명도나 필터를 주면 평면이 되고 앞뒤 면이 다 보인다. 뒤집히는 패널은 감싼 부모의 투명도만 바꾼다.
- 맞춤 컷의 위치는 실행 중에 요소의 화면 좌표를 재서 맞춘다. 고정 좌표를 쓰면 글꼴이 바뀔 때 어긋난다.
- 한국어로 옮길 때 · 첫 문장은 어절 단위로 박마다 붙인다(어절 3~4개). 한국어 글자는 140px 규칙이 있어 띠 낱말 165px 를 그대로 쓸 수 없다. 띠 낱말은 Pretendard SemiBold 140px, 큰 숫자는 InterVariable 굵게 216px 로 둔다(숫자는 라틴 글꼴이라 규칙 밖이다).

## 8. 코드로 재현 못 하는 요소와 대체 방법

글꼴은 Pretendard Regular·SemiBold 뿐이다(숫자·라틴은 InterVariable 도 있다). 값은 1920x1080 기준이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 실사 세로 영상 27개 | 촬영본과 초상권 | 사용자의 영상이 없으면 AI 일러스트(codex-image)로 세로 그림 12장을 그린다. 글자·로고 없이, 손에 든 물건·부엌·창가 같은 장면, 얼굴은 화면 밖이나 뒷모습으로. 그림마다 2초에 1.0 → 1.06배 확대와 4px 좌우 흔들림을 준다 | 사람이 직접 찍은 영상의 생동감 |
| 영상 벽 18개(원근 기울기) | 없다. CSS 3D 로 된다 | 부모에 `perspective: 1600px`. 카드 150x280px, 열 간격 200px, 줄 간격 300px. 카드마다 `rotateY` −6~6°, `rotateZ` −2~2° 를 씨앗 난수로 준다. 훑는 선은 폭 3px 흰 세로 막대 + 좌우 40px 흐림, 0.2초에 가로 18% → 83% | 없음 |
| 원통 회전목마 + 바닥 반사 | 원통 배치와 반사 | three.js. 카드 12장을 반지름 4.2 원통에 30° 간격으로 세운다(`PlaneGeometry` 1.1x2.0, 영상은 `VideoTexture` 대신 낱장 그림을 매 프레임 바꾼 `CanvasTexture`). 반사는 `LOOKS.mirror(cards, 0)` 후 `m.sync()`, 위에 검은 반투명 바닥(투명도 0.75). 카메라 높이는 카드 가운데보다 약 0.3 위 | 반사의 미세한 흔들림 |
| 휙 돌리기 움직임 흐림 | 하위 프레임 합성 기능이 없다 | 회전 속도가 큰 0.3초 동안 원통을 이전 각도 3개(1/240초 간격)로 더 그려 투명도 0.3 씩 겹친다. 또는 `LOOKS.post` 의 결과에 가로 방향만 흐리는 canvas 처리(10~30px)를 속도에 비례해 건다 | 진짜 셔터 흐림의 고른 결 |
| 단추에서 열리는 원 | 없다. CSS 로 된다 | 다음 장면 층에 `clip-path: circle(r at x y)`. 중심은 단추의 화면 좌표, r 은 0.2초에 30px → 화면 대각선(2203px) + 50px. 가장자리에 회색 테 2겹(폭 6px, rgba(255,255,255,.25)) | 없음 |
| 뒤집히는 결과 패널 | 없다. CSS 3D 로 된다 | 패널 부모에 `perspective: 1400px`, 앞뒤 면 `backface-visibility: hidden`, `rotateY` 0 → 180° 0.4초. 감싼 부모만 투명도를 바꾼다 | 없음 |
| 숫자 밀기 + 세기 | 없다 | 숫자 줄을 `translateY` 120px → 0 으로 0.3초, 값은 같은 0.3초에 0 → 목표로 세고 소수 한 자리. 앞 숫자는 −120px 로 밀리며 투명도 1 → 0 | 없음 |
| 휴대폰 틀 | 실존 기기 모양 | 둥근 사각(390x790px, 반지름 56px, 테 10px #1A1A1A)만 그린다. 위쪽 구멍·단추는 그리지 않는다 | 없음 |
