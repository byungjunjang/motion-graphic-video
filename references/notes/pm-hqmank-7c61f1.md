# 개발 도구 런치 · 굵은 대문자와 커서 시연 — 분석 노트

> 명령줄 도구(CLI)를 소개하는 23초 런치 영상(launch video). 밝은 회백색 바탕에 굵고 폭이 넓은 대문자 산세리프(bold grotesque)와 주황 한 색만 쓴다. 표어 → 3단계 도식 → 터미널(terminal) 타이핑 → 브라우저 목업(browser mockup) 안의 커서 시연 → 한 낱말 카드 3장 → 복사 단추가 있는 끝 카드 순서다. 커서 클릭과 낱말 카드의 컷이 음악의 큰 타격에 맞는다. 개발 도구·오픈소스·API 소개에 맞는다. 키네틱 타이포(kinetic typography) + 제품 UI 시연.

출처 · pm:hqmank-7c61f1. 작성자의 프롬프트는 201자다. 프로젝트 이름, 표어, 길이, 쓰임(저장소 소개 문서의 대표 영상)만 있다. 화면 지시는 없다. 이 노트는 영상 프레임(0.5초 간격 46장)을 보고 썼다. 구간 경계와 클릭 시각은 0.1~0.2초 간격 프레임으로 다시 확인했다.
측정 · 파일 1920x1080 · 60fps · 23.0초. 하드 컷은 끝부분에 2번(17.2초, 18.1초)뿐이다. 나머지 장면은 밀기·쓸기·크기 변화로 이어진다. 움직임이 큰 순간은 6.6초, 10.0초, 16.3~19.8초다. 7.1~8.0초는 거의 정지다(작은 타이핑만 있다). 색 값은 화소를 16단계로 묶어 잰 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. BPM 120(마디 2.0초). 큰 타격 23번. 하드 컷 2번이 모두 큰 타격 ±0.1초 안에 있다. 16.8~17.3초와 17.7~18.2초는 무음이고, 무음 바로 뒤에 타격과 컷이 온다. 8.9~10.1초에도 짧은 무음이 4번 있다.

## 1. 본질

- 색은 세 가지다. 따뜻한 회백색 바탕(#E8E8E0 근처), 거의 검정(#181818), 주황(#E86838) 하나. 주황은 강조 낱말, 하이픈, 단추, 클릭 파동, 전환 면에만 쓴다.
- 글자가 주인이다. 굵은 대문자 한 줄이 화면 너비의 절반 이상을 차지한다. 그림·일러스트·사진이 없다.
- UI 는 실제 화면 캡처가 아니다. 가상의 사이트를 단순한 블록으로 다시 그렸다(제목, 회색 막대, 주황 그라데이션 카드, 3열 가격표).
- 커서가 이야기를 끈다. 클릭마다 주황 점선 원이 퍼진다. 클릭한 요소에는 주황 테두리와 작은 꼬리표가 붙는다.
- 화면 네 모서리에 아주 작은 고정폭(monospace) 글자가 있다. 왼쪽 위는 프로젝트 이름, 오른쪽 위는 분류, 왼쪽 아래는 장 번호와 장 이름, 오른쪽 아래는 타임코드다. 맨 아래에 가는 주황 진행 막대가 영상 길이만큼 자란다.
- 아닌 것 · 3D, 입자, 그라데이션 배경, 캐릭터, 여러 포인트 색, 화면 캡처 영상.

## 3. 움직임

- 글자는 마스크 등장 한 가지다. 표어는 줄 단위로, 워드마크는 글자 단위로 아래에서 올라온다. 튀지 않는다.
- 간격이 일정하다. 표어 세 줄과 알약 세 개가 모두 0.4초 간격으로 나온다.
- 커서는 곡선으로 움직이고 클릭 직전에 멈춘다. 클릭 파동은 주황 점선 원이 0.3초쯤 퍼졌다 사라진다.
- 타이핑은 일정한 속도다. 타이핑 구간(7.3~9.9초)에는 다른 움직임이 없다.
- 큰 움직임은 다섯 번뿐이다. 주황 쓸기(6.6초), 터미널이 패널로 줄어드는 배치 변화(10.0초), 낱말 카드 3장(16.3~18.1초), 주황 쓸기(19.0초), 끝 카드 조립(19.2~19.8초). 그 사이는 조용하다.
- 기록 패널의 줄은 위에서 아래로 한 줄씩 쌓인다. 방금 나온 줄만 밝고 앞줄은 어두워진다.

## 4. 전환

- 표어 → 워드마크 · 같은 바탕에서 글자만 교체한다. 표어가 위로 나가고 0.3초 뒤에 워드마크가 올라온다.
- 도식 → 터미널 · 주황 면이 아래에서 위로 쓸고 지나간다. 영상 전체에서 두 번만 쓴다(여기와 끝 카드 앞).
- 터미널 → 시연 · 컷이 아니다. 터미널 카드가 줄어들어 오른쪽 패널로 자리를 옮긴다. 같은 물체가 다음 장면의 일부가 된다.
- 시연 안의 화면 교체 · 약 0.2초의 교차 디졸브(cross dissolve)다.
- 시연 → 낱말 카드 · 검은 면과 주황 면이 왼쪽에서 빠르게 밀고 들어온다.
- 낱말 카드끼리 · 하드 컷 2번. 컷마다 바탕색이 바뀐다(주황 → 검정 → 밝은색). 두 컷 모두 무음 뒤 큰 타격에 맞춘다.
- 낱말 카드 → 끝 카드 · 주황 면 쓸기.

## 5. 타이포

- 제목은 굵고 폭이 넓은 산세리프 대문자다. 자간이 좁다. 낱말을 잇는 하이픈과 마침표를 주황으로 칠한다.
- 표어 한 줄은 보통 굵기의 산세리프, 크기는 제목의 약 1/4 이다. 마지막 마디만 주황이다.
- 라벨·터미널·모서리 글자는 고정폭이다. 대문자와 넓은 자간을 쓴다. 크기가 아주 작다.
- 강조는 색 하나로 한다. 밑줄, 기울임, 그림자를 쓰지 않는다.
- 낱말 카드는 한 낱말 + 마침표다. 낱말 위에 작은 아이콘이나 기호 하나를 둔다.

## 6. 가져올 것

- "표어 → 입력 3단계 도식 → 명령 타이핑 → 실제 동작 시연 → 장점 낱말 3장 → 설치 명령" 순서. 개발 도구를 20초대에 소개하는 뼈대로 쓸 수 있다.
- 터미널 카드가 줄어들어 시연 화면의 기록 패널이 되는 전환.
- 커서 클릭 = 큰 타격. 클릭 4번(1.9초, 12.6초, 14.7초, 21.3초)이 모두 큰 타격 ±0.1초 안에 있다. 클릭 파동, 꼬리표, 패널 기록 한 줄이 같은 순간에 나온다.
- 낱말 카드 앞의 짧은 무음. 무음 뒤 타격과 컷이 함께 와서 낱말이 세게 읽힌다.
- 끝 카드의 복사 단추 클릭. 마지막 동작이 "시청자가 할 일"을 그대로 보여 준다.
- 네 모서리의 장 번호·타임코드와 아래 진행 막대. 장면이 바뀌어도 한 편으로 묶인다.

## 7. 함정

- 화면의 표어, 제품 이름, 명령문은 원작의 것이다. 옮기지 않는다. 역할(표어, 워드마크, 설치 명령)만 가져온다.
- 모서리 글자와 터미널 글자가 아주 작다. 1920x1080 에서도 읽기 어렵다. 읽혀야 하는 글자는 키운다.
- 시연 구간(10.6~16.3초)이 5.7초로 가장 길다. 소개할 대상의 동작이 클릭 두세 번으로 설명되지 않으면 이 구간이 늘어진다.
- 가상의 사이트는 단순한 블록이라서 통한다. 실제 화면 캡처를 넣으면 굵은 글자와 질감이 맞지 않는다.
- 주황 쓸기는 두 번, 바탕색 컷은 두 번뿐이라서 세다. 장면마다 쓰면 효과가 없어진다.
- 한국어 제목은 폭이 넓은 대문자 산세리프의 느낌이 나지 않는다. 굵은 고딕으로 바꾸고 자간과 줄 길이를 다시 잡는다.
