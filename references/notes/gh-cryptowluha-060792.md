# 선에서 완성까지 자라는 주택 모형 — 분석 노트

> 베이지 바탕에서 three.js 주택 모형이 네 단계로 자란다. 짙은 선 스케치 → 흰 무광 매스 → 유리·나무·가구가 들어간 세부 모형 → 해 질 녘 하늘과 실내 조명이 켜진 완성 렌더. 화면 아래 단계 막대 UI 의 점이 19초 동안 왼쪽에서 오른쪽으로 일정하게 움직이고, 왼쪽 아래 단계 번호가 바뀐다. 카메라는 중간에 한 번 크게 돌아 앞면으로 간다. 웹 페이지 화면을 녹화한 영상이다(마우스 커서가 보인다). 건축·인테리어·제품이 "설계에서 완성까지" 가는 과정을 보여 주는 소개에 맞는다. 3D 모형 · 단계 전환 · 와이어프레임에서 렌더로.

출처 · gh:cryptowluha-060792. 작성자의 프롬프트는 약 260자다. 대상(연필 스케치에서 자라는 집), 단계 이름 네 개, 구현 도구(three.js 와 셰이더 언어)만 정했다. 구도, 단계별 재질 값, 카메라, UI, 시각은 없다. 이 노트는 영상 프레임(0.5초 시트 39장, 0.25초 간격 전 프레임 77장, 단계 경계 0.2초 간격 18장, 원본 크기 프레임 5장)을 보고 그 빈칸을 채웠다.
측정 · 파일 1920x1272(가로:세로 1.51:1) · 60fps · 19.1초. 컷 0개. 0.5초마다 움직임 세기의 평균은 7.0 이다. 큰 구간은 카메라가 도는 8.0~12.0초(8.8~16.7), 조명이 바뀌는 14.5초(17.9), 16.5~17.0초(12.5~14.8)다. 거의 정지는 5.0초(0.4)와 18.5초(0.7)다. 진행 막대 점의 위치를 0.25초마다 쟀다. 색 값은 프레임에서 잰 근삿값이다.
소리 · 파일에 소리가 없다.

## 1. 본질

- 바탕은 연한 회베이지다(위 #D1CFCD 근처, 땅 #D6D2CA 근처). 4단계에서 위쪽이 해 질 녘 회청색(#8FA1B0 근처), 양옆 먼 바탕이 짙은 남회색(#3B4550 근처)으로 바뀐다.
- 모형은 두 덩어리 집이다. 2층 상자(왼쪽 위)와 넓은 1층 유리 거실(오른쪽), 앞에 수영장, 계단, 데크, 나무 4~5그루, 낮은 관목 열. 모형 본체가 화면 가로 15~90%, 세로 13~85% 를 차지한다. 대지 평면은 화면 밖까지 이어진다.
- 네 단계의 재질.
  - 01 선 · 짙은 청록 회색(#2F3B38 근처) 두 겹 윤곽선(굵기 2~3px). 면은 없다. 땅에는 평면도 선, 초록 빗금 식재 칸, 떨리는 손그림 원 나무(초록 회색 가는 선), 연한 주황 치수선이 있다.
  - 02 매스 · 흰 무광(#E8E6E1 근처) 판·벽·기둥. 부드러운 그림자. 선은 옅어진다. 나무는 막대 줄기 + 작은 초록 점.
  - 03 세부 · 유리 판(가는 짙은 회색 틀), 흰 가구 상자, 나무 세로 루버(갈색), 물이 찬 수영장(연한 청록), 진짜 같은 나무(짙은 초록 잎 덩어리).
  - 04 완성 · 해 질 녘. 실내 따뜻한 조명(#F2D9AE 근처), 나무 벽(#9C6A41 근처), 수영장 밝은 청록(#44A0A8 근처)에 수중 조명 반사, 하늘 회청색.
- UI 층(DOM).
  - 왼쪽 위 제목 블록 · x 3~25%, y 4~15%. 작은 대문자 머리줄(글자 높이 1.3%), 세리프 큰 제목(대문자 높이 약 4.7%, 마지막 단어 이탤릭), 작은 부제 한 줄(1.4%).
  - 오른쪽 위 아이콘 알약 · x 81~93%, y 4~10%. 보기 전환 아이콘 3개. 4단계 직전(약 12초)에 오른쪽에 짙은 원 버튼(해 아이콘)이 하나 더 나온다.
  - 왼쪽 아래 단계 번호 · x 3~6%, y 75~79%. 이탤릭 세리프 두 자리 숫자(높이 약 3.5%, 녹 붉은 #A0503C 근처). 옆에 짧은 문장 한 줄과 가운데 점으로 나눈 낱말 세 개.
  - 오른쪽 아래 작은 대문자 대상 이름(1.3%)과 가는 밑선.
  - 아래 단계 막대 판 · x 19~81%, y 83~97%, 연한 크림 반투명 판(#EFEDE7 근처, 모서리 둥글기 약 12px). 왼쪽에 짙은 원 재생·일시정지 버튼(지름 68px, #2B3532 근처). 단계 이름 네 개(번호 + 이름)가 막대 위 27%·40%·53.5%·67%(화면 가로) 자리에 놓인다. 지금 단계는 번호가 녹 붉은색, 이름이 짙은 색이다. 막대는 x 27~78.5%(폭 988px), 지나온 부분이 녹 붉은 선, 점 지름 약 14px.
  - 맨 아래 가운데 작은 대문자 조작 안내 한 줄(1.2%).
- 아닌 것 · 컷, 빠른 카메라, 어두운 바탕(4단계 전까지), 화면 가득한 글자, 입자 효과.

## 3. 움직임

- 차오르기 · 매스 단계의 판은 아래에서 위로 높이가 0 → 1 로 자란다(0.5~0.8초, ease-out). 판 사이 간격 0.2~0.4초. 위층이 아래층보다 늦다.
- 선 사라지기 · 면이 찬 판의 선은 0.5초에 불투명도 1 → 0.2 로 옅어진다. 3단계에서는 거의 보이지 않는다.
- 세부 넣기 · 유리 판과 가구는 크기 변화 없이 불투명도로 0.3~0.5초에 나타난다.
- 나무 자라기 · 막대 줄기 → 잎 덩어리가 크기 0 → 1 로 자란다(1초 안팎).
- 색·조명 전환 · 12~17초 약 5초 동안 바탕·하늘·조명이 이어서 바뀐다. 갑자기 바뀌지 않는다. 바탕 위쪽 밝기가 209 → 143 으로, 양옆이 214 → 59 로 내려간다.
- 카메라 · 0~8초는 거의 고정이고, 8~12초에 한 번 크게 돈다. 나머지는 아주 느린 흐름이다. 카메라가 도는 동안 단계 재질도 바뀐다. 두 변화가 겹쳐 3단계가 가장 바쁘다.
- 진행 막대 점은 일정 속도다. 단계 경계에서 멈추지 않는다.
- 마우스 커서가 화면 오른쪽 아래(x≈83%, y≈65%)에 거의 그대로 있다. 사람이 끌어서 돌린 것이 아니라 자동 재생으로 보인다(추정).

## 4. 전환

- 단계 사이에 컷이 없다. 한 모형이 재질과 부품을 바꾸며 이어진다.
- 단계 번호와 문장이 바뀌는 순간(1.5, 7.75, 14.0초)이 단계 경계다. 바뀔 때 0.3초 정도 흐려졌다 다시 선명해진다.
- 막대의 지금 단계 표시가 같은 순간에 다음 이름으로 옮겨 간다.
- 단계 하나의 길이는 6.25초다(02, 03). 01 은 앞이 잘려 1.5초만 보이고, 04 는 5.1초(그중 끝 1.85초 정지)다. 막대 점의 속도로 거꾸로 셈하면 0% 는 약 −1.9초다. 원래 한 바퀴는 약 19초 이상이고 이 영상은 01 단계 중간부터 녹화한 것으로 보인다(추정).

## 5. 타이포

- 제목 · 세리프 글꼴, 대문자 높이 약 4.7%(60px), 마지막 단어 이탤릭, 마침표로 끝난다. 짙은 회색(#2E2E2C 근처). 4단계에서 흰색.
- 머리줄·부제·조작 안내·대상 이름 · 산세리프 작은 대문자, 자간 넓게(약 0.2em), 글자 높이 1.2~1.4%. 회색.
- 단계 번호 · 이탤릭 세리프, 높이 약 3.5%(45px), 녹 붉은색.
- 단계 문장 · 산세리프 1.6%, 낱말 셋 줄 1.3%.
- 막대 판 안 · 번호 1.0%, 단계 이름 1.4%.
- 글자는 모두 작다. 화면의 주인공은 모형이다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 7.75~12.0초. 흰 무광 매스 모형(화면 가로 15~90%, 세로 13~85%)에 유리 판·가구·나무가 끼워지는 동안 카메라가 약 45° 돌아 앞면으로 가고, 아래 단계 막대 판(x 19~81%, y 83~97%)의 점이 51% 를 지나며 왼쪽 아래 단계 번호가 03 으로 바뀐다. 모형이 화면 높이 60% 아래로 작아지거나 단계 막대가 빠지면 이 영상이 아니다.
- 12초 판 압축 예 · 네 단계를 각 2.6초로 두고 끝 1.6초 정지. 0.0~2.6초 선(윤곽이 그려지며 등장) → 2.6~5.2초 매스(판이 아래부터 차오름, 판마다 0.4초) → 5.2~7.8초 세부(유리·가구, 카메라가 30° 돈다) → 7.8~10.4초 완성(하늘·조명 전환 2초) → 10.4~12.0초 정지. 진행 막대 점은 0~10.4초에 0 → 100% 일정 속도. 4단계 직전의 버튼 등장과 조작 안내 줄은 뺀다.
- 19초 판 · 원본 길이를 지킨다면 단계당 4.5초(01 은 처음부터 보여 준다) + 끝 정지 1초로 둔다. 01 4.5 → 02 4.5 → 03 4.5 → 04 4.5 → 정지 1.1초.
- 한 사물이 같은 자리에서 재질만 바꾸며 자란다. 컷을 넣지 않는다.
- 단계 번호 + 진행 막대로 지금 어디인지 늘 보여 준다.
- 마지막 단계에서만 바탕을 어둡게 하고 조명을 켠다. 앞 단계는 모두 밝은 무채색이다.
- 카메라는 한 번만 크게 돈다. 3단계에 둔다.

## 7. 함정

- 화면의 제목, 부제, 단계 문장, 대상 이름, 조작 안내는 원작의 것이다. 옮기지 않는다. 역할(제목 한 줄, 단계 문장 한 줄, 단계 이름 네 개)만 가져온다.
- 마우스 커서가 찍혀 있다. 화면 녹화의 흔적이다. 만들 때 넣지 않는다.
- 세로가 긴 비율(1.51:1)이다. 16:9(1920x1080)로 옮기면 세로 192px 가 모자란다.
  - 가운데를 그대로 잘라 내지 않는다. 위 96px 를 자르면 제목 머리줄이, 아래 96px 를 자르면 조작 안내와 막대 판 아래 여백이 잘린다.
  - UI 를 다시 놓는다 · 제목 블록 y 5~14%(54~151px), 오른쪽 위 알약 y 4~11%, 단계 번호 y 72~76%, 막대 판 높이 140px(원본 172px), y 84~97%(907~1047px), 조작 안내 줄은 뺀다.
  - 모형 본체를 세로 12~80% 에 맞춘다. 원본보다 0.85배 작게 두거나 카메라 시야각을 원본보다 약 8% 넓힌다. 가로는 15~90% 를 지킨다.
- 실사 수준의 디테일(가구 수십 개, 커튼, 잎 수천 장, 반사·굴절 물)을 그대로 따라가면 렌더가 느리고 결정성이 깨지기 쉽다. 단순한 모형 범위를 숫자로 정한다(아래 표). 집 대신 단순한 기하형 제품(예 · 상자 몸체에 둥근 판과 원통 몇 개로 된 가전, 가구 한 점)으로 바꾸면 범위가 더 작아진다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 모형은 three.js(vendor/three), 재질·후처리는 looks.js, UI 는 DOM 층으로 만든다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 셰이더 언어(TSL) 구현 | 내장 three.js 는 IIFE 판이라 TSL 노드 재질을 쓰지 않는다고 본다(확인하지 않았다) | 단계 전환을 재질 uniform 으로 한다. 차오르기는 `material.clippingPlanes` 에 y 평면 하나를 두고 높이를 0 → 판 높이로 올린다(`renderer.localClippingEnabled = true`). 선 옅어지기는 `LineBasicMaterial.opacity` | 셰이더 안에서 한 번에 섞는 부드러운 경계 |
| 연필 스케치 선의 손맛 | 실제 연필 결 | `EdgesGeometry(geo, 30)` 를 두 벌 만들어 하나를 0.6% 크게 겹친다(두 겹 선). 식재 원과 나무 윤곽은 canvas 로 `HAND.ink(ctx, P, { w: 2, color: '#6E7A55', key, B: 0 })` 로 그려 땅 텍스처로 붙인다 | 연필 농담의 차이 |
| 흰 무광 매스의 부드러운 그림자 | 전역 조명(GI) | `LOOKS.env(gl, 'studio')` 환경맵 + 해 한 개의 그림자(`PCFSoftShadowMap`, 크기 2048, 반지름 4). `LOOKS.clay('#E8E6E1', { })` 로 무광과 가장자리 빛. 접촉 그림자는 바닥 아래 어두운 원 텍스처(불투명도 0.25)로 보탠다 | 구석에 고이는 간접광 |
| 유리·물의 반사와 굴절 | 실시간 굴절이 무겁다 | 유리는 `MeshPhysicalMaterial` 투명도 0.25, 거칠기 0.05, 환경맵 반사만. 물은 평면 + 청록 #44A0A8 + 환경맵 + 4단계에서 밝은 점 3개(수중 조명)를 `LOOKS.post` 의 bloom(세기 0.6, threshold 0.85)으로 번지게 한다 | 굴절로 비치는 바닥 |
| 실사 나무·풀 | 잎 수천 장 | 이십면체(세분 1) 잎 덩어리 2~3개 + 원통 줄기. 잎은 #3E5A3A 무광, 정점 색으로 밝기 ±10%. 갈대 같은 풀은 빼거나 가는 원뿔 InstancedMesh 40개 | 잎의 결과 투과광 |
| 해 질 녘 하늘과 조명 전환 | 하늘 산란 | `LOOKS.dome({ base: ['#3B4550', '#8FA1B0'] })` 를 4단계에 쓰고, 그 전에는 `['#D6D2CA', '#D1CFCD']`. 두 색을 seek 에서 t 로 섞는다(5초). 실내 점광 3~4개 세기 0 → 1.5, 색 #F2D9AE. `post` 의 `exposure` 1.0 → 0.85, `tone: 'aces'` | 대기의 깊이 |
| 실사 가구 | 모델 수가 많다 | 가구는 둥근 판(`LOOKS.slab`) 6~8개로만 만든다(소파 2, 탁자 1, 의자 2, 조리대 1). 3단계에서 흰색, 4단계에서 #C9C3B8 와 #8A5A3A 로 바꾼다 | 실내의 생활감 |
| 카메라 회전 | 없다 | `LOOKS.fly(cam, [{ at: [0, 5.2], pos: A, look: C, drift: 0.02 }, { at: [6.5, 12], pos: B, look: C, drift: 0.01 }], t)`. A → B 는 모형 중심 둘레 yaw 40~45°, 높이각 20° → 15° | 손으로 돌린 듯한 불규칙함(원본도 자동이라 잃는 것은 적다) |
| 세리프·이탤릭 제목과 단계 번호 | 세리프 글꼴이 없다 | 제목은 Pretendard SemiBold 52px, 한 단어만 Pretendard Regular 로 두어 굵기 대비로 강조한다. 단계 번호는 InterVariable 300 굵기 48px, `font-style: oblique 10deg`, #A0503C. 머리줄·안내는 Pretendard Regular 16px, 자간 0.2em | 세리프의 건축 잡지 느낌 |
| 화면 녹화의 마우스 커서 | 녹화 흔적 | 넣지 않는다 | 없음 |
