# 등각 인포그래픽 · 떠 있는 판 위의 공급망 — 분석 노트

> 크림색 바탕에 떠 있는 등각 무대 한 장 위의 59초 영상. 손바닥에 열매 하나가 떨어지는 극단적 접사에서 시작해, 산비탈 농장, 말리는 평상, 트럭, 항구 크레인, 바다를 건너는 배를 차례로 따라간다. 배 위 컨테이너 하나로 세 번 파고들어 수십만 알 가운데 한 알을 찾고, 색이 빠진 채 침묵하다가 한 번에 튀어 나온다. 볶는 곳과 가게를 지나 같은 구도의 다른 손으로 돌아오고, 끝에 판 전체와 숫자 이름표가 보인다. 공정 설명, 공급망, 연차 보고, 한 물건이 거치는 거리와 숫자를 보여 주는 영상에 맞는다.

## 3. 움직임

- 원래 글의 움직임 수치(단면 0.3초 + 0.35초, 그림 숫자 튀어나옴, 쌓임의 가속, 착지 찌그러짐 18%, 경로를 따르는 탈것)는 화면과 맞다.
- 영상에서 확인한 점 · 이 영상은 거의 늘 움직인다. 4개 측정 영상 중 평균 움직임 세기가 가장 높다(11.1). 정지는 정보 창이 열리는 자리(7~10초, 18~20초)와 손 장면(50~51초)뿐이다.
- 카메라 확대는 로그 비례로 움직여 큰 물러남(35배, 470배)도 1~2초 안에 끝난다. 그 동안 움직임 세기가 24~41 로 치솟는다.
- 같은 크기의 작은 사물(나무 수백 그루, 도시 블록 수백 개, 컨테이너 수십 개)이 장면마다 화면을 채운다. 큰 단색 면 + 작은 반복 사물이 화면의 질감이다.
- 숫자 이름표는 늘 지시선이 먼저 자라고 숫자가 그 끝에서 올라간다.

## 4. 전환

- 원래 글의 전환(따라가기, 원형 확대 창, 겹친 단면 파고들기, 빠른 로그 물러남, 같은 구도의 메아리)은 화면과 맞다. 컷이 없다.
- 영상에서 확인한 점 · 첫 장면과 끝에서 둘째 장면이 같은 구도다. 처음은 초록 바탕 위 손바닥과 열매, 끝은 갈색 바탕 위 손과 잔이다. 지시선과 거리 이름표 자리도 같다(손 오른쪽 위, 가로 약 50~60%, 세로 약 30%).
- 접사 → 넓은 장면 전환 다음에는 1~3초 정지가 거의 늘 온다. 눈이 새 장소를 읽을 시간이다.

## 5. 타이포

- 이름표 · 작은 대문자 머리말(글자 높이 약 1%)과 그 아래 큰 숫자(약 2.5~3.5%, 약 30~38px)와 작은 단위. 가는 지시선(굵기 약 1.5px) 끝에 붙는다. 짙은 회색.
- 제목 판 · 등각으로 누운 흰 판 위 굵은 빨강 글자. 판이 땅 위에 비스듬히 놓여 글자도 30° 로 기운다. 판 길이 화면 가로의 약 60%.
- 자막 · 아래 가운데에서 조금 왼쪽(세로 약 92~96%), 흰 판 위 한 줄, 글자 높이 약 1.6%, 앞에 붉은 점. 원래 글대로 아래 약 170px 는 자막 자리로 비워 둔다.
- 끝 카드 · 흰 판에 굵은 제목 한 줄, 작은 부제, 큰 거리 숫자, 단계별 길이를 보여 주는 가로 막대 한 줄, 작은 제작 표기.
- 손 장면의 큰 숫자 · 높이 약 5%(약 55px), 지시선 끝.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 28.0~34.0초의 "배 위 컨테이너 하나를 점선 고리로 짚고, 0.9초 · 0.6초 · 0.6초로 점점 빠르게 세 번 파고들어(컨테이너 벽 → 상자 속 → 생두 수백 알) 한 알만 연두로 남기고 나머지를 회색으로 뺀 뒤, 무음 속 느린 밀기로 한 알을 화면 높이의 21% 까지 키웠다가 한 번에 튀어 나오는" 6초다. 점점 빨라지는 세 번과 색이 빠진 침묵이 빠지면 이 영상이 아니다.
- 12초 판 압축 예 · 0~1.5초 손바닥에 열매가 떨어진다(접사), 1.5~2.5초 로그 물러남으로 농장과 제목 판, 2.5~3.5초 말리는 평상과 원형 확대 창 하나, 3.5~4.5초 트럭을 따라가 항구, 4.5~5.5초 컨테이너가 박마다 → 물결로 쌓인다, 5.5~6.0초 배가 떠난다, 6.0~9.5초 대표 장면 3.5초(파고들기 셋 1.2초, 색 빠짐과 느린 밀기 1.6초, 튀어 나오기 0.7초), 9.5~10.5초 같은 구도의 다른 손과 잔, 끝 숫자, 10.5~12.0초 판 전체로 물러나 이름표와 끝 카드. 볶는 곳, 가게 안, 기계 접사는 뺀다.
- 처음과 끝의 손 구도를 같게 맞춘다.
- 판 전체로 끝내고, 끝 카드는 판 옆 빈 크림 모서리에 둔다.

## 7. 함정

- 제목 판, 자막, 이름표 낱말, 끝 카드 문장과 제작 표기는 원작의 것이다. 옮기지 않는다. 역할(제목 판, 이름표, 한 줄 자막, 끝 카드)만 가져온다. 제작 표기에 실존 회사·도구 이름이 있다. 쓰지 않는다.
- 화면의 거리·일수·개수·온도 숫자는 이 영상의 이야기 숫자다. 우리 영상에는 원문에서 확인한 우리 숫자만 쓴다. 그림 숫자(콩 70개 = 잔 하나처럼)도 우리 숫자에 맞춰 개수를 다시 센다.
- 실존 항구·도시·배·운송 회사의 모양이나 이름을 넣지 않는다. 컨테이너에 글자나 상표를 그리지 않는다.
- 사물이 적으면 장난감 장면이 된다. 넓은 장면에서는 같은 종류의 작은 사물을 100개 이상 둔다(나무, 블록, 컨테이너). 그래야 원본처럼 큰 단색 면 위에 반복 질감이 생긴다.
- 외곽선을 넣거나 면 톤을 넷 이상 쓰면 다른 양식이 된다. 사물마다 윗면·왼면·오른면 세 톤만 쓴다.
- 반투명으로 나타나기를 쓰지 않는다(원래 글의 함정과 같다). 쌓이는 사물은 위에서 떨어져 앉는다.
- 원래 글의 함정 절(면 법선, 그리는 순서, 확대 문턱, 높은 사물이 물러남 중 화면을 쓸고 가는 것)은 그대로 맞다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 무대는 three.js(`vendor/three`) 직교 카메라(`OrthographicCamera`)로 만든다. 카메라 방향은 방위 45°, 높이 35.264° 로 고정하고, 확대는 카메라 `zoom` 을 로그 보간한다(zoom = exp(lerp(ln z0, ln z1, e(t)))). 빛 계산은 쓰지 않고 면마다 색을 직접 준다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 면 세 톤 | 빛 없이 면마다 색이 달라야 한다 | 상자 `BoxGeometry` 의 면마다 `MeshBasicMaterial` 3개(윗면 원색, 왼면 원색 x 0.82, 오른면 원색 x 0.66)를 준다. 땅은 #7EA25A / #67854A / #4E7236 | 거의 없음 |
| 나무·블록·컨테이너 수백 개 | 그리기 호출이 많아진다 | `InstancedMesh` 로 종류별 1개씩 둔다(나무 400, 도시 블록 600, 컨테이너 180). 위치·크기·색은 `LOOKS.rng(seed)` 로 정한다. 나무는 원뿔 + 원기둥 두 가지 모양에 초록 3색(#8ABA72, #7EAE66, #5A7E4E) | 개체마다 다른 손질 |
| 컨테이너 쌓임의 가속 | 박에 맞춘 착지 | 컨테이너마다 착지 시각을 정한다. 18.3~20.4초 박마다 1개, 20.4~21.4초 반 박마다, 21.5~22.2초 물결 4번(물결마다 약 44개). 착지 · 높이 7단위 위에서 0.25초에 떨어져 0.08초 동안 세로 0.82배로 찌그러졌다 돌아오고, 작은 튀기 두 번(높이 0.3, 0.1) | 없음 |
| 겹친 단면 파고들기 | 바깥 껍질이 벗겨지고 안이 보여야 한다 | 단계마다 따로 만든 무대(배 → 컨테이너 안 → 상자 안 → 콩 더미)를 같은 화면 중심에 두고, 확대가 문턱(zoom 각 단계의 약 6배)을 넘을 때 다음 무대로 바꾼다. 바꾸는 순간은 화면 가운데 점선 고리(지름 약 390px)에 맞춘다. 앞 껍질은 법선 방향으로 0.35초 밀어내며 `visible` 을 끈다(반투명 없이). 단면 테두리는 빗금 텍스처 canvas(45°, 간격 8px, #5A4A3A)로 0.15초에 붙인다 | 한 덩어리 장면처럼 이어지는 느낌 |
| 수백 알의 콩 더미와 색 빠짐 | 콩 모양과 쌓인 겹침 | 콩 모양은 납작한 타원체(`SphereGeometry` 를 1 : 0.7 : 0.35 로 늘림) + 가운데 홈 하나를 `InstancedMesh` 600개로 빈틈없이 덮는다. 색은 개체 색(`setColorAt`)으로 연두 회색 4단계. 색 빠짐 · 0.5초에 주인공 하나 빼고 개체 색을 #C6C6BA / #A2A296 회색으로 섞는다. 주인공은 #C0CB85 | 콩 껍질의 결 |
| 손 접사(처음과 끝) | 굵은 단순 손의 평면 그림 | SVG 로 그린다. 손바닥 다각형 1개 + 손가락 4개, 면 두 톤(#AE7E66 / #A26642), 소매 #AE362A / #D24E42. 외곽선 없음. 처음과 끝은 같은 SVG 를 쓰고 바탕색(#7EA25A → #C6A272)과 손 위 물건만 바꾼다. 원하면 AI 일러스트(codex-image, 단색 면, 외곽선 없음, 그림자 없음, 글자 없음)로 한 장 그려 `scripts/key.py` 로 잘라도 된다 | 손가락 관절의 입체감 |
| 볶는 통·기계 같은 복잡한 기계 | 원기둥과 곡면이 많다 | 원기둥 `CylinderGeometry` 와 상자를 조합하고, 원기둥 옆면은 세로로 3띠 색(밝음·중간·어두움)을 주는 텍스처로 둔다. 기계마다 알아볼 부품(볶는 통의 둥근 창, 기계의 손잡이)을 하나씩 꼭 넣는다 | 매끈한 곡면 음영 |
| 이름표와 지시선 | 3D 위 글자가 기울면 안 된다 | 지시선은 3D 점을 `LOOKS.pin(v, cam, 1920, 1080)` 으로 화면 좌표로 바꿔 SVG 선(굵기 1.5px #2A2A2A)으로 그린다. 선이 0.3초에 자란 뒤 숫자가 올라간다. 글자는 DOM 층 · 머리말 InterVariable 600 13px 자간 0.1em, 숫자 InterVariable 600 36px, 한국어 단위·낱말은 Pretendard SemiBold 18px | 없음 |
| 그림 숫자(콩 70개 = 잔 하나) | 없다. DOM·SVG 로 된다 | 잔 모양 격자 칸 70개에 콩 아이콘(18 x 13px)을 16분음표마다 하나씩 튀겨 넣는다(크기 0 → 1.15 → 1.0, 0.18초). 개수 숫자를 같은 구간에 올린다 | 없음 |
| 떠 있는 판과 끝 카드 | 판 가장자리 흙 단면 | 판은 큰 상자 하나(윗면은 땅·물 무대, 옆면 #8A6642 / #6E5034, 두께 화면 높이의 약 4%). 끝 카드는 DOM 흰 판 540 x 340px, 모서리 반지름 6px, 오른쪽 아래 빈 크림 자리(가로 71~99%, 세로 66~98%). 단계별 길이 막대는 칸 10~12개의 가로 막대 | 없음 |
