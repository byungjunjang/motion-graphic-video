# 어두운 영상 편집 앱 · AI 커서가 편집하고 앱이 흩어진다 — 분석 노트

> 어두운 영상 편집 앱이 화면을 채우고, AI 커서가 실제 편집 단계를 차례로 해 나가는 18초 영상. 무음 구간을 잘라 내고, 보조 영상 조각 셋을 위 트랙에 끌어 놓고, 자막을 낱말마다 올리고, 색을 따뜻하게 바꾸고, 하단 이름판을 만든다. 내보내기가 끝나면 패널들이 카메라 옆으로 날아 흩어지고 빛줄기와 점토색 섬광 속에서 완성 영상이 화면 전체로 재생된다. AI 가 편집을 직접 해 보이는 기능 시연, 편집 도구 출시, 작업 흐름 설명, 전후 비교에 맞는다.

출처 · c2:editor-ui. 원래 글은 긴 스타일 명세다(색, 글꼴, 움직임 곡선 이름과 초, 카메라·커서 규칙, 대표 동작 4개, 1920 기준 패널 배치, 실사 소재 쓰는 법, 금지 목록). 참조 코드 없이 명세만 있고 원본은 실사 소재를 전제로 만들었다고 적혀 있다. 글에 없는 것은 장면별 시각, 단계마다 카메라가 어디까지 다가가는지, 화면에서 잰 색 값(보정 전후의 그림 색, 섬광 색), 코드로 그린 대체 장면의 실제 구성, 원래 글과 화면이 다른 점이다. 이 노트는 영상 프레임을 보고 썼다.
측정 · 파일 1280x720 · 30fps · 18.0초. 크기는 1920x1080 기준으로 바꿔 적는다(1.5배). 장면 감지 7.07초 한 번은 카메라 컷이 아니다. 재생 모니터 속 그림이 보조 영상에서 인물 장면으로 바뀌고 카메라가 조금 물러나는 자리다. 움직임 세기는 평균 10.3, 최대 50.2(6.5초)다. 큰 값은 0.0초(10.1), 2.0초(16.1), 4.0초(14.6), 6.5초(50.2), 8.0초(19.2), 9.5초(16.5), 12.0~13.0초(16~19), 14.5초(33.3)에 온다. 15.5초 이후는 0.6~3.9 다. 색 값은 프레임에서 잰 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. 이 영상 파일에는 소리 트랙이 없다.

## 3. 움직임

- 원래 글에 밀기·커서 이동·클릭 고리·역배율·초점 테·흩어지기의 수치가 있다. 되풀이하지 않는다.
- 영상에서 확인한 점 · 원래 글은 앱이 1.5초까지 자리 잡는다고 정했다. 화면에서는 0.5초 프레임에 이미 평평하다.
- 단계마다 카메라 배율이 다르다. 타임라인 자르기는 약 2.2배, 보조 영상 끌기는 약 1.4배, 자막과 보정은 약 1.8배다. 단계 사이에 반드시 조금 물러났다가 다음 칸으로 다가간다.
- 마스코트는 자르기 구간에서 0.5초에 한 번씩 뛴다. 마스코트가 박자를 눈에 보이게 한다.
- 6.5초의 큰 값(50.2)은 카메라가 아니라 재생 모니터 속 그림이 밝은 화면 부품 그림으로 바뀌어 생긴다.

## 4. 전환

- 컷·페이드가 없다. 앱 안 장면 바꿈은 모두 카메라 밀기와 옮기기, 앱 → 완성 영상은 흩어지기다. 원래 글에 정한 방식 그대로다.
- 영상에서 확인한 점 · 흩어지기는 14.0~15.0초의 1초다. 섬광은 15.0초 근처에 가장 세고 0.25초 안에 걷힌다. 착지 뒤 구도는 끝까지 거의 움직이지 않는다(15.0초와 17.5초의 등불·창 위치 차이가 화면 가로 1% 안). 원래 글의 끝 5% 밀기는 화면에서 잘 보이지 않는다.

## 5. 타이포

- 원래 글은 앱 글자를 작은 굵은 고딕, 자막을 큰 굵은 고딕, AI 이름 한 낱말만 기울어진 세리프로 정했다. 화면과 맞다.
- 영상에서 확인한 점 · 앱 글자는 전체 화면에서 14~21px 상당으로 작지만 근접 배율(1.4~2.2배)에서 30px 이상이 되어 읽힌다.
- 완성 화면의 자막은 낱말 사이가 넓다(낱말 간격 약 0.5em). 낱말 하나가 나올 때마다 앞 낱말의 알약이 빠지고 새 낱말로 옮겨 간다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 14.0~15.5초의 "내보내기 100% 뒤 앱 전체가 기울고, 패널 다섯 개가 카메라 옆으로 날아 빠지며 빛줄기 약 40개(셋에 하나 점토색)가 가운데에서 뻗고, 재생 모니터 하나만 남아 화면 전체를 채우는 순간 점토색 방사형 섬광이 화면의 70% 를 덮는" 1.5초다. 패널이 날아가지 않고 페이드로 사라지거나, 재생 모니터가 아닌 다른 화면으로 넘어가면 이 영상이 아니다.
- 12초 판 압축 예 · 0~0.6초 기운 앱이 자리 잡는다, 0.6~1.2초 요청과 계획 줄, 1.2~3.2초 타임라인 자르기(무음 세 곳, 마스코트 세 번 뜀, 빈자리 닫힘), 3.2~4.7초 보조 영상 조각 셋 끌기(각 0.5초), 4.7~6.2초 자막 낱말 올리기, 6.2~7.7초 색 보정과 전후 나눔 선, 7.7~8.2초 하단 이름판, 8.2~9.0초 물러나기와 내보내기, 9.0~10.3초 대표 장면, 10.3~12.0초 완성 영상과 자막 다시 쌓기. 원본의 0.5~1.5초 정지와 끝 2.5초 중 1초를 줄인다. 다섯 단계 중 하나를 더 빼야 하면 하단 이름판을 완성 화면에서만 보여 준다.
- 한 시계가 카메라·커서·재생 표시·타임코드·보정을 모두 움직인다.
- 단계마다 다가가고 물러나는 카메라 리듬.
- 앱 장식의 강조색은 점토색 하나뿐이다. 보조 영상 조각과 그림 속 색은 앱 강조와 따로 논다.

## 7. 함정

- 화면에 실존 AI 이름과 그 표식이 있다. AI 칸 머리, AI 커서 이름표, 마지막 자막 낱말에 쓰였다. 옮기지 않는다. 우리 영상의 AI 이름은 사용자가 정한 것만 쓴다. 계획 줄 문구, 요청 문구, 자막 문장, 이름판 자리 글자도 옮기지 않는다. 역할(요청 하나, 계획 6줄, 자막 한 문장, 이름판)만 가져온다.
- 보조 영상 조각 하나는 다른 AI 앱 화면 그림처럼 보인다. 우리 영상에서는 사용자 제품 화면이나 일반 그림으로 바꾼다.
- 원래 글은 화면 위 글자·커서·마스코트를 얼굴에 올리지 말라고 정했다. 원본의 마스코트는 얼굴 오른쪽 옆(가로 60~66%, 세로 49~62%)에 붙어 있다. 실사 얼굴이면 이보다 더 띄운다(얼굴 상자에서 120px 이상).
- 앱 글자를 근접 배율에서도 읽히게 한다. 1.0배 화면에서 14px 인 글자는 근접 배율 2.0 이상에서만 보여 준다. 한국어 계획 줄은 원래 21px 를 24px 로 키운다.
- 한국어 자막 · 72px 는 140px 규칙 안이다. 한국어는 낱말이 길어서 화면 폭을 넘기 쉽다. 한 번에 보이는 자막을 4어절 이하로 하고, 자막 줄 폭을 화면 가로 70% 이하로 둔다.
- 흩어지기 · 패널을 페이드로만 빼면 원래 글의 금지(부드러운 크로스 페이드)에 걸린다. 반드시 3D 로 카메라 옆을 지나가게 한다.
- 빛줄기 수를 줄이면 착지의 힘이 없다. 40~56개를 쓰고, 0.4초 안에 화면 가장자리까지 뻗게 한다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

글꼴은 Pretendard Regular·SemiBold 와 InterVariable 뿐이다. 값은 1920x1080 기준이다. 앱은 DOM/CSS 로, 장면은 SVG 로 그린다. 원래 글도 실사가 없으면 코드로 그린 장면을 쓰라고 정했다. 원본 영상도 코드로 그린 장면이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 기울어진 세리프 한 낱말 | 세리프 글꼴이 없다 | Pretendard Regular, 자막 크기의 1.15배(약 83px), CSS `font-style: oblique 10deg`. 점토색 알약 #D97757 은 낱말보다 좌우 24px, 위아래 10px 크게, 모서리 반경 12px | 세리프의 손글씨 같은 인상 |
| 재생 모니터 속 인물 장면 | 원본 글은 실사를 전제로 한다 | SVG · 벽 선형 그라데이션 #1F424A → #16303A, 창 사각형(모서리 16px, 창살 2줄, #5C8C8C 불투명도 0.6), 등불 원 지름 60px #F3D2AA 와 방사형 빛(반지름 260px, 불투명도 0.45), 실루엣(머리·모자·어깨) #1A1310, 가장자리 빛 테 2px #C9A27A 불투명도 0.6, 마이크 팔 굵기 10px #111. 같은 시계로 등불 빛을 ±3% 흔든다 | 실제 사람의 표정과 입 모양 |
| 따뜻한 색 보정 | 없다. CSS 로 된다 | 장면 감싸개에 `filter: saturate(1.22) sepia(0.14) contrast(1.05)` 와 #FF9448 부드러운 빛 합성 층(불투명도 0.3). 슬라이더 값 0 → 1 에 맞춰 세 값을 선형으로 올린다. 전후 나눔은 보정 층에 `clip-path: inset(0 0 0 X%)`, X 를 0.6초 동안 100 → 50 | 없음 |
| 파형과 무음 구간 | 실제 소리 파형 | canvas 막대 · 폭 2px, 간격 1px, 높이는 시드 고정 난수 x 포락선. 무음 구간 세 곳은 높이 2px 로 평평하게 두고, 그 위에 45° 빗금(#D47554, 간격 14px, 굵기 4px)을 덮는다 | 실제 말소리의 모양 |
| 빛줄기 56개 | 없다. canvas 로 된다 | 가운데에서 바깥으로 선 56개. 각도는 시드 고정 난수, 길이 120~420px, 굵기 1.5~2.5px, 3개에 1개 #D97757 나머지 흰색 불투명도 0.7. 0.6초 동안 반지름 0 → 1400px 로 밀어내며 끝에서 투명하게 | 없음 |
| 패널 흩어지기와 흐림 | 큰 패널 여러 장에 3D 와 흐림을 동시에 걸면 무겁다 | CSS 원근 2600px. 패널마다 화면 가운데에서 패널 중심으로 향하는 방향으로 0.95초 동안 깊이 +900 ~ +1500px, 회전 최대 38°, `filter: blur(0 → 7px)`, 0.05초 차이. 재생 모니터만 깊이 -900px 로 물러난다. 흐림은 마지막 0.4초에만 건다 | 없음 |
| 점토색 섬광 | 없다 | 화면 전체 방사형 그라데이션(가운데 #D97757 불투명도 0.75 → 가장자리 0) 을 `mix-blend-mode: screen` 으로 0.1초에 켜고 0.25초에 끈다 | 없음 |
| 필름 그레인과 비네트 | 없다 | `grainLayer(parent, seed)` 를 앱 위 가장 바깥 층에 한 번 붙이고 반환된 update 를 seek 마다 부른다. 원래 글의 3.5% 보다 세면 불투명도를 낮춘다 | 없음 |
| 불꽃 마스코트 | 없다. SVG 로 된다 | 8갈래 별 모양 SVG(지름 80px, #D97757). 뛰기 0.5초 · 처음 0.08초 세로 0.7배 눌림, 공중 세로 1.15배 늘어남, 착지 뒤 0.15초 흔들림. 아래 그림자 타원은 높이에 따라 1.0 → 0.5배 | 없음 |
