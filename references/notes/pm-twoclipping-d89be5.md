# 바닥에 눕힌 랜딩 페이지 위를 나는 카메라 — 분석 노트

> 흰 바닥에 눕힌 랜딩 페이지 한 장 위를 카메라 하나가 14.5초 동안 끊김 없이 지나가는 영상. 0~8.2초에는 비스듬히 내려다보는 카메라가 맨 위 첫 화면에서 맨 아래까지 일정한 속도로 훑고, 지나가는 자리마다 사진·카드·말풍선이 바닥에서 일어나 카메라를 향한다. 피사계 심도가 얕아서 화면 아래쪽 가까운 부분은 크게 흐리다. 8.2~9.6초에 카메라가 위로 올라가 페이지 전체를 세로로 긴 한 줄로 내려다본 뒤, 첫 화면 쪽으로 빠르게 내려가 끝 카드(두 줄 제목 + 카드 한 장)에서 멈춘다. 웹사이트·구독형 서비스·포트폴리오를 위에서 아래까지 한 숏으로 소개하는 영상, 출시 영상의 첫 장면에 맞는다. 3D 페이지 비행 · 얕은 초점 · 떠오르는 카드.

출처 · pm:twoclipping-d89be5. 작성자의 글은 약 6,600자의 제작 명세다. 입력 목록, 금지 효과, 장 구간(비행·상승·부감·하강·제목 카드)과 0.05초 단위의 사건 시각, 카메라 각도·거리·초점 거리, 속도 곡선, 초점 흐림 공식, 그림자 값, 바닥 색, 끝 카드 크기까지 정했다. 비어 있는 것은 결과 화면의 실제 점유율과 선명한 띠의 위치, 대표 장면이 어디인지, 계획과 결과가 다른 점이다. 겹치는 내용은 짧게 쓴다. 이 노트는 영상 프레임(0.5초 간격 16장, 0.4초 간격 17장, 상승·하강 구간은 0.1초 간격 20장, 원본 크기 9장)을 보고 썼다.
측정 · 파일 1440x1152 · 60fps · 14.55초. 장면 감지(문턱 0.28)가 잡은 컷은 0번이다. 0.5초마다 움직임 세기의 평균은 21.1 로, 같은 작성자의 영상 넷 가운데 가장 높다. 0~9.5초는 14.6~53.2 로 쉬지 않고, 큰 값은 3.0초(53.2), 5.5초(51.8), 5.0초(49.4), 2.5초(47.4)다. 10.5~14.5초는 9개 측정점이 모두 0.4 이하로 사실상 정지다. 크기는 원본 1440x1152 화소로 적는다. 색 값은 9x9 화소 평균으로 잰 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. BPM 129.2(마디 첫 박 격자는 129.8 BPM, 마디 1.85초). 원래 글은 음악을 선택으로 두었다. 음량은 0.25~9.75초 내내 -16~-20dB 로 고르다. 10.0초에 -14dB 로 오른다. 원래 글이 정한 9.97초의 타격과 맞는다(9.81초 세기 0.56, 10.28초 킥 0.70). 원래 글의 바람 소리 두 시각(8.66초, 9.80초)에도 타격(8.67초 0.42, 9.81초 0.56)이 있다. 12.0초부터 줄어 12.84~14.54초는 -29dB 아래 무음이다.

## 1. 본질

- 바탕은 밝은 스튜디오 바닥이다. 가운데 #F7F9F9 근처, 모서리 #F3F4F7 근처로 원래 글의 두 값과 맞는다. 바닥에 무늬가 없다.
- 주인공은 랜딩 페이지 한 장(폭 1440px 캡처)이다. 하늘색 히어로 → 사진 섹션 → 기능 카드 → 단계 카드 → 대상 카드 → 후기 → 질문 목록 → 하늘 사진 푸터 순서다. 페이지 둘레에 넓고 옅은 그림자가 있다.
- 떠오르는 조각이 깊이를 만든다. 휴대폰 목업, 사진 카드, 말풍선, 유리 타일, 후기 카드, 실존 로고 타일 4개가 바닥보다 높이 떠서 렌즈 쪽으로 기운다.
- 초점이 아주 얇다. 0.0초 원본 프레임을 열 줄로 나눠 선명도를 재면 위에서 41–60% 줄만 값이 있고(5, 8), 70–100% 줄은 0 이다. 렌즈 가까운 아래 1/3 이 항상 녹아 있다.
- 색은 페이지에서만 온다. 하늘 파랑, 노을 주황, 사진의 초록이다. 영상이 더하는 색은 없다.
- 아닌 것 · 컷, 카메라의 좌우 회전, 멈췄다 가는 비행, 평면 스크롤 화면, 끝 카드 전의 덧씌운 글자. 원래 글이 금지한 효과는 화면에서 찾지 못했다.

## 3. 움직임

- 카메라는 하나, 회전이 없다. 기울기 약 56°(원래 글)로 페이지를 내려다보며 뒤로 미끄러진다. 화면 속 페이지 글줄이 늘 수평이다.
- 속도 · 0~0.6초 출발, 0.6~1.25초 절반 속도, 1.6초부터 같은 속도, 7.3~8.2초 감속. 움직임 세기가 2.0~6.0초에 34.5~53.2 로 높게 고르다. 세기가 1.0초(21.6)에서 1.5초(34.5)로 뛰는 곳이 두 배 가속이다.
- 떠오름 · 조각은 바닥에서 높이를 얻은 뒤 자기 가운데를 축으로 위 끝이 렌즈 쪽으로 기운다. 각도는 원래 글의 30~54° 와 화면이 맞는다(눈대중). 조각 아래 바닥에 짙은 남색 그림자가 옆으로 비껴 깔린다.
- 선명한 띠가 화면 가운데에서 위쪽에 있다. 5.0초 원본 프레임을 스무 줄로 나누면 0–45% 줄 선명도 2.9~5.2, 50–55% 줄 0.0~0.4, 60–100% 줄 0.7~1.4 다. 위쪽(먼 쪽)은 거의 흐려지지 않고 아래쪽(가까운 쪽)만 많이 흐려진다.
- 로고 타일은 영상 내내 따라다닌다. 화면 밖으로 나갔다가 6.0초 왼쪽 위를 흐리게 지나고, 부감에서 페이지 위 모서리에, 끝 카드에서 카드 모서리에 다시 붙는다.
- 끝 카드에서 카드가 아주 천천히(4초에 약 2%, 원래 글) 다가간다. 측정 세기 0.3 으로 눈에 거의 안 보인다.

## 4. 전환

- 하드 컷이 없다. 14.5초가 카메라 한 대의 한 숏이다.
- 장의 구분은 카메라 높이와 각도가 맡는다. 낮은 비행(0~8.2초) → 솟음(8.2~9.2초) → 바로 위(9.2~9.6초) → 내리꽂힘(9.6~10.0초).
- 하강의 끝에서 페이지가 카드로 바뀐다. 히어로 아래의 섹션이 흐려지며 사라지고, 페이지 모서리 반지름이 커진다(원래 글 24px → 38px).
- 제목은 카드가 앉은 뒤에만 나온다. 비행 중에는 페이지 위에 덧씌운 글자가 하나도 없다.

## 5. 타이포

- 비행 구간의 글자는 모두 페이지 캡처 안의 글자다. 덧씌운 글자가 없다.
- 끝 카드 배지 · 흰 알약 안에 작은 로고 + 이름, 글자 높이 14px(세로 56–70px, 1.2%).
- 첫 줄 · 검정 중간 굵기 고딕, 가운데 정렬. 잉크 높이(대문자 위 ~ 내림 끝) 63px(세로 109–172px, 5.5%), 줄 폭 876px(61%).
- 꼬리 줄 · 회색 기울임 세리프, 잉크 높이 65px(세로 184–249px), 줄 폭 619px(43%). 측정 색 #939599 근처(가는 획이라 원래 글의 #8B8B92 보다 밝게 잡힌다).
- 등장 · 첫 줄은 낱말마다 0.06초, 꼬리 줄은 0.05초 간격(원래 글). 화면에서 10.4초에 첫 줄 끝 낱말과 꼬리 첫 낱말이 함께 보인다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 2.0~3.0초. 화면 위쪽에 멀어지는 히어로(세로 0–15%), 가운데에 바닥에서 일어선 사진 2장 + 유리 타일 하나(590x380px, 화면의 41%x33%, 가로 30–71%), 좌우 끝을 흐리게 빠져나가는 말풍선 2개, 아래 1/3 은 녹아내린 다음 섹션. 페이지가 평면 스크롤로 보이거나, 조각이 일어서지 않거나, 아래쪽이 선명하면 이 영상이 아니다.
- 12초 판 압축 예 · 0~1.2초 출발(히어로 + 타일 떠오름), 1.2~3.0초 가속과 사진 묶음 일어섬, 3.0~5.4초 섹션 두 개 통과(단계 카드, 후기 카드), 5.4~6.6초 상승, 6.6~6.8초 부감 띠, 6.8~7.3초 하강, 7.3~12.0초 끝 카드(제목 등장 0.8초 + 정지 3.9초). 대상 카드 섹션과 질문 목록을 빼고 비행을 8.2초 → 5.4초로 줄인다. 속도 곡선의 모양(출발 → 절반 → 두 배 → 고른 속도 → 감속)은 그대로 둔다.
- 페이지 전체를 한 숏으로 보여 주는 구성. 섹션 수가 많아도 같은 속도로 지나가면 지루하지 않다.
- 카메라가 위로 올라가 페이지 전체를 폭 256px 의 세로 띠로 내려다보는 0.2초. "이만큼 긴 페이지"를 한 장면에 말한다.
- 떠오르는 조각. 페이지에서 사진·카드·말풍선만 따로 떼어 높이와 기울기를 준다.
- 로고 타일이 처음부터 끝 카드까지 따라오는 이음.
- 덧씌운 글자를 끝 카드까지 아끼는 절제.

## 7. 함정

- 페이지 안의 제품 이름, 표어, 버튼 글, 사진, 목업 화면, 실존 로고 타일, 끝 카드의 두 줄 문장은 원작의 것이다. 옮기지 않는다. 역할(서비스 이름, 표어, 섹션 제목, 마무리 문장 + 기울임 꼬리)만 가져온다. 사용자의 페이지와 로고는 허락받은 파일만 쓴다.
- 푸터의 큰 제품 이름 글자가 8.4~9.2초에 일어선다. 원래 글에는 없는 동작이다. 쓰려면 사용자 브랜드의 글자로만 한다.
- 정지가 길다. 10.5~14.55초 4초가 정지다. 12초 판에서는 끝 정지를 2.5초 안팎으로 줄인다.
- 페이지 높이가 바뀌면 그 뒤의 모든 시각이 밀린다. 페이지를 먼저 고정한 뒤 시각을 정한다. 떠오름은 대부분 20~40px 로 작게 둔다.
- 투명도로 사라지는 카드는 뒤가 비쳐 보인다. 하강에서 사라지는 섹션은 먼저 바닥색(#F7F9F9)으로 바랜 뒤 마지막에만 투명해진다.
- 먼 쪽 글자가 반짝이기 쉽다. 페이지 텍스처에 밉맵과 비등방 필터를 켠다(three.js `anisotropy` 16).
- 16:9 로 옮기는 구도(1920x1080). 원본은 5:4 다.
  - 같은 카메라로 화면만 넓히면 비행 중 페이지 좌우 끝과 바닥이 보인다. 페이지를 1440px 대신 1920px 폭으로 캡처하고, 세로 화각을 맞추려고 초점 거리를 1880px × 1080/1152 ≈ 1763px 로 둔다.
  - 선명한 띠는 원본처럼 세로 40–60% 에 둔다. 아래 35% 는 녹인다.
  - 부감 띠는 높이 1080px 에 폭 약 240px(화면 폭 12.5%)가 된다. 좌우 빈 바닥이 넓어지므로 로고 타일 4개를 띠 위 끝 양옆에 붙여 둔다.
  - 끝 카드는 제목 공간 때문에 카드 높이를 75%(810px)로 제한한다. 카드 약 970x810px(가로 25–75%, 세로 25–100%), 제목은 세로 6–22%, 배지는 세로 3%. 아래 모서리의 흐린 덩어리 두 개는 가로 18%·82% 로 벌려 넓어진 좌우를 채운다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

글꼴은 Pretendard Regular·SemiBold 뿐이다(숫자·라틴은 InterVariable 도 있다). 값은 원본 1440x1152 기준이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 바닥에 눕힌 페이지 | 페이지 캡처가 필요하다 | 사용자가 준 페이지 캡처 그림(폭 1440~1920px)을 three.js `PlaneGeometry` 에 붙인다. 캡처가 없으면 섹션 6~8개를 canvas 에 직접 그려 `CanvasTexture` 로 쓴다(섹션 높이 600~900px, 둥근 카드와 사진 자리). 사진 자리는 AI 일러스트(codex-image)로 그린 그림(글자·로고 없이)을 쓴다 | 실제 페이지의 세부 |
| 떠오르는 조각 | 조각별 잘라 내기 | 조각마다 따로 `PlaneGeometry` 를 만들어 페이지 위 높이 z(20~200px 환산)에 두고, 자기 가운데를 축으로 `rotation.x` 를 0 → 30~54° 로 0.6초에 준다. 그리는 순서는 낮은 것부터, 깊이 버퍼 없이 | 없음 |
| 조각 그림자 | 높이에 따른 흐림 | 조각과 같은 모양의 평면을 바닥에 깔고 색 #1A2133, 투명도 0.26, 위치 (0.10z, 4 + 0.36z), canvas 에서 미리 흐림 7 + 0.5z px 로 구운 텍스처를 쓴다(원래 글 값) | 없음 |
| 얇은 초점 흐림 | 화소마다 깊이에 따라 흐림이 다르다 | 바닥이 평면이라 깊이가 화면 세로 위치와 거의 비례한다. 화면을 가로 띠 12개로 나눠 띠마다 canvas `filter: blur()` 를 다르게 건다. 초점 줄(세로 45%)에서 0px, 위쪽 끝 6px, 아래쪽 끝 60px, 그 사이는 선형. 일어선 조각은 자기 아래 끝 높이의 흐림 값을 따로 쓴다 | 조각 가장자리와 띠 경계에서 흐림이 계단처럼 바뀐다 |
| 카메라 비행 | 속도 곡선의 적분 | 위치 열쇠를 찍지 말고 속도(순항 약 770px/초의 배수: 0 → 0.5 → 1.0 → 0.12)를 t 의 함수로 두고 0.001초 단위로 더해 위치를 얻는다. `PerspectiveCamera` 의 `lookAt` 만 바꾸고 회전 값은 건드리지 않는다 | 없음 |
| 상승·하강 | 로그 눈금 확대 | 화면 배율 s 를 `Math.exp` 로 보간한다(상승은 사다리꼴 속도, 하강은 2차 들고 나기). 하강 중에는 페이지 위 끝을 화면 위 끝에 고정하도록 바라보는 점을 거꾸로 푼다 | 없음 |
| 로고 타일 4개 | 실존 로고 | 사용자 로고로 바꾼다. 둥근 네모 한 변 32px → 140~200px, 모서리 반지름 22%, 아래 그림자 `0 12px 30px rgba(26,33,51,.18)`. 로고가 없으면 색 네모 + 흰 기호(SVG)로 둔다 | 없음 |
| 움직임 흐림 | 하위 프레임 합성 기능이 없다 | 비행 구간은 원래도 흐림이 크다. 빠지는 것은 상승 구간뿐이다. 8.35~8.95초에만 직전 2프레임 위치(1/120초 간격)를 투명도 0.3 으로 겹친다 | 상승의 매끄러운 잔상 |
| 기울임 세리프 꼬리 줄 | 세리프 글꼴이 없다 | Pretendard Regular, 회색 #8B8B92, `transform: skewX(-10deg)`, 첫 줄보다 10% 크게. 낱말마다 `translateY` 16px → 0, 흐림 12px → 0, 0.34초, 0.05초 간격 | 손글씨 같은 세리프의 대비 |
