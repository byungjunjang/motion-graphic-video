## 4. 전환

- 하드 컷은 한 번(전체의 45%)이다. 라임 바탕의 띠에서 흰 바탕의 카드 한 장으로 바로 넘어간다. 고른 카드의 가로 위치(폭 706px, 가로 32~68%)는 컷 앞뒤에서 이어진다.
- 확대로 들어가기 · 커서로 확대해 들어간다. 장면이 바뀐 것이 아니라 카메라가 붙은 것이다.
- 휙 회전 이음 · 앞 요소가 돌며 왼쪽 아래로 빠지고, 다음 요소가 반대쪽에서 진자처럼 흔들려 들어온다(약 0.3초). 두 요소의 회전 방향이 이어져 하나의 휙 동작으로 보인다.
- 원 덮음 · 한 요소에서 튄 작은 원이 커져 화면을 덮는다(0.25초 이내). 덮은 직후 가운데에 카드 한 장이 나타나 띠로 불어난다.
- 물러나기로 담기 · 카메라가 물러나 앞 화면의 주인공이 다음 화면 안의 한 요소가 된다.
- 면 덮음 · 흰 면이 아래에서 위로 화면을 덮는다(약 0.25초).
- 끝 글자 줄 사이 · 첫 줄이 사라지고 둘째 줄이 낱말씩 들어온다.
- 박자 · 끝 글자 줄과 이름의 등장을 마디 첫 박에 0.1초 안으로 맞춘다. 누름과 컷은 타격에 맞춘다. 가장 센 타격(마지막 마디 첫 박)은 끝 정지 중에 둔다.

## 5. 타이포

- 글꼴은 기하형 고딕 한 계열이다. 보통 굵기와 중간 굵기만 쓴다. 세리프는 없다.
- 입력 글자 · 대문자 높이 38px(3.5%), 줄 간격 55px, 검정. 두 줄 고정.
- 큰 글자 · 소문자 몸통 약 210px(19.5%), 점 위부터 꼬리 아래까지 약 390px(36%). 같은 글꼴을 카메라로 키운 것이라 굵기가 입력 글자와 같다. 한 글자씩 찍히고 가로 흐림이 진하다.
- 대기 한 줄 · 왼쪽 위(가로 8%, 세로 12~18%), 줄 높이 68px(6.3%), 검정, 글자 사이가 조금 넓다. 한 글자씩 찍힌다.
- 카드 글 · 제목 흰색(대문자 높이 약 26px, 눈대중), 설명 두 줄 회색(약 12px, 눈대중), 아래 정보 줄 회색 아이콘 3개, 숫자 강조 라임. 위 왼쪽에 작은 알약 꼬리표, 위 오른쪽에 점수 표시.
- 결론 문장 · 한 줄 771x67px(가로 29~70%, 세로 47~53%), 대문자 높이 51px(4.7%), 검정, 화면 가운데. 낱말이 0.05~0.1초 간격으로 아래 약 20px 에서 올라오며 회색에서 검정이 된다. 첫 줄은 1.2초 머문다. 둘째 줄은 낱말 사이를 넓게(약 60~80px, 눈대중) 두고 1.5초 동안 보통 띄어쓰기로 좁힌다. 원래 글은 92px 흰 글자를 검은 바탕에 두라고 했다. 실제는 그 절반쯤 크기의 검은 글자가 흰 바탕에 있다.

- 핵심 장치 · 한 요소가 다음 화면의 요소가 되는 이음(덮는 원 → 바탕, 카드 한 장 → 띠, 띠의 한 장 → 다음 화면의 카드). 컷은 전체에 한 번이다.

## 7. 함정

- 원본 화면의 실존 로고·이름은 쓰지 않는다.
- 원래 글과 실제 화면이 다른 점이 많다. 원래 글을 기준으로 만들면 이 스타일과 다른 영상이 나온다.
  - 템포 · 원래 글은 약 130 BPM, 32박(14.8초)으로 정했다. 측정은 120.2 BPM 이고 영상은 16.26초다. 120.2 는 130 의 절반이나 두 배가 아니다. 마디 첫 박 간격 2.013초와 끝 글자의 줄 바꿈 간격(약 2초)이 맞으므로 실제 곡의 템포는 약 120 으로 본다.
  - 컷 · 원래 글은 컷을 금지하고 덮음 색이 작게 줄어드는 전환을 정했다. 실제는 하드 컷 한 번이다.
  - 끝 · 원래 글의 검은 화면 펼침과 상징 표시는 없다. 흰 화면에 작은 검은 글자뿐이다.
  - 색 · 바탕은 따뜻한 흰색이 아니라 순백이다. 라임은 원래 글의 값보다 밝고 푸르다(#C8FF70 근처). 주황은 더 붉고 어둡다(#F26E40 근처). 파랑은 더 어둡다(#3C62E5 근처).
  - 여는 구간은 원근 회전이다. 원래 글은 평면만 쓰라고 했다.
  - 정지 · 원래 글은 1초 넘는 정지를 금지했다. 실제는 1.2초와 끝 2.4초가 정지다.
- 대기 한 줄 맨 앞에 마침표가 붙어 있다. 말줄임표가 문장 앞으로 간 글자 배치 오류로 보인다. 따라 하지 않는다.
- 면 덮음 뒤 흰 화면에 앞 화면(기기 틀 윤곽)이 아주 옅게 비친다. 밝기 차는 255 단계 중 2 이하다. 화면을 덮는 흰 면의 투명도를 1 로 끝내야 한다.
- 끝 6.4초는 화면 점유율이 0.2~0.6% 다. 소리가 없으면 끝난 영상처럼 보인다. 한국어 판에서는 결론 문장을 대문자 높이 70~90px 로 키우거나 정지를 줄인다.
- 카드의 실사 사진이 설득력을 만든다. 외부 사진은 쓰지 않으므로 AI 이미지로 바꾼다(## 8).
- 큰 글자 구간은 한국어에서 그대로 안 된다. 한국어 글자는 140px 이하로 둔다. 화면을 채우는 느낌은 글자 크기 대신 카메라를 붙여 한 화면에 2~3 글자만 보이게 해서 만든다. 입력 문장은 줄바꿈 위치를 고정한 세 줄로 미리 정해 둔다. 줄이 바뀌면 커서를 따라가는 카메라가 튄다.
- 하위 프레임 흐림이 없으면 띠 미끄러짐과 큰 글자 돌진이 끊겨 보인다. 렌더 도구에 하위 프레임 합성이 없으므로 흐림을 화면에서 직접 만든다(## 8).
- 파일이 1920x1078 이다. 만들 때는 1920x1080 으로 둔다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

글꼴은 Pretendard Regular·SemiBold(숫자·라틴은 InterVariable)뿐이다. 외부 사진은 쓰지 않는다. 값은 1920x1080 기준이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 카드 사진 4종 | 외부 사진을 쓰지 않는다 | AI 이미지(codex-image)로 4장. 1024x1024, 검은 바탕, 카드 주제의 대상을 45° 위에서 본 사진풍, 글자·로고 없이. 카드 위쪽 60% 에 `object-fit: cover` 로 채운다. 프롬프트에 실존 브랜드 이름을 넣지 않는다 | 실사 사진의 질감과 신뢰감 |
| 무지개 빛 테 | 번지는 빛 | CSS · 입력창 뒤 가상 요소에 `conic-gradient(#FF4FD8, #FF8A3D, #C8FF70, #4FE3FF, #8B5CFF, #FF4FD8)`, `filter: blur(28px)`, 바깥으로 18px 넓게, 투명도 0.85. 회전 각도는 seek 안에서 `t * 90` 도. 기기 틀 둘레는 같은 값에 blur 40px | 없음(블러 렌더 비용만 는다) |
| 여는 원근 회전 | 없다. CSS 로 된다 | 입력창 묶음에 `perspective: 1400px` + `rotateX(38deg) rotateZ(-14deg) scale(2.6)` → 0.5초에 `rotateX(0) rotateZ(-2deg) scale(1.85)`. 감속 곡선은 3제곱 감속 | 없음 |
| 커서와 꼬리 | 없다. DOM 으로 된다 | 막대 div 폭 14px · 높이 190px(140px 글자 기준) · #3963E5. 왼쪽 꼬리 div 폭 280px, `linear-gradient(90deg, rgba(190,198,246,0), #9AA6EE)`. 글자를 찍을 때마다 막대가 글자 폭만큼 오른쪽으로 0.06초에 간다 | 없음 |
| 커서로 돌진하는 확대 | 한국어 140px 제한 | 무대 묶음 하나에 카메라 변환 하나. 배율은 로그 보간으로 1.85 → 9(1초). 한국어 글자 크기는 140px 를 넘기지 않고, 카메라가 커서 쪽 2~3 글자만 화면에 남도록 붙는다. 숫자·라틴 낱말이면 InterVariable 300px 까지 | 원본의 소문자 몸통 210px 크기 |
| 움직임 흐림 | 렌더 도구에 하위 프레임 합성이 없다 | 빠른 묶음(카드 띠, 큰 글자, 휙 회전)에 SVG 필터 `feGaussianBlur stdDeviation="속도px÷60 0"`(가로만)을 seek 에서 속도에 비례해 건다. 최대 24px. 카드 띠는 같은 띠를 0.006초 간격으로 3벌 겹쳐 그리고 투명도 0.5·0.3·0.2 | 회전 흐림의 자연스러운 꼬리 |
| 반원 주인공의 진자와 작은 원 | 없다. SVG 로 된다 | SVG 반원 path 636x324 · #F26E40, 가는 선 2px · 230px, 끝 원 지름 12px. 진입 각도 θ = 70°·e^(-4.5t)·cos(9t). 작은 원은 3~4개(회색 30px, 초록 168px #6DE48C, 라임 170~310px #C8FF70), 위치 y = y0 − 900t + 1800t² 의 포물선, 0.5~0.75초 간격 | 없음 |
| 원 덮음 | 없다. CSS 로 된다 | 라임 층에 `clip-path: circle(r at 870px 360px)`, r 을 155px → 1280px(가장 먼 모서리까지)로 0.25초, 3제곱 가속. 카드 층의 z-index 를 덮음보다 위에 둔다 | 없음 |
| 카드 띠 | 없다. DOM 으로 된다 | 카드 512x464px, 반지름 28px, #050304, 간격 54px. 띠 translateX 를 1초에 −1700px, 끝 0.2초에 닫힌 식 스프링(감쇠 0.6)으로 멈춤. 고른 카드는 translateY −174px | 없음 |
| 흰 면 덮음 | 없다 | 흰 div 가 아래(translateY 100%)에서 0 까지 0.25초. 끝 투명도를 1 로 고정해 앞 화면이 비치지 않게 한다 | 없음 |
| 결론 문장 낱말 떠오름 | 없다 | 낱말 span 마다 translateY 20px → 0, 색 #9A9A9A → #000 을 0.3초, 낱말 간격 0.07초. Pretendard SemiBold 72px(대문자 높이 약 51px). 둘째 줄은 낱말 사이 여백 70px → 16px 을 1.5초 | 없음 |
