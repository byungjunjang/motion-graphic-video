# 실시간 카운트다운 분할 화면 · 영점에서 하나로 — 분석 노트

> 한 행사의 영점(발사, 발표, 종료 휘슬, 마감)을 앞둔 32.5초와 그 뒤 27초를 자르지 않고 실제 시간 그대로 보여 주는 60초 편집 영상. 시계가 매초 바뀌고, 영점이 가까워질수록 화면이 1칸 → 2칸 → 3~4칸 → 9칸으로 쪼개진다. 모든 칸은 같은 1초를 보여 준다. 영점에 칸들이 한 장면으로 합쳐지고 시계가 주황으로 뒤집힌다. 출시·공개·개표·경기처럼 정해진 순간이 있는 행사 영상에 맞는다.

## 3. 움직임

- 원래 글의 수치(시계 숫자가 14px 떨어지며 0.12초, 재배치 0.34초, 새 칸은 왼쪽 끝에서 열린다, 주황 테두리 0.2초 깜빡)는 화면과 맞다.
- 영상에서 확인한 점 · 칸 안 촬영본은 거의 고정 카메라라 평소 움직임 세기가 0.2~3 이다. 화면을 움직이는 것은 배치 변화와 시계뿐이다. 그래서 1~2초마다 새 요소(칸, 체크, 사건 꼬리표, 확대)가 하나씩 들어온다(원래 글의 함정과 같다).
- 시계 숫자 옆에 작은 소수 한 자리가 붙어 0.1초마다 바뀐다. 원래 글이 정한 초 아래 막대는 화면에서 시계 아래 10칸으로 나뉜 가는 막대로 보인다. 칸 사이에 약 4px 틈이 있고, 켜진 칸만 주황이다(28.0초 영점 −4.5초에 5칸, 45.0초 영점 뒤 +12.5초에 6칸). 꺼진 칸은 #0D1013 근처로 바탕과 거의 같다.
- 영점 뒤 둘째 카운트다운(42~54초)은 작은 역시계(숫자 높이 약 4.9%)가 비행 단계 칸 안에서 따로 줄어든다. 주 시계는 왼쪽 아래 주황 판에서 계속 늘어난다.

## 4. 전환

- 칸 재배치, 왼쪽에서 닦아 바꾸기, 전체 화면끼리 하드 컷, 영점의 합치기뿐이다. 원래 글에 있다.
- 영상에서 확인한 점 · 영점 합치기는 0.5초 안에 세 단계다. 흰 빛 덮개(32.5초) → 시계 칸만 주황으로 뒤집힘(32.6초) → 한 장면이 열리고 시계 판이 왼쪽 아래로(32.75초). 움직임 세기는 32.0초와 32.5초 두 칸 모두 32 안팎이다.
- 원래 글이 정한 영점 직전의 음악 빼기(0.25초 전)는 무음 측정(기준 -26dB)에 잡히지 않았다. 현장 음성이 계속 들리기 때문으로 보인다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 22.4~33.0초의 "가운데 칸에 시계를 둔 9칸 격자가 한 칸씩 채워지고, 영점에 흰 빛 → 시계 칸만 주황으로 뒤집힘 → 한 장면이 열리며 주황 시계 판이 왼쪽 아래로 가는" 흐름이다. 칸은 약 618x339px, 틈 9px, 검은 바탕 #0A0D10, 강조는 주황 #F75C24 하나. 칸이 박마다 하나씩 늘지 않거나 영점에 칸이 그대로 남으면 이 영상이 아니다.
- 12초 판 압축 예 · 실제 시간 원칙 때문에 영점 전 약 8초 + 영점 뒤 약 4초를 자르지 않고 쓴다. 0~2초 1칸 + 아래 띠의 시계(영점 −8초에서 시작), 2~3초 2칸, 3~4.5초 9칸 격자로 바뀌고 빈 칸 세 개, 4.5~7초 셈 호출마다 빈 칸이 하나씩 켜진다(칸마다 0.3초 열림), 7~8초 칸 하나 안에서 점화, 8.0초 영점 합치기(0.5초), 8.5~12초 한 장면 전체 + 왼쪽 아래 주황 시계 판과 자막 판. 사실 카드, 추력 막대, 둘째 카운트다운, 끝 카드는 뺀다.
- 화면 시간 = 행사 시간. 시계와 그림이 어느 프레임에서도 맞는다.
- 정보 칸(점검 목록, 자막, 사실 카드)도 촬영 칸과 같은 격자의 한 칸이다.

## 7. 함정

- 화면의 자막 문장, 점검 목록 낱말, 사실 카드 숫자, 칸 이름, 제목, 출처 표기는 원작의 것이다. 옮기지 않는다. 역할(셈 호출 자막, 점검 목록, 사실 카드 두 줄, 칸 이름)만 가져온다. 화면에 실존 기관·임무·우주선·장소·인물 이름과 실존 기관 로고가 있다. 쓰지 않는다.
- 촬영본 속 사람(관제실 직원, 탑승자)은 실존 인물이다. 우리 영상에 그 모습을 그리지 않는다.
- 우리 주제에 실제 촬영본이 없으면 원래 글의 실제 시간 원칙을 지킬 근거가 없다. 그때는 영상 안에서 실시간 기록이라고 말하지 않는다. 시계와 화면이 서로 맞는 것만 지킨다.
- 코드로 만들 때 밀도가 줄어드는 지점과 막는 법.
  - 칸 수 · 서로 다른 장면 6개를 구하기 어려워 4칸에서 멈추기 쉽다. 9칸 중 촬영 칸은 5~6개, 나머지는 시계·점검 목록·자막 판(두 칸 합침)으로 채운다. 정보 칸이 칸 수를 채워 준다.
  - 움직임 세기 · 원본 평균 3.5 는 낮다. 정지 그림 칸이어도 괜찮지만 1~2초마다 새 요소 하나를 넣는다. 영점 순간은 30 이상이 되게 흰 덮개를 화면 전체에 0.1초 안에 씌운다.
  - 시계 · 비례 폭 숫자는 떨린다. 숫자마다 고정 폭 칸을 둔다(원래 글과 같다). InterVariable 의 고정 폭 숫자 기능(`font-variant-numeric: tabular-nums`)을 쓴다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 실제 행사 촬영본이 없다고 보고 쓴다. 사용자가 허락한 촬영본이 있으면 그것을 칸에 넣는다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 행사 촬영본(발사대·근접·관제실) | 실제 촬영본이 없다 | AI 일러스트(codex-image)로 같은 순간을 다른 자리에서 본 장면 5~6장(넓은 장면, 근접, 위에서, 실내 상황실 뒷모습)을 만든다. 1536x1024, 글자·로고·화면 속 글 없음. 각 칸에 천천히 밀기(1.00 → 1.04)와 칸마다 다른 작은 움직임(연기 층 이동, 깜빡이는 표시등)을 준다 | 실제 시간이라는 증거 |
| 점화·불꽃·연기 | 실제 불꽃의 움직임 | three.js(`vendor/three`) 에 `LOOKS.orbs(600, { color: '#FFB070', size: 0.08 })` 로 불씨를 두고 위치를 t 로 아래로 흘린다. 연기는 AI 일러스트 연기 그림 3장을 투명 그림(`scripts/key.py`)로 만들어 크기 1.0 → 1.6, 투명도 0.9 → 0.5 로 겹친다. 후처리 `LOOKS.post(gl, { bloom: 0.8, threshold: 0.9 })` | 불꽃의 실제 결 |
| 칸 격자와 재배치 | 없다. 그대로 된다 | DOM div 9개. 칸 사각형을 배치 표에서 읽어 0.34초 3차 가감속 보간. 바탕·틈 #0A0D10, 둘레 여백 24px, 틈 9px. 새 칸은 왼쪽 끝에서 폭 0 → 전체로 열리고 3px #F75C24 테두리를 0.2초 보인다 | 없음 |
| 시계 | 없다. 그대로 된다 | InterVariable 굵기 700, 74px(격자 가운데 칸에서는 87px), `font-variant-numeric: tabular-nums`. 앞 글자 #F75C24, 숫자 #F2F2F2, 소수 한 자리 30px #8A8F96. 매초 새 숫자가 위에서 14px 떨어지며 0.12초 | 원본 글꼴의 좁은 비례 |
| 영점 합치기 | 없다. 그대로 된다 | 32.5초 상당 시각에 흰 덮개 div(#FFFFFF, 투명도 0 → 0.7 을 0.05초, 0.7 → 0 을 0.25초). 같은 순간 시계 칸 바탕 #0A0D10 → #FF6028, 숫자 색 흰색 → #111111. 0.1초 뒤 다른 칸 투명도 1 → 0(0.15초), 한 장면 칸을 전체 화면으로, 시계 판을 (가로 1~35%, 세로 83~98%) 로 0.34초에 옮긴다 | 없음 |
| 자막 판과 커서 | 없다. 그대로 된다 | 원어 줄 대신 작은 회색 한국어 줄 Pretendard Regular 24px #8A8F96, 아래 큰 줄 Pretendard SemiBold 40px #F2F2F2. 끝에 #F75C24 세로 막대(4x30px)가 0.5초 주기로 깜빡인다. 셈 호출은 낱말마다 따로 붙인다 | 없음 |
| 칸 이름표·점검 목록 | 없다. 그대로 된다 | 칸 왼쪽 위 12px 안쪽에 주황 네모 10px + Pretendard SemiBold 18px #9AA0A6. 점검 목록은 줄마다 체크 상자 18px(체크되면 #F75C24 채움) + 시각 + 항목 이름, 줄 사이 44px | 없음 |
