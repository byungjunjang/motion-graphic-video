- 큰 면 하나 + 빈 종이 + 가는 선. 장면 전환 앞 0.3~0.4초 무음과 멈춤.
- 12초 판에서 자 장면을 남기려면 · 4초 이상이 필요하다(요소 38개를 읽을 시간). 대신 사각형 줄과 큰 숫자 둘만 남기고 세로 기둥·눈금 숫자·비교 문장을 빼면 2초로 줄어든다. 이 경우 오려 내기 장면을 뺀다.

## 7. 함정

- 제목, 숫자, 자막, 이름표, 제작 표기는 원작의 것이다. 옮기지 않는다. 역할(제목 세 줄, 경사 위 큰 숫자, 자막 상자, 비교 숫자 둘, 결과 공식)만 가져온다. 제작 표기에 실존 연구실 이름과 모델 이름이 있다. 쓰지 않는다.
- 한국어는 140px 이하라서 제목 첫 줄(원본 약 140px)이 상한에 걸린다. 제목은 Pretendard SemiBold 120px 로 두고 크기는 숫자와 도형으로 낸다. 숫자는 InterVariable 굵게 300px 이상까지 키운다.
- 넓이 규칙을 지키면 처음 점이 아주 작다. 원본은 약 40px → 약 450px 가 화면에 들어가게 경사 길이를 정했다. 단계가 8개를 넘으면 원래 글대로 구도를 바꾸고 비율은 바꾸지 않는다.
- 고리를 동심원으로 그리면 과녁이 된다. 원판 중심 = 접점 + 반지름 x (접점에서 공 쪽 단위 벡터).
- 평균 세기 5.0 은 이 스타일에서 정상이다. 요소를 더 움직여 맞추지 않는다. 대신 장면 전환 순간(20~56)을 확실하게 만든다.
- 그레인을 세게 넣으면 낡은 인쇄물이 된다. 종이 잔결 0.7, 파랑 3.2 정도로 둔다.
- 원래 글의 함정 절은 그대로 맞다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

거의 전부 SVG 와 DOM 으로 그대로 된다. 값은 1920x1080 기준이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 굵은 기하 산세리프 제목 | 원형 글자의 기하 글꼴이 없다 | 숫자·라틴은 InterVariable 굵기 800, 자간 -0.02em. 한국어는 Pretendard SemiBold 120px 이하. 둘째 줄은 Pretendard Regular 72px, 자간 0.12em. 글자 하나를 원으로 바꿀 때는 그 자리를 비우고 지름 = 글자 높이 x 0.9 의 초록 SVG 원을 놓는다 | 원형 글자의 기하 인상 |
| 구르며 커지는 공 | 없다 | SVG 원 8개. k 번째 반지름 = 20px x √(2^k). 단계마다 0.5초, 새 원은 0.18초에 0 → 목표 반지름(끝에서 6% 넘쳤다 돌아오는 감속). 회전각 = 굴러간 거리 ÷ 현재 반지름의 적분. 중심은 한 접점에서 안쪽으로 접하게 계산 | 없음 |
| 굴러간 길의 호 | 사이클로이드 계산 | 단계마다 반원에 가까운 SVG 경로 하나. 폭 = 그 단계에 굴러간 거리, 높이 = 공 지름 x 0.55. 먹색 2.5px, `stroke-dashoffset` 으로 공보다 0.05초 늦게 그린다 | 정확한 사이클로이드 |
| 작도선 그리기·줄이기 | 없다 | SVG 선, 먹색 불투명도 0.55, 2px. 등장 0.3초, 줄어들기는 시작점을 끝점으로 0.4초에 옮긴다. 투명도로 지우지 않는다 | 없음 |
| 도형 속으로 들어가기 | 없다 | 공 무리를 CSS 배율 1 → 12 로 0.8초(가속 뒤 감속), 노란 원판 중심을 화면 가운데로. 노랑만 보이는 칸 0.3초, 다음 무리는 배율 6 → 1 로 0.7초 | 없음 |
| 종이 구멍과 접선 | 없다 | 구멍은 종이색 원 + 먹색 2px 외곽선 + 십자(20px). 접선은 두 원의 바깥 공통 접선 공식으로 계산. 컴퍼스 원은 0.6초에 한 바퀴 그린다 | 없음 |
| 종이와 그레인 | 실제 종이결 | 바탕 #F8F6F3 위에 `texTile(seed, { mc: '120,120,130', mottle: .02, dark: .02, light: .02, fibers: 60, specks: 8 })` 를 곱하기로 아주 옅게. `grainLayer(stage, seed)` 의 그레인 층 불투명도를 0.34 → 0.15 로 낮추고 비네트 층은 숨긴다(원본에 비네트가 없다) | 파랑 위 그레인의 결 |
| 자 눈금과 단리 사각형 줄 | 없다 | DOM 또는 SVG. 눈금 8개를 가로 24~88% 에 173px 간격으로, 숫자는 InterVariable 굵기 700, 30px, 흰색. 사각형은 윗변을 세로 78% 에 맞추고 한 변을 34px 에서 81px 까지 칸마다 약 7px 씩 키운다. 칸마다 0.12초 간격으로 0.2초 동안 배율 0 → 1 | 없음 |
| 겹치는 옛 길(옅은 호) | 없다 | 처음 공의 호 경로를 그대로 두고 색을 #D5DCEE, 굵기 2px 로 바꾼다. 새 공의 호는 먹색 2.5px 로 그 위에 그린다 | 없음 |
| 떨어지는 조각 | 물리 시뮬레이션 | 조각마다 0.1초 간격으로 시작해 0.45초에 아래로 1200px(점점 빨라지게), 회전 ±6°. 선은 남긴다 | 서로 부딪히는 느낌 |
