## 3. 움직임

- 선이 그려지는 속도는 고르지 않다. 윤곽은 약 1.0~1.5초에 그리고, 사물 사이를 잇는 긴 곡선은 0.5~1.0초에 빠르게 지나간다.
- 채움은 빠르다. 윤곽이 닫힌 뒤 0.15~0.3초에 그림이 나타난다(불투명도 0 → 1 과 크기 0.96 → 1.0 으로 추정). 채움 순간이 움직임 세기의 작은 정점(2.5, 7.0, 14.5, 19.0, 22.0, 27.0초)이다.
- 화면 이동은 세로다. 선의 머리가 화면 세로 60% 아래로 내려가면 화면 전체가 위로 밀린다. 큰 이동은 4.0, 9.5~10.5, 15.0, 20.0, 27.5초에 있다. 한 번에 화면 높이의 40~60%(약 800~1100px)를 0.5~0.8초에 움직인다(추정). 이동 끝에 감속이 있다.
- 지나간 사물은 화면 위로 밀려 나간다. 한 화면에 보이는 사물은 1~2개다.
- 자막은 제자리에 있다. 화면 이동과 함께 움직이지 않는다.
- 사물 자체는 거의 움직이지 않는다. 예외는 흰 원판의 숨쉬기(29~32초, 지름 ±5%)뿐이다.
- 바탕 결은 고정이다. 화면 이동 때 결이 같이 움직이지 않는다(종이 위에 카메라가 아니라 종이 자체가 고정된 것처럼 보인다).

## 4. 전환

- 컷이 없다. 장면 구분은 "사물 하나 완성 → 선이 떠남 → 화면 이동"의 반복이다. 사물 12개가 약 3초마다 하나씩 나온다.
- 큰 전환은 32.0초의 바탕색 교체 한 번이다. 남색 + 금색에서 연녹 + 적갈색으로 한 프레임에 바뀐다. 문장의 결론부가 시작되는 지점이다. 바탕 결도 티끌 점에서 대각선 망점 그물로 바뀐다.
- 작은 전환은 5.5~8.4초의 바탕 어두워짐이다(#313692 → #202566 → 다시 #313692). 어둠과 해를 말하는 줄에 맞춘다.
- 마지막은 선이 자막의 밑줄이 되며 끝난다. 그림 선과 글자가 한 줄로 이어진다.

## 5. 타이포

- 줄마다 두 층이다. 위에 작은 산세리프 앞 구절(흰색, 글자 블록 높이 약 34px, 화면 높이의 1.8%), 아래에 큰 세리프 핵심 단어(블록 높이 약 145px, 7.5%, 대문자 높이는 약 4.5%로 추정).
- 위치 · 왼쪽 정렬, 왼쪽 여백 약 100px(화면 너비의 9%). 앞 구절은 세로 61~64%, 핵심 단어는 세로 65~73%.
- 강조는 세 가지다. (1) 이탤릭 세리프 + 주황(#EBAF54 근처), (2) 굵은 로마자 세리프 + 흰색, (3) 강조 단어 사이의 아주 작은 연결 단어(높이 1.5%). 한 줄에 큰 단어는 1~3개다.
- 박자 · 앞 구절이 먼저 나오고 0.5~1.0초 뒤 핵심 단어가 나온다. 핵심 단어는 왼쪽부터 글자 단위로 흐릿하게(불투명도 + 약간의 번짐) 0.3~0.5초에 나타난다. 다음 줄이 오기 전에 앞 줄의 강조 단어는 흐린 색(불투명도 약 0.5)으로 가라앉는다. 교체 간격은 1.3~2.7초이고 음량의 숨 골과 맞는다.
- 결론부(32초~)는 주황 대신 적갈(#A64A22), 흰 대신 짙은 녹흑(#1E2A1E 근처)이다.
- 한국어로 옮기면 이탤릭이 없다. 강조 단어는 Pretendard SemiBold + 주황, 일반 단어는 Pretendard Regular + 흰색으로 나눈다. 큰 단어는 110~130px(140px 를 넘기지 않는다), 앞 구절은 32px.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 2.6~4.1초. 금색 선(5px)이 화면 가로 17~81%, 세로 26~45% 의 사각 윤곽을 닫자마자 0.2초에 펼친 책 그림(폭 약 690px, 화면 너비의 64%)이 채워지고, 선이 책 윗변을 따라 고리 하나를 만든 뒤 아래로 빠져나간다. 그림 아래 세로 61~73% 에는 앞 구절 + 이탤릭 주황 강조 단어 두 줄 자막이 있다.
- 12초 판 압축 예 · 사물 3개 x 3초 + 결론 3초. 책 0~3초(윤곽 1.2초, 채움 0.2초, 떠남 0.6초, 이동 0.5초) → 새싹 3~6초 → 신발 또는 주머니 6~9초 → 바탕 전환 9.0초 → 해 반원과 밑줄 9~12초. 달·자명종·종이 뭉치·동심원을 뺀다. 자막은 4줄로 줄인다.
- 선 → 윤곽 → 채움 → 떠남의 4박자. 사물 하나에 약 3초. 대상의 기능·장점을 사물 3~4개로 바꿔 넣을 수 있다.
- 한 줄 = 사물 하나. 문장과 그림이 1:1 로 짝을 이룬다.
- 결론부에서 바탕색을 한 번 바꾸는 방식. 앞부분과 색 대비(차가운 남색 → 따뜻한 연녹)가 크게 나야 한다.
- 마지막 선이 결론 단어의 밑줄이 되는 끝.
- 팔레트(근삿값) · 앞부분 바탕 #313692, 어두운 구간 #202566, 선·강조 #EBAF54, 글자 흰색. 결론부 바탕 #B4C7A5, 선·강조 #A64A22, 글자 #1E2A1E.

## 7. 함정

- 화면의 시 구절은 원작의 문장이다. 옮기지 않는다. 구조(앞 구절 + 강조 단어, 줄마다 사물 하나)만 가져온다.
- 사물 그림이 영상의 질을 정한다. 오린 사진 같은 질감이 없으면 평범한 아이콘 영상이 된다. 사물 그림은 모두 같은 결(종이 결, 흰 오림 테두리, 약한 그림자)로 맞춘다.
- 윤곽과 그림이 맞지 않으면 채움 순간이 어색하다. 그림을 먼저 만들고 그 외곽을 따서 선 경로를 만든다. 선 경로를 먼저 정하면 안 된다.
- 선이 사물을 떠나는 길이 너무 길면 지루하다. 사물 사이 연결선은 1초 아래로 둔다.
- 세로 영상을 16:9 로 옮기는 구도 · 그림 자리와 자막 자리를 위아래에서 좌우로 바꾼다. 1920x1080 에서 그림 자리는 왼쪽 가로 6~56%, 세로 12~88%(약 960x820px), 자막 자리는 오른쪽 가로 60~92%, 세로 40~72%다. 사물 크기는 원본의 화면 너비 비율(최대 64%)이 아니라 화면 높이 비율로 맞춘다. 사물 높이는 화면 높이의 35~45%(380~490px). 화면 이동은 세로 대신 가로(오른쪽으로 진행)로 바꾼다. 선의 머리가 가로 50% 를 넘으면 화면이 왼쪽으로 밀린다. 한 번 이동은 화면 너비의 35~45%(670~860px)를 0.6초에. 자막 큰 단어는 110~120px, 앞 구절은 30px. 자막은 그림 자리와 겹치지 않게 오른쪽에 고정한다.
- 가로로 옮기면 화면이 넓어서 사물이 하나뿐일 때 비어 보인다. 지나간 사물을 화면 왼쪽 끝에 일부(폭의 20~30%) 남겨 흐름을 보인다.
- 이탤릭 세리프 강조가 이 영상의 인상 절반이다. 한국어 Pretendard 만으로는 이 인상이 약하다. 강조 단어 아래에 금색 선이 짧게 지나가는 밑줄(굵기 4px)을 더해 보완한다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 원본 1080x1920 기준이다(16:9 판은 7절의 비율로 바꾼다). 글꼴은 Pretendard Regular·SemiBold 이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 끊기지 않는 선 | 영상 전체가 하나의 경로다 | 경로 전체를 SVG path 하나로 만든다. `getTotalLength()` 로 길이를 재고 `stroke-dasharray: L; stroke-dashoffset: L*(1-p(t))`. stroke 5px #EBAF54, `stroke-linecap: round`. 구간마다 p 의 목표값을 시간표로 정한다(윤곽 구간은 천천히, 연결 구간은 빠르게) | 없음 |
| 오린 사진 같은 사물 그림 | 실사 사진을 쓰지 않는다 | codex-image 로 사물 하나씩 그린다(빈티지 인쇄물 질감, 글자·로고 없이, 마젠타 바탕). `scripts/key.py` 로 투명 PNG 를 만든다. 흰 오림 테두리는 CSS `filter: drop-shadow(0 0 0 #fff)` 대신 SVG `feMorphology operator="dilate" radius="4"` 로 흰 외곽을 만들고, 그림자 `drop-shadow(0 6px 8px rgba(0,0,0,.35))` | 실제 사진의 세부 |
| 윤곽과 그림의 일치 | 그림 외곽을 따라야 한다 | 투명 PNG 의 알파 외곽을 python 으로 추출해(마칭 스퀘어, 점 60~120개로 줄임) SVG 경로로 저장한다. 이 경로를 전체 선 경로의 해당 구간에 넣는다 | 손으로 그린 듯한 어긋남 |
| 채움 순간 | 없다. CSS 로 된다 | 윤곽이 닫힌 시각에 그림을 불투명도 0 → 1, `scale(.96 → 1)` 0.2초. 선은 그림 위에 남긴다 | 없음 |
| 바탕 종이 결 | 티끌 점과 망점 | `texTile(seed, { mc: '255,255,255', mottle: .02, dark: .02, light: .05, fibers: 0, specks: 180 })` 를 남색 위에 `screen` 으로 깐다. 망점은 SVG pattern(원 지름 2px, 간격 6px, 흰색 불투명도 0.05) | 인쇄물의 고르지 않은 결 |
| 결론부 망점 그물 | 대각선 망점 | SVG pattern 을 45° 회전(원 지름 4px, 간격 10px, #6E8A62 불투명도 0.35) | 없음 |
| 이탤릭 세리프 강조 | 세리프·이탤릭 글꼴이 없다 | 강조 단어는 Pretendard SemiBold 120px #EBAF54, 일반 큰 단어는 SemiBold 120px 흰색, 앞 구절은 Regular 32px 흰색, 연결 단어는 Regular 28px. 강조 단어에만 `transform: skewX(-8deg)` 를 줄 수 있으나 한국어에서는 어색하므로 색으로만 나눈다 | 문학적인 인상 |
| 글자 흐릿하게 나타남 | 없다. DOM 으로 된다 | 글자마다 span, 0.04초 간격으로 불투명도 0 → 1, `filter: blur(6px → 0)` 0.3초 | 없음 |
| 세로 화면 이동 | 없다 | 그림 층 전체를 `translateY` 로 옮긴다. 이동 곡선은 `cubic-bezier(.6,0,.2,1)` 0.6초. 자막 층과 바탕 결 층은 고정 | 없음 |
| 낭독 목소리 | 원본은 낭독으로 추정 | ElevenLabs 낭독(문장 사이 0.3~0.5초 숨). 커넥터가 없으면 무음으로 만들고 자막 교체 간격을 2.0초로 고정 | 문장의 호흡 |
