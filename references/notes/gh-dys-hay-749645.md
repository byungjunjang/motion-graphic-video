# 차량 성능 필름 · 로고가 도식과 차로 이어지는 변형 — 분석 노트

> 고성능 승용차 한 대를 소개하는 15초 브랜드 필름(brand film). 남색이 도는 검정 바탕에 흰 선과 진홍 한 색만 쓴다. 로고 그리기 → 로고의 도형이 엔진 단면 도식으로 변형 → 도식의 부품이 차 옆모습 선 그림으로 변형 → 진홍 바탕의 주행과 실시간 타이머 → 성능 수치 3개 → 로고 끝 카드 순서다. 장면이 바뀌는 여섯 곳이 모두 측정된 마디 첫 박에 맞는다. 내부 구조와 성능 수치가 있는 제품(차량·기계·하드웨어) 소개에 맞는다. 변형(morph) 전환 + 선 그림(line art) + 수치 카운터.

출처 · gh:dys-hay-749645. 작성자의 프롬프트는 271자다(일부만 공개). 만든 도구, 길이, 대상 차종, 제작 방식(코드와 합성음), 연출 의도 두 가지(번쩍이는 순서, 실제 시간으로 흐르는 타이머), 비공식 습작이라는 고지가 있다. 화면 지시는 없다. 이 노트는 영상 프레임(0.5초 간격 30장)을 보고 썼다. 정밀한 시각은 프레임을 따로 뽑아 확인했다.
측정 · 파일 1280x720 · 60fps · 15.1초. 컷으로 잡힌 곳은 1번(13.13초)이다. 프레임으로 보면 화면 전체가 한순간 밝아지는 섬광(flash)이다. 움직임이 큰 구간은 2.0, 5.5, 7.0, 11.0, 12.5, 13.0초에서 시작한다. 모두 장면이 바뀌는 곳이다. 0.8초 이상 정지 구간은 없다. 색 값은 화소를 16단계로 묶어 잰 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. BPM 129.2(마디 1.878초). 타격음 32개, 큰 타격 8개(0.23, 0.34, 0.97, 2.84, 3.32, 3.79, 5.65, 13.17초). 컷 1번이 큰 타격 ±0.1초 안에 있다. 무음 구간은 7개다. 긴 것은 0.00~1.90초(이 안에 큰 타격이 3번 있다), 12.70~13.16초, 14.12~15.06초다.

## 1. 본질

- 색은 세 무리다. 남색이 도는 검정 바탕(#181818·#181828·#080818 근처, 가운데가 조금 밝다), 흰색(선·글자), 진홍(#c80838 근처). 진홍은 앞 절반에서 번쩍임·게이지 호·작은 점에만 쓰고, 7.5~11.2초에만 바탕 전체가 된다.
- 그림은 전부 벡터 도형이다. 원, 호, 점선, 가는 선, 면 채움. 사진·화면 캡처·질감·3D 가 없다.
- 한 무리의 도형이 끝까지 간다. 로고의 도형 → 원 8개 → V 모양 도식 → 차의 엔진 자리 → 끝 카드의 로고. 있던 도형을 옮기고 줄인다.
- 글줄은 왼쪽 위 한 줄뿐이다. 그림은 가운데에 있다. 화면의 절반 이상이 빈 바탕이다.
- 후반은 숫자가 주인이다. 숫자 묶음이 왼쪽 위에, 타이머가 오른쪽 위에 놓인다.
- 아닌 것 · 사진, 실사 차량, 3D 렌더, 입자, 여러 포인트 색, 긴 문장, 하드 컷 연속.

## 3. 움직임

- 변형이 중심이다. 같은 도형이 위치·크기·수를 바꿔 다음 그림의 부품이 된다. 한 번에 0.3~0.5초다. 움직이는 도형에 잔상(motion blur)이 붙는다.
- 번쩍임 · 원 안이 옅은 살구색으로 차고 진홍 고리가 둘레에서 퍼진다. 약 0.3초 안에 빈 원으로 돌아온다. 8칸 순서가 고정되어 되풀이되고, 왼쪽 줄과 오른쪽 줄을 오간다.
- 번쩍임은 타격음과 같은 시각이다. 2.85, 3.3, 3.8초의 번쩍임이 큰 타격(2.84, 3.32, 3.79초)과 ±0.1초 안에 있다. 뒤의 번쩍임도 측정된 타격음과 겹친다.
- 나선 날개 아이콘은 조금 넘치게 커졌다가 제 크기로 돌아오고, 계속 돈다.
- 선은 한쪽 끝에서 자라난다(stroke draw-on). 굵은 로고 선은 0.45초, 가는 차체 윤곽은 0.3초에 그려진다.
- 주행 장면에서 차는 거의 움직이지 않는다. 흐려진 바퀴살, 길이와 높이가 제각각인 가는 속도선, 차 아래 도로 점선 3~4줄이 속도를 만든다.
- 숫자는 바뀌는 자리만 세로로 굴러 넘어가고 잔상이 겹친다. 타이머는 7.5초 무렵 0에서 출발한다. 값은 영상의 실제 경과 시간과 같다. 속도 숫자는 8.45초와 9.4초 무렵에 0.05초쯤 멈췄다가 다시 오른다.

## 4. 전환

- 로고 → 원 8개 → V 도식 → 아이콘·게이지 · 컷이 없다. 변형과 추가뿐이다.
- 도식 → 차 선 그림 · 변형. 줄어든 도식은 쓸기 직전까지 번쩍인다.
- 선 그림 → 주행 → 수치 · 사선 쓸기 2번. 왼쪽 위에서 오른쪽 아래로 지나간다. 첫 쓸기가 지나간 자리의 차는 면으로 채워져 있다. 둘째 쓸기는 바탕만 남색으로 되돌린다.
- 수치 → 끝 카드 · 차 퇴장 → 점 8개 → 섬광 → 로고. 무음(12.70~13.16초) 뒤 큰 타격(13.17초)에 섬광이 온다.
- 장면이 바뀌는 여섯 곳(1.95, 3.8, 5.7, 7.45, 11.2, 13.15초 무렵)이 측정된 마디 첫 박(1.90, 3.78, 5.66, 7.54, 11.29, 13.17초)과 ±0.1초 안에 있다. 한 장면이 한 마디(약 1.9초)다. 주행만 두 마디다.

## 5. 타이포

- 글줄 · 굵은 산세리프, 흰색, 대소문자 섞어 쓰기, 왼쪽 위 고정. 대문자 높이는 화면 높이의 약 7%다. 두세 낱말이고 마침표로 끝난다. 네 줄 모두 "수량 낱말 + 대상" 꼴이다. 줄의 수량이 그때 화면에 있는 도형의 수와 같다.
- 등장·교체 · 한 자씩 세로로 민다. 옛 글자는 위로 나가고 새 글자는 아래에서 올라온다. 왼쪽 글자부터 시차를 둔다. 한 줄이 바뀌는 데 약 0.4초다.
- 숫자 묶음 · 아주 굵은 큰 숫자(화면 높이의 약 13%) + 기준선에 맞춘 작은 단위(숫자 높이의 1/3) + 숫자 위의 아주 작은 대문자 라벨.
- 끝 카드 · 가운데 정렬. 로고 아래에 굵은 모델 이름(왼쪽에 작은 진홍 표지), 가는 회색 설명 두 낱말. 맨 아래에 어두운 회색의 작은 대문자 고지.

## 6. 가져올 것

- 로고의 도형을 다음 그림의 부품으로 쓰는 변형 사슬. "로고 → 내부 구조 도식 → 제품 외형 → 로고"로 돌아온다.
- 한 마디에 한 장면. 전환을 마디 첫 박에 두고, 주된 장면에만 두 마디를 준다.
- 반 박마다 한 칸씩 번쩍이는 도식. 타격음 하나에 번쩍임 하나를 맞추고 순서를 고정한다.
- "수량 + 대상" 한 줄. 그림의 도형 수와 글줄의 수량을 맞춘다.
- 실제 시간으로 흐르는 타이머. 화면의 숫자와 영상의 경과 시간이 같다.
- 바탕색 반전. 포인트 색이 바탕 전체가 되는 구간을 한 번만 둔다.
- 무음 → 섬광 → 로고로 닫는 끝.

## 7. 함정

- 화면의 글줄, 모델 이름, 성능 수치, 로고는 원작이 다룬 실존 브랜드의 것이다. 옮기지 않는다. 역할(수량 한 줄, 성능 수치 3개, 로고와 이름의 끝 카드)만 가져온다.
- 변형 사슬은 로고가 단순한 도형 몇 개일 때만 성립한다. 소개할 대상의 로고와 내부 구조에 닮은 도형이 없으면 중립 도형(점·원·막대)에서 출발한다.
- 차 옆모습은 3D 가 아니지만 그릴 것이 많다. 윤곽·창·바퀴살을 SVG 경로(path)로 그리고, 선 판과 면 판을 같은 좌표로 겹쳐야 쓸기 한 번에 바뀐다. 실존 제품의 외형을 흉내 내어 그리지 않는다.
- 번쩍임 간격이 0.235초다. 박 시각표 없이 눈대중으로 넣으면 소리와 어긋난다.
- 도식 안의 글자와 맨 아래 고지는 원본 1280x720 에서 읽기 어렵다. 읽혀야 하는 글자는 키운다.
- 성능 수치는 하나에 약 0.47초다. 한국어 라벨은 이 시간에 읽히지 않는다. 30~40초로 늘릴 때 수치 하나에 0.8초 이상을 준다.
