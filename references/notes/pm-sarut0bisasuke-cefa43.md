- 수치 카운트업은 분수 단위다(¼ 씩). 숫자가 바뀌는 순간과 액체 높이가 눈금을 지나는 순간이 같다. ¾ 단위 눈금 간격은 72px(화면 높이 6.7%)다. 1 단위는 약 96px 이다. 단위 아래에 ml 환산값이 고정폭 글자로 함께 바뀐다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 22.5초 구도. 왼쪽 판(66.8%)에 진행 막대 4칸 찬 상태, 단계 글(이름 높이 4.6% + 큰 분수 11.6%), 잔(가로 28~47%, 세로 41~86%) 위 오른쪽에서 주전자가 크림을 붓고 짙은 층 위에 옅은 층이 생긴다. 오른쪽 띠(33.2%)에는 손글씨 제목 두 줄과 체크리스트 4줄 중 3줄 체크, 4줄째에 화살표. 동시에 보이는 무리는 6개(진행 막대, 단계 글, 잔, 붓는 도구, 제목, 체크리스트)다.
- 12초 판 압축 예 · 판 깔기 1.2초(잔 선 + 제목 + 체크리스트를 겹쳐서) → 얼음 1.0초(숫자 0 → 3) → 붓기 세 번 각 2.6초(솟음 0.3, 붓기 1.8, 사라짐 0.5) → 빨대 1.0초 → 끝 손글씨 1.0초. 첫 진입의 왼쪽 안내 문장과 젓기 화살표 타원은 뺀다.
- 좌우 분할(2:1). 왼쪽은 "지금 무엇을 하나", 오른쪽은 "전체 목록과 지금 위치"를 맡는다. 단계 설명 영상에 그대로 쓸 수 있다.
- 체크리스트 + 진행 막대 + 큰 수치를 한 동작에 묶는 규칙. 숫자·액체·눈금 화살표가 같은 값으로 움직이고, 동작이 끝나는 순간 체크가 그어진다.
- 분수 카운트업. 정수가 아닌 단위로 세면 "재는 중"이라는 느낌이 산다.
- 층으로 쌓이는 액체. 섞이지 않는 단계를 색 층으로 보인다.
- 끝 손글씨 한 줄 + 잉크 튄 자국. 큰 효과 없이 마무리한다.

  - 진행 표시 · 이쪽은 위쪽 5칸 막대가 연속으로 차고, 오른쪽 체크리스트가 따로 있다. 정사각 쌍은 아래 6개 진행 점(체크 원)과 카드 안 채움 막대다.
  - 수치 · 이쪽은 분수(¼ 단위) 손글씨다. 정사각 쌍은 소수(0.1 단위) 팝 글꼴이다.
  - 액체 · 이쪽은 층이 쌓이고 크림이 구름처럼 번진다. 정사각 쌍은 색이 섞여 분홍 → 와인색으로 진해진다.
  - 단계 전환 · 이쪽은 0.15초 교차 페이드다. 정사각 쌍은 카드가 사라지고 큰 수치가 1~2프레임 번쩍한 뒤 기운 카드가 선다.
  - 병 위치 · 이쪽은 잔 오른쪽 위에 아래에서 솟는다. 정사각 쌍은 왼쪽 위 밖에서 미끄러져 들어온다.
  - 끝 · 이쪽은 손글씨 한 줄 + 잉크 자국이다. 정사각 쌍은 반짝임 선 8개 + 잔 흔들림 + 감탄 카드다.
  - 움직임 세기 · 이쪽 0.68, 정사각 쌍 1.46. 이쪽이 절반쯤 조용하다.
- 너무 조용하다. 12초 판에서 붓기를 1.8초로 줄여도 움직임은 작다. 숫자와 액체가 멈추는 순간이 없게 이어 붙인다.
- 손글씨 글꼴이 없다. 한국어로 옮기면 붓펜 느낌을 잃는다(8번 표). 제목을 140px 보다 크게 쓰지 않는다.
- 분수 글리프(¼ ½ ¾)는 한국어 영상에서 낯설다. 한국어 판은 소수(0.25 단위)나 ml 정수로 센다. 단위를 하나로 정하고 섞지 않는다.
- 크림이 번지는 구름 무늬를 흐린 원 여러 개로 대신하면 액체 밖으로 새기 쉽다. 반드시 잔 안쪽 경로로 clip 한다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 글꼴은 Pretendard Regular·SemiBold, 숫자·라틴은 InterVariable 도 쓴다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 붓펜 손글씨 제목·숫자 | 손글씨 글꼴이 없다 | 제목은 Pretendard SemiBold 120px, 색 #3A2A1E, 자간 -0.03em, 두 줄, 둘째 줄 40px 들여쓰기. 큰 수치는 InterVariable 굵기 600, 125px, `font-style: oblique 8deg`. 써지는 등장은 왼쪽부터 `clip-path: inset(0 X% 0 0)` 을 0.4초에 푼다 | 붓 끝의 굵기 변화와 손맛 |
| 고정폭 머리말·주석 | 고정폭 글꼴이 없다 | InterVariable 14px, `font-variant-numeric: tabular-nums`, 대문자, 자간 0.3em, 색 #8A7A6A 근처. 한국어 주석은 Pretendard Regular 16px, 자간 0.15em | 타자기 같은 고른 폭 |
| 손으로 그은 밑줄 | 붓 끝의 결 | `HAND.ribbon(ctx, P, u => 2 + 2.5 * Math.sin(Math.PI * u), { color: '#3A2A1E' })`. 길이 500px, 오른쪽 끝이 12px 올라가게 P 를 준다 | 거의 없음 |
| 체크 표시가 그어짐 | 손 획 | SVG path(꺾인 선 2획) stroke 5px #AB683B, `stroke-dasharray` 를 0.3초에 푼다. 끝이 원 밖으로 8px 나가게 그린다 | 거의 없음 |
| 선화 잔·병·주전자 | 거친 선 | SVG path 를 `HAND.wobble(P, true, 1.5, 'glass', 0)` 으로 한 번 굽혀 고정. stroke 4px #3A2A1E. 병 라벨 안은 글자 대신 가로줄 2개. 또는 `codex-image` 로 글자 없는 병·주전자를 그려 `key.py` 로 투명화 | 라벨 글자의 정보 |
| 층으로 쌓이는 액체 | 잔 안에서만 보여야 한다 | 잔 안쪽 path 를 `clipPath` 로 쓰고 층마다 rect 를 쌓는다(투명 술 #D8E3E7 opacity 0.6, 짙은 술 #362012, 크림 #EADCC4). 짙은 술은 바닥 rect 가 먼저 커진 뒤 위 rect 가 덮는다(1.0초 차) | 경계의 자연스러운 번짐 |
| 크림 구름 무늬 | 유체 | 같은 clip 안에 흰 타원 6개(지름 80~160px, 색 #A08870, `filter: blur(10px)`, opacity 0.6)를 두고 2초에 걸쳐 아래로 40~120px 내린다. canvas 면 `HAND.washPlate` 로 구운 판 3장을 multiply 로 얹는다 | 실제 소용돌이 모양 |
| 종이 판과 띠의 겹침 그림자 | 없다 | 띠 div 에 `box-shadow: inset 30px 0 30px -20px rgba(120,90,60,.25)`. 종이 결은 `texTile(seed, { mc: '120,95,60', mottle: .02, fibers: 60, specks: 8 })` 를 아주 옅게 깐다 | 없음 |
| 잉크 튄 자국 | 무작위 방울 | 원 12개(지름 4~40px, #5A4A3E)를 씨앗 난수로 한 번 정해 고정한다. 큰 원 하나 + 작은 원 무리. scale 0 → 1 을 0.1초에 | 방울의 꼬리 모양 |
