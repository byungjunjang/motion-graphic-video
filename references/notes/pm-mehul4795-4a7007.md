# 사진 글자 인식 앱 런치 · 연한 바탕 세로 카드 UI — 분석 노트

> 사진 속 글자를 읽어 텍스트로 바꿔 주는 휴대폰 앱의 33.5초 세로 런치 영상(launch video)이다. 연보라빛 흰 바탕에 흰 카드 UI, 짙은 남색 굵은 산세리프, 포인트 네 색을 쓴다. 훅 문장 → 아이콘 조립 → 기능 다섯 장(사진 스캔, 언어 수, 손글씨, 내보내기, 기록 검색) → 평점 카드 → 끝 카드 순서다. 기능 장마다 같은 틀(라벨 + 두 줄 제목 + 원본 + 결과 + 완료 알림)을 되풀이한다. 모바일 앱·생산성 도구 소개에 맞는다. 미니멀 UI(minimal UI), 에디토리얼(editorial).

## 1. 본질

- 바탕은 연보라빛 흰색(#E8E8F8 근처 30%, #F8F8F8 근처 22%)이다. 크게 흐린 파스텔 원 4개(분홍, 연보라, 살구, 초록)가 움직이지 않고 깔려 있다.
- 글자는 짙은 남색(#181838 근처), 보조 글은 회남색(#384868 근처)이다. 포인트는 산호 빨강(#F85848 근처, 취소선·+ 기호·구분 점), 노랑(#F8B868 근처, 별·검색어 형광), 초록(#389868 근처, 스캔선)이다. 이 줄의 색은 프레임에서 직접 잰 값이다. 스캔 틀의 네 모서리는 왼쪽 위부터 산호·남색·노랑·초록이다.
- UI 는 흰 둥근 카드와 알약이다. 그림자는 옅고 넓다. 원본은 약간 기운 크림색 종이 카드(#F8F8E8 근처, 세리프 본문)와 줄 친 노란 메모지(#F8F8D8 근처, 필기체)다. 휴대폰은 두꺼운 남색 테두리 하나로 그린다.
- 스캔하는 "사진"도 코드로 그린 종이 카드다.
- 아닌 것 · 사진, 실제 앱 캡처, 손가락·마우스 커서, 3D, 어두운 바탕, 하드 컷·디졸브(dissolve), 화면 흔들림.

## 3. 움직임

- 등장은 세 가지다. 낱말 단위로 옅게 나타나며 조금 올라오기(0.1초 간격). 작게 시작해 커지기(칩, 타일, 알약, + 기호). 아래에서 떠오르기(결과 카드, 알림, 0.1~0.3초).
- 타이핑 끝에 세로 막대 캐럿(caret)이 붙는다. 기능 1 은 한 프레임에 3~4자, 검색어는 0.12초에 한 자를 친다.
- 언어 수 계수기는 1.6초 동안 끝으로 갈수록 느려진다(ease-out).
- 스캔선은 1.5초 동안 약 550px 내려간다. 처음과 끝이 느리다(ease-in-out). 선 위로 옅은 초록 꼬리가 붙는다.
- 장마다 완료 표시 뒤에 0.6~1.8초 멈춘다. 정지 중에도 언어 칩은 천천히 떠다닌다.
- 누름은 손가락 없이 보여 준다. 타일이 조금 작아지고 회색이 된 뒤 알림이 뜬다.

## 4. 전환

- 밀기(push) 3번. 4.93초는 위로, 14.57초와 22.33초는 왼쪽으로 민다. 세 번 모두 약 0.4초 동안 거의 같은 속도로 화면 하나를 간다(한 프레임에 위로 약 160px, 왼쪽으로 약 90px).
- 겹쳐 띄운 뒤 지우기 5번. 새 장면의 첫 요소(아이콘, 숫자, 제목, 카드)가 앞 장면 위에 0.2~0.37초 겹쳐 나온다. 그 뒤 앞 장면이 한 프레임에 사라진다. 장면 사이에 빈 화면이 없다.

## 5. 타이포

- 제목은 굵은 기하 산세리프다. 두 줄, 가운데 정렬, 끝에 마침표. 대문자 높이는 화면 높이의 약 3.8%(장 제목), 6.3%(훅, 평점 숫자, 워드마크), 10%(언어 수 숫자)다.
- 장 제목 위 라벨은 넓은 자간의 작은 대문자 2~4낱말이다. 대문자 높이 약 1.3%.
- 본문은 보통 굵기 산세리프다. 원본만 세리프(종이)와 필기체(메모지)를 써서 결과와 갈린다.
- 강조는 산호 빨강 하나다. 검색어만 노란 형광 표시를 쓴다.
- 숫자 뒤에 단위 기호(+, K, M)를 붙이고 카드 오른쪽에 작은 회색 라벨 두 줄을 둔다.

## 6. 가져올 것

- "훅 한 줄 → 아이콘 조립 → 기능 장 → 평점 숫자 → 같은 아이콘의 끝 카드" 뼈대와 기능 장마다 같은 틀.
- 밀기와 겹쳐 띄운 뒤 한 프레임 지우기를 섞는 장면 교체.
- 원본은 위(약간 기운 종이), 결과는 아래(곧은 흰 카드), 사이에 스캔선이나 화살표를 두는 배치.
- 훅의 취소선. 산호색 굵은 선을 0.3초에 긋는다. 선은 살짝 기울고 낱말 양 끝을 넘는다.
- 계수기가 멈춘 뒤 0.2초 늦게 색 있는 + 기호를 붙인다.
- 끝 카드에서는 단추만 계속 커졌다 작아진다.

## 7. 함정

- 화면의 문장, 앱 이름, 스토어 이름, 제작사 이름, 예시 문서의 글은 원작의 것이다. 옮기지 않는다. 역할(훅 문장, 기능 제목, 예시 문서, 검색어)만 가져온다.
- 원본은 세로 1080x1920(9:16)이다. 16:9 에서는 제목·UI·알림의 세로 쌓기가 높이를 넘는다. 제목은 왼쪽 열, UI 는 오른쪽 열로 나누고 평점 카드는 가로 3열로 바꾼다. 왼쪽 밀기는 거리가 1920 으로 늘어 0.4초면 한 프레임에 160px 를 간다.
- 아이콘 조립은 원작 로고의 생김새를 따른다. 대상의 허락받은 로고나 이름 글자로 바꾼다.
- 숫자(언어 수, 평점, 다운로드·리뷰 수, 처리 시간)는 원문에서 확인한 값만 쓴다. 없으면 평점 장을 뺀다.
- 라벨, 결과 카드 본문, 휴대폰 안 목록 글자가 아주 작다. 키운다.
- 한국어는 장 제목을 두 줄 대구로 맞추고 0.1초 간격을 어절 단위로 바꾼다. 메모지에는 한글 손글씨 글꼴이 필요하다.
