## 7. 함정

- 화면의 공연장 이름과 로고, 악단 이름과 로고, 옛 영화의 상징(무지개, 노랑 벽돌 길, 회오리), 실존 인물을 그린 끝 장 포스터는 모두 실존 대상이다. 다른 대상에서는 쓰지 않는다. 끝 장 인물 그림은 사용자 사진을 바탕으로 한 것으로 보인다. 사용자가 허락한 사진이 아니면 넣지 않는다.
- 제목·설명 카드 문구, 수치, 날짜는 원작의 것이다. 옮기지 않는다. 역할(날짜 알약, 단계 제목, 핵심어 하나 빨강)만 가져온다.
- 구 모양 건물과 바늘 탑 실루엣은 특정 장소를 떠올리게 한다. 다른 대상에서는 그 대상의 모양으로 바꾼다.
- 정지 구간이 두 곳(31~32초, 37~38초) 있다. 12초 판에서는 정지를 0.5초 넘게 두지 않는다.
- 세로 화면(720x1280)을 16:9(1920x1080)로 옮기는 구도.
  - 건설 장 · 구 지름을 화면 높이의 57%(약 620px)로 두고 중심을 가로 62%, 세로 50%에 둔다. 땅선은 세로 80%. 왼쪽 열(가로 6~38%)에 날짜 알약(세로 30%), 제목(세로 38%, 글자 높이 80px), 설명 카드(세로 55~68%, 폭 560px)를 세로로 쌓는다. 연도 눈금자는 위쪽 세로 7%, 가로 10~90% 로 넓혀 눈금 간격을 약 190px 로 둔다. 도시 소품은 구 양옆(가로 40~50%, 80~95%)에 둔다.
  - 처음 수치 · 숫자 높이 200px(18.5%)로 가운데 정렬한다. 세로판의 10% 보다 화면 대비가 커진다.
  - 개장 장 · 포스터를 왼쪽(가로 18~45%, 세로 15~90%)에, 색 카드 4장을 오른쪽 2x2(가로 52~88%, 카드 한 장 330x170px)에 둔다.
  - 목록 장 · 줄 7개를 한 열(가로 25~75%, 줄 높이 64px, 세로 22~82%)로 두거나 두 열(4줄 + 3줄, 열 폭 760px)로 나눈다. 도장은 오른쪽 아래(가로 75%, 세로 78%).
  - 끝 장 · 포스터를 가운데(가로 34~66%, 세로 12~88%)에 두고, 외침 글자를 포스터 왼쪽에, 날짜 띠를 오른쪽에 세로로 둔다. 빛살 중심은 화면 가운데.
- 한국어 제목은 풍선 글꼴이 없다. Pretendard SemiBold 에 테두리와 그림자를 더한다. 140px 를 넘기지 않는다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 16:9(1920x1080) 판 기준이다. 글꼴은 Pretendard Regular·SemiBold 와 InterVariable(숫자)만 쓴다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 굵은 풍선 제목 | 풍선 글꼴이 없다 | Pretendard SemiBold 80px, 색 #9AA3B5, `-webkit-text-stroke: 3px #FFFFFF` 를 한 겹, 그 뒤 같은 글자 복제에 `-webkit-text-stroke: 10px #2C3240` + `text-shadow: 5px 6px 0 #2C3240` | 둥근 글자 모양의 귀여움 |
| 구의 그물과 단계별 쌓기 | 없다. SVG 로 된다 | SVG 원(반지름 310px) 안에 위도선 9개(타원), 경도선 11개(세로 타원), 굵기 6px #2C3240. 각 줄에 `clip-path` 를 주어 아래에서 위로 0.5초마다 한 줄씩 공개. 꼭대기 고리는 타원 80x22px #B8BCC8 | 없음 |
| 외피 빗금 채움 | 아래에서 차오르는 빗금 | canvas 에 `HAND.hatch(ctx, circleP, { angle: 0.8, gap: 7, w: 2, color: '#8E95A6' })` 를 그리고, 사각 마스크 높이를 0 → 620px 로 1초에 올린다. 면은 #C8CCD6 | 손으로 그은 빗금의 강약 |
| 도시 소품(건물, 야자수, 탑, 기중기) | 그릴 것이 많다 | AI 일러스트(codex-image, 글자·로고 없이, 마젠타 바탕)로 소품 4종을 한 장에 굵은 윤곽 만화 화풍으로 그리고 `scripts/key.py --split` 으로 자른다. 탑은 실존 건물을 닮지 않은 모양으로 지시한다 | 윤곽선 굵기의 완전한 통일 |
| 채도 0 멈춤 장 | 없다 | 장면 전체 div 에 CSS `filter: grayscale(1)` 을 0.1초에 주고 2초 뒤 0.2초에 푼다. 소리도 같은 구간을 비운다 | 없음 |
| 고무 도장 | 잉크 결 | SVG 둥근 사각(520x160px, 테두리 8px, #6A5A5A) 안 Pretendard SemiBold 96px, 회전 -8도. 결은 `HAND.stipple` 로 종이색 점 200개를 덮는다. 0.15초에 크기 1.5 → 1.0, 앉을 때 장면 전체를 3px 흔든다 | 도장의 번짐 |
| 빛나는 구의 소용돌이 | 발광 그림 | canvas 원 안에 `createLinearGradient` 띠 4개(#3A5BD9, #8A5CE0, #E07AC8, #5AC8F0)를 sin(t) 로 휘게 그리고, 그물 칸 위에 지름 6px 점 격자를 겹쳐 점 화면처럼 보이게 한다. 둘레에 `filter: blur(24px)` 빛 번짐 | 실제 점 화면의 해상감 |
| 눈알 그림(점 화면 효과) | 구 위 영상 | 다른 대상에서는 쓰지 않는다. 같은 장치가 필요하면 대상의 상징 하나를 SVG 로 그려 위 점 격자로 덮는다 | 원작의 화제성 |
| 포스터와 색 카드 | 없다. DOM 으로 된다 | 포스터 div 620x880px, 흰 #F7F4EC, 테두리 6px, 그림자 10px 12px 0, 회전 -3도, 위 모서리에 반투명 노랑 테이프(140x40px, 투명도 0.7, 회전 ±20도). 카드는 330x170px, 노랑 #F0B43C · 하늘 #5AD0F0 · 분홍 #F06CAE · 초록 #3EB46A, 0.5초 간격으로 크기 0.6 → 1.1 → 1.0 | 없음 |
| 끝 장 노랑 빛살 | 없다 | CSS `repeating-conic-gradient(#F8C838 0 10deg, #F8B808 10deg 20deg)` 를 화면보다 큰 원 div 에 깔고 seek 에서 각도 = t * 12도. 색종이는 씨앗 난수 사각 60개 | 없음 |
| 끝 장 인물 그림 | 실존 인물 | 사용자가 준 사진만 쓴다. 없으면 인물 대신 대상의 상징 그림을 AI 일러스트(글자·로고 없이)로 그린다 | 개인적인 결말의 힘 |
