## 3. 움직임

- 원래 글의 펜 속도, 떨림(2프레임마다), 그린 뒤 정지 규칙은 화면과 맞다.
- 영상에서 확인한 점 · 움직임 세기의 중앙값이 4.9 로 낮다. 화면 변화 대부분은 펜이 선을 더하는 작은 변화다. 큰 값은 카메라 이동(뛰어들기·나오기·밀기·물러나기)에서만 나온다.
- 카메라 이동 사이에도 화면이 비지 않는다. 30.2~36.0초처럼 카메라가 거의 멈춘 구간에서도 막대가 아래부터 차오르고 퍼센트 숫자가 써진다.
- 한 요소의 순서는 외곽선 → 회색 빗금 → 노란 빗금 → 그림자 → 이름표다. 꽃(10.5~14.0초)은 상자 외곽선 0.7초, 리본 0.5초, 꽃 외곽선 1.0초, 낱말 0.6초, 설명 두 줄 1.2초가 걸렸다.
- 노란 마커 칠은 한 획씩 빗금이 쌓이는 모양이다. 면이 한 번에 차지 않는다.

## 4. 전환

- 컷·페이드·페이지 넘김이 없다는 원래 글의 규칙은 맞다. 단 하나의 예외가 15.62초 모양 맞춤 컷이다.
- 모양 맞춤 컷 · 꽃 가운데 노란 원(15.5초, 지름 약 360px, 화면 가로 약 47~66%)이 컷 뒤 같은 자리·같은 크기의 노란 원으로 남는다. 주변 꽃잎과 상자는 사라지고 빈 점 격자만 남는다. 그 뒤 4초 동안 원 둘레에 벌 몸이 그려지며 물러난다.
- 뛰어들기(19.9~20.5초)는 0.6초, 나오기(23.0~23.5초)도 약 0.6초다. 둘 다 움직임 세기 45 이상으로 영상에서 가장 빠르다. 뛰어든 안쪽에서는 선이 가늘어진다(분자 도형 선 굵기 약 3px, 바깥 외곽선 약 9px).

## 5. 타이포

- 손글씨 세 종류 · 리본 속 굵은 대문자 손글씨, 낱말 강조용 굵은 손글씨, 설명용 가는 손글씨. 모두 펜과 같은 검정이다.
- 크기(화면 높이 대비) · 첫 장면 손글씨 약 7%, 상자 속 낱말 약 4.9%(34.5초), 설명 약 3%, 끝 포스터에서 가장 작은 설명 약 1.4%(약 15px).
- 자막 쪽지는 손글씨가 아니다. 위 줄 중국어 약 30px(2.8%), 아래 줄 영어 약 22px(2.1%), 가운데 정렬. 모든 장면에서 같은 자리에 머문다.
- 손글씨는 획 순서대로 써진다. 한 낱말에 약 0.4~0.7초.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 44.2~47.4초의 "큰 숫자 메모에서 종이 전체로 2.5초 동안 물러나며, 비어 있던 제목·정리 상자를 펜 여러 자루가 동시에 채워 포스터 한 장이 되는" 장면이다. 끝 화면은 블록 8개(제목 리본 1, 위 줄 4, 아래 줄 3)가 종이의 약 80% 를 쓰고, 노란색은 화면의 약 3% 로 핵심 셋(제목 마지막 낱말, 큰 숫자, 결론 낱말)에만 있다. 이 물러나기가 없으면 손그림 설명 화면일 뿐이고 이 스타일이 아니다.
- 12초 판 압축 예 · 0~1.5초 빈 점 격자에 첫 사물 외곽선과 손글씨 한 줄(화면 높이 7%), 1.5~2.0초 빈 종이를 휙 지나 첫째 상자로, 2.0~4.0초 첫째 상자(리본 → 아이콘 → 낱말), 4.0~4.6초 아이콘의 노란 원으로 밀기, 4.6~6.0초 모양 맞춤 컷 뒤 원 둘레에 둘째 그림, 6.0~8.0초 셋째 블록의 막대 비교(회색 대 노랑), 8.0~9.0초 큰 숫자 줄과 노란 띠, 9.0~11.0초 대표 장면 물러나기 2초(제목과 정리 상자 동시 완성), 11.0~12.0초 포스터 정지와 핵심 숫자에 노란 고리. 분자 뛰어들기, 바람 선, 병 차오르기, 꽃 아홉 개는 뺀다. 블록은 위 줄 3개 + 아래 줄 2개로 줄인다.
- 포스터를 먼저 짜고, 영상은 그 포스터가 그려지는 과정으로 만든다. 블록마다 끝 포스터 좌표를 먼저 정하고 카메라가 그 좌표를 찾아간다.
- 노란색은 한 줄기 이야기에만. 리본과 화살표 외에는 핵심 숫자·결론 낱말에만 쓴다.

## 7. 함정

- 화면의 제목, 낱말, 숫자, 자막, 머리표는 원작의 것이다. 옮기지 않는다. 역할(제목 리본, 단계 번호 리본, 핵심 숫자 한 줄, 정리 상자)만 가져온다.
- 바닥 제작 표기에 실존 제작자·서비스 이름이 있다. 쓰지 않는다.
- 끝 포스터 글자가 작아진다. 원본도 가장 작은 설명이 약 15px 다. 1920 기준 끝 화면에서 한국어 설명은 22px 이상, 블록 낱말은 34px 이상으로 둔다. 그러려면 블록을 8개 넘게 두지 않는다.
- 노란색이 넘치면 핵심이 사라진다. 끝 화면에서 노란 면이 화면의 5% 를 넘지 않게 한다.
- 단색 회색 칠은 클립아트처럼 보인다. 회색·노랑 모두 빗금 질감으로 칠한다.
- 그림자 방향이 섞이면 종이 느낌이 깨진다. 오른쪽 아래 한 방향, 어긋남 6~10px 로 고정한다.
- 카메라가 빈 종이에 먼저 도착하면 빈 프레임이 생긴다. 원본처럼 이동이 끝나기 0.3~0.5초 전에 도착지의 첫 획을 시작한다.
- 점 격자를 화면에 고정하면 카메라가 움직이지 않는 것처럼 보인다. 점 격자는 종이 좌표에 붙여 배율과 함께 늘고 줄게 한다.
- 원래 글의 함정 절(번쩍임, 한 번에 나타나는 글자, 뛰어들 때 굵은 선)은 그대로 맞다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준, 종이 좌표는 배율 1 기준이다. 종이 전체 크기는 약 2280 x 1290px(끝 화면 0.84배에서 화면을 꽉 채우는 크기)로 둔다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 손글씨 글자 | 손글씨 글꼴이 없다. 한국어 글자를 획 순서대로 쓰는 경로 자료가 없다 | 글자는 DOM 층에 Pretendard SemiBold(낱말·리본 속, 종이 좌표 40~56px)와 Regular(설명, 26~30px)로 둔다. 써지는 등장은 글자 단위로 0.05초씩 차례로 `clip-path: inset(0 100% 0 0)` → `inset(0 0 0 0)` 을 0.12초에 연다(한 낱말 약 0.5초). 글자 덩어리 전체를 페이드하지 않는다. 숫자·라틴 표기는 InterVariable 굵기 700 을 쓴다 | 획 순서와 손맛 |
| 떨리는 외곽선과 그려지는 등장 | 펜 선의 미세한 떨림과 획 순서 | canvas 에 `HAND.ink(ctx, P, { frac, w: 6, color: '#201D20', key, B })`. 상자는 둥근 모서리 사각형 점 배열(모서리 반지름 24px), 아이콘은 직접 짠 점 배열. `B` 는 2프레임마다 바뀌는 칸 번호(0~2)로, `amt` 는 1.2 로 작게. 상자 외곽선 0.7초, 아이콘 외곽선 1.0초에 `frac` 0 → 1 | 손으로 그은 획의 압력 변화 |
| 마커 빗금 칠 | 마커 획이 겹치는 농도 | `HAND.paint(ctx, P, { fill: '#FFD246', tex: [{ k: 'hatch', angle: 0.7, gap: 10, w: 5, color: '#F8A522', alpha: 0.7 }], line: '#201D20', w: 6, key, B })`. 회색은 fill `#DEDCDB` 위에 hatch color `#A5A3A4`, 진한 회색은 fill `#C4C2BF` 위에 color `#858380`. 칠이 쌓이는 등장은 `HAND.trace` 로 만든 경로에 clip 을 걸고, 빗금 방향으로 움직이는 사각형 마스크를 0.4초에 지나가게 한다 | 마커가 겹친 자리의 진한 얼룩 |
| 오른쪽 아래 그림자 | 회색 마커로 그린 그림자 띠 | 같은 외곽 점 배열을 (8px, 8px) 옮겨 `HAND.paint` 로 fill 없이 `tex: [{ k: 'hatch', angle: 0.7, gap: 6, w: 2, color: '#A5A3A4', alpha: 0.6 }]`, `line: false`. 본체를 그 위에 그리고 본체 안쪽은 종이색 #FBF9F6 으로 먼저 칠해 그림자를 가린다 | 없음에 가깝다 |
| 점 격자 종이 | 없다. 코드로 그대로 된다 | 로드 때 오프스크린 canvas 에 종이 #FBF9F6, 점 #B5B5B3 지름 2.4px(종이 좌표), 간격 26px 로 한 번 굽고, seek 에서 카메라 변환을 걸어 `drawImage` 한다. 결은 `texTile(seed, { mc: '128,128,128', mottle: .02, dark: .02, light: .03, fibers: 60, specks: 8 })` 를 곱하기로 아주 옅게 | 없음 |
| 카메라(배율·이동) | 없다. 코드로 그대로 된다 | 종이 좌표 → 화면 변환 하나로 그린다. 배율은 로그 공간에서 보간하고, 큰 배율 변화에서는 중심 이동을 1/배율에 맞춘다. 물러나기 1.9 → 0.84배를 2.5초에, 끝 0.5초는 감속. 뛰어들기는 0.6초에 8~14배 | 없음 |
| 모양 맞춤 컷 | 없다 | 컷 앞 프레임의 노란 원 중심·지름을 기록해 두고, 컷 뒤 장면의 노란 원을 같은 화면 좌표·같은 지름(약 360px)으로 놓는다. 컷 뒤 0.2초 동안 원 밖은 빈 점 격자만 둔다 | 없음 |
| 벌·꽃·벌집 같은 아이콘 | 그림 양이 많고 손그림 맛이 필요하다 | 간단한 아이콘은 위 `HAND.ink`·`HAND.paint` 점 배열로 직접 그린다. 복잡한 그림(벌처럼 날개·다리가 많은 것)은 AI 일러스트(codex-image)로 검은 외곽선 + 회색·노랑 빗금 마커풍, 마젠타 바탕, 글자 없음으로 그리고 `scripts/key.py` 로 자른다. 그려지는 등장은 외곽선만 `HAND.ink` 로 따로 그리고, 일러스트 칠은 그 뒤 0.4초 마스크로 연다 | 일러스트 선과 코드 선의 굵기가 미세하게 다르다 |
| 자막 쪽지 | 없다 | DOM 판 · 배경 #FAF8F5, 그림자 0 2px 6px rgba(0,0,0,0.08), 폭 약 700px, 화면 가로 가운데·세로 88~98%. 왼쪽 위에 #D9D7D6 사각형(66 x 16px, -4° 회전)을 테이프로. 위 줄 Pretendard SemiBold 34px #201D20, 아래 줄 Regular 24px #555 | 없음 |
