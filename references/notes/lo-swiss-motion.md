## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 24.0~30.0초의 "흰 포스터(705 x 1007px) 속 빨간 원(지름 180px)이 혼자 격자를 무시하고 직선으로 미끄러져 포스터 가장자리에 걸리고(지름 360px), 옆의 좌표 표시가 빨간 경고로 바뀌며, 나머지 막대는 가까운 것부터 칸에 딱 맞게 다시 서고, 그 뒤 포스터가 1.5박에 90도 돌아 멈추는" 장면이다. 원만 다르게 움직이지 않으면, 큰 숫자와 작은 메모의 크기 대비가 없으면, 큰 움직임이 마디 첫 박에 떨어지지 않으면 이 영상이 아니다.
- 12초 판 압축 예 · 120 BPM 이면 12초는 6마디다. 0~1.0초 빨간 가로줄과 격자 기둥, 1.0~2.0초 포스터 닦아 내기, 2.0~4.0초 규칙 1·2 를 1마디씩 압축(큰 숫자 + 포스터 변화 하나씩), 4.0~6.0초 규칙 3·4(칼로 자르기 한 번, 빨간 원 앉기), 6.0~9.0초 대표 장면(깨기 0.5 + 원 이동 1.5 + 다시 짜기 0.5 + 90도 돌리기 0.5), 9.0~10.5초 재생선이 한 마디를 지나며 막대가 빨개진다, 10.5~12.0초 같은 체계 포스터 셋으로 물러났다가 빨간 줄로 끝. 규칙 5 화면, 평가 한 줄, 포스터 다섯 장 판의 문구는 뺀다.
- 원인·결과 두 면 구도. 왼쪽 면의 규칙이 오른쪽 면을 바꾼다.
- 예외 하나에만 다른 움직임 문법을 준다.
- 화면 구조 자체를 박자표로 쓴다. 넘어가기 = 마디 첫 박.

## 7. 함정

- 화면의 제목, 규칙 문장, 평가 한 줄, 포스터 속 문구(공연 이름·날짜·장소·가격), 끝 크레딧은 원작의 것이다. 옮기지 않는다. 역할(규칙 한 줄, 포스터 제목, 정보 묶음, 끝 제목)만 가져온다. 끝 크레딧에 실존 글꼴 이름과 실존 서비스 이름이 있다. 쓰지 않는다.
- 이 스타일의 이름은 실존 나라 이름에서 왔다. 우리 화면과 문서에는 "격자 타이포" 같은 일반 이름만 쓴다.
- 큰 숫자를 작게 두면 평범한 발표 화면이 된다. 숫자 높이를 화면 높이의 60% 이상(650px 이상)으로 둔다. 숫자는 아라비아 숫자라서 한국어 140px 규칙에 걸리지 않는다.
- 한국어 규칙 한 줄을 크게 키우고 싶어도 140px 이하로 둔다. 원본의 규칙 한 줄도 54px 정도다. 크기 대비는 숫자가 맡는다.
- 넘어가기를 박과 상관없이 두면 이 스타일이 사라진다. 장면 시각표를 먼저 마디 격자(120 BPM 이면 2초)로 만들고 큰 움직임 끝을 마디 첫 박에 맞춘다. `audio-probe.py --fit` 으로 오차를 잰다. 목표는 1프레임(24fps 에서 약 0.042초) 안이다.
- 튀는 곡선이나 스프링을 쓰면 다른 스타일이 된다. 감속 곡선은 `cubic-bezier(.7,0,.2,1)` 하나만 쓴다.
- 빨강을 처음부터 쓰면 예외가 약해진다. 처음 가로줄과 원 말고는 빨강을 아낀다. 규칙 1~3 화면에 빨강을 넣지 않는다.
- 페이드로 들어오면 다른 스타일이 된다. 모든 등장은 닦아 내기(clip-path 사각형이 한 방향으로 열리기)나 선이 길이 방향으로 자라기로 한다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 이 스타일은 DOM/CSS 나 SVG 로 거의 다 된다. 아래는 어렵거나 값을 정해 두어야 하는 부분이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 굵은 산세리프 큰 숫자 | 원본 글꼴이 없다 | InterVariable 굵기 800, 글자 크기 900px(숫자 높이 약 650px), 자간 -0.04em, 왼쪽 정렬 가로 96px, 기준선 세로 1040px. 아래가 화면 안에 들도록 기준선을 맞춘다 | 원본 숫자의 좁고 무거운 비례 |
| 한국어 규칙 한 줄·포스터 제목 | 한국어 굵은 산세리프가 Pretendard SemiBold 뿐이다 | 규칙 한 줄 Pretendard SemiBold 72px, 자간 -0.02em. 포스터 제목 Pretendard SemiBold 120px, 두 줄로 다시 짤 때 140px, 줄 높이 0.95. 메모·머리말 Pretendard Regular 20px, 숫자는 InterVariable | 굵기 단계가 두 개뿐이라 세밀한 굵기 대비 |
| 모든 움직임을 마디에 맞추기 | 손으로 시각을 적으면 몇 프레임씩 어긋난다 | 장면표를 박 번호로 적고 시각은 `t = 박 번호 x 0.5`(120 BPM)로 계산한다. 움직임은 끝 박에서 한 음표 길이(16분음표 0.125초, 8분음표 0.25초) 앞에 시작한다. 시작·끝 시각을 1/24초 배수로 반올림한다 | 없음 |
| 닦아 내기 등장 | 없다. CSS 로 된다 | 글자 줄마다 overflow: hidden 상자를 두고 글자를 기준선 아래 100% → 0 으로 0.125초에 올린다. 나갈 때는 0 → -100% 로 0.25초. 포스터는 clip-path: inset(100% 0 0 0) → inset(0) 세로 0.5초 | 없음 |
| 칼로 자르기 삭제 | 없다. 두 단계로 된다 | 2px #111111 가로선이 그 줄을 왼쪽에서 오른쪽으로 0.125초에 가로지른 뒤, 줄 전체를 transform: scaleY(1 → 0)(가운데 기준)으로 0.25초에 접는다 | 없음 |
| 빨간 원의 격자 밖 이동과 좌표 표시 | 다른 요소와 다른 곡선을 같은 화면에서 돌려야 한다 | 원은 선형으로 1.5초에 대각선 약 400px, 중간 0.25초 멈춤(8분음표 하나). 지름 180 → 360px 를 같은 선형으로 키운다. 좌표 표시는 매 프레임 원 중심을 칸 폭으로 나눈 값을 소수 둘째 자리까지 InterVariable 22px 로 적는다. 정수가 아니면 상태 글자를 #E20613 으로 바꾼다 | 없음 |
| 90도 돌리기와 확대 | 돌리기와 이름표를 같이 하면 어지럽다 | 포스터 상자 transform: rotate(0 → -90deg) scale(1 → 1.34) 를 0.75초(1.5박) 감속 곡선으로. 돌기가 끝난 뒤 1박 쉬고 음 이름·마디 번호를 닦아 내기로 들인다. 돌린 판 이음매가 보이면 막대를 1px 겹쳐 그린다 | 없음 |
| 재생선과 막대가 빨개지는 순간 | 막대 시작이 프레임 사이에 떨어지면 깜빡인다 | 막대 시작을 0.25초 배수에 둔다. 재생선(폭 3px, #E20613)이 막대 왼쪽 가장자리를 지나는 프레임에 막대 색을 #111111 → #E20613 으로 한 번에 바꾼다. 소리는 같은 시각에 효과음(`synth.py` 의 짧은 타격)이나 음악의 박을 둔다 | 실제 악보 음과의 일치(원본은 음악이 그 막대 음을 낸다) |
| 포스터 다섯 장 판 | 장마다 다른 포스터를 만들어야 한다 | 같은 격자(6열 x 12행)와 같은 세 요소(막대, 원, 제목)를 시드 고정 규칙으로 다섯 번 다시 배치한다. 장마다 240 x 420px, 간격 72px. 한 장만 빨간 원, 나머지는 검은 원이나 빨간 사각형 하나 | 손으로 짠 포스터의 완성도 |
