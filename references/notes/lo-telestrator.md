# 경기 분석 판서 영상 · 멈추고 그리고 다시 튼다 — 분석 노트

> 방송 경기 분석 코너를 흉내 낸 54초 영상. 실제 경기 중계 화면을 제 속도로 튼 뒤 되감고, 멈추고, 그 위에 발밑 고리·점선 화살표·빨간 빈 공간을 마커처럼 그린다. 다시 천천히 틀며 초시계로 프레임을 세고, 다른 각도로 보고, 마지막에 경기장을 위에서 본 판으로 펴서 요약한다. 노란 대각선 띠, 모서리 표시, 점수 막대가 전체를 한 방송처럼 묶는다. 경기 분석, 경기 요약, 코칭처럼 "실제 장면을 보고 한 겹씩 뜯어 보는" 영상에 맞는다.

## 3. 움직임

- 원래 글의 섬광·밀기·채도 낮추기·초점 어둡게 하기 값, 마커 선의 겹, 고리 그리기, 되감기, 느린 재생의 프레임 섞기는 화면과 맞다. 되풀이하지 않는다.
- 영상에서 확인한 점 · 멈춤 길이는 컷 사이로 잰다. 경기 중 멈춤 2.17초(6.83~9.00), 두 각도 멈춤 2.17초(12.43~14.60), 멈춤 ① 1.97초, ② 1.77초, ③ 1.97초다. 원래 글의 1.8~2.4초와 맞는다.
- 멈춤 안에서 그리는 순서는 고리 → 공간·연결선 → 이름표다. 멈춤 ②에서 고리 26.7초, 빨간 공간 27.0초, 하늘색 연결선과 이름표 27.5~28.0초다. 0.3~0.5초 간격이다.
- 제 속도와 멈춤이 번갈아 오므로 움직임 세기가 15~50 과 0.4~1.5 사이를 뛴다. 중간 값이 적다.
- 화면 고정 요소(모서리 표시, 점수 막대)는 움직이지 않는다. 멈춤의 밀기(1.035배)도 받지 않는다. 그리는 선은 밀기를 같이 받는다.

- 원래 글의 편집 문법(구간 사이는 노란 띠 0.34초, 구간 안은 하드 컷, 디졸브 없음)은 화면과 맞다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 26.6~31.6초의 "제 속도로 보던 화면이 섬광과 함께 멈추고(채도 0.74 → 0.45, 밝기 0.53 → 0.31), 초점 타원 안에서 노란 고리 → 빨간 빈 공간(약 470 x 186px) → 하늘색 고리 두 개와 연결선 → 빨간 판 이름표가 0.3~0.5초 간격으로 그려지고, 다시 0.7배로 틀며 왼쪽 위 초시계가 프레임을 센 뒤, 둘째 멈춤에서 노란 긴 점선 궤적이 골문까지 그어지는" 5초다. 화면 위에 그리지 않고 따로 도표로 빼면, 멈춤 때 어두워지지 않으면, 제 속도 장면 없이 멈춤만 있으면 이 영상이 아니다.
- 12초 판 압축 예 · 0~0.8초 첫 장면(분필 경기장 + 노란 마커 선 + 큰 제목), 0.8~2.3초 장면 제 속도(고리 하나), 2.3~2.7초 되감기, 2.7~4.5초 멈춤 ①(고리 + 공간 + 이름표), 4.5~5.5초 0.7배 틀기와 초시계, 5.5~7.5초 멈춤 ②(궤적 + 초시계 정지 값), 7.5~8.5초 공 꼬리와 골망, 8.5~10.0초 원근 펴기로 요약 판(점 하나, 표 한 줄), 10.0~10.4초 노란 띠, 10.4~12.0초 끝 제목. 기록 카드, 화면 나누기, 판독 도장, 반대 각도, 자료 카드, 사진 카드는 뺀다.
- 한 장면을 여러 번 쓰고 매번 한 겹 깊이 들어간다.
- 화면 고정 포장(모서리 표시, 점수 막대, 자막 자리)이 같은 자리에 늘 있다.

## 7. 함정

- 이 영상의 바탕은 실제 프로 경기 중계 화면이다. 화면에 실존 팀 이름·약칭, 실존 선수 이름과 등번호, 실존 경기장, 실존 방송사, 광고판의 실존 기업 이름·로고, 실존 선수 사진, 실존 해설자의 말이 있다. 하나도 쓰지 않는다. 화면의 자막·이름표 문장, 날짜, 점수도 옮기지 않는다. 역할(멈춤 이름표, 자막, 점수 막대, 기록 카드)만 가져온다.
- 중계 화면은 남의 저작물이다. 우리 영상은 사용자가 권리를 가진 화면(자기 팀 경기·훈련 촬영 등)만 쓴다. 화면이 없으면 `## 8` 의 대체(three.js 경기장, AI 일러스트 정지 화면)로 만들고 연출이라고 밝힌다. 광고판·관중석에 글자나 로고를 넣지 않는다.
- 화면에서 셀 수 없는 숫자(공 속도, 뛴 거리)는 쓰지 않는다. 원래 글에 있다. 이 저장소의 사실 규칙과 같다. 초시계는 원본 프레임 수 ÷ 원본 fps 로만 계산한다. 거리는 화면의 실제 선 네 점으로 맞춘 원근 변환에서만 내고 "약" 을 붙인다.
- 첫 장면 큰 제목이 원본은 화면 높이의 18% 다. 한국어는 140px(13%) 이하로 둔다. 크기 대신 노란 마커 선과 도장 넘침(1.6 → 1.0배)으로 힘을 낸다.
- 그린 선이 밀기 변환을 받지 않으면 멈춤의 1.035배 밀기 동안 선수에게서 미끄러진다. 화면과 그림을 한 상자에 넣고 그 상자에 변환을 준다. 모서리 표시와 점수 막대는 그 상자 밖에 둔다.
- 노랑을 아무 데나 쓰면 대표 색의 뜻이 사라진다. 노랑은 공격 쪽과 포장에, 하늘색은 수비 쪽에, 빨강은 빈 공간과 경고 이름표에만 쓴다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 실제 경기 중계 화면 | 남의 저작물이고, 코드로 만들 수 없다 | (가) 사용자가 권리를 가진 경기·훈련 영상이 있으면 그것을 프레임 이미지로 뽑아(`ffmpeg`, 원본 fps) canvas 에 seek(t) 로 그린다. (나) 없으면 three.js(`vendor/three`)로 경기장을 만든다 · 잔디 판에 canvas 로 그린 줄무늬(#6F9720 / #67901D, 폭 1/18), 흰 선 굵기 0.12m, 선수는 InstancedMesh 원기둥 + 구 22개(두 팀 흰색 / 노랑·남색), 카메라 시야각 28도로 높은 옆 자리에서 내려다본다. 관중석·광고판은 어두운 판(#1A1F1C)으로 비운다. 정지 장면만 더 그럴듯하게 하려면 AI 일러스트(codex-image)로 같은 구도 경기장을 그리되 광고판 무늬·글자·로고 없음을 적는다 | 실제 중계 화면의 사실감과 관중의 기운 |
| 원근 위에 그리기와 원근 펴기 | 화면 좌표와 경기장 좌표를 이어야 한다 | 화면에서 보이는 경기장 선의 네 점(구역 모서리 등)과 실제 크기(m)로 3x3 원근 행렬을 직접 계산한다(네 점 방정식). 고리·화살표는 경기장 좌표에서 정해 행렬로 화면에 옮긴다. 펴기는 경기 화면 canvas 를 CSS matrix3d 로 바꿔 행렬을 단위 행렬 쪽으로 0.9초에 보간한다. three.js 경기장이면 카메라를 위에서 내려다보는 자리로 0.9초에 옮기면 된다 | 없음 |
| 느린 재생의 프레임 섞기 | 원본 프레임 사이 값을 만들어야 한다 | 0.6~0.85배일 때 원본 프레임 위치 f = 시작 프레임 + (t − 시작) x fps x 배속. 아래 프레임과 위 프레임을 소수부만큼 불투명도로 겹쳐 그린다. three.js 경기장이면 위치를 그대로 보간하면 된다 | 움직임 흐림의 자연스러움 |
| 마커 선의 빛 | 없다. canvas 로 된다 | 세 겹으로 그린다 · 어두운 테(굵기 w+6, rgba(0,0,0,0.55)), 색 심(굵기 w=7, #FFD300, shadowBlur 18, shadowColor 같은 색), 흰 하이라이트(굵기 w x 0.28, 불투명도 0.8). 꼭짓점마다 시드 고정 ±1.5px 흔들림. 점선은 setLineDash([18, 12]). 길이 방향으로 그리고 마지막 10% 에 화살촉(길이 28px)이 튀어나온다 | 없음 |
| 멈춤 들어가기 | 없다. 값만 맞추면 된다 | 흰 섬광(전체 흰 판 불투명도 0.55 → 0, 0.1초) + 화면 상자 scale 1.035 → 1.0(0.35초 감속) + filter: saturate(0.58) brightness(0.9) + 차가운 색 얹기(#2A4A6A, 곱하기 0.15) + 초점 타원 밖을 0.42 로 어둡게(짝홀 채우기 구멍, 0.3초) + 이후 1.2% 천천히 밀기 | 없음 |
| 되감기 | 원본을 거꾸로 돌려야 한다 | 원본 프레임 위치를 0.6초에 끝 → 처음으로 가속·감속 보간한다. 가로 ±13px 흔들림(시드 고정), 흰 가로 줄 4개(높이 6px, 불투명도 0.6, 위아래로 흐름), 왼쪽에 큰 흰 되감기 기호(높이 75px) | 없음(three.js 경기장이면 선수 위치를 거꾸로 보간) |
| 실존 선수 사진 카드 | 실존 인물 사진은 쓰지 않는다 | 사진 카드를 뺀다. 필요하면 사용자가 허락한 사진만 쓰고, 없으면 등번호만 크게 적은 카드(InterVariable 굵기 800, 160px, #FFD300, 흰 테 10px, 6도 기울임)로 바꾼다 | 사람 얼굴이 주는 친근함 |
| 중계 해설 소리와 경기장 소리 | 실제 방송 소리다 | 내레이션은 motion-video 0단계의 음성 생성 커넥터로만 만든다. 경기장 소리는 `synth.py` 효과음과 음악으로 대신하고, 멈춤 순간에 음악 음량을 0.3배로 0.1초에 낮춘다 | 생생한 현장음 |
| 큰 제목·숫자 글꼴 | 기울어진 압축 산세리프가 없다 | 숫자는 InterVariable 굵기 800 에 CSS transform: skewX(-8deg), 자간 -0.02em. 한국어 제목은 Pretendard SemiBold 140px 이하. 영문 작은 줄은 InterVariable 굵기 700, 대문자, 자간 0.2em | 방송 그래픽 특유의 좁고 기운 글자 |
