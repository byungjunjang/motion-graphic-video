## 4. 전환

- 하드 컷이 없다. 화면 틀은 그대로이고 카드 안 내용만 바뀐다.
- 단계 전환은 다섯 번 모두 같은 3박이다.
  1. 앞 카드가 0.07초 안에 사라진다.
  2. 카드 자리 가운데에 다음 단계의 큰 수치만 1~2프레임(약 0.05초) 뜬다. 크기는 카드 안 수치와 같다.
  3. 새 카드가 약 3° 기운 채 나타나 0.15초에 바로 선다.
- 진행 점 규칙 · 6개 원(지름 46px, 화면 4.3%)이 가로 14~86%에 156px 간격으로 놓이고 가는 선으로 이어진다. 끝난 단계는 산호색 면 + 흰 체크다. 지금 단계는 흰 면 + 짙은 테두리 + 빨강 번호이고, 아래 라벨이 빨강이 된다. 남은 단계는 회색 테두리 + 회색 번호다. 체크는 그 단계의 붓기가 끝나는 순간(병이 나가기 시작할 때) 찍힌다. 다음 점과 잇는 선도 그때 빨강으로 찬다.
- 첫 진입 · 가운데 큰 제목 → 위로 올라감 → 잔 선 긋기 → 카드와 진행 점. 1초 안에 빈 화면이 레이아웃이 된다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 13.5초 구도. 정사각 화면 왼쪽 위에서 빨강 병(폭 24%)이 기울어 줄기를 붓고, 가운데 왼쪽 잔(폭 26%, 높이 34%)의 액체가 분홍빨강으로 2 눈금까지 오른다. 오른쪽 카드(폭 36%)의 큰 수치와 막대가 같이 차고, 아래 진행 점 6개 중 2개가 체크, 3번이 지금 단계다. 동시에 보이는 요소는 7개(제목, 부제, 병, 잔, 눈금, 카드, 진행 점)다.
- 12초 판 압축 예 · 제목 등장과 상승 1.0초 → 잔 긋기 + 얼음 3개 1.5초 → 붓기 세 번 각 2.0초(병 들어옴 0.3, 붓기 1.3, 나감 0.4) → 젓기 1.5초 → 장식 + 끝 카드 2.0초. 단계 전환의 "큰 수치 한순간"은 남긴다. 부제 교체와 젓기 중 스푼 빠지기는 뺀다.
- 액체 높이 · 카드 숫자 · 채움 막대를 한 값으로 묶는 방식. 대상의 수치가 쌓이는 과정을 같은 틀로 보일 수 있다.
- 단계 수가 정해진 설명에서 아래 진행 점을 상시로 두는 방식. 체크 시각을 "그 단계 동작이 끝나는 순간"으로 잡는다.
- 단계 전환 3박(사라짐 → 큰 수치 1~2프레임 → 기운 새 카드가 바로 섬). 짧지만 단계 경계가 분명하다.
- 액체 색이 섞이며 진해지는 진행. 단계가 쌓인다는 것을 색 하나로 보인다.
- 끝 장면의 반짝임 선 8개 + 잔 흔들림. 완성을 0.4초 안에 알린다.

## 7. 함정

- 화면의 칵테일 이름, 재료 이름, 부제, 감탄 문구는 원작의 것이다. 옮기지 않는다. 재료 이름 하나는 실존 상표 이름이다. 화면에 쓰지 않는다. 병 라벨에도 상표처럼 보이는 글자를 넣지 않는다.
- 정사각 → 16:9 로 옮기는 구도(1920x1080 기준).
  - 제목 · 가로 가운데, 세로 10%, 글자 높이 70px 그대로.
  - 잔 · 가로 24~40%(약 310px 폭), 세로 38~74%. 원본 높이 비율(34%)을 지킨다.
  - 병 · 잔 왼쪽 위, 가로 8~22%, 세로 20~38%.
  - 카드 · 가로 52~80%(약 540x300px), 세로 42~70%. 잔과 카드 사이 빈칸을 200px 이상 남긴다.
  - 진행 점 · 가로 22~78%에 6개, 세로 87%. 간격 약 215px.
  - 빈 바탕이 양옆으로 늘어난다. 오른쪽 끝 12%와 왼쪽 끝 8%는 비워 둔다. 요소를 키워 채우지 않는다.
- 움직임이 작은 영상이다(평균 1.46). 12초로 줄이면 붓는 시간이 짧아져 액체가 "뚝" 오른다. 액체 상승은 1.3초 이상 준다.
- 단계 전환의 큰 수치는 1~2프레임뿐이다. 길게 두면 깜박임이 아니라 따로 노는 화면이 된다. 0.1초를 넘기지 않는다.
- 진행 점 6개와 카드 막대가 같이 있어서 "진행"을 두 번 보인다. 12초 판에서 단계를 4개로 줄이면 진행 점도 4개로 줄인다. 체크 순서를 어기면 바로 눈에 띈다.
- 한국어로 옮기면 팝 대문자 제목이 없다. Pretendard SemiBold 에 테두리와 입체 그림자를 붙여 대신한다(8번 표).

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 16:9 로 옮긴 기준이다. 글꼴은 Pretendard Regular·SemiBold, 숫자·라틴은 InterVariable 도 쓴다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 둥근 팝 제목 글꼴 | 팝 디스플레이 글꼴이 없다 | Pretendard SemiBold 120px, 자간 -0.02em, 면 #E58090. `-webkit-text-stroke: 5px #39474A` + `paint-order: stroke fill`. 입체 그림자는 같은 글자를 #A95765 로 (6px, 6px) 어긋나게 한 겹 더 뒤에 둔다. 글자마다 span 으로 나눠 0.17초 간격으로 scale 0.4 → 1.08 → 1(0.25초) | 둥근 글자 모양의 귀여움 |
| 손으로 그은 선화(잔·병·카드 테두리) | 선의 흔들림과 겹침 | SVG path 를 `HAND.wobble(P, true, 2, 'glass', 0)` 으로 한 번 굽혀 고정한다. stroke 4px #39474A, `stroke-linecap: round`. 선 긋기 등장은 `stroke-dasharray` 를 0.6초에 풀어 그린다. 떨지 않는다 | 선 굵기의 미세한 강약 |
| 액체가 차오르는 잔 | 잔 모양 안에서만 보여야 한다 | 잔 안쪽 SVG path 를 `clipPath` 로 쓰고 그 안에 rect 를 둔다. rect 의 y 를 눈금 1 단위 112px(16:9 높이 34% 잔 기준)씩 올린다. 윗면은 높이 14px 의 옅은 타원을 한 겹 얹는다. 색은 단계마다 #DAEBF1 → #E15665 → #A63844 로 0.8초 보간 | 액체 윗면의 출렁임 |
| 붓는 줄기 | 곡선이 병목에서 잔까지 휜다 | SVG path(2차 곡선) stroke 8px, 색은 그 단계 술 색. 시작점은 병목 끝, 끝점은 액체 윗면. 끊길 때는 `stroke-dashoffset` 으로 위에서부터 0.2초에 지운다. 끝에 지름 6px 원 3개를 0.3초 주기로 오르내리게 한다 | 물줄기의 굵기 변화 |
| 병 일러스트 | 라벨 있는 병 그림 | SVG 로 그린다(몸통 rect + 병목 rect + 라벨 rect, 손그림 선). 라벨 안에는 글자 대신 가로줄 2개. 또는 `codex-image` 로 글자 없는 병 3종을 마젠타 바탕으로 그려 `key.py` 로 투명화한다 | 병마다 다른 상표 느낌 |
| 얼음이 떨어져 쌓임 | 물리 충돌 | 미리 정한 세 자리(바닥 둘, 위 하나)로 easeOutBack(0.35초) 낙하. 각 0.45초 간격. 착지 순간 짧은 선 3개(길이 14px)를 0.15초 보였다 지운다 | 쌓이며 미끄러지는 우연 |
| 젓는 스푼과 도는 얼음 | 잔 속 3D 회전 | 스푼은 위쪽 끝을 고정하고 아래 끝을 타원 궤도(가로 반지름 60px, 세로 18px, 주기 0.8초)로 돌린다. 얼음 3개도 같은 타원 위에서 위상을 120°씩 두고 돈다. 뒤쪽 반 바퀴에서는 얼음 opacity 0.7 | 깊이감 |
| 주황 껍질 나선 | 꼬인 곡선 | SVG path 로 고리 3개짜리 나선(폭 320px), stroke 10px #F2A33A 근처 + 안쪽 점 무늬. 위에서 내려오며 scale 0.6 → 1(0.5초) | 껍질의 두께감 |
| 끝의 반짝임 선 | 없다 | 잔 중심에서 반지름 260~300px 위치에 짧은 선 8개(길이 30px, 굵기 5px, 빨강·주황 번갈아). scale 0 → 1 을 0.4초에. 잔은 rotate ±3° 감쇠 진동 두 번(0.8초) | 없음 |
