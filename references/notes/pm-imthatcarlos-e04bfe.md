## 1. 본질

- 바탕은 두 가지다. 앞 15.9초와 끝 14초는 거의 검정(#080808 근처, 18%), 가운데 29초는 따뜻한 회백색(#F8F8E8 근처, 26%)이다.
- 포인트는 민트 초록(#3CFCA5 근처, 프레임에서 직접 잰 값) 하나다. 강조 낱말, 형광펜 상자, 체크 원, 큰 번호, 진행 막대, 로고에 쓴다. 밝은 바탕의 제목 낱말만 짙은 초록(#1DB16C 근처, 직접 잰 값)이다. 빨강은 문제 항목의 × 아이콘과 취소선, 경고 배지 하나에만 쓴다.
- 어두운 장면에는 초록 방사형 빛 한 덩어리(#081808~#182818 근처)와 옅은 격자선이 깔린다.
- 글자가 주인이다. 굵은 산세리프 한두 줄이 화면 너비의 67~84%를 차지하고, 낱말 한두 개만 초록이다.
- UI 는 화면 캡처가 아니다. 연한 민트 둥근 판(#E8F8E8 근처, 너비의 43%) 위 흰 카드 한 장에 제목, 고정폭(monospace) 두세 줄, 배지 하나만 그렸다.
- 끝 14초의 배경은 붓 자국이 보이는 유화풍 그림 7장이다(래스터 이미지). 어두운 막을 덮어 흰 글자가 읽힌다.
- 아닌 것 · 커서, 3D, 입자, 캐릭터, 아이콘 묶음, 둘째 포인트 색, 화면 캡처.

## 3. 움직임

- 낱말 등장은 한 가지다. 낱말마다 아래에서 마스크로 올라온다. 간격 0.1초, 한 낱말에 약 0.2초다.
- 한 장면은 "0.5~1.5초 조립 → 3~5초 정지"다. 단계 네 장은 6.0초 간격으로 바뀐다.
- 카드 안은 세 상태다. 진행 표시(회전 표시 + 고정폭 한 줄, 0.5~0.9초) → 결과가 줄 단위로 0.1~0.2초 간격에 등장 → 정지. 단계마다 움직임이 다르다(타이핑, 코드 줄 쌓기, 점 채우기, 숫자 세기 + 선 그리기).
- 진행 탭의 가는 막대는 그 단계의 6초 동안 일정한 속도로 찬다. 지난 막대는 찬 채로 남는다.
- 낱말 카드만 세다. 0.13초 축소 뒤에 낱말이 0.4초 동안 약 5% 커진다.
- 커서가 없다. 클릭 대신 상태 변화만 보여 준다.

## 4. 전환

- 문제 목록 → 로고 · 흩어진 꼬리표 15개가 가운데로 모여 로고 아이콘이 된다. 컷이 없다. 빛이 같이 커진다.
- 어두움 → 밝음(15.9초), 단계 4 → 그림(45.0초) · 새 장면이 아래에서 올라와 앞 장면을 밀어 올린다. 0.3초.
- 주장 → 단계 1(21.4초) · 가로 밀기 0.3초. 한 번뿐이다.
- 단계 → 단계 · 탭과 바탕은 그대로다. 내용이 0.2초 흐려지고 0.1초 비운 뒤 번호, 제목, 설명 순서로 나온다.
- 낱말 카드 4장 · 하드 컷. 그림과 낱말이 함께 바뀐다.
- 끝 · 교차 디졸브 0.3초로 들어가고 페이드아웃 0.5초로 닫는다.

## 5. 타이포

- 굵은 기하학적 산세리프 한 가지가 문장, 제목, 낱말 카드, 워드마크를 맡는다. 대소문자를 섞고 자간이 좁다. 문장 끝마다 마침표를 찍는다.
- 대문자 높이는 화면 높이의 약 13%(낱말 카드), 10%(끝 선언), 8.6%(여는 한 줄), 7%(주장·문제 제목), 6.4%(단계 제목)다.
- 고정폭은 터미널, 카드 안 값, 탭·역할 라벨, 꼬리표, 주소 알약에 쓴다. 라벨은 대문자에 넓은 자간이다.
- 강조는 세 가지다. 어두운 바탕은 낱말을 초록으로 칠한다. 밝은 바탕의 주장은 검은 글자 뒤에 초록 형광펜 상자를 낱말마다 깐다. 문제 항목은 빨간 취소선을 긋는다.
- 큰 번호는 고정폭 숫자 두 자리다(높이 8.6%). 민트로 채우고 짙은 초록 외곽선을 둘렀다.

## 6. 가져올 것

- "큰 문장 2장 + 문제 목록 → 로고 → 한 줄 주장 → 번호 붙은 네 단계 → 역할 정리 → 장점 낱말 → 끝 카드" 순서. 절차가 있는 서비스를 설명하는 뼈대다.
- 단계 화면의 고정 배치. 위 진행 탭, 왼쪽 "큰 번호 + 역할 라벨 + 두 낱말 제목 + 설명 두 줄", 오른쪽 카드 한 장. 바뀐 내용만 읽으면 된다.
- 카드의 세 상태. 클릭 없이 일이 처리된 것을 보여 준다.
- 단계 길이만큼 차는 탭 막대. 몇 번째이고 얼마나 남았는지 보인다.
- 낱개 꼬리표가 모여 로고가 되는 전환. 흩어진 것이 하나로 묶인다는 뜻을 움직임으로 전한다.
- 바탕 밝기로 장을 나눈다. 문제는 어둡게, 해법과 절차는 밝게, 맺음은 다시 어둡게 간다.
- 긴 정지 뒤의 낱말 카드 4장(0.53초 간격). 끝 카드 앞에서 속도를 올린다.

## 7. 함정

- 화면의 문장, 단계 이름, 명령문, 카드 안 수치와 이름은 원작의 것이다. 옮기지 않는다. 역할(문제 문장, 주장, 단계 제목, 결과 수치)만 가져온다.
- 59초 가운데 34.5초가 정지이고 소리 트랙도 없다. 30~40초로 만들 때는 단계당 6초를 3~4초로 줄이고 등장 시각을 박에 맞춘다.
- 끝 14초의 그림 7장은 래스터 이미지다. AI 이미지로 그린다(`.claude/skills/motion-video/references/ai-image.md`). 첫 장을 참조로 붙여 화풍을 맞추고, 그림 안에 글자를 넣지 않는다.
- 카드 안 고정폭 글자와 탭 라벨은 대문자 높이가 화면 높이의 약 1.2~1.5%다. 읽혀야 하는 줄은 키우고 줄 수를 줄인다.
- 단계 네 장이 같은 틀이다. 카드 안 움직임까지 같으면 24초가 한 장처럼 보인다.
- 한국어는 어절 수가 달라진다. 형광펜 상자는 어절마다 깔리므로 조사까지 상자에 들어간다. 강조할 어절을 2~3개로 고른다.
