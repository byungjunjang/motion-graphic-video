## 3. 움직임

- 원래 글의 연기 규칙은 화면과 맞다.
- 영상에서 확인한 점 · 전체 리듬이 "긴 정지 4~6초 → 짧은 폭발적 줌 1~2초"다. 정지 구간은 움직임 세기 0.1~3, 줌 구간은 30~123 이다. 정지 동안 안내자만 작게 움직인다(고개 끄덕임, 깜박임, 날개 펄럭임).

## 7. 함정

- 제목, 자막, 이름표, 시야 숫자, 끝 제목, 제작 표기는 원작의 것이다. 옮기지 않는다. 역할(제목 두 줄, 다음 정거장 이름표, 시야 숫자, 자막)만 가져온다. 제작 표기에 실존 회사·서비스 이름이 있다. 쓰지 않는다.
- 안내자는 원작의 캐릭터다. 노란 공 몸, 렌즈 눈 하나, 태양 전지판 날개, 빨강 구슬 안테나를 그대로 옮기지 않는다. 우리 판은 눈이 곧 카메라인 안내자라는 역할만 가져오고 몸 모양·색·부속을 바꾼다(예: 크림색 네모 몸, 다리 두 개, 안테나 없음).
- 수치(시야 숫자, 거리, 시간)는 우리 주제의 원문에서 확인한 값만 쓴다. 원작 수치를 옮기지 않는다.
- 줌을 직선 배율로 하면 처음에 느리고 끝에 갑자기 터진다. 배율의 로그 값을 시간에 대해 곡선으로 움직인다. 원본은 0.75초에 8.5배였다.
- 12초 판에서는 정지를 1.5초 아래로 줄이고, 그 안에 표정 하나와 숫자 굴림을 넣는다.
- 한국어 자막은 굵은 윗줄 Pretendard SemiBold 30px, 아랫줄은 넣지 않는다(두 언어 줄은 원작의 형식).

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 평면 도형이라 대부분 SVG 로 된다. 크기 단계마다 SVG 그룹 하나를 두고, 카메라는 그룹의 `transform` 배율을 로그 곡선으로 바꾼다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 안내자의 표정 연기 | 눈동자가 아치로 휘는 웃음, 찌그러짐과 늘어남 | SVG 로 만든다 · 렌즈 테 원(#FEF3E1), 눈동자 원(#4D7BFE, 그늘 #3A5DD8), 동공(#1C2053). 웃음은 눈동자를 반원 아치 경로로 0.2초에 모핑. 찌그러짐은 몸 그룹 `scale(1.12, 0.88)` → `scale(0.92, 1.1)` → 1, 각 0.12초. 깜박임은 위에서 내려오는 눈꺼풀 반원(몸 색) 0.15초 | 손으로 다듬은 표정의 미세함 |
| 은하(점 수백 개) | 손으로 놓기 어렵다 | canvas 에 시드 고정 난수로 그린다 · 팔 2개 나선(로그 나선, 감김 1.3바퀴)을 #3A5DD8·#4D7BFE 두 겹 면으로, 그 위에 타원 점 400개(흰색 60%, 노랑 25%, 민트 10%, 빨강 5%, 지름 4~14px). 중심은 노랑 타원 + 크림 타원. 바깥에 두 겹 고리 빛 타원(#252962, #2F357B) | 원본의 점 배치 맛 |
| 로그 줌으로 고리 뚫기 | 배율이 수십 배로 바뀌면 SVG 선이 깨지거나 점이 사라진다 | 단계마다 그림을 따로 두고, 앞 단계는 배율 1 → 12 로 키우며 지우고 다음 단계는 고리 안에서 배율 0.08 → 1 로 키운다. 배율 = 시작값 × 12^곡선(t), 곡선은 끝이 느려지는 3차. 고리 안은 다음 단계 그림을 원 `clipPath` 로 보인다 | 없음에 가깝다 |
| 두 겹 고리 빛 | 없다. SVG 로 된다 | 주인공 도형 뒤에 같은 모양 원 두 개를 둔다 · 지름 ×1.3 은 #2F357B, ×1.6 은 #252962. 흐림 없이 단단한 가장자리 그대로 | 없음 |
| 점선 시선 | 없다. SVG 로 된다 | 원 25개(지름 4px, 간격 14px, #FFFFFF). 렌즈 쪽부터 0.04초 간격으로 크기 0 → 1.3 → 1(0.15초). 그 뒤 점선 전체를 목표 쪽으로 초당 20px 흐르게 한다 | 없음 |
| 구름 덩어리 뚫기와 숨긴 컷 | 겹쳐 지나가는 큰 구름 | 크림(#FEF3E1)·그늘(#EFDBC0) 두 단의 둥근 막대 구름 6개를 앞뒤 세 겹으로, 앞 겹이 0.6초에 화면을 80% 덮는 순간에 다음 장면으로 바꾼다 | 없음에 가깝다 |
| 손과 손가락 | 손가락 모양 | AI 일러스트(codex-image)로 평면 벡터풍 가리키는 손을 마젠타 바탕에 그리고 `scripts/key.py` 로 자른다. 색 두 단(#FEF3E1, #EFDBC0), 소매 #FF6A5F. 받은 그림의 색을 팔레트 값으로 다시 맞춘다 | 원본 도형의 매끈한 외곽 |
| 피부층 동심원 열림 | 층이 차례로 열리는 모양 | 동심원 6개(크림·연분홍·빨강 단계)를 바깥부터 0.08초 간격으로 반지름 0 → 화면 대각선까지 키운다 | 없음 |
| 눈금 띠와 시야 숫자 | 없다. DOM 으로 된다 | 숫자 InterVariable 굵게 52px, `font-variant-numeric: tabular-nums`, 숫자는 seek(t) 의 배율에서 계산해 굴린다. 띠는 폭 900px 굵기 4px, 지난 부분 #FFC64A | 없음 |
| 굵은 기하 산세리프 제목 | 같은 글꼴이 없다 | 한국어 제목 Pretendard SemiBold 120px 두 줄, 자간 -0.02em, 낱말마다 아래에서 40px 올라오며 0.25초(넘침 한 번) | 기하 글꼴의 둥근 인상 |
