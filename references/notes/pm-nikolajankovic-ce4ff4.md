# 서비스가 1인칭으로 말하는 연필 스톱모션 — 분석 노트

> 미색 종이 위에 가는 연필 선과 손글씨 서체로 다이어그램·온도계·그래프를 그려 가며, 서비스가 "나"로서 자기 일을 설명하는 58초 스톱모션 영상. 1초에 12장이고, 모든 장마다 선과 종이가 조금씩 다시 그려져 화면이 쉬지 않고 떤다. 화면 아래 어두운 띠 위에 테이프로 붙인 종이 쪽지가 있고, 그 위에 1인칭 내레이션 문장이 타자기처럼 한 글자씩 찍힌다. 밤(달·별·잠든 사람)과 낮(해·김 나는 컵) 아이콘으로 시간을 알리고, 온도계 모양 게이지가 위험도를 보여 준다. 금융·보안·자동화처럼 "보이지 않는 곳에서 대신 지켜 주는" 서비스, 개념 설명형 소개에 맞는다. 스톱모션(stop-motion) · 선 떨림(line boil) · 화이트보드 설명 · 1인칭 내레이션 자막.

출처 · pm:nikolajankovic-ce4ff4. 작성자의 프롬프트는 약 107자다. 기법(손그림 스톱모션)과 화자(서비스가 1인칭으로 자기를 설명)만 정했다. 장면, 색, 구도, 자막 방식, 길이는 없다. 이 노트는 영상 프레임(1초 간격 58장, 연속 6프레임, 직접 뽑은 원본 크기 3장)을 보고 썼다.
측정 · 파일 1280x848(약 3:2) · 12fps · 58.0초. 위치는 화면 가로·세로 % 로 적고, 크기는 16:9 1920x1080 으로 옮긴 값(세로 1.274배)을 같이 적는다. 장면 전환 검출 시각은 없다(컷이 없고 장면이 지워졌다 다시 그려진다). 0.5초마다 움직임 세기의 평균은 2.2 다. 큰 값은 51.5초(5.2), 45.5초(4.8), 31.5초(4.4), 13.5초(4.2), 41.0초(4.2)이고 모두 장면을 지우고 새로 그리는 순간이다. 56.5~58초는 0.0 이다(마지막 1.5초는 떨림도 멈춘다). 이어진 6프레임의 앞뒤 차이는 모든 쌍에서 0이 아니다(평균 5~10). 1초에 12장이 모두 서로 다르다. 색 값은 프레임에서 잰 근삿값이다.

## 1. 본질

  - 아래 15%(세로 85~100%) · 짙은 남회색 띠(#1E2326 근처). 그 위에 테이프로 붙인 미색 종이 쪽지(가로 8.6~91.4%, 세로 81~95%)가 걸쳐 있다. 쪽지 위 양 귀퉁이에 반투명 베이지 테이프 조각(약 80x30px, 약 -15°·+15° 기울기).
- 선 · 짙은 회색 연필(#3A3A3A 근처, 추정) 한 가지, 굵기 2~3px(1280 기준). 면을 칠하지 않는다. 칠이 필요한 곳은 사선 빗금(온도계 수은, 이불)이다.

- 화자 · 서비스가 "나", 시청자가 "당신"이다. 화면 그림에도 사용자 칸과 서비스 칸이 나란히 나오는 장면이 있다(46~51초).

## 3. 움직임

- 1초 12장, 모든 장이 새 그림이다(on 1s at 12fps). 이어진 6장의 앞뒤 차이가 모두 0이 아니다. 선의 위치가 1~2px(1280 기준) 흔들리고, 종이 결과 비네트 얼룩도 바뀐다.
- 그려지는 등장 · 선은 시작점에서 끝점으로 그어진다. 상자 하나 약 0.25~0.5초(3~6장), 온도계 약 1초(12장)다. 12fps 이므로 한 장에 선이 길이의 1/6~1/12 씩 늘어난다. 매끈하지 않고 툭툭 늘어난다.
- 놓기 · 칩·카드는 기울어진 채 나타나 다음 몇 장에 바로 선다(21.0 → 22.0초). 종이 조각을 손으로 놓는 동작을 흉내 낸다.
- 지우기 · 장이 바뀔 때 그림이 한 장에 사라지거나 1~2장에 걸쳐 옅어진다. 지우개 자국은 없다.
- 시계와 숫자 · 시계, 현재가, 온도계 % 가 0.5초마다 다음 값으로 바뀐다. 숫자도 손글씨라 바뀔 때마다 모양이 조금 다르다.
- 자막 타자 · 쪽지 위 문장이 왼쪽부터 한 글자씩 찍힌다. 약 초당 15~20자(12fps 에서 한 장에 1~2자)다. 줄이 넘치면 둘째 줄로 내려간다. 다음 문장 전에 쪽지가 비워진다.
- 움직임 세기 목표 · 평균 2.2. 떨림만 있는 정지 장면도 1 안팎을 유지한다. 장이 바뀌는 순간만 4~5 다.

## 4. 전환

- 컷이 없다. 모든 장이 "지우고 → 빈 종이 0~0.5초 → 다시 그리기"다.
- 이어지는 요소는 남긴다. 밤 장(13.5초) → 처리 장(20.5초) → 아침 장(26.5초)에서 온도계는 지우지 않고 같은 자리에 둔다. 달만 해로 바꾼다. 끝 장(51.5초)은 밤 장의 구도를 다시 그려 처음 이야기로 돌아간다.
- 장 제목 · 몽타주 구간(31.5~41초)에서만 위 가운데에 파랑 손글씨 장 제목을 쓴다. 장이 짧을 때 제목이 장을 나눈다.
- 자막 쪽지는 전환과 별개로 움직인다. 그림이 바뀌기 0~0.5초 전에 새 문장이 시작된다.

## 5. 타이포

- 그림 안 글자 · 손글씨 서체, 연필 회색. 장 제목·서비스 이름 높이 약 4.5%(16:9 환산 약 48px), 라벨·값 약 2~2.5%(약 25px), 칩 안 글자 약 2%.
- 시계 숫자 · 높이 약 4.7%(약 50px), 굵은 회색.
- 온도계 % 숫자 · 높이 약 3%, 굵게. 파랑·빨강 선 라벨은 약 2.5%, 각 선의 색.
- 자막 쪽지 · 손글씨 서체, 짙은 회색, 가운데 정렬, 높이 약 2.8%(약 30px), 두 줄까지. 쪽지 안쪽 여백은 좌우 약 4%.
- 모든 글자가 라틴 손글씨다. 한국어로 옮기면 손글씨 느낌의 한국어 글꼴이 없다("## 8").

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 13.5~19.5초의 밤 장. 왼쪽 위(가로 5~10%, 세로 7~16%) 달과 별 4개, 왼쪽 아래(가로 4~25%, 세로 59~76%) 잠든 사람과 z 3개, 왼쪽 가운데 디지털 시계(높이 4.7%)가 0.5초마다 오르고, 가운데(가로 30~66%, 세로 17~58%) 하락 그래프가 늘어나며, 오른쪽(가로 74~80%, 세로 18~65%, 높이 약 510px) 온도계의 % 가 내려간다. 아래 15% 띠 위 쪽지에 1인칭 문장이 찍힌다. 동시에 보이는 요소는 달·별 5 + 침대 1 + 시계 1 + 그래프 1 + 온도계 1 + 쪽지 1 이다.
- 12초 판 압축 예 · 0~1.5초 제목 + 밑줄 → 1.5~6초 밤 장(시계 4번, 그래프 하락, 온도계가 기준선에 닿음) → 6~9초 처리 장(단계 칩 3개 + 온도계 회복) → 9~11초 아침 장(해 + 컵 + 체크) → 11~12초 이름. 연결 장, 카드 장, 몽타주, 지도, 너와 나 장은 뺀다. 자막은 장마다 한 줄(약 20자)로 줄인다.
- 25초 4장면 구성(원본 58초) · ① 0~3초 제목 ② 3~11초 밤 장(위험이 커지는 과정) ③ 11~17초 처리 장(한 번의 처리로 회복) ④ 17~22.5초 아침 장(결과와 체크) → 22.5~25초 끝 이름(밤 구도 위). 몽타주와 지도는 대상의 기능 수가 많을 때만 한 장(3초)으로 넣는다.
- 1인칭 화자. 서비스가 "나는 이것을 본다, 이렇게 한다"로 말하면 기능 설명이 이야기가 된다.
- 밤 → 아침 구조. 위험은 밤에(사용자가 잘 때) 오고, 서비스가 대신 처리하고, 아침에 결과를 본다. 시간 아이콘(달, 해, 컵) 세 개로 이 흐름을 말 없이 보여 준다.
- 게이지 하나를 장을 넘어 남겨 두기. 온도계가 세 장에 걸쳐 같은 자리에 있어 숫자의 변화가 이어진다.
- 테이프 쪽지 자막. 아래 어두운 띠 위의 종이 쪽지가 화면 그림과 섞이지 않고 늘 읽힌다.

## 7. 함정

- 화면에 실존 서비스 이름, 실존 금융 프로토콜·네트워크 이름 다수(상자, 구름 덩어리, 카드 이름), 실존 자산 기호, 실존 주소가 나온다. 쓰지 않는다. 상자와 덩어리는 일반 이름(예: "보관소 A", "거래소 B")이나 빈 칸으로 바꾼다.
- 자막 문장, 장 제목, 카드 값, 가격, % 값, 시계 시각은 원작의 것이다. 옮기지 않는다. 역할(1인칭 설명 문장, 장 제목, 위험 수치, 기준선 라벨)만 가져온다.
- 원작 비율이 약 3:2(1280x848)다. 16:9 로 옮기는 법.
  - 세로를 맞춘다 · 1080 높이에 맞추면 그림 폭이 1630px 이고 좌우에 145px 씩 남는다. 남는 곳은 같은 종이(비네트 포함)로 채운다. 그림 요소는 가로 위치(%)를 1630px 폭 기준으로 둔 뒤 가운데에 놓는다.
  - 아래 띠 · 높이 15%(약 160px)를 그대로 둔다. 쪽지는 가로 12~88%, 세로 81~95%(약 1460x150px)로 넓힌다.
  - 위 85%(약 920px)에 그림을 둔다. 온도계는 가로 78%, 높이 510px. 그래프는 가로 30~64%.
- 글자가 작다. 자막 2.8%(30px), 라벨 2~2.5% 는 16:9 화면에서 읽기 어렵다. 자막 42px, 라벨 32px, 제목 56px 이상으로 키운다. 그만큼 문장을 줄인다(자막 한 줄 25자 안).
- 58초 중 자막이 거의 쉬지 않는다. 문장이 길어(최장 3줄) 타자가 끝나기 전에 장이 바뀌는 곳이 있다(32~40초). 짧은 판에서는 장마다 문장 하나로 줄인다.
- 마지막 1.5초는 떨림도 멈춘다. 이것이 끝났다는 신호다. 재현할 때도 마지막 1초는 같은 그림(B 고정)으로 둔다.
- 떨림을 너무 크게 주면(3px 이상) 글자가 흔들려 읽히지 않는다. 글자는 떨림 1px, 그림 선은 1.5~2px 로 둔다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 16:9 1920x1080 기준이다. 글꼴은 Pretendard Regular·SemiBold 뿐이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 12fps 스톱모션과 선 떨림 | 매 장 새로 그린 손그림 | seek(t) 에서 `const f = Math.floor(t * 12); const B = f % 3;` 그림 시각도 `tq = f / 12` 로 계단을 만든다(움직임도 12fps). 모든 선은 `HAND.ink(ctx, P, { frac, w: 3, color: '#3A3A3A', key, B, amt: 1.8 })` | 연필 압력의 굵기 변화 |
| 연필 질감 선 | 흑연 결 | 선 위에 `HAND.pencil` 질감을 쓰지 않고, 선 색을 `rgba(58,58,58,.85)` 로 하고 같은 경로를 `w: 1, amt: 2.4` 로 한 번 더 겹쳐 그린다 | 흑연 입자 |
| 손글씨 서체 | 한국어 손글씨 글꼴이 없다 | Pretendard Regular, 색 #3A3A3A. 글자마다 span 으로 나누고 `f`(12fps 장 번호)와 글자 번호로 정한 난수로 `translate(±0.8px, ±0.8px) rotate(±0.6deg)` 를 준다(떨림 1px). 장 제목은 SemiBold, 파랑 #5050D0 | 손글씨 느낌 |
| 자막 타자 | 없다 | 쪽지 div 안에 글자 수 `n = Math.floor((tq - t0) * 18)` 만큼 보인다(초당 18자). Pretendard Regular 42px, 줄간격 1.4, 가운데 정렬 | 없음 |
| 테이프 쪽지 | 종이와 테이프 질감 | 쪽지 #F4F2EA + `texTile(seed, { mc: '120,115,100', mottle: .02, fibers: 40 })`, 아래 그림자 없음. 테이프는 `rgba(225,210,170,.7)` 사각 110x40px 두 개, ±15°, 가장자리를 `HAND.wobble` 로 한 번 흔든다 | 테이프 투명감 |
| 종이와 비네트 | 실제 종이 촬영 | 바탕 #E7EDE3, `texTile(seed, { mc: '110,120,110', mottle: .04, dark: .03, light: .03 })` 를 3장 구워 B 로 바꾼다. 위에 `radial-gradient(ellipse at 50% 45%, transparent 45%, rgba(60,70,60,.28) 100%)` | 촬영 조명의 고르지 않음 |
| 빗금 칠(수은·이불) | 손으로 그은 빗금 | `HAND.paint(ctx, P, { fill: 'transparent', tex: [{ k: 'hatch', angle: -0.9, gap: 9 }], key, B })` | 없음 |
| 달·해·컵·침대·열쇠·연필 | 손그림 아이콘 | 모두 선 몇 개로 된 단순 도형이라 SVG 점 배열로 직접 만든다(달 = 원 두 개 차, 해 = 원 + 빗살 8개, 컵 = 사각 + 손잡이 호 + 김 곡선 2). `HAND.ink` 로 그린다. AI 일러스트는 쓰지 않는다(선 굵기와 떨림을 맞추기 어렵다) | 없음 |
| 온도계 게이지 | 없다 | 세로 둥근 사각 70x510px + 아래 원 지름 100px, 수은 높이 = 값에 비례, 파랑 기준선 3px #5050D0, 빨강 점선 `setLineDash([10,8])` #D04040. 닿을 때 빛 번짐은 `radial-gradient` 노랑 rgba(240,215,120,.5) 지름 160px 를 0.5초 | 없음 |
