# 로봇 마스코트와 연필이 채우는 3단계 사용법 — 분석 노트

> 크림 종이 위 손그림 선으로 그린 30초 서비스 사용법 영상. 작은 로봇 마스코트가 화면 왼쪽에 서 있고, 연필 한 자루가 와이어프레임 화면의 칸을 차례로 채운다. 번호 원과 손글씨 제목이 "1 연결 → 2 작성·설정 → 3 공개" 세 단계를 나눈다. 노랑 형광펜이 핵심 낱말에 그어지고, 노랑 체크 원이 끝난 일을 표시한다. 세 단계 뒤에 결론 문장 한 줄과 형광펜 밑줄로 끝난다. 에이전트·자동화 도구, 앱 연동, 가입·등록 절차처럼 "몇 단계면 된다"를 보여 주는 소개에 맞는다. 손그림 설명(doodle explainer) · 마스코트 · 와이어프레임 채우기 · 단계형 사용법.

출처 · gh:mattbean-917572. 작성자의 프롬프트는 약 240자다. 길이(30초), 스타일 이름(손으로 그린 느낌), 주제(판매 장터에 제품을 올리는 과정), 세 단계의 이름만 정했다. 마스코트, 색, 구도, 연필 동작, 전환은 없다. 이 노트는 영상 프레임(1초 간격 30장, 0.25초 간격 120장, 0.1초 간격 9장, 직접 뽑은 원본 크기 3장)을 보고 썼다.

## 3. 움직임

- 그리기 등장 · 선은 처음부터 끝까지 그려지며 나타난다(stroke-dashoffset 방식). 상자 한 개 0.25~0.5초, 로봇 전체 0.5초, 케이블 0.75초다.
- 손글씨 등장 · 제목과 결론 문장은 왼쪽부터 한 글자씩 생긴다. 한 글자 약 0.05~0.08초다.
- 연필 · 한 자루가 단계 2·3 내내 일한다. 촉이 지금 채우는 칸에 닿아 있고, 칸이 채워지는 동안 촉이 좌우로 약 30px 짧게 흔들린다. 칸 하나 0.25~0.75초 걸린다. 칸을 옮길 때는 0.15초에 튀듯 이동한다. 일이 끝나면 판 오른쪽 아래에 눕는다.
- 채우는 순서 · 위에서 아래, 글자 칸 → 그림 칸 → 체크 칸 → 버튼. 칸마다 끝나면 노랑 체크 원이 붙는다. 이 순서가 "에이전트가 대신 채운다"는 뜻을 보여 준다.
- 마스코트 표정 변화(시각 · 눈 모양) · 0.5~6.5초 점 눈 + 웃는 입 → 6.0~21초 일하는 동안 안테나 신호 물결 2줄 → 7.0초 연결 성공 때 ^ ^ 눈 → 13초쯤 집중하는 가는 눈 → 24초 공개 때 ^ ^ 눈 + 두 팔 들기 → 28~29초 손 흔들기 → 끝에 ^ ^ 눈.
- 마스코트는 늘 같은 크기(높이 33%)다. 단계 사이에서 깡충 뛰어 다음 장면으로 간다.
- 움직임 세기 목표 · 평균 2.2. 장면 안에서는 1 안팎(작은 선 그리기뿐), 밀기 전환 네 번만 9~14 다. 조용한 화면이 기본이다.

## 4. 전환

- 장면 밀기 · 3.0, 9.0, 21.25, 26.25초에 네 번. 화면 전체가 0.5초 동안 왼쪽으로 빠지고 새 장면이 오른쪽에서 들어온다. 처음은 느리고 끝은 빠르다(가속).
- 로봇이 전환을 끈다 · 밀기 동안 로봇은 다른 요소보다 늦게 움직이고 높이 약 15% 를 깡충 뛰어, 앞 장면 위를 지나 다음 장면 자리로 간다. 21.5초에는 로봇이 와이어프레임 앞을 지나간다.
- 같은 장면 안 확장 · 15.5초에 판이 하나 더 들어오면서 기존 요소가 약 92% 로 작아지고 왼쪽으로 옮긴다. 컷 없이 칸을 늘린다.
- 판정 메모의 "장면 사이 지우기 전환"은 프레임에서 확인되지 않았다. 0.1초 간격 프레임에서 지우개 자국이나 선이 사라지는 모습은 없고, 장면이 통째로 밀려 나간다.

## 5. 타이포

- 글꼴 · 라틴 손글씨 서체 두 가지다. 제목은 굵은 손글씨 이탤릭, 칸 안 글자와 부제는 가는 손글씨다. 한국어 글자는 없다.
- 크기(화면 높이 대비) · 제목·결론 문장 약 6%(약 65px), 칸 안 굵은 값 약 3%, 칸 이름표·부제 약 2%, 말풍선 약 2.5%.
- 형광펜 · 낱말 아래 2/3 를 덮는 옅은 노랑 띠. 끝이 조금 비스듬하고 거칠다. 띠 높이는 글자 높이의 약 60% 다.
- 강조는 형광펜 한 가지다. 굵기나 색으로 강조하지 않는다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 9.5~15.5초의 2단계. 왼쪽(가로 15~27%)에 로봇(높이 33%), 오른쪽(가로 37~62%, 세로 33~62%, 약 480x310px 에서 시작해 15.5초 이후 두 판 합쳐 약 1000x400px)에 브라우저 와이어프레임, 연필 한 자루가 이름 → 소개 → 가격 → 그림 → 체크박스 순서로 칸을 채우고 칸마다 노랑 체크 원이 붙는다. 동시에 보이는 요소는 번호 원·제목 2 + 로봇 1 + 와이어프레임 1 + 연필 1 + 체크 원 3~6 이다.
- 12초 판 압축 예 · 0~1.5초 제목 + 로봇 그리기 → 1.5~4초 1단계(상자 + 케이블 + 연결 체크) → 4~8.5초 2단계(연필이 칸 4개만 채움, 설정 판은 뺌) → 8.5~10.5초 3단계(카드 + 도장 + 색종이) → 10.5~12초 결론 한 줄 + 형광펜. 밀기 전환은 0.35초로 줄이고, 말풍선 6개는 2개로 줄인다.
- 번호 원 + 손글씨 제목 머리. 단계마다 같은 자리(왼쪽 위)에 같은 형식으로 둔다.
- 마스코트 한 명이 전 과정을 지켜보고 표정으로 반응한다. 말이 없어도 성공 순간(연결, 공개)이 읽힌다.
- 단계마다 다른 동작 하나 · 1단계 케이블 꽂기, 2단계 연필로 칸 채우기, 3단계 도장 찍기와 색종이. 같은 화면 틀 안에서 동작만 바뀐다.
- 체크 원으로 진행을 쌓기. 칸이 끝날 때마다 작은 노랑 체크가 붙어 화면에 진행이 남는다.
- 끝의 형광펜 밑줄 한 줄. 결론 문장의 핵심 두 낱말에만 긋는다.

## 7. 함정

- 화면에 실존 서비스 이름 글자가 상자 안 로고 자리, 승인 문구, 주소, 결론 문장에 나온다. 쓰지 않는다. 대상 서비스 이름은 사용자가 허락한 것만 쓰고, 상자 안은 일반 도형(사각 로고 자리)으로 둔다.
- 화면의 제목, 칸 안 값(앱 이름, 가격, 소개 문구), 말풍선 문구, 결론 문장은 원작의 것이다. 옮기지 않는다. 역할(단계 제목, 칸 값, 판매 알림, 결론 문장)만 가져온다.
- 칸 안 글자가 작다(높이 2~3%). 12초 판에서는 칸 수를 줄이고 글자를 4% 이상으로 키운다. 한국어 손글씨 서체가 없으므로 Pretendard 로 쓰면 손그림 느낌이 약해진다("## 8").
- 연필 촉 위치가 채워지는 칸과 어긋나면 바로 티가 난다. 촉 좌표를 칸 채우기 진행값에서 계산한다.
- 장면 안 움직임이 작다(평균 1 안팎). 소리가 없으면 지루해질 수 있다. 연필 사각거림 효과음이나 단계마다 작은 효과음을 둔다.
- 손그림 선이 떨지 않는다(같은 선이 프레임마다 같다). 선 떨림(boil)을 넣으면 원작과 다른 스톱모션 느낌이 된다. 넣지 않는다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 글꼴은 Pretendard Regular·SemiBold 뿐이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 손글씨 제목·칸 글자 | 손글씨 서체가 없다 | Pretendard SemiBold 64px(제목), Regular 36px(칸 값), 26px(이름표). 제목만 `transform: skewX(-6deg) rotate(-0.6deg)` 로 조금 기울인다. 한 글자씩 등장은 글자마다 span 에 투명도 0 → 1, 간격 0.06초 | 손글씨 느낌 |
| 떨리는 손그림 선 | 손으로 그은 선의 흔들림 | 모든 상자·로봇·케이블 경로를 로드 때 `HAND.wobble(P, closed, 1.6, key, 0)` 로 한 번만 흔든다(B=0 고정, 떨지 않음). 그리기는 `HAND.ink(ctx, P, { frac, w: 5, color: '#1E1C1A', key, B: 0 })` 의 `frac` 으로 | 없음 |
| 로봇 마스코트 | 캐릭터 그림 | 도형으로 그린다. 머리 둥근 사각 230x150px, 몸 150x130px, 안테나 선 40px + 노랑 원 지름 22px, 단추 지름 44px #FFBE00, 볼 터치 타원 24x12px #FDD446. 눈은 점(지름 14px) ↔ ^ 모양 호 두 개를 바꿔 그린다. 깡충 뛰기는 0.5초 포물선 높이 160px + 착지 때 0.08초 동안 높이 92% | 없음 |
| 연필 | 사물 그림 | SVG 다각형(몸통 노랑 #FFD23F 280x34px, 촉 삼각형 + 먹 심, 끝 분홍 지우개). 칸을 채우는 동안 촉 위치 = 칸 시작 + 진행값 x 칸 폭, 거기에 `sin(t*40)*6px` 좌우 흔들림 | 없음 |
| 형광펜 띠 | 거친 끝 | `HAND.ribbon(ctx, P, u => 26, { color: 'rgba(253,212,70,.85)' })`, P 는 낱말 아래 60% 높이를 따라 가는 직선 + 양 끝 4px 기울기. 왼쪽부터 0.25초에 `subPath(P, frac)` | 붓 끝의 결 |
| 도장 | 찍힌 잉크의 빈틈 | 빨강 #ED4A41 사각 테두리 8px + 굵은 낱말(InterVariable 800). 위에 `texTile` 로 만든 얼룩을 `destination-out` 투명도 0.3 으로 뺀다. 0.12초에 140% → 100%, -12° | 잉크 번짐 |
| 색종이 조각 | 수십 개 입자 | 시드 고정 난수로 40개(삼각·별·사각·물결 호), 처음 속도 위쪽 600~1100px/s, 중력 1400px/s², 회전 2~6rad/s. 위치는 t 의 식으로 계산(결정적) | 없음 |
| 점 격자 종이 | 없다 | 바탕 #F8F6EA + `radial-gradient(#D8D4C8 1.5px, transparent 1.6px) 0 0 / 45px 45px` + 가장자리 비네트 rgba(0,0,0,.06) | 없음 |
