# 주황 점 하나가 잇는 일곱 장면 · 모션 기술 시연 — 분석 노트

> 주황 점 하나가 모든 장면을 잇는 15초 모션 디자인 시연 영상. 크림 바탕의 주황 토글을 커서가 눌러 끄면, 설정 이름의 앞 낱말이 글자마다 휘며 떨어지고 뒷 낱말 하나가 화면 폭의 69% 로 커진다. i 의 점이던 주황 점이 뛰어올라 스프링 그래프를 그리고, 구슬 줄을 타고 커져 원이 된다. 그 원이 박마다 바탕색을 뒤집으며 둥근 사각형 → 알약 → 점으로 바뀌고, 점 둘레를 낱말 고리가 돌고, 망점 격자의 물결이 검은 화면으로 번진 뒤 끝 카드의 마침표가 된다. 마지막 1.3초는 모든 장면을 거꾸로 감아 첫 프레임으로 돌아간다. 도구·기술·디자인 시스템 소개, 고리 반복(루프) 광고에 맞는다. 키네틱 타이포 · 도형 변형 · 배경 반전 컷 · 되감기 루프.

출처 · pm:ultimaxbt-bbebf5. 작성자의 글은 약 3,400자다. 주제(제작 도구의 모션 능력 과시), 스타일(크림·검정·주황 한 색, 굵은 글자, 금지 목록), 구성(토글 → 스프링 → 도형 → 글자 → 망점 → 끝 카드 → 되돌아옴의 일곱 장면), 제작 방식(시간 함수 하나, 닫힌 식 스프링, 그래프와 점이 같은 함수)을 정했다. 요소의 크기와 위치, 장면별 길이, 바탕색이 바뀌는 시각, 고리의 기울기, 되돌아오는 방식의 실제 모습은 비어 있다. 이 노트는 영상 프레임(0.5초 간격 시트 31칸, 원본 해상도로 직접 뽑은 프레임 75장)을 보고 썼다.
측정 · 파일 1920x1078(16:9 에서 2px 모자람) · 60fps · 15.12초. 장면 전환 검출은 16번이다. 진짜 컷은 5.65, 6.12, 6.58, 7.05(바탕 반전 4번), 9.42초(글자 고리 → 망점)다. 13.67~14.20초의 11번은 되감기 몽타주의 장면 스침이다. 0.5초마다 움직임 세기의 평균은 24.8 이다. 가장 큰 값은 5.5초(126.3, 바탕 반전), 9.0초(90.1), 6.5초(86.1), 10.5초(73.9)다. 가장 작은 값은 2.5초(0.6)와 3.5초(1.1)다. 크기와 위치는 원본 해상도 프레임에서 화소를 세어 1920x1080 기준으로 적었다. 색 값은 화소를 직접 읽은 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. 측정 BPM 은 84.7 이다. 그러나 타격 간격이 약 0.233초(2.18, 2.42, 2.66, 2.89, 3.12, 3.35초 / 12.05~12.99초 5번)이고 바탕 반전 컷 간격이 0.467초(5.65 → 6.12 → 6.58 → 7.05)라서 실제 박은 약 128 BPM(박 0.47초)으로 본다. 84.7 은 128 의 약 2/3 이다. 그래서 측정된 마디 첫 박(1.94, 4.76, 7.58 …)은 쓰지 않는다. 0~0.52초와 0.58~1.10초가 무음이다. 0.52초에 가장 센 타격(세기 1.00, 저역 없음)이 있고 커서가 토글을 누르는 순간과 같다. 음악은 약 1.1초부터 시작된다. 저역 킥은 2.89~3.35초(점이 뛰어 휙 넘어가는 구간), 4.06·4.30초(그래프 고점), 9.71초(망점 물결), 11.59·11.82초(마침표 착지)에 있다. 13.5초부터 음량이 -26dB 로 떨어지고(되감기), 14.62초 뒤는 무음이다.

## 1. 본질

- 색은 셋뿐이다. 크림 바탕(#EEE8E3 ~ #EDE9E1 근처), 거의 검정(#14120E ~ #16110E 근처), 주황(#FE4D1C 근처). 토글 손잡이만 순백(#FFFFFF)이고 꺼진 토글은 회갈색(#CFC5B9 근처)이다. 끝 카드 윗줄은 회색(#909090 근처, 16단계 묶음 값)이다.
- 주황은 언제나 점이나 그 점이 바뀐 도형 하나에만 쓴다. 예외는 6.12~6.58초의 주황 바탕(이때 도형이 검정으로 뒤집힌다)과 끝 카드의 숫자 한 자다.
- 주인공은 주황 점이다. 지름이 82px(i 의 점) → 80px(그래프) → 500~516px(원) → 106px(점) → 252px → 58px(망점 위) → 36px(마침표)로 바뀐다. 장면이 바뀌어도 점이 화면에서 사라지는 순간이 없다(되감기 제외).
- 장면마다 화면 구성이 다르다. 큰 낱말 하나, 선 그래프, 꽉 찬 도형, 원기둥 글자 고리, 망점 격자, 왼쪽 정렬 글자 세 줄. 같은 구성이 두 번 나오지 않는다.
- 동시에 보이는 요소는 1~3개다. 가장 많을 때는 그래프(축 2개, 점선, 곡선과 표본점, 점, 숫자, 지시선)다.
- 아닌 것 · 그라데이션, 빛 번짐, 입자 터짐, 사진, 아이콘, 둘째 강조색, 가운데 정렬 큰 제목, 설명 문장.

## 3. 움직임

- 점의 이동은 모두 스프링이다. 뛰어오를 때 아래로 늘어난 꼬리, 착지 때 눌림, 멈출 때 작은 넘침이 있다. 넘침은 크지 않다. 셋째 줄이 약 60px 넘었다 돌아오는 것이 가장 크다.
- 그래프의 고점 숫자는 넘침 비율이다. 곡선이 목표 점선을 넘는 높이가 원점에서 목표까지의 약 22% 다. 감쇠비 약 0.43 의 스프링에서 나오는 값이다(## 8 에 식). 곡선을 그리는 함수와 점을 옮기는 함수가 같아서 점이 곡선 위를 벗어나지 않는다.
- 도형 장면은 같은 물체의 상태 변화다. 원(516px) → 45° 둥근 사각형(대각선 약 690px, 변 약 555px, 모서리 반지름 변 길이의 약 20%) → 알약(1098x336px, 끝이 반원) → 점(106px). 중심은 화면 가운데에서 움직이지 않는다. 바뀌는 순간마다 바로 앞 모양이 가는 윤곽선(두께 약 3px)으로 남아 0.3~0.4초에 옅어진다.
- 바탕 반전은 박마다 한 번이다(0.467초 간격 4번). 도형 색과 바탕색이 서로 자리를 바꾼다. 검정 위 주황 → 주황 위 검정 → 크림 위 주황 → 검정 위 주황.
- 글자 고리는 원기둥 둘레를 도는 원근이다. 앞쪽 글자가 크고 진하며, 옆으로 갈수록 좁아지고, 뒤쪽 글자는 회색으로 뒤집혀 보인다. 고리의 기울기는 위에서 약 15° 내려다본 정도다(눈대중). 점은 고리 중심보다 조금 위(세로 45~55%)에 고정이다.
- 망점 격자는 점까지의 거리에 따라 크기가 바뀐다. 물결이 지나가는 고리만 점이 2~3배 커진다. 마지막에 가운데부터 점이 격자 간격(54px)을 넘을 만큼 커져 서로 붙고 검은 면이 된다.
- 끝 카드 글자는 가린 선 아래에서 올라오는 방식이다. 줄마다 출발 시각이 다르다(1·2줄 11.3초, 3줄 12.25초).
- 흐림 · 빠른 이동(0.6초 물러나기, 2.5~3.5초 점 꼬리와 휙 팬, 5.25초 쏘아지기, 9.3초 떨어짐, 되감기 전체)에 진한 움직임 흐림이 있다. 느린 구간은 선명하다.
- 움직임 세기 목표 · 평균 24.8. 컷 순간의 큰 값(126.3, 90.1, 86.1)을 빼도 1~13초 대부분이 5~16 이다. 쉬는 곳은 2.0~2.5초, 3.5~4.0초 두 곳뿐이다.

## 4. 전환

- 진짜 하드 컷은 5번이다. 바탕 반전 4번은 도형의 위치와 크기를 그대로 두고 색만 바꾼다. 9.42초 컷은 떨어지던 점이 다음 장면에서 계속 떨어지며 이어진다.
- 토글 → 낱말 · 카메라 물러나기와 글자 떨어뜨리기로 남길 낱말만 남긴다.
- 낱말 → 그래프 · 점이 뛰어오르고 휙 팬. 점이 팬 방향으로 꼬리를 끌어 두 장면을 잇는다.
- 그래프 → 도형 · 곡선의 표본점이 구슬 줄이 되고, 점이 그 줄을 따라 커진다.
- 도형 → 고리 · 알약이 점으로 줄어들고, 그 점 둘레에 고리가 생긴다.
- 고리 → 망점 · 점이 떨어져 망점 격자 위로 떨어진다(컷).
- 망점 → 끝 카드 · 망점이 커져 검은 면이 되고, 남은 점이 날아가 마침표가 된다.
- 끝 카드 → 처음 · 모든 장면을 약 10배속으로 거꾸로 감는다(13초 분량을 1.3초에). 장면마다 2~9프레임만 보인다.

## 5. 타이포

- 글꼴은 굵은 고딕 한 계열이다. 끝 카드와 큰 낱말은 아주 굵은 굵기, 고리 글자는 굵은 대문자, 끝 카드 윗줄은 중간 굵기다.
- 큰 낱말 · 대문자 높이 286px(26.5%), 폭 1327px(69%). 글자 사이가 좁다.
- 첫 장면 설정 이름 · 1.0초에 대문자 높이 약 127px(11.8%), 두 낱말 폭 1268px. 머리글자만 조금 기울어 있다(떨어지기 직전 동작의 시작).
- 고리 글자 · 대문자, 앞쪽 대문자 높이 88px(8.2%). 낱말 사이에 가운뎃점. 뒤쪽은 회색(#505050 근처).
- 그래프 숫자 · 대문자 높이 89px(8.3%), 검정, 굵게.
- 끝 카드 · 왼쪽 정렬, 왼쪽 여백 154px(8%). 윗줄 회색 대문자 높이 54px(5.0%, 세로 24~30%). 둘째 줄 크림색 대문자 높이 144px(13.4%, 세로 36~50%, 폭 1621px = 84%) + 주황 마침표 36px. 셋째 줄 대문자 높이 120px(11%, 세로 59~70%), 맨 앞 숫자 한 자만 주황.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 5.5~7.25초. 화면 가운데 지름 약 510px 원이 0.467초마다 바탕색과 자리를 바꾸며(크림 → 검정 → 주황 → 크림 → 검정 4번) 45° 둥근 사각형(대각선 약 690px) → 알약(1098x336px) → 점(106px)으로 바뀌고, 바뀔 때마다 앞 모양이 가는 윤곽선 잔상으로 남는다. 요소는 도형 1 + 윤곽선 잔상 1(+ 처음 0.15초의 구슬 줄). 박에 맞춘 바탕 반전과 윤곽선 잔상이 없으면 이 영상이 아니다.
- 12초 판 압축 예 · 0~1.2초 토글 누름과 물러나기(1.2초). 1.2~2.4초 글자 떨어짐과 큰 낱말(1.2초). 2.4~4.4초 점 뛰기, 휙 팬, 그래프(2.0초, 그래프가 멈춘 뒤 0.5초를 뺀다). 4.4~6.3초 구슬 줄과 도형 4상태(1.9초, 대표 장면을 그대로 둔다). 6.3~7.6초 글자 고리(1.3초, 반 바퀴만). 7.6~9.0초 망점 물결과 검은 덮음(1.4초, 물결 1번). 9.0~10.8초 끝 카드(1.8초). 10.8~12.0초 되감기(1.2초). 빼는 것은 2.0~2.5초의 멈춤, 고리 뒤 반 바퀴, 망점 둘째 물결이다.
- 첫 프레임과 끝 프레임이 같은 고리 반복 구조. seek(t) 가 순수 함수면 되감기는 시간을 거꾸로 넣는 것만으로 된다.
- 하나의 점이 장면마다 역할을 바꾸는 구성. 글자의 일부 → 그래프의 측정점 → 도형 → 고리의 중심 → 망점의 원천 → 마침표. 대상의 기능 여섯 가지를 점의 여섯 역할에 대응시킬 수 있다.
- 그래프 숫자를 실제 곡선에서 계산하는 방식. 화면의 숫자와 움직임이 같은 값이다.
- 박마다 바탕을 뒤집는 컷. 도형을 그대로 두고 색만 바꾸면 컷이 많아도 끊겨 보이지 않는다.
- 끝 카드의 마침표를 주인공 점으로 끝내는 마무리.

## 7. 함정

- 화면의 설정 이름, 큰 낱말, 고리 낱말 6개, 그래프 숫자, 끝 카드 세 줄은 원작의 것이다. 옮기지 않는다. 역할(설정 이름, 주제어, 기능 낱말 고리, 수치 하나, 이름 + 한 줄 정의 + 수치 한 줄)만 가져온다. 끝 카드 윗줄은 실존 AI 모델 이름이다. 쓰지 않는다.
- 원래 글과 실제 화면이 다른 점.
  - 커서는 토글을 켜는 것이 아니라 끈다. 첫 화면은 이미 켜진 토글의 극근접이다.
  - 원래 글은 무작위 전환을 금지했다. 실제는 바탕 반전 하드 컷 4번과 고리 → 망점 하드 컷 1번이 있다. 모두 점이나 도형으로 이어져 있어서 무작위로 보이지 않는다.
  - 원래 글은 2D 를 정했다. 글자 고리는 원기둥 원근(뒤쪽 글자가 뒤집힘)이다.
  - 원래 글의 되돌아오기는 점이 망점·그래프·토글을 거꾸로 지나가는 동작이다. 실제는 모든 장면을 빠르게 거꾸로 감는 몽타주다.
  - 끝 카드 셋째 줄은 13.5초에 가라앉아 사라진 뒤 되감기가 시작된다.
- 템포 측정이 틀리기 쉽다. 이 영상은 측정값 84.7 이 아니라 약 128 BPM 이다. 컷과 사건을 0.467초 격자에 맞춘다.
- 컷 순간의 움직임 세기(126.3)가 매우 크다. 바탕 전체가 검정 ↔ 크림 ↔ 주황으로 뒤집히기 때문이다. 0.47초에 4번 이어지면 눈이 피로하다. 4번을 넘기지 않는다.
- 큰 낱말의 i 점 장치는 라틴 글자에만 있다. 한국어 판에서는 끝 카드의 마침표, 받침 ㅇ 자리, 또는 숫자·라틴 낱말(InterVariable)에 점을 붙인다. 한국어 글자는 140px 이하로 두므로 대문자 높이 286px 의 낱말은 한국어로 못 쓴다. 큰 낱말 장면은 숫자·라틴 낱말을 쓰거나, 한국어 140px 낱말에 카메라를 붙여 화면 폭 50% 이상을 채운다.
- 글자가 휘며 떨어지는 동작은 글자 단위로 나뉘어야 한다. 한국어는 음절 단위로 나눈다. 음절이 커서 회전이 어색하면 회전 각을 20° 이하로 줄인다.
- 움직임 흐림이 빠지면 휙 팬과 되감기가 깜박임으로 보인다. 렌더 도구에 하위 프레임 합성이 없으므로 화면에서 흐림을 직접 만든다(## 8).
- 첫 프레임과 끝 프레임의 커서 위치가 다르면 반복 재생 때 튄다. 원본은 끝에서 커서를 화면 밖으로 빼 둔다. 처음 0초에도 커서가 화면 밖에서 들어오게 맞춘다.
- 파일이 1920x1078 이다. 만들 때는 1920x1080 으로 둔다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

글꼴은 Pretendard Regular·SemiBold(숫자·라틴은 InterVariable)뿐이다. 원본의 아주 굵은 굵기가 없으므로 굵기 차이로 생기는 무게감은 크기와 색 대비로 대신한다. 값은 1920x1080 기준이다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 아주 굵은 큰 낱말 | 굵은 굵기 글꼴이 없고 한국어는 140px 제한 | 숫자·라틴 낱말이면 InterVariable `font-weight: 800`, 글자 크기 390px(대문자 높이 약 286px), 자간 −0.03em. 한국어면 Pretendard SemiBold 140px 에 카메라 배율 1.0 을 유지하고 낱말 폭이 화면의 50% 이상이 되게 4~6 음절을 쓴다 | 한국어 판의 화면을 누르는 무게 |
| 글자가 휘며 떨어짐 | 없다. DOM 으로 된다 | 글자 span 마다 회전 −20~−40°, 아래 300~600px, 왼쪽 100~250px 로 0.5초. 글자 사이 출발 간격 0.03초. 닫힌 식 스프링(진동수 8, 감쇠 0.7) | 글자 모양 자체가 휘는 느낌(원본도 회전에 가깝다) |
| 스프링 그래프와 숫자 | 없다. SVG 로 된다 | y(t) = 1 − e^(−ζωt)·(cos ω_d t + ζ/√(1−ζ²)·sin ω_d t), ζ = 0.43, ω = 9, ω_d = ω√(1−ζ²). 넘침 e^(−ζπ/√(1−ζ²)) ≈ 0.22 를 화면 숫자로 쓴다. 축 1240x585px, 곡선 2px 검정, 표본점 지름 7px 을 0.04초 간격. 점은 같은 y(t) 위를 지난다 | 없음 |
| 원 → 사각형 → 알약 → 점 | 없다. DOM 으로 된다 | div 하나의 폭·높이·`border-radius`·회전만 보간한다. 516x516 · 50% → 555x555 · 20% · 45° → 1098x336 · 168px · 0° → 106x106 · 50%. 바뀔 때마다 같은 모양 복제본에 `border: 3px solid`, 배경 투명, 투명도 0.6 → 0, 크기 1 → 1.08 을 0.4초 | 없음 |
| 바탕 반전 4번 | 없다 | 바탕색을 5.65·6.12·6.58·7.05초 프레임에 바로 바꾼다(검정 #14120E, 주황 #FE4D1C, 크림 #EEE8E3). 도형 색은 바탕과 반대로. 각 반전 직전 한 프레임만 두 색의 반반 섞음 | 없음 |
| 원기둥 글자 고리 | 원근과 뒤쪽 글자 뒤집힘 | canvas 2D 로 글자마다 θ 를 주고 x = 700·sinθ, y = 중심 + 220·cosθ, 가로 배율 = cosθ(음수면 좌우 뒤집힘), 크기 = 1 + 0.35·cosθ. 앞쪽(cosθ>0) 흰색 #EEE8E3, 뒤쪽 회색 #505050. 각속도는 초당 약 120°. 대문자 높이 88px(InterVariable 800, 120px) | 글자 획의 실제 원근 왜곡 |
| 망점 격자와 물결, 검은 덮음 | 없다. canvas 로 된다 | 격자 간격 54px, 기본 반지름 3.75px. 점까지 거리 d 에서 반지름 = 3.75 + 8·e^(−((d − R(t))/40)²), R(t) 는 0.7초에 0 → 600px(2번). 덮음은 반지름 = 3.75 + max(0, 40 − d/k(t)), k 를 0.5초에 줄여 화면 끝까지 검게(반지름 38px 이면 이웃 점과 붙는다) | 없음 |
| 움직임 흐림(점 꼬리, 휙 팬, 되감기) | 렌더 도구에 하위 프레임 합성이 없다 | 점 꼬리는 같은 점을 0.012초 간격 과거 위치에 6벌, 투명도 0.5 → 0.05. 휙 팬은 무대 묶음에 SVG `feGaussianBlur stdDeviation="30 0"`. 되감기는 프레임마다 seek 를 0.02초 간격으로 3번 그려 투명도 1/3 씩 겹친다 | 진짜 셔터 흐림의 균일함 |
| 되감기 몽타주 | 없다. seek 가 순수하면 된다 | 13.45~14.75초에서 t' = 13.45 − (t − 13.45)·10 으로 seek(t') 를 부른다. 14.75초 이후는 seek(0) 과 같은 상태로 둔다. 끝 프레임 = 첫 프레임 | 없음 |
| 끝 카드 가린 선 등장 | 없다 | 줄마다 `overflow: hidden` 상자, 글자 translateY 110% → 0 을 0.45초, 셋째 줄은 −8% 넘었다 돌아오는 스프링. 둘째 줄 끝 마침표 자리에 주황 점(36px)이 날아와 앉는다 | 없음 |
