# 털뭉치 시뮬레이션 · 개체가 곧 자료점이 되는 실험판 — 분석 노트

> 따뜻한 크림색 실험판 위에서 털 난 작은 캐릭터 160마리가 실제 규칙대로 먹고, 지치고, 사라지고, 새끼를 낳는 52초 영상. 낮은 근접 화면에서 한 마리를 따라가다가 판 전체를 내려다보는 화면으로 오르기를 되풀이한다. 끝에 스무 세대가 지난 무리가 판에 인쇄된 막대 칸으로 걸어 들어가 스스로 막대그래프가 된다. 진화·게임 이론·감염·대기열·시장처럼 규칙 몇 개에서 결과가 계산되어 나오는 과정을 보여 주는 설명 영상에 맞는다.

## 3. 움직임

- 원래 글의 깡충 걸음, 숨쉬기, 지침·사라짐·태어남 연기, 몸끼리 안 겹치게 밀어내기는 화면과 맞다.
- 영상에서 확인한 점 · 머리 위 화면도 완전히 멈추지 않는다. 6.5~9.0초에 세기 1.1~1.6 이 남는다. 개체들의 숨쉬기와 판의 느린 기울기·회전이 만든다. 마지막 정지(45.5초부터)만 0.0 이다. 원래 글이 정한 규칙(완전 정지는 마지막에만)과 맞다.
- 판정 장면의 머릿수는 한 번에 바뀌지 않는다. 21.5~23.0초에 160 → 158 → 162 → 159 로 사라짐과 태어남이 섞이며 오르내린 뒤 멈춘다.
- 막대로 들어가는 이동은 약 4초(39.5~43.5초)다. 왼쪽 칸이 먼저 차고, 가장 높은 칸이 가장 늦게 찬다. 세기가 7.8 → 1.0 으로 매끄럽게 줄어든다.

## 4. 전환

- 원래 글대로 하드 컷은 박자 자리 세 번뿐이고(10.00, 32.00, 34.42초), 나머지는 이어지는 카메라 하나다.
- 영상에서 확인한 점 · 근접 → 머리 위 오르기는 약 2초(4.5~6.5초)이고, 그동안 세기 33~39 로 이 영상에서 가장 크게 움직인다. 크레인 오르기(19.5~21.0초)는 1.5초, 세기 26~34 다.
- 판정·결과 뒤에는 늘 정지가 온다. 23.0~26.5초 3.5초, 45.5~52.0초 6.5초.

## 5. 타이포

- 둥근 기하 고딕. 제목과 큰 숫자는 아주 굵고, 설명은 보통 굵기다.
- 크기(화면 높이 대비) · 근접 제목 대문자 5.3%(약 57px), 그 위 작은 분류 줄 1.3%, 아래 둘째 언어 줄 3%. 머리 위 판의 머릿수 9.7%(약 105px), 판정 머릿수 11%(약 120px). 규칙 줄 2.4%. 자막 두 줄 3% + 2%.
- 자막은 왼쪽 아래(가로 5~45%, 세로 84~93%)의 반투명 크림 상자에 둔다. 글자는 무리 위에 올리지 않는다. 판의 빈 바닥이나 왼쪽 글 판에만 둔다.

## 6. 가져올 것

- 12초 판에서 꼭 남길 대표 장면 · 원본 39.0~44.5초의 "흩어진 무리가 판에 인쇄된 점선 칸 8개로 걸어 들어가 자기 몸색 그대로 막대그래프가 되는" 장면이다. 개체 약 200마리, 가장 높은 막대에 약 70마리(막대 높이 화면의 39%), 개체 지름 약 33px, 칸이 화면 가로 전체를 쓴다. 다 앉은 뒤 옛 값 → 새 값(대문자 80px, 민트 밑줄)이 오른쪽 위에 뜨고 화면이 완전히 멈춘다. 그래프가 떠 있는 카드가 되면 이 영상이 아니다.
- 12초 판 압축 예 · 0~1.5초 낮은 근접(주인공 높이 40%, 제목 왼쪽 위), 1.5~2.5초 머리 위로 오르기, 2.5~3.5초 머리 위 판과 왼쪽 글 판(규칙 세 줄), 3.5~5.5초 낮은 옆 따라가기 느린 화면(빠른 개체가 먹고 지쳐 회색), 5.5~6.5초 크레인으로 판 전체 판정(고리와 머릿수), 6.5~7.5초 세대 물결 시간 경과(무리가 파랗게 바뀐다), 7.5~9.5초 대표 장면의 걸어 들어가기 2초, 9.5~12.0초 결과 정지 2.5초. 초점 넘기기와 9세대 근접은 뺀다.
- 한 마리를 따라가다 판 전체로 오르는 시점 왕복. 근접에서 머리 위까지 2초 안에 오른다.
- 속도 같은 연속 값을 몸색 하나로 나타낸다. 먹이는 그 색 계열 밖의 색(민트)으로 둔다.

## 7. 함정

- 화면의 제목, 질문 문장, 규칙 문장, 수치, 맺음 문구, 끝 표기는 원작의 것이다. 옮기지 않는다. 역할(질문 한 줄, 규칙 세 줄, 판정 수치, 옛 값 → 새 값)만 가져온다. 끝 표기에 실존 회사·모델 이름이 있다. 쓰지 않는다.
- 원작의 실험 결과(평균이 얼마에서 얼마로)를 우리 영상에 숫자로 옮기지 않는다. 우리 규칙으로 실제로 돌린 결과만 쓴다. 이 저장소의 사실 확인 규칙과 같다.
- 개체 수를 줄이면 "무리"가 아니라 "몇 마리"가 된다. 머리 위 화면에서 판 쪽에 60마리 이상, 마지막 그래프에 150마리 이상을 둔다.
- 캐릭터 색이 판 색과 비슷해지면(노랑이 크림에 묻힘) 무리가 흐려진다. 노랑 개체에는 아래 그림자(불투명 0.3)를 꼭 둔다.
- 결과 정지를 짧게 자르면 결론이 안 남는다. 원래 글대로 2.5초 이상 둔다. 12초 판에서도 마지막 2.5초는 움직이지 않는다(숨쉬기도 멈춘다).
- 근접 화면의 뒤쪽 흐림이 없으면 판이 장난감 매트처럼 보인다. 아래 표의 안개 대체를 꼭 쓴다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 3D 는 three.js(`vendor/three`)와 `vendor/three-looks/looks.js` 로 만든다. 판 1칸 = 1단위로 둔다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 털 난 몸 | 원본은 섬유 법선을 쓴 털 재질이다 | 몸은 위가 둥근 구(SphereGeometry 32x24, 세로 0.9배, 아래 10% 평평)를 InstancedMesh 로 200개. 재질은 `LOOKS.clay(color, { instanced: true, roughness: 0.82, rimPower: 0.3 })` 로 무광 + sheen + 가장자리 빛을 준다. geometry 에 개체 수만큼 `aShow` 속성(모두 1)을 단다. 색은 개체마다 `setColorAt` 으로 속도 색 계열에서 고르고, 지치면 #A07F79 쪽으로 0.8초에 섞는다. 환경맵 `LOOKS.env(gl, 'studio')` | 털끝의 잔 반짝임 |
| 얼굴(눈, 볼, 머리 끝 털) | 근접에서만 보이고 표정이 바뀐다 | canvas 로 얼굴 텍스처 4장(평소, 눈 감음, 놀람, 지침)을 굽고 몸 앞 작은 평면에 붙인다. 눈 #13162B 에 흰 반사점 하나, 볼 분홍 불투명 0.4. 머리 끝 털은 ConeGeometry 를 15° 휘게 놓는다. 머리 위 화면(개체 54px 이하)에서는 눈만 2~3px 점으로 남긴다 | 표정의 미묘함 |
| 실제 시뮬레이션 | 결과를 손으로 놓으면 안 된다 | 시뮬레이션은 JS 로 따로 돌려 기록한다. `LOOKS.rng(seed)` 로 위치·속도를 정하고, 0.05초 단위로 위치·방향·먹은 수·기력을 배열에 쌓는다. seek(t) 는 기록을 보간만 한다. 결과가 밋밋하면 규칙 값을 바꾸고 그 사실을 사실 문서에 적는다 | 없음(시간이 든다) |
| 접촉 그림자 | 화면 공간 차폐는 작은 몸 수백 개에서 깜빡인다 | 해 하나를 고정한 DirectionalLight 그림자 + `LOOKS.floor()` 의 그림자 받는 바닥. 머리 위 화면에서는 몸 아래 원형 그림자 평면(지름 = 몸의 1.1배, 불투명 0.3)을 InstancedMesh 로 더한다 | 부드러운 차폐의 깊이 |
| 근접 화면의 얕은 초점 | `LOOKS.post` 에 초점 흐림이 없다 | `scene.fog = new THREE.Fog('#E3D9CB', 4, 16)` 로 먼 개체를 안개색으로 녹인다. 근접 숏만 판을 두 층으로 그린다(뒤 층 canvas 에 CSS `filter: blur(5px)`, 앞 3마리만 앞 층). 초점 넘기기는 두 층의 개체를 바꿔 끼우며 흐림 0 ↔ 5px 을 0.6초에 바꾼다 | 둥근 빛망울 |
| 판에 인쇄된 칸·축·규칙 | 떠 있는 카드가 되면 안 된다 | 판 위에 눕힌 평면 하나에 canvas 텍스처(4096x2048)로 그린다. 점선 칸(선 4px, 점선 14px/10px, 회색), 칸 안 옅은 채움(칸 색의 12%), 축 숫자는 InterVariable 600. 인쇄 등장은 텍스처의 불투명을 0.4초에 0 → 1. 판 밖 글자(제목, 결과 숫자, 자막)만 DOM 층에 둔다 | 없음 |
| 막대로 걸어 들어가기 | 개체 200마리의 자리와 경로를 정해야 한다 | 칸마다 자리를 가로 6 x 앞뒤 2 x 위로 n줄로 미리 계산한다. 개체를 속도 칸에 넣고, 칸 안에서는 도착 순서대로 아래 줄부터 채운다. 경로는 직선 + 깡충(높이 0.08단위), 출발 지연은 거리 순으로 0~1.5초. 위 줄로 오를 때만 0.15단위 점프 | 서로 비키며 걷는 자연스러움 |
| 깡충 걸음과 찌그러짐 | 없다 | 걸음 위상 = 이동 거리 / 보폭(보폭 0.35 + 속도 x 0.2). 높이 = abs(sin(위상 x π)) x 0.06 x 움직임 비율, 찌그러짐 ±8%, 앞 기울기 0.12~0.22 라디안. 멈출 때 움직임 비율을 0.3초에 0 으로 | 없음 |
| 빠른 개체가 차는 털 뭉치 | 없다 | 흰 크림 구(지름 0.05단위) 2~3개를 발밑에 남기고 0.6초에 0 으로 줄인다. InstancedMesh 하나로 최대 60개 | 없음 |
| 둥근 고딕 제목 | 둥근 글꼴이 없다 | 숫자·라틴은 InterVariable 800, 한국어는 Pretendard SemiBold. 제목 57px, 머릿수 105~120px(숫자라 140px 규칙과 상관없다), 글자색 #2C2D3D | 글자 끝의 둥근 인상 |
