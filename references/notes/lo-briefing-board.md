- 12초 판에서 판정을 둘로 줄일 때 · 판정 1(빨간 취소선, 모자람)과 판정 4(기준선을 크게 넘음, 빨간 타원)를 남긴다. 판정 3 의 아슬아슬한 경우는 뺀다. 두 판정 사이에 강둑 기준 점선 두 줄을 같은 가로 자리(17.7%, 69.5%)에 그대로 두어야 비교가 읽힌다.

## 7. 함정

- 강 폭 숫자, 다리 이름, 길이 숫자, 규칙·결론 문장, 자막, 메모 카드의 출처 표기(실존 기관·사진 작가·음원 이름), 끝 카드의 실존 연구실 이름과 모델 이름은 옮기지 않는다. 역할(강 폭, 선택지 넷, 규칙 하나, 결론 한 줄, 자막 상자)만 가져온다.
- 다리 사진은 실존 다리 사진이다. 원래 글과 이 저장소의 사실 규칙대로 둘 중 하나로만 만든다.
  - 사용자가 준 실제 사진과 출처를 쓴다. 숫자는 그 출처에서 직접 확인한 것만 쓰고, 출처를 끝 카드나 메모 카드에 적는다.
  - 사진이 없으면 `## 8` 의 선 그림 도해를 쓴다. 사진처럼 꾸민 AI 그림을 실존 사물로 내세우지 않는다.
- 처음부터 벽 전체를 보이면 끝이 사라진다. 대표 장면 전까지 보드 폭의 60% 이하만 보이고 양쪽 틀을 같이 보이지 않는다. `render.mjs --snap` 시트로 확인한다.
- 판정 멈춤을 줄이면 숫자를 못 읽는다. 12초 판에서도 판정마다 1.2초 이상 멈춘다.
- 보드를 순백 단색으로 두면 화면 속 화면이 된다. 밝기 기울기(#F1ECE4 → #CDCAC6)와 지운 자국을 넣는다.
- 원래 글의 함정 절은 그대로 맞다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 보드 전체(마지막 배율 0.28 이면 약 6870 x 3860px)를 한 DOM 무대에 놓고 카메라는 무대의 CSS 변형으로 움직인다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 창빛이 비치는 법랑 보드 | 법랑의 반사와 빛 감쇠 | 바탕에 왼쪽 위 → 오른쪽 아래 선형 그라데이션(#F1ECE4 → #CDCAC6). 지름 2000px 흰 타원 반사(불투명도 0.12, 반경 300px 흐림)를 카메라 이동의 0.3배로 미끄러지게. `texTile(seed, { mc: '120,115,105', mottle: .02, dark: .02, light: .03, fibers: 0, specks: 10 })` 를 곱하기로 아주 옅게 | 법랑 표면의 굴곡 |
| 지운 마커 자국 | 손으로 지운 흔적 | `HAND.ink(ctx, P, { frac: 1, w: 6, color: '#24211D' })` 로 선과 사각형 6~10개를 그린 canvas 를 불투명도 0.06, 반경 4px 흐림으로 한 번 구워 깐다 | 지우개 결의 방향 |
| 저절로 그려지는 마커 선 | 없다 | SVG 경로에 `stroke-dashoffset` 으로 손 속도(약 1200px/초, 끝에서 감속). 끝 둥글게, 굵기 9px, #3C5DB8. 경로를 `HAND.wobble(P, false, 1.2, 'line', 0)` 로 한 번 흔들어 쓴다(떨지 않는다) | 잉크 농담 |
| 손글씨풍 숫자와 글자 | 손글씨 글꼴이 없다 | 숫자 InterVariable 400 파랑, 한국어 Pretendard Regular·SemiBold 검정. 왼쪽에서 오른쪽으로 `clip-path` 를 글자당 0.08초로 열어 써지는 순서를 낸다. 투명도로 나타나게 하지 않는다 | 획 순서 |
| 다리·배 사진 출력물 | 실제 사진이다(`## 7`) | 사용자가 준 사진을 사물 모양대로 오려 투명 PNG 로 쓴다. 없으면 SVG 선 도해 · 상판, 교각, 탑, 케이블을 #24211D 3px 선과 #9A958C 면으로, 같은 시점(옆모습)과 같은 축척. 둘 다 그림자 6px 8px 흐림 6px 불투명도 0.25. 착지 때 그림자 거리 24px → 8px, 크기 1.06 → 1.0 을 0.3초, 끝에 2% 튕김 | 진짜 사물이라는 증거의 힘(사진이 없을 때) |
| 자석과 이름표 | 금속 광택 | 자석은 지름 30px 원에 방사형 그라데이션(#6A6C72 → #2A2B30)과 작은 흰 반사점. 박힐 때 크기 1.3 → 1.0 을 0.1초. 이름표는 #C4C2BC 판, 모서리 6px, 그림자 0 4px 8px 불투명도 0.2 | 없음 |
| 빨간 거부 도장 | 잉크 번짐 | 사각 테두리 6px + 글자, #D14E3A, -10°. `texTile` 얼룩 타일을 마스크로 20~30% 를 비운다. 찍힐 때 무대를 6px 흔들고 0.25초에 멈춘다 | 실제 도장의 번짐 |
| 강둑 기준 점선과 치수선 | 없다 | SVG. 기준 점선은 세로 전체, 3px, #3C5DB8, `stroke-dasharray: 14 10`. 치수선은 9px 마커 선에 양끝 화살촉(길이 28px, 폭 22px). 기준을 넘는 부분은 같은 높이에 빨간 점선(#D14E3A, 4px, 12 10)으로 기준선까지 잇는다. 숫자 고리는 `HAND.wobble` 로 한 번 흔든 타원 경로, 굵기 6px, 0.45초에 그린다 | 없음 |
| 움직임 흐림 | 셔터 흐림 | 이동 속도가 화면 폭의 40%/초를 넘는 칸에서만 무대에 CSS 흐림(속도에 비례 0~6px). 판정 멈춤에서는 0 | 방향 있는 흐림 |
| 구름 그림자 | 창밖 빛의 변화 | 지름 3000px 검정 흐린 타원(불투명도 0.07, 반경 400px 흐림)을 마지막 2초 동안 화면 폭의 30% 만큼 옮긴다 | 없음 |
