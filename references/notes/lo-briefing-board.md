# 공학 브리핑 화이트보드 · 선을 타고 근접 이동하다 마지막에 판 전체 — 분석 노트

> 창빛이 비치는 진짜 화이트보드 한 면을 찍은 40초 영상. 파랑·검정·빨강 세 색 마커 선이 저절로 그려지고, 모양대로 오려 낸 사진 출력물과 회색 이름표가 자석으로 붙는다. 하드 컷이 없다. 카메라는 선을 따라 근접에서 근접으로 옮기고, 기준과 비교하는 판정 화면에서 2.6~4.1초 멈춘다. 끝 약 2초에만 판 전체가 한 장의 포스터처럼 보인다. 선택지 비교, 공학 판단, 기준 대비 통과·탈락, 브리핑에 맞는다.

출처 · lo:briefing-board. 원래 글은 약 9천 자의 스타일 명세다(본질, 움직임, 카메라 문법 표, 함정, 시각과 확대 배율이 붙은 숏 표 17개, 판정 화면 폭 수치). 판과 잉크의 색 값, 출력물·이름표·자막 상자의 화면 크기, 마지막 판 전체의 배치, 움직임 세기의 실제 분포는 없다. 그래서 영상 프레임을 보고 이 노트를 썼다. 겹치는 내용은 짧게 적고 잰 값만 채운다.
측정 · 파일 1280x720 · 24fps · 40.0초. 크기는 1920x1080 기준으로 바꿔 적는다(1.5배). 하드 컷은 없다(장면 감지 0회). 움직임 세기 평균은 10.4 다. 큰 값은 8.5~9.5초(23.5~28.1, 도장과 흔들림), 18.5초(24.4), 22.5초(20.2), 28.0~29.0초(19.1~19.2, 출력물 착지 근접), 33.0초(32.3 최대, 낮게 내려가기), 35.5~36.0초(24.5~22.7, 마지막 물러나기)다. 판정 멈춤(16.0~17.5초, 20.0~21.5초, 24.0~27.5초, 31.0~32.0초)은 0.6~2.1 이다. 색 값은 프레임에서 잰 근삿값이다.

BPM 161.5(박 검출 164.2, 마디 약 1.46초). 가장 큰 타격(1.00, 킥)은 7.99초다. 바로 앞 7.00~8.00초가 무음이다. 출력물이 내려앉는 14.98초, 18.98초, 23.10초, 28.85초에 저역 비율 0.88~0.98 의 킥이 온다. 원래 글의 착지 시각과 0.03초 안에서 맞는다. 30.95초(0.95)는 마지막 숫자에 빨간 고리가 그려지는 자리다(원래 글은 31.25초). 35.16~35.74초(마지막 물러나기 직전)도 무음이다. 무음(-29dB 아래, 0.15초 이상)은 모두 25곳이다. 2.32~2.74, 2.82~3.00, 3.82~4.00, 5.08~5.24, 5.32~5.50, 7.00~8.00, 9.72~10.02, 10.56~10.76, 10.78~11.00, 11.04~11.32, 14.64~14.98, 15.34~15.50, 15.58~15.76, 18.32~18.50, 21.82~22.00, 22.22~22.50, 22.72~23.00, 23.84~24.00, 26.80~27.00, 27.62~27.78, 27.82~28.00, 28.08~28.50, 28.54~28.86, 35.16~35.74, 39.50~39.98초. 출력물 착지 킥 넷 중 셋 바로 앞에 0.2~0.35초 무음이 붙는다(14.64~14.98 → 14.98, 22.72~23.00 → 23.10, 28.54~28.86 → 28.85). 음량(0.25초 창)은 근접 이동 동안 -11~-20dB, 판정 멈춤 뒤쪽은 -27~-32dB 로 낮다(14.25~15.5, 18.0~19.5, 21.75~23.75, 26.75~29.5초). 판정 화면에서 소리를 줄여 숫자를 읽게 한다. 가장 큰 값은 5.75초 -11dB 이다. 끝은 39.25초 -25dB, 39.75초 -43dB 로 약 0.7초에 줄어든다. 길이는 40.0초다.

## 3. 움직임

- 원래 글의 움직임 규칙은 화면과 맞다.
- 영상에서 확인한 점 · 움직임 세기가 "착지 근접(17~24) → 판정 멈춤(0.6~2) → 다음 근접"으로 네 번 되풀이된다. 이것이 영상의 몸통이다.
- 빠른 이동에서는 화면 전체가 흐리고 멈추면 글자가 선명해진다. 판정 멈춤도 느린 밀기와 손떨림으로 0 이 아니다.
- 마지막 물러나기(0.25초 단위) · 보이는 판 폭이 약 15% → 20~28% → 40% → 60% → 80% → 95% → 100% 로 넓어진다. 움직임 세기는 24.5 → 22.7 → 17.0 → 17.0 → 16.3 → 16.3 → 3.1 이다. 처음 0.5초는 화면 전체가 움직임 흐림이고 이후 흐림이 줄어든다. 판 폭 약 95% 에서 양쪽 틀이 처음으로 함께 보인다. 판 폭 약 60% 에서 지시선이 그려지기 시작하고, 판 폭 80% 부터 결론 글자가 0.25초에 한 자씩 써진다.

## 4. 전환

- 컷·페이드가 없다. 판정 사이 이동은 모두 "내려가 다음 착지 근접(0.8~1.0초) → 물러나 판정(약 0.6초)"이다.

## 6. 가져올 것

- 핵심 장치 · 판 폭 60% 이하만 보이는 근접 이동을 이어 가다, 끝 약 2초에 한 번의 물러나기로 판 폭 15% → 100% 를 약 1.5초에 드러낸다. 그 전까지 판 양쪽 끝을 한 번도 같이 보이지 않고, 다 드러난 판에는 빈 가운데가 없다(요소 약 30개).
- 핵심 장치 · 착지 근접(움직임 세기 17~24, 0.8~1.0초) → 물러나 판정 멈춤(0.6~2.1, 1.2초 이상)을 되풀이한다. 판정마다 앞 결과를 화면 위 0~15% 에 잘린 채 남겨 계단처럼 쌓고, 기준 점선 두 줄은 내내 같은 가로 자리(17.7%, 69.5%)에 둔다.
- 핵심 장치 · 요소가 내려앉는 순간에 킥, 그 직전 0.2~0.35초 무음. 판정 화면에서는 음량을 -27~-32dB 로 낮춰 숫자를 읽게 한다.
- 판정 수를 줄일 때는 모자란 경우와 기준을 크게 넘는 경우처럼 대비가 큰 둘을 남긴다. 두 판정 사이에 기준 점선 두 줄을 같은 가로 자리에 그대로 두어야 비교가 읽힌다.

## 7. 함정

- 원본의 출력물은 실존 사물의 사진이다. 원래 글과 이 저장소의 사실 규칙대로 둘 중 하나로만 만든다.
  - 사용자가 준 실제 사진과 출처를 쓴다. 숫자는 그 출처에서 직접 확인한 것만 쓰고, 출처를 끝 카드나 메모 카드에 적는다.
  - 사진이 없으면 `## 8` 의 선 그림 도해를 쓴다. 사진처럼 꾸민 AI 그림을 실존 사물로 내세우지 않는다.
- 원본 화면의 실존 로고·이름은 쓰지 않는다.
- 처음부터 판 전체를 보이면 끝이 사라진다. 마지막 물러나기 전까지 판 폭의 60% 이하만 보이고 양쪽 틀을 같이 보이지 않는다. `render.mjs --snap` 시트로 확인한다.
- 판정 멈춤을 줄이면 숫자를 못 읽는다. 짧은 판에서도 판정마다 1.2초 이상 멈춘다.
- 판을 순백 단색으로 두면 화면 속 화면이 된다. 밝기 기울기(#F1ECE4 → #CDCAC6)와 지운 자국을 넣는다.
- 원래 글의 함정 절은 그대로 맞다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

값은 1920x1080 기준이다. 판 전체(마지막 배율 0.28 이면 약 6870 x 3860px)를 한 DOM 무대에 놓고 카메라는 무대의 CSS 변형으로 움직인다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
