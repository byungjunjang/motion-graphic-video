# Torn-Paper Safari Collage — 분석 노트

> 찢은 종이(torn paper) 층으로 쌓은 풍경 위에 사진 오려내기(photo cut-out)를 붙인 15초 종이 콜라주(paper collage) 캠페인 스팟. 화면 전체가 12fps 스톱모션(stop-motion)처럼 끊겨 움직인다. 카메라가 사물 안으로 들어가고 구멍으로 나오면서 다섯 장면을 컷 없이 잇는다. 망점(halftone) 인쇄 조각, 만화경(kaleidoscope) 터널, 종이 넘김(page peel)으로 로고를 연다.

측정 · 파일 736x414 · 23.976fps · 15.0초. 프레임 차이를 재면 초당 11~17번(평균 13번) 화면이 바뀐다. 전 구간이 2프레임에 한 번 갱신된다.
소리는 확인하지 않았다.

## 1. 본질

- 재료는 세 가지다. 찢은 색종이(가장자리에 흰 종이 심이 보인다), 망점 인쇄 조각, 흰 테두리를 남기고 오린 사진.
- 풍경을 그리지 않고 쌓는다. 하늘·산·초원이 각각 찢은 종이 띠 한 장이다. 띠마다 깊이가 다르다.
- 색은 원색 네 개(하늘색·빨강·주황·연두)다. 흑백 바위 사진 조각이 원색 종이 사이에서 무게를 잡는다.
- 카메라가 주인공을 따라간다. 사물 안으로 들어가고, 구멍으로 나오고, 위로 솟는다. 장면 사이에 하드 컷이 없다.
- 아닌 것 · 매끈한 벡터 일러스트, 부드러운 그라데이션, 매 프레임 미끄러지는 움직임, 그림자 없는 조각.

## 2. 시간표

| 구간(초) | 화면 | 움직임 |
|---|---|---|
| 0.0–0.3 | 빈 풍경. 찢은 종이 초원·하늘, 나무 사진 조각 | 정지 |
| 0.3–0.6 | 큰 사물 조각(카세트 라디오 사진)이 위에서 떨어진다 | 기울어진 채 내려와 3~4칸 만에 똑바로 안착 |
| 0.6–3.2 | 동물 조각이 하나씩 튀어나온다 | 뒤쪽 바위 위(작게) → 왼쪽 가장자리 → 앞쪽 아래에서 얼굴이 크게. 깊이 세 층을 번갈아 쓴다 |
| 3.2–4.0 | 카메라가 스피커 원으로 밀고 들어간다 | 원이 찢어지며 빨강 → 하늘색 → 노랑 종이 층이 조리개처럼 열린다 |
| 4.0–6.0 | 만화경 터널 | 방사 대칭으로 복제한 조각이 고리째 바깥으로 밀려나고 가운데에서 새 고리가 생긴다. 2칸마다 고리가 바뀐다 |
| 6.0–6.5 | 터널 가운데 구멍에서 새가 날아 나온다 | 구멍이 커져 다음 장면의 하늘이 된다 |
| 6.5–8.5 | 새 비행 숏 | 새 조각은 화면에 거의 고정. 배경 종이 띠가 대각선으로 흐른다. 카메라가 정면에서 위에서 내려다보는 각도로 돈다 |
| 8.5–10.5 | 새가 나가고 카메라가 내려가 무리 장면 | 조각마다 사진 2~3장을 바꿔 고개를 돌린다 |
| 10.5–11.5 | 한 마리가 색색 종이 띠 다발을 타고 수직으로 솟는다 | 종이 구름이 양옆에 부푼다. 카메라가 따라 올라간다 |
| 11.5–13.2 | 제목 두 줄이 위에서 떨어져 안착 | 새가 제목 앞을 가로질러 지나간다 |
| 13.2–13.6 | 종이 넘김 | 파란 종이가 오른쪽에서 말려 넘어가고, 찢은 흰 띠 위의 로고가 드러난다 |
| 13.7–14.4 | 로고 깜빡임 | 로고가 0.1~0.2초씩 다른 그림체(검은 바탕 글리치, 만화, 분홍, 네온) 6~7개로 바뀐 뒤 종이 띠로 돌아온다 |
| 14.4–15.0 | 로고 정지 | |

## 3. 움직임

- 전 구간 12fps 끊김. 조각의 위치와 각도가 칸마다 조금씩 어긋난다.
- 등장은 미끄러지지 않는다. 조각이 화면 밖에서 툭 올라오거나 떨어져서 2~4칸 만에 멈춘다.
- 풍경 종이는 가만히 있고 사물 조각만 움직인다. 카메라가 움직일 때만 풍경 띠가 깊이마다 다른 속도로 흐른다.
- 새 그림자는 새와 떨어져서 배경 종이 위를 따로 움직인다. 이 간격이 높이를 만든다.
- 사진 조각의 연기는 변형이 아니라 교체다. 같은 동물의 다른 사진 2~3장을 바꿔 끼운다.

## 4. 전환

1. 사물 속으로 · 스피커 원을 찢어 열고 그 안으로 들어간다.
2. 터널 · 같은 재료를 방사 대칭으로 복제해 만화경을 만든다. 새 재료 없이 2초를 채운다.
3. 구멍으로 나오기 · 터널 가운데 구멍이 다음 장면이 된다.
4. 주인공 따라가기 · 새가 나가는 방향의 반대로 카메라가 내려간다. 솟는 조각을 카메라가 따라 올라간다.
5. 종이 넘김 · 종이 한 장이 말려 넘어가며 아래 층을 드러낸다. 말린 종이 아래에 부드러운 그림자가 있다.

## 5. 타이포

- 제목은 굵은 세리프 두 줄이다. 빨강 글자, 파랑 어긋난 그림자, 흰 테두리 세 겹이다. 오려 붙인 글자처럼 보인다.
- 로고는 찢은 흰 종이 띠 위에 놓인다. 띠 아래위로 색종이 조각이 삐져나온다.
- 본문 문구는 없다. 글자는 제목과 로고 두 번만 나온다.

## 6. 가져올 것

- 찢은 종이 띠로 풍경을 쌓는 구성. 띠 가장자리에 흰 심을 한 겹 더 둔다.
- 깊이 세 층에 번갈아 등장하는 조각.
- "사물 속으로 → 터널 → 구멍으로 나오기" 세 단계 전환.
- 그림자를 조각과 따로 움직여 높이를 만드는 방법.
- 끝의 로고 깜빡임. 같은 자리에서 그림체만 바꾼다.

## 7. 함정

- 사진 오려내기가 주 재료다. 동물과 사물 사진이 없으면 이 화면은 나오지 않는다. 그려서 대신하면 다른 톤이 된다.
- 실존 기관의 캠페인이다. 제목·로고·동물 구성을 옮기지 않는다.
- 만화경 터널은 조각 수가 많다. 12fps 로 끊어야 무겁지 않게 보인다.
- 원색 네 개가 모두 세다. 흑백 조각과 흰 종이 심이 없으면 화면이 뭉개진다.
