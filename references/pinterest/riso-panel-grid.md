# 리소 패널 격자 · 세 잉크 겹침과 8fps 루프 칸 8개 — 분석 노트

> 리소 인쇄(risograph) 질감의 정사각 패널 8칸이 4x2 격자(panel grid)로 놓이고, 칸마다 다른 6초 루프(loop)가 동시에 도는 42초 영상. 카메라가 한 숏으로 인쇄 시트(print sheet) 전체까지 물러났다가 칸 하나씩 가까이 훑고 다시 격자로 돌아온다. 노랑·파랑·빨강 세 잉크의 겹침(overprint), 망점 그라데이션(halftone grain), 판 어긋남(misregistration), 8fps 끊김, 루프마다 바뀌는 종이색. 화상 회의·협업·창작 도구 같은 주제의 분위기 영상에 맞는다.

측정 · 파일 736x414 · 8fps · 42.0초(336프레임). 장면 전환으로 잡힌 곳은 0번이다. 전 구간이 한 숏이다. 모든 프레임이 앞 프레임과 다르다. 움직임은 13.5~15.0초(시트에서 한 칸으로 확대)와 28.5초, 31.5초, 36.0~37.5초에 가장 크다. 루프 길이는 48프레임(6.0초)이다. 인쇄 시트 모서리의 프레임 번호가 0.5초에 4씩 오르고 12.0초에 1로 돌아간다. 색 값은 프레임에서 잰 근삿값이다.
소리 · 듣지 못했다. 측정값만 적는다. BPM 74.9(마디 3.2초). 큰 타격 40개가 3.44초부터 38.63초까지 고르게 있다. 루프 경계(6초 간격)는 마디(3.2초 간격)와 맞지 않는다. 가장 큰 화면 변화(13.5초 확대)는 큰 타격(13.03초) 0.5초 뒤다. 타격과 화면 사건의 대응은 확인하지 못했다.

쓰는 법 · 이 노트는 스타일 문법(색·질감·크기 비율·움직임·전환·타이포·밀도)만 적는다. 원본의 소재·장면·순서는 적지 않았다. 숫자는 원본 영상을 보고 잰 근삿값이다.

## 1. 본질

- 프레임 한 장이 인쇄물 한 장이다. 프레임마다 종이 결, 잉크 얼룩, 판 위치가 조금씩 다르다. 그래서 가만히 있는 도형도 떨린다.
- 잉크는 세 가지다. 형광 노랑(#F9EA1C 근처), 파랑(#1C3AB0 근처), 주홍빛 빨강(#FF3F21 근처). 겹치면 짙은 초록(파랑+노랑), 주황(빨강+노랑), 남보라(파랑+빨강)가 된다. 검정 잉크는 없다. 가장 어두운 색은 세 잉크가 겹친 자리다.
- 그라데이션은 망점 알갱이로만 만든다. 매끈한 그라데이션이 없다. 알갱이 밀도가 변한다.
- 구도는 격자다. 정사각 패널 8칸이 화면의 가로 4~96%, 세로 7~86%를 채운다. 칸 하나는 화면 폭의 약 21%(1920 기준 410px)다. 칸 사이 간격은 화면 폭의 2.6%쯤(50px)이다. 아래 가운데에 파란 알약 모양 막대(폭 49%)가 있다. 칸 아래마다 작은 도형 아이콘 줄이 있다.
- 종이색이 루프마다 바뀐다. 흰 종이(#F8F8F8 근처) → 크림(#F0E8D0 근처) → 누런 종이(#F3D170 근처) → 크림 → 흰 종이. 같은 그림을 다른 종이에 찍은 것처럼 보인다. 누런 종이는 24~30초의 6초뿐이다. 나머지 36초는 흰 종이나 크림이다.
- 아닌 것 · 매끈한 벡터 평면색, 부드러운 그림자, 24fps 이상의 미끄러운 움직임, 장면 사이 컷.

## 2. 리듬 표

모든 칸이 같은 6초 루프 안에서 돈다. 아래는 카메라의 리듬이다.

|---|---|---|---|---|

| 85.5–90.5 | 격자 전체로 물러난다 | 36.0~37.5초에 크다 | 격자 전체. 흰 종이로 돌아온다 | 물러나기 |
| 90.5–100 | 고정 | 칸 안에서만 움직인다 | 처음과 같은 화면 | 없음 |

## 3. 움직임

- 8fps 다. 1초에 그림 8장이다. 움직이는 도형은 1초에 8번만 자리를 바꾼다.
- 떨림이 두 겹이다. 도형의 움직임(의도한 것)과 인쇄물마다 다른 판 위치·잉크 농도(재료에서 나온 것). 뒤의 것은 가만히 있는 칸에도 있다.
- 색판이 서로 조금 어긋난다(칸 폭의 1~2%로 보인다). 노란 원의 가장자리에 파랑이나 빨강 테가 삐져나온다. 어긋나는 방향이 프레임마다 다르다.
- 칸 안의 변화는 변형이 아니라 교체다. 윤곽 → 반쯤 참 → 다 참으로 그림이 바뀐다. 중간 보간이 없다.
- 칸 안 변화의 종류 · 작게 나타나 커지기, 하나가 여러 개로 늘어 흩어지기, 윤곽에 색이 차기, 줄마다 색이 바뀌기, 가로 막대 글리치 → 사각 조각으로 부서짐 → 낙서 선으로 다시 그려짐, 제자리 반복 동작. 한 칸은 6초 안에서 3~4단계로 바뀐다.
- 카메라는 끊기지 않는다. 물러나기·확대·훑기가 모두 한 숏이다. 다만 8fps 라서 카메라 이동도 계단처럼 보인다.
- 근접 구간의 카메라는 칸에서 멈추지 않는다. 같은 속도로 계속 흐르고, 칸 하나가 약 3초에 지나간다. 칸의 루프(6초)를 다 보여 주지 않는다.

자리와 크기 (1920x1080 환산 · 잰 근삿값)
- 확대 배율 · 근접 화면은 격자 화면의 약 2.4배다. 칸 하나가 화면 폭의 50%(965px), 높이의 92%를 채운다. 옆 칸까지의 거리(칸+간격)는 화면 폭의 57%다.
- 카메라 속도 · 수평 훑기는 초당 화면 폭의 약 18.5%(355px/s)로 일정하다. 8fps 한 장마다 약 44px 씩 옮긴다. 줄을 바꾸는 수직 이동은 초당 화면 높이의 약 40%로 2.4초 걸린다. 확대는 2.4초, 물러나기는 2초다.
- 칸 안 도형 · 주인공 도형은 지름이 칸 폭의 약 61%, 보조 도형은 약 32%다. 도형이 칸을 거의 채운다. 칸 가장자리 안쪽 여백은 칸 폭의 5~10%뿐이다.
- 손그림 선 굵기 · 빨간 손그림 선은 칸 폭의 약 2.5%다(근접 화면 24px, 격자 화면 10px). 가장자리가 크레용처럼 거칠고 선 안에 종이색 빈틈이 있다.
- 망점 · 회색 바탕과 하늘 자리는 사선 줄 망점이다. 줄 간격은 근접 화면에서 약 9px, 격자 화면에서 약 4px 다. 회색은 파랑과 노랑 알갱이가 섞여서 생긴다. 망점 하늘은 주황 → 노랑으로 간다.
- 판 어긋남 · 근접 화면에서 약 11px, 격자 화면에서 약 4~5px(칸 폭의 1~1.2%)다. 빨간 원 둘레에 노란 테가 보인다.

## 4. 전환

- 컷이 없다. 전환은 카메라 이동 세 가지다.
1. 물러나기 · 격자 → 맞춤 십자가 보이는 한 프레임 → 프레임이 여러 장 찍힌 시트. 영상이 인쇄물이라는 것을 드러낸다.
2. 확대 · 시트에서 한 프레임, 다시 한 칸으로. 2.4초.
3. 훑기 · 칸에서 옆 칸으로 수평 이동, 줄을 바꿀 때 수직 이동.
- 종이색 교체가 장의 경계 구실을 한다. 6.0초, 24.0초, 30.0초, 35초 앞뒤에서 바뀐다. 루프 경계와 겹친다.

## 5. 타이포

- 읽는 글자가 거의 없다. 글자 자리는 글자 대신 가로 선이다. 칸 아래 표시는 작은 도형 줄이다.
- 글자처럼 보이는 것은 손으로 쓴 곱슬 선과 낙서 선이다. 뜻이 없다.
- 실제 글자는 인쇄 시트의 가장자리에만 있다(프레임 번호, 잉크 색 이름, 손글씨 메모). 화면이 물러났을 때만 보인다.

## 6. 가져올 것

- 핵심 장치 · 정사각 칸 8개(칸 폭 화면의 21%, 간격 2.6%)가 4x2 격자로 같은 길이(6초)의 루프를 동시에 돌고, 칸 안 변화는 보간 없는 그림 교체다.
- 핵심 장치 · 카메라가 한 숏으로 전체 격자 → 인쇄 시트로 물러남(2초) → 한 칸으로 확대(2.4초, 약 2.4배) → 초당 화면 폭 18.5% 로 멈추지 않는 수평 훑기 → 전체 격자로 움직이고, 8fps 로 계단처럼 간다.
- 핵심 장치 · 프레임마다 판 위치(근접 ±11px, 격자 ±4px)·알갱이·잉크 농도를 8fps 로 바꿔 가만히 있는 도형도 떨게 한다.
- 핵심 장치 · 루프 경계마다 종이색(#F8F8F8 → #F0E8D0 → #F3D170 → #F0E8D0 → #F8F8F8)을 바꿔 같은 그림에 장 경계를 만든다.
- 세 잉크와 겹침색만 쓰는 팔레트. 검정을 쓰지 않는다.
- 망점 알갱이 밀도로 만드는 그라데이션.

## 7. 함정

- 실제 인쇄물을 스캔한 영상으로 보인다. 코드로 만들면 알갱이·얼룩·어긋남을 프레임마다 다시 계산해야 한다. 고정된 질감을 한 장 덮으면 떨림이 사라진다.
- 8fps 는 렌더 fps 가 아니라 그림 갱신 주기다. 30fps 로 렌더하면 같은 그림을 3~4프레임씩 유지한다.
- 설명 문구가 없다. 정보 전달 영상에 쓰려면 글자 칸을 따로 만들어야 한다. 글자도 같은 잉크와 알갱이로 찍어야 섞인다.
- 세 잉크가 모두 진하다. 종이 여백(칸 사이 간격, 흰 빈 면)이 없으면 화면이 막힌다.
- 6초 루프를 7번 되풀이한다. 카메라 이동이 없으면 12초 뒤에는 볼 것이 없다.

## 8. 코드로 재현 못 하는 요소와 대체 방법

AI 이미지와 외부 사진은 쓰지 않는다고 본다. 값은 1920x1080 기준이다. 칸은 근접 크기(965px)로 그리고, 격자 화면은 CSS `scale(0.42)` 로 줄여 만든다. 그래야 확대해도 선과 망점이 뭉개지지 않는다.

| 요소 | 왜 어려운가 | 대체 방법(구체 값) | 대체하면 잃는 것 |
|---|---|---|---|
| 크레용 결 손그림 선(빨간 손그림 선) | 손으로 그은 선의 거친 가장자리와 빈틈 | `HAND.ink(ctx, P, { w: 24, amt: 2.5, color: '#FF3F21', double: true, key, B })`. 선을 오프스크린 canvas 에 그린 뒤 `destination-out` 으로 2px 잡음 점(면적의 약 15%)을 지워 빈틈을 낸다. 잡음 판은 3장 굽고 B 로 고른다 | 누르는 힘에 따른 굵기 차 |
| 색연필 낙서 도형 | 수백 번 겹친 낙서 획 | `HAND.paint(ctx, 도형 P, { fill: false, line: false, tex: [{ k: 'pencil', color: '#FF3F21', len: 22, w: 3, per: 90, alpha: .85 }, { k: 'pencil', color: '#1C3AB0', angle: .6, len: 18, w: 3, per: 140, alpha: .8 }] })` | 획의 방향 흐름 |
| 망점 도형·망점 바탕 | 인쇄 망점 스캔 | canvas 에 사선 45° 줄 망점을 굽는다. 줄 간격 9px, 줄 굵기 = 9px × 밀도(0.2~0.8). 회색은 파랑 판(45°)과 노랑 판(15°)을 각각 9px 간격으로 겹쳐 만든다. 원형 망점이 필요하면 칸 9px, 점 지름 = 9px × √밀도 | 알갱이의 불규칙한 번짐 |
| 망점 그라데이션 면 | 매끈한 그라데이션을 쓰면 안 된다 | 위 망점에서 밀도를 세로 위치로 바꾼다. 빨강 판 밀도 0.8→0.1, 노랑 판 0.3→0.9(위→아래). 그라데이션 CSS 를 쓰지 않는다 | 없음에 가깝다 |
| 판 어긋남 | 인쇄 때 생긴 우연 | 잉크마다 canvas 층(노랑·파랑·빨강)을 따로 두고 `mix-blend-mode: multiply` 로 겹친다. 노랑 판은 고정하고 파랑·빨강 판만 ±11px(격자 화면에서는 ±4px) 안에서 옮긴다. 값은 `floor(t*8)` 를 씨앗으로 한 난수로 정해 8fps 로 바꾼다 | 판이 휘는 어긋남 |
| 잉크 겹침색 | 없다. 곱하기로 된다 | #F9EA1C·#1C3AB0·#FF3F21 를 곱하기로 겹친다. 검정은 쓰지 않는다 | 실제 잉크의 반투명 차이 |
| 종이 결·얼룩의 떨림 | 프레임마다 다른 인쇄물 | `texTile(seed, { mc: '128,128,128', mottle: .04, dark: .04, fibers: 160 })` 3장을 굽고 `floor(t*8) % 3` 으로 고른다. 그레인은 `grainLayer()` 가 돌려준 함수에 `Math.floor(t*8)/8` 을 넘긴다. 기본값 `mc`(120,95,60)는 화면을 누렇게 만들므로 바꾼다 | 잉크 얼룩의 위치 차 |
| 8fps 끊김 | 없다 | 그리는 t 를 `Math.floor(t*8)/8` 로 끊는다. 카메라 이동도 같은 t 로 계산한다. 렌더는 30fps 로 하고 같은 그림을 3~4프레임 유지한다 | 없음 |
