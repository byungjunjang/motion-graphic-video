# 소리 만들기 (코드 합성)

이 문서는 소리 방식이 `합성` 일 때만 쓴다. ElevenLabs 커넥터가 없고 사용자가 음원 파일을 주지 않은 경우다.
`scripts/synth.py` 가 배경음악과 효과음을 코드로 만든다. 크레딧이 들지 않는다. 같은 인자에는 항상 같은 파일이 나온다. numpy 가 필요하다.

- 내레이션은 만들지 않는다. 내레이션은 ElevenLabs 로만 만든다. 대사 대신 화면 문구로 전달한다.
- 외부 무료 음원을 찾아 내려받지 않는다.
- 스토리보드의 `음악 흐름` 은 아래 분위기 이름과 정점 시각으로 적는다. 악기 이름은 분위기에 정해져 있다.

## 1. 분위기 고르기

`python3 scripts/synth.py list` 로 분위기와 효과음 목록을 본다. 톤에 맞춰 고른다.

| 분위기 | BPM | 톤 |
|---|---|---|
| `calm` | 92 | 에디토리얼 제품 필름, 미니멀 UI, 인포그래픽, 블루프린트, 단면도 |
| `tech` | 120 | 키네틱 타이포, HUD, 다크 네온, 사이버펑크, ASCII, 크롬·Y2K |
| `bright` | 112 | 손그림, 클레이, 카툰, 스톱모션, 복셀, 화이트보드, 콜라주 |
| `cinematic` | 72 | 시네마틱 3D, 파티클, 글래스모픽 3D, 애니, 수묵, 판화·인쇄 |
| `chip` | 132 | 픽셀 |

목록에 없는 톤은 움직임 프로필로 고른다. `smooth`·`draw` 는 `calm`, `snap`·`flicker` 는 `tech`, `squash`·`boil` 은 `bright`, `drift` 는 `cinematic` 이다.

## 2. 음악

장면 시각을 정한 뒤에 만든다. 음악이 장면에 맞추지 않고, 장면 전환을 음악의 마디 첫 박에 놓는다.

1. 정점 장면의 시작 시각을 정한다. 보통 영상 길이의 55~65% 지점이다.
2. 실행한다.
   ```bash
   python3 scripts/synth.py music videos/<id> --mood <분위기> --peak <정점 시작 초>
   ```
   - 마디 격자가 `--peak` 를 지나도록 놓는다. 정점 첫 박은 정확히 `--peak` 에 온다.
   - 흐름 · 도입(패드와 리드 1개, 타악기 없음) → 고조(정점 4마디 앞부터 베이스·하이햇, 마지막 마디에 riser) → 정점(킥·클랩) → 종결 화음.
   - 종결 화음은 영상 끝 2.5초 앞에 가장 가까운 마디 첫 박에 온다. 다른 시각이 필요하면 `--end <초>` 를 준다.
   - 템포를 바꾸려면 `--bpm <값>` 을 준다. 마디 길이가 장면 길이와 맞지 않을 때 쓴다.
   - `cinematic` 은 정점 0.4초 앞을 약 −30dB 로 줄인다. 바닥 소리는 남는다.
3. 출력의 `마디 첫 박` 줄을 본다. 장면 전환 시각을 이 시각 가운데 하나로 옮긴다. 스토리보드의 장면 길이가 1초 안에서 바뀌는 것은 알리지 않아도 된다. 그보다 크게 바뀌면 사용자에게 알린다.
4. 스크립트가 세 곳을 쓴다.
   - `assets/bgm/synth_<분위기>.wav`
   - `video.json` 의 `audio.music` · `{"file", "delay": 0, "gain": [1, 1, 0, 1]}`. 도입·고조·정점의 크기 차이는 합성할 때 넣었으므로 `gain` 을 올리지 않는다. `cut`·`repeat`·`intro_boost` 는 쓰지 않는다.
   - `video.json` 의 `beats` 와 `src/beats.js`. 형식은 `audio-probe.py --onsets --write` 와 같다. 박을 직접 정했으므로 `--onsets` 로 다시 재지 않는다.
5. 장면 시각을 고쳐 정점이 바뀌면 2번을 다시 실행한다. 크레딧이 들지 않는다.

## 3. 효과음

1. 실행한다. 종류를 빼면 10종을 모두 만든다.
   ```bash
   python3 scripts/synth.py sfx videos/<id> click whoosh impact
   python3 scripts/synth.py sfx videos/<id> riser --len 1.2
   ```
2. 3종 안팎을 쓴다. 등장음(`click`·`pop`·`tick`), 전환음(`whoosh`), 톤에 맞는 소리 하나(`shimmer`·`paper`·`key`·`blip`·`impact`).
3. `video.json` 의 `sfx` 에 `[파일, 시각, 음량, 동기점]` 을 적는다. 배치 규칙은 `audio-elevenlabs.md` §3 의 4·5번과 같다.
   - `whoosh` · `"peak"` 를 전환 움직임 시작 4프레임 앞에 둔다.
   - `click`·`tick`·`pop`·`key` · `"onset"` 을 사건 1프레임 앞에 둔다.
   - `riser` · 동기점에 파일 길이(기본 1.5)를 숫자로 적고 시각 칸에 타격 시각을 적는다.
   - `impact` · `"onset"` 을 정점 첫 박에 둔다. 음악에 정점 킥이 이미 있으므로 음량은 0.5~0.6 으로 둔다.

## 4. 믹스 확인

`audio-elevenlabs.md` §4 와 같다. 내레이션이 없으므로 목소리 비교 줄은 나오지 않는다.

시험한 값 (30초 영상, `calm`, 정점 18초, 효과음 4개) · `mix.py` 경고 없음, 통합 음량 −16.2 LUFS, 정점 구간이 도입보다 약 10dB 크다. 측정값이다. 소리의 질은 들어 보지 않았다. 보고에 그렇게 적는다.
